# 复习策略：间隔回看与交叉练习排期

> 适用学段：小学中段 / 小学高段 / 初中（高中同样适用）。
> 配合 `xiaozhi-teach-review-planner` 使用。本文件只放**排期工具**；
> 知识图谱四层与可视化见 `knowledge-map-example.md`，重难点清单见 `key-points-checklist-template.md`，
> 复习活动样例见 `review-activity-library.md`，阶段策略与话术见 [`../SKILL.md`](../SKILL.md) §6、§8。
> （上一版本文件把这四份内容各抄了一遍，两处漂移严重，已改为只保留一份。）

## 一、间隔回看排期表（1 / 3 / 7 / 14 天）

写入 `classWorkspace.reviewPlans[].spacingSchedule`。一个知识点在复习期内至少 4 次接触。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📅 间隔回看排期 · [单元/考试]     考试日：[    ]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
知识点            │ D0 首讲/首复 │ +1 天 │ +3 天 │ +7 天 │ +14 天
──────────────────┼──────────────┼───────┼───────┼───────┼────────
[知识点 1]        │              │       │       │       │
[知识点 2]        │              │       │       │       │
[知识点 3]        │              │       │       │       │
[知识点 4]        │              │       │       │       │
──────────────────┴──────────────┴───────┴───────┴───────┴────────

每次回看做什么（时长是课堂内的嵌入时间，不是额外作业）：
  +1 天  ：5-8 分钟 · 合上书凭记忆说一遍（主动回忆，写在纸上或说给同桌）
  +3 天  ：8-10 分钟 · 做 1-2 道同型题，做完说一句"我凭什么判断用这个方法"
  +7 天  ：10 分钟 · 做 1 道变式题 + 与相邻知识点对比
  +14 天 ：并入交叉练习组（见 §二），不再单独安排

压缩规则：
  · 距考不足 14 天 → 只排 +1 / +3 / +7
  · 距考不足 7 天  → 只排 +1 / +3
  · 撞周末/假期 → 顺延到下一个上课日，不要把两次回看挤到同一天

一条常见误用：
  ❌ 把"回看"做成"再讲一遍 PPT"。
  ✅ 回看的核心动作是**取出来**：先让学生凭记忆产出，再对照课本补漏。
     学生"看着眼熟"和"能自己说出来"之间的差距，就是考场上会不会做的差距。
```

## 二、交叉练习组合表

写入 `classWorkspace.reviewPlans[].interleavingSets`。每组 2-3 个**真的容易混**的知识点。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔀 交叉练习组合 · [单元/考试]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
组 ①：[知识点 A] + [知识点 B]
   为什么容易混：[方法相似 / 题面相似 / 条件只差一点]
   辨别问题（每题做完必问）：[如"这题给的是两点还是斜率与一点？"]
   题目来源：[交给 assignment-designer 按本组配 4-6 题，打散顺序]

组 ②：[知识点 C] + [知识点 D] + [知识点 E]
   为什么容易混：
   辨别问题：
   题目来源：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

组合原则：

- 只把**易混**的放一组。毫不相干的知识点凑一起只是打乱顺序，不产生辨别，等于白花时间。
- 题目顺序必须打散，不按知识点分块——分块排列时学生不需要判断用哪个方法，练的是执行不是选择。
- 每题做完先答"你凭什么判断用这个方法"，再核对答案。判断依据说不出来的，等于没练到。
- **不在首次学习时交叉**：新学的内容先集中练到会（至少走完 +3 天回看），再进交叉。
- 交叉练习的主场是**距考 7-14 天**的强化整合阶段；距考 3 天内不新增组合。

## 四、自检清单

每次输出复习计划前，AI 必须自检：

- [ ] 重难点是否基于 `classWorkspace.weaknessRank`（而不是凭印象）
- [ ] 每个 🔴 必复习知识点是否都进了间隔回看表
- [ ] 间隔序列是否按距考天数做了压缩（<14 天去掉 +14，<7 天只留 +1/+3）
- [ ] 交叉组合里的知识点是不是**真的易混**，每组是否写了"辨别问题"
- [ ] 交叉练习是否安排在距考 7-14 天，且不在首次学习时使用
- [ ] 距考 7 天内是否已停止引入新知识点
- [ ] 考试当天的安排里是否**没有**点弱项、没有新错题清单、没有公布成绩
- [ ] 就寝时间是否按学段引用 `shared/grade-bands.md`，没有写死"8 小时"
- [ ] 是否只输出了"计划"，把具体题目留给了 `xiaozhi-teach-assignment-designer`
- [ ] 是否避免了承诺提分、避开了焦虑话术
- [ ] 写入 reviewPlans 前是否做了脱敏（无姓名、无分数、无排名）

---

> **使用提示**：先填 §一 的回看表（它决定这几周每节课要抠出的 5-10 分钟），再填 §二 的交叉组合，
> 最后合成 §三 的周历交给老师。不要直接套模板，必须按本班的 weaknessRank 调。
