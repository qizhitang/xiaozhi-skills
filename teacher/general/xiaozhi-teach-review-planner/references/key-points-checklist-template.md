# 重难点清单模板

> 适用学段：小学中段 / 小学高段 / 初中（高中同样适用）。
> 对应 `xiaozhi-teach-review-planner` SKILL.md §5.2。得分率来自 `classWorkspace.weaknessRank` 与 `itemStats`。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 重难点清单 · [单元]      考试日：[    ]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 重点（必须掌握）
  ① 知识点 [   ]：[理由] · 课标权重 [   ] · 学情得分率 [   ]（🔴/🟡/🟢）
  ② 知识点 [   ]：[理由] · 课标权重 [   ] · 学情得分率 [   ]（🔴/🟡/🟢）
  ③ 知识点 [   ]：[理由] · 课标权重 [   ] · 学情得分率 [   ]（🔴/🟡/🟢）

■ 难点（需要重点突破）
  ① 知识点 [   ]：[难点表现] · 通用错因维度 [   ] · 突破策略 [   ]
  ② 知识点 [   ]：[难点表现] · 通用错因维度 [   ] · 突破策略 [   ]

■ 易混组（进交叉练习，见 review-strategy.md §二）
  组 ①：[知识点 A] + [知识点 B] · 混在哪一点：[   ]
  组 ②：[知识点 C] + [知识点 D] · 混在哪一点：[   ]

■ 非重点（快速过）
  知识点 [   ] [   ] [   ]

■ ⚪ 待复核（暂不排进计划）
  第 [   ] 题所在知识点：得分率 <10% 且题目本身存疑 → 先查题
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
