# 课后 5 分钟观察记录模板

> 适用学段：小学中段 / 小学高段 / 初中（高中同样适用）。
> 对应 `classWorkspace.interactionLogs`。本模板**没有学生姓名栏**：课堂印象是单次、低置信度的观察，
> 挂到具体学生名下容易固化标签。要定位到个人的结论走 `xiaozhi-teach-student-analyzer` 的逐题数据。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📝 课后 5 分钟观察记录
日期：[   ]   对应教案 planId：[   ]   课题：[   ]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 环节用时（→ segmentTimings，下次排时间矩阵用）
  导入 计划 [  ] / 实际 [  ]    新授 计划 [  ] / 实际 [  ]
  练习 计划 [  ] / 实际 [  ]    巩固 计划 [  ] / 实际 [  ]
  总结 计划 [  ] / 实际 [  ]    作业 计划 [  ] / 实际 [  ]

■ 整体参与度（→ participationNote，只写整体，不写姓名）
  · 主动举手：约 [   ] 人 / [   ] 人（上次约 [   ] 人）
  · 小组任务：[   ] 组按时产出结论，[   ] 组超时
  · 冷场：[N] 次，候场追问是否拉回来：[是/否]

■ 提问链效果（→ questionEffectNote，只记问题本身）
  · 引发最多讨论的一问：[问题原文]
  · 无人回应的一问：[问题原文] → 原因猜测：[没听懂问题 / 太抽象 / 层级跳太快]

■ 暴露的错误理解（→ misconceptionsObserved）
  · [如："把 b 当作与 x 轴的交点"]
  · [如："认为 k 越大图象越靠上"]

■ 下节课调整（→ adjustmentForNext）
  · 互动方式：[继续 / 调整为   ]
  · 问题难度：[升 / 降 / 不变]
  · 需要补讲的点：[知识点，不写人名]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
