# 作业评分标准与分层任务卡模板

> 适用学段：小学中段 / 小学高段 / 初中（示例按八年级数学写；高中可用同一框架）。
> 示例题验算：2026-09-03
> 配合 `xiaozhi-teach-assignment-designer` 使用。分层来自 `classWorkspace.studentTiers`，
> 每道题必须填预计用时（对应 `homeworkAssignments[].tasks[].estimatedMinutes`）。
> 完整 Prompt 逻辑请参阅 [`../SKILL.md`](../SKILL.md)。

## 一、单题评分标准模板

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 评分标准 · 第 [N] 题
知识点：[   ] · 层级：[概念/规则/应用/迁移]
满分：[   ] 分
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 过程分（[N] 分）
  · 步骤 1（[M] 分）：[具体内容]
  · 步骤 2（[M] 分）：[具体内容]
  · 步骤 3（[M] 分）：[具体内容]
  · 关键概念/规则（[M] 分）：[具体内容]

■ 结果分（[N] 分）
  · 答案正确（[M] 分）
  · 单位/格式（[M] 分）

■ 常见错误与扣分
  · 错误 ①：[描述] → 扣 [M] 分
  · 错误 ②：[描述] → 扣 [M] 分
  · 错误 ③：[描述] → 扣 [M] 分

■ 满分模板（参考作答）
  [步骤化满分作答]

■ 给学生的简明反馈（错因按 shared/vocab.md §1 四维 / §3 七类）
  知识漏洞（概念模糊）："概念 X 的定义是 Y，请重读课本第 N 页"
  规则错误（概念模糊）："Y 规则的关键步骤是 Z，你跳过了哪一步"
  审题错误（读题失误）："看清题目问的是 A 不是 B"
  策略错误（方法用错）："这类题用 X 方法更快，先看条件里有没有 [标志]"

  习惯性失误（计算失误）："抄错了原题的数字，做之前先把条件圈一遍"
```

## 二、分层任务卡模板

> 层名（A/B/C）只出现在老师这一侧；发给学生的卡片上印"任务卡一/二/三"。
> 难度档三档：基础 / 中等 / 较难。知识点层级四层：概念① / 规则② / 应用③ / 迁移④。
> 三张卡的总时长应大致相当（差距 ≤ 10 分钟）——分层是换难度，不是给某层加量。

### 2.1 任务卡一（发给 A 层 · 需补基础）

```text
【任务卡一】《[课题]》

  1. [   ]（基础 · 概念①）
     课本例题 [N]（直接套用规则）
     estimatedMinutes：[   ]

  2. [   ]（基础 · 规则②）
     课本练习 [N]（套用规则）
     estimatedMinutes：[   ]

  3. [   ]（中等 · 规则②）
     课本练习 [N]（一步变形）
     estimatedMinutes：[   ]

  4. [   ]（基础 · 概念①）
     看图填空：k>0 / k<0 时图象走向
     estimatedMinutes：[   ]

  ⏱ estimatedTotalMinutes：[   ]，弹性 +[   ] 分钟
  📌 重点：把每一步"为什么"写清楚
```

### 2.2 任务卡二（发给 B 层 · 达标）

```text
【任务卡二】《[课题]》

  1. [   ]（基础 · 概念①）      课本例题 [N]            estimatedMinutes：[   ]
  2. [   ]（中等 · 应用③）      变式题：参数符号变化     estimatedMinutes：[   ]
  3. [   ]（中等 · 应用③）      课本练习 [N]：用图象解应用题  estimatedMinutes：[   ]
  4. [   ]（较难 · 应用③）      综合题：一次函数与正比例函数对比  estimatedMinutes：[   ]

  ⏱ estimatedTotalMinutes：[   ]
  📌 重点：写出思路，不只写答案
```

### 2.3 任务卡三（发给 C 层 · 可拓展）

```text
【任务卡三】《[课题]》

  1. [   ]（中等 · 应用③）      变式题：参数符号变化     estimatedMinutes：[   ]
  2. [   ]（中等 · 应用③）      课本练习 [N]：用图象解应用题  estimatedMinutes：[   ]
  3. [   ]（较难 · 迁移④）      跨章综合：用一次函数描述匀速直线运动 s=vt  estimatedMinutes：[   ]
  4. [   ]（较难 · 迁移④）      开放题：设计一个能列出一次函数的生活情境   estimatedMinutes：[   ]

  ⏱ estimatedTotalMinutes：[   ]，明确截止
  📌 重点：跨章联结的论证
```

## 六、反馈话术库

### 6.1 给学生的简明反馈（≤ 30 字/题，按 shared/vocab.md §1 四维分组）

```text
■ 概念模糊（老师端：知识漏洞 / 规则错误）
  "概念 X 的定义是 Y，请重读课本第 N 页"
  "你把 X 和 Y 概念搞混了，区别在于 A 和 B"
  "Y 规则的关键步骤是 Z，你跳过了哪一步"
  "X 公式的适用条件是 A，本题满足吗？"
  判定线索：换成"纯净版"最简题也做不对 → 概念模糊

■ 读题失误（老师端：审题错误）
  "看清题目问的是 A 不是 B"
  "题目说'不正确的是'，你看清否定词了吗"
  "题目给了 [条件]，你用到了吗？"
  判定线索：把条件读对后立刻会做 → 读题失误

■ 方法用错（老师端：策略错误 / 表达书写不规范）
  "这类题用 X 方法更快，先看条件里有没有 [标志]"
  "你可以先把 [已知] 列出来，再选方法"
  "结论对，但第 2 步没写出来，过程分拿不到"
  判定线索：概念清楚、读题无误，但选错工具或过程不得分 → 方法用错

■ 计算失误（老师端：计算错误 / 习惯性失误）
  "思路对，第 3 步再算一遍"
  "X 步骤的运算是 A → B，你算成 C 了"
  "抄错了原题的数字，做之前先把条件圈一遍"
  "检查符号和单位"
  判定线索：思路对、列式对，算错/抄错/漏单位 → 计算失误

判定顺序：先读题 → 再概念 → 再方法 → 剩下的归计算。
一道错题只记一个主维度。**不写"粗心"**，粗心是结果不是原因。
```

## 七、批改标记速查

| 标记 | 含义 | 用途 |
|------|------|------|
| ✓ | 完全正确 | 标在题号旁 |
| ▲ | 思路对但计算/书写错 | 标在错误处 |
| ? | 思路不清/不完整 | 标在关键步 |
| ✗ | 思路错误 | 标在错处 |
| ?✓ | 部分对，看具体情况 | 教师判断 |
| # | 超纲或独特解法 | 需教师判断 |

## 八、自检清单

每次输出作业前，AI 必须自检：

- [ ] 是否每题都对应一个明确的知识点层级
- [ ] 是否覆盖概念/规则/应用三层（④ 迁移层仅在有学情时）
- [ ] **每题是否都填了 estimatedMinutes，整份是否填了 estimatedTotalMinutes**
- [ ] 各层预计总时长是否大致相当（分层是换难度，不是给某层加量）
- [ ] 分层是否来自 studentTiers，人数是否与之一致；人数为 0 的层是否已省略
- [ ] 分层任务卡是否有明确差异（不是同一题三次）
- [ ] 每题是否配可观测的评分标准
- [ ] 反馈话术是否落到 shared/vocab.md §1 的四维，没有出现"粗心"
- [ ] AI 生成的题是否已按 shared/ai-item-check.md 自检并标注【AI 生成，入库前请人工验算】
- [ ] 写入 completionSummary 时是否只有聚合数据，没有姓名、分数、排名
