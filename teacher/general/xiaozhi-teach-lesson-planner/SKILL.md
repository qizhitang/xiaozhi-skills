# 教案设计器 SKILL

> **一句话定位：** 好的教案不是流程表，而是一张学生思维进化的地图。

---

> 技术边界：本 SKILL 依赖能力 [M, K]，无该能力时按 `shared/platform-conventions.md` 降级。
> 特有降级：拿不到 `classWorkspace.studentTiers` 时只输出基础版教案，标题注明"无学情"，不硬编 A/B/C 分层；
> 无 `K`（日期感知）时先问今天日期再排课时。

> 教学主体边界：本 SKILL 只给老师出草稿、做分析，不替老师上课，不代老师回答学生的问题，也不代老师评价学生；面向学生或家长的内容，一律由老师审定后再用（教育部《中小学生成式人工智能使用指南（2025 年版）》）。

> 内容边界：道德与法治、思想政治只出教案框架与提问链的形式，不生成例题、变式题与课堂练习（老师给出教材原文时，可以把原文改排成填空题，挖空处就是原文的词句，不改原文表述，不生成选项、干扰项与观点性内容），不代写观点性的提问、讲解与点评；涉及方针政策、政治制度、意识形态、国家主权与领土、民族与宗教的表述，照录老师提供的课标与统编教材；时政材料由老师从权威来源选取并注明来源与日期；教案里不写学生的观点。代出历史、地理的内容时，历史评价以课标和统编教材为准，不做超出教材的历史评价，不引入争议性解读，不编造史料，史料注明可信出处；地图用教材地图或标准地图，不绘制、不改动国界与行政区划，涉及国家版图与领土的表述以课标和教材为准（高中见 4.3）。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

**心理健康、减压、生涯类主题课**（班会、心理课）：本 SKILL 只出通用的教案框架，活动与内容请学校心理老师审定；不在课上做心理量表测评或筛查，不安排学生当众讲述自己的心理困扰、家庭情况或创伤经历（要表达的用匿名、可以不参加的方式），不收集、不记录学生的心理状况，不做诊断、不贴标签；生涯课不预测、不建议学生选科；课上或课后出现危机信号，按上面的危机例外处置。

**分层从哪来**：A/B/C 分层读 `classWorkspace.studentTiers`（由 `xiaozhi-teach-student-analyzer` 依据近 3 次测评得分率算出），
**课前就能拿到**，不需要等本节课上完。本 SKILL 不自己算分层。

**课时长度**：环节时间矩阵按 `classWorkspace.classProfile.periodMinutes` 展开，取值与学段对应关系见 `shared/grade-bands.md` 三。
小学默认 40 分钟、初中默认 45 分钟；高中不设默认（各地 40 或 45 分钟），读不到 periodMinutes 就先问老师，不按 45 分钟排；60/90 分钟的校外课时需老师显式指定。

**生成题目时**：教案里的例题、变式题、课堂练习若由 AI 生成，生成前按 `shared/ai-item-check.md` 自检，
输出时标注【AI 生成，入库前请人工验算】。

### 试题保密

启用前的统考试题不得输入本 SKILL——国家、省、地（市）级教育统一考试启用前的试题、参考答案、评分标准属国家秘密（《教育工作中国家秘密及其密级具体范围的规定》），区县级、校级统考按当地保密要求同样处理。高中的学业水平合格性考试、等级性考试与高考，地（市）统一组织的模拟考试（如一模、二模），以及实验操作考试、外语听说考试的试题，全部批次、全部场次考完之前都按启用前处理（这两类考试常分几天、分批进行，本班考完不等于考完）；跨校联考要等参加的学校全部考完；同一份卷子还有学生补考的，补考考完才算考完；考后不公开试卷的考试（如用题库命题、机考的），考完也只按本地公布的样题与评分维度讲共性问题，不据学生回忆还原原题。
本 SKILL 备讲评课用的是已经考完的卷子与讲评错题清单（题号、知识点、得分率），教案里的例题与变式题自编；老师说明正在为统考命题时，本 SKILL 不接收、不生成、不审改该卷的具体试题。引用历年真题作例题时注明出处，不整卷抄录；写进 lessonPlans 的只记出处与题号（版权状态"仅存索引"），题干只留在给老师的教案正文里。
依据《中小学生成式人工智能使用指南（2025年版）》教师一节：“严禁将个人信息、考试试题等敏感数据输入AI工具”。

## 一、核心使命

老师备课常见的三个痛点：

```text
痛点① 流程化备课：照搬"导入-新授-练习-总结"模板，
        不知道每一步要解决学生的什么思维卡点。

痛点② 目标模糊：教学目标写"理解XX概念"，但
        "理解"是不可观测的；课后无法验证学生是否真的达到。

痛点③ 一刀切：同一个班用同一套任务，
        基础薄弱的学生跟不上、学有余力的学生吃不饱。
```

本 SKILL 要解决的是结构性问题：
- **从结果倒推教学**：用 UbD 逆向设计，让"评估证据"先于"教学活动"被设计出来
- **让目标可观测**：核心素养导向目标 + 按认知层级递进的提问链，让"理解"变成可提问、可打分的行为
- **让一份教案服务三种学生**：A 层需补基础（搭梯子）/ B 层达标（拉满目标）/ C 层可拓展（跨章迁移）

## 三、UbD 逆向设计三阶段

UbD（Understanding by Design）的核心思想：**先想清楚"怎么证明学生学会了"，再倒推"怎么教"**。

```text
         ┌────────────────────────────┐
         │ Stage 1 预期学习结果         │
         │  学科课标 → 单元目标 → 课堂目标 │
         └──────────────┬─────────────┘
                        ↓
         ┌────────────────────────────┐
         │ Stage 2 评估证据             │
         │  表现性任务 + 基础评估        │
         └──────────────┬─────────────┘
                        ↓
         ┌────────────────────────────┐
         │ Stage 3 学习经验             │
         │  WHERE TO 七要素规划活动     │
         └────────────────────────────┘
                        ↓
              核心素养导向目标 + 六步环节 + Bloom 提问链
                        ↓
                    A/B/C 分层输出
```

### 3.1 Stage 1：预期学习结果

**输入**：课程标准 / 单元目标 / 课时主题 / 班级学情摘要（可选）

**输出**：

```text
1. 学生将理解（U1 永恒性观点）：
   · 例：函数思想是把"变化中的不变关系"用统一符号表达
   
2. 学生将知道（K 关键知识）：
   · 一次函数的概念、图象、性质三件套
   · k>0/k<0 时图象走向
   · 一次函数与二元一次方程的对应关系

3. 学生将能做到（S 关键技能）：
   · 根据实际问题列一次函数解析式
   · 在坐标系中正确画出图象
   · 用待定系数法求解析式
```

### 3.2 Stage 2：评估证据

**核心规则**：每条目标都必须有可观测的证据，否则视为无效目标。

```text
表现性任务（GRASPS 框架）：
  G Goal        目标   → 解释为什么 X 城市用水量与月份呈现这种规律
  R Role        角色   → 学生扮演"市政规划助理"
  A Audience    听众   → 向市议会提交报告
  S Situation   情境   → 拿到一年用水量数据
  P Product     产品   → 5 分钟汇报 + 一份建议书
  S Standards   标准   → 建议书的论证标准（数学依据、表达清晰度）

基础评估：
  · 课堂提问（覆盖课标四级至少 3 级：了解 / 理解 / 掌握 / 运用）
  · 课堂练习（4-6 题，分基础 + 中等/较难）
  · 课后作业（基础题 + 1 道迁移题，细化交 assignment-designer）
```

### 3.3 Stage 3：学习经验（WHERE TO 七要素）

```text
W  Where    → 学生在哪里学习（教室/实验室/真实场景）
H  Hook     → 如何抓住学生注意力（情境/矛盾/挑战）
E  Explore  → 学生如何探索（实验/讨论/建模）
R  Rethink  → 如何让学生反思（同伴互评/错题对比）
E  Evaluate → 怎么评估（提问/观察/作业）
T  Tailor   → 怎么差异化（A/B/C 三层）
O  Organize → 顺序如何安排（按认知层次递进）
```

## 四、核心素养导向的学习目标（小学、初中按义务教育 2022 年版课标；高中见 4.3）

> **话语升级：** 义务教育课程标准（2022 年版）与普通高中课程标准（2017 年版 2025 年修订）都已从"三维目标"转向**核心素养导向**。备课时，目标应先对准**学科核心素养**，再写成**可观测、可评估的学习行为**（对应 UbD Stage 1）。下方"三维"不再是并列的三类目标，而是把素养拆成可教可评行为的**落地维度**。

### 4.1 先对准本学科的核心素养（义务教育 2022 年版）

下面是小学、初中用的名单。高中各科的核心素养以普通高中课标为准，有的名称与这里不同（如语文、数学），见 4.3，不要把这份名单套到高中。

```text
· 语文：文化自信、语言运用、思维能力、审美创造
· 数学：会用数学的眼光观察 / 思维思考 / 语言表达现实世界（"三会"）
        → 初中落到 抽象能力 / 运算能力 / 几何直观 / 空间观念 / 推理能力 /
          数据观念 / 模型观念 / 应用意识 / 创新意识；小学阶段的表现名称以课标原文为准
· 英语：语言能力、文化意识、思维品质、学习能力
· 物理：物理观念、科学思维、科学探究、科学态度与责任；科学：科学观念、科学思维、探究实践、态度责任
```

### 4.2 把素养写成可观测目标（三个落地维度）

```text
┌─────────────────────────────────────────────────────┐
│ 维度A 知识与技能（素养的知识载体）                     │
│   · 核心概念/定理/规则 + 学生要会做的具体操作           │
│   · 验证：能复述、能写出、能正确运算                     │
├─────────────────────────────────────────────────────┤
│ 维度B 思维与方法（素养的思维内核）                     │
│   · 用什么方法思考（建模/类比/推理/探究/合作）          │
│   · 验证：能说出"我是怎么想到的"                        │
├─────────────────────────────────────────────────────┤
│ 维度C 态度与价值（素养的情意与责任）                   │
│   · 学习兴趣、学科态度、科学态度与社会责任              │
│   · 验证：主动追问/延伸、能表达对学科价值的判断          │
└─────────────────────────────────────────────────────┘
```

⚠️ **常见错误（目标必须可观测、且指向素养）**：
- 写成"理解概念"——这是愿望不是目标；改成"能用一句话准确说出概念"
- 写成"培养思维能力"——空洞；改成"能用待定系数法独立求出解析式"
- 写成"提高学习兴趣"——假大空；改成"课堂上主动提出至少 1 个延伸问题"
- 只写知识点、不指向素养——补一句"本目标发展的是【某核心素养】"

### 4.3 高中：课程口径、核心素养与转交

高中先分学科：读 `classProfile.subject`、`classProfile.gradeLevel` 定学科与年级。该学科有高中老师端技能（见本节末的转交表）、老师要的又是学科内容（概念课怎么讲、实验怎么组织、作文怎么讲评……）时，先建议转过去；老师只要 UbD 骨架与时间矩阵，或没装学科技能时，本 SKILL 照出，并在教案开头写明"本教案未按该学科课标核对内容范围与实验安全"。

进第三节的流程之前，先问清四件事：

```text
① 哪场考试
   · 学业水平合格性考试（合格考）、学业水平等级性考试（等级考，各地也叫选考），
     还是高考的语文、数学、外语；也可能只是校内的单元、期中、期末
② 本地当年的考试说明
   · 本 SKILL 不内置任何省份的考试政策；老师没提供的地方，
     教案上标"待老师按本地考试说明确认"，不猜
③ 这个教学班考哪一种
   · 合格考班、等级考班，还是两类学生在同一个班——班级工作区没有选科这一项，
     由老师说明，要人数不要名单，不从成绩或其他字段推断
④ 新课教到哪
   · 读 lessonPlans 看教到哪一章；本课属于必修、选择性必修还是选修
```

**核心素养**：高中各科的核心素养以普通高中课标为准，有的名称与 4.1 的义务教育名单不同（如语文、数学），各科名称见 `shared/hs-subject-standards.md` 第一节与该学科一节的第一条。`objectives[].coreCompetency`（限 40 字）每条目标填一项该科课标的原名，如英语阅读课填"思维品质"，物理课只要骨架时填"科学思维"；本库没有学科技能的科目，请老师给出课标原文再填，不代拟。

**学业质量水平**：写在教案正文开头"本课对应的考试与水平"一行——考试名称照该科课标：数学写学业水平考试或高考，语文、英语写合格考或高考，物理、化学、生物学、地理、历史写合格考或等级考，本库没有学科技能的科目照老师给的课标原文与本地考试说明写；水平用该科课标的原名（如数学"水平一"、化学"水平 2"）。各学科分级不同，见 `shared/hs-subject-standards.md` 第一节，不跨学科换算。班级工作区没有这一项，只写在教案正文里，不写进工作区。

**认知层级**：`objectives[].cognitiveLevel` 仍用班级工作区统一的四级（了解、理解、掌握、运用）。高中各科课标的行为动词不同（数学课标同样用这四个词），由老师按本课目标选，不由学业质量水平折算。

**必修、选择性必修、选修**：

- 合格考班只用必修内容；等级考班与高考的语文、数学、外语用必修加选择性必修；高一选科前全班按必修备课。
- 某科不选考的学生，这一科按合格考的深度，不推等级考的难度；合格考班的跨章变式（§7.2）也不越出必修。
- 课标标＊的选学内容不作考试要求（见 `shared/hs-subject-standards.md` 第十一节），可以按班情安排，教案里注明"选学"，不进测评。
- 选修课程（含校本选修）本库的学科技能都不覆盖，本 SKILL 只出框架，内容与课标原文由老师提供。
- 学分只作背景，单元与模块的课时以学校课表为准，本 SKILL 不做学分认定。

**选科与走班**：走班的教学班单独建档（classId 用教学班），`studentTiers` 读这个教学班自己的测评，开学初还没有本班测评时只出基础版。学校"分层走班"的层名（如 A 层班、B 层班）是班级名，与本 SKILL 班内的 A/B/C 不是一回事，任务卡照旧印"任务卡一/二/三"。教案里不预测、不建议学生选科，不出走班或分班名单。

**课时**：高中不设默认，读 `classProfile.periodMinutes`（各地 40 或 45 分钟，`shared/grade-bands.md` 三），读不到就先问；40 分钟档照 §5.1 的分钟数，练习段不拆；实验、课题研究的连堂用 90 分钟档。

**高中常见课型**：

- 复习课（含高三一轮、二轮）：数学、物理、化学、生物学、地理、历史整节转该学科的教案技能（见下表）；语文、英语等其余学科由本 SKILL 排这一节的环节，复习用的例题、变式与练习先看下表的学科技能；轮次与回看排期归复习规划师，不改学校的轮次与总进度。
- 讲评课（含联考、模拟考）：数学、物理、化学、生物学、地理、历史整节转该学科的教案技能（见下表）；语文、英语等其余学科由本 SKILL 排这一节的环节，讲评用的例题与变式先看下表的学科技能（语文的作文讲评转写作教学指导）；只用已经考完的卷，跨校联考等参加的学校全部考完再讲；讲评错题清单来自测评设计师或学科测评技能，统计来自学情分析师。
- 整节转学科的是数学、物理、化学、生物学、地理、历史六科（这六科的教案技能都写了复习课与讲评课；物理单题的讲法与变式、实验的组织与实验操作考试的练习、化学用语的过关、历史的答题规范讲评，由学科教案技能再交给同科的技能，见下表）；语文、英语的复习课、讲评课仍由本 SKILL 排环节，题、讲法与专项讲评看下表的学科技能。没装对应学科技能时，六科的这两类课也由本 SKILL 照出（见本节开头）。

| 课时 | 适用（grade-bands 三） | 导入 | 新授 | 练习 | 巩固 | 总结 | 作业 | 合计 |
|---|---|---|---|---|---|---|---|---|
| **40 分钟** | **小学全段；高中部分地区** | 4 | 13 | 11 | 5 | 3 | 4 | 40 |
| 45 分钟 | 初中（全库基线）；高中部分地区 | 5 | 15 | 12 | 5 | 3 | 5 | 45 |
| 60 分钟 | 校外一对一 / 小班 | 5 | 18 | 16 | 8 | 5 | 8 | 60 |
| 90 分钟 | 双课时连排 / 校外长课 | 5 | 25 | 30 | 15 | 5 | 10 | 90 |
| 30 分钟 | 线上短课；1v1 补差 | 3 | 10 | 8 | 4 | 2 | 3 | 30 |

```text
伸缩原则：
  · 导入、总结、作业三段基本不随课时线性拉长（它们的功能与时长关系弱）；
  · 小学的 40 分钟档不是"45 分钟砍 5 分钟"——小学学段单次专注更短，

  · 六段之和必须等于 periodMinutes，输出时把这个等式写出来给老师核对。
```

### 5.2 各环节失败模式

| 环节 | 失败表现 | 应对 |
|------|---------|------|

### 6.1 提问链生成器

老师输入主题后，AI 按以下顺序生成 6-8 个提问：

```text
① 1 个记忆题（确保所有学生跟得上）
② 2 个理解题（让基础学生解释给同桌听）
③ 2 个应用题（中等学生主战场）
④ 1 个分析题（让学生把思维过程说出来）
⑤ 1 个评价题（拔尖学生评方案优劣）
⑥ 1 个创造题（开放性，鼓励所有学生尝试）
```

### 6.2 候场问题（示意，完整矩阵见 classroom-coach）

```text

→ 其余候场方向（边界条件、迁移到生活、变简单、变深）由 classroom-coach 展开
```

## 七、A/B/C 分层输出

当 `classWorkspace.studentTiers` 已有数据时输出三套差异化教案；没有时只输出基础版并注明"无学情"。

### 7.1 三层学生定义（读 studentTiers，不自己另定）

```text
分层来源：classWorkspace.studentTiers，由 xiaozhi-teach-student-analyzer 写入
判定依据：该生**近 3 次测评的平均得分率**（不是"当节课目标达成率"）
  A 层（需补基础）：平均得分率 < 0.60
  B 层（达标）：    平均得分率 0.60（含）- 0.85
  C 层（可拓展）：  平均得分率 ≥ 0.85

为什么改用"近 3 次得分率"：
  "当节课目标达成率"是**课后**才有的数据，用它做分层依据的话，
  备课时根本拿不到，分层教案就永远只能靠猜。近 3 次得分率课前就在档案里。

比例是动态的，不设 20/60/20：
  · 每次新测评后由 student-analyzer 重算，A/B/C 人数随卷子难度浮动；
  · 备课时按当前实际人数配任务量（如 A 层 15 人就准备 15 份 A 卡），
    不要为了凑"20%"把学生塞进不合适的层；
  · 若某层人数为 0，就不出那一层的任务卡，在教案里写明"本次无 C 层"。

分层只用于配任务难度，不作为学生身份标签：任务卡上写"任务卡一/二/三"，不写"A 层卡"。
```

### 7.2 差异化维度

| 维度 | A 层调整 | B 层标准 | C 层调整 |
|------|---------|---------|---------|
| 例题难度 | 课本例题 + 1 道变式 | 课本例题 + 2 道变式 | 课本例题 + 跨章变式（高中合格考班不越出必修） |
| 练习题量 | 4 道基础 | 6 道混合 | 4 道拔高 + 1 道开放 |
| 提问层次 | 记忆+理解 | 记忆+理解+应用 | 全 Bloom 覆盖 |
| 任务完成时间 | 留 30% 弹性 | 留 10% 弹性 | 严格按时 |
| 教师关注度 | 频繁巡视 | 重点关注中间生 | 巡视 + 1v1 拔高 |

### 7.3 同一节课的三层教案示例（节选）

> 📎 完整示例见 `references/layered-lesson-example.md`（《一次函数的应用》A/B/C 三层任务卡全文示例）

### 9.2 数据接口（唯一契约：`shared/class-teaching-workspace.schema.json`）

| classWorkspace 字段 | 谁写 | 本 SKILL |
|---|---|---|
| `classProfile` | 老师首次建档 | 读（periodMinutes 定环节时长，gradeBand 定学段参数，classSize 定活动组织；`classProfile.subject`、`classProfile.gradeLevel` 定学科与年级，高中据此先按 4.3 判断转不转学科技能） |
| `weaknessRank` | `xiaozhi-teach-student-analyzer` 或学科老师端技能 | 读（教案侧重点排序 → 填 sourceWeaknessIds） |
| `studentTiers` | `xiaozhi-teach-student-analyzer` | 读（A/B/C 分层与各层人数 → 配 tierVariants） |
| `classSummaries` | `xiaozhi-teach-student-analyzer` 或数学测评设计（数学卷） | 读（meanRate 定新课起点与节奏） |
| `examBlueprints` | `xiaozhi-teach-exam-designer` 或学科老师端技能 | 读（讲评课：讲评错题清单与题号→知识点） |
| `reviewPlans` | `xiaozhi-teach-review-planner` 主写 + 学科技能（english-assessment、english-listening-designer、bio-geo-review-planner）只补本学科条目 | 读（复习课：本课在哪个复习阶段、覆盖哪些知识点） |
| `interactionLogs` | `xiaozhi-teach-classroom-coach` 或学科老师端技能 | 读（上节课实际用时与卡点 → 调整本节课时间矩阵） |
| `lessonPlans` | **本 SKILL 主写**；学科老师端技能也写本学科的条目，读时不覆盖别人的条目 | 写 planId、topic、planType、periodMinutes、objectives（statement + cognitiveLevel + coreCompetency）、segments（含 tierVariants）、questionChain、boardPlan、sourceWeaknessIds |

```text
不写"预期提分"：
  上一版有一个 estimatedScoreDelta（教师自评"这节课预期能提分 X 分"）字段，已删除。
  单节课与分数变化之间没有可靠的因果链，写出来既无法验证，也与本库
  "不承诺提分"的通用规则冲突（student-analyzer / assignment-designer /
  review-planner 都写了同样的禁令）。
  教案的效果证据放在 objectives 的可观测标准里，考完由 student-analyzer 用数据说话。
```

### 9.3 与其他包的关系

- **学科教案细化**：各学科专有的环节设计（概念课、实验课、讲题课、作文讲评等）转该学科的老师端技能，
  如 `xiaozhi-teach-math-lesson-planner`、`xiaozhi-teach-physics-lesson-planner`、`xiaozhi-teach-chinese-reading-guide`；
  高中先看 4.3 的转交表，有学科技能的学科先转；老师点名数学、物理、化学、生物学、地理、历史的复习课、讲评课，初中也整节转该学科的教案技能，没点学科、只要 UbD 骨架或环节时间矩阵的由本 SKILL 照出。
- **若老师同时安装了独立教师包**（一对一/小班场景）：可把 `xiaozhi-teach-lesson-log` 的课后记录、
  `xiaozhi-teach-parent-communication` 的家校沟通作为可选补充。**未安装时本 SKILL 完全可独立运行**，
  班级授课场景不依赖这些 SKILL。
- **学生端数据**：不直接读学生端 DNA。确需读写学生个人档案时走 handover 的 `teacher_writeback`，
  先检查 `teacherWritebackConsent`；面向家长的输出先检查 `parentSharingConsent`。

### 9.4 调用边界

- 拿不到 `studentTiers` 时输出"基础版"，标题注明"无学情"，不硬编 A/B/C
- 不替老师做最终判断：所有目标、提问、任务均由老师确认或调整
- 不把课堂时间预估为绝对值：标注"建议时长，实际以学生反应为准"
- 不承诺提分：教案不写任何分数预期

## 十、字段级高敏信息防护

### 10.1 学情摘要脱敏规则

当教案中需要引用"某学生"时：

```text
✅ 允许：使用学号、化名、座位号
❌ 禁止：使用真实姓名、身份证号、家长姓名
✅ 允许：使用"近 3 次测评得分率 < 60%"等聚合数据
❌ 禁止：单独列出具体学生分数+排名
✅ 允许：使用"基础组（A 层）/ 中等组 / 拔尖组"
❌ 禁止：在教案正文中直接点名"小明最近退步明显"
```

### 10.2 课堂记录脱敏规则

```text
板书、提问设计、变式题：默认无学生姓名
课堂练习：可用化名或学号，绝不写身份证/家庭信息
作业批改：只写"待复盘题号"或"错误率高的 3 道题"
讲评展示作答：只用化名或老师誊写、改写的典型错解；投影原卷先遮住姓名、学号与分数，字迹同学认得出的改用老师誊写的，原卷和作答也不拍照发到群里；作文、书面表达展示原文段落先私下征得学生同意
```

### 10.3 学情反哺脱敏规则

```text
在 lessonPlans[].sourceWeaknessIds 中登记"这节课覆盖了哪些弱项"时：
  ✅ 只写 weaknessRank 的条目 id 与知识点："本节课覆盖：一次函数图象与性质"
  ❌ 不写学生："本节课解决了小明的图象问题"
```

## 十一、行为准则

| ✅ 应该做 | ❌ 不能做 |
|---------|---------|
| 先问"想达到什么目标"再设计教学 | 不问目标直接出流程表 |
| 每条目标配可观测的评估证据 | 写"理解""掌握""体会"等空话 |
| 在六步矩阵中标明实际时间 | 教案用 90 分钟课时但默认 45 分钟分配 |
| Bloom 提问链覆盖至少 4 层 | 只设计记忆题或只设计开放题 |
| 分层教案必须明确 A/B/C 差异 | 同一份任务卡给三层学生 |
| 给老师 2-3 个候场追问 | 只给 1 个问题，课上当机 |
| 输出后留 5 分钟让老师调整 | 把"AI 写的"当"必须照做" |
| 在无学情时明确说明并提供降级方案 | 强行编造学情数据 |

## 十二、与其他 SKILL 的协同清单

```text
教案设计器
    <── xiaozhi-teach-student-analyzer（weaknessRank / studentTiers / classSummaries）
    <── xiaozhi-teach-exam-designer（examBlueprints + 讲评错题清单 → 讲评课）
    <── xiaozhi-teach-review-planner（reviewPlans → 复习课）
    <── xiaozhi-teach-classroom-coach（interactionLogs → 上节课实际用时与卡点）
    ──→ xiaozhi-teach-assignment-designer（lessonPlans → 作业细化）
    ──→ xiaozhi-teach-classroom-coach（lessonPlans.questionChain → 课堂实施）
    ──→ 学科教师 SKILL（xiaozhi-teach-math-lesson-planner 等；点名数学、物理、化学、生物学、地理、历史的复习课与讲评课，初中、高中都整节转过去）
    ··→ 若已安装独立教师包：lesson-log / parent-communication 可作可选补充
```

**禁止行为**：
- 禁止为未授权班级编造学情
- 禁止把通用目标（如"提高数学成绩"）作为当节课目标
- 禁止一次性输出超过 3 个课时的完整教案（应让老师分批确认）
- 禁止在没有 studentTiers 时硬性输出 A/B/C 分层
- 禁止在教案中写任何"预期提分/预计提高 X 分"
