# 教案模板与示例

> 适用学段：小学中段 / 小学高段 / 初中（高中可用同一框架）。
> 配合 `xiaozhi-teach-lesson-planner` 使用。本模板可直接复制、填入空白。
> 课时档位（40 / 45 / 60 / 90 / 30 分钟）见 `shared/grade-bands.md` 三与 SKILL.md §5.1；
> 下面以 45 分钟为例，小学请换 40 分钟档（4/13/11/5/3/4）。
> 完整 Prompt 逻辑请参阅 [`../SKILL.md`](../SKILL.md)。

## 三、提问链速查（备课时快速查阅，写进教案的是课标四级）

| 课标四级 | 关键词 | 提问模板 | 大致对应 Bloom |
|------|--------|----------|------|
| 了解 | 是什么 / 在哪 / 多少 | "[概念] 的定义是什么？" | 记忆 |
| 理解 | 能不能用自己的话 | "你能用一句话给同桌解释 [概念] 吗？" | 理解 |
| 掌握 | 用这个做一下 | "用 [方法] 解决 [具体问题]。" | 应用 |
| 运用 | 为什么这样选 / 你能设计 | "这两种解法你选哪个？为什么？""用 [知识] 设计一个 [情境] 方案。" | 分析 / 评价 / 创造 |

> 候场追问不在本模板展开：本 SKILL 只出提问链草案，
> 完整的五类候场追问、冷场 3 步走、基础学生参与路径见
> `../../xiaozhi-teach-classroom-coach/references/questioning-strategies.md`。
> 草案里给每问挂一个方向即可，例如：
> 「y=kx+b 中 k 表示什么？」→ 候场方向：k 的正负决定什么。

## 四、A/B/C 分层任务卡模板

```text
【A 层任务卡】《[课题]》
  任务 1：[基础任务，明确步骤]
  任务 2：[半示范任务，教师先做一步]
  任务 3：[判断/识别型任务]
  ⏱ 预计 [   ] 分钟，弹性 +[   ] 分钟
  教师关注：频繁巡视 + 单独提示

【B 层任务卡】《[课题]》
  任务 1：[独立完成型]
  任务 2：[应用型，需要迁移]
  任务 3：[对比分析型]
  ⏱ 预计 [   ] 分钟
  教师关注：重点关注中间生

【C 层任务卡】《[课题]》
  任务 1：[完成 B 层任务]
  任务 2：[跨章/跨学科迁移]
  任务 3：[开放设计型]
  ⏱ 预计 [   ] 分钟，硬性截止
  教师关注：巡视 + 1v1 拔高
```

## 五、备课检查清单

每次备课完成前，对照以下清单自检：

- [ ] 目标指向学科核心素养，且每条可观测目标都配了评估证据
- [ ] 没有任何目标写"理解""掌握""体会"等空话（写成"学生能…"的可观测行为）
- [ ] 提问链草案至少覆盖课标四级中的 3 级
- [ ] 六步时间分配总和 = `classProfile` 里的 periodMinutes（40/45/60/90/30）
- [ ] A/B/C 分层来自 studentTiers（近 3 次测评得分率），不是凭本节课表现现编
- [ ] 各层任务卡明确差异（不是同一题三次）；某层人数为 0 时不出该层
- [ ] 风险预案至少 2 条
- [ ] 课后反思要点已留好填写位置
- [ ] 教案中没有真实学生姓名，也没有"预期提分 X 分"
