> 适用学段：小学中段 / 小学高段 / 初中 / 高中（高中的考试口径、细目表加列与题量见 SKILL.md 第六节 6.4，示例见本文第十一节）。

## 七、三类测评类型对比（课标四级口径）

| 维度 | 诊断性 | 形成性 | 终结性 | （选拔性，竞赛） |
|------|--------|--------|--------|--------|
| 目的 | 查起点 | 阶段反馈 | 评估掌握 | 选拔 |
| 时机 | 单元初 | 单元教学中 | 单元末 / 期中期末 | 竞赛 |
| 目标整卷 P | 0.55-0.70 | 0.65-0.80 | 0.55-0.75 | 0.35-0.55 |
| 中等/较难题 D 期望 | ≥ 0.20 | ≥ 0.20 | ≥ 0.30 | ≥ 0.40 |
| 难度档比例 | 6:3:1 | 6:3:1 | 7:2:1 | 3:4:3 |
| 题量 | 8-12 | 12-18 | 18-25 | 20-30 |
| 时长 | 中 | 较短 | 较长 | 长 |
| 了解 | 30% | 20% | 15% | 5% |
| 理解 | 35% | 35% | 30% | 20% |
| 掌握 | 30% | 35% | 40% | 40% |
| 运用 | 5% | 10% | 15% | 35% |

> 认知层级比例按分值统计；基础题允许 D < 0.20，不计入"区分度不足"。高中不套"题量"一行，按预设作答时间控制总量；合格考、等级考、高考的模拟卷记终结性，但目标整卷 P、难度档比例与认知层级比例不套本表，按本地考试说明定（SKILL.md §6.4）。

## 八、题目改编四原则

```text
■ 改数（参数）
  原题 y=2x+1 → 改编 y=3x-2
  适合：同一知识点不同参数

■ 改问（设问角度）
  原题"求 X" → 改编"判断 X 是否正确"
  适合：换角度测同一概念

■ 改情境（背景）
  原题"出租车" → 改编"网约车"
  适合：让题目更贴近学生生活

■ 改综合度
  单知识点 → 多知识点综合
  适合：测评综合应用能力
```

## 十、自检清单

每次出卷前，AI 必须自检：

- [ ] 双向细目表是否已完整填写（列用课标四级）
- [ ] 知识点覆盖是否完整
- [ ] 认知层级比例是否按分值合计 100%，且符合测评类型；运用层 ≠ 0，校内测评 ≤ 20%（合格考、等级考、高考的模拟卷按本地考试说明）
- [ ] 难度档比例是否按场景选（形成性 6:3:1 / 终结性 7:2:1；高中合格考、等级考、高考的模拟卷按本地考试说明）
- [ ] 每题是否配评分标准
- [ ] 每道 aiGenerated 的题是否已按 `shared/ai-item-check.md` 自检 + 老师人工验算 → verifiedByTeacher=true
- [ ] 题目版权（copyrightStatus）是否清晰
- [ ] 是否只写了 expectedP，没有在考前编造 D
- [ ] 试卷与数据字段中是否只用化名/座号，没有真实姓名
- [ ] 讲评错题清单是否已生成并交给 lesson-planner 或学科教案技能

## 十一、高中细目表示例：高一物理必修 1 的单元测

> 一份**学校自编的单元末终结性测评**的细目表，只示范 SKILL.md §6.4 在高中加的四列（核心素养、学业质量水平、情境、预设作答时间）与课标四级的就近归档；**不是完整试卷，也不代表任何一省合格考、等级考的试卷结构**。
> 物理的核心素养、学业质量与考试的对应、考试范围见同目录 `hs-subject-standards.md` 的物理一节（第五节）；单元划分以学校所用教材为准。

**基本信息**

| 项 | 内容 |
|---|---|
| 班级与测评类型 | 高一教学班，选科之前，全班按必修出题；单元末终结性测评（工作区 assessmentType 记"终结性"） |
| 范围 | 必修 1 的主题"相互作用与运动定律"：重力、弹力与摩擦力，力的合成与分解，共点力的平衡，牛顿运动定律，超重和失重，力学单位制；同一模块前一主题的运动学只作解题工具 |
| 满分与时长 | 100 分，60 分钟（预设作答 55 分钟，留 5 分钟检查）；时长按学校安排 |
| 题量 | 14 题（实验题与第 13 题按小问分列，共 16 行）。高中不套第七节的题量区间，用预设作答时间控制总量 |
| 难度比例 | 基础 : 中等 : 较难 = 7 : 2 : 1（按分值，SKILL.md §6.2 终结性的比例） |
| 课标四级的标法 | 按这道题考查的内容在课标里用的动词就近归档：认识、了解、知道归了解（三种力的认识、胡克定律、力的合成与分解、矢量和标量、超重和失重、力学单位）；理解归理解（牛顿运动定律）；能用……计算、分析、解决归掌握（用动摩擦因数算摩擦力、用平衡条件分析、用牛顿运动定律解决问题）；实验题第(1)问按学业要求里的用图像描述数据、由数据得出结论标掌握；把两段运动综合起来、要自己解释误差来源并改进方案的标运用 |
| 学业质量水平 | 物理分 3 级（见物理一节）。本卷按课标学业质量表的描述标：熟悉情境中直接用概念、规律和常见模型的标水平 1；要自己选模型、把几个条件联系起来分析，或要解释实验误差的来源、提出改进方案的标水平 2；高一必修的单元测不出水平 3 的题。这是本示例的取舍，不是课标的规定，老师按课标原表核对 |
| 情境 | 物理课标没有规定情境的分类，这一列按题目实际用的情境写（生产生活、实验），没有情境的写"—" |

**细目表首行**：高一·物理必修 1"相互作用与运动定律"·单元末终结性测评｜满分 100｜60 分钟｜难度比例 7 : 2 : 1
