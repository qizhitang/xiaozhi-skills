# 数学教案设计 SKILL

> **一句话定位：** 数学不是教学生"记住公式"，而是教学生"用公式思考"——概念建构是核心。

---

> 技术边界：本 SKILL 依赖能力 [M, F]，无该能力时按 shared/platform-conventions.md 降级。
> 本 SKILL 输出**教案框架**与**概念建构路径**，不代替老师备课、不输出"标准答案"、不替老师讲题。
> AI 现出的题一律标注 `【AI 生成，入库前请人工验算】`，生成前按 `shared/ai-item-check.md` 自检；未经老师确认不得写入资源库或试卷。
> 题目版权状态只用 `shared/vocab.md §11` 的四个枚举值：`自有` / `改编` / `公开可引用` / `仅存索引`（教辅原题与历年真题一律 `仅存索引`）。

> 教学主体边界：本 SKILL 只给老师出草稿、做分析，不替老师上课，不代老师回答学生的问题，也不代老师评价学生；面向学生或家长的内容，一律由老师审定后再用（教育部《中小学生成式人工智能使用指南（2025 年版）》）。

### 试题保密

启用前的统考试题不得输入本 SKILL——国家、省、地（市）级教育统一考试启用前的试题、参考答案、评分标准属国家秘密（《教育工作中国家秘密及其密级具体范围的规定》），区县级、校级统考按当地保密要求同样处理。初中学业水平考试（中考），高中数学的学业水平考试与高考，地（市）统一组织的模拟考试（如一模、二模），全部场次考完之前都按启用前处理（有的考试分批、分场或各校不同时考，本班考完不等于考完）；跨校联考要等参加的学校全部考完；同一份卷子还有学生补考的，补考考完才算考完；考后不公开试卷的考试（如用题库命题、机考的），考完也只按本地公布的样题与评分维度讲共性问题，不据学生回忆还原原题。
本 SKILL 备讲评课用的是已经考完的卷子与交来的统计、错因（题号、知识点、得分率、错因），复习课、讲评课里的例题与变式题自编；老师说明正在为统考命题时，本 SKILL 不接收、不生成、不审改该卷的具体试题。引用历年真题、教辅原题作例题时注明出处，不整卷抄录；写进 lessonPlans 的只记出处与题号（版权状态"仅存索引"，`shared/vocab.md §11`），题干只留在给老师的教案正文里。
依据《中小学生成式人工智能使用指南（2025年版）》教师一节：“严禁将个人信息、考试试题等敏感数据输入AI工具”。

## 〇、对齐 2022 版课标

本 SKILL 的教学目标话语沿用 `xiaozhi-teach-lesson-planner` 的核心素养表述，数学学科落到"三会"与九个核心素养表现：

```text
数学课程要培养的核心素养——"三会"：
  会用数学的眼光观察现实世界
  会用数学的思维思考现实世界
  会用数学的语言表达现实世界

初中阶段的主要表现（写目标时从中选 1-2 个，写进 objectives[].coreCompetency）：
  抽象能力 · 运算能力 · 几何直观 · 空间观念 · 推理能力
  数据观念 · 模型观念 · 应用意识 · 创新意识

写目标的方法（对应 classWorkspace.lessonPlans[].objectives）：
  statement       ：学生能…（行为动词 + 条件 + 标准），可观测
  cognitiveLevel  ：课标四级结果目标 了解 / 理解 / 掌握 / 运用
  coreCompetency  ：本目标发展的是哪一个核心素养表现

反例：目标只写"掌握一元一次方程的解法"——没有条件、没有标准、没有指向素养。
改写：学生能在 3 分钟内独立解含括号的一元一次方程并说明每步依据（掌握 / 运算能力）。
```

## 一、核心使命

数学教学常见的三个误区：

```text
误区① 概念=背诵：把概念当定义背诵，学员记不住、
        不会用。考完就忘。

误区② 讲题=念答案：老师在黑板上讲一遍，学员抄一遍，
        学员没有"自己思考"的过程。

误区③ 训练=刷题：只追求"量"，不讲方法、
        不讲变式、不讲关联。
```

本 SKILL 要解决的是：
- **让概念"有根"**：每个概念都有引入情境
- **让讲题"有方"**：每道例题都有思路引导
- **让训练"有变"**：从"刷题"到"变式"
- **让学习"有迹"**：学员能看到自己数学思维成长

## 四、概念建构

### 4.1 概念建构四步（**全库唯一一套**，与 `references/concept-build-template.md` 完全一致）

```text
┌──────────┬──────────────┬────────────────────────┬──────────────┬──────────┐
│ 步骤      │ 名称          │ 描述                    │ 关键问题      │ 45分钟占比│
├──────────┼──────────────┼────────────────────────┼──────────────┼──────────┤
│ 第 1 步   │ 情境引入      │ 激活经验、暴露朴素理解   │ 你看到了什么  │ 15-20%   │
│ 第 2 步   │ 抽象概括      │ 提取共同特征**并命名**   │ 什么是一样的  │ 25-30%   │
│ 第 3 步   │ 应用辨析      │ 正例/反例，区别相似概念  │ 这算不算，为什么│ 30-35%  │
│ 第 4 步   │ 体系化        │ 纳入已有知识网络         │ 它挂在哪儿    │ 15-20%   │
└──────────┴──────────────┴────────────────────────┴──────────────┴──────────┘

注：旧版"命名"单列为第 3 步、"辨析"为第 4 步的说法已废止。
    命名并入第 2 步（抽象概括的收口动作），体系化独立为第 4 步。
    时长占比按 45 分钟一节课（`shared/grade-bands.md` 第三节），四步合计 ≤100%，
    留出的余量给课堂小结与作业布置。
```

### 4.2 情境引入 5 类

```text
① 生活情境
  · 学员生活中有真实体验
  · 例：分数（切披萨）、小数（钱）

② 历史情境
  · 数学史故事
  · 例：负数（古代记账）、圆周率（祖冲之）

③ 游戏情境
  · 让学员玩中学
  · 例：找规律（数字接龙）

④ 问题情境
  · 学员需要解决的具体问题
  · 例：行程问题（相遇追及）

⑤ 反例情境
  · 学员"试错"中理解
  · 例：平行（看上去平但不平行）
```

### 4.3 概念对比辨析

```text
■ 容易混淆的概念配对
  · 平方/立方
  · 锐角/钝角
  · 奇数/偶数
  · 质数/合数
  · 因数/倍数
  · 等腰/等边
  · 半径/直径
  · 周长/面积
  · 速度/时间/路程
  · 比率/比例
  · 概率/统计

■ 辨析三问
  · 这两个概念的共同点？
  · 这两个概念的差异点？
  · 怎么区分它们？
```

## 五、例题示范

### 5.1 例题三要素

```text
① 思路
  · 怎么想到的？
  · 关键是什么？

② 步骤
  · 第一步：X
  · 第二步：X
  · ...

③ 易错
  · 学员会错在哪里？
  · 怎么避免？
```

### 5.2 思路引导法

```text
■ "出声思维"
  · 老师边讲边"出声"
  · "我看到 X，所以想到 Y..."

■ "回溯法"
  · 从问题倒推
  · "要解 X，需要先知道 Y..."

■ "类比法"
  · 联系学员已知
  · "我们学过的 X 和这题有什么相同？"

■ "图示法"
  · 把抽象变形象
  · 线段图/示意图/坐标图

■ "假设法"
  · 先假设一个简单值
  · 看看会发生什么
```

## 六、变式训练

### 6.1 变式三类型

```text
┌──────────┬────────────────────────┬──────────────┐
│ 类型      │ 描述                    │ 训练目标      │
├──────────┼────────────────────────┼──────────────┤
│ 一题多解  │ 一道题多种解法          │ 思维灵活性    │
│ 多题一解  │ 多道题同一种方法        │ 方法识别      │
│ 变条件    │ 改变题目条件/问题       │ 思维深度      │
└──────────┴────────────────────────┴──────────────┘
```

### 6.2 一题多解设计

```text
■ 设计原则
  · 解法之间有差异
  · 解法有不同适用范围
  · 不为了多解而多解

■ 教学法
  · 老师先示范 2 种解法
  · 学员尝试第 3 种
  · 小组讨论"哪种最好"
```

### 6.3 多题一解设计

```text
■ 设计原则
  · 题目的"形"不同
  · 核心方法相同
  · 难度梯度合理

■ 教学法
  · 学员做 3-5 道题
  · 找出"共同点"
  · 总结方法
```

### 6.4 变条件设计

```text
■ 改条件
  · 把整数改成小数或分数
  · 去掉一个条件（注意：去掉后必须仍然有解，否则不成题）
  · 加一个条件（注意：不要加成矛盾条件）

■ 改问题
  · 把"求 X"改成"判断 X 是否成立并说明理由"
  · 把"求值"改成"求取值范围"

■ 改情境
  · 保持数量关系不变，换一个生活场景
    （如"鸡兔同笼"→"5元和10元纸币"→"答对加分答错扣分"）

⚠️ 每一道变式题，出题后按 `shared/ai-item-check.md` 自检：
   自解一遍 → 有解且唯一 → 条件充分不多余 → 数值友好（人数/件数为非负整数）
   → 学段内 → 与原题同型。三个"变"里最容易出问题的是"去掉一个条件"。
```

## 八、错例档案

### 8.1 错因分类

老师端七类见 `shared/vocab.md §3`；写入任何档案或与学生端交换时必须映射到通用四维。

```text
┌──────────────┬────────────────────────┬──────────────┐
│ 老师端七类    │ 描述                    │ 通用四维      │
├──────────────┼────────────────────────┼──────────────┤
│ 知识漏洞      │ 缺前置知识              │ 概念模糊      │
│ 概念模糊      │ 没理解本节概念          │ 概念模糊      │
│ 规则错误      │ 公式/法则记错           │ 概念模糊      │
│ 审题错误      │ 漏看条件/看错问题/抄错题 │ 读题失误      │
│ 策略错误      │ 方法选择不当            │ 方法用错      │
│ 表达/书写不规范│ 会做但过程不得分        │ 方法用错      │
│ 计算错误      │ 列式对、算错            │ 计算失误      │
│ 习惯性失误    │ 漏写单位/漏写步骤/不检查 │ 计算失误      │
└──────────────┴────────────────────────┴──────────────┘

互斥规则（一道题只归一类）：
  "移项不变号" → 规则错误（概念），不归计算错误
  "看错数字/抄错题" → 审题错误，不归习惯性失误
  "不写单位" → 表达/书写不规范或习惯性失误，按是否影响得分区分
不使用"粗心"作为原因——粗心是结果，不是原因。
```

```text
      → 复习课：本课在哪个复习阶段、能不能引入新知识点（排期本身不归本 SKILL）
  classWorkspace.reviewPlans[].spacingSchedule[]（knowledgePoint / reviewDates）
      → 复习课：这几天该回看哪些知识点
  classWorkspace.examBlueprints[]（examId / title）
  classWorkspace.examBlueprints[].items[]（itemNo / knowledgePoint）
      → 讲评课：哪场考试、题号对应哪个知识点
  classWorkspace.itemStats[]（examId / itemNo / pValue / flag）
      → 讲评课：各题得分率与异常标记（由数学测评设计或学情分析师写入，本 SKILL 只读）

写（生成待确认条目，老师确认后落库）：
  classWorkspace.lessonPlans[]
    .planId / .topic / .date / .planType / .periodMinutes
    .objectives[] { statement, cognitiveLevel（了解/理解/掌握/运用）, coreCompetency }
    .segments[]   { name, minutes, activity, tierVariants{A,B,C} }
        → 概念课：概念建构四步对应四个 segment，minutes 之和 ≤ periodMinutes；复习课、讲评课的分段见第十五节
    .questionChain[]      → 课堂提问链，按 cognitiveLevel 递进
    .boardPlan            → 板书设计（课堂小结的结构图放这里）
    .sourceWeaknessIds[]  → 本课针对的 weaknessRank 条目
  classWorkspace.interactionLogs[]
    .misconceptionsObserved[] → 课上观察到的典型错误（错例档案的来源）
    .questionEffectNote       → 哪一问引发思考、哪一问无人回应
    .adjustmentForNext        → 下次调整
```

**写回学生端档案**：只走 `handoverType: "teacher_writeback"`，
payload 为 `teacherWritebackData`（`teacherSkill` / `studentAlias` / `weakKnowledgePointUpdates[]` / `note`），

**给家长的反馈**：本 SKILL 不直接生成家长内容；需要时学校班级交 `xiaozhi-teach-student-analyzer` 出家长版，独立教师交 `xiaozhi-teach-parent-communication`，

## 十三、高中：高一衔接段的教案

依据《普通高中数学课程标准日常修订版（2017 年版 2025 年修订）》必修主题一"预备知识"（建议 18 课时）与主题二"函数"（建议 52 课时）。课时、班额、教材版本一律以 `classWorkspace.classProfile` 为准，本 SKILL 不写死教材章节与课时数；必修后半与选择性必修的教案见第十四节。

- **概念建构四步照用**：函数概念、单调性、弧度制、诱导公式等高一概念课，情境引入与抽象概括可以用课标附录的案例 2、5、3、6 作素材；单调性的单元整体设计还可参考案例 32（函数单调性主题教学设计，只取必修部分）。案例与单元的对应见 `references/math-hs-curriculum-map.md` 第八节。
- **衔接要点**（课标教学提示）：初中阶段数学知识相对具体，高中阶段相对抽象，要帮学生完成学习心理与学习方式的过渡；集合与常用逻辑用语以学过的初中内容为载体来梳理；单调性要引导学生用符号语言表达；定义域、值域与函数性质的教学避免偏题、怪题和烦琐的技巧训练；鼓励用信息技术画函数图像、探索规律。
- **目标对齐**：`objectives[].coreCompetency` 填高中数学六个核心素养之一——数学抽象、逻辑推理、数学建模、直观想象、数学运算、数据分析。
- **变式训练**照第六节做，变式题生成前按 shared/ai-item-check.md 自检，不超出高一必修范围。
- **选学内容**：课标标＊的"函数的形成与发展""对数概念的形成与发展"是选学内容，不作为考试要求。

课程结构、各主题的单元要点、课标案例对应、学业质量与考试见 `references/math-hs-curriculum-map.md`。

## 十四、高中：必修后半与选择性必修的教案

依据《普通高中数学课程标准日常修订版（2017 年版 2025 年修订）》必修主题三"几何与代数"（建议 42 课时）、主题四"概率与统计"（建议 20 课时）、主题五"数学建模活动与数学探究活动"（建议 6 课时），以及选择性必修的"函数"（30 课时）、"几何与代数"（44 课时）、"概率与统计"（26 课时）、"数学建模活动与数学探究活动"（4 课时）。课时、班额、教材版本仍以 `classWorkspace.classProfile` 为准。

- **概念建构四步照用**，各单元可用的课标教学案例：向量投影（案例 9）、复数的引入（案例 10）、正方体截面的探究（案例 11）、投掷骰子问题（案例 12）、分层抽样（案例 13）、阶梯电价的设计（案例 14）、用向量方法研究距离问题（案例 17）、二项式定理与杨辉三角（案例 18、19）；对应关系见 `references/math-hs-curriculum-map.md` 第八节。
- **各单元的教学提示**（课标）：向量从力、速度、位移入手，从物理、几何、代数三个角度理解；复数重在表示与几何意义，避免烦琐的计算与技巧训练；立体几何初步借助长方体与实物模型，判定定理只要求直观感知、操作确认，到选择性必修再用向量方法论证；概率与统计让学生经历数据处理的全过程；数列与一元一次函数、指数函数类比；导数从平均变化率过渡到瞬时变化率，理解不求一步到位；空间向量与综合几何方法对比着用；解析几何先说清图形的几何特征，再建系、用代数语言描述，最后回到几何解释。
- **数学建模活动与数学探究活动**：必修、选择性必修各要求完成一个课题研究（课标案例 15、16）。教案里写清选题、开题、做题、结题的时间节点和评价方式；开题报告与研究报告由学生完成，教师引导学生遵守学术规范、坚守诚信底线。
- **只备学业水平考试的班级**：教学只到必修，不引入选择性必修的方法（如用空间向量证明位置关系）。选修课程（A～E 类）本 SKILL 不覆盖。
- **选学内容**：课标标＊的复数的三角表示、几何学的发展、数学归纳法、微积分的创立与发展、平面解析几何的形成与发展、贝叶斯公式是选学内容，不作为考试要求；教案可以按班情安排，但不进测评。
- **目标对齐**与第十三节相同，`objectives[].coreCompetency` 填六个核心素养之一。
- **变式训练**照第六节做，变式题生成前按 shared/ai-item-check.md 自检，不超出所教班级已学的必修、选择性必修范围，不用这个范围以外的方法。

## 十五、复习课与讲评课

### 15.1 分工与数据来源

老师点名数学的复习课、讲评课，初中、高中都由本 SKILL 出整节（环节、例题与变式）；没点学科、只要 UbD 骨架或环节时间矩阵的，教案设计器（xiaozhi-teach-lesson-planner）照出。本 SKILL 只排一节课，或一个单元复习的几节课。

**本 SKILL 不接的相邻请求**：

| 老师说 | 转给 |
|---|---|
| "期末前两周数学复习怎么排""这几周哪天回看哪些知识点" | 复习规划师（xiaozhi-teach-review-planner） |
| "出一份复习卷""这次数学月考每道题的难度、区分度算一下" | 数学测评设计（xiaozhi-teach-math-exam-designer） |
| "这次月考的错因帮我归一下类" | 班级错因分析（xiaozhi-teach-math-error-analyzer） |
| "讲评后的订正和巩固作业怎么布置" | 作业设计师（xiaozhi-teach-assignment-designer） |
| "学生答不上来怎么追问、怎么分组" | 课堂互动教练（xiaozhi-teach-classroom-coach） |
| "这次成绩怎么跟家长说" | 学校班级：学情分析师（xiaozhi-teach-student-analyzer）出家长版；独立教师：家长沟通助手（xiaozhi-teach-parent-communication）。都由它们先核对授权（§9.2） |

**数据从哪来**（字段见 §9.2 的读块）：

- 复习课：`reviewPlans` 只用来看本课在哪个复习阶段、这几天该回看哪些知识点，排期不改。
- 讲评课：`examBlueprints` 看哪场考试、题号对应哪个知识点；`itemStats` 看各题得分率与异常标记（数学测评设计或学情分析师写入）；错因归类与讲评建议用班级错因分析交来的结论。
- 拿不到统计与错因时，请老师口头给题号、得分率与主要错法。本 SKILL 不算统计、不改分：逐人逐题的 itemScores 不读，也不用逐题得分自己算得分率或错因占比。

### 15.2 复习课

复习课把学过的内容按结构、方法与易错重新组织，不是把例题从头再讲一遍，也不是整节刷题（§一 误区③）。

- **范围与阶段**：复习范围以老师给的为准，只用范围内已经学过的内容。读 `reviewPlans` 的阶段：newContentAllowed 为 false 时不引入新知识点，C 层的拓展变式也一样；spacingSchedule 里这几天该回看的知识点，可以放进当堂变式或小结。
- **环节**用本 SKILL 现成的做法，不另起一套名目：
  - 结构梳理：学生先自己画本单元的结构图，再补上位、下位、并列联系（§4.1 第 4 步"体系化"，`references/concept-build-template.md` §2.4；图式照 §7.2），定稿进 boardPlan；
  - 典型例题：每类方法选一道，照 §5.1 讲思路、步骤、易错，引导法见 §5.2，易错按 §8.1 的七类预设；
  - 多题一解：形不同、方法相同的 3—5 道题，找共同点、总结方法（§6.3），这是复习课的主体；
  - 易混辨析：用 §4.3 的辨析三问，配对按本单元选（§4.3 的配对例子偏小学，只借三问）；
  - 当堂变式：改条件或改问题（§6.4），每题出完照 §6.4 的自检，AI 生成的标注【AI 生成，入库前请人工验算】；分层的变式印成"任务卡一/二/三"，不印 A/B/C 层名；
  - 小结：§7.3 反思三问，第三问落在"下次遇到这类题先想什么方法"。
- **写进 lessonPlans**：planType 填"复习"；segments 照下例列，小结与作业位也算一段，minutes 合计等于 periodMinutes；复习作业只留作业位，转作业设计师。

```text
复习课示例（45 分钟，一个单元的复习）
  ① 结构梳理    8 分钟   学生先画结构图，再对照补上位、下位、并列联系
  ② 典型例题   10 分钟   1—2 道，讲思路、步骤、易错
  ③ 多题一解   12 分钟   3—5 道，找共同点，总结方法
  ④ 易混辨析    6 分钟   辨析三问
  ⑤ 当堂变式    5 分钟   改条件或改问题，出题后自检
  ⑥ 小结        4 分钟   反思三问，留作业位
  合计 8 + 10 + 12 + 6 + 5 + 4 = 45 分钟
  45 分钟是初中默认；高中读不到 periodMinutes 先问（15.5）；别的课时按比例伸缩，合计等于 periodMinutes
```

### 15.3 讲评课

**前提**：卷子已经考完。联考、统考与一模二模要等参加的学校、全部批次都考完，本班考完不等于考完（见文首"试题保密"）；没考完的卷不接收、不改编，可以先排环节框架，题目与变式等全部考完再填。

**讲哪几道、按什么顺序**：

- 按交来的统计与错因排：数学测评设计的 itemStats（得分率低、flag 异常的题）与班级错因分析的错因归类、讲评建议；测评设计师出的讲评错题清单、老师自己给的题号清单也可以用。
- 同一类错因的题放在一起讲，失分面广的先讲；flag 为"疑似错题"的题，先请老师复核题目与参考答案，查清再定讲不讲；个别学生的失误不进全班讲评，私下沟通。

**每道题怎么讲**：

- 先讲思路，再讲步骤与易错（§5.1—5.2）；同一类错因的几道题讲透一道，其余点出共同的错法。参考答案与评分标准以试卷与老师为准，本 SKILL 排讲法、易错与变式；各类错因的讲法可参考 `references/error-pattern-rubric.md` 第 4 节的检查表。
- 每类错因讲完配一道当堂变式（§6.4 的改条件、改问题，出题后照 §6.4 自检）；课末的反思照 §7.3 改问：错在哪、为什么错、下次怎么避免。
- 展示作答只用化名或老师誊写、改写的典型错解（§十），投影原卷先遮住姓名、学号与分数，字迹同学认得出的改用老师誊写的；点评对题不对人，不当众点名批评，表扬进步也不报分数与名次；不公布个人分数与排名。

**记录与后续**：

- 写进 lessonPlans 时 planType 填"讲评"；topic 写明哪场考试（如"第二次月考讲评"），lessonPlans 没有考试编号字段；题号清单与题干留在给老师的教案正文里。
- 课上观察到的典型错误记进 interactionLogs 的 misconceptionsObserved：只写错误本身，错因用通用四维（§8.1），不写是谁错的，也不写个别学生的分数。
- 写回学生端、给家长的内容照 §9.2 先核对授权，个人分数与排名不在班级群、家长群公开；订正与巩固作业转作业设计师。
- 考后有学生情绪低落，课上照常对题不对人；出现危机信号，停止讲评设计，按 §9.2 末的危机例外处置。

```text
讲评课示例（45 分钟，讲评 4 道题，已按交来的统计与错因排好先后）
  ① 考情与目标    3 分钟   只说全班的整体情况与进步，点出本课要解决的 2—3 类错因
  ② 自查自纠      7 分钟   学生先订正自己能改的题；老师巡视，个别失误私下提示
  ③ 按错因讲题   20 分钟   4 道，每道约 5 分钟：先讲思路，再讲步骤与易错
  ④ 当堂变式      8 分钟   每类错因一道，改条件或改问题
  ⑤ 反思          7 分钟   错在哪、为什么、下次怎么避免；留作业位
  合计 3 + 7 + 20 + 8 + 7 = 45 分钟；课时不同时照 15.2 示例末行伸缩
```

### 15.4 初中：目标与考试说明

- **目标**照 §〇 写：coreCompetency 从九个核心素养表现里选 1—2 个，cognitiveLevel 用四级，statement 可观测。复习课的目标落在会归类、会选方法，讲评课的目标落在会纠正这一类错误，不照抄新授课的目标。
- **课时**：读 `classProfile.periodMinutes`，读不到按 45 分钟（`shared/grade-bands.md` 第三节），即 15.2、15.3 的示例。
- **考试说明**：中考（初中学业水平考试）与期末考试的范围、题型、分值，以本地当年的考试说明为准；本 SKILL 不内置考点与题型比例，老师没给的地方在教案里标"待老师按本地考试说明确认"。
- **范围**：例题与变式不超出所用教材的范围（本 SKILL 不内置初中课标的内容清单，§〇 只管目标的写法）；references 里标"适用学段：初中"的模板与样板可以直接参照。
- **作业**：时长照"双减"，不因复习、考后额外加量，作业转作业设计师。

### 15.5 高中：考试口径、范围与转交

设计高中的复习课、讲评课之前，先问清四件事：

```text
① 哪场考试：学业水平考试、高考，还是校内的单元、期中、期末
② 本地当年的考试说明：本 SKILL 不内置任何省份的考试政策，老师没提供的地方标"待老师按本地考试说明确认"
③ 本班考哪一种：只备学业水平考试，还是要参加高考；两类学生都有时请老师说明各多少人，要人数不要名单，不从成绩推断
④ 新课教到哪：请老师说明，本次复习、讲评的范围属必修还是选择性必修
```

- **考试口径**照 `references/math-hs-curriculum-map.md` 第九节：高中数学课标里的考试只有学业水平考试与高考两类，教案里照这两个名称写。学业水平考试考必修，水平一是命题依据；高考考必修与选择性必修，命题不超过水平二。水平用数学课标的原名（水平一、二、三），不与别的学科换算，只写在教案正文开头"本课对应的考试与水平"一行，不写进工作区。
- **只备学业水平考试的班级**：复习、讲评都只到必修（§十四）。数列、一元函数导数及其应用、空间向量与立体几何、平面解析几何、计数原理，以及条件概率、离散型随机变量及其分布列、正态分布、成对数据的统计相关性、一元线性回归模型、2×2 列联表，都在选择性必修（math-hs-curriculum-map 第七节），不进这类班的复习课；讲评也不用选择性必修的方法（如用空间向量证明位置关系）。课标标＊的选学内容不进测评，也不作复习重点。
- **课时**：高中不设默认（各地 40 或 45 分钟，`shared/grade-bands.md` 第三节），读不到 periodMinutes 先问，不按 45 分钟排；40 分钟照 15.2、15.3 的示例按比例压缩，合计等于 40。
- **高三轮次**：一轮、二轮、三轮的安排以学校为准，本 SKILL 只排其中的一节课，不改轮次与总进度；回看排期转复习规划师。
- **作业**：转作业设计师，按本校晚自习与就寝时间协调，不内置分钟数。
- **素材**：课标案例 17（用向量方法研究距离问题）可作空间向量与立体几何复习课的素材；案例 20—31（素养水平的评价案例）与案例 32（跨章节的主题教学设计），math-hs-curriculum-map 第八节说适合设计测评或单元整体教学，单元复习课可以从中选综合任务。只备学业水平考试的班级，与选择性必修有关的部分不用。
- **讲评**：联考、一模、二模等参加的学校、全部批次考完再讲（文首"试题保密"）；成绩等级与位次不是得分率，不拿来定讲评重点，讲评顺序仍照 15.3。
- **目标与变式**：coreCompetency 照第十三节，填六个核心素养之一；变式照第六节，不超出所教班级已学的必修、选择性必修范围（§十四）。
