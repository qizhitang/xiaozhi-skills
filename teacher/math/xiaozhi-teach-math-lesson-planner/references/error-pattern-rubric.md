# 数学错因分类表（教案层）

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-math-lesson-planner` 使用。从教案设计角度区分 7 类常见错因，帮助老师在备课阶段就预防典型错误。
> **词表以 `shared/vocab.md §3` 为唯一来源**：七类只用于教师端教学诊断，写入档案或与学生端交换时必须映射到通用四维。

## 1. 7 类错因总览（含通用四维映射）

```text
┌──────┬────────────────┬────────────────────────┬────────────┐
│ #    │ 错因类别        │ 典型表现               │ 通用四维    │
├──────┼────────────────┼────────────────────────┼────────────┤
│ 1    │ 知识漏洞        │ 前置知识不会           │ 概念模糊    │
│ 2    │ 概念模糊        │ 用错公式/混淆符号      │ 概念模糊    │
│ 3    │ 规则错误        │ 算法步骤错/法则记错    │ 概念模糊    │
│ 4    │ 审题错误        │ 看错条件/漏关键字/抄错题│ 读题失误    │
│ 5    │ 策略错误        │ 方法选择不当           │ 方法用错    │
│ 6    │ 表达/书写不规范  │ 会做但过程写不全、跳步  │ 方法用错    │
│ 7    │ 计算错误        │ 列式对、算术或符号算错  │ 计算失误    │
│ 8    │ 习惯性失误      │ 漏写单位/漏写步骤/不检查│ 计算失误    │
└──────┴────────────────┴────────────────────────┴────────────┘

注：本表列了 8 行，其中"知识漏洞/概念模糊/规则错误"三行同属概念模糊维度，
    教师端把它们合称"7 类"是历史叫法；分类使用时以 shared/vocab.md §3 的七类为准
    （知识漏洞、规则错误、计算错误、审题错误、策略错误、表达/书写不规范、习惯性失误），
    "概念模糊"是这七类映射后的通用维度名。备课时按上表任一行标注均可，
    但写入 classWorkspace.errorTally 时 dimension 只能填通用四维。

⚠️ 不使用"粗心"作为原因——粗心是结果，不是原因。原"粗心大意"一类已改为"习惯性失误"，
   并要求写清具体行为（漏写单位 / 跳步 / 不检验），否则不能作为一条错因记录。
```

## 1.1 互斥判定规则（一道题只归一类）

```text
一题一类。同一道题出现多个特征时，按下面的优先顺序判：

① 前置知识都没有 → 知识漏洞（不再往下判）
② 本节概念说不清 → 概念模糊
③ 概念清楚但法则记错（移项不变号、不等式两边乘负数不变号）
   → **规则错误**，不归计算错误
④ 条件读错、看错数字、抄错题 → **审题错误**，不归习惯性失误
⑤ 读题无误、概念清楚，但选错方法/路径 → 策略错误
⑥ 方法对、答案对，只是过程写不全或跳步扣分 → 表达/书写不规范
⑦ 列式正确、只在运算中出错 → 计算错误
⑧ 以上都不是，属于漏写单位/不检验一类的固定动作缺失 → 习惯性失误

高频争议对照：
  "移项不变号"        → 规则错误（③），不是计算错误
  "看错 5 写成 6"     → 审题错误（④），不是习惯性失误
  "不等式乘负数没变号" → 规则错误（③）
  "结果没写单位"      → 表达/书写不规范或习惯性失误，按是否扣分区分
  "会做但没时间写完"  → 不记为错因，记为答题节奏问题
```

## 2. 七类错因详解

### 2.1 概念模糊

```text
【定义】学员对核心概念理解不透彻
【典型表现】
  · 用错公式（如把长方形面积当周长）
  · 混淆符号（如把 ≠ 当 =）
  · 概念张冠李戴（如把"等腰"当"等边"）
  · 概念边界不清（如不知道"0"是否属于正数）

【教案预防】
  · 在概念引入时增加正/反例对比
  · 给出"概念辨析卡"
  · 设计"找错"练习
```

### 2.2 规则错误

```text
【定义】学员对运算法则/规则记忆错
【典型表现】
  · 解方程移项不变号
  · 分数运算不找最小公倍数
  · 因式分解漏项
  · 函数单调性记反

【教案预防】
  · 把规则拆成最小步骤
  · 设计"我说你做"操练
  · 配合口诀/图示
```

### 2.3 审题错误

```text
【定义】学员没看清题目条件
【典型表现】
  · 看错数字（如把 5 看 6）
  · 漏掉关键字（如"至少"、"整数"）
  · 多余条件没排除
  · 问什么答什么没搞清

【教案预防】
  · 设计"信息提取卡"
  · 训练"圈关键字"习惯
  · 答案前问"题目问什么"
```

### 2.4 策略错误

```text
【定义】学员选择的方法不当
【典型表现】
  · 用复杂方法解决简单题
  · 不会用方程/反用算术
  · 不会分类讨论
  · 不画图分析

【教案预防】
  · 一题多解展示
  · 策略选择"决策树"
  · 强调"先想再算"
```

### 2.5 计算错误

```text
【定义】学员算术/代数运算错
【典型表现】
  · 整数加减错
  · 分数四则错
  · 移项变号错
  · 公式代入错

【教案预防】
  · 强计算专项训练
  · 分步展示避免跳步
  · 估算验证（先估后算）
```

### 2.6 习惯性失误（原"粗心大意"一类）

```text
【定义】固定动作缺失导致的失分——是**行为习惯问题**，不是态度问题
【典型表现】
  · 誊抄自己的中间结果时写错（如把自己算出的 8 抄成 3）
  · 漏写单位、漏写答句
  · 跳步导致自己回看时接不上
  · 做完不检验（方程不代回、几何不复核图）

【不属于本类】
  · 看错题目里的数字 → 审题错误
  · 抄错题目 → 审题错误
  · 法则记错 → 规则错误

【教案预防】（训练的是流程，不是心态）
  · 规范答题模板：设→列→解→检验→答，五步固定
  · "二次检查"清单化：符号 / 单位 / 是否回答了所问
  · 把检验写进例题示范里，让检验成为解题的一部分而不是额外动作
  · 限时训练用于练节奏，不用于施压
```

### 2.7 知识漏洞

```text
【定义】学员前置知识不会
【典型表现】
  · 分数运算不会 → 比例不会
  · 三角形面积不会 → 几何综合题不会
  · 一元一次方程不会 → 一元二次不会

【教案预防】
  · 课前测诊断
  · 关联前置知识复习
  · 阶梯式例题设计
```

## 3. 错因识别流程（按 §1.1 的顺序，问到第一个"否"就定类）

```text
学员答错 → 按顺序问：
  ① 前置知识会不会？   不会 → 知识漏洞（停）
  ② 本节概念说得清吗？ 说不清 → 概念模糊（停）
  ③ 法则记对了吗？     记错 → 规则错误（停）
  ④ 题目读对了吗？     读错/抄错 → 审题错误（停）
  ⑤ 方法选对了吗？     选错 → 策略错误（停）
  ⑥ 过程写全了吗？     没写全但方法对 → 表达/书写不规范（停）
  ⑦ 运算做对了吗？     列式对、算错 → 计算错误（停）
  ⑧ 以上都过了 →       习惯性失误（写清具体是哪个动作缺失）

一题只走一遍这个流程，只落一类。
```

## 5. 各类错因的高发知识点（用于备课时预设易错点）

```text
┌────────────────┬──────────────────────────────┐
│ 错因            │ 高发知识点                    │
├────────────────┼──────────────────────────────┤
│ 知识漏洞        │ 跨章节综合、需要用到前一学期内容的题 │
│ 概念模糊        │ 函数概念、几何判定、符号与绝对值    │
│ 规则错误        │ 移项变号、不等式两边乘负数、去括号  │
│ 审题错误        │ 应用题、含"至少/不少于/整数解"的题 │
│ 策略错误        │ 综合题、压轴题、需要分类讨论的题    │
│ 表达/书写不规范  │ 证明题、解答题的过程分            │
│ 计算错误        │ 分式运算、二次根式、代数式化简      │
│ 习惯性失误      │ 应用题不写答句、几何不标图、不检验   │
└────────────────┴──────────────────────────────┘
```

> **本表不给占比**：各类错因的比例因班、因单元、因试卷难度差异很大，
> 全库统一的占比数字没有出处，也会误导备课重点。
> 需要占比时，用本班 `classWorkspace.homeworkAssignments[].completionSummary.commonErrors[]`
> 或 `classWorkspace.itemScores[]` 的实际数据现算，并注明样本量与来源。
