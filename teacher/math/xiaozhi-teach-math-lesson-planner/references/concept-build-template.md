# 数学概念建构四步模板

> 适用学段：初中（7-9 年级）；按 45 分钟一节课设计（`shared/grade-bands.md` 第三节）。
> 示例题验算：2026-09-03
> 配合 `xiaozhi-teach-math-lesson-planner` 使用。从"情境-抽象-应用-体系化"四步建构数学概念，是数学教案设计的核心骨架。
> **本表是全库唯一一套概念建构四步**，SKILL.md §4.1 与本文件一致；旧版把"命名"单列一步的说法已废止（命名并入第 2 步）。

## 1. 概念建构四步总览

```text
┌──────────┬──────────────┬────────────────┬──────────────┬──────────┐
│ 步骤      │ 名称          │ 关注重心        │ 关键问题      │ 45分钟占比│
├──────────┼──────────────┼────────────────┼──────────────┼──────────┤
│ 第 1 步   │ 情境引入      │ 激活经验        │ 你看到了什么  │ 15-20%   │
│ 第 2 步   │ 抽象概括      │ 提取本质并命名  │ 什么是一样的  │ 25-30%   │
│ 第 3 步   │ 应用辨析      │ 巩固理解        │ 这算不算，为什么│ 30-35%  │
│ 第 4 步   │ 体系化        │ 建立联系        │ 它挂在哪儿    │ 15-20%   │
└──────────┴──────────────┴────────────────┴──────────────┴──────────┘

四步合计 ≤100%，余量留给课堂小结与作业布置。
写进教案时对应 classWorkspace.lessonPlans[].segments[]，
四个 segment 的 minutes 之和 ≤ classProfile.periodMinutes。
```

## 2. 概念建构四步详细

### 2.1 第 1 步：情境引入

```text
【目标】
  · 激活学员已有经验
  · 暴露学员朴素理解
  · 制造"认知冲突"

【3 类情境】
  · 生活情境：生活中遇到的场景
  · 游戏情境：可操作的活动
  · 历史情境：数学史故事

【设计要点】
  · 情境必须"真实"（学员觉得是有意义的问题）
  · 情境必须"具体"（可观察、可操作）
  · 情境必须"开放"（有多种解法/答案）

【时长占比】整节课 15-20%
```

### 2.2 第 2 步：抽象概括（含命名）

```text
【目标】
  · 从具体情境中提取数学本质
  · 给出"数学定义"或"数学表达式"
  · 学员自己命名/表述（命名是本步的收口动作，不单列一步）

【3 种抽象路径】
  · 归纳抽象：从多个实例中归纳共同点
  · 类比抽象：用学员熟悉的概念类比
  · 符号抽象：用数学符号/字母表达

【关键提问】
  · "你发现这些例子有什么共同点？"
  · "如果让你给这个概念起个名字，你会叫什么？"
  · "你能用一句话描述这个概念吗？"

【时长占比】整节课 25-30%
```

### 2.3 第 3 步：应用辨析

```text
【目标】
  · 在新情境中识别并应用概念
  · 区分易混淆概念
  · 形成"什么时候用 / 什么时候不用"的判断

【3 类应用】
  · 正面应用：典型题，识别→应用
  · 反例辨析：找出反例，加深理解
  · 类比应用：迁移到相似概念

【关键提问】
  · "这是[概念]的实例吗？为什么？"
  · "下列哪些是[概念]？为什么？"
  · "[概念 A] 和 [概念 B] 有什么区别？"

【时长占比】整节课 30-35%
```

### 2.4 第 4 步：体系化

```text
【目标】
  · 把新概念纳入已有知识图谱
  · 建立"上位/下位/并列"关系
  · 形成"概念网络"

【3 种联系】
  · 上位联系：新概念属于哪个更大的类？
  · 下位联系：新概念包含哪些特例？
  · 并列联系：与哪些概念并列/对比？

【输出形式】
  · 概念图（思维导图）
  · 知识树
  · 关系表

【时长占比】整节课 15-20%
```

## 3. 教学样板：建构"一元一次方程"概念（45 分钟）

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📐 概念建构样板：一元一次方程 · 45 分钟
━━━━━━━━━━━━━━━━━━━━━━━━━━━

【第 1 步：情境引入】（8 分钟，18%）
  · 问题 1：妈妈买苹果，每个 3 元，买 5 个，共花多少元？
    → 学员列算式：3 × 5 = 15                （已知推未知，算术思路）
  · 问题 2：妈妈有 50 元，买了 5 个苹果，每个 x 元，还剩多少元？
    → 学员列代数式：50 − 5x                  （出现字母，但还不是方程）
  · 问题 3：妈妈有 50 元，买了 x 个苹果，每个 3 元，还剩 35 元，求 x。
    → 学员列等式：50 − 3x = 35               （未知数参与列式，方程思路）
  · 关键认知冲突：问题 3 用算术倒着算也能得 x=5，
    但让学员比较"倒着算"和"顺着列等式"哪个更容易说清楚——引出方程的价值。

【第 2 步：抽象概括（含命名）】（12 分钟，27%）
  · 并排给出：50 − 3x = 35、5x = 10、2x + 3 = 11、x/2 = 4
  · 追问："这几个式子有什么共同点？"
    → 都是等式；都只有一个字母；字母的次数都是 1；等号两边都是整式
  · 学员自己命名，教师给出规范名称：一元一次方程
  · 三个关键词（缺一不可）：
      一元 —— 只含一个未知数
      一次 —— 未知数的次数是 1
      整式 —— **等号两边都是整式**（这一条最容易漏，是本节的关键）
  · 回看第 1 步：50 − 5x 只是代数式，没有等号，所以不是方程。

【第 3 步：应用辨析】（15 分钟，33%）
  · 判断下列各式是不是一元一次方程，并说明理由：
    □ x + 5 = 8        ✓ 一元、一次、两边都是整式
    □ x + 5            ✗ 不是等式（没有等号），是代数式
    □ 2x + 3y = 10     ✗ 二元
    □ x² = 9           ✗ 未知数次数是 2
    □ x/2 = 3          ✓ 分母是数字 2，x/2 仍是整式
    □ 0.5x = 3         ✓ 系数是小数不影响，仍是一元一次方程
    □ 1/x = 2          ✗ **分母里含未知数，左边不是整式 → 这是分式方程，不是一元一次方程**
  · 追问推进："x/2 = 3 可以，1/x = 2 不行——差别在哪里？"
    → 让学员自己说出"字母在不在分母上"
  · 写出"我能识别一元一次方程的 3 个关键"：一元 / 一次 / 两边都是整式

【第 4 步：体系化】（7 分钟，16%）
  · 两棵树分开挂，不要混成一棵：

    树一（按"式子的种类"分）：
      代数式
        ├── 整式（单项式 / 多项式）
        └── 分式（分母含字母）
      —— 方程**不在**这棵树上：方程是"含未知数的等式"，代数式没有等号。

    树二（按"方程的种类"分）：
      等式
        └── 方程（含未知数的等式）
              ├── 整式方程
              │     ├── 一元一次方程   ← 本节
              │     ├── 一元二次方程（九年级）
              │     └── 二元一次方程（→ 与另一个方程组成二元一次方程组）
              └── 分式方程（如 1/x = 2，八年级）

  · 追问："1/x = 2 挂在哪个位置？为什么不挂在一元一次方程下面？"
  · 输出：学员自己画的两棵树（拍照存入错例/学案档案，用化名）

【机动】（3 分钟）课堂小结 + 布置作业
━━━━━━━━━━━━━━━━━━━━━━━━━━━

四步合计 42 分钟 + 3 分钟机动 = 45 分钟，占比 18%/27%/33%/16%，落在 §1 的建议区间内。
```

## 4. 概念建构自检清单

```text
□ 第 1 步：情境是否真实/具体/开放？
□ 第 2 步：抽象是否由学员主动完成？
□ 第 3 步：是否有反例辨析？
□ 第 4 步：是否画出了概念图？
```

## 5. 概念建构常见误区

```text
误区 ① 跳过情境直接给定义
  → 学员"知道"但"不理解"
误区 ② 抽象过快，学员跟不上
  → 学员放弃参与
误区 ③ 应用题都是"识别→套公式"
  → 学员迁移能力差
误区 ④ 体系化变成抄板书
  → 学员没有内化
```
