# 教学干预设计模板

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-math-error-analyzer` 使用。基于错因分析结果，设计 4 步干预方案（识别-诊断-干预-跟踪）。
>
> **工作量前提（先读这一段再往下用）：**
> 本模板里的"错因记录卡""诊断记录卡""学员访谈 5 问"**不是给全班每人每题填的**。
> 一个班 45 人 × 一份卷 25 题 = 1125 次判定，做不完，也不必做。默认走：
> ① 全量只记通用四维（四选一，机器可从逐题得分推）；
> ② **错误率 >30% 的题**才做七类精细判定，每题抽 5-8 份答卷（覆盖高中低三档）；
> ③ 访谈与个体诊断卡只用于老师点名关注的 3-5 名学生。
> 报告里凡是抽样得到的比例，必须写"抽样 N 份"；样本 <10 份时只给方向、不给百分比。

## 1. 干预设计 4 步

```text
┌──────────┬────────────────┬────────────────────┐
│ 步骤      │ 名称            │ 关注重心            │
├──────────┼────────────────┼────────────────────┤
│ 第 1 步   │ 识别错因        │ 学员哪里错          │
│ 第 2 步   │ 诊断原因        │ 为什么错            │
│ 第 3 步   │ 设计干预        │ 怎么补              │
│ 第 4 步   │ 跟踪评估        │ 干预是否有效        │
└──────────┴────────────────┴────────────────────┘
```

## 2. 第 1 步：识别错因

### 2.1 错因分类（参见同目录 error-classification-rubric.md）

```text
教师端七类（shared/vocab.md §3）：
  知识漏洞 / 概念模糊 / 规则错误 / 审题错误 / 策略错误 /
  表达·书写不规范 / 计算错误 / 习惯性失误

映射到通用四维（写入档案或跨端交接时必用）：
  知识漏洞·概念模糊·规则错误 → 概念模糊
  审题错误                    → 读题失误
  策略错误·表达书写不规范      → 方法用错
  计算错误·习惯性失误          → 计算失误

⚠️ 不使用"粗心"作为原因；原"粗心大意"改为"习惯性失误"，须写清具体动作。
```

### 2.2 错因识别三问

```text
问 1：学员在哪个知识点出错？
  → 定位第 3 层知识点

问 2：学员在哪个步骤出错？
  → 定位第 4 层细节

问 3：学员错因属于 7 类中的哪一类？
  → 给出错因标签
```

## 3. 第 2 步：诊断原因

### 3.1 原因分析 5 层

```text
层 1：表面层
  → 学员"算错了" / "不会"

层 2：知识层
  → 哪个公式/规则/概念不熟

层 3：思维层
  → 是逻辑/推理/建模哪一步出问题

层 4：习惯层
  → 是跳过步骤/不检查/字迹潦草等

层 5：情绪层
  → 是畏难/紧张/失去兴趣等
  → 只作为教学安排的参考（如调整难度、换搭档），**不做心理诊断、不贴标签**；
    出现持续严重困扰按 shared/crisis-exception.md 处置或转学校心理老师
```

### 3.2 学员访谈 5 问（只用于点名关注的 3-5 名学生）

```text
问 1：你能给我讲讲你的思路吗？
问 2：你在哪一步卡住的？
问 3：你当时是怎么想的？
问 4：再给你一次机会你会怎么做？
问 5：你能用另一种方法做吗？
```

## 4. 第 3 步：设计干预

### 4.1 干预方案 4 象限

```text
┌────────────────┬────────────────┐
│  低难度         │  高难度         │
│  学员能自己补   │  学员需老师辅导  │
├────────────────┼────────────────┤
│  · 同类题 5 道  │  · 1 对 1 讲题  │
│  · 微课视频     │  · 概念重讲     │
│  · 思维导图复习 │  · 阶梯练习     │
├────────────────┼────────────────┤
│  低频率         │  高频率         │
│  学员偶发错误   │  学员反复错误   │
├────────────────┼────────────────┤
│  · 一次讲清     │  · 三次复习     │
│  · 不必过度练   │  · 形成性评价   │
└────────────────┴────────────────┘
```

### 4.2 干预 4 类（按错因）

```text
┌──────────┬────────────────────┬──────────────────────┐
│ 错因      │ 干预方法            │ 时长                  │
├──────────┼────────────────────┼──────────────────────┤
│ 知识漏洞  │ 前置知识补 + 关联  │ 1-3 次课              │
│ 概念模糊  │ 概念重讲 + 正反例  │ 1 次课（45 分钟）     │
│ 规则错误  │ 步骤拆解 + 操练    │ 2 次课（90 分钟）     │
│ 审题错误  │ 审题训练 + 模板    │ 1 次课（45 分钟）     │
│ 策略错误  │ 一题多解 + 决策树  │ 2 次课（90 分钟）     │
│ 表达不规范│ 过程分示范 + 评分点│ 1 次课（45 分钟）     │
│ 计算错误  │ 计算专项 + 估算    │ 每次课前 5 分钟，持续 │
│ 习惯性失误│ 五步答题模板+检验单│ 每次课前 5 分钟，持续 │
└──────────┴────────────────────┴──────────────────────┘

注：课时数是经验值，按班级实际调整。"每日 10 题"一类的固定量已去掉——
    作业总量按学段由老师统一协调，本模板不单独规定题量。
```

### 4.3 干预方案样板

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 干预方案：学员 A-007 · 解方程步骤错
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 错因类别：规则错误（通用四维：概念模糊）
■ 弱项状态：顽固弱项（近 4 次测评中该知识点错误率 >30% 达 3 次，
             计数来自 homework-tracker，本 SKILL 不自行累加）
■ 错因定位：2.1.3 解方程步骤 / 移项不变号
■ 注意：移项不变号是**规则错误**，不记为计算错误

【干预目标】
  1. 短期（1 周）：移项时能说出"为什么要变号"（等式性质），而不只是记住口诀
  2. 中期（2 周）：含括号、含分母的方程也能正确移项
  3. 长期（1 月）：形成"移项后回代检验"的固定动作

【干预步骤】
  · 第 1 步：1 对 1 重讲移项的依据——等式两边同加同减（10 分钟）
    追问："x+3=7 两边同时减 3，得到什么？这和'把 +3 搬过去变 -3'是同一件事吗？"
  · 第 2 步：正反例对照，让学生自己判断对错并说理由（5 分钟）
    正：3x-5=10 → 3x=10+5
    反：3x-5=10 → 3x=10-5  ← 让学生指出错在哪、依据是什么
  · 第 3 步：阶梯练习（20 分钟，题目按 shared/ai-item-check.md 自检后使用）
    ① 基础：x + 3 = 7            → x = 4
    ② 进阶：3x - 5 = 10          → x = 5
    ③ 综合：2(3x - 1) = 10       → 6x - 2 = 10 → x = 2
  · 第 4 步：之后每次课前用 2 道移项题热身（并入常规课堂，不额外增加作业量）

【资源需求】
  · 阶梯练习题（自编或改编，标注 copyrightStatus；AI 生成题标注
    【AI 生成，入库前请人工验算】）

【跟踪评估】
  · 第 3 天：3 道移项题，要求逐题说出依据
  · 第 7 天：3 道含括号/含分母的综合题
  · 攻克判定：**两次独立验证做对，间隔 ≥3 天，其中至少 1 次是换题型**
    （shared/vocab.md §5；不用"90% 正确率"这类无出处的阈值）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 5. 第 4 步：跟踪评估

### 5.1 跟踪 3 时间点

```text
T+3 天：短期检测
  → 3 道同类题，看是否"刚讲完还记得"，要求说出依据

T+7 天：中期检测（间隔 ≥3 天，可作为攻克判定的第 2 次验证）
  → 3 道**换题型**的题，看是否只是记住了原题形式

T+30 天：长期检测
  → 2 道综合题，看是否能在有干扰条件时仍然用对
```

### 5.2 跟踪记录表（填实际做对数，不填估计值）

```text
┌──────────┬────────────┬────────────┬────────────┬──────────────┐
│ 学员化名  │ T+3（对/总）│ T+7（对/总）│ T+30（对/总）│ 当前状态      │
├──────────┼────────────┼────────────┼────────────┼──────────────┤
│ A-007    │  3/3       │  3/3       │  2/2       │ 已攻克        │
│ A-008    │  2/3       │  2/3       │  -         │ 突破中        │
│ ...      │            │            │            │              │
└──────────┴────────────┴────────────┴────────────┴──────────────┘

状态用五档：待处理 / 初步弱项 / 顽固弱项 / 突破中 / 已攻克（shared/vocab.md §4）
```

### 5.3 干预效果评估

```text
判定依据是**状态迁移**，不是百分比阈值：

已攻克：两次独立验证都做对，间隔 ≥3 天，其中至少 1 次为换题型/纯净版
突破中：顽固弱项之后首次做对，但还没满足上面的两次条件
仍为顽固弱项：验证仍然做错
  → 先复核错因判定是否正确（很多"干预无效"其实是一开始归错了类），
    再调整干预方案

⚠️ 不使用"90% 正确率""70% 以下算无效"这类无出处的阈值：
   3 道题的正确率只有 0/33%/67%/100% 四个取值，百分比在这个样本量上没有意义。
```
