# 错因分类细则

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-math-error-analyzer` 使用。教师端七类错因的识别信号 + 溯源参考。
> **词表以 `shared/vocab.md §3` 为唯一来源**；写入档案或跨端交接时必须映射到通用四维。
> 使用范围：只对**错误率 >30% 的题**做七类精细判定（阈值触发），其余题只记通用四维。

## 1. 错因分类总览

```text
┌────────────────┬────────────────────────┬────────────┬──────────────────────┬──────────┐
│ 错因（教师端七类）│ 描述                    │ 关键特征    │ 教学策略              │ 通用四维  │
├────────────────┼────────────────────────┼────────────┼──────────────────────┼──────────┤
│ 知识漏洞        │ 缺前置知识              │ 前几节内容错│ 补前置                │ 概念模糊  │
│ 概念模糊        │ 没理解本节概念          │ 题目陌生    │ 重讲概念 + 正反例      │ 概念模糊  │
│ 规则错误        │ 公式/法则记错           │ 错得"有理"  │ 最小步骤拆解 + 操练    │ 概念模糊  │
│ 审题错误        │ 漏看条件/看错问题/抄错题 │ 答非所问    │ 训练审题（圈关键词）   │ 读题失误  │
│ 策略错误        │ 方法选择不当            │ 解题思路错  │ 教策略选择 + 题组训练  │ 方法用错  │
│ 表达/书写不规范  │ 会做但过程分丢了        │ 答案对、扣分│ 过程分示范 + 评分说明  │ 方法用错  │
│ 计算错误        │ 列式对、算错            │ 过程对结果错│ 计算专项 + 估算验证    │ 计算失误  │
│ 习惯性失误      │ 漏单位/跳步/不检验       │ 固定动作缺失│ 习惯与检查流程训练     │ 计算失误  │
└────────────────┴────────────────────────┴────────────┴──────────────────────┴──────────┘

⚠️ 不使用"粗心"作为原因——粗心是结果。原"粗心大意"改为"习惯性失误"，
   且必须写清具体动作（漏写单位 / 跳步 / 未检验），否则不能作为一条错因记录。
⚠️ 习惯性失误的干预是**习惯与检查流程训练**，不是"心理干预"。老师端不做心理诊断。
```

## 1.1 互斥判定规则（一道题只归一类）

```text
按顺序问，问到第一个"是"就定类：
  ① 前置知识都不会？        → 知识漏洞
  ② 本节概念说不清？        → 概念模糊
  ③ 法则/公式记错？          → 规则错误（**不归计算错误**）
  ④ 条件看错、抄错题？       → 审题错误（**不归习惯性失误**）
  ⑤ 方法选错？              → 策略错误
  ⑥ 方法对、过程写不全被扣分？→ 表达/书写不规范
  ⑦ 列式对、只是算错？       → 计算错误
  ⑧ 漏单位/跳步/不检验？     → 习惯性失误

高频争议对照：
  "移项不变号"        → 规则错误（③），不是计算错误
  "看错 5 写成 6"     → 审题错误（④），不是习惯性失误
  "不等式乘负数没变号" → 规则错误（③）
  "结果没写单位"      → 表达/书写不规范或习惯性失误，按是否扣分区分
  "会做但没时间写完"  → 不记为错因，记为答题节奏问题
```

## 2. 错因识别信号

### 2.1 概念模糊

```text
信号：
  · 学员错得"很没把握"
  · 同一概念反复错
  · 学员自己说"我没懂"
  · 学员不能讲出概念

学员原话：
  · "我没学懂"
  · "我不确定"
  · "什么是 X？"
```

### 2.2 规则错误

```text
信号：
  · 学员说"我记了公式但用错"
  · 错得"有理有据"（学员觉得自己对）
  · 概念清晰但规则错
  · 多次用错同一规则

学员原话：
  · "公式是 X 吗？"
  · "我记得是这样..."
  · "我以为是这样用"
```

### 2.3 审题错误

```text
信号：
  · 答非所问
  · 漏看条件
  · 看错问题（求面积看成周长）
  · 不止一次审题错

学员原话：
  · "我看错了"
  · "我没看到那个条件"
  · "我以为是求 X"
```

### 2.4 策略错误

```text
信号：
  · 解题方向错
  · 学员不知道"用哪个方法"
  · 复杂题不会拆
  · 复杂题完全没思路

学员原话：
  · "我不知从哪下手"
  · "我用了 X 方法但做不下去"
  · "这种题我没见过"
```

### 2.5 计算错误

```text
信号：
  · 过程对，结果错
  · 学员能"指出来错了"
  · 简单题算错
  · 限时练习算错多

学员原话：
  · "我算错了"
  · "我以为是 X"
  · "我重新算一遍"
```

### 2.6 表达/书写不规范

```text
信号：
  · 答案对但过程分被扣
  · 证明题只写结论不写依据
  · 跳步，改卷时接不上
  · 不写"解:"、不写答句

学员原话：
  · "我明明做对了为什么扣分"
  · "这一步不用写吧"
  · "我心算的"
```

### 2.6b 习惯性失误（原"粗心大意"一类）

```text
信号（都是**固定动作缺失**，不是态度问题）：
  · 誊抄自己的中间结果时写错
  · 漏写单位、漏写答句
  · 做完不检验（方程不代回、几何不复核图）

不属于本类：
  · 抄错题目、看错数字 → 审题错误
  · 法则记错 → 规则错误

学员原话：
  · "我忘了写单位"
  · "我没检查"
  · "我算完就交了"

⚠️ 记录时必须写清是哪个动作缺失，只写"不小心/赶时间"不能成为一条错因。
```

### 2.7 知识漏洞

```text
信号：
  · 缺前置知识
  · 学员听不懂讲解
  · 不是本节内容，是前几节内容
  · 同类问题都错

学员原话：
  · "这个我没学过"
  · "我忘了"
  · "我之前没掌握"
```

## 3. 错因溯源四层

```text
第一层：表面错因
  学员做错了

第二层：错因分类
  7 类之一

第三层：根因
  概念模糊 → 是哪个概念？
  规则错误 → 是哪个规则？
  知识漏洞 → 是哪个前置？

第四层：教学原因
  教法问题？
  学员基础问题？
  复习问题？
```

## 5. 错因追踪规则

```text
口径按 `shared/vocab.md §5` 的**老师端**规则：由 `xiaozhi-teach-homework-tracker` 计数，
本 SKILL 不自行累加。粒度是"同一知识点 + 同一通用四维"（不是同一子类别）。

■ 累计 3 次 → 顽固弱项
  · 启动专项干预
  · 设计针对性训练
  · 写入 classWorkspace.weaknessRank[]，stubbornCount +1

■ 累计 5 次 → 高危
  · 先与学生本人沟通策略
  · 是否告知家长依授权位（shared/vocab.md §8）：先查 parentSharingConsent，
    涉及情绪内容再查 emotionSharingWithParent；不默认推送家长
  · 需要外部支持时，走学校既有流程

■ 两次独立验证做对（间隔 ≥3 天，含 1 次换题型）→ 已攻克
  · 状态用五档：待处理 / 初步弱项 / 顽固弱项 / 突破中 / 已攻克
  · 已攻克后 30 天内再错 → 回到"突破中"
  · 不用"错因消失/已解决"这类说法
```

## 6. 教学干预建议

### 6.1 概念模糊

```text
■ 重新讲解
  · 用更具体的情境
  · 用更直观的图示
  · 用学员能理解的语言

■ 检测
  · 学员能用自己话讲
  · 学员能举出例子
  · 学员能做简单题
```

### 6.2 规则错误

```text
■ 强调规则
  · 写下来
  · 反复读
  · 正反例对比

■ 检测
  · 学员能正确写出
  · 学员能正确使用
```

### 6.3 审题错误

```text
■ 训练审题
  · 画关键词
  · 标问题（求什么）
  · 标条件（已知什么）

■ 检测
  · 学员不漏条件
  · 学员不错看问题
```

### 6.4 策略错误

```text
■ 教策略
  · 给方法框架
  · 给方法选择清单
  · 题组训练

■ 检测
  · 学员能选对方法
  · 学员能说出为什么选这个方法
```

### 6.5 计算错误

```text
■ 加强练习
  · 限时计算
  · 验算习惯
  · 减少跳步

■ 检测
  · 计算正确率提升
```

### 6.6 表达/书写不规范

```text
■ 过程分示范
  · 公开评分标准：这道题的分点在哪几步
  · 老师板书一份"满分答卷"，学生对照自己的写法
  · 证明题固定格式：因为…所以…（依据）

■ 检测
  · 同一道题的过程分从 [N] 提到 [N]
  · 学生能自己指出"这里少写了依据"
```

### 6.6b 习惯性失误

```text
■ 习惯与检查流程训练（不是心理干预）
  · 五步答题模板固定下来：设 → 列 → 解 → 检验 → 答
  · 检验写进例题示范，让它成为解题的一部分而不是额外动作
  · 交卷前检查清单：符号 / 单位 / 是否回答了所问

■ 检测
  · 漏单位、漏答句的题数下降
  · 学生能在交卷前自己查出至少 1 处

⚠️ 老师端不做心理诊断、不开心理处方。学生出现持续情绪困扰时，
   按 shared/crisis-exception.md 处置或转学校心理老师。
```

### 6.7 知识漏洞

```text
■ 补前置
  · 找出缺哪个前置
  · 单独讲解
  · 加前置练习

■ 检测
  · 前置知识掌握
  · 本节内容能学会
```
