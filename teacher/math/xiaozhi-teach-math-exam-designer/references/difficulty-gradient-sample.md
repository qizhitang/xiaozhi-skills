# 难度比例样板

> 适用学段：初中（7-9 年级）。
> 难度档用 schema 的三个枚举值：基础 / 中等 / 较难（`difficultyBand`）。
> 比例按适用场景选，并写入 `examBlueprints[].difficultyRatio`。

## 场景一：校内形成性测评（6:3:1）

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 10 题排布 · 形成性 · difficultyRatio = "6:3:1"
   目的：调进度、看学生学到哪，多数学生要能拿到基础分
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 第 1-6 题（基础，共 60%）
  · 单一知识点、单一方法、直接应用
  · 预期 P ≈ 0.8-0.95
  · 基础题允许 D < 0.2（大家都会本来就不该拉开差距）

■ 第 7-9 题（中等，共 30%）
  · 多个知识点、需要先判断用什么方法
  · 预期 P ≈ 0.5-0.7
  · 要求 D ≥ 0.2（这一档是区分度的主要来源）

■ 第 10 题（较难，10%）
  · 综合/探究/开放
  · 预期 P ≈ 0.15-0.35，要求 D ≥ 0.2

■ 排布原则
  · 由易到难，同题型集中
  · 不忽高忽低（第 3 题突然很难会打乱学生节奏）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 场景二：期末 / 中考模拟（7:2:1）

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 10 题排布 · 终结性 · difficultyRatio = "7:2:1"
   目的：贴近中考卷结构（中考卷的基础题占比高于校内练习卷）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 第 1-7 题（基础，共 70%）  预期 P ≈ 0.8-0.95
■ 第 8-9 题（中等，共 20%）  预期 P ≈ 0.5-0.7，D ≥ 0.2
■ 第 10 题（较难，10%）      预期 P ≈ 0.15-0.35，D ≥ 0.2
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 场景三：诊断性测评（8:2:0）

```text
只出基础与中等，不出较难题——目的是看"起点在哪"，不是拉开差距。
不排名、不计入评价。
```

## 考后校准

```text
拼卷时填的是**预期 P**（items[].expectedP）；
考后算出**实际 P** 与 **D**（itemStats[]），两者对不上就是下次命题的校准依据：
  实际 P 明显低于预期 → 这道题比预想的难，flag = 偏难
  实际 P 明显高于预期 → flag = 偏易
  中等/较难题 D < 0.2 → flag = 区分度低
  D < 0 → flag = 疑似错题，先复核题目本身
```
