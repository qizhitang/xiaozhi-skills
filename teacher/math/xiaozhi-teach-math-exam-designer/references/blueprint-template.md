# 双向细目表模板

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-math-exam-designer` 使用。让测评从"凭感觉"到"系统化"。
> **纵轴统一用 2022 版课标四级结果目标**（对应 schema `cognitiveLevel` 的 enum）；Bloom 六级只作对照。

## 1. 双向细目表定义

```text
横轴：知识点
纵轴：能力层级（课标四级：了解 / 理解 / 掌握 / 运用）
交叉点：题号 + 分值
首行必须写明：测评类型（诊断性/形成性/终结性）与难度比例及其适用场景
```

## 2. 能力层级：课标四级（含 Bloom 对照）

```text
┌──────────┬──────────────────────────────┬──────────────┬────────────────┐
│ 课标四级  │ 含义（课标行为动词）           │ 常见题型      │ Bloom 对照      │
├──────────┼──────────────────────────────┼──────────────┼────────────────┤
│ 了解      │ 知道、说出、辨认、举例          │ 选择/填空     │ 记忆            │
│ 理解      │ 描述、解释、说明、比较、判断     │ 选择/填空/判断 │ 理解            │
│ 掌握      │ 计算、求解、证明、画出、应用     │ 计算/解答/作图 │ 应用            │
│ 运用      │ 分析、探究、设计、建模、论证     │ 综合/开放/探究 │ 分析/评价/创造   │
└──────────┴──────────────────────────────┴──────────────┴────────────────┘

习惯 Bloom 的老师按右列换算：
  记忆→了解  理解→理解  应用→掌握  分析/评价/创造→运用
```

## 3. 双向细目表设计原则

```text
■ 知识点覆盖
  · 本单元所有重要知识点
  · 重点知识点题量多
  · 次要知识点题量少

■ 能力层级分布（按分值占比，经验值，可按本班调整）
  · 了解 + 理解：40-50%
  · 掌握：      35-45%
  · 运用：      10-20%
  · 三段合计 100%；诊断性测评可把"了解+理解"提到 60%

■ 难度比例（difficultyRatio，按适用场景二选一）
  · 校内形成性：基础 60% / 中等 30% / 较难 10%   → "6:3:1"
  · 期末·中考模拟：基础 70% / 中等 20% / 较难 10% → "7:2:1"
  · 诊断性：可用 "8:2:0"，不出较难题

> 能力层级 ≠ 难度：一道"运用"层的题可以是中等难度，
> 一道"掌握"层的题也可能因运算量大而较难。两栏分别填。
```

## 4. 双向细目表样板

> 三份样板的分值分布都按 §3 的规则算过：了解+理解 40-50%、掌握 35-45%、运用 10-20%；
> 难度比例与首行声明的适用场景一致。照抄前请按本班实际调整。

> ⚠️ 旧版三份样板存在两个问题，已修正：
> ① 首行学段写"小学"但内容是初中（三元一次方程组、方程组消元），学段与内容不符；
> ② 纵轴用 Bloom 六级，与 SKILL 正文和 schema 的 `cognitiveLevel`（课标四级）不一致，
>    且分值分布不满足自己声明的比例规则。现三份样板均按课标四级重排并逐项校验过。

## 5. 双向细目表自检

```text
□ 首行是否写明测评类型与难度比例的适用场景？
□ 知识点是否覆盖本单元所有重要点？重点知识点题量是否足够？
□ 纵轴是否用课标四级（了解/理解/掌握/运用），没有混进 Bloom 六级？
□ 能力层级分值：了解+理解 40-50%？掌握 35-45%？运用 10-20%？
□ 难度分值是否与首行声明的比例一致（6:3:1 或 7:2:1）？
□ 总分是否等于 fullScore（100/120/150）？
□ 每道题的 cognitiveLevel 与 difficultyBand 是**分别**判定的，没有互相推导？
□ AI 生成的题是否已标【AI 生成，入库前请人工验算】且老师已验算？
□ copyrightStatus 为"仅存索引"的题是否只记了题号与出处、没有复制题面？
```

## 6. 题目选编与版权

> 题目来源表、选编原则与版权四值（自有 / 改编 / 公开可引用 / 仅存索引）
> 统一见 `xiaozhi-teach-math-exam-designer/SKILL.md` §六，本文件不重复维护，避免两处口径不一致。

## 7. 双向细目表使用流程

```text
① 列出本单元所有重要知识点
  · 根据教学大纲
  · 根据本班教学实际

② 确定每个知识点的能力层级（课标四级）
  · 课标对这个知识点的要求是"了解"还是"掌握"

③ 设计题目
  · 按双向细目表设计
  · 标注每道题的知识点 + 能力层级 + 难度档 + copyrightStatus

④ 检查分布（用 §5 自检表逐条过）
  · 知识点是否覆盖
  · 能力层级分值是否落在区间内
  · 难度分值是否等于首行声明的比例

⑤ 调整
  · 不合理的地方调整
```
