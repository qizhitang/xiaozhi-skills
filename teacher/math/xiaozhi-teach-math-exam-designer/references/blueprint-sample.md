# 双向细目表样板

> 适用学段：初中（7-9 年级）。
> 纵轴用 2022 版课标四级结果目标（了解/理解/掌握/运用），与 schema `cognitiveLevel` 一致。
> 更完整的三份学科样板见同目录 `blueprint-template.md` §4。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 双向细目表 · [测评名] · [日期]
   测评类型：[诊断性/形成性/终结性]   满分：[100/120/150]
   难度比例：[6:3:1 校内形成性 / 7:2:1 期末·中考模拟 / 8:2:0 诊断性]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
知识点      │ 了解        │ 理解        │ 掌握        │ 运用
────────────┼─────────────┼─────────────┼─────────────┼──────────
知识点 1    │ T1(4) T2(4) │ T5(8)       │             │
知识点 2    │ T3(4)       │ T6(6)       │ T9(10)      │
知识点 3    │ T4(4)       │ T7(8)       │ T10(12)     │
知识点 4    │             │ T8(8)       │ T11(10)     │ T13(4)
知识点 5    │             │             │ T12(8)      │ T14(10)
────────────┴─────────────┴─────────────┴─────────────┴──────────
共 14 题，满分 100

【能力层级分值】了解 16% / 理解 30% / 掌握 40% / 运用 14%
   校验：了解+理解 46%（应在 40-50%）✓
        掌握 40%（应在 35-45%）✓
        运用 14%（应在 10-20%）✓

【难度分值】基础 [N] / 中等 [N] / 较难 [N]
   校验：与首行声明的难度比例一致 ✓

【题目属性】每题另记：itemType / difficultyBand / expectedP /
            copyrightStatus（自有·改编·公开可引用·仅存索引）/
            aiGenerated / verifiedByTeacher
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

> ⚠️ 旧版样板纵轴用 Bloom 六级（记忆/理解/应用/分析/评价/创造），
> 与 SKILL 正文和 schema 的 cognitiveLevel 不一致，且分值分布未按规则校验，已按课标四级重排。
