# 数学测评题目统计模板

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-math-exam-designer` 使用。考后先做**逐题项目分析（P/D）**，
> 再看分数分布与知识点得分率。**本模板到此为止。**
>
> ⚠️ **边界（先读这一段再往下填）**
> 本模板只填**题目层面的统计量**——每道题多难、能不能区分、哪些知识点得分率低。
> 下列四类内容**不在本 SKILL 范围内，本模板不提供填写指令，只提供交接口**：
>
> | 想做的事 | 该由谁做 |
> |---|---|
> | 错因归类、七类错因分布、个体错因诊断 | `xiaozhi-teach-math-error-analyzer` |
> | 学员分层（A/B/C tier）、重点关注名单 | `xiaozhi-teach-student-analyzer` |
> | 补救计划、教学干预、课时增减、讲评课编排 | `xiaozhi-teach-math-lesson-planner` |
> | 成绩告知、家长沟通措辞、约谈安排 | `xiaozhi-teach-parent-communication` |
>
> 老师在本流程里直接提出上述需求时：说明这属于哪个 SKILL，交出可用的最小字段
> （examId + itemStats[] + itemScores[]），不要在本模板里就地代做。
> 若平台未安装对应 SKILL，如实说明"这部分需另行启用"。
>
> **前提：需要逐题分数**（`classWorkspace.itemScores[]`）。只有总分时，
> 本模板只能填第 1 维（分数分布），第 0 维与第 2 维都做不了，报告中必须写明
> "本次只有总分，未做项目分析"。

## 0. 第 0 维：逐题项目分析（考后第一件事）

写入 `classWorkspace.itemStats[]`。

```text
难度 P = 该题班级平均得分 ÷ 该题满分            （0-1，越大越容易）
区分度 D = 高分组得分率 − 低分组得分率          （-1~1，越大越能区分）
  分组：按总分排序，**前 27% 为高分组、后 27% 为低分组**（groupingMethod = "27%"）
  样本 < 30 人时每组不足 8 人，改用"上下各半"并注明，D 只作参考

┌──────┬────────┬────────┬────────┬────────┬──────────┬────────────────┐
│ 题号  │ 知识点  │ 难度档  │ 预期P   │ 实际P   │ 实际D     │ flag           │
├──────┼────────┼────────┼────────┼────────┼──────────┼────────────────┤
│ T1   │ [X]    │ 基础    │ 0.90   │ 0.92   │ 0.10     │ 正常           │
│ T5   │ [X]    │ 中等    │ 0.60   │ 0.38   │ 0.35     │ 偏难           │
│ T9   │ [X]    │ 中等    │ 0.60   │ 0.55   │ 0.12     │ 区分度低       │
│ T12  │ [X]    │ 较难    │ 0.25   │ 0.20   │ -0.05    │ 疑似错题       │
│ ...  │        │        │        │        │          │                │
└──────┴────────┴────────┴────────┴────────┴──────────┴────────────────┘

flag 判读规则：
  正常     实际P 接近预期P，且（中等/较难题）D ≥ 0.2
  偏难     实际P 明显低于预期P
  偏易     实际P 明显高于预期P
  区分度低 **只对中等/较难题**判：D < 0.2
           —— 基础题 D 低是正常的（大家都会），不判此项
  疑似错题 D < 0（高分组反而做得差），或 P 极低且高分组集体失分
           —— 先复核题干、答案、评分标准，再归因到学生

【信度】Cronbach α（写入 classSummaries[].reliabilityAlpha）
  · 需要逐题分数才能算
  · 样本 < 20 人时参考价值有限，必须注明"样本 N 人，α 仅供参考"
  · 单元卷题目少、内容单一，α 偏低是常见现象，不等于卷子不合格
  · α 描述的是"这些题是否测同一件事"，**不描述学生水平**，
    不能用它给学生或班级下结论
```

## 1. 维度总览（本模板只做前三维）

```text
┌──────────┬────────────────┬──────────────────┬──────────────────────────┐
│ 维度      │ 关注重心        │ 输出              │ 归属                      │
├──────────┼────────────────┼──────────────────┼──────────────────────────┤
│ 0. 逐题    │ P / D / 信度    │ 项目分析表        │ ✅ 本 SKILL               │
│ 1. 分数    │ 整体分布        │ 分数分布图        │ ✅ 本 SKILL               │
│ 2. 知识点  │ 章节得分率      │ 知识点得分率表    │ ✅ 本 SKILL               │
├──────────┼────────────────┼──────────────────┼──────────────────────────┤
│ ─ 错因    │ 错因分布与诊断  │ —                │ ❌ 转 math-error-analyzer │
│ ─ 学员    │ 个体诊断与分层  │ —                │ ❌ 转 student-analyzer    │
│ ─ 干预    │ 补救与讲评编排  │ —                │ ❌ 转 math-lesson-planner │

└──────────┴────────────────┴──────────────────┴──────────────────────────┘

三条实线以上是"这份卷子考出了什么"，以下是"接下来怎么办"。
本 SKILL 只负责上半张表，下半张表交出字段即止。
```

## 4. 交接口：错因、分层、干预、家长（本 SKILL 不做）

前三维填完，报告在本 SKILL 内就结束了。下面这些是老师常接着要的，
**每一项都有专门 SKILL**，本模板只给交接话术与要交出的字段，不给操作步骤。

### 4.1 错因归类与个体诊断 → `xiaozhi-teach-math-error-analyzer`

```text
本 SKILL 能交出的：
  · examId
  · classWorkspace.itemStats[]（哪几题 P 低 / D 低 / flag 异常）
  · classWorkspace.itemScores[]（逐题分数，若老师已录入）
  · 错误率 >30% 的题号清单

话术：
  "T5、T9、T12 三道题错误率超过 30%，逐题数据我整理好了。
   要判断学生是概念没通、还是步骤上出问题，需要看实际答卷，
   这块交给〔班级错因分析〕更准——要我把 examId 和逐题数据交过去吗？"

❌ 本模板不提供：七类错因分布表、错因 × 知识点交叉表、个体主导错因判定。
   错因词表见 shared/vocab.md §3，由错因分析 SKILL 使用，不在此处代填。
```

### 4.2 学员分层与重点关注 → `xiaozhi-teach-student-analyzer`

```text
本 SKILL 能交出的：
  · examId
  · classWorkspace.classSummaries[]（样本量 / 均值 / 标准差 / 分数段分布）
  · 分数段人数分布（不含"谁在哪一段"的姓名或化名对应关系）

话术：
  "分层要看近几次的稳定表现，单次卷子做不了这个判断。
   〔学情分析师〕维护 studentTiers，我把这次的班级统计交过去？"

❌ 本模板不提供：A/B/C 分层判定标准、重点关注学员名单、个人诊断卡。
❌ 本 SKILL 不写 classWorkspace.studentTiers[]。
```

### 4.3 补救、讲评与教学调整 → `xiaozhi-teach-math-lesson-planner`

```text
本 SKILL 能交出的：
  · examId + flag 异常的题号 + 得分率最低的知识点

话术：
  "哪些内容要重讲、讲评课怎么排、要不要加课时，是教案设计的事。
   我把这次得分率最低的三个知识点交给〔数学教案〕？"

❌ 本模板不提供：课时增减建议、讲评重点排序、个别辅导安排、变式训练设计。
   复习排期另转 xiaozhi-teach-review-planner。
```

### 4.4 成绩告知与家长沟通 → `xiaozhi-teach-parent-communication`

```text
❌ 本 SKILL 不生成任何家长可见内容，不安排约谈，不统计"要沟通几名家长"。
   家长侧输出一律交 xiaozhi-teach-parent-communication，
   由它核对 parentSharingConsent 后决定给什么、怎么给。
   本 SKILL 任何情况下都不发班级排名、不发个人名次。
```

## 5. 统计报告样板（本 SKILL 的最终输出）

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📄 [化名] 班 [化名] 测评题目统计报告
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 测评：[化名]（[日期]）   类型：[诊断性/形成性/终结性]
■ 班级：[化名] 班   应考 [N] 人，实考 [N] 人

【一、整体分布】
  · 平均分 [N] 分（得分率 [N]%），与上次相比 [+/-N]
  · 中位数 [N]，标准差 [N]
  · 分数段：见第 1 维

【二、逐题项目分析】
  · 分组方法：27%（样本 <30 人改"上下各半"并注明）
  · flag 异常题：[题号]（偏难/偏易/区分度低/疑似错题）
  · 需要复核题目本身的：[题号]（D<0 或高分组集体失分）
  · 信度 α：[N]（样本 <20 人注明"仅供参考"；无逐题分数填"—"）

【三、知识点得分率】
  · 得分率最低的 3 个知识点：[知识点]（[N]%）

【四、可交接给谁】
  · 错因归类 → 〔班级错因分析〕：examId + itemStats + itemScores
  · 分层与关注名单 → 〔学情分析师〕：examId + classSummaries
  · 补救与讲评 → 〔数学教案〕：flag 异常题号 + 低得分率知识点
  · 家长侧输出 → 〔家长沟通助手〕（本 SKILL 不代写）
  以上均需老师确认后再交出。

【五、写回确认】
  · 待确认条目：examBlueprints / itemStats / classSummaries 各 [N] 条
  · 老师确认前不写入工作空间
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
