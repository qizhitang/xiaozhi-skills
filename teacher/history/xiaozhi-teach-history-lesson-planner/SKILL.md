# 历史教案设计 SKILL

> **一句话定位：** 历史课不是把结论讲给学生听，而是带学生在时空框架里读史料、得结论——每节课都要让学生自己"论从史出"一次。

> 技术边界：本 SKILL 依赖能力 [M, F]，无该能力时按 shared/platform-conventions.md 降级。
> 特有降级话术：本 SKILL 输出教案框架、史料清单与提问链草案，不代替老师备课、不替老师上课。
> AI 整理的史料与素材必须标注 `【AI 整理，入库前请人工核对史实与出处】`；生成课堂练习前按 shared/ai-item-check.md 自检。
> 面向学生的提问链按 `shared/hint-ladder.md` 逐级升，本 SKILL 提供到 L4（半步）的提问设计，L5、L6 的完整示范由老师在课堂上决定。

> 教学主体边界：本 SKILL 只给老师出草稿、做分析，不替老师上课，不代老师回答学生的问题，也不代老师评价学生；面向学生或家长的内容，一律由老师审定后再用（教育部《中小学生成式人工智能使用指南（2025 年版）》）。

> 内容边界：涉及历史评价与史观的表述，以课程标准和统编教材为准；教案草稿不做超出教材的历史评价，不引入争议性解读；史料一律注明可信出处，不用来路不明的网络"史料"（SECURITY_BASELINE.md 4.4）。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

## 一、核心使命

历史课最常见的三种走偏：

```
只讲结论：   老师把意义、影响讲一遍，学生背下来——换一则材料就不会
堆砌史料：   一节课放十几则材料，没有设问，学生只是"看过"
不交代时空： 讲事件不讲时间地点，学生记住了事，却放不回历史里
```

本 SKILL 让每节课都走完"时空定位 → 史料探究 → 历史解释 → 认识与迁移"的闭环，目标对准课标的五个核心素养。

---

## 二、课堂结构：一节课的闭环

| 环节 | 做什么 | 对应的核心素养 |
|---|---|---|
| 时空定位 | 用时间轴或历史地图交代这一课的时间、空间与前后联系 | 时空观念 |
| 史料探究 | 2～4 则精选史料，每则配一个指向明确的设问 | 史料实证 |
| 历史解释 | 学生依据史料说出自己的认识，老师追问"依据在哪里" | 历史解释、唯物史观 |
| 认识与迁移 | 回到课题，联系古今或中外；按教材口径落实价值目标 | 家国情怀 |

提问链从"提取信息"到"解释原因"再到"比较与认识"逐级递进，每级都能在史料里找到依据。

---

## 三、史料的选用规范

```text
① 可信：出自教材、权威史料集或学术著作，写明出处（作者、书名或文献名、年份）
② 精选：一节课 2～4 则，每一则都对应一个教学目标；不为"丰富"而堆砌
③ 多类型：文献、实物、图像、口述、统计，按课题选配
④ 不改原意：删节处用省略号标明，不拼接、不改写
⑤ 不用伪史料：网络流传、查不到原始出处的"名人名言"和图片一律不用
⑥ 地图：用教材地图或标准地图，地图须符合国家有关规定
```

`【AI 整理】` 的史料出处，老师核对原书或原文后才能进课件。

## 四、单元统筹与课时

- **初中**：课标的七个板块（中国古代史、近代史、现代史，世界古代史、近代史、现代史，跨学科主题学习）。跨学科主题学习按课程方案用不少于 10% 的课时。
- **高中**：必修"中外历史纲要"共 25 个专题，4 学分，建议高一修完；选择性必修三个模块为专题史。纲要一课内容多，取舍的原则是：保住时空主线和一两个核心问题，其余交给学生课后阅读。
- 课时、班额、教材版本一律以 `classWorkspace.classProfile` 为准，本 SKILL 不写死教材章节与课时数。

课程结构、25 个专题与选择性必修模块的标题，见 `references/history-curriculum-map.md`。

---

## 五、高中：从初中的通史到高中的通史与专题史

初高衔接要讲清三处升级：课程组织从"七个板块的通史"到"纲要通史 + 选择性必修专题史"；史料从"理解教材提供的可信史料"到"多则史料的综合、比较与互证"；历史解释从"有理有据地表达看法"到"分辨不同的历史解释"。对照表见参考文件第 2.5 节。高一第一课就可以设计一个"同一件事，两则史料说法不同，为什么"的小活动。

## 六、接口

数据契约唯一来源：`shared/class-teaching-workspace.schema.json`（根对象记作 `classWorkspace`）。

```text
读：
  classWorkspace.classProfile     → 年级、班额 classSize、每节课分钟数 periodMinutes、教材版本；
                                     课时伸缩与活动分组都由这里决定
  classWorkspace.weaknessRank     → 本班的薄弱点（如史料信息提取、时空定位），决定这一课的重点与提问密度
  classWorkspace.studentTiers     → A/B/C 分层，决定各环节的 tierVariants
  classWorkspace.interactionLogs  → 上一节课的实际用时（segmentTimings）、观察到的迷思
                                     （misconceptionsObserved）、下次调整建议（adjustmentForNext）

写（均生成待确认条目，老师确认后落库）：
  classWorkspace.lessonPlans[]    → planId / topic / date / periodMinutes /
                                     objectives（statement + cognitiveLevel + coreCompetency）/
                                     segments（含 minutes 与 tierVariants）/
                                     questionChain / boardPlan / sourceWeaknessIds
```

> 本 SKILL 不写考试蓝图 examBlueprints、不写逐题得分 itemScores（命题与讲评在历史命题与答题规范指导，统计在老师通用测评 SKILL）。

`objectives[].coreCompetency` 填五个核心素养之一（唯物史观、时空观念、史料实证、历史解释、家国情怀）。

---

## 七、字段级高敏信息防护

教案与课堂记录里只出现班级、化名或座号；不写学生真实姓名、联系方式、家庭情况与健康信息。老师贴进带真实姓名的名单时，提醒改用化名或座号（`SECURITY_BASELINE.md` 4.1）。

---

## 八、禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---|---|
| 每节课先交代时空，再读史料 | 只讲结论，让学生背意义和影响 |
| 史料写明出处，删节标省略号 | 使用查不到原始出处的网络"史料" |
| 每则史料配一个指向明确的设问 | 堆砌史料不设问 |
| 评价性内容按课程标准和统编教材的口径 | 在教案里写超出教材的历史评价 |
| 按 classProfile 的实际课时设计 | 写死某个版本教材的章节与课时 |
