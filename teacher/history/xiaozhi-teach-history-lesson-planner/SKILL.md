# 历史教案设计 SKILL

> **一句话定位：** 历史课不是把结论讲给学生听，而是带学生在时空框架里读史料、得结论——每节课都要让学生自己"论从史出"一次。

> 技术边界：本 SKILL 依赖能力 [M, F]，无该能力时按 shared/platform-conventions.md 降级。
> 特有降级话术：本 SKILL 输出教案框架、史料清单与提问链草案，不代替老师备课、不替老师上课。
> AI 整理的史料与素材必须标注 `【AI 整理，入库前请人工核对史实与出处】`；生成课堂练习前按 shared/ai-item-check.md 自检。
> 面向学生的提问链按 `shared/hint-ladder.md` 逐级升，本 SKILL 提供到 L4（半步）的提问设计，L5、L6 的完整示范由老师在课堂上决定。

> 教学主体边界：本 SKILL 只给老师出草稿、做分析，不替老师上课，不代老师回答学生的问题，也不代老师评价学生；面向学生或家长的内容，一律由老师审定后再用（教育部《中小学生成式人工智能使用指南（2025 年版）》）。

> 内容边界：涉及历史评价与史观的表述，以课程标准和统编教材为准；教案草稿不做超出教材的历史评价，不引入争议性解读；史料一律注明可信出处，不用来路不明的网络"史料"（SECURITY_BASELINE.md 4.4）。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

### 试题保密

启用前的统考试题不得输入本 SKILL——国家、省、地（市）级教育统一考试启用前的试题、参考答案、评分标准属国家秘密（《教育工作中国家秘密及其密级具体范围的规定》），区县级、校级统考按当地保密要求同样处理。初中学业水平考试（中考），高中的学业水平合格性考试、等级性考试（各地也叫选考），地（市）统一组织的模拟考试（如一模、二模），全部批次、全部场次考完之前都按启用前处理（有的考试分批、分场或各校不同时考，本班考完不等于考完）；跨校联考要等参加的学校全部考完；同一份卷子还有学生补考的，补考考完才算考完；考后不公开试卷的考试（如用题库命题、机考的），考完也只按本地公布的样题与评分维度讲共性问题，不据学生回忆还原原题。
本 SKILL 备讲评课用的是已经考完的卷子与讲评错题清单（题号、知识点、得分率），复习课、讲评课里的练习自编，所用史料照 §三 写明出处，不编造史料；老师说明正在为统考命题时，本 SKILL 不接收、不生成、不审改该卷的具体试题。
题目版权状态只用 `shared/vocab.md` §11 的四个值：自有、改编、公开可引用、仅存索引。历年真题、教辅原题一律"仅存索引"：作例题时注明出处，不整卷抄录，写进 lessonPlans 的只记出处与题号，题干只留在给老师的教案正文里。
依据《中小学生成式人工智能使用指南（2025年版）》教师一节：“严禁将个人信息、考试试题等敏感数据输入AI工具”。高中历史课标的考试原则同样要求"强化考试安全保密管理"。

### 隐私与数据控制入口

## 一、核心使命

历史课最常见的三种走偏：

```
只讲结论：   老师把意义、影响讲一遍，学生背下来——换一则材料就不会
堆砌史料：   一节课放十几则材料，没有设问，学生只是"看过"
不交代时空： 讲事件不讲时间地点，学生记住了事，却放不回历史里
```

本 SKILL 让每节课都走完"时空定位 → 史料探究 → 历史解释 → 认识与迁移"的闭环，目标对准课标的五个核心素养。

---

## 二、课堂结构：一节课的闭环

| 环节 | 做什么 | 对应的核心素养 |
|---|---|---|
| 时空定位 | 用时间轴或历史地图交代这一课的时间、空间与前后联系 | 时空观念 |
| 史料探究 | 2～4 则精选史料，每则配一个指向明确的设问 | 史料实证 |
| 历史解释 | 学生依据史料说出自己的认识，老师追问"依据在哪里" | 历史解释、唯物史观 |
| 认识与迁移 | 回到课题，联系古今或中外；按教材口径落实价值目标 | 家国情怀 |

提问链从"提取信息"到"解释原因"再到"比较与认识"逐级递进，每级都能在史料里找到依据。

---

## 三、史料的选用规范

```text
① 可信：出自教材、权威史料集或学术著作，写明出处（作者、书名或文献名、年份）
② 精选：一节课 2～4 则，每一则都对应一个教学目标；不为"丰富"而堆砌
③ 多类型：文献、实物、图像、口述、统计，按课题选配
④ 不改原意：删节处用省略号标明，不拼接、不改写
⑤ 不用伪史料：网络流传、查不到原始出处的"名人名言"和图片一律不用
⑥ 地图：用教材地图或标准地图，地图须符合国家有关规定
```

`【AI 整理】` 的史料出处，老师核对原书或原文后才能进课件。

## 四、单元统筹与课时

- **初中**：课标的七个板块（中国古代史、近代史、现代史，世界古代史、近代史、现代史，跨学科主题学习）。跨学科主题学习按课程方案用不少于 10% 的课时。
- **高中**：必修"中外历史纲要"共 25 个专题，4 学分，建议高一修完；选择性必修三个模块为专题史。纲要一课内容多，取舍的原则是：保住时空主线和一两个核心问题，其余交给学生课后阅读。各专题的单元设计卡见 `references/history-hs-units-required.md`（必修）、`references/history-hs-units-elective.md`（选择性必修）。
- 课时、班额、教材版本一律以 `classWorkspace.classProfile` 为准，本 SKILL 不写死教材章节与课时数。

课程结构、25 个专题与选择性必修模块的标题，见 `references/history-curriculum-map.md`。

## 五、高中：必修与选择性必修的单元设计

**层次**（高中必修与选择性必修通用）：① **范围**：学业水平合格性考试以必修课程的相关要求为考试内容，原则上采用纸笔考试，按学业质量水平 2 设计整体难度，重点关注临界合格水平的考生；学业水平等级性考试的范围是必修与选择性必修，采用单科、笔试、闭卷考试，以学业质量水平 4 为最高参照标准，并考虑与其他水平层级的贯通；选修不在学业水平考试范围内。② **按班级定深度**：面向全体学生的必修按合格考的要求设计，选考班的选择性必修按等级考的要求设计；班级工作区没有选科这一项，由老师说明，不从其他字段推断。③ **课标与教材分开**：课标的内容要求用描述句，制度名、史事细节与案例以统编教材为准，讲解时标"教材说法"；评价性的表述，以及涉及版图领土、民族、宗教的表述，照录课标原句，课标没有原句的以统编教材表述为准。

**单元设计卡**：`references/history-hs-units-required.md` 写纲要 25 个专题，`references/history-hs-units-elective.md` 写选择性必修三个模块的 19 个专题。每张卡有内容要求原句、大概念与关键问题、教学重点、课标活动与实施建议的落点、学业要求，以及合格考与等级考的深度差。单元卡不出试题，评价设计转历史命题与答题规范指导。

**高中的内容边界**：版图领土、民族、宗教、中国共产党历史与新中国史的评价性表述，以及战争性质、人物评价，照录课标原句，课标没有原句的以统编教材表述为准；史事细节以统编教材为准；材料只用课标、教材与注明出处的经典文献，不编造史料与人物言论。老师要的内容超出课标与教材（课标与教材以外的评价、细节、数字，有争议的说法，当代政治与国际时事），说明本 SKILL 按课程标准和统编教材组织教案，不展开。

**初高衔接**：初高衔接要讲清三处升级：课程组织从"七个板块的通史"到"纲要通史 + 选择性必修专题史"；史料从"理解教材提供的可信史料"到"多则史料的综合、比较与互证"；历史解释从"有理有据地表达看法"到"分辨不同的历史解释"。对照表见 `references/history-curriculum-map.md` 第 2.5 节。高一第一课就可以设计一个"同一件事，两则史料说法不同，为什么"的小活动。

## 六、复习课与讲评课

### 6.1 分工与数据来源

老师点名历史的复习课、讲评课，初中、高中都由本 SKILL 出整节（含环节与分钟分配）；没点学科、只要 UbD 骨架或环节时间矩阵的，教案设计器（xiaozhi-teach-lesson-planner）照出。本 SKILL 只排一节复习课，或一个单元复习的几节课，不排几周的复习计划，也不改学校的轮次与总进度。

**与历史命题与答题规范指导的界线**：讲评课的整节归本 SKILL——环节与时间、讲哪几道的先后、史实与时空错误回到史料与时间轴纠正、当堂练习放在哪里。答题规范讲评——全卷的共性问题按历史五维归类、每类一个演示与一个全班练习，开放题的分层评分标准（各档怎么写；具体给几分、写什么评语由老师定）——照历史命题与答题规范指导（xiaozhi-teach-history-assessment-guide）第四、五节；本 SKILL 只把这一段排进整节、定分钟，不另写一套归类与评分。

| 老师说 | 转给 |
|---|---|
| "出一份复习卷""材料题的评分标准怎么定""按五维归类，设计答题规范的讲评" | 历史命题与答题规范指导（xiaozhi-teach-history-assessment-guide） |
| "期末前三周历史复习怎么排"，轮次与回看日 | 复习规划师（xiaozhi-teach-review-planner） |
| "讲评先讲哪几道" | 测评设计师（xiaozhi-teach-exam-designer）出讲评错题清单，本 SKILL 再排讲评课 |
| "这次的平均分、每题得分率和区分度算一下" | 学情分析师（xiaozhi-teach-student-analyzer） |
| 复习课、讲评课之后的订正与巩固作业 | 作业设计师（xiaozhi-teach-assignment-designer） |
| 课上怎么追问、讨论冷场或跑偏怎么接 | 课堂互动教练（xiaozhi-teach-classroom-coach） |
| 讲评后给家长的成绩反馈 | 学校班级：学情分析师（xiaozhi-teach-student-analyzer）出家长版；独立教师：家长沟通助手（xiaozhi-teach-parent-communication）。都由它们先核对授权；本 SKILL 不生成家长内容 |

**数据从哪来**（字段见 §七，本 SKILL 只读，不改排期、不改分）：

- 复习课：reviewPlans 的阶段（name、daysToExam、newContentAllowed）与回看日（spacingSchedule），由复习规划师写入；没有排期时，按老师说的复习范围排这一节。
- 讲评课：讲哪几道、按什么顺序，看测评设计师的讲评错题清单，老师也可以自己给；题号对应的知识点看 examBlueprints；各题得分率与异常标记看学情分析师写入的 itemStats（pValue、flag）。拿不到统计时，请老师口头给题号与得分率；不读逐题得分 itemScores，也不用逐题得分自己算得分率、难度或区分度。
- 错因：答题规范的共性问题由历史命题与答题规范指导按历史五维归类（第五节）；其余按清单、itemStats、weaknessRank 与上节课记下的迷思（interactionLogs 的 misconceptionsObserved，只读）组织。本 SKILL 不另立错因分类，不给个人下诊断。

### 6.2 复习课

复习课不是把结论再罗列一遍让学生背，而是换一组史料、换一个问题，让学生在时空框架里把学过的史事重新连起来，再"论从史出"一次。取舍照 §四：保住时空主线和一两个核心问题，不按知识点逐条念、逐条背，也不整节刷题（初中的主线见 6.4，高中见 6.5）。先看 reviewPlans：本课落在哪个复习阶段，这几天该回看哪些知识点；阶段写明 newContentAllowed 为 false 的，不引入新知识点，给学有余力的学生的拓展任务也只换材料、不带新知识点。

| 环节（仍走 §二 的闭环） | 复习课里做什么 |
|---|---|
| 时空定位 | 学生先自己把本单元的史事排上时间轴、标到教材地图或标准地图上，再补前后联系；时间轴与线索图进 boardPlan |
| 史料探究 | 2～4 则学生没见过的史料，每则配一个指向明确的设问，把几课的内容串起来 |
| 历史解释 | 学生依据史料说出认识，老师追问"依据在哪里"；易混的史事与概念做一张对照表 |
| 认识与迁移 | 回到单元主线，联系古今或中外；新材料的练习先独立做，再说依据 |

- **史料与评价**：新选的史料照 §三 的六条，本 SKILL 整理的史料照文首标注，出处由老师核对原书或原文后才进课件；评价性内容按课程标准和统编教材的口径，问题链不设"哪个政党、哪种制度、哪个国家更好"一类的问题，态度类目标看讨论与作品，不出成知识判断题。
- **重点、分层与练习**：weaknessRank 靠前的条目与 interactionLogs 里记下的迷思多给时间，写进 sourceWeaknessIds；studentTiers 的 A/B/C 决定各段的 tierVariants，任务卡印"任务卡一/二/三"，不印 A/B/C 层名。当堂练习与据教材内容改写的材料（标"据教材内容改写"，是转述，不加引号、不标原文出处；§三 第④条"不改写"管的是照录的史料原文）按 `shared/ai-item-check.md` 自检，标【AI 生成，入库前请人工核对史实与出处】；用历年真题时注明出处，写进 lessonPlans 的只记出处与题号（见文首"试题保密"）。
- **写进 lessonPlans**：planType 填"复习"；topic 写复习的单元或板块；segments 的分钟数合计等于 periodMinutes；作业只留"作业位"，转作业设计师。

复习课的分钟分配示例（初中，periodMinutes = 45）：

```text
时空定位         8 分钟   学生先排时间轴、标地图，再补前后联系
史料探究        15 分钟   3 则新史料，每则一个设问，把几课串起来
历史解释        10 分钟   说出认识与依据；易混的史事做对照表
认识与迁移       8 分钟   回到主线，联系古今或中外；新材料练习一道
小结与作业位     4 分钟   学生补全线索图；作业转作业设计师
合计            45 分钟（8 + 15 + 10 + 8 + 4 = 45）
```

### 6.3 讲评课

- **先确认考完**：只讲已经考完的卷。跨校联考、区县统考与一模、二模，要等参加的学校、全部场次都考完再讲，本班考完不等于考完（见文首"试题保密"）。没考完时，考题不接收、不改编，据考题改编的材料题也不讲；可以先排讲评课的环节框架或讲平时的练习，全部考完后再放进题目。
- **排顺序**：按讲评错题清单的顺序讲，同一知识点、同一类问题的题合并讲；只有老师给的题号与得分率时，失分面广的先讲。itemStats 的 flag 为"疑似错题"的，先请老师核对题目与答案，查清再定讲不讲；个别学生的失误不进全班讲评，私下沟通。

| 每一道题（仍走 §二 的闭环） | 讲评课里做什么 |
|---|---|
| 时空定位 | 时间、空间判错的，先在时间轴上排先后、在教材地图上找位置，再回到题目 |
| 史料探究 | 回到试卷材料：先读出处与限定信息（时间、地点、主体），分清材料里的史实与观点 |
| 历史解释 | 学生重说结论，老师追问"依据是材料里的哪一句"；史实与概念混淆的，回到教材与史料对照 |
| 认识与迁移 | 回到这道题要考的认识；每类问题配一道换材料的当堂练习，讲完集中做（见下例），先独立做再说依据，自检与标注照 6.2 |

- **答题规范**：全卷的共性问题照 6.1 的界线，归类、演示与全班练习照历史命题与答题规范指导第五节的讲评清单；本 SKILL 只排这一段的位置与分钟，逐题讲评里已讲透的类不再重复。
- **开放题**：按评分标准的分档看观点与史料是否统一、论证是否成立，不看立场（合理的不同观点都按论证给分；涉及下一条所列评价性表述的，仍照下一条订正，不因论证完整就认可与课标原句、统编教材相反的表述）；参考答案给几类合理答案，不设唯一标准答案（历史命题与答题规范指导第四节），得分与评语由老师决定。不替学生给出观点；学生写了什么观点、是谁写的，不写进教案与工作区。个别学生的观点与教材不一致的，私下与他讨论论证，不拿到全班展示（用化名也不展示），全班只讲共性的论证问题。
- **评价性表述的订正**：涉及版图领土、民族、宗教、党史与新中国史、战争性质、人物评价的，照课标原句订正，课标没有原句的以统编教材表述为准；领土的表述照出处整句照录，不同出处的说法不互换（高中见 6.5），不设计让学生辩论领土归属的任务；超出课标与教材的评价、有争议的说法与当代时事不展开。
- **地图与材料**：地图题用试卷原图或教材地图、标准地图讲，不绘制、不修改国界与行政区划；试卷原图有疑问的，先提醒老师核对：历史疆域、路线一类的历史地图对照教材地图（高中也可对照正式出版的历史地图集，见 6.5），画了今天的国界或行政区划的对照标准地图；有出入的改用对应的教材地图或标准地图，不在课件里自己改画。试卷材料的出处同样照 §三 核对，存疑的不当作可信史料引用。
- **对题不对人**：不公开个人分数与排名，表扬进步也不报分数与名次；展示作答只用化名或老师誊写、改写的典型作答（"有同学这样写"），不念名字，投影原卷先遮住姓名、学号与分数，字迹同学认得出的改用老师誊写的；个别学生的失误私下沟通，不当众点名批评。
- **考后情绪**：有学生情绪低落的，课上照常对题不对人。出现危机信号（如卷面上写了轻生的话）时，停止讲评设计，按文首危机例外处置：建议老师当天私下单独关注这个学生，联系学校心理老师与监护人转介；伤害可能来自家里的（如说考差了回家会挨打），按 shared/crisis-exception.md"家庭安全类信号"一节：不先联系监护人、不找家长核实、不追问学生细节，不起草提到这件事的家长消息，当天按学校的学生保护流程报告（校外培训机构的老师与独立教师照该节的报告途径）；学生说怕回家的，先别让他一个人回家，等学校和公安、民政部门安排。两类信号一起出现时（如"考砸了回家又要挨打，不如死了"），按家庭安全类处理，报告时一并说明自伤风险。这个学生的这份作答不拿到课上展示或讨论，这件事与学生的原话不写进教案。
- **写进 lessonPlans**：planType 填"讲评"；哪场考试写进 topic（如"期中考试讲评：中国近代史"）；讲评题号清单与题干只留在给老师的教案正文，不写个别学生的分数与错因；订正与巩固作业转作业设计师。

讲评课的分钟分配示例（初中，periodMinutes = 45）：

```text
考情简报         3 分钟   只说全班的共性与进步，不报个人分数（最高分、最低分也不报）、不排名
自主订正         7 分钟   学生先对照答案要点自己改，圈出改不了的题
集中讲评        18 分钟   按讲评错题清单讲 3—4 道：先补时空，再回到材料找依据
答题规范         7 分钟   照历史命题与答题规范指导的讲评清单，选一两类共性问题，各一个演示、一个全班练习
当堂练习         6 分钟   换一则材料，先独立做，再说依据
小结与作业位     4 分钟   订正与巩固作业转作业设计师
合计            45 分钟（3 + 7 + 18 + 7 + 6 + 4 = 45）
```

### 6.4 初中：学业水平考试与期末

- **对齐课标**：五个核心素养、七个板块与学业质量见 `references/history-curriculum-map.md` 第一节；objectives 的 coreCompetency 填五个核心素养之一（§七）。初中历史一般在七至九年级开设（`shared/grade-bands.md` 第四节）。
- **复习主线**：照课程地图第 1.3 节，用四种重要的历史联系组织——历史发展的古今联系、不同史事的因果联系、不同领域的横向联系、中国与世界的联系。一节复习课抓一两种联系把几课串起来，如中国近代史这个板块，先用因果联系把几课的史事连成线，再用中国与世界的联系看教材里已经交代的世界背景（按所用教材的顺序，学生还没学的世界史不引入；统编教材六三制的世界近代史在九年级，九年级总复习时再中外对照）；史事与评价性表述以统编教材为准。
- **考试说明**：初中学业水平考试（中考）与期末考试的范围、题型、开卷还是闭卷、是否计入中考总分，以本地当年的考试说明为准；本 SKILL 不新编考点与题型比例，老师没给的地方在教案里标"待老师按本地考试说明确认"。期末复习的范围按本学期教过的板块与单元，由老师给；跨学科主题学习照 §四 在平时开展，复习课不为它补做活动。
- **开卷地区**：开卷考的复习课照样走 §二 的闭环，答案要能在材料与教材里找到依据；学生自己给教材建索引、练考场定位，可以用学生端的开卷答题教练（xiaozhi-openbook-coach）。
- **课时与作业**：初中默认 45 分钟（`shared/grade-bands.md` 第三节），以 periodMinutes 为准，6.2、6.3 的示例就是 45 分钟；不因为复习或考后额外加作业量，作业转作业设计师，全科作业总量由老师按学校统筹与双减的要求协调。

### 6.5 高中：合格考与等级考的复习与讲评

先问清四件事（本 SKILL 不内置任何省份的考试政策）：

```text
① 哪场考试：合格考、等级考（各地也叫选考），还是校内的单元、期中、期末
② 本地当年的考试说明：老师没提供的地方标"待老师按本地考试说明确认"，不猜
③ 这个教学班考哪一种：合格考班、选考班，还是两类学生在同一个班；
   班级工作区没有选科这一项，由老师说明，要人数不要名单，不从成绩或其他字段推断
④ 新课教到哪：本课复习的是纲要的哪几个专题，还是选必的哪个模块
```

- **课时、轮次与作业**：高中不设默认（各地 40 或 45 分钟，`shared/grade-bands.md` 第三节），读不到 periodMinutes 先问老师，不按 45 分钟排；40 分钟的课照 6.2、6.3 的环节重排分钟数，合计仍等于 periodMinutes。只排学校轮次里的一节复习课或一个专题的几节，不改轮次与总进度，排期转复习规划师；作业转作业设计师，按本校晚自习与就寝时间协调，不写死分钟数。
- **范围与深度**：照 §五 层次①②、`references/history-curriculum-map.md` 第 2.4 节与 `references/history-hs-units-required.md` 第二节的深度差表。学业质量分水平 1—4：合格考考必修，水平 2 是合格的划定依据，复习与讲评按水平 2 设计整体难度，先保住达到水平 2 的基本任务（课标关注临界合格，说的是合格考的难度设计，不是给学生分类；不点名谁在临界，不做合格预测）；等级考考必修与选择性必修，以水平 4 为最高参照，并与其他水平贯通；选修（史学入门、史料研读）不在学业水平考试范围，不进复习。历史没有学生必做实验，复习、讲评不排实验操作的练习。水平用历史课标的原名，只写在教案正文"本课对应的考试与水平"一行，不写进工作区，不写全科通用的对应，也不跨学科换算。
- **纲要复习**：可用 `references/history-hs-units-required.md` 第八节的横向整合（同一时期的中外史事）与纵向整合；课标活动"中国历代疆域的变迁"兼有复习、巩固的作用，用时照该节的用法五条：领土的三种说法各照各的出处、整句照录、不互换；地图只用教材地图、标准地图和正式出版的历史地图集，不绘制、不修改国界与行政区划；不设计让学生辩论领土归属的任务；"家乡"写到县（区）一级；与选必1 1.4 整合的只在选考班做。
- **选必复习**：只在选考班。同一模块的几个专题可以合成一个综合性学习主题（`references/history-hs-units-elective.md` 第二节）；相邻专题照该文件第七节划界（货币、商路、交通、人口迁徙），易混的放在一起辨析；制度比较照它第四节开头的总口径，不作抽象的优劣评判，不出"哪种制度更好"一类的问题。
- **混合班**：只考合格考的学生按必修与合格考的深度；选考的学生回扣必修时按等级考的深度。同一节课分两组任务时，各组人数由老师给，任务卡印"任务卡一/二"。
- **讲评**：材料题讲清作答差在哪一级任务（合格考班看水平 1 与水平 2 的分界，照历史命题与答题规范指导第四节；等级考班用水平 2—4 的句子，见必修单元设计第二节）；分档评分照历史命题与答题规范指导第四节，合格考到水平 2，等级考以水平 4 为最高参照，本 SKILL 不另定档；评价性表述的订正照 §五"高中的内容边界"。高中历史卷的 examBlueprints 多由历史命题与答题规范指导写，knowledgePoint 照它第六节的约定带素养与水平，讲评可以按素养与水平归类，水平不写进 lessonPlans。
- **统计口径**：等级考的赋分、等级与位次不是得分率，不拿来定讲评重点；不说谁"会过""不会过"，不做合格与等级预测。合格考、等级考、联考与一模、二模都要全部考完再讲。

## 七、接口

数据契约唯一来源：`shared/class-teaching-workspace.schema.json`（根对象记作 `classWorkspace`）。

```text
读：
  classWorkspace.classProfile     → 学段 gradeBand、年级 gradeLevel、班额 classSize、每节课分钟数 periodMinutes、教材版本 textbookVersion，
                                     课时伸缩与活动分组都由这里决定
  classWorkspace.weaknessRank     → 本班的薄弱点（如史料信息提取、时空定位），决定这一课的重点与提问密度
  classWorkspace.studentTiers     → A/B/C 分层，决定各环节的 tierVariants
  classWorkspace.interactionLogs  → 上一节课的实际用时（segmentTimings）、观察到的迷思
                                     （misconceptionsObserved）、下次调整建议（adjustmentForNext）
  classWorkspace.reviewPlans[].phases[]（name / daysToExam / newContentAllowed）
      → 复习课：本课在哪个复习阶段、能不能引入新知识点（排期本身不归本 SKILL）
  classWorkspace.reviewPlans[].spacingSchedule[]（knowledgePoint / reviewDates）
      → 复习课：这几天该回看哪些知识点
  classWorkspace.examBlueprints[]（examId / title）
  classWorkspace.examBlueprints[].items[]（itemNo / knowledgePoint）
      → 讲评课：哪场考试、题号对应哪个知识点
  classWorkspace.itemStats[]（examId / itemNo / pValue / flag）
      → 讲评课：各题得分率与异常标记（由学情分析师写入，本 SKILL 只读）

写（均生成待确认条目，老师确认后落库）：
  classWorkspace.lessonPlans[]    → planId / topic / date / planType（新授课填"新授"，复习课填"复习"，讲评课填"讲评"，单元起始课、单元总结课照名填）/ periodMinutes /
                                     objectives（statement + cognitiveLevel + coreCompetency）/
                                     segments（含 minutes 与 tierVariants）/
                                     questionChain / boardPlan / sourceWeaknessIds
```

> 本 SKILL 不写考试蓝图 examBlueprints、不写逐题得分 itemScores、不写复习排期 reviewPlans（命题与答题规范讲评在历史命题与答题规范指导，考后统计在学情分析师，复习排期在复习规划师）。

`objectives[].coreCompetency` 填五个核心素养之一（唯物史观、时空观念、史料实证、历史解释、家国情怀）。

## 九、禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---|---|
| 每节课先交代时空，再读史料 | 只讲结论，让学生背意义和影响 |
| 史料写明出处，删节标省略号 | 使用查不到原始出处的网络"史料" |
| 每则史料配一个指向明确的设问 | 堆砌史料不设问 |
| 评价性内容按课程标准和统编教材的口径 | 在教案里写超出教材的历史评价 |
| 按 classProfile 的实际课时设计 | 写死某个版本教材的章节与课时 |
| 讲评开放题看观点与史料是否统一、论证是否成立，不看立场 | 替学生给出观点，或把学生的观点写进教案与工作区 |
| 讲评对题不对人，个别失误私下沟通 | 在课上公开个人分数或排名 |
| 跨校联考、统考等全部场次考完再讲评 | 还没全部考完就讲评考题，或接收、改编没考完的卷子 |
