# 高中历史学业水平合格性考试命题：范围、蓝图、情境题型与评分

> 示例题验算：2026-10-05
> 适用学段：高中（历史学业水平合格性考试，下称"合格考"；考试内容是必修"中外历史纲要"）。
> 本文是 `xiaozhi-teach-history-assessment-guide`（历史命题与答题规范指导）的参考资源（老师端）。等级考见 `references/history-hs-exam-elective.md`；初中的命题流程与四档量表见 `references/history-item-design.md`。
> 课程依据：《普通高中历史课程标准日常修订版（2017 年版 2025 年修订）》七、实施建议（二）学业水平考试建议；六、学业质量；五、课程内容（一）必修课程。
> 层次：合格考全体学生参加，只考必修，按学业质量水平 2 设计整体难度。选择性必修只在学业水平等级性考试（下称"等级考"）范围内，选修不在考试范围（课标列出的考试范围只有必修，以及必修与选择性必修）。条目编号带模块名：必修 1.9；选择性必修写"选必1 1.2"等。本文的"水平 N"都指学业质量水平（六、学业质量），不是附录「历史学科核心素养水平划分」。
> 口径：「」内是课标原文；「」外是整理与建议，标"整理者理解"的是课标没有明说、从原文推出来的。考试的具体形式、题型、题量、分值、时长，以老师提供的本地当年考试说明为准，课标没写的标【待老师按本地考试说明确认】。样题都标【AI 生成，入库前请人工核对史实与出处】，生成前按 `shared/ai-item-check.md` 自检；史事细节与评价性表述以课程标准和统编教材为准。

## 一、合格考：课标怎么规定

| 项目 | 课标原文 |
|---|---|
| 性质与合格标准 | 「一类是合格性考试，全体学生均须参加，以必修课程的相关要求为考试内容，达到学业质量水平 2 即为合格，是学生学分认定和毕业的重要依据」 |
| 合格的划定依据 | 「历史学科学业质量水平 2 是学生高中毕业应当达到的要求，也是学业水平考试合格等级的划定依据；」 |
| 考试范围 | 「学业水平考试的内容以课程标准规定的课程内容为限。历史学科合格性考试范围为必修课程内容与相关要求；」 |
| 与义务教育衔接 | 「合格性考试与等级性考试均要关注与义务教育阶段历史课程相关内容的有效衔接。」 |
| 依据的教材 | 「合格性考试主要依据必修教材内容及比例设计，做到匹配合理；」 |
| 考试形式 | 「历史学科学业水平考试形式应与考试目标相适应，根据考试目的设置不同的考试形式与考试时长。合格性考试原则上采用纸笔考试形式，考试成绩原则上分为合格、不合格两类。」 |
| 整体难度 | 「合格性考试要依据学业质量水平 2 设计整体难度，重点关注临界合格水平的考生；」 |
| 难度配置 | 「两类考试均应依据试卷难度合理配置易、中、难试题分值比例，提高区分度。」 |

**课标没写、要看本地考试说明的**：题型和各题型的分值、题量、时长；必修里中国史、世界史各占多少（课标只写「主要依据必修教材内容及比例设计」）；合格考开卷还是闭卷（课标里"闭卷"只写在等级考的形式里：「等级性考试采用单科、笔试、闭卷考试形式」）；补考等其他安排。这些一律标【待老师按本地考试说明确认】，不套用其他地区的做法。

### 1.1 "按水平 2 设计、关注临界合格"在命题时怎么落实（整理者理解）

1. **设问的主体是水平 2 的任务**。水平 2 第一段：「对于给定的多则史料所反映的史事，能够综合判断其发生的时间、空间及特征；能够辨别史料类型并说明各自价值，明了史料间的相互关联，提炼出与之关联的事件、人物、现象等历史要素及关键信息；」「能够运用史料描述、解释与之相关的历史现象及规律等，说明史事间的联系，」合格考的材料题可以给两三则材料、要求综合判断，不必压成只读一则材料的题。
2. **临界合格的考生**。达到水平 2 即合格，"临界合格水平的考生"就是表现在水平 1 与水平 2 之间的考生。试卷要让这部分考生的差别显出来：材料题的设问分步，先有水平 1 的任务（「对于给定的具体史事及相关史料，能够判断其发生的时间、空间；」、提炼历史要素），再有水平 2 的任务（多则材料的综合判断、说明史事间的联系）；评分细则把"只复述材料"和"说明了联系"分开给分（见第五节）。
3. **基础题给台阶**。整体难度按水平 2，不等于每道题都卡在水平 2。按「合理配置易、中、难试题分值比例」，留一部分水平 1 的基础题（时间判断、史料类型等），比例由本地考试说明定。
4. **水平 3、4 的任务不作为合格考的主体**。「对于多则、多类型的史料所反映的复杂史事」的综合判断、「对于不同来源、不同观点的史料能够进行比较、分析与互证」的辨析，是等级考的命题参照（见 `references/history-hs-exam-elective.md`）。
5. **选择性必修不进合格考卷**。必修与选择性必修模块1 都从 1.1 编号，蓝图里写全"必修 1.4""选必1 1.4"，免得把选择性必修的内容混进来。

## 二、四条考试原则与六点命制要求

现有 `references/history-item-design.md` 第一节的三条命题原则（导向性、科学性、规范性）和五步流程出自《义务教育历史课程标准（2022 年版）》。高中课标写的是四条「考试的基本原则」和六点「试题命制」要求，原文如下。命题时的工作顺序可以沿用五步（先定考查目标，再找素材、设情境与设问、预估难度、定评分标准），但写课标依据时引高中这四条和六点（整理者建议）。

### 2.1 四条考试原则（原文照录）

| 原则 | 原文 | 命题时对照（整理者） |
|---|---|---|
| 「（1）强化育人导向」 | 「学业水平考试要以习近平新时代中国特色社会主义思想为指导，全面贯彻党的教育方针，落实立德树人根本任务，把握新时代教育评价改革方向。」「考试内容要注重引导学生从历史角度关心国家命运和世界发展，继承和弘扬社会主义先进文化、革命文化、中华优秀传统文化，传承和践行以爱国主义为核心的民族精神和社会主义核心价值观，了解和借鉴人类文明优秀成果，厚植学生文化底蕴，坚定文化自信，成为德智体美劳全面发展的社会主义建设者和接班人。」 | 试题立意与材料的价值导向以课程标准和统编教材为准；家国情怀融进情境与设问，不出成"是否认同"的知识判断题 |
| 「（2）依据课程标准进行命题」 | 「命题要准确理解普通高中历史课程标准的基本内涵，发挥历史课程运用唯物史观的基本观点和方法、展现历史演进基本过程和人类文明成果、解释人类历史发展基本规律的教育功能；要依据课程标准确定考查目标、考试内容范围，运用学业质量标准合理设置试卷难度，综合考查学生正确的价值观、必备品格和关键能力。」 | 考查目标与内容范围按课标条目定（第一节）；难度与评分按学业质量定（第一节 1.1、第五节） |
| 「（3）坚持改革创新」 | 「学业水平考试改革要瞄准深化课程标准理念，立足引导教学改革、优化质量管理、服务科学选才。学业水平考试命题要充分体现核心素养立意，创新试题形式，优化情境设计，注重基础性、综合性、应用性，增强探究性和开放性；要合理运用学业质量标准，客观反映学生学业成就表现，也有助于高校选拔学生。」 | 新情境与探究性、开放性试题（第四节）；合格考仍以基础性为主（第一节 1.1） |
| 「（4）坚持科学规范」 | 「学业水平考试要遵循教育测量与评价的基本要求，明确考试目标，严格命题程序，优化命题技术，强化考试安全保密管理，避免试卷、试题出现政治性、公平性、科学性、规范性问题。」 | 逐题自查政治性、公平性、科学性、规范性四类问题；试题保密见第七节 |

### 2.2 六点试题命制要求

| 要点 | 原句（节选） | 本文落实 |
|---|---|---|
| 「（1）制定命题蓝图」 | 「制定命题蓝图旨在落实命题立意，确保考查内容的代表性和命题的科学性，实现考试目标。命题蓝图要体现考试设计要求，具体化试卷结构，明确每道试题的测试功能和命制要求。」「命题蓝图主要包括考查的学科核心素养、学科内容、学业质量水平等，同时还包括考试时间、题型、分值、预设难度等信息。」 | 第三节 |
| 「（2）注重历史学科核心素养的全面考查」 | 「试题命制要考查学生所具备的历史知识，更要突出考查历史学科核心素养的达成度。」「试卷设计、试题命制要处理好内容分布、核心素养水平分布与分值配置间的比例关系。评分标准应以学业质量标准为参照，能够检测学生核心素养水平的达成度。」 | 第三节（素养分布）、第五节（评分） |
| 「（3）优化考试内容」 | 「试题要以考查课程标准和统编教材所列的相关内容为主，」「也要考虑政治、经济、思想、文化、社会等方面内容的分布及比例，还要重视中国史和世界史不同内容间的整合，以及相关学科内容间的整合；考查内容要与学科核心素养相关联。」 | 第三节（内容分布）；合格考依据的教材见第一节 |
| 「（4）创设新情境」 | 「创设新情境有利于设计探究性、开放性、综合性试题，可有效规避学生日常识记的知识与做题模式，引导学生通过知识迁移，在新情境下分析和解决新问题。」 | 第四节 |
| 「（5）创新试题形式」 | 题型原句见第四节 | 第四节 |
| 「（6）合理控制难度」 | 「考试难度包括试卷总体难度、试题类型难度和各试题难度等。试题命制要根据考试目的、性质、时长和学情等，综合确定整体难度。」 | 第一节 1.1 |

## 三、命题蓝图示例（合格考，示意）

课标的蓝图要素与本技能写入的 `examBlueprints` 字段对应如下（字段以 `shared/class-teaching-workspace.schema.json` 为准，schema 不改）：

| 课标的蓝图要素 | 写进哪个字段 |
|---|---|
| 考查的学科核心素养、学科内容、学业质量水平 | `items[].knowledgePoint`，用下面的约定写法 |
| 题型 | `items[].itemType`（选择 / 材料解析 / 论述） |
| 分值 | `items[].score`；合计写 `fullScore` |
| 预设难度 | `items[].difficultyBand`（基础 / 中等 / 较难） |
| 考试时间 | `durationMinutes` |

**约定写法**：

- `knowledgePoint` 写成"必修 1.9／史料实证／水平 2"：条目编号带模块前缀，用"／"分隔；素养用课标的五个名称（唯物史观、时空观念、史料实证、历史解释、家国情怀）；"水平 N"是学业质量水平。全长不超过 60 字（schema 上限）。
- 一道题考几个素养时，`knowledgePoint` 只写主考的一个，其余写在给老师看的蓝图表里（`items` 没有备注字段）；一道题分档评分时，写它能考到的最高水平。
- `cognitiveLevel` 的四级（了解、理解、掌握、运用）是本库字段的枚举（schema 注明取自 2022 年版义务教育课标的结果目标），高中历史课标没有这套分级。按设问实际要学生做的事填，不由学业质量水平折算。
- 写入的条目由老师逐条确认；AI 生成的题 `aiGenerated` 为 true，老师核对前 `verifiedByTeacher` 为 false，未核对的题不进卷（SKILL.md 接口一节）。

## 四、情境与题型

**情境**：「历史学科试题情境可分为学习情境、生活情境、社会情境、学术情境等类型，根据情境信息情况又可分为简单情境、复杂情境和综合情境。试题命制时应根据考查目标选择情境类型。」

- 课标对四类情境只列名称，没有下定义；2020 年版附的定义和例子，2025 年版已删去，不当课标引用。第六节样题标的情境类型是按素材判断的，仅供参考。
- 简单、复杂、综合三种信息情境，课标没有与学业质量水平一一对应，本文不自造对应。合格考材料的条件照水平 2 的原文：「对于给定的多则史料所反映的史事」，即材料是给定的、多则的。

**题型**：「历史试题一般分为客观题和主观题两大类型。客观题主要表现形式多为选择题，主观题多为材料解析题。不同性质的考试对题型、题量、分值等要求不同，需合理配置；探究性、开放性、综合性试题应占一定比例；鼓励对试题形式进行新探索，以更适合核心素养的考查。」合格考各题型的比例、有没有开放性设问，以本地考试说明为准。

**选择题怎么出（整理者建议）**：

- 题干给足时间、地点、主体等限定。
- 错误选项在作答精度下要与正确选项明确不同（时代、主体、性质至少一处明确不符）；"只有一个答案"的题，把每个选项逆向读一遍。
- 年代先后、年代差的结论写 `verify` 断言（`shared/ai-item-check.md` 第三节）。
- 必修 1.9—1.15：本技能生成的题只出史实题（时间、地点、事件名），事件名用课标或统编教材的原词；不出价值判断题，不出比较哪一事件、哪一人物更重要的题。老师自己命制"认识……意义"一类设问时，参考答案照录课标原句或统编教材表述，不自拟评价。

**材料解析题的材料（三种来源）**：

1. 课标原文；
2. 统编教材正文或教材引用的史料，拿不准原文的写成"材料（据教材内容改写）"，不加引号，不标原文出处；
3. 公认的经典文献短句，写书名、篇名，入库前逐字核对，拿不准的不用。

不编造人物言论、档案、报刊、日记的原文。统计数字只用教材里的；示意数据标"示意"，写"某地""某时期"，不冠以真实国家、年份。`references/history-item-design.md` 第三节的材料选用五条同样适用，其中第②条"不拼接、不改写"针对照录的史料原文；"据教材内容改写"的材料是转述，不加引号、不标原文出处，不当作史料原文。

## 五、评分：以学业质量为参照（合格考到水平 2）

课标：「试题设计要参照学业质量标准，指向历史学科核心素养的考查。」「评分标准应以学业质量标准为参照，能够检测学生核心素养水平的达成度。」合格考的评分档最高到学业质量水平 2。

| 评分档 | 学业质量参照（原句） | 材料解析题卷面上看什么（整理者） |
|---|---|---|
| 水平 2 档（合格要求） | 第一段：「对于给定的多则史料所反映的史事，能够综合判断其发生的时间、空间及特征；」「能够运用史料描述、解释与之相关的历史现象及规律等，说明史事间的联系，」第二段：「在运用史料说明历史问题时，能够运用唯物史观的基本观点和方法，体现出对唯物史观主要内容及唯物史观是科学历史观的初步理解。」 | 用到两则以上材料；判断出时间、空间或特征；说明了史事之间的联系（原因、影响、前后变化），不只复述 |
| 水平 1 档 | 第一段：「对于给定的具体史事及相关史料，能够判断其发生的时间、空间；能够说明给定史料的类型和价值，并提炼出与之关联的事件、人物、现象等历史要素；能够运用所给史料说明历史问题，做到观点和材料的统一；」 | 能从材料里提取要素、判断时间，观点与材料一致；但只用一则材料，或只罗列现象、没有说明联系 |
| 0 档 | （课标没有描述） | 与材料无关；照抄材料、没有提炼；时间、主体判断错误 |

评分细则怎么写（整理者理解与建议）：

1. **最高到水平 2**。答出更高水平的内容（如从来源、目的评析材料），按水平 2 档给满分，不另加分；没有写这类内容也不扣分。
2. **写清水平 1 与水平 2 的分界**。"只复述、只用一则材料"与"综合两则以上、说明联系"分开给分，临界合格考生的分数就落在这条分界上。
3. **唯物史观到"初步理解"**。水平 2 要求的是「体现出对唯物史观主要内容及唯物史观是科学历史观的初步理解」，能用生产力、生产关系等基本观点说明简单的因果即可；水平 3 的「说明、论述历史的发展变化和社会形态演变的基本规律」不作合格考的要求。
4. **家国情怀不设单纯表态的得分点**。第三段的"把握……要素"可以设问；"表达出对中华民族共同体的认同"一类态度要求，不出成知识判断题，也不按是否写出某句表态给分。
5. 参考答案给几类合理答案，不设唯一标准答案；分值区间由老师按本地评分细则定。讲评时共性问题按学生端历史五维归类（`references/history-item-design.md` 第五节）。

### 样题 1（选择题；必修 1.2）

【AI 生成，入库前请人工核对史实与出处】

阅读两则材料：

> 材料一："为政以德，譬如北辰，居其所而众星共之。"——《论语·为政》
>
> 材料二："民为贵，社稷次之，君为轻。"——《孟子·尽心下》

综合两则材料，下列判断正确的是

- A. 材料一主张为政以德，材料二主张民贵君轻，都是春秋战国时期儒家的政治主张
- B. 材料一主张以法治国，材料二主张加强君权，都是战国时期法家的政治主张
- C. 材料一主张为政以德，材料二主张民贵君轻，都是西汉"尊崇儒术"以后才提出的主张
- D. 两则材料都主张清静无为、顺应自然，是春秋战国时期道家的政治主张

答案：A。

设计说明：

- 学科内容：必修 1.2「了解老子、孔子学说；通过孟子、荀子、庄子等了解“百家争鸣”的局面及其意义。」
- 学业质量水平 2：「对于给定的多则史料所反映的史事，能够综合判断其发生的时间、空间及特征」。这里综合判断的是两则材料的时代（春秋战国）与学派特征（儒家）。
- 蓝图：必修 1.2／史料实证／水平 2；理解；中等。情境：研读典籍短句（按素材判断为学术情境）。
- 干扰项：B 把"君为轻"读反，又把儒家主张安到法家（对应子类型 LS04、LK08）；C 学派对、时代错，忽视了《论语》《孟子》是先秦典籍（对应子类型 LS02）；D 学派错（对应子类型 LK08）。
- 逆向试读：A 的两个判断（主张、时代）都与材料和史实相符；B、C、D 各有一处与材料或时代明确不符，作答时能区分。
- 临界合格：只会读出处的考生能排除 B、D；要在 A 和 C 之间作出判断，得把两部典籍放回春秋战国，这一步就是水平 2 的"综合判断时间"（整理者理解）。
- 入库前核对：两则引文按通行本《论语》《孟子》逐字核对。
