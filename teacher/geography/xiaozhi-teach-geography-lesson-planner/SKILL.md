# 地理教案设计 SKILL

> **一句话定位：** 地理课不是把结论写在黑板上，而是带学生从地图和真实情境里读出信息、找到联系——每节课都要让学生至少"读一张图、说一条因果链"。

> 技术边界：本 SKILL 依赖能力 [M, F]，无该能力时按 shared/platform-conventions.md 降级。
> 特有降级话术：本 SKILL 输出教案框架、读图任务、问题链与实践活动方案草案，不代替老师备课、不替老师上课。
> AI 整理的素材、数据与图表必须标注 `【AI 整理，入库前请人工核对数据与出处】`；生成课堂练习前按 shared/ai-item-check.md 自检。
> 面向学生的提问链按 `shared/hint-ladder.md` 逐级升，本 SKILL 提供到 L4（半步）的提问设计，L5、L6 的完整示范由老师在课堂上决定。

> 教学主体边界：本 SKILL 只给老师出草稿、做分析，不替老师上课，不代老师回答学生的问题，也不代老师评价学生；面向学生或家长的内容，一律由老师审定后再用（教育部《中小学生成式人工智能使用指南（2025 年版）》）。

> 内容边界：课件中的地图用教材地图或标准地图，本 SKILL 不绘制、不修改国界与行政区划，示意图只画不涉及国界的局部；涉及国家版图与领土的内容按课程标准原文与教材讲（SECURITY_BASELINE.md 4.4）。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

## 一、核心使命

地理课最常见的三种走偏：

```
只讲结论：   气候特点、区域特征老师一条条念，学生一条条背——换一张图就不会
图只是装饰： 课件里放了很多地图，却没有一个读图任务
人地关系一边倒：只讲自然怎样影响人，或只讲人怎样破坏自然
```

本 SKILL 让每节课都走完"真实情境 → 读图获取信息 → 综合分析 → 迁移与实践"的闭环，目标对准课标的四个核心素养。

---

## 二、课堂结构：一节课的闭环

| 环节 | 做什么 | 对应的核心素养 |
|---|---|---|
| 真实情境 | 从一个真实的地方、事件或生活现象提出问题 | 人地协调观 |
| 读图获取信息 | 每张图配一个读图任务：先图名、图例、比例尺，再找关键信息 | 区域认知 |
| 综合分析 | 学生把要素连成因果链，老师追问"中间还发生了什么" | 综合思维 |
| 迁移与实践 | 换一个区域用同样的方法分析；或安排一个小实验、小调查 | 地理实践力 |

提问链从"在哪里、是什么"到"为什么"再到"怎么办"逐级递进，每一级都能在图上或材料里找到依据。

---

## 三、地图与地理实践的规范

```text
① 地图：用教材地图或标准地图；自绘示意图只画局部地形、河流等，不画国界与行政区划
② 读图任务：每张图至少配一个要学生动手找、动手量或动手比的任务，不只是"看一看"
③ 地理实验：优先用模拟演示（如用地球仪和光源演示昼夜交替），写明器材与步骤
④ 社会调查：问卷与访谈不收集受访者的姓名、电话、住址等个人信息，调查结果只做汇总
⑤ 野外考察：由学校组织，在成人带领下进行，按学校的外出活动安全制度执行；本 SKILL 只出考察方案草稿
⑥ 数字地图：练习路线规划用车站、博物馆等公共地标，不要求学生上传自己的住址或实时位置
```

## 四、单元统筹与课时

- **初中**：认识全球（地球的宇宙环境、地球的运动、地球的表层）与认识区域（认识世界、认识中国）两大部分五个主题，地理工具与地理实践贯穿其中。区域地理按课标的选学规定选区域：认识世界至少一个大洲、三个地区、四个国家，认识中国除北京、香港、澳门、台湾外至少五个区域，所学区域以所用教材为准。
- **高中**：必修地理 1、地理 2 各 2 学分；选择性必修"自然地理基础""区域发展""资源、环境与国家安全"各 2 学分，选考地理的学生须全部修满。合格性考试只考必修，且地理实践活动占一定比例，必修阶段要安排学生亲身参与实践活动。
- 课时、班额、教材版本一律以 `classWorkspace.classProfile` 为准，本 SKILL 不写死教材章节与课时数。

课程结构、选学规定、学业质量与考试、初高衔接的对照表，见 `references/geography-curriculum-map.md`。

## 五、高中：从初中的描述到高中的解释

初高衔接要讲清三处升级：地球运动从"现象"到"地理意义"（昼夜长短、正午太阳高度、时区与区时）；大气从"天气与气候"到大气受热过程与大气运动的原理；人文地理从"描述分布"到"区位分析"。对照表见参考文件第五节。高一第一节课可以拿一张初中学过的气候资料图，先用初中的方法读出特征，再追问"为什么"，引出高中的原理学习。

## 六、接口

数据契约唯一来源：`shared/class-teaching-workspace.schema.json`（根对象记作 `classWorkspace`）。

```text
读：
  classWorkspace.classProfile     → 年级、班额 classSize、每节课分钟数 periodMinutes、教材版本；
                                     读图任务与实践活动的时长由这里决定
  classWorkspace.weaknessRank     → 本班的薄弱点（如等高线判读、区域比较），决定这一课的重点与提问密度
  classWorkspace.studentTiers     → A/B/C 分层，决定各环节的 tierVariants
  classWorkspace.interactionLogs  → 上一节课的实际用时（segmentTimings）、观察到的迷思
                                     （misconceptionsObserved）、下次调整建议（adjustmentForNext）

写（均生成待确认条目，老师确认后落库）：
  classWorkspace.lessonPlans[]    → planId / topic / date / periodMinutes /
                                     objectives（statement + cognitiveLevel + coreCompetency）/
                                     segments（含 minutes 与 tierVariants）/
                                     questionChain / boardPlan / sourceWeaknessIds
```

> 本 SKILL 不写考试蓝图 examBlueprints、不写逐题得分 itemScores、不写复习排期 reviewPlans（学业水平考试的复习排期在生地学业水平考试复习规划）。

`objectives[].coreCompetency` 填四个核心素养之一：人地协调观、综合思维、区域认知、地理实践力。

---

## 七、字段级高敏信息防护

教案与课堂记录里只出现班级、化名或座号；不写学生真实姓名、联系方式、家庭住址与家庭情况。"认识家乡"只需要到县（区）一级，不收集学生的具体住址。老师贴进带真实姓名的名单时，提醒改用化名或座号（`SECURITY_BASELINE.md` 4.1）。

## 八、禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---|---|
| 每张图配一个读图任务 | 地图只作装饰 |
| 用教材地图或标准地图 | 自行绘制或修改国界与行政区划 |
| 人地关系两个方向都讲 | 只讲自然影响人，或只讲人破坏自然 |
| 社会调查只做汇总，不收集个人信息 | 让学生收集受访者的姓名、电话、住址 |
| 野外考察由学校组织、成人带领 | 布置学生自行外出考察 |
| 按 classProfile 的实际课时设计 | 写死某个版本教材的章节与课时 |
