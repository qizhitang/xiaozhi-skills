# 地理教案设计 SKILL

> **一句话定位：** 地理课不是把结论写在黑板上，而是带学生从地图和真实情境里读出信息、找到联系——每节课都要让学生至少"读一张图、说一条因果链"。

> 技术边界：本 SKILL 依赖能力 [M, F]，无该能力时按 shared/platform-conventions.md 降级。
> 特有降级话术：本 SKILL 输出教案框架、读图任务、问题链与实践活动方案草案，不代替老师备课、不替老师上课。
> AI 整理的素材、数据与图表必须标注 `【AI 整理，入库前请人工核对数据与出处】`；生成课堂练习前按 shared/ai-item-check.md 自检。
> 面向学生的提问链按 `shared/hint-ladder.md` 逐级升，本 SKILL 提供到 L4（半步）的提问设计，L5、L6 的完整示范由老师在课堂上决定。

> 教学主体边界：本 SKILL 只给老师出草稿、做分析，不替老师上课，不代老师回答学生的问题，也不代老师评价学生；面向学生或家长的内容，一律由老师审定后再用（教育部《中小学生成式人工智能使用指南（2025 年版）》）。

> 内容边界：课件中的地图用教材地图或标准地图，本 SKILL 不绘制、不修改国界与行政区划，示意图只画不涉及国界的局部；涉及国家版图与领土的内容按课程标准原文与教材讲（SECURITY_BASELINE.md 4.4）。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

### 试题保密

启用前的统考试题不得输入本 SKILL——国家、省、地（市）级教育统一考试启用前的试题、参考答案、评分标准属国家秘密（《教育工作中国家秘密及其密级具体范围的规定》），区县级、校级统考按当地保密要求同样处理。初中学业水平考试、高中的学业水平合格性考试（合格考）与等级性考试（等级考，各地也叫选考）、地（市）统一组织的模拟考试（如一模、二模），以及合格考的非纸笔测试（上机测试、实验测试、地理野外考察测试、社会调查测试），全部批次、全部场次考完之前都按启用前处理（非纸笔测试可能分几次、分批进行，本班考完不等于考完）；跨校联考要等参加的学校全部考完；同一份卷子还有学生补考的，补考考完才算考完；考后不公开试卷的考试（如用题库命题、机考的），考完也只按本地公布的样题与评分维度讲共性问题，不据学生回忆还原原题。
本 SKILL 备讲评课用的是已经考完的卷子与讲评错题清单（题号、知识点、得分率），复习课、讲评课里的练习自编；老师说明正在为统考命题时，本 SKILL 不接收、不生成、不审改该卷的具体试题。
题目版权状态只用 `shared/vocab.md` §11 的四个值：`自有` / `改编` / `公开可引用` / `仅存索引`；历年真题与教辅原题一律 `仅存索引`，只记出处与题号，不整卷抄录，写进 lessonPlans 的也只记出处与题号，题干只留在给老师的教案正文里。
依据《中小学生成式人工智能使用指南（2025 年版）》教师一节："严禁将个人信息、考试试题等敏感数据输入AI工具"。

## 一、核心使命

地理课最常见的三种走偏：

```
只讲结论：   气候特点、区域特征老师一条条念，学生一条条背——换一张图就不会
图只是装饰： 课件里放了很多地图，却没有一个读图任务
人地关系一边倒：只讲自然怎样影响人，或只讲人怎样破坏自然
```

本 SKILL 让每节课都走完"真实情境 → 读图获取信息 → 综合分析 → 迁移与实践"的闭环，目标对准课标的四个核心素养。

---

## 二、课堂结构：一节课的闭环

| 环节 | 做什么 | 对应的核心素养 |
|---|---|---|
| 真实情境 | 从一个真实的地方、事件或生活现象提出问题 | 人地协调观 |
| 读图获取信息 | 每张图配一个读图任务：先图名、图例、比例尺，再找关键信息 | 区域认知 |
| 综合分析 | 学生把要素连成因果链，老师追问"中间还发生了什么" | 综合思维 |
| 迁移与实践 | 换一个区域用同样的方法分析；或安排一个小实验、小调查 | 地理实践力 |

提问链从"在哪里、是什么"到"为什么"再到"怎么办"逐级递进，每一级都能在图上或材料里找到依据。

---

## 三、地图与地理实践的规范

```text
① 地图：用教材地图或标准地图；自绘示意图只画局部地形、河流等，不画国界与行政区划
② 读图任务：每张图至少配一个要学生动手找、动手量或动手比的任务，不只是"看一看"
③ 地理实验：优先用模拟演示（如用地球仪和光源演示昼夜交替），写明器材与步骤；档位按 shared/lab-safety.md 判定（接 220 V 的灯具由老师插拔，明火与热水演示由老师在场组织）
④ 社会调查：问卷与访谈不收集受访者的姓名、电话、住址等个人信息，调查结果只做汇总；出校的调查由学校组织、成人带领、结伴进行，访谈在公共场所，不入户
⑤ 野外考察：由学校组织、成人带领、结伴进行，按学校的外出活动安全制度执行，不独自去水边、山地、工地；本 SKILL 只出考察方案草稿
⑥ 数字地图：练习路线规划用车站、博物馆等公共地标，不要求学生上传自己的住址或实时位置
```

## 四、单元统筹与课时

- **初中**：认识全球（地球的宇宙环境、地球的运动、地球的表层）与认识区域（认识世界、认识中国）两大部分五个主题，地理工具与地理实践贯穿其中。区域地理按课标的选学规定选区域：认识世界至少一个大洲、三个地区、四个国家，认识中国除北京、香港、澳门、台湾外至少五个区域，所学区域以所用教材为准。
- **高中**：必修地理 1、地理 2 各 2 学分；选择性必修"自然地理基础""区域发展""资源、环境与国家安全"各 2 学分，选考地理的学生须全部修满。合格性考试只考必修，且地理实践活动占一定比例，必修阶段要安排学生亲身参与实践活动。
- 课时、班额、教材版本一律以 `classWorkspace.classProfile` 为准，本 SKILL 不写死教材章节与课时数。

**层次**（高中必修与选择性必修通用）：① **范围**：学业水平合格性考试考必修地理 1、地理 2，一般采用纸笔测试和地理实践活动相结合的形式，非纸笔测试包括上机测试、实验测试、地理野外考察测试、社会调查测试等，地理实践活动需占一定比例，学业质量水平 1 是合格等级的划定依据；学业水平等级性考试再加三个选择性必修模块，采取纸笔测试，不超过学业质量水平 3；选修不进考试范围。② **按班级定深度**：面向全体学生的必修按合格考的要求设计，选考班的选择性必修按等级考的要求设计；班级工作区没有选科这一项，由老师说明，不从其他字段推断。③ **课标与教材分开**：课标的内容要求多数不点名具体的地貌类型、天气系统名称、案例区域与国家战略，这些以所用教材为准，讲解时标"教材说法"。

高中各模块的单元设计见 `references/geography-hs-units-required.md`（地理 1、地理 2）与 `references/geography-hs-units-elective.md`（三个选择性必修模块）；课标点名的地理实践活动、组织方式与安全口径见 `references/geography-hs-practice-activities.md`。

课程结构、选学规定、学业质量与考试、初高衔接的对照表，见 `references/geography-curriculum-map.md`。

## 五、高中：从初中的描述到高中的解释

初高衔接要讲清三处升级：地球运动从"现象"到"地理意义"（教材展开为昼夜长短、正午太阳高度、时区与区时，属教材说法）；大气从"天气与气候"到大气受热过程与大气运动的原理；人文地理从"描述分布"到"区位分析"。对照表见参考文件第五节。高一第一节课可以拿一张初中学过的气候资料图，先用初中的方法读出特征，再追问"为什么"，引出高中的原理学习。

**数据来源**（读写字段见 §七 接口）：

- 复习课：reviewPlans 的阶段与回看知识点，由复习规划师或生地学业水平考试复习规划排定；本 SKILL 只读，用来定这一节课，不改排期。

### 6.2 复习课

本 SKILL 只设计一节复习课，或一个单元复习的几节课；几周的排期、轮次与回看日见 6.1，不改学校的总进度。

- **先看阶段**：有 reviewPlans 时，先读本课所在的阶段（phases）与这几天要回看的知识点（spacingSchedule）。阶段的 newContentAllowed 为 false 时不引入新知识点，迁移任务与 C 层的拓展也只换材料、不带新知识点；没有复习计划时，范围与阶段请老师说明。
- **一条线串起来**：照 §二 的闭环，用一个真实情境或区域把几个单元串起来（如一条旅行线路、一条河的上下游、一个区域的一组资料），不按知识点逐条念、逐条背，也不整节刷题；提问链从"在哪里、是什么"到"为什么"再到"怎么办"。
- **读图带复习**：每张图配一个读图任务（§三 ②），先图名、图例、比例尺，再找关键信息；学生边读边补知识结构图，结构图写进 boardPlan。地图用教材地图或标准地图（§三 ①）。
- **情境数据**：用公开来源并标出处，本 SKILL 整理的照文首标注，不编数据。
- **实验与实践的回看**：用当时的记录单、报告与汇总结果回看；复习课里重做的模拟实验照 §三 ③ 按 `shared/lab-safety.md` 定档，中档的不布置在家做；复习课不另外安排外出，确需外出的社会调查、野外考察由学校组织、老师带队（§三 ④⑤）。
- **练习与分层**：迁移任务按 studentTiers 写 tierVariants，任务卡印"任务卡一、二、三"；练习自编，按 `shared/ai-item-check.md` 自检，标【AI 生成，入库前请人工验算】；用历年真题时注明出处，写进 lessonPlans 的只记出处与题号（见文首"试题保密"）。
- **写进教案**：planType 填"复习"，topic 写复习的单元或主题，segments 的分钟合计等于 periodMinutes；作业只留"作业位"，转作业设计师。

下面以初中默认的 45 分钟为例（读不到 periodMinutes 时照 6.4、6.5 处理），其他课时按比例伸缩，合计等于 periodMinutes：

```text
复习课（示例：periodMinutes = 45）
① 情境与回看     5 分钟   一个真实区域或事件；按回看的知识点提两三个快问
② 读图梳理      12 分钟   两三张图，每张配一个读图任务，边读边补知识结构图
③ 综合分析      13 分钟   问题链把几个单元的要素连成因果链，追问"中间还发生了什么"
④ 迁移练习      10 分钟   换一个区域或一张新图，用同样的方法分析（任务卡一、二、三）
⑤ 小结与作业位    5 分钟   学生补全结构图、说出一条因果链；作业位转作业设计师
合计 45 分钟
```

### 6.3 讲评课

- **前提**：卷子已经考完——联考、统考等参加的学校全部考完，分批、分场进行的考试全部批次、全部场次考完（见文首"试题保密"）。没考完时，可以先排讲评的环节框架或讲平时的练习；这次的考题不讲、不改编，据考题编的变式也不讲，不请老师把题目发过来，全部考完后再放进题目与变式。
- **顺序**：照 6.1 的讲评错题清单与统计排；只有老师给的题号与得分率时，失分面广的先讲，同一类图或同一知识点的题归在一起。flag 为"疑似错题"的题先请老师核对题目与答案，再定讲不讲；个别学生的偶发失误不进全班讲评，私下沟通。
- **读图题**：回到试卷原图，照 §二 的读图顺序拆开讲——图名、图例、比例尺 → 关键信息 → 因果链 → 这一类图的读法与常见错误（如漏看图例、比例尺换算错、方向判反、只抄材料不提取关键信息）。每道精讲题配一道换区域或换图的当堂变式，自编，按 `shared/ai-item-check.md` 自检。
- **主观题**：按评分要点与老师改写的典型作答讲"要点"和"表述"，开放题讲清几种合理答案；参考答案与评分标准以试卷与老师为准。
- **地图与版图**：讲评用试卷原图或教材地图、标准地图，不重绘、不改画含国界与行政区划的地图，示意图只画不涉及国界的局部（§三 ①）；试卷原图画了国界或行政区划的（联考卷、本校自命题的卷子都一样），先提醒老师按标准地图核对，有出入的改用教材地图或标准地图，不在课件里自己改画。版图与领土的题照课标原文与教材讲（`references/geography-curriculum-map.md` 第一节、第三节的国家版图一段）。
- **实践类题**：实验题讲每一步的目的与安全要点（档位照 §三 ③）；调查题只用汇总结果，不出现受访者的个人信息（§三 ④）。
- **对题不对人**：不公开个人分数与排名；展示作答只用化名或老师誊写、改写的典型错解，投影原卷先遮住姓名、学号与分数，字迹同学认得出的改用老师誊写的，原卷和作答也不拍照发到群里；不当众点名批评，表扬进步也不公布名次与分数；课后记录不写个别学生的分数与错因（见 §八、§九）。
- **情绪与危机**：学生考后情绪低落时，课上照常对题不对人，不拿某个学生的卷子当反面例子；出现危机信号（如说不想活了），立即停止讲评设计，按文首危机例外处置——课上不评判、不公开讨论，尽快单独关注这个学生，立即联系学校心理老师与监护人（伤害可能来自家里的，不联系监护人，按 shared/crisis-exception.md"家庭安全类信号"一节报告）；讲评课放到这件事处置之后再排，这件事与学生的原话不写进教案。
- **写进教案**：planType 填"讲评"；lessonPlans 没有考试编号这一项，讲评哪场考试写进 topic；题号清单与题干留在给老师的教案正文里；segments 的分钟合计等于 periodMinutes；订正与巩固作业转作业设计师。

```text
讲评课（示例：periodMinutes = 45，讲评错题清单 4—6 道）
① 整体反馈       3 分钟   只说全班的共性：哪几类题失分多、哪里有进步；不报个人分数与排名
② 自查自纠       7 分钟   学生对照老师给的答案要点先自己订正，标出还不会的题
③ 共性题精讲     20 分钟   3—4 道：回到原图 → 关键信息 → 因果链 → 这类题的思路与常见错误
④ 当堂变式       10 分钟   每道精讲题配一道换区域或换图的同类题（任务卡一、二、三）
⑤ 小结与作业位     5 分钟   学生写"错在哪、为什么、下次怎么读图"；订正作业转作业设计师
合计 45 分钟
```

### 6.4 初中：学业水平考试与期末

- **目标与范围**：照 `references/geography-curriculum-map.md` 第一节写——四个核心素养、五个主题与选学规定；学业质量对照第二节的三组描述。区域复习照 §四 的选学规定，所学区域以所用教材为准，本 SKILL 不替教材选区域。
- **国家版图**：复习、讲评照课程地图第一节"国家版图"一段，按课标原文与教材讲，不增减、不改写。
- **学业水平考试**（各地也叫会考）：命题范围、题型与课标样题见课程地图第二节；样题（等高线地形图上的铁路线路，设问由读图到分析原因、再到方案选择）可以作复习课读图任务与讲评设问的参照。是否计入中考总分、考试形式与分值、有没有实践类考查，以本地当年的考试说明为准，本 SKILL 不新编考点与题型比例；会考的复习排期与考前练习转生地学业水平考试复习规划。
- **期末**：复习范围按本学期已经教过的主题与单元，由老师给；期末的复习排期转复习规划师。
- **课时与作业**：初中默认 45 分钟（`shared/grade-bands.md` 第三节），以 classProfile.periodMinutes 为准，6.2、6.3 的示例就是 45 分钟；复习、考后不额外加作业量，作业转作业设计师，全科作业总量由老师按学校统筹与"双减"的要求协调。

### 6.5 高中：合格考与等级考的复习与讲评

- **先问四件事**：哪场考试——合格考、等级考（各地也叫选考），还是校内的单元、期中、期末；本地当年的考试说明，没提供的地方标"待老师按本地考试说明确认"，不猜；这个教学班考哪一种——两类学生同班时要人数不要名单，班级工作区没有选科这一项，由老师说明，不从成绩或其他字段推断；新课教到哪。
- **课时**：高中不设默认，读 classProfile.periodMinutes（各地 40 或 45 分钟，`shared/grade-bands.md` 第三节），读不到先问，不按 45 分钟排；40 分钟时 6.2、6.3 示例的各环节按比例收，合计等于 40。
- **范围与深度**：照 §四 的层次①—③与 `references/geography-curriculum-map.md` 第四节——合格考只用必修地理 1、地理 2，难度主要依据学业质量水平 1；等级考加三个选择性必修模块，不超过水平 3，主观题分值占比高于客观题，讲评要讲清推理过程。两类学生同班时，合格考那一组的任务只用必修，选择性必修的内容不展开（`references/geography-hs-units-required.md` 第七节）。水平按地理课标写水平 1、2、3，只写在教案正文，不写进工作区，不跨学科换算。
- **复习课的锚点**：必修照 `references/geography-hs-units-required.md` 第四、五节末的"地理 1：复习与测评""地理 2：复习与测评"——用一份情境材料串几个单元，按水平 1 的结构良好情境出题（这是必修学完时面向全体学生的复习；等级考班或同班考等级考的一组复习必修内容时，按等级考的要求，难度主要依据水平 3、不超过水平 3）；选择性必修三个模块各留一次复习与测评，见 `references/geography-hs-units-elective.md` 第三节总表。复习任务可照该文件第七节问题式教学的八步搭（核心内容 → 真实问题 → 情境 → 目标 → 任务 → 问题链……），情境数据标出处。
- **专题复习举例**：大气专题可以用一次真实的天气过程（如一次冷空气过程），串起地理 1 的大气受热过程、热力环流，与选择性必修"自然地理基础"的锋、低压（气旋）、高压（反气旋）和简易天气图；天气图、云图用气象部门公开发布的原图并标出处，不编天气数据，不自绘含国界的底图。只考合格考的学生复习到必修的大气受热过程与热力环流为止，教材在必修讲得更深的，按教材与本地考试说明处理。
- **讲评**：主观题、实践报告可以用 `references/geography-hs-units-elective.md` 第八节的表现性评价量规讲（量规三档不等于学业质量三级水平）。赋分、等级、位次不是得分率，不拿来定讲评重点；不说谁"会过""不会过"，合格线由老师按本地考试说明给。
- **非纸笔测试**：合格考的上机、实验、野外考察、社会调查测试可能分几次、分批进行，全部批次、全部场次考完再讲评；没考完之前，平时的实践活动照常讲评，看方案设计与实施、工具与方法、数据收集与记录、结果整理与报告、参与与合作五个方面（`references/geography-hs-units-required.md` 第六节）。考前逐项练与排期转生地学业水平考试复习规划。
- **外出与实验**：复习、讲评涉及的野外考察、社会调查、地理实验与上机，组织与安全照 `references/geography-hs-practice-activities.md` 第五节：离校活动由学校组织、老师带队、结伴进行，访谈在公共场所、不入户，结果只做汇总。
- **轮次、联考与作业**：高三一轮、二轮的轮次与总进度由学校定，本 SKILL 只排其中一节或一个专题的几节；联考、一模、二模等参加的学校全部考完再讲；作业不内置分钟数，按本校晚自习与就寝时间协调，转作业设计师。

## 七、接口

数据契约唯一来源：`shared/class-teaching-workspace.schema.json`（根对象记作 `classWorkspace`）。

```text
读：
  classWorkspace.classProfile     → 学段 gradeBand、年级 gradeLevel、班额 classSize、每节课分钟数 periodMinutes、教材版本 textbookVersion，
                                     读图任务与实践活动的时长由这里决定
  classWorkspace.weaknessRank     → 本班的薄弱点（如等高线判读、区域比较），决定这一课的重点与提问密度
  classWorkspace.studentTiers     → A/B/C 分层，决定各环节的 tierVariants
  classWorkspace.interactionLogs  → 上一节课的实际用时（segmentTimings）、观察到的迷思
                                     （misconceptionsObserved）、下次调整建议（adjustmentForNext）
  classWorkspace.reviewPlans[].phases[]（name / daysToExam / newContentAllowed）
      → 复习课：本课在哪个复习阶段、能不能引入新知识点（排期本身不归本 SKILL）
  classWorkspace.reviewPlans[].spacingSchedule[]（knowledgePoint / reviewDates）
      → 复习课：这几天该回看哪些知识点
  classWorkspace.examBlueprints[]（examId / title）
  classWorkspace.examBlueprints[].items[]（itemNo / knowledgePoint）
      → 讲评课：哪场考试、题号对应哪个知识点
  classWorkspace.itemStats[]（examId / itemNo / pValue / flag）
      → 讲评课：各题得分率与异常标记（由学情分析师写入，本 SKILL 只读）

写（均生成待确认条目，老师确认后落库）：
  classWorkspace.lessonPlans[]    → planId / topic / date / periodMinutes /
                                     planType（新授课填"新授"，复习课填"复习"，讲评课填"讲评"，单元起始课、单元总结课照名填）/
                                     objectives（statement + cognitiveLevel + coreCompetency）/
                                     segments（含 minutes 与 tierVariants）/
                                     questionChain / boardPlan / sourceWeaknessIds
```

> 本 SKILL 不写考试蓝图 examBlueprints、不写逐题得分 itemScores、不写复习排期 reviewPlans（初中学业水平考试与高中合格性考试的复习排期在生地学业水平考试复习规划；高中等级性考试的复习排期在复习规划师）。

`objectives[].coreCompetency` 填四个核心素养之一：人地协调观、综合思维、区域认知、地理实践力。

## 八、字段级高敏信息防护

教案与课堂记录里只出现班级、化名或座号；不写学生真实姓名、联系方式、家庭住址与家庭情况。"认识家乡"只需要到县（区）一级，不收集学生的具体住址。老师贴进带真实姓名的名单时，提醒改用化名或座号（`SECURITY_BASELINE.md` 4.1）。

## 九、禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---|---|
| 每张图配一个读图任务 | 地图只作装饰 |
| 用教材地图或标准地图 | 自行绘制或修改国界与行政区划 |
| 人地关系两个方向都讲 | 只讲自然影响人，或只讲人破坏自然 |
| 社会调查只做汇总，不收集个人信息 | 让学生收集受访者的姓名、电话、住址 |
| 野外考察由学校组织、成人带领 | 布置学生自行外出考察 |
| 按 classProfile 的实际课时设计 | 写死某个版本教材的章节与课时 |
| 讲评用试卷原图、教材地图或标准地图 | 讲评时重绘或改画含国界的地图 |
| 讲评对题不对人，个别失误私下沟通 | 在课上公布个人分数或排名 |
