# 地理课程地图：初中五个主题与高中模块

> 适用学段：初中、高中。
> 本文是 `xiaozhi-teach-geography-lesson-planner` 的参考资源：初中的课程内容结构、选学规定、学业质量与学业水平考试；高中的课程结构、学业质量与考试；初高衔接点。本文只写课程标准层面的结构，不写死任何版本教材的章节与课时。
> 课程依据：《义务教育地理课程标准（2022 年版）》；《普通高中地理课程标准（2017 年版 2025 年修订）》。
> 内容边界：地图以教材和标准地图为准，课件与板图不绘制、不修改国界与行政区划；涉及国家版图与领土的表述，按课程标准原文与教材讲。

## 一、初中：课程内容结构

**核心素养**：人地协调观、综合思维、区域认知、地理实践力。

课程按"宇宙—地球—地表—世界—中国"的空间尺度组织，分认识全球、认识区域两大部分共五个主题，地理工具和地理实践贯穿其中：

| 部分 | 主题 | 内容 |
|---|---|---|
| 认识全球 | 主题一　地球的宇宙环境 | 地球在宇宙中；太空探索 |
| | 主题二　地球的运动 | 地球自转；地球公转 |
| | 主题三　地球的表层 | 自然环境（陆地和海洋、天气与气候）；人文环境（居民与文化、发展与合作） |
| 认识区域 | 主题四　认识世界 | 认识大洲；认识地区；认识国家 |
| | 主题五　认识中国 | 认识中国全貌；认识分区；认识家乡 |
| 贯穿 | 地理工具与地理实践 | 地球仪、地图（含数字地图）；地理实验、社会调查、野外考察 |

课标另设跨学科主题学习，以地理课程内容为主干，整合其他课程的知识和方法。

**选学规定**

- 认识世界：除南极和北极地区是必学区域外，至少选择一个大洲、三个地区和四个国家；所选"大洲—地区—国家"组合必须涉及所有大洲，并涵盖本主题全部内容要求。
- 认识中国：除北京、香港、澳门、台湾外，至少选择五个不同空间尺度或不同类型的区域；家乡范围一般指县一级行政区；从本主题内容要求中至少选择一条，以实践活动的方式展开教学。

**国家版图**：课标要求运用地图，描述中国的地理位置与疆域特征，说明南海诸岛是中国领土的组成部分，钓鱼岛及其附属岛屿是中国固有领土，增强国家版图意识与海洋权益意识；说明台湾的自然地理、历史文化传统和经济建设特点，认识台湾自古以来就是中国不可分割的领土，以及促进海峡两岸经济社会融合发展的意义。教案中的这部分内容按课标原文与教材讲，不增减、不改写。

## 二、初中：学业质量与学业水平考试

**学业质量**按学习内容分三组描述：地球的宇宙环境与地球的运动；地球的表层；认识世界与认识中国。每组都写明对应的核心素养表现，教学目标可以对照着写。

**学业水平考试**（课标"课程实施"部分）：

- 目的：检测学生在义务教育阶段的学业成就，同时为高一级学校招生提供重要依据
- 命题范围：地球所处的宇宙环境，地球的自转和公转运动，地球表层的自然和人文环境，世界的大洲、地区和国家，中国的整体面貌、不同分区及家乡
- 题型如单项选择题、简答题、综合题等；试题要阅读、获取、解读图示信息，一些试题涉及地图等地理工具的运用
- 课标附有一道以测评核心素养为目标的样题：以等高线地形图上的铁路线路为情境，设问由读图到分析原因、再到方案选择与开放讨论，可作为设计课堂任务的参照

各地是否计入中考总分、考试形式与分值，以本地当年的考试说明为准。

## 三、高中：课程结构

| 类别 | 模块 | 学分 |
|---|---|---|
| 必修 | 地理 1（地球科学基础、自然地理实践、自然环境与人类活动的关系）；地理 2（人口、城镇和乡村、产业区位选择、环境与发展） | 各 2 学分，共 4 学分 |
| 选择性必修 | 自然地理基础；区域发展；资源、环境与国家安全 | 各 2 学分，共 6 学分；选择修习地理课程的学生须全部修满 |
| 选修 | 天文学基础、海洋地理、自然灾害与防治、环境保护、旅游地理、城乡规划、政治地理、地理信息技术应用、地理野外实习 | 校本课程，由学校开设 |

**核心素养**：人地协调观、综合思维、区域认知、地理实践力（与初中同名，要求逐级提高）。

## 四、高中：学业质量与学业水平考试

**学业质量分三级水平**：水平 1 是高中学生毕业应当达到的要求，也是合格等级的划定依据；等级性考试不超过水平 3。

| | 合格性考试 | 等级性考试 |
|---|---|---|
| 范围 | 必修课程；地理 1 与地理 2 的内容比例大体一致，地理实践活动需占一定比例 | 必修课程与三个选择性必修模块，内容比例均衡 |
| 形式 | 一般采用纸笔测试与地理实践活动相结合；非纸笔测试包括上机测试、实验测试、地理野外考察测试、社会调查测试等 | 纸笔测试 |
| 题型 | 以单项选择题为主，且有一定比例的主观题 | 主观题分值占比高于客观题 |
| 难度 | 主要依据学业质量水平 1，重点关注临界合格水平的学生 | 主要依据学业质量水平 3 |

纸笔考试的客观题一般有单项选择题、多项选择题等，主观题一般有简答题、填图作图题、论述题等。具体的考试安排以本地当年的考试说明为准。

## 五、初高衔接

| 方面 | 初中 | 高中 |
|---|---|---|
| 地球运动 | 自转、公转的方向与周期，产生的主要自然现象及对生产生活的影响 | 选择性必修 1：地球运动的地理意义（昼夜长短与正午太阳高度的变化、时区与区时） |
| 大气 | 天气与气候，气温与降水的分布，纬度位置、海陆分布、地形对气候的影响 | 地理 1：大气的组成与垂直分层、大气受热过程与热力环流；选择性必修 1：气压带与风带、常见天气系统 |
| 区域 | 认识大洲、地区、国家与中国的分区：归纳区域特征、比较区域差异 | 选择性必修 2：区域发展与区域协调，因地制宜 |
| 人文 | 人口、城乡、文化、发展与合作：以描述为主 | 地理 2：人口、城镇和乡村、产业区位选择、环境与发展：以解释和区位分析为主 |
| 地理工具 | 地球仪、地图、数字地图 | 地理信息技术的应用（地理 1 内容要求 1.12、地理 2 内容要求 2.11） |

高一第一节课可以拿一张初中学过的气温曲线与降水量柱状图，先请学生用初中的方法读出气候特征，再追问"为什么是这样"，引出高中大气受热过程与大气运动的学习。
