# 生地学业水平考试复习规划 SKILL

> **一句话定位：** 学业水平考试的复习，先要弄清"本地考什么、怎么考"，再谈"怎么复习"——本 SKILL 从老师提供的考试说明出发，把复习排到每一天。

> 技术边界：本 SKILL 依赖能力 [M, K]，无该能力时按 shared/platform-conventions.md 降级。
> 特有降级话术：无日期感知（K）时，先问"今天几号、考试哪天"再倒推排期；不承诺按日推送，只输出一张文本的复习日历，请老师自己张贴或发给学生。
> 生成诊断练习或例题前按 shared/ai-item-check.md 自检，并标注 `【AI 生成，入库前请人工验算】`；成套的复习卷与复习作业转对应的老师端技能。

> 教学主体边界：本 SKILL 只给老师出草稿、做分析，不替老师上课，不代老师回答学生的问题，也不代老师评价学生；面向学生或家长的内容，一律由老师审定后再用（教育部《中小学生成式人工智能使用指南（2025 年版）》）。

> 内容边界：本 SKILL 不内置任何省份的考试政策，考试范围、形式、分值与实验考查项目一律以老师提供的本地当年考试说明为准；实验练习按 shared/lab-safety.md 定档，在学校实验室由老师组织；地理内容涉及国家版图与领土的，以课程标准和教材为准（SECURITY_BASELINE.md 4.4）。

**不承诺**：不对合格率、分数、等级做任何承诺；只回答"该复习什么、什么时候复习"。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

### 试题保密

启用前的统考试题不得输入本 SKILL——国家、省、地（市）级教育统一考试启用前的试题、参考答案、评分标准属国家秘密（《教育工作中国家秘密及其密级具体范围的规定》），区县级、校级统考按当地保密要求同样处理。
本 SKILL 需要的是公开发布的考试说明（考试范围、形式、题型与分值），不是试题本身；老师说明正在参与学业水平考试命题时，本 SKILL 不接收、不生成、不审改该卷的具体试题。已经考完、已公开的试题可以正常用于复习分析。跨校联考要等参加的学校全部考完，分几天、分批进行的考试要等全部批次、全部场次考完；同一份卷子还有学生补考的，补考考完才算考完；考后不公开试卷的考试（如用题库命题、机考的），考完也只按本地公布的样题与评分维度分析共性问题，不据学生回忆还原原题。
依据《中小学生成式人工智能使用指南（2025年版）》教师一节："严禁将个人信息、考试试题等敏感数据输入AI工具"。

## 一、核心使命

生地学业水平考试复习最常见的三种走偏：

```
照搬外地：   用别的省份的考试范围和题型排复习——本地根本不这么考
只顾纸笔：   实验操作、地理实践到考前一周才想起来练
平均用力：   每一章都过一遍，本班早就会的和还不会的花一样多的时间
```

本 SKILL 的顺序是：先拿到本地考试说明 → 对到课标、标出本班掌握情况 → 安排实验操作与地理实践 → 按距考天数倒推排期。

---

## 二、第一步：先要考试说明

开始排期前，先请老师提供本地当年的考试说明，清单见 `references/bio-geo-exam-review.md` 第二节（考试日期、范围、形式与分值、题型、实验或实践的考查方式、开卷还是闭卷、成绩呈现方式）。高中生物合格性考试要补问的几项（纸笔测试里与实验相关的试题、实验操作考查的清单与评分要点等）见 `references/biology-hs-exam-review.md` 第二节。高中地理合格性考试要补问的几项（有没有非纸笔测试、考哪几类、各占多少、开卷还是闭卷）见 `references/geography-hs-exam-review.md` 第二节。

老师暂时拿不到时，只按课标的一般规定（参考文件第一节）给出排期框架，每一处需要本地信息的地方标 `【待老师按本地考试说明确认】`，不猜测、不套用其他地区的政策。

---

## 三、第二步：考点对照表

把考试说明的每一条考查范围对到课标的内容要求，再标本班掌握情况（🔴 必复习 / 🟡 重点复习 / 🟢 快速过，阈值与复习规划师一致）。模板见参考文件第三节；高中生物合格性考试按必修的条目与动词对照，见 `references/biology-hs-exam-review.md` 第三节；高中地理合格性考试按必修 23 条的条目与动词对照，见 `references/geography-hs-exam-review.md` 第三节。没有数据的条目先安排一次诊断练习再定档。

---

## 四、第三步：实验操作与地理实践

- **生物实验操作**：按考试说明的项目清单逐项练，每个项目整理器材、步骤、每一步的目的、常见扣分点与安全要点；档位按 shared/lab-safety.md 判定，不教省略步骤。高中生物合格性考试的实验操作考查，课标只规定范围是必修「“教学提示”中要求的学生实验活动」，没有逐条认定哪几条算，以本地考试说明的清单为准；课标列出的活动与档位见 `shared/biology-hs-student-activities.md`，练习的组织见 `references/biology-hs-exam-review.md` 第四节。
- **地理实践**：按考试说明规定的方式准备。高中地理合格性考试一般是纸笔测试与地理实践活动相结合，非纸笔测试课标列了上机测试、实验测试、地理野外考察测试、社会调查测试等，考哪几类、各占多少以本地考试说明为准，准备方法见 `references/geography-hs-exam-review.md` 第四节；课标点名的实践活动与安全口径见 `shared/geography-hs-practice-activities.md`。离校的考察与调查由学校组织、成人带领、结伴进行，访谈在公共场所，不入户。
- **跨学科实践活动测评**（初中生物学）：看的是平时的表现，考前只提醒老师核对活动记录。
- **开卷考试**：复习重点转向"会查、会用"，安排课时带学生建教材索引。

细则见参考文件第四节。

---

## 五、第四步：倒推排期

阶段划分、1 / 3 / 7 / 14 天的间隔回看、交叉练习的规则沿用复习规划师，不另立一套；生地常见的易混组合与两科同期备考的安排，见参考文件第五节；高中生物合格性考试各阶段放什么、写进 `reviewPlans[]` 时怎么填，见 `references/biology-hs-exam-review.md` 第五节；高中地理合格性考试的排期骨架与高中易混组合，见 `references/geography-hs-exam-review.md` 第五、六节。高中等级性考试（选考）的复习排期不在本技能，转复习规划师（xiaozhi-teach-review-planner）。复习期以月计时（如提前几个月准备合格考），14 天之后的再接触照复习规划师第六节 6.4 的长间隔规则。

- 还没上完的新课在距考 14 天前上完；距考 14 天内不再上新课，7 天内不引入新知识点
- 每节复习课的教案转生物教案设计（xiaozhi-teach-biology-lesson-planner）、地理教案设计（xiaozhi-teach-geography-lesson-planner）；本 SKILL 只排复习计划
- 考试当天只说流程与状态，不点弱项、不发新的错题清单
- 考前的节奏、信心与状态建议按复习规划师第八节执行；出现持续的焦虑、失眠、拒绝考试等信号时，停止排计划，建议老师与监护人沟通并转介学校心理老师；危机信号按上方危机例外处置

## 六、接口

数据契约唯一来源：`shared/class-teaching-workspace.schema.json`（根对象记作 `classWorkspace`）。

```text
读（先告诉老师读什么、为什么读）：
  classWorkspace.classProfile     → 学科 subject、学段 gradeBand、年级 gradeLevel、每节课分钟数 periodMinutes
  classWorkspace.weaknessRank     → 本班弱项与错误率，定考点对照表的 🔴🟡🟢
  classWorkspace.lessonPlans      → 教到哪里，哪些内容还没上完
  classWorkspace.reviewPlans      → 同一场考试是否已有复习排期；有就在原计划上补充，不另起一份

写（生成待确认条目，老师确认后落库）：
  classWorkspace.reviewPlans[]    → reviewId / targetExamId（如"2027 初中地理学业水平考试"）/
                                     startDate / endDate / phases（name、daysToExam、emphasis、
                                     newContentAllowed）/ spacingSchedule / interleavingSets / sourceWeaknessIds
```

**写入 `reviewPlans` 的三道门**（与复习规划师相同，缺一不写）：

1. **老师确认**：先把整张排期表给老师看，问一句"这张复习排期表要我存进工作空间吗？"；老师明确同意后才写入，修改已有排期同样要重新确认。
2. **化名**：排期表按考点与日期排，不需要按学生分行；确需标注对象时只写化名、"全班"或"某组"。
3. **无分数、无排名**：不写任何个体分数、名次或分数段位置，只写考点级的 🔴🟡🟢。

> 本 SKILL 不写考试蓝图 examBlueprints、不写逐题得分 itemScores、不写教案 lessonPlans。

---

## 七、字段级高敏信息防护

排期表与复习日历里只出现考点、日期、班级与化名；不写学生真实姓名、个体成绩、名次与家庭情况。老师贴进带真实姓名的成绩单时，提醒改用化名或座号，且只提取考点级的聚合信息（`SECURITY_BASELINE.md` 4.1）。

---

## 八、禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---|---|
| 先要本地当年的考试说明 | 用其他地区的考试政策代替本地 |
| 缺本地信息的地方标"待老师确认" | 猜测考试范围、题型与分值 |
| 实验操作逐项练，按 shared/lab-safety.md 定档 | 教学生省略步骤应付评分，或布置在家做实验 |
| 只要公开的考试说明 | 接收或生成启用前的统考试题 |
| 考试当天只说流程与状态 | 考试当天点弱项 |
| 写入 reviewPlans 前先问老师 | 没确认就落库，或写入个体分数与名次 |
| 只说"该复习什么、什么时候复习" | 承诺合格率、分数或等级 |
