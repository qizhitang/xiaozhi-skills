# 作文批改标准：等级描述式（一至四类文）+ 三维观察 15 项

> 适用学段：小学高段 / 初中。
> 配合 `xiaozhi-teach-chinese-writing-guide` §6 使用。**本文件是本 SKILL 作文批改标准的唯一出处**，
> 三维 15 项细则也只在这里定义一份，别处不再另列。

## 0. 这份标准怎么用（两件事，别混）

```text
【定档】用第 1-2 节的"一至四类文 × 中考四项"给一篇作文定一个等级。
        四项＝内容 / 结构 / 语言 / 书写，与各地中考作文评分表一致。
        本文件**不给分数细目**——各地满分不同（40/50/60 分都有），
        定档之后按第 3 节的换算带落到本校本地的分值。

【诊断】用第 4 节的"三维观察 15 项"说清楚"问题具体在哪、下一步改什么"。
        三维＝结构 / 语言 / 思维，是讲评和面批用的观察镜，**不是**评分表，
        不逐项打分、不加总。

一句话：定档看四项等级，讲评看三维 15 项。
```

> 与学生端的关系：学生端 `xiaozhi-chinese-writing-coach` 用的是"论点/论据/语言**三要素**批改"，
> 面向单篇自我修改；本文件的"三维观察"是老师端班级教学用的另一套镜头。名称不同，不要互相套用。

## 1. 等级总表（一至四类文）

```text
┌────────┬──────────────────────────────────────────────────────────┐
│ 等级    │ 总体印象                                                  │
├────────┼──────────────────────────────────────────────────────────┤
│ 一类文  │ 切合题意，中心明确且有自己的思考；材料真实具体、有说服力；    │
│        │ 结构完整、层次分明、详略得当；语言准确流畅、有表现力；        │
│        │ 书写规范美观，标点正确，几乎无错别字。                      │
├────────┼──────────────────────────────────────────────────────────┤
│ 二类文  │ 符合题意，中心明确；材料较具体；结构完整、条理清楚；          │
│        │ 语言通顺，偶有不当；书写工整，错别字与标点问题很少。          │
├────────┼──────────────────────────────────────────────────────────┤
│ 三类文  │ 基本符合题意，中心尚明确但较浅；材料一般或较空泛；            │
│        │ 结构基本完整但层次不清或详略失当；语言基本通顺，有语病；      │
│        │ 书写尚清楚，有一定数量的错别字或标点错误。                  │
├────────┼──────────────────────────────────────────────────────────┤
│ 四类文  │ 偏离题意或中心不明；材料贫乏或与主题脱节；结构残缺、条理混乱；│
│        │ 语病较多、表达不清；书写潦草难辨或错别字很多。               │
│        │ （另：未完篇、明显抄袭套作、字数严重不足，按本地规定单独处理） │
└────────┴──────────────────────────────────────────────────────────┘
```

**定档原则：**

```text
① 先看内容（是否切题、中心是否明确）——内容定基调，其他三项做微调。
② 四项等级不一致时，取"内容"所在等级为基准，其余三项每有一项低两档，降半档。
③ 拿不准就往中间靠：多数作文是二类文与三类文，一类与四类都应是少数。
④ 只凭"字写得漂亮"不能升到一类；只凭"字丑"也不能压到四类——书写只占四项之一。
```

## 2. 四项分档描述（中考口径）

### 2.1 内容（切题 / 中心 / 选材 / 思想）

| 等级 | 描述 |
|------|------|
| 一类 | 切合题意；中心明确且有个人思考，不停在人所共知的道理；选材真实、具体、典型，能支撑中心 |
| 二类 | 符合题意；中心明确；选材真实，较具体，基本能支撑中心 |
| 三类 | 基本符合题意；中心尚明确但停留在表层；选材一般、较空泛或与中心结合不紧 |
| 四类 | 偏离题意或中心不明；选材贫乏、虚假或与主题脱节 |

### 2.2 结构（完整 / 层次 / 详略 / 照应）

| 等级 | 描述 |
|------|------|
| 一类 | 结构完整；层次分明，思路清晰；重点部分展开充分、次要部分点到即止；首尾照应自然 |
| 二类 | 结构完整；条理清楚；详略基本得当；过渡尚自然 |
| 三类 | 结构基本完整；层次不够清楚，或详略失当（该详的略、该略的详）；过渡生硬 |
| 四类 | 结构残缺（无头无尾、中途中断）；条理混乱，读不出思路 |

> 不以段数定档。写成三段还是七段都可以，看的是层次是否分明、详略是否服务于中心。

### 2.3 语言（准确 / 通顺 / 得体 / 表现力）

| 等级 | 描述 |
|------|------|
| 一类 | 语言准确流畅，有表现力；句式有变化；修辞用得恰当而不堆砌；基本无语病 |
| 二类 | 语言通顺；用词基本准确；偶有不当或不够精炼 |
| 三类 | 语言基本通顺；用词单调或不够准确；有若干语病 |
| 四类 | 语病较多，表达不清，影响理解 |

> 不数修辞、不数"高级词"。堆了五个比喻但不贴切，低于一处贴切的比喻。

### 2.4 书写（卷面 / 字迹 / 标点 / 错别字）

| 等级 | 描述 |
|------|------|
| 一类 | 卷面整洁，字迹规范美观；标点正确；几乎无错别字 |
| 二类 | 卷面整洁，字迹工整；标点基本正确；错别字很少 |
| 三类 | 卷面尚可，字迹清楚；标点有错（如通篇一逗到底）；有一定数量的错别字 |
| 四类 | 卷面涂改多或字迹潦草难辨；标点混乱；错别字很多 |

> 错别字扣分按**本地评分细则**执行（各地规则不同：有的每字扣、有的重复不计、有的设扣分上限）。
> 本文件不规定扣几分，老师按学校/统考的规定填在第 3 节的换算带里。

## 3. 本地满分换算带（老师填一次，长期沿用）

```text

字数不足的处理：____________________________

┌────────┬──────────────────┬──────────────────┐
│ 等级    │ 建议分数区间       │ 本校实际区间       │
├────────┼──────────────────┼──────────────────┤
│ 一类文  │ 满分的 85% 及以上  │ ______ ~ ______  │
│ 二类文  │ 满分的 70% ~ 85%  │ ______ ~ ______  │
│ 三类文  │ 满分的 55% ~ 70%  │ ______ ~ ______  │

      同一次作文，全班用同一条换算带，中途不改。
```

## 4. 三维观察 15 项（讲评与面批用，不打分）

> 用途：定档之后，从这 15 项里挑 **1-2 项**作为这篇作文的"下一步"，写进批语。
> 每项只回答"做到了 / 部分做到 / 没做到"，**不打分、不加总**。

### 4.1 结构维（5 项）

```text
① 标题扣题     标题与内容一致，不偏、不模糊；半命题补得准
② 开篇入题     不照抄题目、不绕远，尽早进入具体场景或观点
③ 段落层次     一段一个核心意思；段与段之间读得出推进关系
④ 详略与过渡   最能体现中心的部分写得最充分；段间衔接不突兀
⑤ 结尾收束     不草率、不硬升华；能回扣中心或留有余味
```

### 4.2 语言维（5 项）

```text
① 用词准确     每个词都在做事，不堆砌华丽辞藻
② 句式变化     长短句结合，不通篇一种句式
③ 表达具体     不写"很开心""风景很美"，写出让人看见的具体表现
④ 修辞恰当     修辞服务于表达，不是为了凑数
⑤ 通顺无错字   无明显语病与错别字（语病类型判定见学生端语病追踪档案的六类口径）
```

### 4.3 思维维（5 项）

```text
① 立意明确     全文围绕一个中心，不散
② 思想深度     不止于人所共知的道理，有自己的想法
③ 选材典型     材料真实且能支撑中心，不是万能素材
④ 真实感受     写的是自己的经验与感受，不是套话
⑤ 独到视角     有个人观察角度，读完能记住这一篇
```

## 5. 批改样板：记叙文《那一刻，我长大了》

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 作文批改 · 学员化名：小龙（初二）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 题目：《那一刻，我长大了》

【四项等级】
  内容：二类  切题，中心是"学会照顾妹妹"，明确但停在表层
  结构：二类  五段完整，层次清楚；第 3 段过长挤掉了结尾
  语言：二类  通顺，用词基本准确；有 1 处比喻用得好
  书写：一类  卷面整洁，无错别字，标点正确

【定档】二类文（以"内容"为基准，其余三项无低两档者，不降档）
【分数】按本校 50 分制的二类区间给：______ 分

【三维观察 · 本次只点两项】
  ✗ 结构④ 详略与过渡：第 3 段（做饭）比第 5 段（那一刻的感受）长一倍，
    但"长大"发生在第 5 段。详略和中心反了。
  ✗ 思维② 思想深度：结尾"我长大了"是结论，不是发现。
    你在哪一个具体瞬间意识到自己变了？把那一秒写出来。

【下一步（只做一件事）】
  把第 5 段扩开：那一刻你在做什么、听见什么、心里第一个念头是什么。
  第 3 段可以砍掉一半。

■ 一句话
  你的材料是真的，这最难；现在缺的只是把镜头对准最要紧的那一秒。
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 6. 老师批语三段式

```text
┌────────────────────────────────────────┐
│ 第一段：指出本次一个真实的优点（要具体到句） │
│ 第二段：指出 1-2 项三维观察中的短板         │
│ 第三段：给一个可操作的"下一步"，只给一件事   │
└────────────────────────────────────────┘

反对：写"结构清晰，语言流畅，继续努力"这类放在谁身上都成立的批语。
```

> 💡 **小智提醒：** 定档是为了给学员一个位置感，批语是为了给学员一个方向。
> 位置可以是二类，方向必须是具体的一件事。
