# 学员写作风格长期记录模板

> 适用学段：小学高段 / 初中。
> 配合 `xiaozhi-teach-chinese-writing-guide` §7 使用。跟踪学员写作风格 6 维度的演变。
> 本文件只记"风格"，不记等级与分数——等级批改见 `three-dim-rubric.md`。
> 风格判断需要证据：单篇观察标 🔴 样本不足，不写入档案（词表见 shared/vocab.md §7）。

## 1. 写作风格 6 维度

```text
┌──────────┬──────────────────┬──────────────┐
│ 维度      │ 含义              │ 追踪粒度      │
├──────────┼──────────────────┼──────────────┤
│ 词汇      │ 用词偏好与变化    │ 高频词 + 高级词│
│ 句式      │ 句子长度与结构    │ 长短比 + 从句  │
│ 修辞      │ 修辞手法偏好      │ 比喻/排比/拟人│
│ 情感      │ 情感表达倾向      │ 浓烈/克制/平实│
│ 思维      │ 立意与思考深度    │ 思辨/联想/感悟│
│ 结构      │ 篇章组织模式      │ 总分/时间/空间│
└──────────┴──────────────────┴──────────────┘
```

```text

## 3. 风格演变的三个阶段

> 阶段按**积累的作文篇数与观察证据**划分，不按月份——写得多的学员三个月就能到形成期，
> 一学期只写四篇的学员一年也未必到。不要用时间给学员贴阶段。

```text
【阶段 1：萌芽期】 判据：档案内 1-5 篇，风格特征尚不稳定
  · 特征：明显模仿范文，结构较固定
  · 下一步：从"会写一件事"到"会写一类事"

【阶段 2：形成期】 判据：档案内 6-15 篇，某些偏好在 3 篇以上重复出现
  · 特征：开始有自己的偏好，但换文体就不稳
  · 下一步：偏好逐渐清晰，出现可辨认的"个人标签"

【阶段 3：稳定期】 判据：档案内 15 篇以上，跨文体仍能看出同一个人的痕迹
  · 特征：风格成熟，能按题材调整而不失自己
  · 下一步：能根据题材/读者主动切换写法

（以上篇数为经验值，老师可按班级实际调整；关键是"有几篇证据"，不是"过了几个月"。）

## 5. 风格 DNA 应用场景

```text
场景 ① 批改时
  → 比对风格档案，针对短板维度给出建议

场景 ② 讲评时
  → 展示学员"风格演变时间线"，肯定进步

场景 ③ 推荐范文时
  → 推荐与该学员风格相近的范文（避免学不像）

场景 ④ 阶段小结时
  → 用风格档案呈现学员成长；给家长看之前先核对 parentSharingConsent
```

## 6. 学员化名示例档案

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 学员档案示例：A-007（初二·小龙）
━━━━━━━━━━━━━━━━━━━━━━━━━━━

【词汇指纹】
  · 高频词：突然、那一刻、忽然、猛地、渐渐地
  · 高级词：倏地、骤然、怔住、恍惚、若有所失
  · 趋势：词汇越来越丰富

【句式指纹】
  · 短句 30% / 中句 50% / 长句 20%
  · 标志性句式：长短句交替 + 排比收束

【修辞指纹】
  · 比喻 + 拟人为主，少用排比
  · 标志性修辞：把"风"比作"急促的脚步"

【情感指纹】
  · 浓度：含蓄克制
  · 主旋律：温暖 + 略带孤独
  · 盲点：很少写愤怒/冲突场景

【思维指纹】
  · 立意：从中层向深层发展
  · 联想：适度，能由物及人

【结构指纹】
  · 偏好：时间顺序（70%）+ 总分总（30%）
  · 段数：5 段为主

【风格成熟度】
  · 当前：形成期（依据：档案内 9 篇，长短句交替与"由物及人"的联想各出现 3 次以上）
  · 置信度：🟢 数据充分
  · 下一阶段目标：稳定期
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
