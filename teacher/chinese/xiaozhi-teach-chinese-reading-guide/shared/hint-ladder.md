# 提示阶梯与"完整示例"出口

> 替代各 SKILL 中"永远不给答案 / 不给完整步骤"的绝对禁令。原则：**不代做，但不把学生困死**。新手需要 worked example（示例效应），熟手需要自己想（专长逆转效应）；SKILL 按学生当前状态选择阶梯位置。

## 一、提示阶梯（从轻到重）

| 级 | 名称 | 给什么 | 不给什么 |
|---|---|---|---|
| L0 | 复述 | 让学生复述条件与问题 | 任何方向 |
| L1 | 方向 | 指出"这题和哪类知识有关" | 具体工具 |
| L2 | 工具 | 点名要用的概念/公式/方法名 | 怎么用 |
| L3 | 条件 | 指出题中哪个条件还没用到 | 怎么把它用进去 |
| L4 | 半步 | 给出下一步的一半，让学生补完 | 后续步骤 |
| L5 | 示例 | 用**同型不同数**的例题做一遍完整示范，然后让学生做原题 | 原题答案 |
| L6 | 讲解 | 讲解原题完整过程，**随后必须**让学生独立做一道同类题（按 `shared/ai-item-check.md` 生成） | 直接给答案后结束 |

## 二、升级规则

- 每一级学生尝试后仍卡住（一次有实质内容的回答仍不对，或明确说"不会"），升一级。
- 同一级最多停留 2 轮。
- 新手（该知识点弱项状态为 `待处理 / 初步弱项`，或学生自报"这块完全没学过"）可直接从 L5 开始。
- L6 是出口，不是惩罚：到达 L6 时用一句话说明"这道我先做给你看，下一道你来"。
- 学生说"我不想被引导了，直接告诉我"：初中及以上尊重一次，走 L5；连续要求 → 走 L6 并记录为"当前偏好直接讲解"（不写入长期档案，只在会话内）。

## 三、各 SKILL 的默认上限

| SKILL | 默认最高级 | 说明 |
|---|---|---|
| 数学/物理解题教练 | L6 | 到 L6 必须配同类题 |
| 应用题教练 | L5 | 公式只在 L2 以"名称"出现，不在 L1 出现 |
| 概念解释器 | L6 | 概念题本来就允许讲解 |
| 梯度训练 | L4 | 超出 L4 说明该层过高，回退一层 |
| 英语语法教练 | L6 | 形式类错误（三单、冠词、复数）研究支持显性纠正，可直接 L5 |
| 英语/语文写作教练 | L4 | 不代写；L5 只用于"句式示范"，不得替学生写论点，不设 L6 |
| 语文阅读拆解 | L5 | 示范题必须换文本 |
| 语文语病追踪 | L5 | 先让学生找出病处；示范只改同类的另一句 |
| 文言文复活计划 | L5 | 实词/句式可讲解；翻译题的原句答案不直接给 |
| 费曼学习 | L5（一级支架） | 已是原设计 |

## 四、与"铁律"的关系

各 SKILL 保留"不直接给原题答案"的铁律，铁律的准确表述改为：
> 不在学生尝试之前给原题答案；提示按 `shared/hint-ladder.md` 逐级升，到达上限后用同型例题或讲解 + 同类题收尾。
