# 文言文教学指导 SKILL

> **一句话定位：** 文言文不是"古人的语文"，而是"中国文化的活化石"——教学要让它在现代学员心里"活"起来。

---

> 技术边界：本 SKILL 依赖能力 [M, V, F]，无该能力时按 shared/platform-conventions.md 降级。
> 无语音合成（V）时不做示范朗读，节奏只能用文字标注（"关关/雎鸠"）；无文件能力（F）时档案表格改为对话内纯文本。

**本 SKILL 的内容边界（不是平台能力问题，是产品定位）：**
- 古文原文属公有领域；**教材版本的注释、翻译、助读设计仍受版权保护**，不复制。所有引用标注 `copyrightStatus`：`自有` / `改编` / `公开可引用` / `仅存索引`（教辅原题与历年真题一律 `仅存索引`）。
- 只输出**串讲框架**与主题解析，不逐字逐句串讲整篇古文（由老师主导）。
- 不提供完整现代汉语翻译，只输出关键句段的翻译框架。

### 隐私与数据控制入口

## 一、核心使命

文言文教学常见的三个误区：

```text
误区① 串讲=翻译：老师把古文"翻译"成现代汉语，
        学员被动接受，没有和古文直接接触。

误区② 训诂=死记：要求学员死记硬背实词虚词，
        没有语境、没有应用。

误区③ 主题=贴标签：把古文主题归结为几个标签
        （思乡/爱国/山水），学员记不住、感受不到。
```

本 SKILL 要解决的是：
- **让古文"可诵读"**：通过节奏、韵律让古文"动"起来
- **让训诂"语境化"**：实词虚词在语境中理解
- **让主题"有共鸣"**：与现代学员生活连接
- **让文化"可累积"**：每篇古文成为学员文化 DNA 的一部分

## 四、诵读正音

### 4.1 诵读三阶

```text
┌──────────┬────────────────────────┬────────────┬──────────────┐
│ 阶       │ 描述                    │ 重点        │ 学员任务      │
├──────────┼────────────────────────┼────────────┼──────────────┤
│ 正音      │ 读准字音                 │ 字音/多音  │ 跟读 3 遍     │
│ 断句      │ 读对节奏                 │ 句读/停顿  │ 划节奏 1 遍   │
│ 情感      │ 读出意味                 │ 轻重/缓急  │ 试读 2 遍     │
└──────────┴────────────────────────┴────────────┴──────────────┘
```

### 4.2 断句 5 法

```text
① 句末虚词
  · 也、矣、乎、哉、焉、耳
  · 多为语气词，可停顿

② 对称结构
  · "山高 / 水长" "天时 / 地利"
  · 对称处可断

③ 顶真修辞
  · "A...A..." 顶真处可断

④ 重复结构
  · "X 则 X" "X 不 X"
  · 重复处可断

⑤ 标点参考
  · 句号/逗号处必断
```

### 4.3 节奏 3 类

```text
· 四言诗：2+2 节奏（如"关关/雎鸠"）
· 五言诗：2+3 节奏（可细分 2+2+1 或 2+1+2，如"床前/明月光"）
· 七言诗：2+2+3 节奏（也可 4+3，如"两个/黄鹂/鸣翠柳"）

古文：按"意群"断，无固定节奏
```

### 4.4 诵读教学法

```text
■ 老师范读
  · 1 遍正音
  · 1 遍断句
  · 1 遍带情感

■ 学员跟读
  · 先无声（看）
  · 后有声（读）
  · 最后有情（演）

■ 配乐诵读
  · 选古风/民乐
  · 让学员"沉浸"

■ 角色诵读
  · 叙事古文：角色扮演
  · 诗歌：分角色
```

## 五、训诂（字词句式）

### 5.1 训诂三阶

```text
┌──────────┬────────────────────────┬────────────┐
│ 阶       │ 描述                    │ 重点        │
├──────────┼────────────────────────┼────────────┤
│ 字词      │ 单字/词的含义           │ 常用义/语境义│
│ 句式      │ 古文句式特点            │ 倒装/省略/判断│
│ 语法      │ 词类活用/虚词          │ 活用/虚词   │
└──────────┴────────────────────────┴────────────┘
```

### 5.2 实词训诂 4 法

```text
① 字形推断
  · 形声字："江"从水，工声
  · 形旁表意

② 组词推断
  · 学=学习/学生
  · 联系现代汉语

③ 语境推断
  · "学而时习之"
  · "学"=学习（语境）

④ 联想推断
  · 联系同主题/同作者
  · 推断通用义
```

### 5.3 课堂高频虚词 7 个

> 这 7 个是课堂讲解的最小集；完整 20 个虚词速查见 `references/classical-vocab-quick-ref.md` §2，
> 教研时用完整表，课堂上先讲这 7 个。

```text
┌──────────┬────────────────────────┬──────────────┐
│ 虚词      │ 常见义                   │ 例子         │
├──────────┼────────────────────────┼──────────────┤
│ 之        │ 助词/代词/动词           │ 学而时习之   │
│ 者        │ 代词/语气词              │ 仁者爱人     │
│ 也        │ 句末语气词               │ 孔子曰...... │
│ 矣        │ 句末语气词（了）         │ 可行矣       │
│ 乎        │ 句末语气词/介词           │ 不亦说乎     │
│ 哉        │ 句末语气词（感叹）       │ 何其...哉   │
│ 焉        │ 句末语气词/代词          │ 忽焉在...   │
└──────────┴────────────────────────┴──────────────┘
```

### 5.4 词类活用 6 类（例句均取自部编初中篇目）

```text
① 名词作动词
  · "一狼洞其中"（洞＝挖洞）——《狼》七上
  · 名词处在谓语位置或后面带宾语时，活用为动词

② 名词作状语
  · "其一犬坐于前"（犬＝像狗一样）——《狼》七上
  · 名词直接修饰动词，作状语

③ 形容词作动词
  · "亲贤臣，远小人"（亲＝亲近，远＝疏远）——《出师表》九下
  · 形容词带宾语，表动作

④ 动词作名词
  · "猛浪若奔"（奔＝飞奔的马）——《与朱元思书》八上
  · 动词临时表示与该动作相关的人或事物

⑤ 使动用法
  · "无案牍之劳形"（劳＝使……劳累）——《陋室铭》七下
  · 主语使宾语怎么样

⑥ 意动用法
  · "渔人甚异之"（异＝以……为奇怪）——《桃花源记》八下
  · 主语认为宾语怎么样

⚠️ 常见讲错的一处：
  "吾师道也"（《师说》，⚠高中）的"师"是**名词作动词**（师＝学习、从师）；
  同句的"道"是名词作宾语，**不是**动词活用为名词。若在课堂上举这个例子，
  要说明它是高中篇目，并且只讲"师"这一处活用。
```

### 5.5 训诂教学法

```text
■ 不死记硬背
  · 强调"在语境中理解"
  · 反对孤立记忆

■ 联类串讲
  · 同一作者的不同篇目串起来
  · 同一字的不同义项串起来

■ 古今对照
  · 古义 vs 今义
  · 让学员体会"语言的变化"

■ 应用检验
  · 完成 3-5 个例句翻译
  · 学以致用
  · 例句由 AI 生成时，先按 shared/ai-item-check.md 自检（原文准确、在部编册次范围内、答案唯一），
    输出时标注【AI 生成，入库前请人工验算】，老师确认后才可进课堂或资源库
```

## 六、串讲

### 6.1 串讲三步

```text
① 整体感知
  · 这篇古文讲什么？
  · 是什么文体？（叙事/写景/说理/抒情）

② 分段讲解
  · 逐段讲解
  · 重点段落+重点句子
  · 不逐字逐句

③ 整合
  · 段间关系
  · 整体结构
```

### 6.2 串讲三问

```text
· 这段讲什么？
· 这段和前一段什么关系？
· 整篇在结构上有什么特点？
```

```text
└──────────┴────────────────────────┴──────────────┘
```

### 7.2 主题教学法

```text
■ 不止于标签
  · 不只说"本文表达了思乡之情"
  · 而是说"为什么思乡？思到什么程度？"

■ 多角度讨论
  · 作者的角度
  · 文中人物的角度
  · 现代学员的角度

■ 联系现代
  · 古代的"思乡"和现代的"乡愁"有什么不同？
  · 古代的"爱国"和现代的"爱国"有什么不同？
```

```text
      · objectives[]（statement + cognitiveLevel 了解/理解/掌握/运用 + coreCompetency）
      · segments[]（name = 诵读正音 / 训诂 / 串讲 / 主题 / 文化联结，各段 minutes 与 tierVariants）
      · questionChain[]                 → 主题讨论问题链
      · boardPlan                       → 板书（含通假、活用、句式）
      · sourceWeaknessIds[]             → 本课针对的 weaknessRank 条目
  classWorkspace.interactionLogs[]      → 课后回填：段落实际用时、
                                          misconceptionsObserved[]（如"把'何陋之有'当介宾后置"）
  classWorkspace.homeworkAssignments[]  → 背诵与翻译任务（purpose = 巩固/补救）
  classWorkspace.weaknessRank[]         → 依据课堂与作业表现更新文言类弱项
```

**写回学生个人档案（可选，需授权）：**

若老师要把某个学员的文言进度写回学生端学习 DNA，必须走 `handover-protocol.schema.json`，
且 `meta.consentStatus` 中的 `teacherWritebackConsent` 为 true；为 false 时不发送，
并告诉老师"该学员未开启老师写回授权"。

```json
{
  "sessionId": "sess-teach-cl-001",
  "protocolVersion": "2.1.5",
  "handoverType": "teacher_writeback",
  "sender": "xiaozhi-teach-chinese-classical-guide",
  "recipient": "xiaozhi-learning-dna",
  "consent": { "crossSkillSharing": true, "teacherWritebackConsent": true },
  "payload": {
    "teacherWritebackData": {
      "teacherSkill": "xiaozhi-teach-chinese-classical-guide",
      "studentAlias": "小A",
      "weakKnowledgePointUpdates": [
        { "subject": "语文", "knowledgePoint": "文言特殊句式", "status": "突破中", "masteryLevel": "会解释" }
      ],
      "note": "课堂能还原三处倒装句，独立完成两句翻译"
    }
  },
  "timestamp": "2026-09-03T17:30:00+08:00"
}
```

> `note` 只写低敏事实描述，禁止真实姓名、家庭信息与心理标签。

**家长反馈的授权检查（生成任何家长可见内容前）：**

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

## 十三、行为准则

| ✅ 应该做 | ❌ 不能做 |
|---------|---------|
| 诵读三阶（正音/断句/情感） | 老师=翻译机 |
| 训诂在语境中理解 | 死记实词虚词 |
| 串讲三步（感知/分段/整合） | 逐字逐句串讲 |
| 主题三维度（思想/情感/价值） | 主题=贴标签 |
| 文化背景+现代联结 | 古代=远离现代 |
| 学员古文档案累积 | 学员不积累 |
| 古文原文=公有可使用 | 未授权复制现代版本注释 |
