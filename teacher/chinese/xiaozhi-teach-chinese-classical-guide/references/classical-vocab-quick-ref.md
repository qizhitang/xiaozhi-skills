## 3. 特殊句式 5 类

> ⚠️ 最容易讲错的一处：「何以战」「何陋之有」是**宾语前置**，不是介词结构后置。
> 判定口诀：疑问代词或"之"把宾语提到了动词/介词**前面** → 宾语前置；
> 「以……」「于……」整个介宾短语落在动词**后面** → 介词结构（状语）后置。

```text
┌──────────┬──────────────────────────┬────────────────────────────────────┐
│ 句式      │ 标志                      │ 例句（部编册次）→ 还原              │
├──────────┼──────────────────────────┼────────────────────────────────────┤
│ 判断句    │ ……者，……也              │ 陈胜者，阳城人也（九下《陈涉世家》）│
│           │ ……，……也                │ 南阳刘子骥，高尚士也（八下）        │
│           │ 则、乃、即                 │ 此则岳阳楼之大观也（九上）          │
├──────────┼──────────────────────────┼────────────────────────────────────┤
│ 被动句    │ 为……所……               │ 山峦为晴雪所洗（八下《满井游记》）  │
│           │ 意念被动（无标志）          │ 帝感其诚（八上）＝天帝被他的诚心感动│
├──────────┼──────────────────────────┼────────────────────────────────────┤
│ 倒装句    │ ① 宾语前置                 │ 何陋之有（七下）＝ 有何陋           │
│           │   （疑问代词/"之"提宾）     │ 何以战（九下）＝ 以何战             │
│           │ ② 定语后置                 │ 马之千里者（八下《马说》）＝千里之马 │
│           │ ③ 状语后置（介词结构后置）  │ 饰之以金 ＝ 以金饰之                │
│           │                          │ 战于长勺（九下）＝ 于长勺战          │
│           │ ④ 主谓倒装                 │ 甚矣，汝之不惠（八上《愚公移山》）  │
│           │                          │ ＝ 汝之不惠甚矣                     │
├──────────┼──────────────────────────┼────────────────────────────────────┤
│ 省略句    │ 省主语/宾语/介词            │ （渔人）便舍船，从口入（八下）      │
│           │                          │ 场主积薪其中（＝积薪于其中，七上）  │
├──────────┼──────────────────────────┼────────────────────────────────────┤
│ 固定句    │ 如……何（把……怎么办）     │ 其如土石何（八上《愚公移山》）      │
│           │ 孰与（跟……比哪个更……）   │ 吾孰与徐公美（九下《邹忌讽齐王纳谏》）│
│           │ 不亦……乎（不也……吗）     │ 不亦说乎（七上《论语》）            │
│           │ 何……之有（有什么……呢）   │ 何陋之有（七下《陋室铭》）          │
└──────────┴──────────────────────────┴────────────────────────────────────┘
```

## 4. 词类活用 6 类

> ⚠️ 校订：旧版把「吾师道也」的"道"列为"动词作名词（道＝道理）"，这是错的——
> "道"在该句里是**普通名词作宾语**，没有活用；活用的是"师"（名词作动词，师＝从师学习）。
> 且《师说》属 ⚠高中 篇目，初中教学不用它举例。

```text

├──────────┼──────────────────────────┼────────────────────────────────────┤
│ 名作动    │ 名词处在谓语位置或带宾语    │ 一狼洞其中（洞＝挖洞，七上《狼》）   │
│           │                          │ 域民不以封疆之界（域＝限制，八上）   │

├──────────┼──────────────────────────┼────────────────────────────────────┤
```
