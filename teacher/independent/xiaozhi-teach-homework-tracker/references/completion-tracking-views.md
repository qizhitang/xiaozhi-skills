# 作业完成度追踪视图模板

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-homework-tracker` §五使用。独立教师带一对一或小班，没有"班级"，因此第二张表是**学员列表视图**而不是班级花名册。
> 状态只用 schema 七档枚举：已布置 / 已提交 / 部分提交 / 未交 / 已批改 / 已订正 / 已减免。逾期与否看 `overdueDays`，不新造 `overdue` 状态。
> 只登记课上练习与学员带来的学校作业、考试错题（`task` 开头写类别与日期），不登记回家做的作业；完成度只算课上练习，学校作业、考试错题从 `已批改` 或 `已订正` 起记，不算完成度、不算逾期。

## 一、单学员作业完成度视图

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 作业完成度 · [化名] · [周次]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 本周课上练习（dueDate = 约定做完的那节课）
  · 练习 1（[日期] 课上）：□已布置 □已提交 □部分提交 □未交 □已批改 □已订正 □已减免
      逾期：[overdueDays] 天（0 表示在约定的那节课做完了）
  · 练习 2（[日期] 课上）：□已布置 □已提交 □部分提交 □未交 □已批改 □已订正 □已减免
      逾期：[overdueDays] 天
  · 练习 3（[日期] 课上）：□已布置 □已提交 □部分提交 □未交 □已批改 □已订正 □已减免
      逾期：[overdueDays] 天

■ 学员带来的学校作业、考试错题（学员自愿带来，不追交、不催交）
  · [学校作业 / 考试错题]（[日期] 带来）：□已批改 □已订正 · 记错题 [N] 条

■ 课上练习完成情况（按条数，不按题数；学校作业、考试错题不算）
  · 课上做完（已提交，含已批改/已订正）：[N] / 总 [N]
  · 课上没做完（部分提交）：[N] / 总 [N]
  · 下节课也没补上（未交）：[N] / 总 [N]
  · 已减免：[N]（不计入未交）

■ 与上周对比
  · 上周：[N] / [N] 条按约定做完
  · 本周：[N] / [N] 条按约定做完
  · 趋势：[好转 / 持平 / 下降]
  · 说明：单周条数少时不下"趋势"结论，标 🔴 样本不足

■ 错因统计（按 shared/vocab.md §1 四维；课上练习与学校作业、考试错题一起算）
  · 本周新记错题：[N] 条
  · 概念模糊 [N] · 计算失误 [N] · 读题失误 [N] · 方法用错 [N]
  · 已达 vocab §5 阈值待老师确认：[N] 个知识点
  · 已订正：[N] / [N]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 二、学员列表视图（跨学员横看）

只给老师自己看，不排名、不公示、不发群。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 学员作业一览 · [科目] · [日期]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 逐学员状态
  ┌────────┬──────────┬──────────┬────────────┐
  │ 化名    │ 本次状态  │ 逾期天数  │ 待跟进事项  │
  ├────────┼──────────┼──────────┼────────────┤
  │ 小A     │ 已批改    │ 0        │ 订正第 3 题 │
  │ 小B     │ 部分提交  │ 0        │ 下节课补完  │
  │ 小C     │ 未交      │ 2        │ 查卡在哪    │
  │ 小D     │ 已减免    │ —        │ —          │
  │ 小E     │ 已订正    │ —        │ 学校作业    │
  └────────┴──────────┴──────────┴────────────┘
  （小E 那条是学员带来的学校作业，从已批改起记，不算完成度、不追交）

■ 需要跟进的学员（判据见 SKILL §十）
  · 小C：近 4 周 3 条 overdueDays ≥ 1 → 高度，先自查课上练习的量与难度
  · 小B：近 4 周 2 条 overdueDays ≥ 1 → 中度，课上问一句卡在哪

■ 多名学员共同错的题（仅小班场景）
  · [知识点]：[N] 人错，主要维度 [概念模糊 / 计算失误 / 读题失误 / 方法用错]
  · 处理：下节课当共性内容讲；只有 1 人错的放个体任务
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 三、填写注意

- 化名一律用 `studentCards[].alias`，任何视图里不出现真实姓名。
- "完成度"只统计课上练习的条数（学校作业、考试错题不算），不换算成对学员的评价用语；学员带来多少学校作业也不用来评价学员。
- 学员卡 `status` 为"暂停记录"或"已结课"时，不再新增行。
- 统计跨周数据依赖平台的跨会话统计能力；没有该能力时只列本次会话已知的几条，并说明"这不是完整历史"。
