# 下节课预诊断输出模板

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-homework-tracker` §8.2 使用。
> 预诊断是**生成的报告段落**，不是工作空间存储字段；事实来源为 `workspace.homeworkFollowups[].mainErrors[]`。老师要留档时，由 `xiaozhi-teach-lesson-log` 写入 `lessonLogs[].nextLessonFocus`。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔍 下节课预诊断 · 基于 [日期] 作业 · [化名]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 必须讲
  · [知识点]：dimension [概念模糊/计算失误/读题失误/方法用错]
      判据：本次错 [N] 题；28 天内第 [N] 次
      讲什么：[针对该维度的具体切入点]
  · [知识点]：dimension [   ]
      判据：[   ]
      讲什么：[   ]

■ 可以带过
  · [知识点]：只错 1 题且此前无记录 → 口头点一句，不占时间

■ 需要专项处理
  · [知识点]：已达 shared/vocab.md §5 阈值
      → 先回到定义/纯净版，再换题型验证，两次验证间隔 ≥ 3 天

■ 小班场景补充（一对一跳过）
  · 多人共同错：[知识点]（[N] 人）→ 统一讲
  · 单人错：[化名] [知识点] → 单独任务，不占公共时间

■ 时间怎么分（按 shared/grade-bands.md 三，
  校外一对一/小班默认 60 或 90 分钟；线上单次建议 ≤ 30-45 分钟）
  · 回看上次错因：[N] 分钟
  · 必须讲的知识点：[N] 分钟
  · 当堂验证（换题型）：[N] 分钟
  · 新内容：[N] 分钟
  注：以上按老师实际课时长度分配，不写死总时长

■ 交给谁
  · 老师带进下一节课；本 SKILL 不写教案
  · 要留档 → xiaozhi-teach-lesson-log 写 lessonLogs[].nextLessonFocus
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 填写注意

- 每条"必须讲"都要有判据（错了几题、28 天内第几次），没有判据的不写进必须讲。
- 不写"这孩子基础差"这类整体评价，只写知识点和维度。
- 用于验证的同类题若由 AI 生成，先按 `shared/ai-item-check.md` 自检，并标注【AI 生成，入库前请人工验算】。
