# 顽固弱项档案模板

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-homework-tracker` §7.3 使用。
> 弱项状态五档与进出条件见 `shared/vocab.md §4`；计数口径见 `shared/vocab.md §5`。本文件只提供填写格式，不另定阈值。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔴 顽固弱项档案 · [化名]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 弱项 ①
  知识点（knowledgePoint）：[            ]
  通用维度（dimension）：□概念模糊 □计算失误 □读题失误 □方法用错
  老师端七类（teacherCategory，选填）：[            ]
  计数：28 天内 [N] 次（[d1] [d2] [d3]）
  首次出现：[日期] · 最近一次：[日期]
  弱项状态（shared/vocab.md §4）：
    □待处理 □初步弱项 □顽固弱项 □突破中 □已攻克
  置信度（shared/vocab.md §7）：□🟢 数据充分 □🟡 初步趋势 □🔴 样本不足
  是否已写入学员卡：□老师已确认，已写入 primaryWeaknesses
                    □仅在 progressEvidence，等老师确认
  跟进动作：
    · 第 [N] 次课：回到定义 / 纯净版最简题
    · 第 [N] 次课：换题型验证
    · 第 [N] 次课：独立验证（间隔 ≥ 3 天）

■ 弱项 ②
  （同上格式）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 状态怎么变（引用 shared/vocab.md §4）

```text
待处理 ──首次记录────────────────────────→
初步弱项 ──28 天内同知识点同维度第 2 次───→
顽固弱项 ──28 天内第 3 次──────────────→
突破中   ──顽固后首次独立验证做对────────→
已攻克   ──再一次独立验证做对，间隔 ≥ 3 天，
           且至少 1 次为换题型/纯净版验证──→
已攻克后 30 天内再错 → 退回突破中
```

## 填写注意

- **攻克标准不是"连对 3 次"**：是连续 2 次独立验证做对、间隔 ≥ 3 天、至少 1 次换题型或纯净版（`shared/vocab.md §5`）。
- 28 天内累计 5 次属高危：建议与学员本人谈学习策略；是否告知家长依 `shared/vocab.md §8` 的授权位判断，不默认告知。
- 写入 `studentCards[].primaryWeaknesses` 上限 5 条，且必须老师逐条确认；未确认的留在 `progressEvidence` 里。
- 档案只写知识点和维度，不写错题原文，不写对学员的性格评价。
