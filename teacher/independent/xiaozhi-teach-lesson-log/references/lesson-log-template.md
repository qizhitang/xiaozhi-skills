# 课后记录 5 维度与学习轨迹模板

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-lesson-log` 使用。
> 完整 Prompt 逻辑请参阅 [`../SKILL.md`](../SKILL.md)。
> 掌握度五档见 `shared/vocab.md §6`；课堂反应只用 `studentReaction` 五枚举；课时长度参数见 `shared/grade-bands.md` 三。
> 本文件里的每一份模板都是**待老师确认的草稿**：填好先给老师看，老师说"存"才写入工作空间；课时条目在老师点头前只是待确认条目。
> 记录只放可观察的事实与掌握档位，不放对特质的推断（抗挫能力、思维能力、专注力强弱、学习动机、性格）。

## 三、5 分钟即时记录原则

```text
窗口 1（理想）：课后 0-5 分钟
  · 学生刚走，趁记忆清晰
  · 完成核心 5 维度记录

窗口 2（可接受）：课后 5-30 分钟
  · 关键信息不丢
  · 5 分钟内补完

窗口 3（事后回忆）：课后 30 分钟-24 小时
  · 标注"事后回忆，准确度有限"
  · 重点补核心：学了什么 + 掌握度

窗口 4（过期）：课后 > 24 小时
  · 强烈不建议
  · 教学价值大幅下降
```

### 3.1 速记法（5 句话）

```text
学生离开前 1 分钟（5 句话速记）：
  ① 今天（[日期]）学了 [课题]
  ② [化名] 掌握了 [X]，没掌握 [Y]
  ③ 课堂反应：□投入 □平稳 □疲惫 □抗拒 □未观察
  ④ 下次讲 [X]
  ⑤ 需要给家长说：[X / 暂不需要]

课后再花 3-5 分钟补全 5 维度与 perTopicMastery。
日期是必填项：没有 date 的记录不参与"最近 N 条""上次讲到哪"的判断。
```

## 五、课时消耗登记

### 5.1 待确认条目机制

课时不由 AI 扣减。每节课后生成一条待确认条目，老师确认后才计入 `usedUnits`。

```text
生成：coursePackageLedger[].pendingConfirmations 追加
      { "lessonId": "[课节ID]", "units": [数字], "generatedAt": "[时间]" }
问一句：「[化名] 今天这节课记 [N] 课时，确认吗？
         （确认 / 改成 X 课时 / 这次不扣）」
老师确认 → 移出待确认，usedUnits +N、remainingUnits -N
老师没回 → 留在待确认，剩余课时不变；下次打开时再问一次

剩余课时的任何展示都注明"未含 [N] 条待确认"。

课时包到期提示（只陈述事实，不催单）：
  · expiryDate 距今 ≤ 7 天：提示一次剩余课时与到期日
  · 续费节点口径：已用 50% / 70%
    （与 xiaozhi-teach-renewal-report 一致，本文件不另设节点）
```

### 5.2 特殊场景

```text
学生请假：
  · 生成 units=0 的待确认条目
  · evidence 只记"已请假"，不记家庭细节、不记请假理由的私人内容

老师取消：
  · 不生成课时条目
  · 补课时间由 xiaozhi-teach-schedule-manager 生成待确认的补课建议，
    不涉及退款

补课：
  · 按实际时长生成待确认条目
  · 对应 lessonSchedule[].status = makeup

试听：
  · 不生成任何课时条目
  · 对应 lessonSchedule[].status = trial（schema 枚举值，不用文字备注代替）
  · 试听照常写 lessonLogs，供老师判断是否适配
```

## 七、家长事实摘要模板（内部草稿）

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

**本节产出的是写进 `parentSummary` 的内部草稿**：它留在工作空间里给老师看，不是一条已发送的家长消息。本 SKILL 不代发、不推送。

### 7.1 起草前的两道检查（不可跳过）

```text
① workspace.studentCards[].consent 中 parentCommunicationAllowed
     false 或缺失 → 不起草任何家长内容，连内部草稿也不生成
     （这一道对任何 parentSummary 都要过，哪怕只写学习内容）
② 内容涉及课堂反应（疲惫/抗拒）时，再查同一处的 emotionSharingWithParent
     false → 只写学习事实，删掉课堂反应部分
     true  → 可写，但只写行为，不写猜测和标签
```

### 7.2 什么时候值得写一条

```text
■ 值得写
  · 有具体可说的进展（讲清了某个卡了很久的点）
  · 有需要家庭配合的具体事项（下次带某本练习册）
  · 课时包进度到节点：已用 50% / 70%
    （与 xiaozhi-teach-renewal-report 同口径，本文件不另设节点）

■ 不必每节课都写
  · 平稳推进的课写"按计划推进"即可，或不写
  · 没有新信息的"今天表现不错"是噪音
```

### 7.3 摘要模板（写入 parentSummary，≤500 字符，内部草稿）

```text

📬 课后事实摘要（内部草稿）· [化名] · [日期]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 本节课学了什么
  · 课题：[X]
  · 完成情况：[X / Y]

■ 今天看到的具体表现
  · 做到了：[可观察的行为，如"上次错的三道题这次自己做对两道"]
  · 还需要练：[具体知识点，不写"不认真""基础差"]

■ 建议家庭配合（可选，只写做得到的一件事）
  · ____________________________________

■ 下节课打算讲
  · ____________________________________
```

### 7.4 话术（老师自己发，本 SKILL 不代发）

```text
■ 有进展
  "[化名] 今天在 [X 知识点] 上有具体进展：
   上次做不出来的 [X 题型]，这次自己完成了 [N] 道。"

■ 需要多练
  "[化名] 今天 [X 知识点] 还需要再练一练，
   下节课我会换个角度再讲一遍。
   在家不用额外加练，等下次课后我再看效果。"

■ 需要家庭配合
  "[化名] 下次课要用到 [X 材料]，麻烦提醒他带上。"

■ 课堂状态（仅在 emotionSharingWithParent = true 时写）
  "今天后半节 [化名] 注意力不太集中，
   我把练习换成了口头问答，效果还行。"

  ⚠️ 不写"情绪低落""厌学""抗拒数学"这类标签；

   这段时间在 [X] 上的具体变化是 [事实]。
   接下来打算 [下一步计划]。"
  ⚠️ 只陈述事实与计划，不催单、不制造紧迫感。
```

## 八、5 维度评估尺度

### 8.1 掌握度五级（对齐 schema.lessonLog.masteryStatus）

```text
□ 已掌握：能独立完成类似题，反应快
□ 基本理解：懂了思路，但还不够熟练
□ 仍需巩固：能做对但需要时间，可能在变式题上卡住
□ 需要重讲：做不对/概念仍有偏差，需重新讲解
□ 证据不足：本次未充分暴露掌握情况，暂不判定
```

### 8.2 课堂反应五档（对齐 schema.lessonLog.studentReaction）

只描述**这节课看到的行为**，不推测原因、不贴心理标签。判定参照的专注时长按学段取值，见 `shared/grade-bands.md` 二（小学中段 15-20 分钟、小学高段 20-25 分钟、初中 25 分钟、高中 25-40 分钟为一个专注段）。

```text
□ 投入：主动提问或主动尝试；整节课基本跟得住
□ 平稳：按部就班完成，无明显起伏
□ 疲惫：本学段一个专注段内就开始走神，或明显打不起精神
□ 抗拒：拒绝动笔、拒绝回答、明确说不想做
□ 未观察：本次没有足够观察，或线上课看不到状态

配套写 evidence（可观察的行为，一两句）：
  ✅ "后 20 分钟两次走神，问'还有多久下课'"
  ✅ "第 3 题卡住后放下笔，说'这个我不会'"
  ❌ "情绪低落"（这是判断不是观察）
  ❌ "可能昨晚没睡好"（这是猜测）
  ❌ "对数学有畏难情绪"（这是标签）
```

**为什么砍掉"情绪""抗挫"这类栏目**：它们要求老师对孩子的内在特质下判断——抗挫能力、思维能力、专注力强弱、学习动机、性格——而一节课、甚至十节课的观察都不足以支撑；写下来又会进入阶段报告和家长沟通，误判的代价很高。本模板与学习轨迹视图里因此都不留这类字段，只留可核对的行为、掌握档位与日期。需要理解原因时，去和学员本人聊，聊到的内容不写进档案。

### 8.3 进步三档

```text
□ 进步：与上节课对比有明显改善
□ 持平：与上节课基本一致
□ 退步：与上节课对比有下滑
```

### 8.4 调整三档

```text
□ 有效：目标达成，方法可继续
□ 一般：目标部分达成，方法需小调
□ 低效：目标未达成，方法需大调
```

## 九、自检清单

每次输出课后记录前，AI 必须自检：

- [ ] 触发语里是否有学员化名与日期（没有就先问，不要先写）
- [ ] 是否把要写入的内容先给老师预览、并得到"确认保存"
- [ ] 是否写了 date（必填）
- [ ] 是否课后 5 分钟内补录；超 30 分钟是否标注"事后回忆，准确度有限"
- [ ] 5 维度是否完整（学/掌握/课堂反应/进步/调整）
- [ ] 多个知识点是否分别写进 perTopicMastery[]
- [ ] masteryStatus 与 studentReaction 是否都取自 schema 枚举
- [ ] 课堂反应是否只写行为、没有猜测和标签
- [ ] 课时是否生成为待确认条目（而非直接扣减）
- [ ] 试听是否记为 status=trial 且未生成课时条目
- [ ] 家长摘要前是否查过 parentCommunicationAllowed；
      含课堂反应时是否另查 emotionSharingWithParent
- [ ] 家长摘要是否被当作内部草稿处理（没有代发、没有说成"已告知家长"）
- [ ] 是否使用化名，未暴露真实姓名
- [ ] 是否避免了负面标签与家庭情况描述
