# 7 区块日工作台输出模板

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-solo-dashboard` 使用，对应 SKILL.md「四、7 区块日工作台输出模板」。
> 全部只读渲染，工作台不写任何字段。逾期看 `overdueDays`；"最近 N 条"按 `lessonLogs[].date` 倒序取。
