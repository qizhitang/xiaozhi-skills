# 资源标签、检索与脱敏

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-resource-library` §五、§六、§九、§十使用。
> 五大类资源的用途与入库示例见 `resource-entry-examples.md`；版权标注格式见 `copyright-annotation-template.md`。本文件不重复那两份内容。
> 字段与枚举以 `solo-teacher-workspace.schema.json` 的 `resourceIndexItem` 为准；版权四档见 `shared/vocab.md §11`，错因四维见 §1。

---

## 一、标签字段

```text
┌──────────────────┬──────────────────────────────┬──────────┐
│ 字段              │ 取值                          │ 是否必填  │
├──────────────────┼──────────────────────────────┼──────────┤
│ resourceId       │ 自定义编号（R-001）           │ 必填      │
│ title            │ 一句话说清是什么（≤120 字）   │ 必填      │
│ resourceType     │ 题目/讲义/课件/板书/讲评话术/ │ 必填      │
│                  │ 错因案例/家长话术             │          │
│ copyrightStatus  │ 自有/改编/公开可引用/仅存索引 │ 必填      │
│ subject          │ 数学/语文/英语/物理/…         │ 推荐      │
│ knowledgePoint   │ 一次函数图象/定语从句/…       │ 强烈推荐  │
│ difficulty       │ 基础/中等/提升/挑战           │ 强烈推荐  │
│ gradeLevel       │ 年级或学段                    │ 推荐      │
│ aiGenerated      │ true / false                  │ AI 生成必填│
│ verifiedByTeacher│ true / false                  │ 同上      │
│ usageNotes       │ 用过几次、效果、改编来源      │ 推荐      │
└──────────────────┴──────────────────────────────┴──────────┘
```

`knowledgePoint` 和 `difficulty` 虽然 schema 上非必填，但**不填就检索不到**——三个月后翻库时，一堆只有标题的条目和没存过没有区别。

**没有"学员类型"标签**。按"基础学员/拔尖学员"给资源分层，用起来是方便了，但会让老师照着标签发题，而不是照着这个孩子当前卡在哪儿发题。要匹配就按 `knowledgePoint` + `difficulty`。

## 二、检索

### 2.1 按关键词

```text
输入："一次函数 复习"
匹配：title / knowledgePoint / usageNotes 命中
排序：knowledgePoint 精确匹配 > 标题匹配 > 备注匹配
标注：verifiedByTeacher=false 的条目标灰，附
      「待验算，先别直接给学员」
```

### 2.2 按学员当前情况

```text
读：workspace.studentCards[].gradeBand / .primaryWeaknesses
    workspace.homeworkFollowups[].mainErrors[].knowledgePoint / .dimension
匹配：knowledgePoint 相同 + difficulty 与当前掌握度相称
      + gradeLevel 在该学员学段内
输出：每条给出推荐理由（"针对小A 移项的概念模糊"），
      不给理由的推荐等于没推荐
超纲的：要用就在同一行标 ⚠高中 并说明是拓展，不默认推荐
```

### 2.3 按错因

```text
输入：通用四维之一（概念模糊/计算失误/读题失误/方法用错）
匹配：resourceType=错因案例，或题目的 knowledgePoint 对应该维度
输出：案例描述（已脱敏）+ 当时的应对 + 效果事实
```

**检索不支持反查学员**："这条案例是谁"这类问题一律不回答——案例入库时就脱敏了，能反查说明脱敏没做干净。

## 三、案例脱敏

### 3.1 必脱敏

```text
■ 必须处理
  · 真实姓名 → 化名，且化名与学员卡里的不同
    （案例里用"某学员"，不要用 studentCards[].alias，
      否则库里一查就对上了）
  · 学校名称 → 移除，不写"某公立学校"也不写地区
  · 年级 → 模糊到学段（"初中学员"）
  · 具体日期 → 模糊到月份或删除
  · 家长身份、家庭住址、联系方式 → 全部移除

■ 可保留（案例的价值就在这些）
  · 学科、知识点
  · 错因维度（shared/vocab.md §1 四维）
  · 当时的应对动作
  · 效果事实（"两周后换题型做对"）
```

### 3.2 脱敏检查清单

```text
□ 姓名已换成与学员卡无关的代称
□ 学校、地区信息已移除
□ 年级已模糊到学段
□ 具体日期已模糊或删除
□ 家长信息、住址、联系方式已移除
□ 案例描述中没有"独特到能对上号"的细节
  （"那个每次带哈利波特水杯的学生"这种要删）
□ 案例分析写的是错因/方法/效果，不是某个人
□ 该学员若已要求删除数据，本案例是否也一并处理
```

**判断标准很简单**：把这条案例给同一个学校的另一位老师看，他能不能猜到是谁。能猜到就再脱一层。

## 四、什么时候入库

```text
■ 值得立刻入库
  · 花时间做出来的讲义、课件
  · 讲清楚了某个反复讲不通的点的那套说法
  · 一个典型错因的完整处理过程（含效果）
  · 自己出的、验算过的好题

■ 可以入库
  · 家长沟通里效果不错的措辞
  · 课堂过渡话术

■ 不必入库
  · 一次性的、下次不会再用的东西
  · 网上随手搜到的未授权资源（连索引都不必存）
  · 没有 knowledgePoint 也说不清用途的零散内容
```

**趁热存**。教完当下花两分钟填几个字段，比"以后有空整理"划算——等回头整理时，当初为什么这么讲已经想不起来了。

## 五、自检清单

每次入库或检索前：

- [ ] `copyrightStatus` 是否填了；教辅原题/真题是否为"仅存索引"
- [ ] "仅存索引"的条目是否**没有**录入题干
- [ ] `knowledgePoint` 与 `difficulty` 是否填了
- [ ] AI 生成的是否标了 `aiGenerated=true`
- [ ] 未验算的是否带【AI 生成，入库前请人工验算】且未推荐给学员
- [ ] 改编件是否重新验算过、是否写了原出处与改动点
- [ ] 学员案例是否过了脱敏清单
- [ ] 检索结果是否给了推荐理由
- [ ] 超纲内容是否标了 ⚠高中
- [ ] 是否**没有**向学员推送资源（只给老师看）
