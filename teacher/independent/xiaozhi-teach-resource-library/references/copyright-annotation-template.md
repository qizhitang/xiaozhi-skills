# 版权标注模板

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-resource-library` §8.2 使用。四档取值来自 `shared/vocab.md §11`，与 `solo-teacher-workspace.schema.json` 的 `resourceIndexItem.copyrightStatus` 枚举一致，不另设分类。
> 版权信息写在 `usageNotes` 里（`copyrightStatus` 本身是独立字段）。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
📄 资源版权信息
━━━━━━━━━━━━━━━━━━━━━━━━━━━
resourceId：[   ]
copyrightStatus：[自有 / 改编 / 公开可引用 / 仅存索引]

【自有】
  作者：老师本人
  创建时间：[YYYY-MM]
  → 完整存储

【改编】
  原出处：[书名/网站/资料名]
  改了什么：
    · [如"把出租车情境换成快递"]
    · [如"系数由 2 改为 3，重新算过答案"]
  改编时间：[YYYY-MM]
  → 完整存储；改完必须重新验算一遍

【公开可引用】
  来源：[教材名 / CC 协议资源]
  许可：[如 CC BY 4.0；教材例题写"教材例题"]
  → 完整存储，标注来源

【仅存索引】
  出处：[书名/卷名] [出版社] 第 [X] 页 第 [X] 题
  → 只记出处，不录题干、不存扫描件、不存拍照件
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 哪些必须走"仅存索引"

```text
· 教辅原题（不论是不是自己买的书）
· 历年真题及其汇编本
· 培训机构的内部讲义
· 出版物上的整页内容
```

**没有例外**。"这本书是我买的""大家都在用""只是自己用不外传"都不构成授权。存索引不影响使用：书在手边，按页码翻到即可；存题干则是在自己的库里做了一份未授权复制件——一旦这个库被导出、分享或迁移，那就是分发。

## 判断顺序

```text
① 是我自己写的吗？ → 是：自有
② 是基于别人的东西改的吗？ → 是：改编（记原出处 + 改动点）
③ 是教材例题，或有明确开放授权吗？ → 是：公开可引用（记来源与许可）
④ 以上都不是 → 仅存索引（只记出处）
判不准的一律按 ④ 处理。存索引的成本只是多翻一次书。
```

## 禁止入库

```text
❌ 盗版扫描件、整页拍照件
❌ 未授权转载的网络资源（连索引都不必存——出处本身就不可靠）
❌ 来源不明的题（不知道从哪来的，就不知道能不能用）
```

## AI 生成的题算哪一档

算 **自有**（是本地生成的，不是复制来的），但必须同时置 `aiGenerated = true`，并在 `verifiedByTeacher` 为 true 之前带上【AI 生成，入库前请人工验算】。版权归属和质量把关是两件事，两个都要过。
