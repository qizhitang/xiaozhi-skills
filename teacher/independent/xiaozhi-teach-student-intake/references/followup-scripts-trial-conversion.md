# 试听后转化期跟进节奏与话术

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-student-intake` §9.1 使用。
> **本文件只覆盖"试听 → 报名"这一段。** 报名后“建正式学员卡”仍由本 SKILL 完成——那是建档的最后一步，不是跟进； 学员报名之后的跟进不在建档技能里：续费节点沟通、家长犹豫时的回应、阶段报告、流失挽回与体面结束，全部交 `xiaozhi-teach-renewal-report`；缺课跟进、改期与补课交 `xiaozhi-teach-schedule-manager`。老师在这里问起那些场景时，说明该找哪个技能，不要在本文件里现编话术。
> 所有话术**由老师本人发出**，本 SKILL 只起草。起草前查 `studentCards[].consent` 的 `parentCommunicationAllowed`；为 false 时不生成任何家长内容。

---

## 一、转化期跟进节奏（试听后 1-7 天）

```text
目标：让双方判断合不合适，不是让家长尽快下单
节奏（最多三次，之后就停）：
  试听后当天：一条简短反馈（说看到了什么，不说"孩子很聪明"）
  试听后 2-3 天：问一句有没有疑问
  试听后 5-7 天：如果对方没回，就此打住——不追第四次
```

## 二、话术示例

```text
■ 试听当天（说观察，不说结论）
  "今天试听我看到 [化名] 在 [具体知识点] 上 [具体表现]，
   [另一个知识点] 需要从 [起点] 开始补。
   我把看到的整理了一下，您有问题随时问我。"

■ 试听后 2-3 天（给一次判断依据，不催）
  "上次试听我看到 [化名] 在 [具体知识点] 上 [具体表现]，
   [另一个知识点] 需要从 [起点] 开始补。
   如果您觉得这个节奏合适，我们可以先约几节课试试；
   要是想再看看别的老师，也完全没问题。"

■ 对方明确说不报名（一句话收尾，不追问）
  "好的，谢谢您来试听。
   我把今天看到的整理成几句给您，
   之后不管跟谁学，从 [具体知识点] 接上都合适。"
```

## 三、避免事项

```text
· 隔一两天问一次"考虑得怎么样了"
· "名额不多了""这个价格只到本周"
· 贬低其他机构或老师
· 让孩子当着家长面表态"想不想跟老师学"
· 用孩子的弱项制造紧迫感（"再不补就跟不上了"）
· 把试听观察说成长期结论——单次观察一律标 🔴 样本不足
```

## 四、跟进结束之后

```text
■ 报名了 → 按 SKILL.md §十建正式档案（建卡前先确认监护人同意），
           首课排期交 xiaozhi-teach-schedule-manager
■ 没报名 → 试听记录按"试听日 + 90 天"设 retentionUntil，
           到期提示老师删除（见 SKILL.md §12.3）；
           这一段之后不再主动跟进，也不转成续费话术
```

## 五、共同禁令

- 不代老师发送任何消息，只起草。
- 不用焦虑、比较、紧迫感推动决定（"别的孩子都在学""这样下去中考危险"）。
- 不承诺提分、不承诺效果。
- 话术里只出现化名，不出现真实姓名，也不出现联系方式。
- 家长没有开启 `parentCommunicationAllowed` 时，一条都不生成。
- 不在本文件里处理续费、缺课、流失、退费——这些转 `xiaozhi-teach-renewal-report` 与 `xiaozhi-teach-schedule-manager`。
