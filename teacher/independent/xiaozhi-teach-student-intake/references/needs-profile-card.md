# 需求画像卡模板

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-student-intake` §5.3 使用。目标写入 `studentCards[].goals[]`，讲解偏好写入 `learningPreferences[]`。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎯 需求画像 · [化名]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 学习目标（goals[]，用可观察的行为写，不用分数写）
  近期（约 1 个月）：____________________________________
  中期（约 3 个月）：____________________________________
  ✅ "能自己列出方程再解"　❌ "提 20 分"

■ 讲解与节奏偏好（learningPreferences[]，记具体可观察的偏好）
  讲解方式：先举例再讲道理 / 先讲框架再填细节 · 需要多举例 / 点到即可
  互动节奏：快问快答 / 慢一点深入讲
  难度节奏：接受难度跳跃 / 需要循序渐进
  （注：VAK"视觉型/听觉型/动手型学习风格"缺乏科学证据，不作为分型标签；
    此处只记具体可观察的偏好。也不要把上课时间写进这个字段——
    时间写 availability[]）

■ 家长的期待（原话记录，不替家长改写）
  家长说的原话：____________________________________
  这个期待里，可教学的部分是：____________________________________
  需要说明的部分是：____________________________________
  ⚠️ 家长提出具体提分数字时，不写进档案，也不接这个承诺；
     改成"我们先把 [具体知识点] 拿下，一个月后一起看效果"

■ 学员本人的态度（问过学员本人才填，没问就留空）
  想不想学：[学员原话]
  最想解决的：[学员原话]
  ⚠️ 不打分、不评级、不写"动机不足"这类判断

■ 需要留意的地方
  时间：□充足 □紧张（判据：availability[] 与作业量）
  作业完成：□基本能完成 □常拖 □不清楚（首次一般填不清楚）
  ⚠️ 不填"家庭支持不足""家长不重视"这类对家庭的评价
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 填写注意

- 画像只是第一次见面的印象，**置信度一律 🔴 样本不足**（`shared/vocab.md §7`），不作为长期结论，上过几节课后再修。
- 目标用行为写，不用分数写：分数受试卷难度影响，写进档案后会变成一个跟不掉的承诺。
- 学员本人的话优先于家长转述；两边说法不一致时，两条都记，标明各自出处。
