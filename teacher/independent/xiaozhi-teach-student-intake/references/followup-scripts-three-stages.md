# 转化/续费/流失三阶段跟进节奏与话术库

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-student-intake` §九使用。
> 所有话术**由老师本人发出**，本 SKILL 只起草。起草前查 `studentCards[].consent` 的 `parentCommunicationAllowed`；为 false 时不生成任何家长内容。
> 续费节点全库统一为**已用 50% / 70%** 两个（与 `xiaozhi-teach-renewal-report`、`xiaozhi-teach-schedule-manager` 一致）。

## 一、转化期（试听后 1-7 天）

```text
目标：让双方判断合不合适，不是让家长尽快下单
节奏：
  试听后当天：一条简短反馈（说看到了什么，不说"孩子很聪明"）
  试听后 2-3 天：问一句有没有疑问
  试听后 5-7 天：如果对方没回，就此打住

话术示例（试听后 2-3 天）：
  "上次试听我看到 [化名] 在 [具体知识点] 上 [具体表现]，
   [另一个知识点] 需要从 [起点] 开始补。
   如果您觉得这个节奏合适，我们可以先约几节课试试；
   要是想再看看别的老师，也完全没问题。"

⚠️ 避免：
  · 隔一两天问一次"考虑得怎么样了"
  · "名额不多了""这个价格只到本周"
  · 贬低其他机构或老师
  · 让孩子当着家长面表态"想不想跟老师学"
```

## 二、续费期（课时包已用 50% / 70%）

```text
目标：让家长知道钱花出去买到了什么，据此自己决定
节奏（只有两次，不是三次）：
  已用 50%：给一次阶段性反馈——这半程学了什么、有什么具体变化
  已用 70%：把"还剩多少课时、下一阶段打算做什么"说清楚

为什么砍掉 80%/90% 节点：
  节点越多越像催单。50% 谈进展、70% 谈计划，剩下的交给家长判断。
  课时快用完时如实说一次剩余数就够了，不需要第三次提醒。

话术示例（已用 50%）：
  "[化名] 的课上到一半了，跟您同步一下：
   [具体知识点] 已经能自己做对了（上次做不出来的 [X] 题这次做对 [N] 道），
   [另一个知识点] 还在练。
   后半程我打算 [具体计划]。"

话术示例（已用 70%）：
  "[化名] 还剩 [N] 课时。
   这段时间的具体变化是 [事实，不是形容词]。
   后面如果继续，我打算 [下一阶段计划]；
   如果想先停一停，也把进度整理给您，换老师也接得上。"

⚠️ 避免：
  · "再不续就衔接不上了"
  · 用孩子的退步或焦虑推动续费
  · 把剩余课时说得比实际少（未确认的课时要注明）
```

## 三、流失期（连续 2-3 次缺课，或明确表达不再继续）

```text
目标：先搞清楚原因，再决定挽留还是体面结束
节奏：
  缺课 1 次：正常问候，不追问
  缺课 2 次：问一次原因，给调整的选项
  缺课 3 次：直接问是不是想先停一停

话术示例（连续 2 次缺课后）：
  "注意到 [化名] 这两次没来上课。
   是时间安排上有冲突吗？如果是，我们可以换个时段。
   如果是别的原因，也欢迎直接告诉我。"

话术示例（对方表达要停）：
  "好的，理解。我把 [化名] 这段时间的学习进度整理一份给您，
   包括已经掌握的、正在练的、下一步建议从哪儿开始，
   之后不管是自己练还是找别的老师，都能接得上。
   有需要随时找我。"

⚠️ 注意：
  · 不强行挽留，不问第二遍
  · 不诋毁、不抱怨、不暗示是孩子不努力
  · 体面结束：整理一份进度交接，这是专业，也是留给以后
  · 结课后把 studentCards[].status 改为"已结课"，
    按 consent.retentionUntil 到期提示删除
```

## 四、三阶段共同禁令

- 不代老师发送任何消息，只起草。
- 不用焦虑、比较、紧迫感推动决定（"别的孩子都在学""这样下去中考危险"）。
- 不承诺提分、不承诺效果。
- 话术里只出现化名，不出现真实姓名。
- 家长没有开启 `parentCommunicationAllowed` 时，一条都不生成。
