# 典型场景话术模板

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-parent-communication` §六、§八使用。本文件是家长沟通话术的唯一出处。
> **每条话术都由老师本人发出**，本 SKILL 只起草。起草前先查 `studentCards[].consent` 的 `parentCommunicationAllowed`；涉及情绪或课堂状态的再查 `emotionSharingWithParent`。
> 学员一律用化名；具体学员的反馈一律私聊，`channel` 不得为 `群公告`。

---

## 一、6 类典型场景

### 1.1 学员有进展

```text
"[化名] 今天在 [知识点] 上有具体进展：
① [可观察的事实，如"上次做不出来的去分母，今天 4 道自己做对 3 道"]
② [可观察的事实]

下节课我们会 [计划]。
您在家不用额外加练，[一件具体能做的小事] 就够了。"
```

⚠️ 不写"孩子很聪明""进步神速"——夸的是人不是事，下次没进展时就没法说了。

### 1.2 学员近期表现下滑

```text
"这阶段 [化名] 的情况有些变化，跟您同步一下：

看到的现象（都是具体的）：
① [如"近三次作业有两次逾期，最长逾期 4 天"]
② [如"移项这个知识点 28 天内错了 3 次"]

我已经做的调整：
  · [具体动作，如"下节课先回到定义重讲一遍"]
  · [具体动作，如"这周作业减到 5 题，先把正确率稳住"]

想请您配合一件事：
  · [一件、具体、做得到的事]

不用着急，我们先把 [具体知识点] 拿下来再看。
方便的话，我想约您 [时间] 聊 5-10 分钟。"
```

⚠️ 写"现象"就只写现象，**不要在消息里列"可能的原因"**：老师隔着一节课猜出来的原因（学习兴趣下降、被别的事占用时间）到了家长那里会变成质问孩子的依据。原因去问孩子本人，问到了也不必写进消息。
⚠️ 不用"错题率上升 X%"这类比例：单次作业题量小，比例不稳定。用"三次里有两次""28 天内 3 次"这样的次数。

### 1.3 课堂状态需要家庭配合

**前置**：必须已开启 `emotionSharingWithParent`。未开启时只发学习内容，并告诉老师为什么。

```text
"今天 [化名] 后半节注意力不太集中，
我把练习换成了口头问答，把节奏放慢了一些。

我做的：[具体动作]
想请您：[一件具体的事，如"这两天别追问这次作业"]

孩子这两天状态怎么样，您比我看得清楚。
如果家里有什么需要我配合的，随时告诉我。"
```

⚠️ **不写"触发点（猜测）"**。也不写"可能是昨晚没睡好""好像对数学有畏难情绪"——这些是推测，写下来却会被当成结论。只写课上看到的行为。
⚠️ 出现自伤、被霸凌、持续绝望、家庭安全等信号时，不走本流程，按 `shared/crisis-exception.md` 处置：如实提示监护人，给出求助渠道（即时危险 110/120；12355；400-161-9995），不做诊断、不贴标签。

### 1.4 续课说明（已用 50% / 70%）

```text
"[化名] 课时还剩 [N] 课时（另有 [N] 条待我确认）。
跟您说一下这段时间的情况：

■ 这段时间的具体变化
  · [事实，不是形容词]
  · [事实]

■ 下阶段打算做什么
  · [重点 1]
  · [重点 2]

■ 续费建议
  推荐 [N 课时包]（约 [X 周]）：
  · 适合 [化名] 当前节奏（每周 [N] 课时）
  · 可以完整覆盖 [X 阶段]
  · 续费优惠：[X 优惠信息]

如果想先停一停，也没问题，我把进度整理给您。"
```

⚠️ 节点只有 **已用 50% 和 70%** 两个（全库统一）。不设 80%、90%，不在其他时候提续费。
⚠️ 剩余课时必须注明未确认条目，不能让家长按虚高的数字做判断。
⚠️ 不说"再不续就衔接不上了"，不在群里发续费接龙——续费是 1 对 1 的事。

### 1.5 家长表达担心

```text
"我理解您的担心。
跟您说几个我这边看到的：
  · [化名] 在 [具体知识点] 上已经 [具体事实]。
  · [另一个知识点] 还需要时间，我们正在 [具体计划]。

我不敢跟您保证什么时候能提多少分——
这个我说了不算。
但 [具体知识点] 这块，我有把握在 [时间] 内让他能自己做出来。

如果还有具体担心的点，我们约个时间细聊。"
```

⚠️ 不承诺提分、不说"一定会有更多进步"。家长的焦虑不能用另一个承诺去压。
⚠️ 不说"每个孩子有自己的节奏"这类话来搪塞——听着温和，实际什么都没回答。

### 1.6 家长配合不上（先内部反思，不急着发消息）

```text
内部先问自己（不发家长）：
  1. 我之前给的配合动作，是不是太多或太难了？
  2. 我说的是"多关注"还是一件具体的事？
  3. 家长是不是真的没时间（双职工、二胎、上夜班）？
  4. 这件事没有家长配合，我自己能不能解决？

多数情况下第 4 条是有解的：把需要家长盯的部分挪回课上。

确实需要沟通时：
  "之前我请您每天陪 [化名] 复习 10 分钟，
   我想了想这个可能不太现实。
   改成这样行不行：[更小的一件事]。
   其他的我在课上解决。"
```

## 二、敏感场景应对

### 2.1 持续下滑

```text
第 1 步：自己先诊断
  · 是知识漏洞、习惯问题、还是我讲的方式不对？
  · 我已经做了哪些调整？效果如何？
  · 作业量和难度是不是该降？

第 2 步：再与家长沟通
  · 不夸大、不轻描淡写
  · 具体现象 + 我已做的 + 请您配合的一件事

第 3 步：调整教学
  · 降难度重建信心 → 补基础 → 再提速
```

### 2.2 孩子因这门课在家挨批评

```text
观察点：
  · 上课是否变得不敢答、答错就紧张
  · 是否开始回避提问

应对：
  · 课上多给能做对的题，先把"我能做对"找回来
  · 私下温和鼓励，但不评论家长的批评
  · 必要时跟家长说一句：
    "[化名] 这周答题比之前谨慎，
     可能有点怕做错。这块我在课上调整，
     在家不用再提这次的事了。"
```

### 2.3 家长质疑教学

```text
原则：
  · 先听完，不打断，不立刻辩解
  · 承认对方感受的合理性
  · 再给具体证据

话术：
  "谢谢您跟我说这个。
   关于 [具体问题]，我这边看到的是：[具体事实]。
   我做的调整是：[具体动作]。
   不知道您那边看到的是什么情况？
   我们对一下，看怎么调整更合适。"
```

### 2.4 换老师 / 阶段结束

```text
提前说：
  · 提前 1-2 个月告诉家长
  · 说明原因，不含糊

交接：
  · 整理一份进度：学到哪、掌握什么、下一步建议从哪开始
  · 这份交接不含任何评价性标签，只有事实
  · 结课后把 studentCards[].status 改为"已结课"，
    到 consent.retentionUntil 提示删除档案
```

## 三、沟通频率

```text
┌──────────┬──────────────┬──────────────┐
│ 阶段      │ 频次          │ 形式          │
├──────────┼──────────────┼──────────────┤
│ 试听后    │ 1-2 天 1 次    │ 私聊          │
│ 前 1 个月 │ 每节课 1 次    │ 课后简短反馈  │
│ 稳定期    │ 每周 1-2 次    │ 课后反馈/周反馈│
│ 节点期    │ 已用 50%/70%   │ 私聊          │
│ 有情况时  │ 当次           │ 私聊          │
└──────────┴──────────────┴──────────────┘

以上为默认经验值，家长明确说"不用每次都发"时，以家长的要求为准，
并把 guardianCommunicationPreference 改为"不主动联系"。

发得太密的判断：近 7 天已有 3 条 sentStatus=sent 时，
提示老师一次「这周已经发了 3 条，这次要不要攒到周末一起说？」
```

## 五、自检清单

每次输出沟通话术前，逐条过一遍：

- [ ] `parentCommunicationAllowed` 是否为 true
- [ ] 含情绪或课堂状态时，`emotionSharingWithParent` 是否为 true
- [ ] 是否用具体行为而非模糊评价
- [ ] 是否避开了焦虑话术（"再这样下去""别人家孩子"）
- [ ] 是否**没有**写推测、猜测的原因、心理标签
- [ ] 是否只给了家长 1 个具体可做的动作
- [ ] 是否使用化名，未出现真实姓名
- [ ] 具体学员的内容是否走私聊而非群公告
- [ ] 续课说明是否只在已用 50% / 70% 两个节点
- [ ] 剩余课时是否注明"未含 N 条待确认"
- [ ] 是否避免了提分承诺
- [ ] 是否留给老师确认与自行发送的空间
