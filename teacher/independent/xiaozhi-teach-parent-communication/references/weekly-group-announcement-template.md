# 家长群公告模板（每周固定）

> 适用学段：小学中段 / 小学高段 / 初中 / 高中
> 配合 `xiaozhi-teach-parent-communication` §7.1 使用。仅适用于**小班有家长群**的情形；一对一没有群，跳过本文件，用私聊模板（见 `typical-scenario-scripts.md`）。
> 群公告写入记录时 `channel = 群公告`；**具体学员的任何反馈都不能用这个渠道**。

```text
"各位家长好，本周 [学科] 的学习重点是 [主题]。

■ 这周讲了什么
  · [知识点 1]
  · [知识点 2]

■ 这周普遍需要多练的地方（不点名）
  · [知识点]：这周的练习里，这一块出错的同学比较多，
    下周我会再讲一遍。

■ 在家可以做的一件事
  · [具体、做得到的一件事，如"这周把练习册 P32 的错题重做一遍"]

■ 通知
  · [调课通知 / 材料准备 / 假期安排等]

下周我们会 [计划]。"
```

## 群里能发什么

```text
✅ 可以发：
  · 教学计划、作业安排、材料准备
  · 不点名的共性提醒（"这周这个知识点出错的同学比较多"）
  · 学习方法分享
  · 通知性内容（调课、假期安排）

❌ 不能发：
  · 任何具体学员的分数、作业情况、课堂表现
  · 未交作业的名单
  · 学员之间的对比、排名
  · "别人家孩子都…"这类制造攀比的表述
  · 单个学员的诊断结论或弱项
  · 续费接龙、优惠倒计时
```

## 为什么个体信息一条都不能发群

家长群里每个人都看得见。一条"某某这周作业没交"，对家长是提醒，对孩子是当众点名——而孩子本人往往还不在群里，没法解释也没法回应。学员个体的事，一律私聊，没有例外。

需要提醒某个孩子的家长时：切私聊，`channel` 记 `私聊文字` 或 `私聊语音`，按 `typical-scenario-scripts.md` 的对应模板起草。

## 频率

每周固定一条即可。临时通知（调课、停课）单独发，不必等到固定时间。同一周内群公告超过 3 条时，提示老师合并——群消息发多了，重要的那条就被划过去了。
