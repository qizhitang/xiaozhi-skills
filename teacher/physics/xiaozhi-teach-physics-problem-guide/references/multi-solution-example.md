# 一题多解样板 · 漂浮木块的浮力

> 适用学段：初中（7-9 年级）。
> 示例题验算：2026-09-03
> 本题为初中人教版范围内的自有题（copyrightStatus 记为"自有"），已按 `shared/ai-item-check.md` 验算：三种解法答案一致、条件充分不多余、数据为整数、不超学段。
> 一题多解的教学目的不是"多算几遍"，而是让学生看见**同一个物理事实可以从不同角度描述**，并在对比中理解每种方法的适用条件。

---

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧮 一题多解 · 漂浮的正方体木块
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 题目
  边长 10 cm 的正方体木块静止漂浮在水面上，浸入水中的深度为 6 cm。
  （g 取 10 N/kg，ρ水 = 1.0×10³ kg/m³）
  求：(1) 木块受到的浮力；(2) 木块的密度。

■ 基础数据（三种解法公用）
  · 木块总体积 V物 = 0.1 m × 0.1 m × 0.1 m = 1×10⁻³ m³
  · 底面积 S = 0.1 m × 0.1 m = 1×10⁻² m²
  · 浸入深度 h = 0.06 m
  · 排开水的体积 V排 = S × h = 1×10⁻² × 0.06 = 6×10⁻⁴ m³

─────────────────────────────
■ 解法 1：阿基米德原理（最通用）
  · F浮 = ρ水 g V排
  · F浮 = 1.0×10³ × 10 × 6×10⁻⁴ = 6 N
  · 再由漂浮条件 G物 = F浮 = 6 N
  · m = G/g = 0.6 kg，ρ木 = m/V物 = 0.6 ÷ 1×10⁻³ = 6×10² kg/m³

─────────────────────────────
■ 解法 2：压力差法（回到浮力的来源）
  · 上表面露出水面 → 水对它没有向下的压力，F上 = 0
  · 下表面在水下 0.06 m 处 → p下 = ρ水 g h = 1.0×10³ × 10 × 0.06 = 600 Pa
  · F下 = p下 × S = 600 × 1×10⁻² = 6 N
  · F浮 = F下 − F上 = 6 N − 0 = 6 N
  · 后续同解法 1，得 ρ木 = 6×10² kg/m³

─────────────────────────────
■ 解法 3：浮沉条件 + 体积比（最快）
  · 漂浮 → F浮 = G物 → ρ水 g V排 = ρ木 g V物
  · 约掉 g：ρ木 / ρ水 = V排 / V物 = 6×10⁻⁴ ÷ 1×10⁻³ = 0.6
  · ρ木 = 0.6 × 1.0×10³ = 6×10² kg/m³
  · 再由 G物 = ρ木 V物 g = 6×10² × 1×10⁻³ × 10 = 6 N，即 F浮 = 6 N

─────────────────────────────
■ 三种解法的比较

  ┌────────────┬──────────────────┬──────────────────────┐
  │ 解法        │ 适用范围          │ 教学价值              │
  ├────────────┼──────────────────┼──────────────────────┤
  │ 阿基米德原理 │ 一切浸在液体/气体 │ 主干方法，必须掌握     │
  │            │ 中的物体          │                      │
  │ 压力差法    │ 上下表面水平的规则 │ 解释浮力"从哪来"，    │
  │            │ 物体              │ 破除"浮力是凭空的"     │
  │ 浮沉条件    │ **只在漂浮或悬浮**│ 最快，但最容易被误用   │
  │ + 体积比    │ 时成立            │ 到下沉物体上           │
  └────────────┴──────────────────┴──────────────────────┘

■ 课堂用法
  · 先让学生用自己会的那一种做出来
  · 再问："还有别的算法吗？"——学生说不出时给出方法名，不给过程
  · 三种算完后必须做一次对比：**哪一种换成"沉底的铁块"就不能用了？**
    → 解法 3（浮沉条件）不能用；解法 1、2 仍然成立

■ 反思与常见错
  · 常见错①：把解法 3 当成万能公式，对下沉物体也写 F浮 = G物
  · 常见错②：压力差法里忘了"上表面露出水面，F上 = 0"，硬去算一个上表面压力
  · 常见错③：V排 用成 V物（本题浸入的只有 6/10）
  · 常见错④：cm 与 m 混用，体积算成 600（应为 6×10⁻⁴ m³ 或 600 cm³）

■ 变式接口
  · 改条件：把水换成盐水（ρ 变大）→ 浸入深度变浅，浮力仍等于重力
  · 改问题：给出木块密度反求浸入深度
  · 改情境：在木块上再放一个小物块，求新的浸入深度

```
