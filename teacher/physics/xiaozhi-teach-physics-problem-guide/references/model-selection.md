# 物理模型选择参考（初中五类模型）

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-physics-problem-guide` 使用。从"问题类型 → 模型选择 → 关键式子"三步走，帮助学生建立模型选择的判断力。
> 本文与学生端 `student/physics/xiaozhi-physics-modeling-coach/references/physics-modeling-patterns.md` 用同一套五类模型命名，老师端侧重"怎么教选模型"，学生端侧重"怎么自己选"。
> 超出初中课标的模型见文末"初高衔接（⚠高中）"，不作为课堂讲解与命题依据。

## 1. 初中五类模型总览

```text
┌──────┬────────────────────────┬──────────────────────────────────┐
│ #    │ 模型                    │ 关键式子                          │
├──────┼────────────────────────┼──────────────────────────────────┤
│ 1    │ 匀速直线运动与平均速度   │ v=s/t；v̄=s总/t总                  │
│ 2    │ 力学平衡（同一直线二力） │ F₁=F₂；G=mg                       │
│      │ ├ 简单机械分支          │ F₁L₁=F₂L₂；F=(G物+G动)/n；η=W有/W总│
│ 3    │ 压强与浮力              │ p=F/S；p=ρgh；F浮=ρ液gV排         │
│      │ └ 称重法                │ F浮=G物−F示                        │
│ 4    │ 电路分析（含动态电路）   │ I=U/R；串联 U=U₁+U₂、R=R₁+R₂；    │
│      │                         │ 并联 I=I₁+I₂；P=UI=I²R=U²/R；     │
│      │                         │ Q=I²Rt                            │
│ 5    │ 功、功率与能量转化       │ W=Fs；P=W/t；Q=cmΔt；Q=mq         │
└──────┴────────────────────────┴──────────────────────────────────┘
```

## 2. 模型选择决策树

```text
读题 → 圈出题目里出现的物理量
│
├── 出现"路程/时间/速度/平均速度/过桥/相遇/追上"
│   └──→ 模型 1：匀速直线运动与平均速度
│        追加确认：问的是某一段的速度，还是全程平均速度？
│
├── 出现"静止/匀速/保持不动/匀速拉动/弹簧测力计示数"
│   └──→ 模型 2：力学平衡
│        追加确认：配对的两个力在同一直线上、作用在同一物体上吗？
│
├── 出现"杠杆/支点/力臂/滑轮/滑轮组/机械效率/斜面"
│   └──→ 模型 2 的简单机械分支
│        追加确认：力臂量对了吗？几段绳承担物重？
│
├── 出现"压力/受力面积/压强/深度/浮力/漂浮/浸没/排开/大气压"
│   └──→ 模型 3：压强与浮力
│        追加确认：是压在固体表面，还是在液体内部？浸没了没有？
│
├── 出现"电流/电压/电阻/串联/并联/开关/滑动变阻器/电功率/电能"
│   └──→ 模型 4：电路分析
│        追加确认：每个开关或滑片状态都画等效电路图了吗？
│
├── 出现"做功/功率/机械效率/热量/比热容/热值/能量转化"
│   └──→ 模型 5：功、功率与能量转化
│        追加确认：分清有用功、额外功、总功了吗？
│
└── 出现多个上述关键词
    └──→ 多过程综合题，分段选模型（见第 8 节）
```

## 3. 模型 1 选择：匀速直线运动与平均速度

```text
【何时用】题目只给"路程与时间"，或问"平均速度"

【适用条件】沿直线运动。速度在变时，初中只作定性判断（越来越快/越来越慢）

【关键式子】
  v = s / t
  v̄ = s总 / t总   ← 必须用定义式，不能把各段速度求算术平均

【典型题】测小车的平均速度、过桥问题、相遇与追及、看到闪电后估算雷电距离

【学生最常错】
  · 把上下半程速度直接平均
  · 过桥漏加车长
  · km/h 与 m/s 换算方向搞反（km/h→m/s 除以 3.6）

【老师追问】"这道题问的是哪一段？总路程多少？总时间多少？"
```

## 4. 模型 2 选择：力学平衡（含简单机械）

```text
【何时用】物体静止或匀速直线运动；或涉及杠杆、滑轮、机械效率

【适用条件】初中只处理**同一直线上的两个力**；不做力的分解

【关键式子】
  F₁ = F₂           二力平衡（同物、同线、等大、反向）
  G = mg            g 取 10 N/kg
  F₁L₁ = F₂L₂       杠杆平衡条件
  F = (G物 + G动)/n  滑轮组（n 为承担物重的绳段数）
  s = n h           绳自由端移动距离
  η = W有/W总 = G物h/(Fs)

【典型题】悬挂物体求拉力、水平匀速拉木块求摩擦力、杠杆求动力、滑轮组求效率

【学生最常错】
  · 漏画摩擦力或浮力
  · 把"压力"与"支持力"当成一对平衡力（那是相互作用力，不在同一物体上）
  · 力臂量成支点到作用点的距离
  · 算总功时用提升高度 h 而不是绳端移动距离 s

【老师追问】"这两个力作用在同一个物体上吗？在同一条直线上吗？"
```

## 5. 模型 3 选择：压强与浮力

```text
【何时用】涉及压力与受力面积、液体深度、物体浮沉、大气压

【适用条件】
  p = F/S      F 是垂直压在表面上的力；水平面上放物体时 F = G
  p = ρ液gh    h 是从液面竖直向下量的深度，与容器形状、液体多少无关
  F浮 = ρ液gV排 阿基米德原理，普遍成立
  F浮 = G物    **只在漂浮或悬浮时成立**
  F浮 = G物−F示 称重法（弹簧测力计实验）

【典型题】容器对桌面的压强、液体对容器底的压力、称重法测密度、
          漂浮木块求密度、冰化成水后液面变化、大气压实验

【学生最常错】
  · 对下沉物体也写 F浮 = G物
  · V排 用成物体总体积
  · h 用成容器高度或物体高度
  · S 用 cm² 直接代入（应 ÷10000 换成 m²）
  · 认为浸没后越深浮力越大

【老师追问】"这个物体是漂着、悬着，还是沉底？你怎么判断的？"
```

## 6. 模型 4 选择：电路分析（含动态电路）

```text
【何时用】涉及电流、电压、电阻、电功率、电热

【适用条件】初中把电源电压视为不变；欧姆定律只用于电阻本身不随温度显著变化的元件

【关键式子】
  I = U/R
  串联：I 处处相等，U = U₁+U₂，R = R₁+R₂
  并联：各支路电压相同，I = I₁+I₂，总电阻比任何一条支路都小
  P = UI = I²R = U²/R
  W = UIt；Q = I²Rt（纯电阻时 Q = W）

【动态电路的推导链（中考高频）】
  滑片移动 → 接入阻值变 → 总电阻变 → 干路电流变 → 各表示数依次判断
  串联中：R滑↑ → R总↑ → I↓ → U(定值电阻)↓ → U(滑变)↑

【典型题】串联动态电路与量程范围、并联求各支路电流、电热水壶的额定与实际功率、
          电能表读数、家庭电路安全用电

【学生最常错】
  · 开关或滑片状态改变后不重画等效电路
  · 分不清电压表并在哪个元件两端
  · 混淆额定功率与实际功率
  · 把小灯泡当成定值电阻，对多次测得的电阻求平均值
  · 并联也用 R = R₁ + R₂

【老师追问】"这个电压表读的是谁两端的电压？滑片移动后，电路结构变了吗？"
```

## 7. 模型 5 选择：功、功率与能量转化

```text
【何时用】涉及做功、功率、机械效率、吸放热、能量形式的转化

【适用条件】W=Fs 中的 F 与 s 必须同方向；物体没移动或力与移动方向垂直都不做功

【关键式子】
  W = Fs；P = W/t = Fv（初中只在匀速时用 P=Fv）
  η = W有/W总（W总 = W有 + W额）
  Q吸 = cmΔt；Q放 = cmΔt；燃料放热 Q = mq
  能量转化：E初 = E末 + 损耗

【典型题】滑轮组机械效率、爬楼功率、电热器加热水求效率、
          燃料燃烧放热与水吸热的比较、动能与重力势能的相互转化（定性）

【学生最常错】
  · 搬着重物水平走也算做功
  · 有用功与总功颠倒
  · Δt 用成末温而不是温差
  · 把"效率"算出大于 1 而不检验

【老师追问】"这个力有没有让物体沿它的方向移动？有用功是哪一部分？"
```

## 8. 综合问题的模型选择

```text
【综合题】把浸没在水中的物体匀速提出水面，再匀速举高，求全过程拉力做的功

  · 第 1 阶段：物体完全浸没时匀速上提
    → 模型 3 + 模型 2：F拉 = G物 − F浮

  · 第 2 阶段：物体露出水面后匀速上升
    → 模型 2：F拉 = G物
    → 衔接点：刚露出水面的一刻，拉力从"扣掉浮力"变成"全部重力"

  · 第 3 阶段：求这段拉力做的功
    → 模型 5：W = F拉 · h

【综合题】滑片从一端移到另一端，求两个状态下的电流与功率

  · 状态 1、状态 2 各画一张等效电路图 → 模型 4
  · 两个"不变量"（电源电压、定值电阻）就是连接两个状态的桥梁

【启示】综合题要"分阶段/分状态"，每一段只用一个主模型；
        衔接量写清楚，是把几段连起来的唯一办法。
```

## 9. 模型选择训练 3 步

```text
第 1 步：识别
  · 学生读题 → 圈出已知量和待求量
  · 学生判断：题目里出现了哪些物理量？

第 2 步：选择
  · 学生选：用哪一类模型？
  · 学生验证：这个模型的适用条件满足吗？
    （最关键的一问：F浮 = G物 的前提是什么？欧姆定律用在小灯泡上要注意什么？）

第 3 步：应用
  · 学生列出关键式子
  · 学生求解
  · 学生检验（单位、数量级、物理意义）
```

## 12. 初高衔接（⚠高中）

下列模型**不在初中课标范围**。老师备课时若从课外资料上取到，不要放进初中课堂；学生问起时一句话说明"这是高中内容"即可。

| ⚠高中 模型 | 关键式子（仅供老师识别） | 初中的替代 |
|---|---|---|
| ⚠高中 匀变速直线运动 | v=v₀+at；s=v₀t+½at²；v²−v₀²=2as | 模型 1：只算平均速度 |
| ⚠高中 牛顿第二定律 | F=ma | 模型 2：二力平衡 |
| ⚠高中 力的正交分解 | Gx=mg sinθ，Gy=mg cosθ | 模型 2：斜面只比较拉力与重力、算机械效率 |
| ⚠高中 动量与动量守恒 | m₁v₁+m₂v₂=m₁v₁′+m₂v₂′ | 碰撞题只作定性描述，不列守恒式 |
| ⚠高中 动能定理 | W合 = ΔEk | 模型 5：只作能量转化的定性分析 |
| ⚠高中 机械能守恒的定量方程 | Ek+Ep = 常数 | 模型 5：动能与重力势能相互转化（定性） |
| ⚠高中 万有引力与天体运动 | F = GMm/r² | 不涉及 |
| ⚠高中 简谐运动与单摆周期 | T = 2π√(L/g) | 累积法测心跳一次的时间 |
| ⚠高中 闭合电路欧姆定律 | I = E/(R+r)，含电源内阻 | 模型 4：电源电压视为不变 |
| ⚠高中 电场强度与场的模型 | E = F/q | 不涉及 |

> 💡 **小智说：** 选模型的能力，是靠"验证适用条件"练出来的，不是靠背模型清单。每次讲题多问一句"这个式子凭什么能用"，比多讲三道题有用。
