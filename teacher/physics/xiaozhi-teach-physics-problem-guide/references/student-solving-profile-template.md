# 学员物理解题档案模板

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-physics-problem-guide` 使用。
> **只用化名或座号**，不记真实姓名、联系方式、家庭信息。掌握度词表用 `shared/vocab.md §6` 的老师端五档；错因词表用 `shared/vocab.md §3` 的老师端七类；本模板不另立词表。
> 本档案存放在 `classWorkspace` 之外的老师本地笔记中；只有向学生端写回时才走 `teacher_writeback` 交接，且必须先核对授权位 teacherWritebackConsent。

---

## 一、五步能力档案

每一步用 `shared/vocab.md §6` 的老师端五档记录，不打分数、不排名。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧮 解题档案 · [学员化名/座号]     记录日期：[YYYY-MM-DD]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 第一步 审题        ：[已掌握 / 基本理解 / 仍需巩固 / 需要重讲 / 证据不足]
    观察到的事实：[如"三次作业里两次漏掉'匀速'这个条件"]

■ 第二步 建模        ：[五档之一]
    · 选模型          ：[五档之一]  例：能分清"用阿基米德原理"还是"用浮沉条件"
    · 简化与忽略      ：[五档之一]  例：知道题目说"不计绳重和摩擦"意味着什么
    · 画图            ：[五档之一]  例：电路题是否先画等效电路图

■ 第三步 过程分析     ：[五档之一]
    · 受力分析        ：[五档之一]  例：漏画摩擦力/浮力的频次
    · 状态分析        ：[五档之一]  例：能否判断"静止/匀速/变速"
    · 多状态分析      ：[五档之一]  例：开关或滑片改变后是否重画电路

■ 第四步 列式        ：[五档之一]
    · 选规律          ：[五档之一]
    · 式子完整        ：[五档之一]  例：是否漏掉"电源电压不变"这一条

■ 第五步 求解与检验   ：[五档之一]
    · 单位换算        ：[五档之一]  例：cm²→m²、min→s
    · 结果检验        ：[五档之一]  例：是否检查数量级与物理意义

■ 反思与变式         ：[五档之一]
    · 能说出"换个条件会怎样"：[五档之一]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**证据要求**：每一档都要写出至少一条可核查的事实（哪次作业、哪道题、什么表现）。**只有一次观察时一律记"证据不足"**，不写入长期结论。

## 二、错因计次（老师端七类，shared/vocab.md §3）

一道题只归一类；判定互斥规则同 §3（"看错数字"归审题错误，不归习惯性失误）。

```text
■ 近 4 周错因计次
  · 知识漏洞          ：[N] 次   典型：[一句话]
  · 规则错误          ：[N] 次   典型：[一句话]
  · 计算错误          ：[N] 次   典型：[一句话]
  · 审题错误          ：[N] 次   典型：[一句话]
  · 策略错误          ：[N] 次   典型：[一句话]
  · 表达/书写不规范    ：[N] 次   典型：[一句话]
  · 习惯性失误        ：[N] 次   典型：[一句话]

■ 对应的通用四维（写回学生端时用这一列）
  知识漏洞、规则错误 → 概念模糊
  计算错误、习惯性失误 → 计算失误
  审题错误 → 读题失误
  策略错误、表达/书写不规范 → 方法用错
```

## 五、使用与共享规则

- 本档案供老师备课与教研使用，**不用于给学生打分、排名或公开点评**。
- 需要与家长沟通时，只输出事实描述，不带心理标签；且必须经老师判断确有沟通必要。
- 向学生端学习档案写回时：`handoverType` 取 `teacher_writeback`，负载用 `teacherWritebackData`，只带 `studentAlias`、`weakKnowledgePointUpdates`（subject / knowledgePoint / status / masteryLevel）与 ≤200 字低敏 note；**发送前核对授权位 teacherWritebackConsent 为 true**，否则不发送并告知老师。
- 学生或监护人要求查看、更正、删除本档案时，按 `shared/platform-conventions.md` 第四节的控制入口处理。

> 💡 **小智说：** 档案的价值在"证据"两个字。写不出具体是哪道题的哪一步，就先记"证据不足"，别急着下结论。
