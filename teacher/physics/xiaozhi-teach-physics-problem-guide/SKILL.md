# 物理解题教学指导 SKILL

> **一句话定位：** 物理解题不是"套公式"，而是"建模型"——五步解题法是核心。

## 一、核心使命

物理解题教学常见的三个误区：

```text
误区① 解题=套公式：学员记公式，
        不会建模型，不会分析过程。

误区② 解题=算对：学员只关心"答案对不对"，
        不关心"思路对不对"、"模型对不对"。

误区③ 解题=刷题：让学员做大量题，
        学员没建立"五步法"，没掌握"建模"。
```

本 SKILL 要解决的是：
- **让解题"有方法"**：五步物理解题法
- **让建模"有思路"**：模型选择+简化+建构
- **让过程"有分析"**：受力+运动+能量
- **让解后"有反思"**：结果+过程+拓展
- **让训练"有变式"**：一题多解+多题一解+改条件

## 四、五步解题法

### 4.1 五步总览

```text
① 审题：明确场景/已知/求
② 建模：选择/简化/建构
③ 过程分析：受力/运动/能量
④ 列方程：规律/关系/约束
⑤ 求解：数学/讨论/检验
+ 反思（贯穿始终）
```

### 4.2 第一步 · 审题

```text
■ 三读
  · 一读：场景（讲什么）
  · 二读：已知（给什么）
  · 三读：求（求什么）

■ 关键动作
  · 划关键词
  · 标已知量
  · 标未知量
  · 标隐藏条件

■ 学员常见问题
  · 不读题
  · 漏看条件
  · 看错问题
```

### 4.3 第二步 · 建模

```text
■ 模型选择（初中五类）
  · 匀速与平均速度 / 二力平衡与简单机械 /
    压强与浮力 / 电路（含动态电路）/ 功、功率与能量转化

■ 简化
  · 哪些因素在初中可以忽略（绳重、摩擦、容器壁厚）？
  · 哪个物理量是题目真正要的？

■ 建构
  · 画图（受力图 / 运动过程图 / 等效电路图 / 光路图）
  · 标已知量、未知量、单位

■ 学员常见问题
  · 不会选模型（例：对下沉物体也用 F浮=G物）
  · 不会简化（例：把容器形状当成液体压强的影响因素）
  · 不会画图（例：不画等效电路就直接列式）
```

### 4.4 第三步 · 过程分析

```text
■ 受力分析
  · 画受力图：重力 → 接触力（支持力/拉力/浮力）→ 摩擦力
  · 每个力标出大小、方向和施力物体

■ 运动/状态分析
  · 静止、匀速直线，还是速度在变？
  · 电路题：开关或滑片改变后，电路结构变成什么样？

■ 能量分析
  · 找能量转化（电能→内能、机械能→内能、重力势能↔动能）
  · 标出有用功、额外功、总功

■ 学员常见问题
  · 受力分析错、漏力（最常漏：摩擦力、浮力）
  · 多画说不出施力物体的力（"下滑力""惯性力"）
  · 电路状态改变后没重画等效电路
  （力的正交分解属 ⚠高中 内容，初中不作要求，见文末"初高衔接"）
```

### 4.5 第四步 · 列方程

```text
■ 规律式（初中常用）
  · 速度 v=s/t；平均速度 v̄=s总/t总
  · 二力平衡 F₁=F₂；重力 G=mg（g 取 10 N/kg）
  · 压强 p=F/S；液体压强 p=ρgh
  · 阿基米德原理 F浮=ρ液gV排；称重法 F浮=G物−F示
  · 杠杆平衡条件 F₁L₁=F₂L₂；滑轮组 F=(G物+G动)/n
  · 欧姆定律 I=U/R；串联 U=U₁+U₂、R=R₁+R₂；并联 I=I₁+I₂
  · 电功 W=UIt；电功率 P=UI=I²R=U²/R；焦耳定律 Q=I²Rt
  · 热量 Q=cmΔt；燃料放热 Q=mq
  · 功 W=Fs；功率 P=W/t；机械效率 η=W有/W总

■ 几何/数量关系
  · 路程的加减（过桥、相遇、追及）
  · 面积换算（cm²→m² 除以 10000）
  · 体积与质量（ρ=m/V）

■ 约束条件
  · 绳只能拉不能推
  · 电表量程与滑动变阻器的规格（"最大不超过…"）
  · 物理量非负、人数/件数为整数

■ 学员常见问题
  · 不知道用哪个规律
  · 漏列一个关系式（常见：漏掉电源电压不变这一条）
  · 单位没统一就代入
```

### 4.6 第五步 · 求解

```text
■ 数学求解
  · 解方程
  · 代入数据
  · 算结果

■ 讨论
  · 结果是否合理
  · 是否多解
  · 特殊情况

■ 检验
  · 单位
  · 数量级
  · 极限情况

■ 学员常见问题
  · 算错
  · 没讨论
  · 没检验
```

### 4.7 反思

```text
■ 结果反思
  · 答案对吗
  · 单位对吗
  · 数量级对吗

■ 过程反思
  · 思路对吗
  · 模型对吗
  · 方程对吗

■ 拓展反思
  · 一题多解
  · 改条件
  · 联系实际
```

## 六、过程分析专项

### 6.1 受力分析三步

```text
① 画重力（竖直向下，作用在重心）
② 找接触力：支持力（垂直接触面）/ 拉力（沿绳）/ 弹力 / 浮力（竖直向上）
③ 找摩擦力（沿接触面，方向与相对运动或相对运动趋势相反）

■ 关键
  · 一次画一个，不要漏
  · 每个力都要说得出施力物体，说不出就是多画的
  · 画完检查：静止或匀速时，同一直线上的两个力应当能配成一对
```

### 6.2 运动分析三步

```text
① 判断运动性质
  · 匀速/匀加速/匀减速/曲线

② 分解运动
  · 水平 + 竖直
  · 或：径向 + 切向

③ 标运动参量
  · 初速度
  · 加速度
  · 方向
```

### 6.3 能量分析三步

```text
① 找能量初态
  · 初动能
  · 初势能
  · 初其他能量

② 找能量末态
  · 末动能
  · 末势能
  · 末其他能量

③ 找能量转化
  · 哪个能量增加
  · 哪个能量减少
  · 减少的 = 增加的 + 损失
```

## 七、变式训练

### 7.1 变式三类型

```text
┌──────────┬────────────────────────┬──────────────┐
│ 类型      │ 描述                    │ 训练目标      │
├──────────┼────────────────────────┼──────────────┤
│ 一题多解  │ 一道题多种解法          │ 思维灵活性    │
│ 多题一解  │ 多道题同一种方法        │ 方法识别      │
│ 变条件    │ 改变题目条件/问题       │ 思维深度      │
└──────────┴────────────────────────┴──────────────┘
```

### 7.2 物理解题变式

```text
■ 改条件
  · 水平面 → 换成粗糙程度不同的表面（探究摩擦力）
  · 物体浸没 → 改为部分浸入（V排 变，F浮 变）
  · 清水 → 换成盐水（ρ液 变）
  · 定值电阻 → 换成小灯泡（电阻随温度变，不能求平均）
  · 一个开关 → 加第二个开关（多状态电路）

■ 改问题
  · 求浮力 → 求物体密度
  · 求电流 → 求电功率 → 求通电时间内产生的热量
  · 求某段速度 → 求全程平均速度
  · 求动力 → 求动力臂 / 求机械效率

■ 改情境
  · 弹簧测力计挂物入水 → 改成量筒排水法测体积
  · 滑轮组绕法从 2 段绳改为 3 段绳
  · 电路图从"两电阻串联"改为"两电阻并联"
  · 从表格数据判断规律 → 改为从图像判断规律
```

## 八、错因分析

### 8.1 物理解题错因

老师端**只用** `shared/vocab.md §3` 的七类错因；本 SKILL 不另立词表。物理情境下的常见表现如下：

| 老师端七类（§3） | 物理常见表现 | 通用四维（§1） | 物理五维（§2） |
|---|---|---|---|
| 知识漏洞 | 不知道浮力与深度无关；不知道并联各支路电压相同 | 概念模糊 | C 概念混淆 |
| 规则错误 | 对下沉物体用 F浮=G物；力臂量成支点到作用点 | 概念模糊 | C 概念混淆 |
| 计算错误 | cm² 未换成 m²；两位小数进位错 | 计算失误 | T 数学工具 |
| 审题错误 | 漏掉"匀速""浸没""不计绳重"；看错电表量程 | 读题失误 | R 过程分析（审题部分） |
| 策略错误 | 不画等效电路直接列式；多状态电路只分析一个状态 | 方法用错 | P 图景建立 / R 过程分析 |
| 表达/书写不规范 | 只写数字不写公式；结论不写前提条件；漏单位 | 方法用错 | F 公式误用 |
| 习惯性失误 | 抄错自己上一行的中间结果 | 计算失误 | T 数学工具 |

判定互斥规则同 §3：一道题只归一类；"看错数字"归审题错误，不归习惯性失误。

> 写回学生端时（`teacher_writeback`，需 `teacherWritebackConsent`）只传通用四维；物理五维供本班教研讨论使用，不进入交接字段。

### 8.2 五步对应错因

```text
· 审题这一步出问题 → 审题错误
· 建模这一步出问题 → 策略错误（模型选错）或 规则错误（适用条件记错）
· 过程分析出问题   → 策略错误（漏画/漏状态）
· 列式出问题       → 知识漏洞（不知道该用哪条规律）或 规则错误
· 求解出问题       → 计算错误
· 书写与结论出问题 → 表达/书写不规范
```

### 10.2 接口

数据契约唯一来源：`teacher/general/schemas/class-teaching-workspace.schema.json`（根对象记作 `classWorkspace`）。

```text
读：
  classWorkspace.classProfile          → 年级、班额、每节课分钟数、教材版本、卷面满分
  classWorkspace.weaknessRank          → 本班顽固弱项排序（knowledgePoint / errorRate /
                                          dimension / stubbornCount），决定讲哪道题
  classWorkspace.lessonPlans           → 本课的 topic 与 objectives，保证讲题与教学目标对齐
  classWorkspace.itemStats             → 逐题难度 pValue 与区分度 dValue，找出"该讲的题"
  classWorkspace.studentTiers          → A/B/C 分层，决定变式题给谁

写（均生成待确认条目，老师确认后落库）：
  classWorkspace.lessonPlans[].questionChain      → 本题的提问链（按 cognitiveLevel 递进）
  classWorkspace.lessonPlans[].segments[].tierVariants
                                                  → A/B/C 三层的变式题安排
  classWorkspace.homeworkAssignments[].tasks[]    → 课后变式训练（knowledgePoint /
                                                     cognitiveLevel / difficultyBand /
                                                     tier / estimatedMinutes）
  classWorkspace.weaknessRank[]                   → 讲题中新发现的弱项条目

写回学生端（可选，走 handover-protocol.schema.json）：
  handoverType 取 teacher_writeback，负载用 teacherWritebackData，
  只带 studentAlias、weakKnowledgePointUpdates（subject / knowledgePoint /
  status / masteryLevel）与 ≤200 字的低敏 note；
  发送前必须核对授权位 teacherWritebackConsent 为 true，否则不发送并告知老师。
```

> 本 SKILL 不写考试蓝图 examBlueprints（命题在老师通用测评 SKILL），也不写逐题得分 itemScores（阅卷录入）。
