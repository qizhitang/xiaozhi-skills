## 一、核心使命

物理实验教学常见的三个误区：

```text
误区① 实验=走过场：演示实验老师做，
        学生实验按"标准步骤"做，
        学员没真正"探究"。

误区② 实验=记数据：学员只关心"数据对不对"，
        不会分析数据、不会找规律。

误区③ 实验=验证：实验只是为了"验证"已知规律，
        没让学员"发现"规律。
```

本 SKILL 要解决的是：
- **让实验"有目标"**：验证/探究/测量 三类
- **让实验"有设计"**：变量控制+器材选择+步骤
- **让数据"有分析"**：表格+图像+误差
- **让报告"有深度"**：结构+规范+反思
- **让实验"有探究"**：让学员"发现"规律

## 四、实验目标（三类）

### 4.1 三类实验

```text
┌──────────┬────────────────────────┬──────────────┐
│ 类型      │ 描述                    │ 目的          │
├──────────┼────────────────────────┼──────────────┤
│ 验证性    │ 验证已知规律            │ 加深理解      │
│ 探究性    │ 探究未知规律            │ 培养能力      │
│ 测量性    │ 测量物理量              │ 学会方法      │
└──────────┴────────────────────────┴──────────────┘
```

### 4.2 按分层安排自主程度（A/B/C 口径同 classWorkspace.studentTiers）

**分层调的是"自主程度"和"支架多少"，不是"探究还是不探究"。** 所有层次的学生都应该做探究性实验——课标要求的 21 个学生必做实验里，探究类有 11 个（清单见 references/experiment-types.md §12）。

```text
■ A 层（需补基础）
  · 同样做探究，但给到"半成品"支架：
    表格已画好表头、变量已列出、步骤给前两步让学生补后面
  · 器材连接先由老师检查一遍再通电/加热
  · 侧重：读数准确、记录完整

■ B 层（达标）
  · 给出探究问题和器材，步骤由学生自己排
  · 表格自己设计，老师只检查"变量控制对不对"
  · 侧重：控制变量、数据处理

■ C 层（可拓展）
  · 只给探究问题，器材自选、方案自定
  · 追加一问："你这个方案有什么系统误差？怎么改进？"
  · 侧重：方案评价与改进
```

### 4.3 验证 vs 探究

```text
■ 验证性
  · 规律已经讲过，实验是为了"证实"
  · 适用：规律本身超出学生可探究范围，或课时实在不够
  · 风险：学生知道答案，容易"凑数据"

■ 探究性
  · 规律还没讲，实验是为了"发现"
  · 适用：课标列为"探究"的实验（探究影响滑动摩擦力的因素、
    探究浮力的大小、探究电流与电压/电阻的关系……）
  · 这类实验**不能**因为学生基础弱就改成验证

■ 教学建议
  · 课标写"探究"的，就按探究上；基础弱的班级用 A 层支架，而不是改成验证
  · 课标写"测量/练习使用"的（测密度、伏安法测电阻），本身是测量性实验
  · 同一个课题可以先探究后验证：先做出结论，再用另一组器材复核
  · 常见教学失误：把"基础弱"当成"只做验证"的理由——
    学生越弱，越需要亲手发现一次，只是需要更多支架
```

## 五、实验设计

### 5.1 实验设计四要素

```text
① 实验目的
  · 验证/探究/测量什么

② 实验原理
  · 用什么物理规律

③ 实验器材
  · 选什么器材

④ 实验步骤
  · 怎么操作
```

### 5.2 变量控制

```text
┌──────────┬────────────────────────┐
│ 变量      │ 描述                    │
├──────────┼────────────────────────┤
│ 自变量    │ 主动改变的量            │
│ 因变量    │ 随自变量变化的量        │
│ 控制变量  │ 保持不变的量            │
└──────────┴────────────────────────┘
```

### 5.3 实验设计原则

```text
■ 变量控制
  · 一次只改变一个变量
  · 其他保持不变

■ 多次测量
  · 减少偶然误差
  · 数据更可靠

■ 范围合理
  · 数据要覆盖到能看出规律的区间（至少 5-6 组）
  · 不超电表量程、不超测力计量程、不超温度上限

■ 安全第一
  · 每个实验先定 safetyLevel（三档见 references/experiment-types.md）
  · "高"档一律改演示；"中"档必须老师全程在场并逐组检查装置
```

### 5.4 课堂约束（排实验课前必须先算的三笔账）

数字全部来自 `classWorkspace.classProfile`，不要凭印象估。

```text
① 器材账
   需要的套数 = ⌈班额 classSize ÷ 每组人数⌉ + 1~2 套备用
   每组人数取 2-4 人（经验值）：
     · 班额 ≤ 30 → 每组 2 人，约 15 套
     · 班额 31-45 → 每组 3 人，约 11-15 套
     · 班额 46-60 → 每组 4 人，约 12-15 套
     · 班额 > 60 → 优先轮换制，不建议一次全班分组
   器材不够的三条退路（按优先级）：
     轮换制 → 拼组并分配角色 → 降级为演示+全班数据处理（下策）

② 时间账（初中一节课 periodMinutes 默认 45 分钟）
   复习与明目的 5 + 讲操作与安全 5 + 分发检查 5 +
   动手记录 18 + 数据处理 7 + 归还小结 5 = 45
   分发与归还合计 10 分钟是硬开销，排课时不能不算
   一节课装不下时：把数据处理挪到下一课时或课后作业，
   不要压缩"动手记录"的 18 分钟

③ 角色账（每组人人有事做）
   操作员 / 读数员 / 记录员 / 计时员 / 复核员
   3 人组：操作 + 读数记录 + 复核计时
   中途至少轮换一次角色，避免总是同一个人动手
```

> 📎 完整样板见 `references/experiment-design-sample.md`（探究电流与电压、电阻的关系：目的/原理/器材/变量/步骤 全流程范例）

## 六、实验实施

### 6.1 演示实验实施

```text
■ 老师操作
  · 边做边讲
  · 关键步骤强调

■ 学员观察
  · 学员看现象
  · 学员听讲解
  · 学员记录

■ 老师引导
  · 学员预测
  · 学员描述
  · 学员总结
```

### 6.2 学生实验实施

```text
■ 学员操作
  · 学员亲自做
  · 学员合作
  · 老师巡回指导

■ 老师角色
  · 监督安全
  · 答疑解惑
  · 引导探究

■ 时间分配（经验值，见 §5.4 的时间账）
  · 讲解与安全提示约 10 分钟
  · 学生动手与记录约 18 分钟
  · 数据处理与小结约 7 分钟
  · 器材分发与归还约 10 分钟（硬开销，不能不算）
  · 时间不够时优先压缩数据处理（可挪到课后），
    不压缩学生动手
```

### 6.3 实验注意事项

```text
■ 安全（按 safetyLevel 分档执行）
  · 低：老师巡视即可
  · 中：课前讲安全要点 + 老师全程在场 + 每组第一次操作前老师确认装置
  · 高：只作演示，学生保持安全距离；或改用视频/仿真

■ 规范
  · 操作规范：接线先断开开关、天平先调平、量筒平视读数
  · 记录规范：表头写量与单位、当场记录、不涂改原始数据
  · 报告规范：结论带前提条件

■ 节约
  · 不浪费器材，用后归位
  · 破损当场报备，不隐瞒

■ 合作
  · 每组按角色分工，中途轮换
  · 不允许一人做、其他人抄
```

```text
  · 用更精密的仪器

■ 严格操作
  · 减少错误
  · 规范步骤
```

### 9.3 实验报告评分

```text
│ 数据记录  │ 表头有量与单位、有效数字  │ 20%          │
│           │ 规范、不改数据           │              │
│ 数据分析  │ 图像/计算过程完整、       │ 25%          │
│           │ 异常点有说明             │              │
│ 实验结论  │ 结论带前提条件，          │ 20%          │
│           │ 区分"实验结论"与"推理结论"│              │
│ 反思讨论  │ 误差来源与改进方向        │ 10%          │

段落数以 references/lab-report-template.md 为准（8 段），本表逐段对应。
```

### 11.2 接口

```text
读：
  classWorkspace.classProfile     → 年级、班额 classSize、每节课分钟数 periodMinutes、
                                     教材版本；分组人数与器材套数都由这里推出来
  classWorkspace.lessonPlans      → 本课的 topic / objectives / segments，
                                     实验环节要嵌进已有的时间分配里
  classWorkspace.weaknessRank     → 本班弱项，决定这次实验重点练哪一环
  classWorkspace.studentTiers     → A/B/C 分层，决定给多少支架
  classWorkspace.interactionLogs  → 上一次实验课的实际用时 segmentTimings、
                                     观察到的迷思 misconceptionsObserved、
                                     下次调整 adjustmentForNext
                                     —— 这是与课堂教学教练的实际衔接点：
                                     排本次实验的分钟数、决定哪一步要多讲，都先读它

写（均生成待确认条目，老师确认后落库）：
  classWorkspace.lessonPlans[].segments[]      → 实验各环节的名称与分钟数
                                                （含分发与归还器材的固定开销）
  classWorkspace.lessonPlans[].segments[].tierVariants
                                               → A/B/C 三层的支架差异
  classWorkspace.lessonPlans[].questionChain   → 实验前后的提问链
  classWorkspace.homeworkAssignments[].tasks[] → 实验后的数据处理任务
  classWorkspace.weaknessRank[]                → 实验中新发现的操作类弱项
```

**上一次实验课的反馈怎么用**（读 `classWorkspace.interactionLogs` 的三步）：

```text
① segmentTimings：哪一环节 actualMinutes 超了
   → 本次把它的分钟数调大；若是"分发器材"超时，改为课前预置到各组桌面
② misconceptionsObserved：上次学生真实卡住的地方
   → 写进本次的"操作要点讲解"，或做成一个反例演示
③ adjustmentForNext：上次课后自己写下的调整
   → 逐条落到本次的 segments 或 questionChain
interactionLogs 为空时跳过本步，并在方案里注明"无上次反馈"。
```

> 本 SKILL 不写考试蓝图 examBlueprints、不写逐题得分 itemScores。

## 十三、行为准则

| ✅ 应该做 | ❌ 不能做 |
|---------|---------|
| 实验三类（验证/探究/测量） | 实验=走过场 |
| 变量控制 | 一次多变量 |
| 数据处理（表格/图像/计算） | 实验=记数据 |
| 结论归纳（规律/讨论/反思） | 结论=抄数据 |
| 报告规范 | 实验=验证 |
| 学员实验档案累积 | 学员不积累 |
| 学员化名 | 公开批评学员实验 |
| 标注 safetyLevel | 推荐危险实验 |
