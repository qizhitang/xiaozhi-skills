# 实验报告模板与评分细则（8 段）

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-physics-experiment-coach` 使用。从"抄数据"到"真探究"。
> 实验报告固定 **8 段**：目的 / 原理 / 器材 / 步骤 / 数据记录 / 数据分析 / 实验结论 / 反思讨论。填好的完整示例见 `lab-report-sample.md`。
> 下面的占比是**经验值**，供老师参考，可按本校要求调整；本 SKILL 不替老师给报告打分。

## 1. 实验报告结构（8 段）

```text
1. 实验目的
2. 实验原理
3. 实验器材
4. 实验步骤
5. 数据记录
6. 数据分析
7. 实验结论
8. 反思讨论
```

## 2. 评分维度

```text
┌──────────┬────────────────────────────────┬──────────────┐
│ 段落      │ 看什么                          │ 占比（经验值）│
├──────────┼────────────────────────────────┼──────────────┤
│ 实验目的  │ 探究什么 / 测量什么，写清楚      │ 5%           │
│ 实验原理  │ 用了哪条规律、哪种方法           │ 10%          │
│ 实验器材  │ 型号与量程写全（并入步骤一起看）  │ —            │
│ 实验步骤  │ 可复现，控制变量交代清楚         │ 10%          │
│ 数据记录  │ 表头有量与单位、不涂改原始数据    │ 20%          │
│ 数据分析  │ 图像/计算完整，异常点有说明       │ 25%          │
│ 实验结论  │ 带前提条件，区分实验结论与推理结论 │ 20%          │
│ 反思讨论  │ 误差来源与改进方向               │ 10%          │
└──────────┴────────────────────────────────┴──────────────┘
```

八段与 SKILL.md §9.3 的权重表一致，两处不要各写一套。

## 3. 各维度评分细则

### 3.1 实验目的（5%）

```text
■ 优
  · 目的明确
  · 与物理概念相关
  · 包含验证/探究/测量目标

■ 良
  · 目的基本明确
  · 与概念相关

■ 合格
  · 目的不够明确
  · 写得简单

■ 差
  · 目的不清
  · 偏离物理
```

### 3.2 实验原理（10%）

```text
■ 优
  · 原理正确
  · 公式/规律清晰
  · 与实验目的一致

■ 良
  · 原理基本正确
  · 公式/规律基本清晰

■ 合格
  · 原理有缺漏
  · 公式/规律部分正确

■ 差
  · 原理错
  · 公式/规律不清
```

### 3.3 实验步骤（10%）

```text
■ 优
  · 步骤完整
  · 顺序合理
  · 安全规范

■ 良
  · 步骤基本完整
  · 顺序基本合理

■ 合格
  · 步骤部分缺失
  · 顺序有问题

■ 差
  · 步骤混乱
  · 不安全
```

### 3.4 数据记录（20%）

```text
■ 优
  · 表格规范
  · 单位正确
  · 多次测量
  · 数据完整

■ 良
  · 表格基本规范
  · 单位基本正确
  · 数据基本完整

■ 合格
  · 表格不规范
  · 单位有缺漏
  · 数据部分缺失

■ 差
  · 表格混乱
  · 单位错误
  · 数据不完整
```

### 3.5 数据分析（25%）

```text
■ 优
  · 表格规范
  · 图像清晰
  · 计算正确
  · 找规律
  · 数学表达

■ 良
  · 表格基本规范
  · 图像基本清晰
  · 计算基本正确
  · 找规律

■ 合格
  · 表格不规范
  · 图像有问题
  · 计算有错
  · 规律不清

■ 差
  · 数据分析缺失
  · 找不出规律
```

### 3.6 实验结论（20%）

```text
■ 优
  · 结论准确
  · 与数据一致
  · 有物理意义
  · 适用范围

■ 良
  · 结论基本准确
  · 与数据基本一致
  · 有物理意义

■ 合格
  · 结论部分准确
  · 与数据部分一致

■ 差
  · 结论错
  · 与数据不符
```

### 3.7 反思讨论（10%）

```text
■ 优
  · 反思有想法
  · 误差分析
  · 改进方向
  · 拓展思考

■ 良
  · 反思基本有想法
  · 误差有讨论
  · 改进有方向

■ 合格
  · 反思简单
  · 误差分析不深

■ 差
  · 反思缺失
  · 没误差分析
```

## 5. 评分原则

```text
■ 关注过程
  · 不只看结果
  · 关注"怎么想"

■ 鼓励反思
  · 反思有想法加分
  · 改进有方向加分

■ 关注数据
  · 数据记录规范
  · 数据分析有深度

■ 关注报告
  · 报告结构完整
  · 内容充实
```

## 6. 分层要求（口径同 classWorkspace.studentTiers 的 A/B/C）

分层调的是**要求的高度**，不是"给谁多打几分"。

```text
■ A 层（需补基础）
  · 必须达到：步骤可复现、表头写对、原始数据不涂改
  · 暂不强求：分析深度、误差方向的判断
  · 支架：表格表头先印好，误差来源给出选项让学生勾选

■ B 层（达标）
  · 必须达到：控制变量交代清楚、图像规范、结论带前提条件
  · 加分：说得出误差方向（偏大还是偏小）

■ C 层（可拓展）
  · 必须达到：结论区分"实验结论"与"推理结论"
  · 加分：提出可操作的方案改进，并说明改进后误差往哪个方向变
```

## 7. 评分反馈话术

```text
■ 肯定
  · "你的数据记录很规范"
  · "你的图像画得清楚"
  · "你的结论准确"

■ 改进（指出具体位置，不用笼统评价）
  · "第 5 段表头缺单位，U 和 I 各是什么单位？"
  · "第 7 段结论少了前提——在什么条件下成立？"
  · "第 8 段说了误差来源，但没说会让结果偏大还是偏小"
  · "这几次测的其实是不同温度下的电阻，不能求平均"

■ 鼓励（指向具体行为，不空夸）
  · "你把异常的那一组单独说明了，这一点做得好"
  · "结论里写了'在电阻一定时'，前提条件抓住了"
  · "你自己想到了改进办法，而且是能真做的"

■ 不要用的评语
  · "分析可以更深一点"（学生不知道怎么才叫深）
  · "态度不端正"（评人不评事）
  · "优 / 良 / 差"（笼统标签，没有信息量）
```
