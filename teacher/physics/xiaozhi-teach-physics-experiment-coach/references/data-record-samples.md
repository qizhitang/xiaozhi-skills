# 数据记录样板（数据表格 + 数据图像）

> 适用学段：初中（7-9 年级）。
> 示例题验算：2026-09-03
> 配合 `xiaozhi-teach-physics-experiment-coach` 使用。评分锚点见 `data-processing-rubric.md`，本文只给可以直接印发给学生的空白表与填好的样例。

---

## 一、表格设计的四条规矩

```text
① 表头写"量的符号 / 单位"，如 U / V、I / A、m / g、V / cm³
   —— 不要写成 "电压 V(V)"，电压的符号是 U，V 是伏特这个单位
② 每一行是一次完整的测量，不要把两次数据挤在一行
③ 原始数据当场填，不涂改；算出来的量（如 R、ρ）单独占一列
④ "平均"这一行**不是每张表都有**——判断标准见下面第三节
```

## 三、"平均"行填不填？

```text
能求平均（同一个量重复测多次，为减小偶然误差）：
  · 定值电阻的阻值
  · 物体的长度、质量
  · 同一段路程的多次计时

不能求平均（每次测的其实是不同的量）：
  · 小灯泡在不同电压下的电阻 —— 温度不同，本就是不同的电阻
  · 不同深度处的液体压强
  · 不同路段的速度
  · 探究类实验中"改变自变量后"的各组因变量
```

## 四、填好的样例

**样例 1：伏安法测定值电阻（可求平均）**

```text
 次数 │ U / V │ I / A │ R / Ω
──────┼───────┼───────┼───────
  1   │ 1.0   │ 0.10  │ 10.0
  2   │ 2.0   │ 0.20  │ 10.0
  3   │ 3.0   │ 0.29  │ 10.3
  4   │ 4.0   │ 0.40  │ 10.0
  5   │ 5.0   │ 0.51  │  9.8
──────┼───────┼───────┼───────
 平均 │   —   │   —   │ 10.0
```

**样例 2：测量小灯泡的电功率（不可求平均）**

```text
小灯泡规格 "2.5 V  0.3 A"

 次数 │ U / V │ I / A │ R / Ω │ P / W
──────┼───────┼───────┼───────┼───────
  1   │ 1.0   │ 0.20  │  5.0  │ 0.20
  2   │ 1.5   │ 0.24  │  6.3  │ 0.36
  3   │ 2.0   │ 0.27  │  7.4  │ 0.54
  4   │ 2.5   │ 0.30  │  8.3  │ 0.75   ← 额定状态
  5   │ 3.0   │ 0.32  │  9.4  │ 0.96

本表无"平均"行：五个 R 对应五个不同的灯丝温度，平均没有意义。
额定功率取额定电压那一行：P额 = 2.5 × 0.30 = 0.75 W。
```

## 五、数据图像样板

```text
■ 画图五步
  ① 定横轴纵轴：横轴放自变量（如 U），纵轴放因变量（如 I）
  ② 标名称与单位：U / V、I / A
  ③ 定标度：让数据点尽量铺满整张图，不要挤在角落
  ④ 描点：用"+"或小圆点，落笔要准
  ⑤ 连线：先看点的分布再决定
       接近一条直线 → 用直尺画直线，让点均匀分布在线两侧
       明显弯曲     → 用光滑曲线，**不要**折线，也不要硬拉直线

■ 三种典型图线
  · 定值电阻的 I-U：过原点的直线 → 可以说"成正比"
  · 小灯泡的 I-U：向上弯曲、越来越平 → 只能说"随…增大"
  · 水沸腾的温度-时间：先上升后出现水平段 → 水平段说明沸腾时温度不变

■ 异常点怎么办
  · 明显偏离趋势的点：保留在图上，但连线时不迁就它
  · 在报告里写一句"第 N 组数据偏离较大，可能原因是…"
  · 不允许直接擦掉或改数
```
