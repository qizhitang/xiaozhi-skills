# 实验设计样板（探究电流与电压、电阻的关系）

> 适用学段：初中（7-9 年级）。
> 示例题验算：2026-09-03
> 配合 `xiaozhi-teach-physics-experiment-coach` 使用。本实验是课标要求的学生必做实验之一（清单见 `experiment-types.md` §12），目的类型为**探究型**、组织形式为**分组**、`safetyLevel: 中`。

---

## 一、完整设计

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧪 实验设计样板 · 探究电流与电压、电阻的关系
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 实验目的
  探究导体中的电流与它两端的电压、导体电阻之间的关系
  （探究性：结论由数据归纳，**不预先告知** I = U/R）

■ 实验原理（方法）
  用控制变量法，分两步：
  ① 保持电阻 R 不变，改变电压 U，测对应的电流 I；
  ② 保持电压 U 不变，换用不同的定值电阻 R，测对应的电流 I。
  I 与 U、R 的定量关系（正比 / 反比）由学生从数据自行归纳，
  不在实验前直接给出 I=U/R 的结论。

■ 实验器材
  · 学生电源（或 3 节干电池）
  · 定值电阻若干（5 Ω、10 Ω、15 Ω、20 Ω 各一）
  · 电流表（0~0.6 A）、电压表（0~3 V）
  · 滑动变阻器（0~20 Ω，1 A）
  · 开关、导线若干

■ 变量
  · 自变量：第①步是电压 U；第②步是电阻 R
  · 因变量：电流 I
  · 控制变量：第①步控制 R 不变；第②步控制 U 不变

■ 实验步骤
  ① 按电路图连接电路：定值电阻与滑动变阻器串联，
     电流表串在干路，电压表并在定值电阻两端
  ② 连接时开关断开、滑片置于阻值最大端（保护电路）
  ③ 第①步：接入 10 Ω 定值电阻，移动滑片使电压表示数依次为
     1.0 V、1.5 V、2.0 V、2.5 V、3.0 V，逐次记录电流
  ④ 第②步：把电压表示数**固定在 2.0 V**，依次换用
     5 Ω、10 Ω、15 Ω、20 Ω 的定值电阻，每换一次都要重新
     移动滑片把电压调回 2.0 V，逐次记录电流
  ⑤ 分别画 I-U 图像与 I-R 图像
  ⑥ 归纳结论
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 二、参考数据（供老师预演与批阅时对照）

**第①步：R = 10 Ω 不变**

```text
 U / V │ 1.0  │ 1.5  │ 2.0  │ 2.5  │ 3.0
 I / A │ 0.10 │ 0.15 │ 0.20 │ 0.25 │ 0.30
 → I-U 图像是过原点的直线，斜率 0.10 A/V
 → 结论：电阻一定时，电流与电压成正比
```

**第②步：U = 2.0 V 不变**

```text
 R / Ω │ 5    │ 10   │ 15   │ 20
 I / A │ 0.40 │ 0.20 │ 0.13 │ 0.10
 → 各组 I·R 分别为 2.0、2.0、1.95、2.0（V），基本是常数
 → 结论：电压一定时，电流与电阻成反比
 → I-R 图像是一条向下弯的曲线，**不是直线**；
    要判断反比，看的是乘积 I·R 是否为常数
```

## 三、教学要点

```text
① 滑动变阻器在这里有两个作用
   · 保护电路（连接时置于最大阻值）
   · 第①步用它改变定值电阻两端的电压
   · 第②步用它**把电压调回同一个值**——这一点学生最容易漏
     换电阻后如果不重新调电压，控制变量就失效了

② 为什么第②步的电压要固定在 2.0 V 而不是 3.0 V
   · 换成 5 Ω 时若 U=3.0 V，则 I=0.6 A，正好卡在电流表满量程
   · 留出余量，取 2.0 V 更稳妥

③ 探究不能变成验证
   · 不要在实验前写出 I=U/R
   · 学生先得到两条分结论，再合起来
   · "验证欧姆定律"这个说法本身就与课标定位冲突

④ 判断反比不能靠"看图像像不像"
   · 反比的图像是曲线，学生容易误判
   · 正确做法：算 I·R 是不是常数
```

## 四、分层安排（口径同 classWorkspace.studentTiers）

```text
■ A 层：表格表头已印好、电路图已给出、第①步的电压值已列出
        重点练：正确连接电路、准确读数
■ B 层：给探究问题与器材，表格自己设计
        重点练：控制变量、从数据归纳
■ C 层：追加一问——"第②步换电阻后为什么必须重新调电压？
        如果不调，得到的结论会偏向哪一边？"
```

## 五、常见问题与处置

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 闭合开关灯不亮、表无示数 | 有断路 | 用电压表逐段查 |
| 电流表指针反偏 | 正负接线柱接反 | 断电后调换 |
| 换电阻后电压变了 | 忘了重新调滑片 | 强调这是控制变量的关键一步 |
| 第②步 I·R 明显不是常数 | 电压没调准 | 回到那一组重测 |
| 数据太"漂亮" | 可能是抄的 | 追问某一组是怎么读出来的 |

> 💡 **小智说：** 这个实验的教学价值一半在"控制变量"，一半在"换了电阻要把电压调回去"。后面那一步做到位了，学生对控制变量的理解才算落地。
