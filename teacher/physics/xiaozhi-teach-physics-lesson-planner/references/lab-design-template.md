# 初中物理实验设计模板

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-physics-lesson-planner` 使用。演示实验是物理教学的核心。
> `safetyLevel` 的三档定义与判定规则见 `../xiaozhi-teach-physics-experiment-coach/references/experiment-types.md`；本文每个实验都按该定义标注。
> 课标要求的学生必做实验清单同样见该文件，本文不重复维护。

## 1. 演示实验选材原则

```text
■ 现象明显
  · 学员能清楚看到
  · 现象有冲击力

■ 容易观察
  · 学员能描述
  · 学员能解释

■ 安全
  · 不涉及危险
  · 不需要特殊防护

■ 可重复
  · 实验可重复
  · 结果稳定
```

## 2. 演示实验流程

```text
① 介绍实验
  · 实验目的
  · 实验器材
  · 实验现象预测

② 操作演示
  · 边做边讲
  · 关键步骤强调
  · 让学员看清

③ 学员观察
  · 学员描述
  · 学员记录
  · 学员提问

④ 引导规律
  · 学员描述现象
  · 老师引导
  · 学员总结
```

### 3.2 力学 · 浮力

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧪 演示实验 · 浮力
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 实验
  弹簧测力计下挂重物
  记录空气中示数 G1
  浸入水中，记录示数 G2
  F 浮 = G1 - G2

■ safetyLevel：低（常温、无电、无火、无锐器）

■ 涉及概念
  · 浮力的存在与大小
  · 称重法（这一步只测出浮力的**数值**，还不是阿基米德原理）

■ 学生观察
  · 浸入水中示数变小
  · 变小了多少 → 就是浮力的大小

■ 引导（关键：不要一步跳到阿基米德原理）
  · 第一步：F浮 = G₁ − G₂，这叫**称重法**，只告诉我们浮力多大
  · 第二步：追问"浮力跟什么有关？" → 换不同液体、换浸入深浅，再测几次
  · 第三步：改用溢水杯把排开的水接出来称重，比较 F浮 与 G排
  · 第四步：多次数据都吻合 → 才归纳出 **F浮 = G排 = ρ液gV排**（阿基米德原理）
  · 常见教学失误：做完称重法就直接宣布"这就是阿基米德原理"——
    称重法没有测排开的液体，推不出这条原理
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 3.8 电学 · 欧姆定律

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧪 演示实验 · 欧姆定律
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 实验
  电源 + **定值电阻** + 电流表 + 电压表 + 滑动变阻器
  移动滑片改变定值电阻两端的电压，逐次记录电流
  以 U 为横轴、I 为纵轴画 I-U 图像

■ safetyLevel：低（低压直流；提醒不要把电流表直接接在电源两极）

■ 涉及概念
  · 电流与电压的关系（控制电阻不变）
  · 欧姆定律 I = U/R
  · 符号规范：电压的符号是 **U**，伏特是单位 V；不要写成"V = IR"

■ 学生观察
  · 电压越大，电流越大
  · 各组数据的 U/I 基本是同一个数
  · I-U 图像是一条**过原点的直线**

■ 引导
  · 先归纳"电阻一定时，电流与电压成正比"
  · 再换一个阻值不同的定值电阻，得到另一条斜率不同的直线
  · 合起来才是欧姆定律 I = U/R
  · 追问：如果把定值电阻换成小灯泡，图线还是直线吗？
    → 不是。灯丝电阻随温度升高而变大，图线会弯，
      而且多次测得的电阻**不能求平均值**
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 3.10 热学 · 比热容

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧪 演示实验 · 比较水和食用油吸热升温的快慢
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 实验
  两只相同的烧杯，分别装**质量相同**的水和食用油
  用相同的电加热器（或相同的酒精灯、相同的火焰）同时加热
  每隔 1 分钟记录一次温度

■ safetyLevel：中（涉及加热与明火/电加热，需老师现场把控，
                  学生佩戴护目用具、油温不超过 60 ℃ 即停止）

■ 涉及概念
  · 比热容
  · 控制变量法（质量相同、加热方式相同、加热时间相同）
  · 转换法（用"加热时间"表示"吸收的热量"）

■ 学生观察
  · 相同时间内，食用油升温比水快
  · 要升到相同温度，水需要加热更久

■ 引导
  · 相同时间 = 吸收的热量相同（这是转换法的关键假设）
  · 同样吸热，水升温少 → 水的"吸热本领"强 → 比热容大
  · 生活联系：沿海地区昼夜温差小；汽车用水做冷却剂
  · 追问：如果两杯液体的质量不一样，这个实验还能得出结论吗？
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 4. 学生实验设计

### 4.1 学生实验选材

```text
■ 简单安全
  · 学生可独立操作，safetyLevel 为"低"或"中"
  · safetyLevel 为"高"的一律改为演示，不进分组
  · 不需要学校没有的器材

■ 数据可靠
  · 学生能测得出
  · 同一组重复两次，结果不会差得离谱

■ 时间合适
  · 一节课内可完成（初中一节课 45 分钟，见 shared/grade-bands.md）
```

### 4.1.1 课堂约束（排实验课前必须先填这张表）

所有数字都来自 `classWorkspace.classProfile`，不要凭印象估。

```text
┌────────────────┬──────────────────────────────────────────────┐
│ 约束项          │ 取值与来源                                     │
├────────────────┼──────────────────────────────────────────────┤
│ 班额            │ classWorkspace.classProfile.classSize          │
│ 一节课时长      │ classWorkspace.classProfile.periodMinutes      │
│                │ （初中默认 45 分钟）                            │
│ 分组人数        │ 每组 2-4 人（经验值）。2 人组人人动手但器材需求  │
│                │ 大；4 人组器材省但容易有人旁观，需分配角色       │
│ 需要的器材套数   │ ⌈班额 ÷ 每组人数⌉，再加 1-2 套备用             │
│ 教材版本        │ classWorkspace.classProfile.textbookVersion    │
│ 本课针对的弱项   │ classWorkspace.weaknessRank 中的条目            │
└────────────────┴──────────────────────────────────────────────┘

【器材不够时的三条退路（按优先级）】
① 轮换制：把班级分成两批，一批做实验、一批做配套的数据分析任务，中途交换
② 拼组：把每组人数上调到 5-6 人，但必须给每人指定角色
   （操作员 / 读数员 / 记录员 / 计时员 / 复核员），并在中途轮换角色
③ 降级为演示 + 全班数据处理：老师做，学生各自记录并处理数据
   —— 这是下策，动手环节没了，要在后续课时补回来

【45 分钟分组实验的时间分配（经验值，可按实际调整）】
  · 复习与明确目的：5 分钟
  · 讲清操作要点与安全事项：5 分钟
  · 分发器材与检查连接：5 分钟
  · 学生动手与记录数据：18 分钟
  · 数据处理与得出结论：7 分钟
  · 归还器材与小结：5 分钟
  → 器材分发与归还合计 10 分钟是**硬开销**，排课时不能不算

【分组人数与班额的对应（经验值）】
  · 班额 ≤ 30：每组 2 人，需 15 套器材
  · 班额 31-45：每组 3 人，需 11-15 套器材
  · 班额 46-60：每组 4 人，需 12-15 套器材
  · 班额 > 60：优先轮换制，不建议一次全班分组
```

## 5. 实验安全与 safetyLevel

三档定义以 `../xiaozhi-teach-physics-experiment-coach/references/experiment-types.md` 为准，本文只写它在教案里的用法：

```text
■ safetyLevel: 低
  · 常温、无电或仅低压直流、无明火、无锐器、无腐蚀性物质
  · 可以放心安排为分组实验，老师巡视即可
  · 例：测平均速度、杠杆平衡、凸透镜成像、串并联电路连接

■ safetyLevel: 中
  · 涉及加热、明火、玻璃器皿、220 V 以下但需接线的电学实验、重物提升
  · 可以分组，但必须：课前讲安全要点 + 老师全程在场 +
    每组第一次操作前老师确认接线/装置无误
  · 例：探究水的沸腾、比较不同物质的吸热能力、伏安法测电阻、
        测小灯泡电功率、滑轮组机械效率

■ safetyLevel: 高
  · 涉及 220 V 家庭电路带电操作、强酸强碱、高压气体、可能飞溅或爆裂的装置
  · **只作演示，不进分组**；老师操作、学生保持安全距离；
    或改用视频、仿真软件
  · 例：家庭电路带电连接（改为断电情况下的模拟板）、
        大气压破坏性演示

【判定顺序】先看有没有 220 V 带电操作或化学品 → 有则"高"；
再看有没有加热、明火、玻璃、通电接线 → 有则"中"；都没有 → "低"。
判不准时就往高一档写。
```

## 6. 实验设计自检

```text
□ 现象明显吗？后排学生能看清吗？
□ 学生能用自己的话描述现象吗？
□ safetyLevel 标了吗？是"高"的话已经改成演示了吗？
□ 实验可重复吗？失败了有备用方案吗？
□ 器材套数够吗（⌈班额÷组人数⌉ + 备用）？
□ 加上分发与归还的 10 分钟，还装得进 45 分钟吗？
□ 实验与本节概念相关吗？针对的是 weaknessRank 里的哪一条？
□ 这个实验是不是课标要求的学生必做实验？（清单见 experiment-types.md）
```
