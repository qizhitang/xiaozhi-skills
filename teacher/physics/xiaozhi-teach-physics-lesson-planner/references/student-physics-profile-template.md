# 班级物理档案模板

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-physics-lesson-planner` 使用。
> **只用班级代号或学生化名/座号**，不记真实姓名、联系方式、家庭信息。
> 掌握度只用 `shared/vocab.md §6` 的老师端五档（已掌握 / 基本理解 / 仍需巩固 / 需要重讲 / 证据不足），**不打分、不用百分比、不排名**。错因只用 `shared/vocab.md §3` 的老师端七类。
> 每一档都要写出可核查的证据（哪次作业/测评的哪几题）。只有一次观察时一律记"证据不足"。

## 二、数据来源与边界

| 本档案的字段 | 来自哪里 |
|---|---|
| 班额、课时、教材版本 | `classWorkspace.classProfile` |
| 各知识点的错误率与顽固次数 | `classWorkspace.weaknessRank` |
| 逐题难度与区分度 | `classWorkspace.itemStats` |
| 逐题得分（生成弱项分析的唯一来源） | `classWorkspace.itemScores` |
| 分层（A/B/C） | `classWorkspace.studentTiers` |
| 课堂上真实出现的迷思 | `classWorkspace.interactionLogs[].misconceptionsObserved` |

**只有总分、没有逐题得分时，不生成逐知识点或逐概念的分析**，在档案中写明"数据不足"。

---

## 三、使用规则

- 本档案供老师备课与教研使用，**不用于给学生打分、排名或公开点评**。
- 不把学生的错题在班内公开展示；讲评时只呈现"这一类错误"，不点名。
- 向学生端学习档案写回时：`handoverType` 取 `teacher_writeback`，负载用 `teacherWritebackData`，只带 `studentAlias`、`weakKnowledgePointUpdates`（subject / knowledgePoint / status / masteryLevel）与 ≤200 字的低敏 note；**发送前核对授权位 teacherWritebackConsent 为 true**，否则不发送并告知老师。
- 需要与家长沟通时只输出事实描述，不带心理标签。
- 学生或监护人要求查看、更正、删除时，按 `shared/platform-conventions.md` 第四节的控制入口处理。

> 💡 **小智说：** 写不出"是哪次作业的哪一题"，就先记"证据不足"。档案的价值在证据，不在结论。
