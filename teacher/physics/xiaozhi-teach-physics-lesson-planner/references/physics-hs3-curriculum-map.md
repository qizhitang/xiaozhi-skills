# 高中物理课程地图：选择性必修

> 适用学段：高中（选择性必修 1、2、3）。
> 本文是 `xiaozhi-teach-physics-lesson-planner` 第十七节的参考资源：选择性必修三个模块各主题的内容要求、教学提示与学业要求（要点），以及学生必做实验。本文只写课程标准层面的结构，不写死任何版本教材的章节与课时。
> 课程依据：《普通高中物理课程标准日常修订版（2017 年版 2025 年修订）》。选择性必修是学业水平等级性考试的范围（必修与选择性必修内容及相关的 21 个学生必做实验，命题不超过学业质量水平 3）；只备合格性考试的班级不进入本文内容。

## 一、高中·选择性必修 1

由"动量与动量守恒定律""机械振动与机械波""光及其应用"三个主题组成。

| 主题 | 内容要求（要点） |
|---|---|
| 1.1 动量与动量守恒定律 | 理解冲量和动量；通过理论推导和实验，理解动量定理和动量守恒定律，能解释生产生活中的有关现象（如火箭发射利用反冲），知道动量守恒定律的普适性；通过实验了解弹性碰撞和非弹性碰撞的特点，定量分析一维碰撞问题 |
| 1.2 机械振动与机械波 | 通过实验认识简谐运动的特征，能用公式和图像描述；通过实验探究单摆的周期与摆长的定量关系，会用单摆测量重力加速度；认识受迫振动的特点，了解共振的条件及应用；认识波的特征，能区别横波和纵波，能用图像描述横波，理解波速、波长和频率的关系；知道波的反射和折射，了解波的干涉与衍射；认识多普勒效应 |
| 1.3 光及其应用 | 理解光的折射定律，会测量材料的折射率；知道光的全反射现象及其条件，初步了解光纤；观察光的干涉、衍射和偏振，知道光是横波，会用双缝干涉实验测量光的波长；了解激光的特性及其应用 |

**教学提示要点**：探究碰撞中的守恒量，经历理论推导和实验验证，理解动量定理与牛顿第二定律的一致性；建构弹性碰撞、简谐运动、单摆等模型，学会用守恒定律解决问题；用光的干涉、衍射现象论证光具有波动性，增强证据意识；从动量守恒定律的普适性认识自然界的统一性。

**学业要求要点**：能用动量和机械能的知识解决一维碰撞问题；能用恰当的物理量描述简谐运动和机械波；知道光的干涉、衍射和偏振，能解释光学现象；能从牛顿运动定律、动量守恒、能量守恒等不同角度思考问题；能完成"用单摆测量重力加速度的大小"等实验。

**学生必做实验**：1. 验证动量守恒定律；2. 用单摆测量重力加速度的大小；3. 测量玻璃的折射率；4. 用双缝干涉实验测量光的波长。

## 二、高中·选择性必修 2

由"磁场""电磁感应及其应用""电磁振荡与电磁波""传感器"四个主题组成。

| 主题 | 内容要求（要点） |
|---|---|
| 2.1 磁场 | 通过实验认识安培力，能判断安培力的方向、计算它的大小；通过实验认识洛伦兹力，能判断方向、计算大小；能用洛伦兹力分析带电粒子在匀强磁场中的圆周运动，了解质谱仪和回旋加速器的工作原理 |
| 2.2 电磁感应及其应用 | 探究影响感应电流方向的因素，理解楞次定律；通过实验理解法拉第电磁感应定律；了解自感现象和涡流现象；通过实验认识交变电流，能用公式和图像描述正弦交变电流；探究并了解变压器原、副线圈电压与匝数的关系，知道远距离输电通常采用高压的原因；了解发电机和电动机工作过程中的能量转化 |
| 2.3 电磁振荡与电磁波 | 初步了解麦克斯韦电磁场理论的基本思想；通过实验了解电磁振荡；知道电磁波的发射、传播和接收；认识电磁波谱及各波段的特征和应用 |
| 2.4 传感器 | 知道非电学量转换成电学量的技术意义；通过实验了解常见传感器的工作原理，会利用传感器制作简单的自动控制装置；列举传感器在生产生活中的应用 |

**教学提示要点**：通过安培力和洛伦兹力的学习进一步认识场；对感应电流的探究强调对实验现象和结果进行归纳推理；利用实际情境了解法拉第电磁感应定律、楞次定律的应用，了解电磁振荡、交变电流的产生、高压输电与变压器的原理，认识常用传感器和简单的控制电路。

**学业要求要点**：理解法拉第电磁感应定律、楞次定律，了解电磁振荡和电磁波；能综合分析磁场和电磁感应问题；能完成"探究影响感应电流方向的因素"等实验，写出完整的实验报告；能认识我国在特高压输电领域的成就。

**学生必做实验**：5. 探究影响感应电流方向的因素；6. 探究变压器原、副线圈电压与匝数的关系；7. 利用传感器制作简单的自动控制装置。

## 三、高中·选择性必修 3

由"固体、液体和气体""热力学定律""原子与原子核""波粒二象性"四个主题组成。

| 主题 | 内容要求（要点） |
|---|---|
| 3.1 固体、液体和气体 | 通过实验估测油酸分子的大小，了解分子动理论的基本观点及实验证据；了解扩散现象，观察并解释布朗运动，了解分子运动速率分布的统计规律；了解固体的微观结构，知道晶体和非晶体的特点，了解液晶；了解材料科学的有关知识（如半导体、纳米材料）；观察液体的表面张力现象，知道毛细现象；通过实验了解气体实验定律，知道理想气体模型，能用分子动理论和统计观点解释气体压强和气体实验定律 |
| 3.2 热力学定律 | 知道热力学第一定律；理解能量守恒定律；通过自然界中宏观过程的方向性，了解热力学第二定律 |
| 3.3 原子与原子核 | 了解人类探索原子结构的历史，知道原子的核式结构模型，通过氢原子光谱了解原子的能级结构；了解原子核的组成和核力的性质，知道四种基本相互作用，能根据质量数守恒和电荷守恒写出核反应方程；了解放射性和原子核衰变，知道半衰期及其统计意义，了解放射性同位素的应用，知道射线的危害与防护；认识原子核的结合能，了解核裂变和核聚变 |
| 3.4 波粒二象性 | 通过实验了解光电效应，知道爱因斯坦光电效应方程及其意义，能说明光的波粒二象性；知道实物粒子具有波动性，了解微观世界的量子化特征 |

**教学提示要点**：通过对物质微观结构、热力学定律、原子与原子核、波粒二象性的学习，促进物质观念、运动和相互作用观念、能量观念的形成；通过油膜法实验体会测量微观量的思想和方法；通过光电效应等认识光及实物粒子的波粒二象性；引导学生讨论核能等对人类生活和社会发展的影响。

**学业要求要点**：能认识光电效应现象，说明光的波粒二象性；能把物质的宏观性质与微观结构联系起来；能在一定条件下用理想气体模型分析实际气体问题；能根据能量守恒定律质疑不符合物理规律的传闻；能完成"用油膜法估测油酸分子的大小"等实验，写出完整、规范的实验报告。

**学生必做实验**：8. 用油膜法估测油酸分子的大小；9. 探究等温情况下一定质量气体压强与体积的关系。

**安全提示**：原子与原子核一章只讲原理、看演示视频或仿真，**不组织任何涉及放射源的学生操作**；射线的危害与防护按课本讲清即可。

## 四、高中·备课时要注意的三处

- **微观内容没有生活经验可依**：分子、原子、光子，按"现象 → 证据 → 模型"组织——先看布朗运动、α 粒子散射、光电效应这些现象，再问它们证明了什么，最后才给模型。
- **守恒观念贯穿**：动量守恒、能量守恒、电荷守恒、质量数守恒——备课时可以把"守恒"做成一条跨模块的主线，也呼应课标对自然界统一性的强调。
- **讲到什么深度**：选考班按等级考备课，命题不超过学业质量水平 3，可以综合应用。只讲含义的内容按课标划定，选择性必修里是麦克斯韦电磁场理论的基本思想、电磁振荡、电磁波谱、液晶、分子速率分布、四种基本相互作用：课标对它们只作了解层次的要求（"了解""初步了解""知道""认识"），学业要求也只要求说出或解释（电磁振荡是能用来解释生产生活中的电磁现象）；即使教材给了公式，也只讲是什么、为什么，测评不出计算题，T = 2π√(LC) 最多出"L、C 变为几倍，周期变为几倍"的比例判断。其余课标动词为"了解""知道"的规律（热力学第一定律、光电效应方程、能级跃迁、半衰期），按所用教材例题的深度定量；学业要求明确要应用的（气体实验定律："能在一定条件下应用理想气体模型分析和研究实际气体的问题"），按学业要求定量。深度以所用教材和本地考试说明为准。
