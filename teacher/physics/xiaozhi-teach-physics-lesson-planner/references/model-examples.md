# 初中物理模型案例库

> 适用学段：初中（7-9 年级）。
> 示例题验算：2026-09-03
> 配合 `xiaozhi-teach-physics-lesson-planner` 使用。物理模型是连接实际与理论的桥梁；本文档分两部分：**理想化对象**（把实物简化成什么）与**五类解题模型**（把一类问题归到哪套关系式）。
> 五类解题模型的命名与 `../xiaozhi-teach-physics-problem-guide/references/model-selection.md` 及学生端建模教练完全一致。
> 超出初中课标的模型见文末"初高衔接（⚠高中）"，不在初中课堂建立。

## 一、理想化对象（初中真正会用到的六个）

```text
┌──────────────┬────────────────────┬──────────────────────────┐
│ 理想化对象     │ 忽略了什么          │ 出现在哪一课              │
├──────────────┼────────────────────┼──────────────────────────┤
│ 光线          │ 光束的粗细          │ 光的直线传播、反射、折射   │
│ 轻质杠杆      │ 杠杆自重            │ 杠杆平衡条件              │
│ 轻绳、轻滑轮   │ 绳重、滑轮重、摩擦   │ 滑轮组、机械效率（先算理想│
│              │                    │ 情况，再讨论"为什么达不到"）│
│ 光滑水平面     │ 摩擦                │ 牛顿第一定律的理想实验     │
│ 定值电阻      │ 温度对电阻的影响     │ 欧姆定律、串并联          │
│ 匀速直线运动   │ 速度的微小起伏       │ 机械运动、平均速度        │
└──────────────┴────────────────────┴──────────────────────────┘
```

**教学要点**：理想化不是"骗人"，而是"先抓主要矛盾"。每引入一个理想化对象，都要问学生一句：

> "如果不忽略它（绳重 / 摩擦 / 温度影响），结果会往哪个方向偏？"

这一问能同时训练"理想化"和"误差分析"两种意识。

## 三、模型 1：匀速直线运动与平均速度

### 3.1 模型定义

```text
【何时用】题目只给出路程与时间，或出现"平均速度"

【核心关系】
  v = s / t
  v̄ = s总 / t总（必须回到定义式）

【理想化】把速度的微小起伏忽略，看作匀速；速度明显在变时，
          初中只作"越来越快 / 越来越慢"的定性判断
```

### 3.2 案例

```text
【案例 1】测小车的平均速度（学生必做实验）
  · 全程 1.2 m 用时 4 s → v̄ = 0.3 m/s
  · 上半段 0.6 m 用时 3 s → v̄上 = 0.2 m/s
  · 下半段 0.6 m 用时 1 s → v̄下 = 0.6 m/s
  · 教学价值：(0.2+0.6)/2 = 0.4 ≠ 0.3，用数据打掉"速度可以求平均"的迷思

【案例 2】过桥问题
  · 列车长 200 m，以 20 m/s 通过一座长 600 m 的桥
  · 路程 = 桥长 + 车长 = 800 m；t = 800 ÷ 20 = 40 s
  · 教学价值：画图才能看出"路程要加车长"

【案例 3】看到闪电后 3 s 听到雷声（v声 = 340 m/s）
  · s = 340 × 3 = 1020 m
  · 教学价值：光传播的时间可以忽略，这是一次"抓主要矛盾"的训练
```

## 四、模型 2：力学平衡（含简单机械）

### 4.1 模型定义

```text
【何时用】物体静止或匀速直线运动；或涉及杠杆、滑轮、机械效率

【核心关系】
  F₁ = F₂（同物、同线、等大、反向）
  G = mg（g 取 10 N/kg）
  F₁L₁ = F₂L₂（杠杆平衡条件）
  F = (G物 + G动)/n；s = n h（滑轮组）
  η = W有/W总 = G物 h /(F s)

【初中边界】只处理同一直线上的两个力，不做力的分解
```

### 4.2 案例

```text
【案例 1】水平匀速拉动木块（测滑动摩擦力）
  · 弹簧测力计读数 2.5 N → f = 2.5 N
  · 追问：为什么必须"匀速"？不匀速时读数还等于摩擦力吗？

【案例 2】竖直匀速提升
  · 质量 3 kg 的物体匀速上升 → G = 30 N → F拉 = 30 N
  · 追问：如果它在加速上升，拉力比 30 N 大还是小？（定性即可）

【案例 3】杠杆
  · 阻力 300 N、阻力臂 0.2 m、动力臂 0.8 m → F₁ = 75 N
  · 动力臂减半到 0.4 m → F₁ = 150 N
  · 教学价值：力臂减半、动力加倍，用数据建立反比直觉

【案例 4】滑轮组机械效率
  · G物 = 480 N，G动 = 120 N，n = 3，h = 2 m
  · F = 600/3 = 200 N；s = 6 m；W总 = 1200 J；W有 = 960 J；η = 80%
  · 追问：为什么效率不可能是 100%？额外功花在哪了？
```

## 五、模型 3：压强与浮力

### 5.1 模型定义

```text
【何时用】压力与受力面积、液体深度、物体浮沉、大气压

【核心关系】
  p = F / S（水平面上放物体时 F = G）
  p = ρ液 g h（h 为该点在液面下的深度）
  F浮 = ρ液 g V排（阿基米德原理，普遍成立）
  F浮 = G物 − F示（称重法）
  F浮 = G物（**只在漂浮或悬浮时**成立）
```

### 5.2 案例

```text
【案例 1】称重法测密度
  · 空气中 2.7 N，浸没在水中 1.7 N → F浮 = 1.0 N
  · V = 1.0 ÷ (1.0×10³ × 10) = 1×10⁻⁴ m³
  · ρ = 0.27 kg ÷ 1×10⁻⁴ m³ = 2.7×10³ kg/m³
  · 追问：如果它没完全浸没，这套算法哪一步先出错？

【案例 2】漂浮的木块
  · 边长 10 cm，浸入 6 cm → V排 = 6×10⁻⁴ m³ → F浮 = 6 N
  · 漂浮 → G物 = 6 N → ρ木 = 6×10² kg/m³
  · 追问：ρ木/ρ水 = 0.6，正好等于浸入的比例，这是巧合吗？

【案例 3】容器对桌面的压强
  · S = 5×10⁻² m²，水深 0.2 m，m水 = 10 kg，容器自重 4 N
  · 水对底的压强 2000 Pa；水对底的压力 100 N
  · 容器对桌面的压力 104 N；压强 2080 Pa
  · 追问：为什么两个压强不一样？两个"F"分别是什么？

【案例 4】覆杯实验（大气压）
  · 装满水的杯口盖硬纸片倒过来，水不流出
  · 追问：托住水的是什么？如果杯子换成两倍高，还托得住吗？
```

## 六、模型 4：电路分析（含动态电路）

### 6.1 模型定义

```text
【何时用】电流、电压、电阻、电功率、电热

【核心关系】
  I = U / R
  串联：I 处处相等，U = U₁ + U₂，R = R₁ + R₂
  并联：各支路电压相同，I = I₁ + I₂，总电阻比任一支路都小
  P = UI = I²R = U²/R；W = UIt；Q = I²Rt

【初中边界】电源电压视为不变；不引入电源的内部电阻（⚠高中 内阻）
```

### 6.2 案例

```text
【案例 1】串联动态电路
  · U = 6 V，R₁ = 10 Ω，滑动变阻器 0~20 Ω
  · R₂ = 20 Ω 时：I = 0.2 A，U₁ = 2 V
  · R₂ = 0 时：I = 0.6 A，U₁ = 6 V
  · 推导链：R₂↓ → R总↓ → I↑ → U₁↑ → U₂↓
  · 追问：电压表并在谁两端？读数是 U₁ 还是 U₂？

【案例 2】并联电路
  · U = 6 V，R₁ = 20 Ω，R₂ = 30 Ω
  · I₁ = 0.3 A，I₂ = 0.2 A，I = 0.5 A，R总 = 12 Ω
  · 追问：为什么总电阻比 20 Ω 还小？（相当于导线变粗）

【案例 3】小灯泡的 I-U 图线
  · 图线是**弯**的，不是过原点的直线
  · 多次测得的电阻**不能求平均值**
  · 追问：欧姆定律在这里失效了吗？（没有——失效的是"把灯泡当定值电阻"）
```

## 七、模型 5：功、功率与能量转化

### 7.1 模型定义

```text
【何时用】做功、功率、机械效率、吸放热、能量形式的转化

【核心关系】
  W = F s（F 与 s 必须同方向）
  P = W / t
  η = W有 / W总
  Q = c m Δt；燃料放热 Q = m q
  能量转化：E初 = E末 + 损耗
```

### 7.2 案例

```text
【案例 1】爬楼功率
  · 同一个人跑上三楼和走上三楼，做的功相同（W = Gh）
  · 用时不同 → 功率不同
  · 教学价值：把"功"与"功率"彻底分开

【案例 2】电热水壶
  · "220 V 1100 W" → I = 5 A，R = 44 Ω
  · 正常工作 5 min → W = 3.3×10⁵ J
  · 电压降到 198 V → P实 = 198²/44 = 891 W
  · 追问：为什么不能直接用 1100 W 乘时间？
  🔴 这是**纸面计算题**，铭牌数据只用来算，不是让学生去测。
     220 V 市电严禁带电操作：不拆装电器、不测量家用电器工作电流电压、
     不做任何家庭电路带电实验；课堂涉及市电一律用断电模拟板，
     由老师演示，方案见 xiaozhi-teach-physics-experiment-coach。
     布置为课后作业时，同样要写明"只算不做"。

【案例 3】水的吸热
  · 2 kg 水从 20 ℃ 升到 70 ℃，c水 = 4.2×10³ J/(kg·℃)
  · Q吸 = 4.2×10³ × 2 × 50 = 4.2×10⁵ J
  · 追问：Δt 是 70 还是 50？（是温度**变化量**）

【案例 4】能量转化链
  · 电热水壶：电能 → 内能
  · 电动机：电能 → 机械能 + 内能
  · 滑梯：重力势能 → 动能 + 内能（摩擦生热）
  · 追问：哪一环节的能量"跑掉了"？跑到哪去了？
```

## 八、模型选择决策树

```text
学生面对问题 → 题目里出现了什么物理量？
  · 路程、时间、平均速度          → 模型 1
  · 静止 / 匀速 / 杠杆 / 滑轮      → 模型 2
  · 压力与面积 / 深度 / 浮沉       → 模型 3
  · 电流 / 电压 / 电阻 / 开关滑片   → 模型 4
  · 做功 / 功率 / 效率 / 吸放热     → 模型 5
  · 上述多项同时出现               → 分段或分状态，每段一个主模型
```

## 九、模型迁移训练

```text
【训练 1】同一问题，不同解法
  · 例：求漂浮木块的浮力
    · 阿基米德原理：F浮 = ρ液gV排
    · 压力差法：F浮 = F下 − F上
    · 浮沉条件：F浮 = G物（只在漂浮/悬浮时）
  · 关键追问：换成沉底的铁块，哪一种先失效？

【训练 2】不同问题，同一模型
  · 例：模型 2（二力平衡）可用于
    · 水平匀速拉木块求摩擦力
    · 竖直匀速提升求拉力
    · 匀速下落的降落伞求空气阻力
    · 悬浮的鱼求浮力

【训练 3】综合问题的模型选择
  · 例：把浸没的物体匀速提出水面再举高
    · 阶段 1：模型 3 + 模型 2
    · 阶段 2：模型 2
    · 阶段 3：模型 5
```

## 十一、初高衔接（⚠高中）

以下模型**不在初中课标范围**，不要在初中课堂建立；学生问起时一句话说明"这是高中的内容"即可。

| ⚠高中 模型 | 关键式子（仅供老师识别） | 初中的替代 |
|---|---|---|
| ⚠高中 质点、刚体 | 忽略大小 / 忽略形变 | 直接说"物体""硬棒" |
| ⚠高中 匀变速直线运动 | v=v₀+at；s=v₀t+½at² | 模型 1：只算平均速度 |
| ⚠高中 牛顿第二定律 | F=ma | 模型 2：二力平衡 |
| ⚠高中 力的正交分解 | mg sinθ、mg cosθ | 模型 2：斜面只比较拉力与重力、算机械效率 |
| ⚠高中 动量守恒 | m₁v₁+m₂v₂ = m₁v₁′+m₂v₂′ | 碰撞只作定性描述 |
| ⚠高中 动能定理、机械能守恒方程 | W合=ΔEk；Ek+Ep=常数 | 模型 5：能量转化的定性分析 |
| ⚠高中 理想气体与玻意耳定律 | pV = 常数 | 注射器演示"体积变小压强变大"（定性） |
| ⚠高中 点电荷与电场强度 | E = F/q | 只讲电荷间的相互作用 |
| ⚠高中 万有引力 | F = GMm/r² | 只讲重力与地球的吸引 |
| ⚠高中 弹簧振子、单摆 | T = 2π√(L/g) | 不涉及 |
| ⚠高中 理想流体与伯努利方程 | — | 吹纸片演示"流速大压强小"（定性） |

> 💡 **小智说：** 初中的"建模"不是让学生记住模型清单，而是让他每次都问一句"这个式子凭什么能用在这道题上"。
