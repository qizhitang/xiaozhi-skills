# 物理教案设计 SKILL

> **一句话定位：** 物理不是教学生"记公式"，而是教学生"用物理观念看世界"——物理观念建构是核心。

---

> 技术边界：本 SKILL 依赖能力 [M, F, K]，无该能力时按 shared/platform-conventions.md 降级。
> 特有降级话术：本 SKILL 输出教案框架与概念建构路径，不代替老师备课、不替老师讲题。
> AI 生成的题与素材必须标注 `【AI 生成，入库前请人工验算】`，生成前按 shared/ai-item-check.md 自检。
> 铁律"不替老师讲题"的准确表述：面向学生的提问链按 `shared/hint-ladder.md` 逐级升，本 SKILL 提供到 L4（半步）的提问设计，L5/L6 的完整示范由老师在课堂上决定。

> 教学主体边界：本 SKILL 只给老师出草稿、做分析，不替老师上课，不代老师回答学生的问题，也不代老师评价学生；面向学生或家长的内容，一律由老师审定后再用（教育部《中小学生成式人工智能使用指南（2025 年版）》）。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

### 实验边界（进课堂前必读）

本 SKILL 是**教案设计**技能，不是实验教学技能。教案里当然要有"实验位"，
但**实验位不等于实验方案**：

```text
✅ 本 SKILL 做的（教案层面）
  · 这一课用不用实验、放在哪个环节、占多少分钟
  · 这个实验能建立什么概念、配什么提问链、学生要观察什么
  · 用 safetyLevel 三档做**初筛**，决定"能不能进这节课、进演示还是进分组"

❌ 本 SKILL 不做的（实验教学层面）——转 xiaozhi-teach-physics-experiment-coach
  · 器材清单、器材套数、分组人数与角色分配
  · 具体操作步骤、读数方法、装置搭建
  · 课堂安全组织流程、防护要求、应急处理
  · 实验失败的现场处置与备用方案

⚠️ 本 SKILL 及其 references 里出现的一切实验内容，
   都是**需老师复核的草稿**，不是可以照着做的实验方案。
   进课堂前必须由老师按学校实际器材、场地与安全规定核实一遍；
   涉及安全的部分以 xiaozhi-teach-physics-experiment-coach
   与学校实验室管理规定为准，与本 SKILL 不一致时以前者为准。

🔴 下列四类只要出现在教案草稿里，必须同时写出危险提示与"使用前须核实"：
  · 激光（激光笔、光具座光源）→ 不得射向眼睛或经镜面反射进入视线
  · 加热与明火（酒精灯、电加热器、热水）→ 烫伤与引燃风险
  · 玻璃器皿（烧杯、量筒、玻璃管、温度计）→ 破碎与割伤风险
  · 市电 220 V（家庭电路、带电接线）→ 一律不进分组、不带电操作
  写不出这三项（危险点 / 防护要求 / 复核要求）的实验，不要写进教案，
  改为"此处需要一个实验，方案请找〔物理实验教学指导〕"。
```

> 演示/分组实验一律标注 `safetyLevel`（三档定义见 `shared/lab-safety.md`；物理实验的逐项档位与激光专项见 `shared/experiment-types.md`）；`safetyLevel: 高` 的实验只作演示、不进分组，且必须由老师现场把控；要敞口使用、灌装或转移水银的实验（如托里拆利实验）老师也不现场做，只看课本插图或视频；分组测温优先用煤油温度计或数字温度计，还在用水银温度计的，打破了照 `shared/lab-safety.md` 第一节第 4 条。判不准时往高一档写。

### 试题保密

启用前的统考试题不得输入本 SKILL——国家、省、地（市）级教育统一考试启用前的试题、参考答案、评分标准属国家秘密（《教育工作中国家秘密及其密级具体范围的规定》），区县级、校级统考按当地保密要求同样处理。初中学业水平考试（中考），高中的学业水平合格性考试、等级性考试（各地也叫选考），地（市）统一组织的模拟考试（如一模、二模），以及实验操作考试的试题，全部批次、全部场次考完之前都按启用前处理（实验操作考试常分几天、分批进行，本班考完不等于考完）；跨校联考要等参加的学校全部考完；同一份卷子还有学生补考的，补考考完才算考完；考后不公开试卷的考试（如用题库命题、机考的），考完也只按本地公布的样题与评分维度讲共性问题，不据学生回忆还原原题。高中物理是否组织实验操作考查，以本地当年的考试说明为准，组织的同样按分批处理。
本 SKILL 备讲评课用的是已经考完的卷子与讲评错题清单（题号、知识点、得分率），复习课、讲评课里的例题与变式题自编；老师说明正在为统考命题时，本 SKILL 不接收、不生成、不审改该卷的具体试题。
题目版权状态只用 `shared/vocab.md` §11 的四个值：自有、改编、公开可引用、仅存索引。历年真题、教辅原题一律"仅存索引"：作例题时注明出处，不整卷抄录，写进 lessonPlans 的只记出处与题号，题干只留在给老师的教案正文里。
依据《中小学生成式人工智能使用指南（2025年版）》教师一节：“严禁将个人信息、考试试题等敏感数据输入AI工具”。

## 一、核心使命

物理教学常见的三个误区：

```text
误区① 物理=公式：把物理当数学公式背，
        学员记不住、不会用、没"物理感"。

误区② 物理=题海：只追求"做题量"，
        没建立"物理观念"，没培养"建模能力"。

误区③ 物理=枯燥：物理课就是讲概念+做题，
        学员没有"看物理"的兴趣。
```

本 SKILL 要解决的是：
- **让物理"有观念"**：建立"物质/运动/能量/相互作用"等观念
- **让概念"有情境"**：在生活/科技/演示中引入
- **让规律"有过程"**：实验+数据+归纳
- **让建模"有方法"**：理想化+简化+抽象
- **让应用"有联系"**：联系生活/科技/前沿

## 二、触发时机

激活需要**两个条件同时成立**：① 学科是初中物理（力/热/光/电/声），或高中物理（必修与选择性必修，见第十七节）；
② 任务是**备一节课**（教案、环节编排、概念怎么讲、提问链）。选修课程（选修 1～3）如实说明不覆盖。

## 四、物理核心素养与物理观念

### 4.1 物理观念的三个维度

> 说明：《义务教育物理课程标准（2022 年版）》与《普通高中物理课程标准日常修订版（2017 年版 2025 年修订）》均以**核心素养**为导向，物理学科核心素养含四方面：**物理观念、科学思维、科学探究、科学态度与责任**。其中"物理观念"下含三个维度（见下表）；本 SKILL 以物理观念组织概念主线，另三项素养在"科学思维/科学探究/科学态度"教学环节中落实，不要把它们与物理观念并列。

```text
┌──────────────────┬────────────────────────────────┬──────────────────┐
│ 物理观念维度      │ 描述                            │ 例子              │
├──────────────────┼────────────────────────────────┼──────────────────┤
│ 物质观念          │ 物质客观存在，有结构            │ 分子/原子/密度    │
│ 运动与相互作用观念│ 物体运动有规律；物质间存在相互作用│ 机械运动/重力/电磁力│
│ 能量观念          │ 能量守恒，可转化                │ 机械能/内能/电能  │
└──────────────────┴────────────────────────────────┴──────────────────┘
```

### 4.2 观念建构路径

```text
· 物质观念 → 物质是什么？怎么组成？
· 运动与相互作用观念 → 物质怎么运动？物质间怎么相互影响？
· 能量观念 → 能量是什么？怎么转化与守恒？
```

### 4.3 观念-概念-规律 三层

```text
■ 观念（最上）
  · 抽象
  · 高位
  · 跨单元

■ 概念（中间）
  · 具体化
  · 单元内
  · 可定义

■ 规律（具体）
  · 数学表达
  · 实验验证
  · 可应用
```

## 五、概念建构

### 5.1 概念建构三步

```text
① 引入
  · 生活情境
  · 演示实验
  · 反例情境

② 抽象
  · 抓住关键
  · 排除干扰
  · 形成定义

③ 应用
  · 区分相似概念
  · 联系实际
  · 拓展应用
```

### 5.2 生活情境引入

```text
┌──────────┬────────────────────────┐
│ 概念      │ 生活情境                │
├──────────┼────────────────────────┤
│ 速度      │ 汽车/跑步/风速          │
│ 力        │ 推/拉/压/支持           │
│ 压强      │ 切菜/钉钉/雪地行走      │
│ 浮力      │ 游泳/船/热气球          │
│ 电流      │ 电池/家电/电灯          │
│ 电阻      │ 导线/电炉丝             │
│ 磁场      │ 磁铁/指南针/电磁铁      │
└──────────┴────────────────────────┘
```

### 5.3 演示实验引入

```text
┌──────────┬────────────────────────┐
│ 概念      │ 演示实验                │
├──────────┼────────────────────────┤
│ 惯性      │ 鸡蛋/硬币实验           │
│ 浮力      │ 阿基米德实验            │
│ 电流      │ 水果电池/电铃           │
│ 反射      │ 镜面反射/漫反射         │
│ 折射      │ 水中筷子/硬币           │
│ 杠杆      │ 撬棍/天平               │
└──────────┴────────────────────────┘
```

### 5.4 反例情境引入

```text
· 力不是维持运动的原因（亚里士多德错误）
· 重的物体不一定先落地（伽利略反驳）
· 没有"绝对静止"（相对运动）
```

### 5.5 概念辨析

```text
■ 容易混淆的概念
  · 速度 vs 加速度
  · 重力 vs 质量
  · 压力 vs 压强
  · 内能 vs 温度
  · 电流 vs 电压
  · 串联 vs 并联
  · 凸透镜 vs 凹透镜

■ 辨析三问
  · 这两个概念的共同点？
  · 这两个概念的差异点？
  · 怎么区分？
```

## 六、规律教学

### 6.1 规律教学三步

```text
① 实验
  · 演示实验
  · 学生实验
  · 数据记录

② 数据
  · 处理数据
  · 找出规律
  · 数学表达

③ 归纳
  · 总结规律
  · 讨论局限
  · 应用推广
```

### 6.2 演示实验在教案里的"位置"（不是实验方案）

```text
✅ 本 SKILL 在教案里填的
  · 选材判断：现象是否明显、后排能否看清、safetyLevel 初筛结果
  · 教学位置：放在哪个环节、占多少分钟
  · 教学设计：让学员先预测 → 描述现象 → 归纳规律的提问链
  · 与本课概念的对应关系

❌ 本 SKILL 不写、交 xiaozhi-teach-physics-experiment-coach
  · 器材清单与规格、装置怎么搭
  · 逐步操作步骤、读数方法
  · 现场安全交代与防护要求、失败时的处置

⚠️ 教案里写的实验都是**待复核草稿**。涉及激光、加热与明火、玻璃器皿、
   市电 220 V 的，必须同时写出危险点、防护要求与"使用前须核实"，
   写不出就不要写进教案。
```

### 6.3 学生分组实验在教案里的"位置"

```text
✅ 本 SKILL 在教案里填的
  · 这一课要不要安排分组实验（safetyLevel 为"高"的一律不进分组）
  · 实验环节占几分钟、前后接什么环节
  · 学生要记录什么数据、数据怎么导向本课规律
  · 实验报告在教学上的作用（数据 + 分析 + 结论三段）

❌ 本 SKILL 不写、交 xiaozhi-teach-physics-experiment-coach
  · 器材套数、分组人数与角色分配、器材不足时的替代方案
  · 实验步骤与操作规范
  · 课堂安全组织流程与应急处理

交接话术：
  "这节课我在'规律教学'环节留了 18 分钟的分组实验位，
   要建立的是〔概念〕。具体用什么器材、分几组、安全怎么交代，
   〔物理实验教学指导〕更专业——要我把课题和时间预算交过去吗？"
```

## 七、模型建构

### 7.1 物理模型定义

```text
把复杂事物简化为
"理想化模型"，
便于研究。
```

### 7.2 物理模型分类

初中阶段的"模型"有两层含义，备课时要分清：

**（一）理想化对象**——把实物简化成便于研究的对象

```text
┌──────────────┬────────────────────────┬────────────────────────┐
│ 理想化对象     │ 忽略了什么              │ 初中出现在哪里          │
├──────────────┼────────────────────────┼────────────────────────┤
│ 光线          │ 忽略光束的粗细          │ 光的反射/折射/透镜成像  │
│ 轻质杠杆      │ 忽略杠杆自重            │ 杠杆平衡条件            │
│ 轻绳、轻滑轮   │ 忽略绳重、滑轮重、摩擦   │ 滑轮组、机械效率        │
│ 光滑表面      │ 忽略摩擦                │ 牛顿第一定律的推理      │
│ 定值电阻      │ 忽略温度对电阻的影响     │ 欧姆定律、串并联        │
│ 匀速直线运动   │ 忽略速度的微小变化       │ 平均速度、机械运动      │
└──────────────┴────────────────────────┴────────────────────────┘
```

**（二）解题模型**——把一类问题归到同一套关系式（与学生端建模教练同一套命名）

```text
┌──────┬────────────────────────┬──────────────────────────────┐
│ #    │ 模型                    │ 初中的核心关系式              │
├──────┼────────────────────────┼──────────────────────────────┤
│ 1    │ 匀速直线运动与平均速度   │ v=s/t；v̄=s总/t总              │
│ 2    │ 力学平衡（同一直线二力） │ F₁=F₂；F₁L₁=F₂L₂；η=W有/W总   │
│ 3    │ 压强与浮力              │ p=F/S；p=ρgh；F浮=ρ液gV排     │
│ 4    │ 电路分析（含动态电路）   │ I=U/R；P=UI=I²R=U²/R；Q=I²Rt  │
│ 5    │ 功、功率与能量转化       │ W=Fs；P=W/t；Q=cmΔt；Q=mq     │
└──────┴────────────────────────┴──────────────────────────────┘
```

> 超出初中的理想化对象（质点、刚体、理想气体、点电荷、理想流体、弹簧振子、⚠高中 单摆）见文末"初高衔接（⚠高中）"，不在初中课堂建立。

### 7.3 建模三步

```text
① 抓主要
  · 哪些因素是主要的？
  · 哪些是次要的？

② 忽略次要
  · 理想化
  · 简化

③ 建立模型
  · 用模型描述
  · 用模型分析
  · 用模型预测
```

### 7.4 建模教学

```text
■ 学员面对真实问题
  · 学员先想"这是什么问题"
  · 学员想"忽略什么"
  · 学员想"用什么模型"

■ 老师引导
  · 老师不直接给模型
  · 老师问"你觉得应该怎么简化"
  · 老师引导学员自己建模

■ 模型 vs 真实
  · 模型是简化
  · 模型有局限
  · 模型可修正
```

## 十六、初高衔接（⚠高中）

|---|---|---|

| ⚠高中 弹簧振子与单摆（简谐运动） | 周期性运动的定量描述 | 不引入；累积法测时间可用"数心跳"代替 |

## 十七、高中：必修与选择性必修的教案

依据《普通高中物理课程标准日常修订版（2017 年版 2025 年修订）》必修与选择性必修。课时、班额、教材版本以 `classWorkspace.classProfile` 为准。

### 17.1 必修 1

必修 1 的两个主题："机械运动与物理模型""相互作用与运动定律"。

- **概念建构**：速度、加速度、力这些核心概念，要让学生经历建构过程——瞬时速度体会极限方法，加速度体会抽象思维，质点体会模型建构的必要性与适用条件（课标必修 1 的内容要求与教学提示）。
- **规律教学**：匀变速直线运动同时用公式和 v-t 图像描述；牛顿运动定律结合"探究加速度与物体受力、物体质量的关系"的实验来建立，实验里用控制变量设计方案、用图像处理数据。
- **从初中到高一的三处跃迁**，备课时要专门设计过渡：标量走向矢量（先规定正方向，力的合成与分解）；只看结果走向看过程（v-t 图、分段列式）；二力平衡走向牛顿第二定律（受力分析从单个物体到连接体）。
- **目标对齐**：`objectives[].coreCompetency` 填高中物理四个核心素养之一——物理观念、科学思维、科学探究、科学态度与责任。
- **实验位**：必修 1 的 4 个学生必做实验的组织、器材与安全转物理实验教学指导；教案里只写实验位。

### 17.2 必修 2、必修 3

- **两处跃迁**：从"力与运动"走向"能量"——动能定理、机械能守恒只看初、末状态；从"物体"走向"场"——电场强度、电势用物理量之比定义，电场线、磁感线是描述场的模型。备课时专门设计过渡（例如同一道题用牛顿定律和动能定理两种解法对比；用重力场 g = G/m 类比电场 E = F/q）。
- **规律教学**：动能定理由牛顿第二定律推导（课标必修 2 的举例）；机械能守恒先实验验证、再理论理解，讲清它是一种理想情况；平抛运动、匀速圆周运动体会"化繁为简"；闭合电路欧姆定律结合"测量电源的电动势和内阻"的实验来建立；库仑定律结合物理学史（库仑扭秤的实验思想）。
- **实验位**：必修 2 的 3 个、必修 3 的 5 个学生必做实验的组织、器材与安全转物理实验教学指导；教案里只写实验位。

必修 2、必修 3 各主题的内容要求、教学提示与学业要求（要点），见 `references/physics-hs2-curriculum-map.md`。

### 17.3 选择性必修

- **只备合格性考试的班级**（学生没有选考物理）不进入选择性必修；选考班按等级性考试的范围备课。
- **动量与振动、波、光**：动量定理与牛顿第二定律的一致性要经历理论推导和实验验证；建构弹性碰撞、简谐运动、单摆等模型；用光的干涉、衍射现象论证光的波动性，培养证据意识。
- **电磁**：安培力、洛伦兹力进一步认识场；楞次定律用"探究影响感应电流方向的因素"的实验归纳得出，不先给结论；联系变压器、高压输电、传感器的实际应用。
- **热学与近代物理**：分子、原子、光子没有生活经验可依，按"现象 → 证据 → 模型"组织（布朗运动、α 粒子散射、光电效应）；原子核一章不组织任何涉及放射源的学生操作；核能的利与弊可以组织讨论。
- **实验位**：选择性必修的 9 个学生必做实验转物理实验教学指导。

选择性必修三个模块的内容要求、教学提示与学业要求（要点），见 `references/physics-hs3-curriculum-map.md`。

### 17.4 考试与学业质量

合格性考试考必修内容与 12 个学生必做实验，等级性考试考必修与选择性必修内容与 21 个学生必做实验；学业质量在 2025 年修订后改为三级（水平 1 为合格依据，等级考不超过水平 3）。课程结构、学业质量与考试的原文要点见 `references/physics-hs1-curriculum-map.md`。

**层次**（必修与选择性必修通用）：① **上限**：合格考按学业质量水平 1；等级考命题不超过水平 3，可以综合应用。② **只讲含义**（按课标划定的清单）：相对论时空观（含长度收缩、时间延缓）、能源与可持续发展、麦克斯韦电磁场理论的基本思想、电磁振荡、电磁波谱、液晶、分子速率分布、四种基本相互作用——课标对它们只作了解层次的要求（"了解""初步了解""知道""认识"），学业要求也只要求说出或解释（电磁振荡是能用来解释生产生活中的电磁现象）；即使教材给了公式，也只讲是什么、为什么，测评不出计算题，T = 2π√(LC) 最多出"L、C 变为几倍，周期变为几倍"的比例判断。③ **按教材例题的深度定量**：清单以外、课标动词为"了解""知道"的规律（如电容 C = Q/U、磁通量 Φ = BS、c = λf 与 ε = hν、热力学第一定律 ΔU = W + Q、光电效应方程 Ek = hν − W₀、能级跃迁 hν = Em − En、半衰期），按所用教材例题的深度定量；内容要求或学业要求明确要分析、应用的（如带电粒子在电场中的运动、用电势能分析能量转化、闭合电路欧姆定律、气体实验定律），按要求的深度定量。等级考可以把它们与其他规律综合，深度以所用教材和本地考试说明为准。

### 18.2 复习课

复习课不是把公式再罗列一遍，也不是整节刷题（§一 误区①②），而是用物理观念把学过的概念、规律和模型重新串起来，再换一个情境用一次。先看 reviewPlans：本课落在哪个复习阶段，这几天该回看哪些知识点；阶段写明 newContentAllowed 为 false 的，不引入新知识点，给学有余力的学生的拓展任务也不带新知识点。

| 环节（仍走 §三 的主线） | 复习课里做什么 |
|---|---|
| 观念串联 | 学生先画本单元的结构图，再按物质、运动与相互作用、能量三个观念把概念和规律归位（§4.1—4.3；`references/physics-concepts-map.md` 第 4 节场景 ③）；定稿进 boardPlan |
| 概念辨析 | 本单元的易混概念放在一起，用 §5.5 的辨析三问；配对按本单元选，interactionLogs 里记下的迷思作反例 |
| 规律与实验回看 | 翻出当时的实验记录、数据表与图像，说出控制了哪些变量、规律的适用条件（§6.1、§6.4） |
| 模型归类与多题一解 | 形不同、模型相同的 3—4 道题放在一起，找出共同的模型与适用条件（§7.2）；初中照 `references/model-examples.md` 第八节的模型选择决策树与第九节的迁移训练。这是复习课的主体 |
| 迁移应用 | 换一个生活或科技情境（§8.1），题先独立做，再说用了哪个观念、哪个模型；当堂变式改条件、改问题或改情境（物理解题教学指导第七节），按 `shared/ai-item-check.md` 自检，标【AI 生成，入库前请人工验算】 |
| 小结 | §9.1 的三层小结；§9.2 反思三问的第三问落在"下次遇到这类问题先想哪个模型" |

- **实验回看**：先用当时的记录与数据；要重做的只排实验位，照 `shared/lab-safety.md` 第二节定 safetyLevel：高档只演示，中档老师全程在场，接 220 V 电源的器材插头由老师插拔（§6.2、§6.3）。激光、加热与明火、玻璃器皿、市电 220 V 四类照文首"实验边界"写全危险点、防护要求与复核要求，写不出就不进教案；器材、分组与安全组织转物理实验教学指导。不布置在家做的实验，课后延伸也不安排在家复现。要敞口使用、灌装或转移水银的实验（如托里拆利实验）只看课本插图或视频，不重做。
- **重点**：weaknessRank 靠前的条目与 interactionLogs 里记下的迷思多给时间，写进 sourceWeaknessIds；studentTiers 的 A/B/C 决定各段的 tierVariants，任务卡印"任务卡一/二/三"，不印 A/B/C 层名。
- **写进 lessonPlans**：planType 填"复习"；topic 写复习的单元或主题；segments 的分钟数合计等于 periodMinutes；作业只留作业位，转作业设计师。

复习课的分钟分配示例（初中，periodMinutes = 45，一个单元的复习）：

```text
概念辨析               7 分钟   辨析三问
```

### 18.3 讲评课

- **先确认考完**：只讲已经考完的卷。实验操作考试等分批、分场的考试，全部批次、全部场次考完才讲，本班考完不等于考完；联考、区县统考与一模二模等参加的学校全部考完再讲（见文首"试题保密"）。没考完时，考题不接收、不改编，据考题编的变式也不讲；可以先排讲评课的环节框架，全部考完后再放进题目与变式。
- **排顺序**：按讲评错题清单的顺序讲，同一模型、同一类错因的题合并讲；老师自己给题号的，失分面广的先讲；itemStats 的 flag 为"疑似错题"的，先请老师核对题目与参考答案，查清再定讲不讲；个别学生的失误不进全班讲评，私下沟通。

| 每一道题 | 讲评课里做什么 |
|---|---|
| 说题 | 学生先说出情境、已知与所求，再说想用哪个模型、为什么能用（§7.2；初中照模型选择决策树） |
| 找错步 | 对照物理解题教学指导第四节的五步（审题 → 建模 → 过程分析 → 列方程 → 求解与反思）找出全班错在哪一步，完整讲法照那里，本 SKILL 不另写一套；提问链给到 L4（半步）为止，L5、L6 的完整示范由老师在课上决定（文首技术边界） |
| 纠正 | 错在概念上的回到 §5.5 的辨析三问，错在规律上的回到当时的实验数据与适用条件（§6.4），错在模型上的回到模型的适用条件（§7.4"模型有局限"） |
| 当堂变式 | 每类错因配一道，改条件、改问题或改情境（变式链照物理解题教学指导第七节），先独立做再说理由；按 `shared/ai-item-check.md` 自检，标【AI 生成，入库前请人工验算】 |

- **实验题**：讲每一步的目的、控制了哪些变量、数据怎么处理、误差从哪来（§6.4；误差的讲法照物理实验教学指导第七节），以及规范操作与安全要点；规范与安全本身是考点，不教省略步骤（`shared/lab-safety.md` 第五节）。要演示的只排实验位、标 safetyLevel，高档只演示，接 220 V 电源的器材插头由老师插拔；不布置在家练。
- **非选择题**：按试卷的评分要点讲，参考答案与评分标准以试卷与老师为准；展示作答只用化名或老师誊写、改写的典型错解（"有同学这样写"），不念名字，只呈现"这一类错误"（`references/student-physics-profile-template.md` 第三节）；投影原卷先遮住姓名、学号与分数，字迹同学认得出的改用老师誊写的，原卷和作答也不拍照发到群里。
- **对题不对人**：不公开个人分数与排名，表扬进步也不报分数与名次，也不公布进步或退步的名单；个别学生的失误私下沟通，不当众点名批评。
- **考后情绪**：有学生情绪低落的，课上照常对题不对人。出现危机信号（如卷面上写了轻生的话）时，停止讲评设计，按文首危机例外处置：建议老师当天私下单独关注这个学生，联系学校心理老师与监护人转介；这个学生的这份作答不拿到课上展示或讨论。伤害可能来自家里的（如说考差了回家会挨打），照 `shared/crisis-exception.md`"家庭安全类信号"一节：不先联系监护人，不找家长核实，不追问学生细节，也不起草提到这件事的家长消息，当天按学校的学生保护流程报告班主任或分管学生保护工作的校领导（校外培训机构的老师与独立教师照该节的报告途径）；学生说怕回家的，先别让他一个人回家，等学校和公安、民政部门安排。两类信号一起出现时（如"考砸了回家又要挨打，不如死了"），按家庭安全类处理，报告时一并说明自伤风险。这件事与学生的原话都不写进教案。
- **写进 lessonPlans**：planType 填"讲评"；哪场考试写进 topic（如"期中讲评：压强与浮力"）；讲评题号清单与题干只留在给老师的教案正文，不写个别学生的分数与错因。物理解题教学指导已为这节课写过 questionChain 或 tierVariants 的，不覆盖它的条目，两边不一致的请老师定。订正与巩固作业转作业设计师。

讲评课的分钟分配示例（初中，periodMinutes = 45，讲评 4 道题，已按讲评错题清单排好先后）：

```text
考情简报           3 分钟   只说全班的得分率与进步，不报个人分数（最高分、最低分也不报）、不排名
自主订正           7 分钟   学生先对照答案自己改，圈出改不了的题
集中讲评          20 分钟   4 道，每道约 5 分钟：说题 → 找错步 → 纠正
当堂变式          10 分钟   每类错因一道
小结与作业位       5 分钟   反思：错在哪、为什么错、下次怎么避免；作业转作业设计师
合计              45 分钟（3 + 7 + 20 + 10 + 5 = 45）
```

### 18.4 初中：目标、中考与实验操作考试

- **目标**：objectives 的 coreCompetency 填物理观念、科学思维、科学探究、科学态度与责任之一（§4.1、§11.2）。复习课的目标落在会用观念归类、会选模型并说出适用条件，讲评课的目标落在会纠正这一类错误，不照抄新授课的目标。
- **开课年级、课时与作业**：物理一般在八、九年级开设，浙江等地是综合的《科学》课（`shared/grade-bands.md` 第四节表下说明）；初中默认 45 分钟（同一文件第三节），以 periodMinutes 为准，即 18.2、18.3 的示例。不因为复习或考后额外加作业量，作业转作业设计师，全科作业总量由老师按学校统筹与双减的要求协调。
- **考试说明**：初中学业水平考试（中考）与期末考试的范围、题型、分值，有没有实验操作考试、考哪些实验、是否计入中考总分，都以本地当年的考试说明为准，本 SKILL 不内置；老师没给的地方在教案里标"待老师按本地考试说明确认"。期末复习与讲评按本学期所教的章节，范围以学校的安排为准。
- **实验操作考试**：复习课用当时的记录单回看每一步的目的与规范，可对照 `shared/experiment-types.md` 第 12 节的义务教育课标 21 个学生必做实验（这是课标清单，不是考试清单，考哪几个以本地当年的考试说明为准）；逐项练、模拟与器材组织转物理实验教学指导。口径照 `shared/lab-safety.md` 第五节：只讲步骤、每一步的原因、评分维度与常见扣分点，不替代真实动手，不教省略步骤，"考试时能不能跳过这一步"一律按规范答；考场要求考生自己接 220 V 电源的，听从考场规定与监考老师，讲解时不指导插拔插头；全部批次、全部场次考完才讲评。
- **范围**：例题、变式与模型不超出初中（§7.2 的理想化对象与五类解题模型）；§十六 列出的内容不在初中的复习课、讲评课里建立。

### 18.5 高中：合格考与等级考的复习与讲评

先问清四件事（本 SKILL 不内置任何省份的考试政策）：

```text
① 哪场考试：合格考、等级考（各地也叫选考），还是校内的单元、期中、期末
② 本地当年的考试说明：老师没提供的地方标"待老师按本地考试说明确认"，不猜
③ 这个教学班考哪一种：合格考班、等级考班，还是两类学生在同一个班；
   班级工作区没有选科这一项，由老师说明，要人数不要名单，不从成绩或其他字段推断
④ 新课教到哪：本课复习、讲评的是必修还是选择性必修的内容
```

- **课时**：高中不设默认（各地 40 或 45 分钟，`shared/grade-bands.md` 第三节），读不到 periodMinutes 先问老师，不按 45 分钟排；40 分钟的课照 18.2、18.3 的环节重排分钟数，合计仍等于 periodMinutes。
- **考试口径**：照 §17.4 与 `references/physics-hs1-curriculum-map.md` 第四节。学业质量分水平 1、2、3：水平 1 是合格等级的划定依据，等级考命题不超过水平 3；合格考考必修与相关的 12 个学生必做实验，等级考考必修、选择性必修与相关的 21 个；考试形式、题型与是否组织实验操作考查，以本地当年的考试说明为准。旧教参、旧试卷分析里 2017 年版"水平 2 合格、水平 4 等级考"的说法不照搬。水平只写在教案正文开头"本课对应的考试与水平"一行，不写进工作区，不写全科通用的对应，也不跨学科换算。
- **范围与深度**：只备合格考的班级不进入选择性必修（§17.3），复习、讲评都只到必修；只讲含义的内容按 §17.4 层次②的清单，复习课的当堂变式不出计算题；其余按层次③的教材例题或学业要求的深度定量，教材讲得更深的不说成课标要求。两类学生在同一个班的，只考合格考的学生按必修与合格考的深度，选考的学生按等级考的深度、以水平 3 为上限；分两组任务时各组人数由老师给，任务卡印"任务卡一/二"。
- **专题复习的主线**：必修 2、必修 3 的复习可以照 §17.2 的两处跃迁组织——同一道题先用牛顿运动定律、再用动能定理解，比较两种方法各自适用的场合；用重力场（g = G/m）类比电场（E = F/q），回看电场强度、电势这些用比值定义的量（`references/physics-hs2-curriculum-map.md` 第三节）；选考班可以把动量守恒、能量守恒、电荷守恒做成一条跨模块的守恒主线（`references/physics-hs3-curriculum-map.md` 第四节）。平抛、向心力的来源、闭合电路等题，五步里每步要加的内容照物理解题教学指导第十四节；测量电源的电动势和内阻等必做实验相关的题，教学重点与常见错误照物理实验教学指导第十五节。
- **实验**：合格考的 12 个、等级考的 21 个学生必做实验，与义务教育课标的 21 个是两份清单；复习要重做的只排实验位，档位与接 220 V 器材的插拔照物理实验教学指导第十五节与 `shared/lab-safety.md`，逐项练转物理实验教学指导；原子核一章不组织任何涉及放射源的学生操作（§17.3）。本地组织实验操作考查的，全部批次、全部场次考完再讲评。
- **统计口径**：等级考的赋分、等级与位次不是得分率，不拿来定讲评重点；不说谁"会过""不会过"，不做赋分与等级预测。联考、一模、二模都要参加的学校全部考完再讲，讲评顺序仍照 18.3。
- **轮次与作业**：一轮、二轮、三轮的安排以学校为准，本 SKILL 只排其中的一节课，不改轮次与总进度，回看排期转复习规划师；作业转作业设计师，按本校晚自习与就寝时间协调，不内置分钟数。
