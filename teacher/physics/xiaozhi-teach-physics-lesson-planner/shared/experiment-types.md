# 初中物理实验类型详解

> 适用学段：初中（7-9 年级）。
> 配合 `xiaozhi-teach-physics-experiment-coach` 使用。
> **两套分类不要混淆**：
> · 按**实验目的**分 7 类（本文第 1-8 节）：测量型 / 验证型 / 探究型 / 演示型 / 设计型 / 课外型 / 仿真型
> · 按**课堂组织形式**分 3 类（`../xiaozhi-teach-physics-lesson-planner/references/lab-design-template.md` 用的就是这一套）：**演示 / 分组 / 课外**
> 同一个实验在两套分类里各有一个位置，例如"探究浮力的大小"是目的上的探究型、组织上的分组实验。
> 本文第 11 节给出全库统一的 `safetyLevel` 三档定义，第 12 节给出课标要求的学生必做实验清单。

## 2. 类型 1：测量型实验

### 2.1 定义与目的

```text
【定义】用实验方法测量某个物理量
【目的】掌握测量方法，理解测量原理
【典型】测密度、测电阻、测速度
```

### 2.2 设计要点

```text
【核心】选择合适的测量工具
【步骤】
  ① 明确待测量
  ② 选择测量工具（精度匹配）
  ③ 设计测量步骤
  ④ 多次测量取平均
  ⑤ 误差分析

【案例】测金属块密度
  · 工具：天平、量筒
  · 步骤：测质量 m、测体积 V
  · 计算：ρ = m/V
  · 误差：量筒读数误差、天平精度
```

### 2.3 常见测量型实验

```text
┌────────────────────┬──────────────────────┐
│ 实验                │ 测量量                │
├────────────────────┼──────────────────────┤
│ 测金属块密度        │ 质量、体积            │
│ 测小石块密度        │ 质量、体积            │
│ 测盐水密度          │ 质量、体积            │
│ 测小灯泡电阻        │ 电压、电流            │
│ 测滑轮组机械效率    │ 拉力、物重、距离      │
│ 测小灯泡的电功率    │ 电压、电流            │
│ 测斜面机械效率      │ 拉力、物重、距离      │
└────────────────────┴──────────────────────┘
```

## 3. 类型 2：验证型实验

### 3.1 定义与目的

```text
【定义】用实验验证已学过的物理规律
【目的】加深对规律的理解，同时练习"用数据说话"
【典型（初中）】验证阿基米德原理、验证杠杆平衡条件、验证焦耳定律

【重要提醒】课标把"电流与电压、电阻的关系"列为**探究**，不是验证。
把探究型实验改成"验证欧姆定律"，等于先告诉学生结论再让他们凑数据，
探究的价值就没了。教学中不要出现"验证欧姆定律"这个说法。
```

### 3.2 设计要点

```text
【核心】把抽象规律转化为可测量的物理量
【步骤】
  ① 列出待验证的规律
  ② 转化为可测量的关系
  ③ 设计实验方案
  ④ 测量数据
  ⑤ 比对预期与实际

【案例】验证阿基米德原理
  · 规律：F浮 = G排
  · 实验：溢水杯 + 小桶 + 弹簧测力计
    ① 测物体在空气中的重 G物
    ② 测空小桶的重 G桶
    ③ 把物体浸入盛满水的溢水杯，读出测力计示数 F示，
       同时用小桶接住溢出的水
    ④ 测"小桶 + 水"的重 G桶+水
  · 计算：F浮 = G物 − F示；G排 = G桶+水 − G桶
  · 比对：两者在误差范围内相等 → F浮 = G排 成立
  · 常见教学失误：只做①②（称重法）就宣布"验证了阿基米德原理"——
    没有测排开的液体，什么也验证不了
```

### 3.3 常见验证型实验

```text
┌────────────────────┬──────────────────┐
│ 实验                │ 验证规律          │
├────────────────────┼──────────────────┤
│ 验证阿基米德原理    │ F浮 = G排         │
│ 验证杠杆平衡条件    │ F₁L₁ = F₂L₂       │
│ 验证焦耳定律        │ Q = I²Rt          │
│ 验证串联电路电压规律 │ U = U₁ + U₂       │
│ 验证并联电路电流规律 │ I = I₁ + I₂       │
│ 验证同一直线二力平衡 │ F₁ = F₂           │
│ （⚠高中 才有的验证型：验证牛顿第二定律 F=ma、           │
│   验证机械能守恒——初中不做）                            │
└────────────────────┴──────────────────┘
```

## 4. 类型 3：探究型实验

### 4.1 定义与目的

```text
【定义】通过实验探究未知的物理规律
【目的】培养科学探究能力
【典型】探究液体内部压强、探究电流与电压电阻关系
```

### 4.2 设计要点

```text
【核心】运用控制变量法
【步骤】
  ① 提出问题
  ② 猜想与假设
  ③ 设计实验（控制变量）
  ④ 收集数据
  ⑤ 分析数据
  ⑥ 得出结论
  ⑦ 评估

【案例】探究电流与电压、电阻的关系
  · 问题：电流与电压、电阻有什么关系？
  · 假设：I ∝ U, I ∝ 1/R
  · 实验：
    ① 控制 R 一定，改变 U，测 I
    ② 控制 U 一定，改变 R，测 I
  · 结论：I = U/R
```

### 4.3 常见探究型实验

```text
┌────────────────────┬──────────────────┐
│ 实验                │ 探究内容          │
├────────────────────┼──────────────────┤
│ 探究液体压强        │ 影响因素          │
│ 探究浮力大小        │ 影响因素          │
│ 探究杠杆平衡条件    │ F 与 L 的关系     │
│ 探究电流与电压电阻  │ 欧姆定律          │
│ 探究电磁铁磁性强弱  │ 影响因素          │
│ 探究导体电阻        │ 影响因素          │
│ 探究动能            │ 影响因素          │
└────────────────────┴──────────────────┘
```

## 5. 类型 4：演示型实验

### 5.1 定义与目的

```text
【定义】老师演示，学员观察的实验
【目的】直观展示物理现象
【典型】大气压存在、电磁感应现象
```

### 5.2 设计要点

```text
【核心】现象要明显，过程要直观
【步骤】
  ① 选择能产生明显现象的实验
  ② 设计演示过程
  ③ 引导学员观察
  ④ 引导学员思考

【案例】大气压存在
  · 实验：覆杯实验
  · 现象：水不流出
  · 引导：是什么托住了水？
  · 结论：大气压存在
```

## 6. 类型 5：设计型实验

### 6.1 定义与目的

```text
【定义】学员自己设计方案完成实验
【目的】培养综合实验能力
【典型】测未知电阻、估测大气压
```

### 6.2 设计要点

```text
【核心】开放性问题，多种解法
【步骤】
  ① 明确实验目的
  ② 列出可用器材
  ③ 设计方案（多个）
  ④ 选择最优方案
  ⑤ 实施
  ⑥ 误差分析

【案例】只给一个电表，怎么测未知电阻
  · 方法 1：伏安法（有电压表和电流表时的标准做法）
  · 方法 2：只有电压表 + 一个已知定值电阻 R₀
           把 R 与 R₀ 串联，分别测 R 与 R₀ 两端的电压，
           由 I 相同得 Rx = R₀ · Ux / U₀
  · 方法 3：只有电流表 + 一个已知定值电阻 R₀
           把 R 与 R₀ 并联，分别测两条支路的电流，
           由 U 相同得 Rx = R₀ · I₀ / Ix
  · 选择依据：手头有哪个电表、电源电压是否已知
  · （⚠高中 才有的电桥法，初中不作要求）
```

## 7. 类型 6：课外型实验

### 7.1 定义与目的

```text
【定义】在课后、家庭、社区进行的实验

【典型】自制密度计、自制电磁铁
```

### 7.2 设计要点

```text
【核心】安全、有趣、可操作
【步骤】
  ① 选择安全材料
  ② 简化操作
  ③ 引导观察
  ④ 撰写实验报告

【案例】自制密度计
  · 材料：吸管、橡皮泥
  · 步骤：吸管底部塞橡皮泥
  · 测试：放入不同液体
  · 结论：液体密度越大，吸管露出越多
```

## 8. 类型 7：仿真型实验

### 8.1 定义与目的

```text
【定义】用计算机软件模拟实验
【目的】弥补实物实验的不足
【典型】PhET 仿真、Algodoo
```

### 8.2 设计要点

```text
【核心】补充非可视化的实验
【步骤】
  ① 选择仿真软件
  ② 设置参数
  ③ 运行实验
  ④ 观察结果
  · 与实物对比

【优势】
  · 安全（无危险操作）
  · 经济（无器材损耗）
  · 直观（可看内部过程）
  · 可逆（可任意改变参数）

【局限】
  · 缺少真实感
  · 软件可能不准确
```

## 9. 实验类型选择决策

```text
学员面对实验 → 想要达到什么目的？
  · 测物理量 → 测量型
  · 验证规律 → 验证型
  · 探究关系 → 探究型
  · 直观展示 → 演示型
  · 培养综合能力 → 设计型
  · 课后延伸 → 课外型
  · 弥补条件 → 仿真型
```

## 11. safetyLevel 三档定义（全库统一口径）

本表是 `safetyLevel` 在全库的唯一定义；物理教案设计、实验教学指导两个 SKILL 都引用本节，不各自另立标准。

```text
┌────────┬──────────────────────────────┬──────────────────────────────┐
│ 档位    │ 判定特征（满足任一即归入）      │ 课堂处置                      │
├────────┼──────────────────────────────┼──────────────────────────────┤
│ 低      │ 常温、无明火、无加热           │ 可直接安排分组实验            │
│        │ 无锐器、无易碎玻璃             │ 老师巡视即可                  │
│        │ 无腐蚀性/易燃物质              │ 学生可在家复现（家长知情）     │
│        │ 电学仅限干电池等低压直流        │                              │
├────────┼──────────────────────────────┼──────────────────────────────┤
│ 中      │ 涉及加热、明火（酒精灯）        │ 可分组，但必须：              │
│        │ 涉及玻璃器皿、可能割伤的器材     │ ① 课前讲安全要点              │
│        │ 涉及需要接线的电学实验（学生电源）│ ② 老师全程在场                │
│        │ 涉及重物提升、可能砸落           │ ③ 每组首次操作前老师确认装置   │
│        │ 液体温度可能超过 60 ℃           │ ④ 备好急救用品与灭火用具       │
│        │ 使用激光笔等定向强光源          │ ⑤ 激光另见本节「激光专项」      │
│        │                              │ 不建议学生在家单独做           │
├────────┼──────────────────────────────┼──────────────────────────────┤
│ 高      │ 220 V 家庭电路的带电操作        │ **只作演示，不进分组**         │
│        │ 强酸强碱等化学品                │ 老师操作，学生保持安全距离      │
│        │ 高压气体、可能爆裂或飞溅的装置    │ 或改用视频 / 仿真软件          │
│        │ 需要专业防护的装置              │ **禁止**推荐学生在家做         │
└────────┴──────────────────────────────┴──────────────────────────────┘
```

**判定顺序（自上而下，命中即停）**：

```text
① 有没有 220 V 带电操作、化学品、高压气体、可能爆裂飞溅？ → 有 → 高
② 有没有加热、明火、玻璃器皿、需要接线的电学、重物提升？   → 有 → 中
③ 有没有激光笔等定向强光源？                            → 有 → 中（见「激光专项」）
④ 以上都没有                                            → 低
判不准时一律往高一档写。
```

**常见实验的档位参考**

| safetyLevel | 实验举例 |
|---|---|
| 低 | 测平均速度、探究杠杆平衡条件、探究光的反射规律（**限普通光源 + 光具盘**；改用激光笔即升为中）、探究凸透镜成像规律、连接串并联电路、用天平测质量、用刻度尺测长度 |
| 中 | 用激光笔演示光的反射/折射/直线传播、探究水沸腾时温度变化的特点、比较不同物质的吸热能力、伏安法测电阻、测量小灯泡的电功率、探究浮力的大小（涉及玻璃溢水杯）、滑轮组机械效率（重物提升） |
| 高 | 家庭电路的带电连接（改用断电模拟板）、破坏性的大气压演示、任何涉及 220 V 直接操作的项目 |

---

**激光专项（光学实验凡用激光笔即适用）**

```text
危险点：激光直射，或经镜面、水面、玻璃反射后进入眼睛，可造成不可逆的视网膜损伤；
        眨眼反射来不及保护，且光斑越小越危险。
必须做到：
  · 只用课堂教学用低功率激光笔，使用前核实功率标识（无标识不得使用）
  · 光路压在桌面高度以下，学生视线不与光路同高
  · 严禁射向任何人的眼睛，严禁对准镜面、玻璃、金属等会反射的物体乱扫
  · 由老师操作，或老师在旁全程盯着；不放进分组器材箱由学生自取
  · 不推荐学生在家复现
可替代：普通光源 + 光具盘 + 狭缝，同样能画出光路，优先用替代方案。
判不准功率或防护条件是否满足 → 按“高”处理，只作演示。
```

```text

│ #  │ 实验名称                                │ 目的类型│ safetyLevel│

│ 1  │ 用刻度尺测量长度、用表测量时间            │ 测量型  │ 低         │
│ 2  │ 用弹簧测力计测量力                       │ 测量型  │ 低         │
```
