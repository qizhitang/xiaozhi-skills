# 英语听力材料设计 SKILL

> **一句话定位：** 听力不是教学生"听懂每个词"，而是教学生"用英语获取信息"——微技能训练是核心。

---

> 技术边界：本 SKILL 依赖能力 [M, V, X, F]，无该能力时按 shared/platform-conventions.md 降级。
> 无 V（语音合成）时不生成音频，只给文本 + 朗读要点，由老师或录音朗读；
> 无 X 时不输出跨次的听力能力变化统计，只呈现本次数据。

**本 SKILL 不做的三件事：**
- 不替老师做听写评分、不替老师给学员听力打分，只提供评估框架与教学建议。
- 不替学员做听力题。
- 听力材料必须标注 `copyrightStatus`（`自有` / `改编` / `公开可引用` / `仅存索引`）；不复制未授权音频。

**AI 生成的听力材料与题目**：按 `shared/ai-item-check.md` 自检（答案在录音里能直接听到、
干扰项来自原文的相近信息、词汇不超该学段词表），输出时一律标注
`【AI 生成，入库前请人工验算】`；未经老师确认不得入库或进卷
（对应 `classWorkspace.examBlueprints[].items[].aiGenerated` / `verifiedByTeacher`）。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

### 隐私与数据控制入口
- 查看：「查看我的班级听力记录」
- 更正：「更正我的班级听力记录」
- 删除：「删除我的班级听力记录」（删除后不可恢复，会先确认一次）

## 一、核心使命

英语听力教学常见的三个误区：

```text
误区① 听力=刷题：让学员做大量听力题，
        学员只关注"对错"，没关注"听懂"。

误区② 听力=逐字听：让学员听写每个词，
        学员压力大，没建立"听"的整体感。

误区③ 听力=只听不教：只放录音、对答案，
        没教听力策略、没训练微技能。
```

本 SKILL 要解决的是：
- **让听力"有目标"**：主旨/细节/推断/观点
- **让材料"有梯度"**：精听/泛听/听写 分层
- **让听法"有策略"**：预测/抓主旨/记关键
- **让微技能"可训练"**：每个微技能都有训练法

## 四、听力目标与中考题型

### 4.1 目标 ↔ 中考听力四节结构

> 排题型时按**中考听力的实际结构**走，不用托福/雅思式的"主旨/细节/推断/观点"四分法命题。
> 那四类是**能力目标**，中考的四节是**题型载体**——目标藏在题型里，不单独成节。

```text
┌──────────────────┬──────────────────────┬────────────────────────┐
│ 中考听力节次      │ 主要考的能力目标      │ 材料形态                │
├──────────────────┼──────────────────────┼────────────────────────┤
│ 第一节 听句选图/  │ 细节（关键词捕捉）    │ 单句或一问一答，读两遍  │
│   短对话选答语    │                      │                        │
│ 第二节 对话理解   │ 细节 + 关系/意图      │ 2-3 段对话，每段 3-4 问 │
│ 第三节 短文理解   │ 主旨 + 细节 + 推断    │ 1-2 篇短文             │
│ 第四节 听填信息   │ 细节（精确到词形拼写）│ 表格/笔记填空，读三遍   │
└──────────────────┴──────────────────────┴────────────────────────┘

语速：约 100-120 词/分钟（各地中考听力的常见区间）。
观点/态度题在中考里通常并入短文理解，不单设一节；课堂训练可单练，命题不必单列。

⚠️ 第四节"听填信息"最容易被省掉，但它是唯一无法靠排除法蒙对的题型——
   最能区分"真听懂了"和"猜对了"。设计整卷时不要省。
```

### 4.2 学员层次目标

```text
■ 基础层
  · 抓主旨 + 关键细节
  · 关键词识别

■ 中等层
  · 主旨 + 细节 + 简单推断
  · 数字/时间/地点

■ 提升层
  · 主旨 + 细节 + 推断 + 观点
  · 言外之意/讽刺
```

## 五、听力材料选编

### 5.1 材料来源（copyrightStatus 取值见 shared/vocab.md §11）

```text
┌──────────────┬────────────────────────┬──────────────┐
│ copyrightStatus │ 说明                 │ 适用          │
├──────────────┼────────────────────────┼──────────────┤
│ 自有          │ 老师自录 / 原创文本     │ 针对本班      │
│ 改编          │ 在自有或公开材料上改编  │ 调难度用      │
│ 公开可引用    │ 明确允许教学使用的公开材料 │ 拓展       │
│ 仅存索引      │ 教辅原题、历年真题       │ 只记出处，不复制内容 │
└──────────────┴────────────────────────┴──────────────┘

教材配套音频：按学校获得的授权范围在课堂内使用，不外传、不入公开资源库。
```

### 5.2 材料难度（可懂率口径只有一套）

```text
■ 可懂率：**首次听后能听懂约 90%**（全库唯一口径）
  · 换算成生词：生词密度 ≤ 2-3%，约 3-8 个新词
  · 依据：词汇覆盖率低于 95% 时，学员无法靠上下文补全，
    只能猜整段大意，练的就不是听力了
  · ⚠️ 不使用"可懂 70%"这一档：三成内容听不懂时，
    学员在课堂上的实际反应是放弃跟读，不是"跳一跳"

■ 语速：按学段取（与学生端听力训练师同一套）
  · 小学高段 90-100 / 初一 100 / 初二 110 / 初三 120 词/分钟
  · 上限就是中考语速；练得比中考快没有意义

■ 难度的四个可调项（先调前两项，再考虑后两项）
  · 生词个数 → 语速 → 句长 → 话题熟悉度
```

### 5.3 材料类型

```text
┌──────────┬────────────────────────┬────────────────────┐
│ 类型      │ 例子                    │ 对应中考节次        │
├──────────┼────────────────────────┼────────────────────┤
│ 短对话    │ 问路/买东西/约时间      │ 第一、二节          │
│ 长对话    │ 计划活动/讨论问题       │ 第二节              │
│ 独白/短文 │ 通知/介绍/个人经历      │ 第三节              │
│ 信息型    │ 表格式通知/日程/天气    │ 第四节（听填信息）  │
│ 故事      │ 短篇故事                │ 第三节的拓展         │
│ 影视片段  │ 动画/纪录片节选         │ 课堂拓展，不进测评   │
└──────────┴────────────────────────┴────────────────────┘
```

### 5.4 选材原则

```text
■ 主题贴近学员
  · 学员生活相关
  · 学员兴趣相关

■ 难度略高于水平
  · 首听可懂约 90%（生词 ≤2-3%），语速按学段（§5.2）
  · 有"跳一跳"感，但不是"够不着"

■ 类型多样
  · 对话 + 独白 + 新闻 + 故事
  · 不同口音/语速

■ 来源合法
  · 标注 copyrightStatus
  · 不复制未授权材料
```

### 5.5 材料版权

```text
✅ 每条材料入库时必须填 copyrightStatus（自有 / 改编 / 公开可引用 / 仅存索引）
✅ 教辅原题与历年真题一律 `仅存索引`：只记出处与题号，不复制内容进资源库
✅ 教材配套音频：按学校授权范围在课堂内使用

❌ 禁止：未授权复制音频文件
❌ 禁止：未授权转载 podcast、把付费内容录下来分发
❌ 禁止：把来源不明的音频放进班级共享资料
```

## 七、听中分层

```text
■ 第一遍（泛听）

  · 不查细节
```

## 八、听后任务

### 8.1 三类听后任务

```text
┌──────────┬────────────────────────┐
│ 任务      │ 描述                    │
├──────────┼────────────────────────┤
│ 复述      │ 学员用自己的话讲        │
│ 讨论      │ 围绕主题讨论            │
│ 写        │ 写读后感/概要           │
└──────────┴────────────────────────┘
```

### 8.2 复述任务

```text
■ 关键词复述（最常用，负担最低）
  · 老师给 3-5 个关键词，学员据此复述
  · 一条指令说完："用这几个词，说说他们在聊什么。"
  · 适合大部分课堂情境

■ 概要复述
  · 学员用自己的话讲主要内容，2-3 句
  · 适合短文材料

■ 角色复述
  · 学员扮演材料中的一方，用第一人称讲
  · 适合对话材料

⚠️ 不要求"逐字复述"：逐字复述考的是短时记忆容量，不是听力理解，
   而且失败率高、挫败感强。要检查细节请用听填信息，不要用逐字复述。

⚠️ 一次只给一条指令。"用自己的话说 3-5 句、不要翻译原文、说你记住的就好、
   不要求完整"——四条要求叠在一起，学员的负担比听力本身还大。
```

### 8.3 讨论任务

```text
■ 围绕主题
  · 学员讨论材料主题
  · 联系自己的生活

■ 角色讨论
  · 学员扮演材料中的角色
  · 表达观点
```

### 8.4 写任务

```text
■ 概要
  · 学员写 100-200 字概要

■ 读后感
  · 学员写"我的看法"

■ 同主题写作
  · 学员围绕同主题写
```

## 九、听力微技能训练

### 9.1 微技能总览（全库唯一一套，共 8 项）

> 本表是**唯一**的微技能清单。`references/micro-skill-training.md` 的训练法、
> `references/listening-rubric.md` 的评分、`student-listening-profile-template.md` 的档案栏位
> 都按这一套走，不再另立第二套名称。

```text
┌────┬──────────────┬────────────────────────┬──────────────────┐
│ 编号│ 微技能        │ 描述                    │ 主要在哪一节考    │
├────┼──────────────┼────────────────────────┼──────────────────┤
│ M1 │ 抓主旨        │ 听出"整段在讲什么"      │ 第三节 短文理解   │
│ M2 │ 抓细节        │ 听出具体信息            │ 第一、二节        │
│ M3 │ 抓数字/时间   │ 听准数字、时间、价格    │ 第二、四节        │
│ M4 │ 抓转折        │ 听出 but / however 之后 │ 第二、三节        │
│ M5 │ 抓连接        │ 听出 first/then/finally │ 第三、四节        │
│ M6 │ 抓语气        │ 听出说话人态度与意图    │ 第二、三节        │
│ M7 │ 推断          │ 听出没有明说的信息      │ 第三节            │
│ M8 │ 记笔记        │ 边听边记关键词          │ 第四节 听填信息   │
└────┴──────────────┴────────────────────────┴──────────────────┘

⚠️ 旧版曾出现过第二套名称（"预测/猜测词义/理解意图/捕捉主旨"），已废弃。
   "听前预测"是**教学环节**（§六），不是微技能；
   "猜测词义"归入词汇，由词汇教学处理，不占听力微技能的位置。
```

### 9.2 微技能训练法（详见 references/micro-skill-training.md）

```text
■ M1 抓主旨：听前预测 → 听首尾句 → 一句话说主题（不查细节）
■ M2 抓细节：先看题干圈关键词 → 带着问题听 → 只记实词
■ M3 抓数字/时间：先提示"这段有 3 个数字" → 专门听 → 听后核对
■ M4 抓转折：先只听 but / however / although，再听它后面的内容
■ M5 抓连接：听 first / then / next / finally，排出事件顺序
■ M6 抓语气：同一句话用三种语气读，让学员判断态度
■ M7 推断：先说出"我猜他会…"，听后修正，并说"我是从哪句听出来的"
■ M8 记笔记：只记名词、数字、动词原形，用符号缩写；听后互看笔记

训练顺序：M2 → M3 → M1 → M5 → M4 → M6 → M8 → M7（由具体到综合）
```

### 9.3 听写训练

```text
■ 听写三阶段
  · 阶段 1：听写短句（5-10 词）
  · 阶段 2：听写长句（15-25 词）
  · 阶段 3：听写段落（50-100 词）

■ 听写法
  · 听 1 遍：抓主旨
  · 听 2-3 遍：补全
  · 对照原文
  · 学员自己发现错误

■ 听写频率
  · 每周 1-2 次
  · 不频繁（学员压力大）
```

### 11.2 接口（唯一真实字段来源：`shared/class-teaching-workspace.schema.json`）

```text
读：
  classWorkspace.classProfile          → 学段、班额、课时（决定语速档与听力时长）
  classWorkspace.lessonPlans[]         → 本课教案与 segments（听力任务嵌在哪一段）

                                          只有总分时不得生成微技能画像）
  classWorkspace.itemStats[]           → 听力题的难度 P / 区分度 D
  classWorkspace.weaknessRank[]        → 班级听力弱项排序

写（均为待老师确认的条目，确认后落库）：
  classWorkspace.lessonPlans[].segments[]   → 听前/听中/听后三段的活动与分钟数
  classWorkspace.examBlueprints[].items[]   → 听力题条目（itemType = "听力"）
                                              AI 生成题 aiGenerated=true，
                                              老师验算后才可 verifiedByTeacher=true
  classWorkspace.weaknessRank[]             → 由听力题得分归纳出的弱项条目
  classWorkspace.reviewPlans[]              → 微技能训练的排布

写回学生档案（可选，需授权）：
  handoverType = "teacher_writeback"，recipient = xiaozhi-learning-dna
  前置：交接体中的授权快照 teacherWritebackConsent 必须为 true，否则丢弃并告知老师
  内容：weakKnowledgePointUpdates 列表（subject = "英语"，
        knowledgePoint 写微技能名如"听力·听填信息"），note 只写低敏事实描述
  ❌ 不写等级、不写学员真实姓名、不写"某某听力差"这类评价
```

## 十三、行为准则

| ✅ 应该做 | ❌ 不能做 |
|---------|---------|
| 听力目标（主旨/细节/推断/观点） | 听力=刷题 |
| 材料首听可懂约 90% | 听写=逐字复述 |
| 听前预测 | 只听不教 |
| 三遍听法 | 一遍就完事 |
| 微技能训练 | 学员不学策略 |
| 听力档案累积 | 学员不积累 |
| 学员化名 | 公开批评学员听力 |
