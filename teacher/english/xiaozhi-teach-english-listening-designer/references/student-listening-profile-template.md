# 学员听力档案模板

> 适用学段：小学高段与初中（7-9 年级）。

> 配合 `xiaozhi-teach-english-listening-designer` 使用。
> 栏位与 SKILL.md §9.1 的微技能 M1-M8 一一对应；**只记得分与强弱项，不记等级**。
> 等级须由老师对照 CSE 描述语判定，流程见
> `../../xiaozhi-teach-english-assessment/references/cefr-can-do-statements.md` §8。

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎧 听力档案 · [学员化名]（[年级]）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 数据来源
  · 逐题分：[有 / 只有总分]
  · ⚠️ 只有总分时，下面的微技能栏一律留空——微技能强弱只能由逐题分反推

■ 各节得分（按中考四节结构）
  · 第一节 听句选图/选答语：[N] / 5
  · 第二节 对话理解：      [N] / 8
  · 第三节 短文理解：      [N] / 7
  · 第四节 听填信息：      [N] / 5
  · 合计：[N] / 25   （核对：5+8+7+5 = 25）

■ 微技能 M1-M8（由逐题得分反推：全对 ✓ / 对一半 不稳定 / 全错 ✗）
  · M1 抓主旨：      [✓ / 不稳定 / ✗]
  · M2 抓细节：      [✓ / 不稳定 / ✗]
  · M3 抓数字/时间： [✓ / 不稳定 / ✗]
  · M4 抓转折：      [✓ / 不稳定 / ✗]
  · M5 抓连接：      [✓ / 不稳定 / ✗]
  · M6 抓语气：      [✓ / 不稳定 / ✗]
  · M7 推断：        [✓ / 不稳定 / ✗]
  · M8 记笔记：      [✓ / 不稳定 / ✗]

■ 听音速度
  · 舒适语速：[N] 词/分钟（能稳定听懂的档位）
  · 上限语速：[N] 词/分钟（再快就明显丢信息）
  · 参考档位：小学高段 90-100 / 初一 100 / 初二 110 / 初三 120

■ 词汇（写"哪一类词听不出来"，不写词汇量数字）
  · [如：数字连读听不出来；人名地名一带而过就丢；已学词在快读时反应不过来]
  · ⚠️ 不填"听力词汇量 N 词"——课堂上没有可靠的测量手段

■ 弱项状态（shared/vocab.md §4：待处理/初步弱项/顽固弱项/突破中/已攻克）
  · [微技能名]：[状态]，近 [N] 次测评中出现 [N] 次
  · [微技能名]：[状态]

■ 历次得分
  · 第 1 次：[N] / 25
  · 第 2 次：[N] / 25
  · 第 3 次：[N] / 25
  · （分数在同一水平区间内上涨是正常进步，不等于提级）

■ 下一步训练重点
  · [取 1-2 项最弱的微技能，写具体训练动作，见 micro-skill-training.md]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

> 写入位置：`classWorkspace.itemScores[]`（逐题分）、`classWorkspace.weaknessRank[]`（弱项条目）。
> 写回学生个人档案需 `teacherWritebackConsent = true`，只写微技能弱项与状态，不写等级、不写真实姓名。
