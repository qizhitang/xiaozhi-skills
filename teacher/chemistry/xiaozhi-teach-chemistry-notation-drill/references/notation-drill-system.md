## 一、各级清单

### 第 1 级：常见元素符号

氢 H、氦 He、碳 C、氮 N、氧 O、氟 F、氖 Ne、钠 Na、镁 Mg、铝 Al、硅 Si、磷 P、硫 S、氯 Cl、氩 Ar、钾 K、钙 Ca、锰 Mn、铁 Fe、铜 Cu、锌 Zn、银 Ag、钡 Ba、碘 I、汞 Hg、金 Au。

书写规范：由一个字母表示的大写；由两个字母表示的，第一个大写、第二个小写。

### 第 2 级：常见元素与原子团的化合价

| 化合价 | 元素 / 原子团 |
|---|---|
| +1 | K、Na、Ag、H；铵根 NH₄ |
| +2 | Ca、Mg、Ba、Zn；Cu（常见）；Fe（亚铁） |
| +3 | Al；Fe（铁） |
| −1 | Cl（金属氯化物中）、F；氢氧根 OH、硝酸根 NO₃、碳酸氢根 HCO₃ |
| −2 | O；硫酸根 SO₄、碳酸根 CO₃ |

### 第 3 级：常见物质的化学式（按类别）

| 类别 | 物质 |
|---|---|
| 单质 | O₂、H₂、N₂、C、S、P、Fe、Cu、Zn、Mg |
| 氧化物 | H₂O、H₂O₂、CO、CO₂、SO₂、CaO、CuO、Fe₂O₃、Fe₃O₄、MnO₂、P₂O₅、Al₂O₃ |
| 酸 | HCl、H₂SO₄、HNO₃、H₂CO₃ |
| 碱 | NaOH、KOH、Ca(OH)₂、Cu(OH)₂、Fe(OH)₃、Mg(OH)₂ |
| 盐 | NaCl、Na₂CO₃、NaHCO₃、CaCO₃、CuSO₄、FeSO₄、FeCl₂、FeCl₃、AgNO₃、BaCl₂、BaSO₄、KMnO₄、K₂MnO₄、KClO₃、NH₄Cl、NH₄NO₃、(NH₄)₂SO₄ |

## 三、常见错例库（改错题素材）

| 错误写法 | 改正 | 错在哪 |
|---|---|---|
| CO（表示钴元素） | Co | 第二个字母应小写；CO 是一氧化碳 |
| CaOH₂ | Ca(OH)₂ | 原子团个数大于 1 要加括号 |
| AlO | Al₂O₃ | 没按化合价交叉 |
| NaCO₃ | Na₂CO₃ | 化合价代数和不为零 |
| NH₄SO₄ | (NH₄)₂SO₄ | 铵根 +1、硫酸根 −2 |
| Fe + 2HCl = FeCl₃ + H₂↑ | Fe + 2HCl = FeCl₂ + H₂↑ | 铁与稀盐酸反应生成氯化亚铁 |
| Mg + O₂ ==点燃== MgO₂ | 2Mg + O₂ ==点燃== 2MgO | 改了化学式来"配平" |
| C + O₂ ==点燃== CO₂↑ | C + O₂ ==点燃== CO₂ | 反应物中有气体，生成物中的气体不标 ↑ |
| 3Fe + 2O₂ = Fe₃O₄ | 3Fe + 2O₂ ==点燃== Fe₃O₄ | 漏写反应条件 |

## 五、第 5 级：高中必修起点

依据《普通高中化学课程标准日常修订版（2017 年版 2025 年修订）》必修主题 2「氧化还原反应」「电离与离子反应」：

| 过关内容 | 题型 |
|---|---|
| 电离方程式 | 写出常见强电解质的电离方程式 |
| 离子方程式 | 按"写、拆、删、查"书写；判断给定离子方程式的正误（拆写、原子守恒、电荷守恒） |
| 电子转移 | 用双线桥标出指定反应的电子得失与数目 |

常见错例：Fe³⁺ + Cu = Fe²⁺ + Cu²⁺（原子守恒但电荷不守恒，应为 2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺）；碳酸钙拆写成离子（沉淀不拆）；Fe + 2H⁺ = Fe³⁺ + H₂↑（应生成 Fe²⁺，且原式电荷不守恒）。

