## 一、高中·第 6～8 级总览

| 6 | 原子结构示意图（1～20 号）、电子式、必修有机反应式 | 必修主题 3、主题 4；学业质量 2-1 | 高一学原子结构与化学键、简单的有机化合物时 |

## 二、高中·第 6 级：必修（合格考范围）

依据：必修主题 3 学业要求「能画出 1~20 号元素的原子结构示意图」「能判断简单离子化合物和共价化合物中的化学键类型」；电子式课标没有点名，依据学业质量 2-1「能用化学符号、模型等表示简单原子的结构、常见物质中的化学键」，深度按教材；必修主题 4 学业要求「能描述乙烯、乙醇、乙酸的主要化学性质及相应性质实验的现象，能书写相关的反应式」。"结构简式"课标只在选择性必修 3 点名，必修写反应式用到的乙烯、乙醇、乙酸、乙酸乙酯的结构简式按教材要求。

| 过关内容 | 题型 |
|---|---|
| 原子结构示意图 | 画出 1～20 号元素的原子与简单离子的结构示意图；说出与某离子核外电子排布相同的稀有气体原子；找错改错 |
| 电子式 | 先判断离子化合物还是共价化合物，再写常见物质的电子式（NaCl、MgCl₂、Na₂O；H₂O、NH₃、CO₂、N₂、HCl、CH₄）；用电子式表示形成过程（教材有此要求时） |
| 必修有机反应式 | 乙烯：燃烧、与溴的加成、与水（或 HCl、H₂）的加成、加聚；乙醇：与钠反应、燃烧、催化氧化；乙酸：与碳酸钠反应、酯化反应；结构简式里不省略官能团 |

**过关标准**（经验值，老师可调）：三项内容分开出卡，各自连续两次随堂过关全对。

**样题**

| 题 | 题目 | 答案 | 考的是 |
|---|---|---|---|
| 6-1 | 画出钾原子的结构示意图 | 圆圈内写 +19，弧线上由内向外依次写 2、8、8、1 | 最外层不超过 8 个电子（常错成 2、8、9） |
| 6-2 | 画出 S²⁻ 的结构示意图 | 圆圈内写 +16，弧线上依次写 2、8、8 | 阴离子的核外电子数 = 质子数 + 所带负电荷数 |
| 6-3 | 写出 MgCl₂ 的电子式 | Mg²⁺ 写在中间，两侧各写一个氯离子：Cl 周围 8 个电子，加方括号，括号外右上角标"−"；不能合写成 [Cl]₂⁻ | 离子化合物：方括号、电荷、相同离子分写 |
| 6-4 | 写出 CO₂ 的电子式 | C 与每个 O 之间 2 对共用电子，每个 O 另有 2 对未成键电子；C、O 周围都是 8 个电子，不加方括号、不标电荷 | 共价分子：不漏写未成键电子 |
| 6-5 | 改错：某同学把 HCl 写成离子化合物的电子式（H⁺ 与带方括号的 Cl⁻） | HCl 是共价化合物：H 与 Cl 之间 1 对共用电子，Cl 另有 3 对未成键电子，不写方括号和电荷 | 先判断化合物类型 |
| 6-6 | 改错：nCH₂=CH₂ → [CH₂=CH₂]ₙ（条件：催化剂） | 加聚时碳碳双键打开，链节是 —CH₂—CH₂—：nCH₂=CH₂ → [CH₂—CH₂]ₙ（条件：催化剂） | 链节里不再有双键 |
| 6-7 | 写出乙醇在铜作催化剂、加热条件下被氧气氧化的化学方程式 | 2CH₃CH₂OH + O₂ → 2CH₃CHO + 2H₂O（条件：Cu 或 Ag、△） | 产物是乙醛，不是乙酸 |
| 6-8 | 写出乙酸与乙醇发生酯化反应的化学方程式 | CH₃COOH + CH₃CH₂OH ⇌ CH₃COOCH₂CH₃ + H₂O（条件：浓硫酸、△） | 可逆符号与条件；乙酸乙酯的结构简式 |

**常见错误归类**（老师端七类，`shared/vocab.md §3`；一道错题只归一类）

| 老师端七类 | 常见表现 | 通用四维 |
|---|---|---|
| 知识漏洞 | 分不清离子化合物与共价化合物（把 HCl 写成离子式；以为含金属元素的化合物都是离子化合物）；乙醇催化氧化的产物记成乙酸 | 概念模糊 |
| 规则错误 | 钾画成 2、8、9；离子化合物的电子式不写方括号和电荷，或把 MgCl₂ 的两个 Cl⁻ 合写；共价分子漏写未成键电子；加聚产物的链节里仍写双键 | 概念模糊 |
| 计算错误 | 数价电子时数错（CO₂ 的电子式画出 14 个或 18 个电子） | 计算失误 |
| 审题错误 | 题目要离子的结构示意图却画了原子的；要结构简式却写成分子式 C₂H₆O | 读题失误 |
| 策略错误 | 写电子式前不先判断化合物类型；写有机反应式不先找官能团和断键位置 | 方法用错 |
| 表达/书写不规范 | 乙烯写成 CH₂CH₂（漏写碳碳双键）；酯化反应用"="或漏写"浓硫酸，△"；有机反应漏写条件 | 方法用错 |
| 习惯性失误 | 写完不数电子、不查原子守恒，漏掉的未成键电子、少写的 H₂O 没被发现 | 计算失误 |

## 三、高中·第 7 级：选择性必修 1（等级考范围）

依据：选择性必修 1 学业要求「能用热化学方程式表示反应中的能量变化」，教学提示「理解热化学方程式的书写规则」；学业要求「能分析、解释原电池和电解池的工作原理」，教学提示「电极反应、电极材料、离子导体、电子导体是电化学体系的基本要素」；主题 3 学业要求「能用化学用语正确表示水溶液中的离子反应与平衡」。

| 过关内容 | 题型 |
|---|---|
| 热化学方程式 | 由文字信息写热化学方程式：标聚集状态（s、l、g、aq），ΔH 的符号、数值与单位 kJ/mol，ΔH 与化学计量数对应（计量数可以是分数）；由已知方程式按盖斯定律写目标方程式；找错改错 |
| 电极反应式 | 原电池（酸性、碱性介质与常见化学电源）和电解池（阳极、阴极）的电极反应式与总反应；电镀的两极；逐式检查电荷守恒与原子守恒 |
| 电离与水解方程式 | 强电解质用"="，弱电解质用"⇌"，多元弱酸分步电离；盐类水解用"⇌"、一般不标"↑""↓"，多元弱酸根分步水解；辨认给定的式子是电离还是水解 |

**过关标准**（经验值，老师可调）：三项内容分开出卡，各自连续两次随堂过关全对；电极反应式按介质分卡。

**样题**

| 题 | 题目 | 答案 | 考的是 |
|---|---|---|---|

| 7-4 | 写出碱性（KOH 溶液）氢氧燃料电池的电极反应式和总反应 | 负极：2H₂ + 4OH⁻ − 4e⁻ = 4H₂O；正极：O₂ + 2H₂O + 4e⁻ = 4OH⁻；总反应：2H₂ + O₂ = 2H₂O | 碱性介质里不出现 H⁺；两极得失电子数相等 |
| 7-5 | 用惰性电极电解饱和食盐水，写出两极的电极反应式与总反应 | 阳极：2Cl⁻ − 2e⁻ = Cl₂↑；阴极：2H₂O + 2e⁻ = H₂↑ + 2OH⁻（也写作 2H⁺ + 2e⁻ = H₂↑，按教材）；总反应：2NaCl + 2H₂O ==通电== 2NaOH + H₂↑ + Cl₂↑ | 与电源正极相连的是阳极，发生氧化反应 |
| 7-6 | 写出 H₂CO₃ 的电离方程式和 NaHCO₃ 在水中的电离方程式 | H₂CO₃ ⇌ H⁺ + HCO₃⁻，HCO₃⁻ ⇌ H⁺ + CO₃²⁻（分步写）；NaHCO₃ = Na⁺ + HCO₃⁻ | 多元弱酸分步电离；强电解质用"=" |

| 习惯性失误 | 写完不查电荷守恒与原子守恒 | 计算失误 |

## 四、高中·第 8 级：选择性必修 2、3（等级考范围）

依据：选择性必修 2 学业要求「能结合能量最低原理、泡利不相容原理、洪特规则书写 1~36 号元素基态原子的核外电子排布式和轨道表示式，并说明含义」；选择性必修 3 内容要求「知道简单有机化合物的命名」，学业要求「能写出烃及其衍生物的官能团、简单代表物的结构简式和名称」「能描述和分析各类有机化合物的典型代表物的重要反应，能书写相应的反应式」「能写出典型的加聚反应和缩聚反应的反应式」。

| 过关内容 | 题型 |
|---|---|
| 核外电子排布式与轨道表示式 | 写 1～36 号元素基态原子（及常见离子）的电子排布式、简化电子排布式、价电子排布式（教材也叫价层电子排布式）；画轨道表示式；Cr、Cu 的排布；找出违反泡利不相容原理或洪特规则的写法 |
| 结构简式与命名 | 写官能团（碳碳双键、碳碳三键、羟基、氨基、碳卤键、醛基、酮羰基、羧基、酯基、酰胺基）与简单代表物的结构简式和名称；用系统命名法命名简单的烷烃、烯烃、醇；结构简式与键线式互写（给图） |
| 有机反应式 | 卤代烃的取代与消去（条件不同）；醇的催化氧化；醛的氧化（银氨溶液、新制 Cu(OH)₂）；酯的水解；典型的加聚与缩聚 |

**常见错误归类**（老师端七类，`shared/vocab.md §3`；一道错题只归一类）

| 老师端七类 | 常见表现 | 通用四维 |
|---|---|---|
| 知识漏洞 | Cr、Cu 按常规写成 3d⁴4s²、3d⁹4s²；分不清卤代烃取代与消去的条件 | 概念模糊 |
| 规则错误 | 轨道表示式违反洪特规则（2p 电子先成对）或泡利不相容原理（同一轨道两个电子自旋相同）；过渡金属形成离子时先失 3d 电子；命名时主链选错、编号方向错；缩聚反应漏写小分子或小分子数与端基不对应 | 概念模糊 |
| 计算错误 | 排布式各能级电子数之和与电子数对不上；数结构简式中的 H 数错 | 计算失误 |
| 审题错误 | 题目要价电子排布式却写了完整排布式；要离子却写了原子的；漏看"NaOH 的乙醇溶液" | 读题失误 |
| 策略错误 | 命名前不先找含官能团的最长碳链；写有机反应式不先看官能团与条件、找断键部位 | 方法用错 |
| 表达/书写不规范 | 结构简式漏写或写错官能团（CH₂=CH₂ 写成 CH₂CH₂，—CHO 写成 —COH）；键线式漏画官能团；有机反应漏写条件或小分子 | 方法用错 |
| 习惯性失误 | 写完不数 H、不查原子守恒 | 计算失误 |
