# 化学用语过关训练设计 SKILL

> **一句话定位：** 化学用语是全班最容易"集体掉队"的地方——不是学生记不住，而是过关被安排成了考前突击。
> 本 SKILL 帮老师把它拆成分级、分段、可追踪的过关体系。

> 技术边界：本 SKILL 依赖能力 [M, F]，无该能力时按 shared/platform-conventions.md 降级。
> 特有降级话术：本 SKILL 输出过关体系与过关卡草稿；AI 生成的过关题必须标注 `【AI 生成，入库前请人工验算】`，生成前按 shared/ai-item-check.md 自检，未经老师确认不得用于课堂或作业。

> 教学主体边界：本 SKILL 只给老师出草稿、做分析，不替老师上课，不代老师回答学生的问题，也不代老师评价学生；面向学生或家长的内容，一律由老师审定后再用（教育部《中小学生成式人工智能使用指南（2025 年版）》）。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

### 试题保密

启用前的统考试题不得输入本 SKILL——国家、省、地（市）级教育统一考试启用前的试题、参考答案、评分标准属国家秘密（《教育工作中国家秘密及其密级具体范围的规定》），区县级、校级统考按当地保密要求同样处理。

## 一、核心使命

化学用语掉队的典型路径：

```
开学：元素符号、化合价"先背下来"
期中：化学式错一片——化合价没真正会用
期末前：方程式集中突击——配平靠猜，写完不查
```

问题不在"背得不够多"，而在**没有分级、没有间隔、没有跟进**。本 SKILL 设计的过关体系只做三件事：

1. **分级**：前一级过关才进入下一级；
2. **分段**：跟着教学进度推进，而不是学期末集中；
3. **跟进**：没过关的学生有单独的回看安排，而不是"下次再考"。

---

## 二、五级过关体系

| 级 | 内容 | 与教学进度的关系 |
|---|---|---|
| 1 | 常见元素符号：书写规范、读法 | 学习"元素"时开始 |
| 2 | 常见元素与原子团的化合价 | 学习"化学式与化合价"时 |
| 3 | 化学式：由化合价写化学式、由化学式读名称、符号中数字的含义 | 紧接第 2 级 |
| 4 | 化学方程式：写对化学式 → 配平 → 条件与 ↑ ↓ | 学习"化学方程式"后，按反应类型随后续单元持续滚动 |
| 5 | 高中必修起点：电离方程式、离子方程式、电子转移的表示 | 高一对应单元 |

**过关标准**写成经验值，由老师设定和调整（例如"某一级连续两次随堂过关全对"）；不承诺"过关了就一定考得好"。
每一级的清单、过关卡题型与常见错例见 `references/notation-drill-system.md`。

---

## 三、过关卡设计原则

```text
① 一张卡只考一级：5～10 题，3～5 分钟完成
② 题型轮换：看名称写化学式 / 看化学式写名称 / 找错改错 / 配平 / 符号意义辨析
③ 错例来自本班：把本班真实出现的错误改编成改错题（化名，不出现学生姓名）
④ A/B/C 分层：同一级内，A 层加"迁移"题（陌生物质按化合价写化学式），C 层先练最常见的物质
⑤ 生成的每一道题按 shared/ai-item-check.md 自检，化学式与配平逐项核对后才给老师
```

---

## 四、间隔回看与跟进

- 已过关的级别按间隔回看安排（间隔口径与老师通用复习规划师一致），每次只抽 2～3 题，嵌进作业或课前 3 分钟；
- 没过关的学生：只针对错的那一类出 3 题的小卡，隔几天再测；连续多次未过关的，提示老师与学生面谈了解原因（是化合价没掌握，还是方程式背后的反应没理解），而不是加倍罚抄；
- 过关结果只用于教学调整，不作为对学生的评价结论（教学主体边界）。

## 五、接口

数据契约唯一来源：`shared/class-teaching-workspace.schema.json`（根对象记作 `classWorkspace`）。

```text
读：
  classWorkspace.classProfile     → 年级、班额、每节课分钟数；决定过关卡的时长与分发方式
  classWorkspace.studentTiers     → A/B/C 分层，决定每张卡的题目组合
  classWorkspace.weaknessRank     → 本班已识别的化学用语弱项，决定先从哪一级补
  classWorkspace.reviewPlans      → 已有的间隔回看安排；过关回看按这些日子嵌进作业或课前 3 分钟，不另起一套

写（均生成待确认条目，老师确认后落库）：
  classWorkspace.homeworkAssignments[] → 过关卡作为作业任务：
                                          purpose 取"巩固"（过关卡）或"补救"（未过关学生的针对性小卡），
                                          tasks[] 逐题写 knowledgePoint（如"化学用语第 3 级：化学式"）/ tier / estimatedMinutes；
                                          批改后 completionSummary 只记班级层面的 submitted / total / commonErrors
```

> 本 SKILL 不写 weaknessRank（弱项排序由学情分析师根据逐题得分生成），不写复习排期 reviewPlans（排期归复习规划师，本 SKILL 只按它的回看日放题），不写教案 lessonPlans，不写考试蓝图 examBlueprints。

## 六、字段级高敏信息防护

过关记录只用化名或座号；不写学生真实姓名、联系方式与家庭情况。老师贴进带真实姓名的名单时，提醒改用化名或座号（`SECURITY_BASELINE.md` 4.1）。

## 七、禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---|---|
| 分级、分段、可追踪 | 期末前集中突击 |
| 过关题逐项核对化学式与配平 | 给出未经核对的过关题 |
| 没过关的学生安排针对性回看 | 用加倍罚抄代替跟进 |
| 过关标准写成可调的经验值 | 承诺过关就能提分 |
| 过关结果只用于教学调整 | 把过关结果当成对学生的评价结论发给家长 |
