# 化学实验教学指导 SKILL

> **一句话定位：** 化学实验课的第一目标是安全，第二目标是让学生真的"看见"并"想通"——两者都要在课前算清楚。

> 技术边界：本 SKILL 依赖能力 [M, F]，无该能力时按 shared/platform-conventions.md 降级。
> 特有降级话术：本 SKILL 输出实验课的组织方案草稿，一切实验内容进课堂前须由老师按学校器材、场地与安全规定核实；与学校实验室管理规定不一致时以学校为准。
> 每个实验都要标注 `safetyLevel`（三档定义与判定顺序以 `shared/lab-safety.md` 为准）；`safetyLevel: 高` 的一律只作演示、不进分组，也不推荐学生在家做。

> 教学主体边界：本 SKILL 只给老师出草稿、做分析，不替老师上课，不代老师回答学生的问题，也不代老师评价学生；面向学生或家长的内容，一律由老师审定后再用（教育部《中小学生成式人工智能使用指南（2025 年版）》）。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

## 一、核心使命

化学实验课有两个常见的走偏：

```
走偏一：为了安全全改成看视频 → 学生必做实验变成"必看实验"，操作考试时第一次摸到仪器
走偏二：为了"让学生多动手"忽视分档 → 把应该演示的实验放进分组
```

本 SKILL 帮老师在课前把三件事算清楚：**这个实验归哪一档、能不能进分组、分组了怎么保证每个学生都真的动手**。

---

## 二、演示还是分组：按 safetyLevel 决定

| safetyLevel | 课堂形式 | 老师要做的 |
|---|---|---|
| 高 | 只作演示，或改用视频 / 仿真 | 老师操作，学生保持安全距离；讲清每一步的安全原因 |
| 中 | 可以分组 | 课前讲安全要点；全程在场；每组首次操作前确认装置；全员戴护目镜；备好急救用品、灭火用具与洗眼设施 |
| 低 | 直接分组 | 巡视即可 |

初中 8 个学生必做实验的档位与每个实验的组织要点见 `references/chemistry-lab-teaching.md` 第二节。

## 三、课前三笔账

数字全部来自 `classWorkspace.classProfile`，不凭印象估：

```text
① 分组账：班额 classSize ÷ 器材套数 = 每组人数
   每组超过 4 人时，保证"轮流操作"而不是"一人做、三人看"：给每个角色（操作、记录、观察、安全员）排轮换
② 时间账：每节课分钟数 periodMinutes − 讲安全要点 − 分发与归还器材 − 整理与废液处理 = 实际操作时间
   实际操作时间不够时，砍讲解不砍操作；分发器材超时就改成课前预置到各组桌面
③ 药品账：每组用量按"最少量"原则（液体 1～2 mL，固体盖满试管底部）；
   剩余药品与废液的回收容器、存放位置按学校危险化学品管理规定执行
```

## 四、课堂安全组织

安全规范以 `shared/lab-safety.md` 第三节为准，课前向学生讲清楚，至少包括：

- 药品取用"三不"与最少量原则；用剩的药品放入指定容器；
- 酒精灯的使用规范；加热试管的规范；
- 酸碱沾到皮肤或溅进眼睛：立即用大量流动的水冲洗，同时报告老师；
- 可燃性气体点燃前验纯；有毒气体在通风处或通风橱中进行。

**应急预案**：本 SKILL 只提示老师确认学校的应急流程（洗眼器、灭火器材的位置，急救联系方式），不给医疗处置建议；具体以学校实验室安全制度为准。

## 五、实验报告与现象记录

实验报告按"目的—原理—仪器药品—步骤—现象—结论—反思"组织。批改时重点看两处：

- **现象与结论是否分开**：现象只写感官感知到的，不出现生成物名称；
- **结论是否有现象支撑**：结论不能超出现象能支持的范围。

AI 只出批改要点草稿，不代老师给学生打分或写评语（教学主体边界）。

---

## 六、实验操作考试的组织

多地把理化生实验操作考试计入中考总分，考查清单、评分细则与分值以本地当年的考试说明为准。本 SKILL 帮老师：

- 把本地考试说明里的评分细则拆成课堂可练的"操作—原因—扣分点"清单；
- 设计模拟考的轮换与计时（按 classSize 与器材套数）；
- 提醒：模拟考只评规范与原因，不教省略步骤。

---

## 七、高中必修起点

《普通高中化学课程标准日常修订版（2017 年版 2025 年修订）》必修课程有 9 个学生必做实验（清单见 `references/chemistry-lab-teaching.md` 第三节）。本 SKILL 目前给出其中两个的组织要点：配制一定物质的量浓度的溶液、用化学沉淀法去除粗盐中的杂质离子——二者分别从初中的"配制溶液"与"粗盐提纯"升级而来，适合作为高一的衔接实验。其余必修必做实验暂不覆盖。

## 八、接口

数据契约唯一来源：`shared/class-teaching-workspace.schema.json`（根对象记作 `classWorkspace`）。

```text
读：
  classWorkspace.classProfile     → 年级、班额 classSize、每节课分钟数 periodMinutes；分组人数与器材安排由这里推出
  classWorkspace.lessonPlans      → 本课的 topic / objectives / segments，实验环节要嵌进已有的时间分配里
  classWorkspace.studentTiers     → A/B/C 分层，决定给多少操作支架
  classWorkspace.interactionLogs  → 上一次实验课的实际用时 segmentTimings、观察到的迷思 misconceptionsObserved、
                                     下次调整 adjustmentForNext

写（均生成待确认条目，老师确认后落库）：
  classWorkspace.lessonPlans[].segments[]      → 实验各环节的名称与分钟数（含讲安全、分发与归还器材、整理的固定开销）
  classWorkspace.lessonPlans[].questionChain   → 实验前后的提问链
  classWorkspace.homeworkAssignments[].tasks[] → 实验后的现象记录与反思任务
```

## 九、禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---|---|
| 每个实验先定 safetyLevel | 把高档实验放进分组 |
| 分组时排角色轮换，保证人人动手 | 用视频完全替代学生必做实验 |
| 安全规范以 shared/lab-safety.md 和学校制度为准 | 给出医疗处置建议 |
| 批改只出要点草稿 | 代老师给学生打分、写评语 |
| 操作考试只练规范与原因 | 教学生省略步骤应付评分 |
