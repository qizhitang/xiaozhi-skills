# 生物错因维度表

> 适用学段：初中生物学；第八节为高中的子类型。
> 本文档是 `xiaozhi-biology-error-dna` 的核心参考资源，定义生物六维错因、子类型、跨维度关联规则与交接契约；生物的其他学生端技能随包带的是同一份副本。
> 词表与阈值以 `shared/vocab.md` 为唯一来源；本表只定义生物子类型 ID 的含义（`shared/vocab.md §2`）。表中的概率与比例写成 `verify` 断言，由 CI 验算。
> 课程依据：《义务教育生物学课程标准（2022 年版）》（2025 年日常修订版如有调整，以修订版为准）；《普通高中生物学课程标准日常修订版（2017 年版 2025 年修订）》。
> 内容边界：本表只描述学习上的错误类型；涉及人体健康的内容以教材为准，不做诊断、不给用药或治疗建议（SECURITY_BASELINE.md 4.4）。
>
> ⚠️ **编码命名空间**：生物子类型一律用「S + 维度字母」两字母前缀（如 `SG02`）。

## 一、维度总览

| 维度 | 定义 | 交叉判定（怎么确认是这一维） | 通用四维 |
|---|---|---|---|
| 概念网络（SC） | 概念之间的关系混淆 | 只考这一对概念的纯净版辨析题，仍然错 | 概念模糊 |
| 结构与功能（SF） | 说不出结构怎样适应功能 | 请学生按"这个结构有什么特点 → 适合完成什么功能"讲一遍，讲不出 | 概念模糊 |
| 图表识读（SG） | 曲线、示意图、系谱图读错 | 请学生先说出坐标、单位和关键点，说错 | 读题失误 |
| 变量与实验设计（SV） | 实验设计与结果分析出错 | 能说出要研究的变量，却设计不出对照、控制不了其他条件 | 方法用错 |
| 表述与术语（SE） | 意思对，表述不规范 | 口头能说对，写成答案就丢分 | 方法用错 |
| 遗传与数据计算（SQ） | 概率、比例、倍数类题目的列式或计算出错 | 相关概念说得清（纯净版概念题做对），列式（如分母选错、运算关系用错）或计算出错 | 计算失误 |

**判定顺序**：先请学生复述图表或题干条件（排除 SG）→ 纯净版概念题（SC、SF）→ 实验题看变量（SV）→ 计算单独验算（SQ）→ 最后看表述（SE）。一道错题只记一个主维度。

## 二、维度①：概念网络（SC）

**定义：** 概念之间的包含、因果或对应关系混淆。**判断标准：** 只考这一对概念的纯净版辨析题仍然错 → SC。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| SC01 | 基因、DNA 与染色体的关系混淆 | 说"染色体就是基因"；不知道一个 DNA 分子上有许多个基因 | → 遗传推理教练 |
| SC02 | 光合作用与呼吸作用混淆 | 以为植物白天只进行光合作用、夜里才进行呼吸作用；原料与产物写反 | → SF02 |
| SC03 | 生态系统的组成混淆 | 漏掉阳光、水等非生物部分；把营腐生生活的细菌、真菌算成生产者 | → SG04 |
| SC04 | 分类单位的关系混淆 | 以为分类单位越大，生物之间的共同特征越多 | — |
| SC05 | 显性性状与隐性性状混淆 | 以为隐性性状在任何个体身上都表现不出来 | → SQ01 |
| SC06 | 免疫的概念混淆 | 分不清抗原与抗体，分不清非特异性免疫与特异性免疫 | — |

---

## 三、维度②：结构与功能（SF）

**定义：** 不能把结构特点和它所完成的功能联系起来。**判断标准：** 请学生按"结构特点 → 适合完成的功能"讲一遍，讲不出 → SF。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| SF01 | 细胞结构与功能对应错 | 说"细胞壁控制物质进出"（应是细胞膜）；以为所有植物细胞都有叶绿体 | → SG03 |
| SF02 | 器官结构与功能不能联系 | 说不出小肠的哪些结构特点适于吸收，说不出叶片的哪些结构适于光合作用 | → SC02 |
| SF03 | 只抓住一个结构特点 | 解释肺泡适于气体交换时只说"数量多"，漏了"肺泡壁和毛细血管壁都只由一层细胞构成" | → SE02 |
| SF04 | 适应的解释不完整 | 只描述生物的特征，不说明这个特征怎样帮助它在该环境中生存 | → SE03 |

## 四、维度③：图表识读（SG）

**定义：** 读曲线、示意图、系谱图时漏读或误读。**判断标准：** 请学生先说出坐标、单位和关键点，说错 → SG。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| SG01 | 坐标与单位没看清 | 把横坐标"温度"看成"时间"；忽略纵坐标的单位 | — |
| SG02 | 曲线关键点的含义读错 | 说不出曲线的起点、拐点、最高点、与横轴的交点各代表什么 | → 生物图表与材料题教练 |
| SG03 | 结构示意图辨认错误 | 在细胞、器官的结构示意图中标错结构名称 | → SF01 |
| SG04 | 食物网读错 | 数食物链时从分解者或非生物部分开始；把箭头方向理解反了 | → SC03 |
| SG05 | 遗传系谱图读错 | 看错男女符号，或把"患病"与"正常"的图例看反 | → 遗传推理教练 |

---

## 五、维度④：变量与实验设计（SV）

**定义：** 探究实验的设计、实施或分析出错。**判断标准：** 能说出要研究的变量，却设计不出对照、控制不了其他条件 → SV。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| SV01 | 缺少对照组 | 探究光对植物生长的影响，只设了有光的一组 | → 生物实验探究教练 |
| SV02 | 变量不唯一 | 两组除了要研究的条件外，温度、水分等其他条件也不同 | — |
| SV03 | 样本太少、没有重复 | 每组只用 1 粒种子或 1 只动物，结论不可靠 | — |
| SV04 | 结论超出证据 | 只用一种植物做了实验，就下结论"所有植物都是这样" | → SE04 |
| SV05 | 说不出步骤的目的 | 说不出"暗处理""酒精隔水加热"等步骤是为了什么 | → 生物实验探究教练 |

## 六、维度⑤：表述与术语（SE）

**定义：** 意思基本对，但表述不符合答题规范。**判断标准：** 口头说对，写成答案却丢分 → SE。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| SE01 | 术语不规范 | 用自造的说法代替教材术语；把"消化"与"吸收"混用 | — |
| SE02 | 要点不全 | 解释"结构与功能相适应"时只答出一点 | → SF03 |
| SE03 | 答非所问 | 问"意义"答成"过程"，问"原因"答成"结果" | — |
| SE04 | 实验结论表述不完整 | 结论只写"有影响"，不写在什么条件下、有什么影响 | → SV04 |

## 七、维度⑥：遗传与数据计算（SQ）

**定义：** 概率、比例、倍数类题目的列式或计算出错（含分母选错、运算关系用错）。**判断标准：** 先确认相关概念说得清（如显性与隐性、放大倍数的含义）；说得清而列式或计算出错 → SQ；概念本身说不清 → 回到 SC 或 SF。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| SQ01 | 分离比与概率算错 | 双眼皮（Aa）的父母生出的双眼皮孩子中，基因组成为 AA 的概率算成 1/4（应为 1/3） | → 遗传推理教练 |
| SQ02 | 生男生女的概率想错 | 以为"已经生了一个男孩，下一胎是女孩的概率更大"（每一胎都是 1/2） | — |
| SQ03 | 显微镜放大倍数算错 | 目镜 10× 与物镜 40× 相加得 50 倍（应相乘，为 400 倍） | → 生物实验探究教练 |

## 八、高中：子类型的升级

以下子类型对应《普通高中生物学课程标准》必修"分子与细胞""遗传与进化"两个模块，只在学生已进入高中时使用；编号接在初中子类型之后。

| 子类型ID | 名称 | 典型表现 | 对应的课标内容 |
|---|---|---|---|
| SC07 | 有丝分裂与减数分裂混淆 | 分不清同源染色体的联会、分离发生在哪一种分裂 | 必修 1 概念 2.3.1；必修 2 概念 3.2.1 |
| SC08 | 遗传信息的传递与表达混淆 | 把复制、转录、翻译的模板、原料或产物对错 | 必修 2 概念 3.1 |
| SF05 | 细胞器结构与功能对应错 | 说不出线粒体内膜向内折叠与有氧呼吸的关系 | 必修 1 概念 1.2 |
| SG06 | 光合作用曲线读错 | 把净光合速率当成总光合速率 | 必修 1 概念 2.2 |
| SV06 | 自变量、因变量与无关变量辨认错 | 探究温度对酶活性的影响时，把酶的用量当成自变量 | 必修 1 概念 2 的教学活动 |
| SQ04 | 自由组合的概率算错 | AaBb × AaBb 的后代中双显性个体的比例算成 3/16（应为 9/16） | 必修 2 概念 3.2 |
| SQ05 | 伴性遗传的概率算错 | 母亲是红绿色盲基因携带者（XᴮXᵇ）、父亲正常（XᴮY），把"子女中患病"与"儿子中患病"的概率混为一谈（分别为 1/4 与 1/2） | 必修 2 概念 3.2.4 |
| SQ06 | 碱基比例算错 | 已知双链 DNA 中 A 占 20%，把 G 算成 20%（应为 30%） | 必修 2 概念 3.1.2 |
| SQ07 | 基因频率算错 | 已知 AA、Aa、aa 分别占 30%、60%、10%，把 A 的基因频率算成 30%（应为 60%） | 必修 2 概念 4 的教学活动 |

## 九、跨维度关联规则

```text
SC ↔ SQ：遗传概率算错（SQ01），根子常在显性、隐性与基因组成的关系没想清（SC05）
          → 先画遗传图解，再算概率

SF ↔ SE：结构与功能只答一点（SF03），写成答案就是要点不全（SE02）
          → 按"结构特点 → 功能"逐条列

SG ↔ SC：食物网读错（SG04），常因为生态系统的组成本身没分清（SC03）

SV ↔ SE：结论超出证据（SV04），表述上就会写成以偏概全（SE04）

主维度判定仍以交叉判定为准；跨维度只作为突破时的联动线索。
```

## 十、与通用错题本的协作边界

### 10.1 职责分工

```text
通用错题本（表面层，唯一计数权威）：
  → 接收所有科目错题；基础四维分类（shared/vocab.md §1）
  → 28 天累计计数与"顽固"判定（shared/vocab.md §5）

生物错误DNA（深度层，持有本表）：
  → 生物六维深度分类与子类型定位
  → 跨维度关联分析；顽固弱项专项突破（计数不在本层）

生物的其他学生端技能：
  → 在各自的练习里用本表定位子类型；学生同意后经错题本交接，不自行建错题档案
```

### 10.2 维度映射

```text
通用四维（basicDimension）  →  生物六维可能映射   →  判断依据
────────────────────────────────────────────────────────
概念模糊                →  SC / SF         →  概念关系，还是结构与功能？
读题失误                →  SG              →  复述图表后立刻会做
方法用错                →  SV / SE         →  实验设计，还是表述规范？
计算失误                →  SQ              →  概念说得清，列式或计算出错
```

反向映射（写回通用层时用，`shared/vocab.md §2`）：生物 SC、SF → 概念模糊；SG → 读题失误；SV、SE → 方法用错；SQ → 计算失误。
本 SKILL 的判断写入 `biologyDimension`，通用层的 `basicDimension` 保持错题本给出的值不变。
