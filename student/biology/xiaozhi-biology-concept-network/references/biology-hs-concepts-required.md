### 2.1 生物大分子的结构与功能（SF07）

课标：必修 1.1.6、1.1.7（原文见第一节）；3.1.2 写明「碱基的排列顺序编码了遗传信息」。肽键、脱水缩合、变性是教材说法。
**先问**："你先说说，蛋白质的功能由哪些结构上的因素决定？""鸡蛋煮熟后，蛋白质的哪一层结构变了？连接氨基酸的键断了没有？"

| 大分子 | 结构特点（教材说法） | 适合完成的功能 |
|---|---|---|
| 蛋白质 | 氨基酸以肽键连成肽链，再盘曲折叠成特定的空间结构；氨基酸的种类、数目、排列顺序和空间结构千差万别 | 功能多样：催化（绝大多数酶）、运输、免疫、信息传递、构成细胞结构等（教材说法）；「细胞的功能主要由蛋白质完成」 |
| 核酸 | 由核苷酸聚合而成；DNA 一般是两条链、含脱氧核糖和碱基 T，RNA 一般是一条链、含核糖和碱基 U | 核苷酸（碱基）的排列顺序千变万化，适于储存与传递遗传信息 |

- 常见说法与订正：①"两种多肽的氨基酸种类和数目相同，功能就相同"——功能「取决于氨基酸序列及其形成的空间结构」，还要看排列顺序和空间结构；②"高温使蛋白质的肽键断裂"——高温、过酸、过碱破坏的是空间结构（变性），肽键一般不断；煮熟的蛋白质更容易消化，也是因为空间结构变得伸展、松散（教材说法）；③"DNA 和 RNA 只差在碱基 T 和 U"——五碳糖也不同，链数一般也不同。
- 结构的多样性可以用数算给学生看：只看 10 个碱基对长的一段 DNA，碱基对的排列方式就有 4¹⁰ = 1 048 576 种。
- 纯净版检验："两种多肽的氨基酸种类和数目完全相同，它们的功能一定相同吗？为什么？"（要点：不一定；氨基酸的排列顺序和空间结构可能不同）

### 2.2 细胞各部分的结构、分工与合作（SF05、SF06）

课标：必修 1.2、1.2.1—1.2.4（原文见第一节）。内容要求没有逐个点名细胞器，1.2.2 概括为「多个相对独立的结构」；除 2.2.3 和观察叶绿体的活动点到叶绿体外，线粒体、内质网、高尔基体、核糖体等名称只见于附录 2 的教学案例；各细胞器的结构与分工按教材讲。SF05 是单个结构的"结构特点 → 功能"对不上，SF06 是讲分工合作时漏了环节。
**先问**："挑一个细胞器，按'它的结构有什么特点 → 适合完成什么功能'讲一遍。"（SF05）"一种分泌到细胞外的蛋白质，从合成到分泌依次经过哪些结构？哪些结构没有直接'经手'，却少不了？"（SF06）

| 结构 | 结构特点（教材说法） | 适合完成的功能（教材说法） |
|---|---|---|
| 质膜 | 以磷脂双分子层为基本支架，蛋白质镶嵌、贯穿其中 | 「质膜将细胞与其生活环境分开，能控制物质进出，并参与细胞间的信息交流」 |
| 线粒体 | 双层膜，内膜向内折叠形成嵴，扩大了内膜面积 | 有氧呼吸的主要场所，为生命活动供能 |
| 叶绿体 | 双层膜，类囊体堆叠成基粒，扩大了受光面积 | 光合作用的场所 |
| 核糖体 | 没有膜 | 合成蛋白质 |
| 内质网、高尔基体 | 单层膜；内质网膜面积大，与核膜相连 | 内质网加工、运输蛋白质并合成脂质；高尔基体对蛋白质再加工、分类和包装 |
| 细胞核 | 双层核膜，有核孔 | 「遗传信息主要储存在细胞核中」；核孔实现核质之间的物质交换和信息交流 |

- 分工合作的链条（以分泌蛋白为例，教材说法）：核糖体上合成肽链 → 内质网加工 → 囊泡运输 → 高尔基体再加工、包装 → 囊泡与质膜融合，胞吐出细胞；全过程主要由线粒体供能，细胞核里的遗传信息指导合成。漏掉其中任何一环，就是说不完整（SF06）。
- 常见说法与订正：①只会说"线粒体是动力车间"，说不出内膜折成嵴与功能的关系——嵴扩大了膜面积，为有氧呼吸有关的酶提供附着位点（SF05）；②"原核细胞没有任何细胞器"——课标写的是「原核细胞与真核细胞的最大区别是原核细胞没有由核膜包被的细胞核」，原核细胞也有核糖体（教材说法）（SF05）；③"分泌蛋白只由内质网和高尔基体完成"——漏了核糖体、线粒体和细胞核（SF06）。
- 纯净版检验："唾液腺细胞合成并分泌唾液淀粉酶。按顺序说出这种酶经过的结构，再说出主要为这个过程供能的结构。"（要点：核糖体 → 内质网 → 高尔基体 → 质膜，结构之间靠囊泡运输；供能的主要是线粒体）学生手上的题若是胰腺细胞分泌消化酶，示范就换成这类唾液腺的材料，反过来也一样。

### 2.3 物质进出细胞的方式（SC09）

课标：必修 2.1、2.1.1—2.1.3（原文见第一节）只分被动运输、主动运输和胞吞、胞吐，用「载体蛋白」一词；自由扩散、协助扩散、转运蛋白、通道蛋白是教材说法。
**先问**："你先说说，主动运输和被动运输各是什么意思，你是按什么分的？""一种物质进出细胞要借助膜上的蛋白质，能不能就此断定它是主动运输？"

| 对比项 | 被动运输（教材再分自由扩散、协助扩散） | 主动运输 | 胞吞、胞吐 |
|---|---|---|---|
| 浓度方向 | 顺浓度梯度 | 逆浓度梯度 | 主要运输大分子，不按浓度梯度判断 |
| 能量 | 不需要额外提供能量 | 需要 | 需要（教材说法） |
| 膜上的蛋白质 | 自由扩散不需要；协助扩散需要转运蛋白（教材说法） | 需要载体蛋白 | 不靠载体蛋白逐个转运，由膜包裹形成囊泡（教材说法） |
| 例子（教材说法） | O₂、CO₂ 进出细胞；葡萄糖进入红细胞 | 细胞从低浓度环境中吸收某些离子 | 分泌蛋白分泌到细胞外 |

- 常见说法与订正：①"需要膜上蛋白质帮忙的就是主动运输"——协助扩散也需要转运蛋白，区分要看是不是逆浓度梯度、要不要能量；②"消耗能量的一定是主动运输"——胞吞、胞吐也消耗能量；③"大分子也能靠载体蛋白运进细胞"——课标写的是「大分子物质可以通过胞吞、胞吐进出细胞」。
- 纯净版检验："某种离子进入细胞时，细胞内的浓度已经比细胞外高；加入抑制细胞呼吸的物质后，吸收速率明显下降。它进入细胞的方式是什么？依据是哪两条？"（要点：主动运输；逆浓度梯度，需要细胞呼吸提供能量）

### 2.4 酶与 ATP（SC11）

课标：必修 2.2.1、2.2.2（原文见第一节）。课标写的是「绝大多数酶」；糖类是「生命活动的主要能源物质」，ATP 是「驱动细胞生命活动的直接能源物质」。活化能、腺苷三磷酸、ADP 是教材说法。
**先问**："你先说说，酶在反应里起什么作用？ATP 又在反应里提供什么？""一个反应加了酶以后变快了，是因为酶给反应提供了能量吗？"

| 对比项 | 酶 | ATP |
|---|---|---|
| 是什么 | 绝大多数是蛋白质，少数是 RNA（教材说法） | 腺苷三磷酸（教材说法） |
| 起什么作用 | 催化：降低化学反应的活化能（教材说法），本身不提供能量 | 水解释放能量，直接供给各项生命活动 |
| 反应前后 | 本身不变，可以反复起作用 | 水解成 ADP 和 Pi，再利用细胞呼吸（植物还有光合作用）提供的能量重新合成（教材说法） |
| 特点（教材说法） | 高效性、专一性，作用条件较温和，活性受温度、pH 等影响 | 细胞中含量很少，与 ADP 的相互转化十分迅速 |

- 二者的联系：ATP 的合成与水解都要酶催化；许多耗能的反应又要 ATP 水解供能（教材说法）。
- 常见说法与订正：①"酶都是蛋白质""酶为反应提供了能量"——课标写的是「绝大多数酶」；酶降低活化能，不提供能量；②"ATP 是细胞的主要能源物质"——主要能源物质是糖类，ATP 是直接能源物质；③"低温和高温都会使酶永久失活"——低温只是抑制，回到适宜温度活性可以恢复，高温、过酸、过碱破坏空间结构，失活不可恢复（教材说法）；④"ATP 的 A 指腺嘌呤"——A 指腺苷，由腺嘌呤和核糖组成（教材说法）。
- 纯净版检验："两份相同的酶，一份在低温下放置，一份经过高温处理，再都放回最适温度。哪一份的活性能恢复？为什么？"（要点：低温放置的那份；高温破坏了酶的空间结构）

### 2.5 光合作用与细胞呼吸：物质与能量的变化（SC10）

课标：必修 2.2.3、2.2.4（原文见第一节）；学业要求「从物质与能量视角，探索光合作用与呼吸作用」。高中学生的这类错误记 SC10，不再记初中的 SC02；场所、条件的初中对照见 `references/biology-concept-map.md` 第三节，这里只讲物质与能量。光反应、暗反应、有氧呼吸、无氧呼吸在内容要求里都没有，是教材说法。
**先问**："你先说说，光合作用的能量从哪里来、最后存到哪里？细胞呼吸呢？""光合作用产生的 ATP 和细胞呼吸产生的 ATP，用途一样吗？"

| 对比项 | 光合作用 | 细胞呼吸 |
|---|---|---|
| 物质变化 | 「二氧化碳和水转变为糖与氧气」；O₂ 中的氧来自水（教材说法，同位素标记的科学史实验） | 有氧呼吸把有机物分解成二氧化碳和水；无氧呼吸生成酒精和二氧化碳，或生成乳酸（教材说法） |
| 能量变化 | 光能 → 糖分子中的化学能（必修 2.2.3） | 有机物中的化学能 → 有氧呼吸：一部分转移到 ATP 中，其余以热能形式散失；无氧呼吸：只释放少量能量（其中一部分转移到 ATP 中），大部分能量仍留在酒精或乳酸中（教材说法；具体数据按所用教材） |
| 分阶段（教材说法） | 光反应在类囊体薄膜上产生 ATP 等，供暗反应在叶绿体基质中把二氧化碳合成糖 | 有氧呼吸分三个阶段，第一阶段在细胞质基质，后两个阶段在线粒体；无氧呼吸全在细胞质基质 |
| 什么时候进行 | 有光时 | 活细胞时刻都在进行 |

- 常见说法与订正：①"植物白天只进行光合作用，夜里才进行细胞呼吸"——细胞呼吸时刻在进行；②"细胞呼吸把有机物里的能量全部转移到 ATP 中"——只有一部分转移到 ATP 中：有氧呼吸时其余以热能形式散失，无氧呼吸时葡萄糖中的大部分能量还留在酒精或乳酸中（教材说法）；③"光合作用产生的 ATP 供给主动运输等各项生命活动"——教材口径是光反应产生的 ATP 用于暗反应，细胞其他生命活动所需的 ATP 主要来自细胞呼吸；④"光合作用释放的 O₂ 来自 CO₂"——来自水（教材说法）。
- 纯净版检验："有同学说：'叶绿体把捕获的光能转换并储存为糖分子中的化学能；细胞呼吸再把糖分子中的能量全部转移到 ATP 中。'前后两句，哪一句不对？怎么改？"（要点：后一句；细胞呼吸只把一部分能量转移到 ATP 中——有氧呼吸时其余以热能形式散失，无氧呼吸时大部分能量还留在酒精或乳酸中）

### 2.6 有丝分裂与减数分裂（SC07）

课标：必修 2.3.1、3.2.1、3.2.2（原文见第一节）。同源染色体、联会、四分体、染色单体、着丝粒在课标里都是 0 处，是教材说法（部分教材把两次分裂写作减数分裂Ⅰ、Ⅱ，着丝粒旧称着丝点）。
**先问**："你先说说，有丝分裂和减数分裂产生的子细胞，各拿去做什么？""二倍体生物的体细胞进行有丝分裂时，细胞里有没有同源染色体？它们会两两配对吗？"

| 对比项 | 有丝分裂 | 减数分裂 |
|---|---|---|
| 发生在 | 体细胞增殖 | 有性生殖的生物形成精细胞或卵细胞时 |
| 复制与分裂（教材说法） | 染色体复制一次，细胞分裂一次 | 染色体复制一次，细胞连续分裂两次 |
| 子细胞的染色体数 | 与亲代细胞相同 | 减半（必修 3.2.1） |
| 同源染色体（教材说法） | 有，但不联会、不分离 | 第一次分裂中联会、分离，这就是染色体数目减半的原因 |
| 意义 | 「保证了遗传信息在亲代和子代细胞中的一致性」 | 与受精作用一起，使子代的染色体数目与亲代相同，并产生多种多样的配子（教材说法） |

- 人的数字（教材说法）：体细胞 46 条染色体（23 对），精子、卵细胞各 23 条，受精卵恢复为 46 条。只算非同源染色体的自由组合，一个人产生的配子，染色体组合就有 2²³ = 8 388 608 种（约 839 万）——这是「基因组合有多种可能」在细胞层面的来源之一。
- 常见说法与订正：①"有丝分裂过程中没有同源染色体"——二倍体体细胞里一直有，只是不联会；②"染色体数目减半发生在第二次分裂，因为着丝粒分裂了"——减半发生在第一次分裂（同源染色体分离），着丝粒分裂使染色体数目暂时加倍；③"一个卵原细胞经减数分裂得到 4 个卵细胞"——只得到 1 个卵细胞（教材说法）。
- 纯净版检验："减数分裂过程中，染色体数目减半发生在第几次分裂？是染色体的什么行为造成的？"（要点：第一次分裂；同源染色体分离，分别进入两个子细胞）

### 2.7 细胞分化、衰老与死亡（SC12）

课标：必修 2.3.2、2.3.3，以及 3.1.4 里的「细胞分化的本质是基因选择性表达的结果」。课标只写「细胞衰老和死亡是一种自然的生理过程」；细胞凋亡、细胞坏死、细胞自噬、细胞的全能性都是教材说法。
**先问**："你先说说，细胞分裂和细胞分化各让细胞发生了什么变化？""人的神经细胞和肌肉细胞差别很大，它们细胞核里的遗传信息一样吗？差别从哪里来？"

| 对比项 | 细胞分裂 | 细胞分化 | 细胞衰老与死亡 |
|---|---|---|---|
| 带来什么 | 细胞数目增多 | 细胞种类增多，形态、结构和功能出现稳定的差异（教材说法） | 衰老：代谢减慢、多种酶的活性降低等；死亡：分为细胞凋亡（由基因决定的程序性死亡）和细胞坏死（不利因素造成）（均为教材说法） |
| 遗传信息 | 有丝分裂使亲子代细胞保持一致 | 一般不变，不同细胞表达的基因不同 | 一般不变 |
| 对个体 | 生长、补充 | 形成各种组织和器官 | 细胞凋亡对个体有积极意义，如蝌蚪尾的消失；多细胞生物的细胞衰老与个体衰老不同步（教材说法） |

- 常见说法与订正：①"细胞分化使细胞数目增多"——数目增多靠分裂，分化使种类增多；②"分化后的细胞遗传物质变了，所以功能不同"——遗传物质一般不变，差别在于表达的基因不同；③"细胞死亡对个体都是有害的"——细胞凋亡是正常的生命进程（教材说法）；④"个体衰老就是细胞衰老"——多细胞生物中两者不同步，单细胞生物的细胞衰老就是个体衰老（教材说法）。
- 纯净版检验："同一个人的唾液腺细胞和肌肉细胞，细胞核里都有唾液淀粉酶基因吗？都合成唾液淀粉酶吗？"（要点：都有；只有唾液腺细胞合成——基因选择性表达）
- 癌变与基因突变有关（必修 3.3.3），转遗传推理教练。

### 2.8 遗传信息的传递与表达（SC08）

课标：必修 3.1.3、3.1.4（原文见第一节）；学业要求「通过复制、转录、翻译等过程传递和表达遗传信息」。"中心法则"在课标里只见于选修，必修的依据是 3.1.3、3.1.4，教材用它概括这些过程，是教材说法；mRNA、tRNA、密码子也是教材说法。
**先问**："你先说说，复制、转录、翻译各自'照着什么、用什么原料、做出什么'？""半保留复制的'半'是什么意思？"

| 对比项（教材说法） | 复制 | 转录 | 翻译 |
|---|---|---|---|
| 模板 | DNA 的两条链 | DNA 的一条链 | mRNA |
| 原料 | 4 种脱氧核苷酸 | 4 种核糖核苷酸 | 氨基酸 |
| 产物 | 两个 DNA 分子 | RNA | 多肽链 |
| 主要场所 | 细胞核 | 细胞核 | 核糖体 |
| 碱基配对 | A 与 T、G 与 C | A 与 U、T 与 A、G 与 C | mRNA 上的密码子与 tRNA 上的反密码子配对：A 与 U、G 与 C |

- 常见说法与订正：①"转录以 DNA 的两条链为模板"——以一条链为模板；②"翻译的原料是核糖核苷酸"——是氨基酸，核糖核苷酸是转录的原料；③"半保留复制后，一个子代 DNA 全是新链、另一个全是旧链"——每个子代 DNA 都是一条旧链、一条新链；④"密码子在 tRNA 上"——密码子在 mRNA 上，tRNA 上的是反密码子。
- 表观遗传（必修 3.1.5）挂在这条线上：「碱基序列不变但表型改变」，和碱基序列改变的基因突变（必修 3.3.1）不是一回事；甲基化等机制是教材说法。这一条的错误也记 SC08，和基因突变、环境引起的变异怎样区分，细讲转遗传推理教练。
- 纯净版检验："一个 DNA 分子复制一次，得到两个 DNA 分子。每个子代 DNA 分子里，有几条链来自原来的 DNA？"（要点：各 1 条）

### 2.9 可遗传变异（SC13）

基因突变、基因重组、染色体变异的类型与来源（必修 3.3.1—3.3.5，子类型 SC13）转遗传推理教练；本技能只在第三节"遗传信息"那条线上画出它们的位置。

### 2.10 进化的观点（SC14）

课标：必修 4.2、4.2.1—4.2.5（原文见第一节）；模块说明「进化的本质是遗传物质的改变」。拉马克、达尔文、用进废退、种群基因频率、地理隔离、生殖隔离、协同进化在内容要求里都没有，是教材说法（"基因频率"只见于必修概念 4 的教学活动）。
**先问**："你先说说，自然选择'选'的是什么？""变异是在选择之前就有，还是被环境'造'出来的？进化一定要形成新物种吗？"

| 对比项 | 常见的错误直觉 | 课标与教材的讲法 |
|---|---|---|
| 变异从哪里来 | 环境需要什么，生物就产生什么变异 | 选择之前，种群里就存在各种可遗传变异，变异是不定向的（教材说法） |
| 环境起什么作用 | 诱导出变异 | 选择：「具有优势性状的个体在种群中所占比例将会增加」 |
| 进化的单位 | 个体 | 种群（教材说法） |
| 新物种 | 出现新性状就是新物种 | 「变异、选择和隔离可导致新物种形成」；教材以生殖隔离的形成为标志 |

- 常见说法与订正：①"抗生素使细菌产生了抗药性"——抗药性变异在用药前就存在，抗生素起选择作用（教学活动「探讨耐药菌的出现与抗生素滥用的关系」）；②"生物为了适应环境而主动变异"——变异不定向，适应是自然选择的结果；③"有了地理隔离就形成了新物种"——教材以生殖隔离的形成作为新物种形成的标志；④"进化就是形成新物种""种群基因频率一改变就形成了新物种"——种群的遗传组成发生改变就是进化（教材说法：种群基因频率改变），但不一定形成新物种，新物种的形成以生殖隔离为标志。
- 纯净版检验："某地长期使用同一种除草剂，除草效果越来越差。有人说'除草剂让杂草产生了抗药性变异'。这句话错在哪里？应该怎么说？"（要点：抗药性变异在使用除草剂之前就存在于杂草种群中；除草剂起选择作用，使抗药个体所占的比例增加）

## 三、跨模块联系：用生命观念串起来

课标列出的生命观念是「结构与功能观、物质与能量观、进化与适应观、稳态与平衡观等」，必修两个模块主要用前三个；模块说明还写到「细胞生命活动中物质、能量和信息变化的统一」。下面三条线都跨越两个模块，每个箭头请学生读成一句完整的话，读不出来的就是没想清的地方。

```text
物质与能量（物质与能量观）
  光能 ─叶绿体捕获、转换→ 糖分子中的化学能（必修 2.2.3）
  糖等有机物 ─细胞呼吸→ 生命活动可以利用的能量，经 ATP 驱动（2.2.4、2.2.2）
  ATP ─供能给→ 主动运输（2.1.2）、胞吞胞吐（2.1.3）、物质合成（1.2.2）
  每一步化学反应 ─都靠→ 酶催化，酶活性受温度、pH 影响（2.2.1）

结构与功能（结构与功能观）
  氨基酸序列 → 空间结构 → 蛋白质的功能（1.1.6）
  质膜 ─选择透过性→ 控制物质进出（1.2.1、2.1.1）
  各种细胞器 ─既分工又合作→ 完成分泌等生命活动（1.2.2、1.2.4）
  双螺旋与碱基互补配对 ─保证→ 半保留复制准确进行（3.1.2、3.1.3）

遗传信息（最后接到进化与适应观）
  碱基的排列顺序 ─储存→ 遗传信息，主要在细胞核（1.1.7、3.1.2、1.2.3）
  有丝分裂 ─保持→ 亲子代细胞遗传信息一致（2.3.1）；减数分裂与受精 ─传给→ 子代（3.2.1、3.2.2）
  遗传信息 ─经 RNA 指导→ 蛋白质 ─表现为→ 性状；分化是基因的选择性表达（3.1.4）
  可遗传变异（3.3）─经自然选择→ 适应（4.2）；化石、比较解剖学和胚胎学的证据（4.1.1）与细胞、分子层面的共同特征（4.1.2）─共同支持→ 当今生物有共同的祖先
```

- 必修 1 的学业要求把第一条线概括为「阐明细胞生命活动过程中贯穿着物质与能量的变化」，并要求「解释光合作用在碳中和方面的重要作用」。
- 选考生物的学生，再把三条线接到选择性必修：物质与能量接生态系统的能量流动与物质循环，遗传信息接基因工程，结构与功能接稳态与调节（稳态与平衡观），见 `references/biology-hs-concepts-elective.md` 第四节。

## 四、课标原词与教材说法

引课标时照原词；讲解可以用教材说法，但要说明是教材的叫法，不说"课标要求掌握××"。教材用词各版本不尽相同，以学生所用的版本为准。

| 课标原文的写法 | 教材常用说法（教材说法） | 讲解时注意 |
|---|---|---|
| 「质膜」 | 细胞膜 | 课标的"细胞膜"只出现在选必的神经细胞膜一处 |
| 「被动运输、主动运输」、「载体蛋白」 | 自由扩散、协助扩散；转运蛋白（载体蛋白、通道蛋白） | 被动运输的细分是教材的 |
| 「通常由 20 种氨基酸」 | 部分教材写 21 种 | 引课标不改数字，答题按所用教材 |
| 「细胞呼吸」 | 有氧呼吸、无氧呼吸及其各阶段 | 阶段细节属教材 |
| 「叶绿体从太阳光中捕获能量」 | 光反应、暗反应（卡尔文循环） | 课标只到能量转换 |
| 「细胞衰老和死亡」 | 细胞凋亡、细胞坏死、细胞自噬 | 课标没有这三个词 |
| 「基因的分离和自由组合」 | 孟德尔的分离定律、自由组合定律 | 课标不点定律名 |
| 「性染色体上的基因传递和性别相关联」 | 伴性遗传 | 课标用"概述" |
| 「可由此预测子代的遗传性状」 | 遗传图解 | 课标没有规定预测用什么方式表示 |
| 「表型」 | 表现型（旧教材） | 引课标写"表型" |
| 「交叉互换」 | 部分教材写作"互换" | 以所用教材为准 |
| 「染色体结构和数量的变异」 | 染色体组、单倍体、多倍体 | 课标没有这三个词 |
| 「遗传信息通过 RNA 指导蛋白质的合成」 | 中心法则 | 课标里"中心法则"只见于选修 |
| 「常规遗传学技术」 | 杂交育种、诱变育种等 | 必修里"育种"0 处，育种方法的分类属教材 |
| 「隔离」 | 地理隔离、生殖隔离；协同进化 | 课标只写"隔离" |
| — | 同源染色体、等位基因、联会、四分体、显性、隐性、测交 | 课标都是 0 处 |
| — | 斐林试剂、双缩脲试剂、苏丹Ⅲ染液、解离液 | 课标只写活动名称，试剂和步骤是教材做法，转生物实验探究教练 |

## 五、合格考与等级考：必修是共同的范围

- 范围：「学业水平合格性考试的内容范围包括普通高中生物学课程“分子与细胞”和“遗传与进化”两个必修模块」，「合格性考试分为纸笔测试和实验操作考查两种形式」；等级考在这两个必修模块之外再加三个选择性必修模块。所以必修的概念网，选不选考生物都要画。
- 深度：「学业质量水平 1 是高中生毕业应当达到的要求，也是生物学科学业水平考试合格等级的划定依据。学业质量水平 3 是生物学科学业水平等级性考试命题可达到的最高要求。」水平 2 原文没写考试用途；水平 3 是上限，不说"按水平 3 命题"。

| 学业质量 | 水平 1（合格等级的划定依据） | 水平 2 | 水平 3（等级考命题可达到的最高要求） |
|---|---|---|---|
| 情境 | 「在熟悉的、结构良好的」 | 「在较为陌生的、结构良好的」 | 「在较为陌生的、结构不良的」 |
| 生命观念 | 「运用特定的生命观念，从微观和宏观层面描述生命活动规律」 | 「从微观和宏观层面解释生命活动规律」 | 「综合运用多个生命观念，从微观和宏观层面阐释生命活动规律」 |
| 遗传与变异 | 「举例说明遗传与变异的物质基础和规律，以及生物的多样性和统一性」 | 「说明遗传与变异的物质基础和规律，以及生物的多样性和统一性的原因」 | 「阐释遗传与变异的物质基础和规律，以及生物的多样性和统一性的原因」 |

- 本技能怎么用：第一节的条目两类学生都要画到，都按条目自己的动词讲到位；差别在检验的情境。没有选考生物的学生，纯净版检验用熟悉的、结构良好的情境（水平 1）；选考生物的学生，再换成较为陌生的情境（水平 2、3），并把必修的网接到选择性必修。
- 合格考的实验操作考查范围是必修"教学提示"中要求的学生实验活动，哪几条在内原文没有逐条认定，以本地当年的考试说明为准；实验的准备转生物实验探究教练。
