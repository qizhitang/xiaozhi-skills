## 一、DNA 的结构：碱基互补配对的推理（必修 3.1.2，SQ06）

课标：「概述 DNA 分子是由四种脱氧核苷酸构成，通常由两条碱基互补配对的反向平行长链形成双螺旋结构，碱基的排列顺序编码了遗传信息」。教学活动：「搜集 DNA 分子结构模型建立过程的资料并进行讨论和交流」、「制作 DNA 分子双螺旋结构模型」。

- 配对规则（教材）：A 与 T 配对，G 与 C 配对；A 与 T 之间有 2 个氢键，G 与 C 之间有 3 个。一对配对的碱基叫一个碱基对（教材说法）：碱基数 = 碱基对数 × 2。
- 课标写的是「通常由两条碱基互补配对的反向平行长链」：题目给的 A 与 T 不相等时，先想是不是单链 DNA（试卷常见的设问）。
- 推论（教材与试卷常用，只对双链 DNA 成立）：
  1. A = T，G = C，所以 A + G = T + C，嘌呤与嘧啶（教材说法）各占全部碱基的 50%；
  2. A + T 在一条链中所占的比例 = 在互补链中的比例 = 在整个 DNA 分子中的比例，G + C 也一样；
  3. 一条链中 (A + G)/(T + C) = k 时，互补链中是 1/k，整个 DNA 分子中是 1（如 k = 0.8，互补链中是 1.25）；
  4. 某碱基占一条链的比例，换成占整个 DNA 分子的比例，要除以 2。
- 算之前先问"分母是谁"：整个分子的碱基、一条链的碱基，还是碱基对。

**示范 1（SQ06）**：某双链 DNA 分子中，G 与 C 之和占全部碱基的 44%，甲链中 A 占甲链碱基的 26%。（1）整个 DNA 分子中，T 占全部碱基的多少？A 与 G 之和占多少？（2）甲链的互补链（乙链）中，A 占乙链碱基的多少？

先请你自己推：配对的碱基之间有什么数量关系？"占甲链"和"占整个分子"，分母各是什么？

核对：
- （1）A + T = 100% − 44% = 56%，A = T = 28%；G = C = 22%，A + G = 28% + 22% = 50%。
- （2）由推论 2，甲链中 A + T 也占 56%，甲链的 T = 56% − 26% = 30%；乙链的 A 与甲链的 T 配对，所以乙链的 A 占 30%。
- 常见错算：26%（以为两条链的 A 一样多）、28%（用了整个分子的比例）、15%（又除以 2，把分母换成了整个分子）。

```verify
{"claim": "示范1：G+C 占 44% 时 A+T 占 56%，T 占 28%，G 占 22%，A+G 占 50%；甲链 A 占 26% 时甲链 T 占 30%，乙链 A 占 30%，与错算 26%、28%、15% 都不同；推论3：k = 0.8 时互补链为 1.25", "expr": "[100 - 44, (100 - 44) / 2, 44 / 2, (100 - 44) / 2 + 44 / 2, (100 - 44) - 26, [26, 28, 15].includes((100 - 44) - 26), 1 / 0.8]", "expect": [56, 28, 22, 50, 30, false, 1.25]}
```

## 二、DNA 的复制：半保留复制的数量推理（必修 3.1.3，SQ08）

课标：「概述 DNA 分子通过半保留方式进行复制」。

- 半保留（教材）：两条链解开，各自作为模板（教材说法），按碱基互补配对合成新链；每个子代 DNA 分子都含一条亲代的链（母链）和一条新合成的链（子链）。
- 课标只要求"概述"。下表是教材习题与试卷常用的算法，前提是：从 1 个 DNA 分子开始，连续复制 n 次，每次都完整、没有差错。

| 问的是 | 复制 n 次后 | n = 3 时 |
|---|---|---|
| DNA 分子数 | 2ⁿ | 8 |
| 脱氧核苷酸链数 | 2ⁿ⁺¹ | 16 |
| 含亲代母链的 DNA 分子 | 2 个，占全部分子的 2/2ⁿ | 2 个，占 1/4 |
| 亲代母链 | 2 条，占全部链的 2/2ⁿ⁺¹ | 2 条，占 1/8 |
| 只含新链的 DNA 分子 | 2ⁿ − 2 | 6 |
| 共消耗某种游离的脱氧核苷酸（亲代 DNA 中这种有 m 个） | (2ⁿ − 1) × m | 7m |
| 只算第 n 次复制消耗的 | 2ⁿ⁻¹ × m | 4m |

- 含亲代母链的分子数与亲代母链数都是 2，所以题目常问"占几分之几"：一个以分子为分母，一个以链为分母，相差一倍。
- 消耗的原料要减去 1 个分子的量：2ⁿ 个分子里还保留着亲代的两条链，合起来正好是 1 个 DNA 分子，这部分不用新原料。
- 同位素标记（教材：用 ¹⁵N 标记的实验证明了半保留复制）：亲代 DNA 两条链都含 ¹⁵N、原料只含 ¹⁴N，复制 n 次后，含 ¹⁵N 的 DNA 分子是 2 个（都是一条 ¹⁵N 链加一条 ¹⁴N 链），只含 ¹⁴N 的是 2ⁿ − 2 个，而含 ¹⁴N 的是全部 2ⁿ 个。"含"与"只含"要分清。

**示范 2（SQ06 → SQ08）**：某 DNA 分子有 800 个碱基对，其中 C 有 300 个。（1）这个 DNA 分子中 A 有多少个？（2）连续复制 3 次，共需游离的腺嘌呤脱氧核苷酸（教材说法）多少个？其中第 3 次复制需要多少个？（3）若亲代 DNA 的两条链都含 ¹⁵N，原料只含 ¹⁴N，复制 3 次后，含 ¹⁵N 的 DNA 分子占全部 DNA 分子的几分之几？含 ¹⁵N 的链占全部链的几分之几？只含 ¹⁴N 的 DNA 分子有几个？

先请你自己推：800 个碱基对是多少个碱基？复制 3 次后有几个 DNA 分子，哪些链是原来就有的？

核对：
- （1）碱基共 1600 个；C = G = 300，A = T = (1600 − 600) ÷ 2 = 500。把 800 当成碱基总数会算出 100，这一步错记 SQ06。
- （2）共需 (2³ − 1) × 500 = 3500 个；第 3 次复制前有 4 个分子、复制后有 8 个，需要 2² × 500 = 2000 个。常见错算：2³ × 500 = 4000（忘了亲代的两条链不用新原料）、3 × 500 = 1500（以为复制几次就乘几）。
- （3）含 ¹⁵N 的分子 2 个，占 2/8 = 1/4；含 ¹⁵N 的链 2 条，占 2/16 = 1/8；只含 ¹⁴N 的分子 8 − 2 = 6 个（含 ¹⁴N 的是 8 个）。

```verify
{"claim": "示范2与表：800 个碱基对共 1600 个碱基，C=G=300 时 A=500，错把 800 当碱基总数得 100；复制 3 次共需 3500 个、第 3 次需 2000 个，错算 4000、1500；含 15N 的分子占 1/4、含 15N 的链占 1/8；只含 14N 的分子 6 个、含 14N 的 8 个；n=3 时链数 16，原料倍数 7 与 4", "expr": "[800 * 2, (800 * 2 - 300 * 2) / 2, (800 - 300 * 2) / 2, (Math.pow(2, 3) - 1) * 500, Math.pow(2, 3 - 1) * 500, Math.pow(2, 3) * 500, 3 * 500, 2 / Math.pow(2, 3), 2 / Math.pow(2, 3 + 1), Math.pow(2, 3) - 2, Math.pow(2, 3), Math.pow(2, 3 + 1), Math.pow(2, 3) - 1, Math.pow(2, 3 - 1)]", "expect": [1600, 500, 100, 3500, 2000, 4000, 1500, 0.25, 0.125, 6, 8, 16, 7, 4]}
```

## 三、基因表达：模板、原料、产物与"碱基数—氨基酸数"（必修 3.1.4，SC08、SQ08）

课标：「概述 DNA 分子上的遗传信息通过 RNA 指导蛋白质的合成，细胞分化的本质是基因选择性表达的结果，生物的性状主要通过蛋白质表现」；还有「概述多数生物的基因是 DNA 分子的功能片段，有些病毒的基因在 RNA 分子上」。"转录""翻译"两个词见于学业要求（〇节）；中心法则是教材说法，课标只在选修里出现。

三个过程（教材；课标只写到「通过 RNA 指导蛋白质的合成」和「复制、转录、翻译」）：

| 过程 | 模板（教材说法） | 原料 | 产物 | 碱基配对 |
|---|---|---|---|---|
| 复制 | 亲代 DNA 的两条链 | 4 种游离的脱氧核苷酸 | 2 个 DNA 分子 | A—T、G—C |
| 转录 | DNA 的一条链（以基因为单位） | 4 种核糖核苷酸 | RNA（如 mRNA） | 模板链上的 A 对 U、T 对 A，G 与 C 互配 |
| 翻译 | mRNA | 氨基酸（蛋白质「通常由 20 种氨基酸分子组成」） | 多肽链（教材说法），再形成蛋白质 | tRNA 上的反密码子与 mRNA 上的密码子配对（教材说法），A—U、G—C |

- 真核细胞中，复制和转录主要在细胞核里进行，翻译在细胞质的核糖体上（教材）。mRNA 上 3 个相邻的碱基决定 1 个氨基酸，叫一个密码子；终止密码子不对应氨基酸（教材说法）。
- RNA 病毒的遗传信息怎样传递（RNA 复制、逆转录）按教材讲；"逆转录"在课标里只见于选修。
- 3.1.4 的后两句是概念：同一个体的不同体细胞一般含有相同的遗传信息，表达的基因不同；基因通过控制酶的合成来控制代谢、进而控制性状，也能通过控制蛋白质的结构直接控制性状（教材）。这些说不清时转生物概念网络构建器（细胞分化记 SC12）。
- 模板、原料、产物、配对对错记 SC08；纯净版概念题做对、只在数量上错，才记 SQ08。

纯净版检验（SC08）：某基因的模板链上 A 占 20%、T 占 30%（题目设定这一段全部转录），转录出的 mRNA 上 U 占多少？A 占多少？——U 与模板链上的 A 配对，占 20%；A 与模板链上的 T 配对，占 30%。答成"U 代替了 T，所以 U 占 30%"，是配对关系没分清（SC08）。

"碱基数—氨基酸数"的算法（教材与试卷常用，课标没写）：
- 1 个氨基酸 ↔ mRNA 上 3 个碱基（1 个密码子）↔ 基因中 6 个碱基（3 个碱基对，两条链都算）。只算编码氨基酸的部分、不算终止密码子时，基因中碱基数 : mRNA 碱基数 : 氨基酸数 = 6 : 3 : 1。
- 为什么常说"至少""最多"：实际的 mRNA 上还有不编码氨基酸的碱基（例如终止密码子），基因中也有不编码氨基酸的序列。由氨基酸数推碱基数，说"至少"；由碱基数推氨基酸数，说"最多"。
- 终止密码子算不算看题目：写了"考虑终止密码子"，m 个氨基酸对应的 mRNA 至少 3(m + 1) 个碱基、基因至少 6(m + 1) 个；没写时常见的做法是不计（6 : 3 : 1），以所用教材和本地考试说明为准。
- 看清给的是"碱基"还是"碱基对"，是基因（双链）还是 mRNA（单链）。

**示范 3（SQ08）**：（1）某蛋白质由一条多肽链构成，含 150 个氨基酸。不考虑终止密码子，控制它合成的 mRNA 至少有多少个碱基？基因中至少有多少个碱基？考虑终止密码子时又各是多少？（2）某基因有 1200 个碱基对，不考虑终止密码子，它控制合成的多肽链最多含多少个氨基酸？

先请你自己推：一个氨基酸对应几个碱基？题目给的是 mRNA 还是基因，是碱基还是碱基对？

核对：
- （1）mRNA 至少 150 × 3 = 450 个碱基，基因至少 150 × 6 = 900 个碱基；考虑终止密码子时分别至少 453、906 个。常见错算：基因也写 450（忘了基因是双链）。
- （2）1200 个碱基对 = 2400 个碱基，最多 2400 ÷ 6 = 400 个氨基酸（考虑终止密码子则最多 399 个）。常见错算：1200 ÷ 6 = 200（把碱基对当成碱基）。

## 四、表观遗传（必修 3.1.5）

课标：「概述某些基因中碱基序列不变但表型改变的表观遗传现象」。

- 讲到"概述"：说得出是什么、举得出一个例子、能和基因突变分开；机制细节按教材讲，不展开。
- 抓住课标这句话的两半：「碱基序列不变」「表型改变」。
- 常见教材的定义还多一条：基因表达和表型的变化可以遗传（以所用教材为准）。常讲的机制是 DNA 甲基化（教材说法，课标没写）：甲基化会抑制基因的表达。
- 和相近的情况分开：碱基序列改变了 → 基因突变（第五节）；碱基序列没变、只由环境引起、不能遗传 → 不可遗传的变异（教材说法）。
- 把表观遗传说成基因突变，记 SC08（见本文第九节）。

**示范 4**：判断下面三种情况各属于哪一类，说出依据。
- 甲：某种植物的两株个体基因型相同，基因 X 的碱基序列也完全相同；其中一株的基因 X 被甲基化、几乎不表达，花色与另一株不同，这株的部分后代也表现出同样的花色。
- 乙：另一株个体的基因 X 中有一个碱基对被替换，花色也改变了。
- 丙：同一品种的两株，一株种在肥沃的土里、一株种在贫瘠的土里，株高不同；把它们的种子种在相同条件下，后代的株高没有差别。

先请你自己判断：碱基序列变没变？变化能不能传给后代？

核对：甲是表观遗传（序列没变，表达改变且能遗传）；乙是基因突变（碱基的替换）；丙是环境引起、不能遗传的变异。只看课标那一句（序列不变、表型改变），甲和丙分不开，要用上教材定义里"可以遗传"这一条。

## 五、可遗传的变异：类型与来源（必修 3.3.1—3.3.5，SC13）

课标：「由基因突变、染色体变异和基因重组引起的变异是可以遗传的」。
- 3.3.1「概述碱基的替换、插入或缺失会引发基因中碱基序列的改变」
- 3.3.2「阐明基因中碱基序列的改变有可能导致它所编码的蛋白质及相应的细胞功能发生变化，甚至带来致命的后果」
- 3.3.3「描述细胞在某些化学物质、射线，以及病毒的作用下，基因突变概率可能提高，而某些基因突变能导致细胞分裂失控，甚至发生癌变」
- 3.3.4「阐明进行有性生殖的生物在减数分裂过程中，染色体所发生的自由组合和交叉互换，会导致控制不同性状的基因重组，从而使子代出现变异」
- 3.3.5「举例说明染色体结构和数量的变异都可能导致生物性状的改变甚至死亡」
- 学业要求「基于证据，论证可遗传的变异来自基因重组、基因突变和染色体变异」

| 类型（课标原词） | 变的是什么 | 教材常讲的补充（教材） |
|---|---|---|
| 基因突变 | 一个基因内部的碱基序列：碱基的替换、插入或缺失 | 产生新的基因；光学显微镜下看不到；发生在体细胞中的，一般不能通过有性生殖传给后代 |
| 基因重组 | 基因本身不变，控制不同性状的基因在减数分裂中重新组合 | 非同源染色体上的基因自由组合；同源染色体的非姐妹染色单体之间交叉互换（同源染色体、非同源染色体都是教材说法）；不产生新基因，产生新的基因型 |
| 染色体变异 | 染色体的结构或数量 | 结构：缺失、重复、倒位、易位（教材说法），改变基因的数目或排列顺序；数量：个别染色体增减，或以染色体组（教材说法）为单位成倍增减；光学显微镜下能看到 |

- 课标用的是「交叉互换」，所用教材的叫法可能不同；引课标照原词。自由组合与交叉互换时染色体怎样动，可以借课标活动「观察减数分裂的装片或视频，运用模型模拟染色体的变化」来看。
- 3.3.2 说的是「有可能」：碱基序列变了，蛋白质不一定变（例如替换后的密码子仍对应同一种氨基酸）；插入或缺失 1 个碱基对，mRNA 上其后的密码子都会错位，影响往往更大（教材）。
- 3.3.3 只要求"描述"。学生借此问自己会不会得癌症、要不要做检查时，不做判断、不给医疗建议，提示告诉家长并向医生咨询。

染色体组、单倍体、多倍体（都是教材说法；课标只写「染色体结构和数量的变异」）：
- 一套形态、功能各不相同的非同源染色体叫一个染色体组；由受精卵发育成、体细胞含两个染色体组的叫二倍体，含三个或更多的叫多倍体。
- 由配子直接发育成的个体叫单倍体，不管它含几个染色体组：四倍体（4 个染色体组）的配子含 2 个染色体组，由这种配子发育成的单倍体也含 2 个。先看发育起点：配子 → 单倍体；受精卵 → 再数染色体组。

判断变异类型的步骤：

```text
① 遗传物质变没变？
   没变、只由环境引起、不能遗传 → 不可遗传的变异（教材说法）
   碱基序列没变、基因表达的变化能遗传 → 表观遗传（第四节），不归入下面三类
② 变在一个基因内部的碱基序列（替换、插入或缺失）→ 基因突变
③ 基因本身没变，控制不同性状的基因在减数分裂中重新组合 → 基因重组
④ 染色体的一段缺失、重复、倒转，或接到非同源染色体上 → 染色体结构变异
   染色体条数增减，或染色体组成倍增减 → 染色体数量的变异
⑤ 写出依据："变的是……，发生在……，所以是……"
```

常混的地方：

| 容易混的一对 | 怎么分 |
|---|---|
| 碱基对的缺失 与 染色体片段的缺失 | 缺的是一个基因内部的几个碱基对 → 基因突变；缺的是含有若干基因的一段染色体 → 染色体结构变异 |
| 交叉互换 与 易位 | 同源染色体的非姐妹染色单体之间交换 → 基因重组；非同源染色体之间交换 → 染色体结构变异 |
| 性状分离、受精时配子的随机结合 与 基因重组 | 课标写的是「控制不同性状的基因重组」，发生在「减数分裂过程中」：只涉及一对等位基因（教材说法）的性状分离、受精时的随机结合都不是基因重组 |
| 单倍体 与 "只有一个染色体组" | 看是不是由配子发育而来，染色体组可以不止一个 |
| "可遗传的变异" 与 "一定传给后代" | 可遗传指遗传物质改变了；体细胞中的基因突变一般不经有性生殖传给后代（教材） |
| 基因突变 与 表观遗传 | 看碱基序列变没变（第四节） |

纯净版检验（SC13）："交叉互换和易位都交换了染色体片段，为什么一个是基因重组、一个是染色体结构变异？"

**示范 5（SC13）**：（1）—（5）各属于哪一类变异？（6）是不是基因重组？都说出依据。
- （1）某基因中缺失了 3 个碱基对。
- （2）一条染色体缺失了含有若干个基因的片段。
- （3）基因型为 AaBb 的个体中，A 与 B 在一条染色体上，a 与 b 在它的同源染色体上；减数分裂时这对同源染色体的非姐妹染色单体之间发生交叉互换，产生了含 Ab、aB 的配子。
- （4）一条染色体的一段接到了另一条非同源染色体上。
- （5）某种植物的体细胞中多了一条染色体。
- （6）基因型为 Aa 的植株自交，后代中出现了 aa 个体。

先请你自己判断：每一项变的是一个基因内部的碱基序列、基因的组合，还是染色体？

核对：（1）基因突变；（2）染色体结构变异（缺失）；（3）基因重组；（4）染色体结构变异（易位）；（5）染色体数量的变异；（6）不是基因重组：只涉及一对等位基因，是它们分离后配子随机结合的结果（性状分离）。（1）和（2）、（3）和（4）是两组对照，最能看出分没分清。

## 六、人类遗传病：可以检测和预防（必修 3.3.6）

课标：「举例说明人类遗传病是可以检测和预防的」；教学活动「调查常见的人类遗传病并探讨其预防措施」；教学提示「基于近年来基因组研究的进展，教师可介绍通过生物信息学方法筛查遗传病的技术。」。

## 七、常规遗传学技术的应用（必修 2 学业要求）

课标：学业要求「运用遗传与变异的观点，解释常规遗传学技术在现实生产生活中的应用」。

| 杂交育种 | 基因重组 | 把分散在不同亲本上的优良性状组合到一起；需要的类型在杂种后代中才分离出来，还要连续自交、选择才能得到稳定遗传的纯合子，年限长 |

## 八、基因频率与自然选择（必修 4.2，SQ07）

课标：「适应是自然选择的结果」；「举例说明种群内的某些可遗传变异将赋予个体在特定环境中的生存和繁殖优势」；「阐明具有优势性状的个体在种群中所占比例将会增加」。教学活动「用数学方法讨论自然选择使种群的基因频率发生变化」；学业要求「运用统计与概率的相关知识，解释并预测种群内某一遗传性状的分布及变化」。模块说明写的是「进化的本质是遗传物质的改变」。

- 深度照课标活动：会由基因型的数目或比例算基因频率，会在"某种个体存活或繁殖较少"时重算一次，看出有利于生存和繁殖的基因频率上升。"种群基因库""生物进化的实质是种群基因频率的改变"是教材说法。
- 算法（教材与试卷常用）：
  - 某基因的频率 = 该基因的数目 ÷ 这对基因的总数（每个个体有 2 个）；
  - 由基因型比例算：A 的频率 = AA 的比例 + Aa 比例的一半；
  - 选择之后，先算留下来（活到繁殖期或留下后代）的个体中各基因型的数目，再重算，分母换成留下来的个体的基因总数；
  - X 染色体上的基因：女性有 2 个、男性只有 1 个，分母是 2 × 女性数 + 男性数。例：某群体女性 100 人中携带者 8 人、患者 1 人，男性 100 人中患者 7 人（题目设定），这个隐性致病基因的频率 = (8 + 2 × 1 + 7) ÷ 300 ≈ 5.7%；分母用 400 会算成约 4.3%。
- 拓展（教材的讨论题用到，课标没有这个公式）：种群很大、个体间随机交配、没有迁入和迁出、没有突变、没有自然选择时，下一代 AA、Aa、aa 的比例是 p²、2pq、q²（p、q 分别是 A、a 的频率），基因频率代代不变。只有题目说明满足这些前提时才能用；尤其不能拿 aa 的比例开平方当作 a 的频率。
- 进化的观点说错（如"抗生素使细菌产生了耐药的变异""变异是为了适应环境才产生的"）记 SC14，转生物概念网络构建器；现代生物进化理论、隔离与新物种形成（4.2.4、4.2.5）的概念也在那里讲。课标活动「探讨耐药菌的出现与抗生素滥用的关系」只讨论选择的道理，不给用药建议。

**示范 8（SQ07）**：某昆虫种群有 100 只个体：AA 50 只、Aa 20 只、aa 30 只。（1）A、a 的基因频率各是多少？（2）环境改变后，AA、Aa 个体都能活到繁殖期，aa 个体只有一半能活到繁殖期。活到繁殖期的个体中，A、a 的基因频率各是多少？（3）这说明了什么？

先请你自己推：100 只个体共有多少个这对基因？选择之后，分母变没变？

- （1）这对基因共 200 个；A 有 2 × 50 + 20 = 120 个，频率 60%；a 有 20 + 2 × 30 = 80 个，频率 40%。常见错算：A 答 50%（只算了 AA）、70%（把带 A 的个体数当成 A 的数目）；a 答约 54.8%（把 aa 的 30% 开平方，这个种群不满足前提，不能这样算）。
- （2）活到繁殖期的有 AA 50 只、Aa 20 只、aa 15 只，共 85 只、170 个基因；A 有 120 个，频率约 70.6%；a 有 20 + 2 × 15 = 50 个，频率约 29.4%。常见错算：a 答 25%（分母仍用 200）。
- （3）aa 个体在这个环境中存活得少，a 的频率下降、A 上升：自然选择使种群的基因频率发生了变化。表现显性性状（A_，教材说法）的个体所占比例也从 70% 升到约 82.4%（这是个体的比例，不是基因频率），对应课标「具有优势性状的个体在种群中所占比例将会增加」。

## 九、子类型与分界

判断顺序照维度表第一节：先请学生复述题干条件 → 用纯净版概念题看是不是 SC → 计算单独验算（SQ）。例如复制题算错时，先问"复制 3 次后，亲代的两条链在哪几个分子里？"答不出记 SC08，答得出、只是列式错记 SQ08。

| 子类型 | 本文件里管什么 | 分界 |
|---|---|---|
| SQ08 DNA 复制与基因表达中的数量计算错（维度表第十一节） | 复制 n 次后的分子数、链数、消耗的原料数；基因、mRNA 的碱基数与氨基酸数（本文第二、三节，示范 2（2）（3）、示范 3） | 只在一个 DNA 分子内部算碱基比例或数目 → SQ06；模板、原料、产物本身说不清 → SC08；两对基因、性染色体上基因的概率 → SQ04、SQ05；种群的基因频率 → SQ07 |
| SC13 可遗传变异的类型与来源混淆（维度表第十一节） | 基因突变、基因重组、染色体结构与数量的变异分不清；说不出育种方法利用了哪种变异（本文第五、七节，示范 5、示范 7（3）） | 联会、四分体、同源染色体的分离在哪种分裂里说不清 → SC07；知道发生在减数分裂、却把交叉互换当成易位 → 仍记 SC13；变异与选择的因果说反 → SC14；基因、DNA、染色体的关系说不清 → 转生物概念网络构建器 |
| SQ06 碱基比例算错（维度表第八节） | 一个 DNA 分子内部（双链、单链）的碱基比例与数目（本文第一节，示范 1、示范 2（1）） | 跨过复制、转录或翻译的数量关系 → SQ08 |
| SC08 遗传信息的传递与表达混淆（维度表第八节） | 复制、转录、翻译的模板、原料、产物、配对对错；把表观遗传说成基因突变（本文第三、四节） | 纯净版概念题做对、只错在数量上 → SQ08；细胞分化与基因选择性表达 → SC12，转生物概念网络构建器 |
| SQ04、SQ05（维度表第八节） | 两对基因、性染色体上基因的概率（`references/genetics-reasoning.md`）；育种题里的比例（示范 7（1）（2）） | 说不出方法利用了哪种变异 → SC13 |
| SQ07 基因频率算错（维度表第八节） | 由基因型的数目或比例算基因频率，选择之后重算，X 染色体上基因的分母（本文第八节，示范 8） | 进化的观点说错 → SC14 |

人类遗传病（本文第六节）的说法错误，维度表没有单列子类型：按维度表第一节的判定顺序只定维度，不硬套上面的编号。

## 十、常见失分对照

| 失分 | 子类型 | 改法 |
|---|---|---|
| 把碱基对数当成碱基数 | SQ06 / SQ08 | 先写"碱基数 = 碱基对数 × 2" |
| 占一条链的比例与占整个分子的比例混用 | SQ06 | 先问分母是一条链还是两条链 |
| 复制 n 次消耗的原料算成 2ⁿ × m | SQ08 | 亲代的两条链不用新原料，减去 1 个分子的量 |
| "含 ¹⁴N"与"只含 ¹⁴N"不分 | SQ08 | 圈出"只"字再数 |
| 由基因推氨基酸忘了双链，或不看终止密码子的约定 | SQ08 | 先写 6 : 3 : 1 和题目的前提 |
| 转录时把 U 对到模板链的 T 上 | SC08 | 按模板链逐个配对 |
| 交叉互换与易位、碱基对缺失与染色体片段缺失分不清 | SC13 | 看交换在谁之间、缺的是什么 |
| 以为单倍体只有一个染色体组 | SC13 | 看是不是由配子发育而来 |
| 选择之后基因频率的分母没换 | SQ07 | 分母换成留下来的个体的基因总数 |
| 不满足前提也拿 aa 的比例开平方 | SQ07 | 先问题目有没有说明随机交配等前提 |
