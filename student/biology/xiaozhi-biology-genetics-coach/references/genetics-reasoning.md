## 一、遗传图解怎么写

```text
亲代（高中记作 P）        性状  ×  性状
                          基因组成   基因组成
                            ↓          ↓
生殖细胞（高中叫配子）    列出每一方可能产生的生殖细胞
                              ╲      ╱
子代（高中记作 F₁）       列出所有组合 → 写出基因组成 → 写出性状 → 写出比例
```

用词：初中写"性状""基因组成""生殖细胞"；高中对应写"表型""基因型""配子"。

四条规范：
1. 先写亲代的性状，再写基因组成，显性基因用大写字母，隐性基因用同一字母的小写；
2. 生殖细胞（配子）一栏每种只写一次；
3. 子代要同时写基因组成、性状和比例；
4. 算概率之前，先确认问的是"全部子代中"还是"某一类子代中"。

## 二、初中：基因组成与概率

**显性与隐性**：基因组成为 AA、Aa 的个体表现显性性状，aa 表现隐性性状。隐性性状并不是"表现不出来"，而是只有基因组成为 aa 时才表现。

**例 1**：双眼皮（Aa）的父母生孩子，孩子是单眼皮的概率？双眼皮孩子中，基因组成为 AA 的概率？

- 子代 AA : Aa : aa = 1 : 2 : 1，单眼皮（aa）占 1/4；
- 双眼皮（AA、Aa）共占 3/4，其中 AA 占 1/4 ÷ 3/4 = 1/3。

```verify
{"claim": "例 1：Aa × Aa，单眼皮占 1/4；双眼皮中 AA 占 1/3", "expr": "[1 / 4, (1 / 4) / (3 / 4)]", "expect": [0.25, 0.3333333333333333]}
```

**性别决定**：人的体细胞中有 23 对染色体，其中 1 对是性染色体，男性为 XY，女性为 XX。每一胎是男是女的概率各为 1/2，与之前生了几个男孩、几个女孩无关。

```verify
{"claim": "性别决定：父亲产生含 X 与含 Y 的精子各占 1/2，所以每一胎生男孩的概率为 1/2", "expr": "1 / 2", "expect": 0.5}
```

## 三、推理四步

```text
① 定性状：哪个是显性、哪个是隐性？题目给了，还是要从杂交结果判断？
② 定基因组成：由性状（高中叫表型）和亲子关系推出每个个体的基因组成
③ 画图解：按第一节的规范画出来
④ 算概率：先确认"在谁之中"，再算
```

学生跳过第③步直接算概率时，先拉回来："先把遗传图解画出来。"

## 四、高中：分离定律与自由组合定律

**分离定律**：杂合子 Aa 产生 A、a 两种配子，比例 1 : 1。Aa 自交，子代 AA : Aa : aa = 1 : 2 : 1，显性 : 隐性 = 3 : 1。

**自由组合定律**：位于非同源染色体上的非等位基因自由组合。AaBb × AaBb，两对相对性状分开算、再相乘：

| 子代类型 | 概率 |
|---|---|
| 双显性（A_B_） | 3/4 × 3/4 = 9/16 |
| 一显一隐（A_bb 或 aaB_） | 各 3/4 × 1/4 = 3/16 |
| 双隐性（aabb） | 1/4 × 1/4 = 1/16 |

```verify
{"claim": "AaBb × AaBb：9 : 3 : 3 : 1", "expr": "[(3 / 4) * (3 / 4) * 16, (3 / 4) * (1 / 4) * 16, (1 / 4) * (3 / 4) * 16, (1 / 4) * (1 / 4) * 16]", "expect": [9, 3, 3, 1]}
```

**例 2**：AaBb × aabb（测交），子代中双隐性个体的比例？

- Aa × aa → aa 占 1/2；Bb × bb → bb 占 1/2；相乘得 1/4。

```verify
{"claim": "例 2：AaBb × aabb，双隐性占 1/4", "expr": "(1 / 2) * (1 / 2)", "expect": 0.25}
```

## 五、高中：伴性遗传与系谱图

**伴 X 隐性遗传（如红绿色盲）**：母亲是携带者（XᴮXᵇ）、父亲正常（XᴮY）时——

- 女儿都不患病，其中一半是携带者；
- 儿子中有一半患病；
- 全部子女中，患病的占 1/4。

```verify
{"claim": "XᴮXᵇ × XᴮY：儿子中患病 1/2，全部子女中患病 1/4", "expr": "[1 / 2, (1 / 2) * (1 / 2)]", "expect": [0.5, 0.25]}
```

算这类题时，先问清楚"在全部子女中"还是"在儿子中"——这是最常见的失分点（子类型 SQ05）。

**系谱图判断遗传方式**：

```text
① 先定显隐：
   双亲都正常，却生出患病的孩子 → 隐性遗传
   双亲都患病，却生出正常的孩子 → 显性遗传
② 再定是否伴 X：
   隐性遗传中，只要有一个女患者的父亲或儿子正常 → 不是伴 X 隐性，是常染色体隐性
   显性遗传中，只要有一个男患者的母亲或女儿正常 → 不是伴 X 显性，是常染色体显性
③ 定不下来时，写出"最可能"的方式，并说明依据
```

读系谱图前，先看图例：哪个符号表示男性、哪个表示女性，哪种填充表示患病（子类型 SG05）。

## 六、常见失分对照

| 失分 | 子类型 | 改法 |
|---|---|---|
| 不画图解直接算 | SQ01 | 先画图解，再算 |
| 把"显性个体中的纯合子"算成"全部子代中的纯合子" | SQ01 | 先写清"在谁之中" |
| ⚠高中 自由组合时把两对性状的概率相加 | SQ04 | 两对性状分开算，再相乘 |
| ⚠高中 伴性遗传把"子女中"与"儿子中"混为一谈 | SQ05 | 先确认分母是谁 |
| 系谱图看错图例 | SG05 | 读图前先看图例 |
