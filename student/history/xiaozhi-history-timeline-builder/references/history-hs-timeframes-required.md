# 高中时空框架：必修《中外历史纲要》25 个专题

> 示例题验算：2026-10-05
> 适用学段：高中，必修"中外历史纲要"（学业水平合格性考试、等级性考试都考）。
> 本文是 `xiaozhi-history-timeline-builder`（时空线索构建器）的参考资源：纲要 25 个专题的时空框架，每个专题写阶段与关键节点、同期中外对照的骨架、历史地图与路线图的识读要点、对应子类型；年代差、跨公元前后的间隔、世纪与年代的归属写成 `verify` 断言，由 CI 重算。
> 课程依据：《普通高中历史课程标准日常修订版（2017 年版 2025 年修订）》必修课程"中外历史纲要"的内容要求 1.1—1.25，时空观念的定义、课程目标与附录水平划分，学业质量水平 2—4，实施建议中有关时空与地图的原文。
> 写法约定：「」内是课标原文，「」外是整理的讲法。课标的内容要求不写年代，下文的年代与事件名，凡课标没有的，都是统编教材的说法（见 1.4 对照表）；早期文明与上古的年代多是估计，写"约"，以教材为准；各地教材版本若有出入，以学生手里的教材为准。纪年换算的规则见 `references/timeline-methods.md` 第一节，这里不重复；选择性必修的专题时间轴与时空尺度见 `references/history-hs-timeframes-elective.md`。
> 讲到什么深度：本文全部是必修，合格考、等级考都考。授权后看 `basicInfo.subjectSelection`：没选考历史的学生按合格考的深度用本文，练把给定的史事放进时间和空间、排先后、做中外对照（学业质量水平 2）；选考的学生再练较长时段的概括与时空尺度（学业质量水平 3、4，见选择性必修那份参考的第一节）；未授权或拿不准时问一句。考试的具体形式与题型以本地当年的考试说明为准。
> 用法：骨架里留空的格子由学生对照教材自己填，本 SKILL 只核对时间对不对得上、表述与教材是否一致，提示按 `shared/hint-ladder.md` 逐级升；小练习是换题素材，学生手上的原题在他尝试之前不给答案；给学生的新排序题、新对照题，按 `shared/ai-item-check.md` 自检后再给。
> 内容边界：本文只定时间、定空间、理先后，不写历史评价。中国共产党历史与中华人民共和国史（必修 1.9—1.15）只列课标原句与教材通行的基本节点（年份、会议、事件名称），名称以课标和教材原文为准；涉及版图、民族、宗教、战争性质的表述照录课标原句，课标没有原句的以统编教材表述为准。本 SKILL 不绘制、不改动历史地图，地图以教材地图与标准地图为准，只讲识读方法，不描述国界线的走向。

## 一、怎么用这份框架

### 1.1 课标里的时空观念

- 定义：「时空观念是在特定的时间联系和空间联系中对事物进行观察、分析的意识和思维方式。」
- 课程目标：「知道划分历史时间与空间的多种方式，并在历史叙述和历史解释中运用这些方式；」「按照时间顺序和空间要素，建构历史事件、历史人物、历史现象之间的相互关联；」
- 必修的结构：「课程内容分为中国史、世界史两部分，每个部分的内容均在历史时序的框架下，由若干学习专题构成。」「本课程共有 25 个专题，是高中历史学习的基本内容。」课标只分中国史、世界史两部分；本文为了做时间轴方便，分中国古代（1.1—1.6）、中国近现代（1.7—1.15）、世界史（1.16—1.25）三节。
- 教学提示：「在历史时空框架下把握重要的历史事件、历史人物和历史现象」
- 学业质量（两套"水平"分开写）：
  - 学业质量水平 2（合格考的划定依据）：「对于给定的多则史料所反映的史事，能够综合判断其发生的时间、空间及特征；」「能够运用历史资料制作历史图表；」做时间轴、中外对照表，就是在练这两条（整理的理解）。
  - 学业质量水平 3：「建立较长时段、多个史事间的时空联系」
  - 学业质量水平 4（等级考的最高参照）：「能够有意识地运用时空框架、选择恰当时空尺度，对历史和现实问题进行独立的分析、比较、综合、探究；」
  - 附录·时空观念水平 2：「能够将给定的史事定位在特定的时间和空间框架下；能够借助历史年表、历史地图等对相关史事加以描述；」

### 1.2 每个专题的四项怎么读

| 项 | 写了什么 | 怎么用 |
|---|---|---|
| 阶段与节点 | 教材通行的年代与事件名，按先后排；"→"只表示先后，不表示因果 | 学生合上书，用"先……后来……于是……"讲一遍（`references/timeline-methods.md` 第二节） |
| 对照骨架 | 只列时段和一侧的史事，另一侧留空，注明去对照哪个专题 | 学生对照教材自己补；本 SKILL 只核对时间对不对得上（LT05） |
| 地图 | 这一专题常见的历史地图、路线图先看什么 | 读法见 1.3 |
| 子类型 | 这一专题最常见的时空错误 | 定义见 `shared/history-error-dimension-table.md`（LT01—LT06 在第三节，LT07 在第七节，LT08—LT10 在第十节） |

年代计算的口径：

- "相隔"一律用后一年减前一年；跨公元前后再减 1（没有公元 0 年）；两个公元前的年份，用较大的数减较小的数。
- "共经历几个年头"要把首尾两年都算上，比"相隔"多 1。教材说某一时期"历时""存在"多少年时用的是哪一种，以教材为准；题目问"相隔"就用减法。

```verify
{"claim": "两个公元前的年份：公元前 221 年到公元前 207 年相隔 14 年，首尾两年都算是 15 个年头", "expr": "[221 - 207, 221 - 207 + 1]", "expect": [14, 15]}
```

### 1.3 地图识读四点：方位、比例、图例、时间限定

`references/timeline-methods.md` 第五节写了读图的顺序，这里补高中常用的四点：

- **方位**：先找指向标；没有指向标的，一般按上北下南读，有经纬网的按经纬网定方向。路线图分清向哪个方向走、先后经过哪里。
- **比例**：全国图、世界图比例尺小，只读大致位置、相对方位和范围；战役图、城市图比例尺大，可以按比例尺估距离，不凭目测。示意图不按比例，不估距离。
- **图例**：颜色、线型、箭头、符号各代表什么，先读图例再读图；不同政权常用不同颜色，不同年份、不同人物的路线常用不同线型。读错图例记 LS05。
- **时间限定**：看图名或注记里的年份（或时段），弄清这张图画的是哪一年、哪一段的情况。不同年份的图不能叠起来读；把后来才有的政权、地名、路线读进早期的图，是时代错置（LT06）；看错方位、古今地名记 LT04。

版图与疆域：「地图要符合国家有关规定，保证对中国版图的专业、精准表达。」本 SKILL 不绘制、不改动地图，不描述国界线的走向；疆域、版图的变化看教材地图，相关表述照录课标原句（必修 1.6 见第二节）。课标的两个例子：「能够运用秦朝形势图和西汉形势图，明确秦汉疆域的四至；」「2. 对中国历代疆域相关的地图进行比较，认识中国疆域在历史进程中的延续、变迁、发展，提高对历史地图的辨识能力和运用能力。」四至与疆界以教材地图为准，比较两张图之前先对齐两张图的时间限定。

## 二、中国古代（必修 1.1—1.6）

必修（合格考、等级考都考）。这一段的时间轴从石器时代排到清朝中叶，先分清"约公元前……""公元前……""公元……"三种写法：公元前的年份数字越大越早，跨公元前后算间隔要减 1。

### 必修 1.1 中华文明起源与国家的产生

课标：「通过了解石器时代中国境内有代表性的文化遗存，认识它们与中华文明起源以及私有制、阶级和早期国家产生的关系；通过甲骨文、青铜铭文及其他文献记载，了解夏商西周奴隶制王朝的特征。」

- **阶段与节点**：旧石器时代 → 新石器时代（起止年代与各文化遗存的年代以教材为准）→ 约公元前 2070 年（教材说法）夏朝建立 → 约公元前 1600 年（教材说法）商朝建立 → 约公元前 1046 年（教材说法）西周建立 → 公元前 771 年西周灭亡，次年（公元前 770 年）平王东迁。三代的"约"字不能省。
- **对照骨架**：新石器时代｜中国：有代表性的文化遗存（对照教材）｜世界：＿＿（对照必修 1.16）。课标讲过这种横向整合：「一是加强历史横向联系的整合，即将同一历史时期的中外史事整合在一起，使学生以更为宽阔的历史视野进行认识。」
- **地图**：文化遗存分布图，图例区分不同遗址或文化类型，先看它们分布在哪些流域；时间限定看各处注记的"距今约××年"，同一张图上的点不一定同时存在。
- **子类型**：以为公元前的数字越大越晚，把夏、商、西周的先后排反（LT03）；把甲骨文、青铜铭文所属的时代放错（LT06）；夏商西周的制度特征记混，转材料解析题教练（LK07）。

### 必修 1.2 春秋战国时期的政治、经济及思想变动
