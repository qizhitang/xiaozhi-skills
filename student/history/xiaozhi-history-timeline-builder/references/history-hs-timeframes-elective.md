## 一、专题时间轴怎么搭

### 1.1 课标依据

- 结构：「各模块由若干学习专题构成，在各专题下的具体内容依照时序进行表述，」实施建议：「历史选择性必修课程按学习专题编排，各专题既相互独立，又有一定的关联，要求学生从多个角度探寻与专题相关的史事，深入了解其发展状况及成因。」
- 学业质量水平 3：「对较长历史时段、较大空间范围、较为复杂的历史现象进行概括」；学业质量水平 4：「能够有意识地运用时空框架、选择恰当时空尺度，对历史和现实问题进行独立的分析、比较、综合、探究；」
- 附录·时空观念水平 3：「能够把握多则史事的时间、空间联系，并用特定的时间和空间术语对较长时段的史事加以概括和说明。」附录·时空观念水平 4：「能够选择恰当的时空尺度对其进行分析、综合、比较。」

### 1.2 时空尺度：长时段、中时段、短时段

"长时段、中时段、短时段"是史学常用的说法，课标的原词是「较长时段」与「时空尺度」；下表的跨度只是做时间轴时的参考，不是课标的规定。

| 尺度 | 大致跨度 | 适合的设问 | 选择性必修里的例子 |
|---|---|---|---|
| 长时段 | 几百年到上千年 | "自……至……""古代至近代""从古至今"的演变与趋势 | 宰相制度、地方行政层级、选官方式、赋税制度、生产工具、商路 |
| 中时段 | 几十年到一二百年 | 一个朝代或一个时期内的调整，一次技术革命的扩展 | 工业革命带来的劳作与交通变化，新航路开辟后的物种交流，现代社会保障制度的建立 |
| 短时段 | 几天到几年 | 一次改革、一次会议、一场战争、一个条约 | 780 年实行两税法，1905 年废除科举制 |

选尺度分两步：

1. 先看设问的时间限定词（"自……至……""……以来""……时期""……前后"），它定了尺度；空间限定词（"中国""西方""世界"）定了范围。
2. 概括长时段，取能覆盖首尾的几个节点，写成"阶段 + 趋势"，趋势的说法以教材表述为准。用一个时间点上的事件去概括长时段，是时空尺度选择不当（LT07）。反过来，设问只问一次事件，却拉成上千年的趋势，也与设问的尺度不合。

判 LT07 之前先排除读题：请学生复述设问的时间范围，复述不出（没注意"演变""自……至……"）的，按设问指向没读清记 LS06；复述得对、仍用一个时间点概括的，才记 LT07（判定顺序见 `shared/history-error-dimension-table.md` 第一节）。

**小练习（LT07）**：设问"概括唐朝至清朝赋税制度演变的趋势"，某学生只答"780 年实行两税法"。问：错在哪？怎么改？

- 作答：设问的时段从唐朝建立（618 年）到清朝结束（1912 年），将近 1300 年，是长时段；780 年只是其中一个点，记 LT07。改法是取覆盖首尾的节点：唐朝前期的租庸调制 → 780 年两税法 → 明朝一条鞭法 → 清朝雍正时摊丁入亩（教材说法），再用教材的说法概括趋势。
- 区分点：只答一个节点的，答不出"演变"；节点覆盖了唐、明、清几段的，才答得出趋势。

```verify
{"claim": "唐朝建立（618 年）到清朝结束（1912 年）相隔 1294 年，将近 1300 年；780 年在这一时段之内，只是其中一个点", "expr": "[1912 - 618, 780 > 618 && 780 < 1912]", "expect": [1294, true]}
```

### 1.3 专题轴挂到通史轴上

- 选择性必修的专题时间轴，是从必修的通史时间轴上抽出的一条线。先在纲要的时间轴上找到朝代或时期（`references/history-hs-timeframes-required.md`），再把专题的节点挂上去，这样不会把制度挂错朝代（LT06）。例：780 年两税法挂在必修 1.4 的安史之乱（755—763 年）之后。
- 课标给了两种切法：「如按历史时期分组，分别探讨各时期中央与地方之间各方面的情况；或按地方行政层级、财政税收、军队编制与部署等专题分组」。按时期切，是在通史轴上截一段，把几条线并排看；按专题切，是抽出一条线从头看到尾。
- 一个节点可以挂在几条线上（如货币，既在选必1 1.5 的国家制度线上，又在选必2 2.3 的日常生活线上），每条线只写本专题的角度。
- 中外对照：把中外的同类制度或现象放进同一张对照表，先对齐时间（LT05）；比较本身的论证（「要避免简单的类比和抽象的优劣评判」）由历史论述题教练（xiaozhi-history-essay-coach）讲，对应子类型 LA09。

## 二、选必1 国家制度与社会治理：制度演变线

选择性必修（只在等级考范围）。模块的教学提示：「注重引导学生在时空框架下认识历史；」讲一项制度，先放回它产生的时空：「要注意引导学生探明某一制度产生的历史背景，以及与该制度有关的历史渊源；」再在中时段、长时段上看它的变化：「三是要注意某一制度是否在以后有不断完善或问题暴露、积累、激化的情况等；」学业要求的提法：「能够认识到制度会随着社会变迁而变化，任何一种制度都不是十全十美的；」

### 选必1 1.1 政治体制（中枢线、地方线）

课标：「了解中国古代政治体制在秦朝建立前后的巨大变化；通过宰相制度和地方行政层级管理的变化，认识自秦起中央集权政治体制的演变线索；了解古代至近代西方政治体制各主要类型的产生和演变过程，以及共和制在中国建立的曲折过程，理解中国政治道路发展的独特性。」

- **秦朝建立前后**：西周的分封制 → 公元前 221 年秦朝建立，实行皇帝制度、三公九卿、郡县制（教材说法）。这是以公元前 221 年为界的前后对比，时间轴上画一条分界线。
- **中枢线**（宰相制度）：秦汉三公九卿 → 汉武帝时形成中朝 → 隋唐三省六部 → 北宋中书门下与枢密院、三司分掌 → 元朝中书省 → 1380 年明朝废除丞相，此后设内阁 → 清朝雍正时设军机处（年份以教材为准）。
- **地方线**（地方行政层级）：秦朝郡、县两级 → 西汉初郡国并行 → 东汉后期州、郡、县三级 → 隋唐基本是州、县两级（唐朝在州之上设道）→ 宋朝路、州、县 → 元朝行省 → 明清省、府、县。各级名称与层级以教材为准。
- **西方政体线**（课标说「各主要类型」，没有点名；下面是教材说法）：古代雅典民主政治，罗马的共和制与帝制 → 近代英国君主立宪制（1689 年《权利法案》）→ 美国 1787 年宪法 → 德意志帝国 1871 年宪法 → 法国 1875 年宪法。
- **共和制在中国**：1912 年中华民国建立，此后的曲折与必修 1.8 的时间轴对齐，节点以教材为准。
- **尺度**：中枢线、地方线是"自秦起"的长时段，到 1912 年清帝退位跨两千多年；概括"演变线索"要取覆盖首尾的节点，只拿 1380 年废丞相一个点去概括，是 LT07。
- **易错**：把三省六部、行省、军机处挂错朝代（LT06）；英、美、德、法几部宪法的先后与所在世纪对错（LT03、LT01）；制度内容记混，转材料解析题教练（LK22）。

### 选必1 1.2 官员的选拔与管理（选官线）

课标：「了解中国古代官员选拔方式的更迭过程和不同阶段的特征，知道中央集权政治体制下古代中国的官员考核和监察制度；了解中国科举制与西方近代文官制度渊源关系，知道西方近代文官制度的特点，以及对近现代中国公务员制度的影响。」

- **选官线**：先秦「世卿世禄」→ 战国奖励军功（课标在实施建议的商鞅变法例里提到）→ 两汉察举制 → 魏晋南北朝九品中正制（220 年曹魏开始实行，教材说法）→ 隋朝创立科举制，唐朝完善，此后历代沿用（各朝的变化以教材为准）→ 1905 年清政府废除科举制。
- **考核与监察**：各朝的机构与办法（如御史、刺史、都察院等）以教材为准；时间轴上单列一条，与选官线并排。
- **西方文官制度与中国公务员制度**：19 世纪中后期英国确立近代文官制度，其他国家相继建立（年份以教材为准）→ 中国 1993 年《国家公务员暂行条例》→ 2005 年《中华人民共和国公务员法》（教材说法）。
- **尺度**：选官线从先秦到 1905 年，是长时段；"渊源关系"是中外对照，先把科举制在中国实行的时段与英国文官制度确立的时段对齐，再谈影响。
- **易错**：察举制与九品中正制的先后、所属朝代弄错（LT03、LT06）；把科举制的创立写成唐朝，属史实记混，转材料解析题教练（LK23）。

### 选必1 1.3 法律与教化（法律线）

课标：「知道中国先秦时期成文法的产生过程，以及这一时期思想家对于德治、法治关系的讨论；知道自西汉起历代王朝法律、礼教并用的统治手段；了解近代西方法律制度的渊源和基本特征，知道宗教伦理在西方社会发展进程中的作用；了解当代中国的法制建设和精神文明建设成就。」

- **中国线**：春秋后期公布成文法（公元前 536 年郑国铸刑书，教材说法）→ 战国李悝编《法经》（教材说法）→ 课标所说的「自西汉起」，历代法律、礼教并用 → 唐朝《唐律疏议》→ 明清的律典（名称以教材为准）→ 当代的法制建设（课标用"法制"，节点以教材为准）。
- **西方线**：古罗马《十二铜表法》（约公元前 450 年，教材说法）→ 罗马法 → 近代英美法系与大陆法系（1804 年《法国民法典》，教材说法）。宗教伦理只按课标「知道宗教伦理在西方社会发展进程中的作用」讲，不点名具体宗教，不作教义评价。
- **尺度**：成文法的公布集中在公元前 6—前 5 世纪前后，是中时段；"自西汉起"的礼法并用是长时段。
