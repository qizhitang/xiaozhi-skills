# 历史材料解析题四步法

> 适用学段：初中历史；第五节为高中。
> 本文是 `xiaozhi-history-source-analyzer` 的参考资源：四步法细则、史料的类型与价值、设问词与答题规范、一道课标样题的拆解。
> 课程依据：《义务教育历史课程标准（2022 年版）》的学业质量与学业水平考试部分；《普通高中历史课程标准日常修订版（2017 年版 2025 年修订）》的学科核心素养、学业质量与核心素养水平划分。
> 内容边界：本文只演示方法；涉及历史评价的表述，以课程标准和统编教材为准。

---

## 一、四步法细则

### Step 1：读出处

```text
① 谁写的、什么时候写的、在什么场合写的？
② 是哪一类史料？（实物、文献、图像、口述，或统计图表）
③ 是当时人的记录，还是后人的追述或研究？
```

义务教育历史课标的学业质量要求：能够准确理解教材和教学活动中所提供的可信史料，如不同历史时期的实物材料、文献材料、图像材料和口述材料等，辨识其中的含义。

跳过这一步最常见的后果：把后人的评论当成当时的记录（LS02），把作者的看法当成史实（LS03）。

### Step 2：提取信息

```text
① 逐句圈出时间、地点、人物或群体、做了什么、结果如何
② 分两层：材料直接说了什么 → 结合上下文，它暗含了什么
③ 回到设问：设问问什么，就只找与之对应的信息
```

提取完请学生用自己的话复述一遍。复述不出来，不急着往下做。

### Step 3：结合所学

```text
① 把材料放回时空框架：它属于哪个时期？当时发生了什么？
② 对应教材里的史事和概念，换成历史术语
③ 分清哪些信息来自材料、哪些来自所学，作答时分开写
```

### Step 4：得出结论

```text
① 论从史出：每个结论都要能在材料或所学史实里找到依据
② 按设问词组织答案（第二节）
③ 检查：逐条问"这一点的依据在哪里"，找不到依据的删掉
```

## 二、设问词与答题规范

| 设问 | 要答什么 | 常见失分（子类型） |
|---|---|---|
| 概括、归纳 | 用历史术语提炼材料的意思，不照抄原文 | 照搬材料（LA06）；口语化（LE01） |
| 原因、背景 | 当时的政治、经济、思想文化与外部环境；材料给出的和所学补充的分开写 | 把影响写成原因（LS06）；因果倒置（LK04） |
| 影响、意义 | 按教材的表述，分清对当时和对后来、对不同领域的作用 | 答成过程（LE03）；评价片面（LE05） |
| 变化、特点 | 前后对照，写清"由……到……" | 只答了一个时间点（LS06） |
| 比较 | 相同点和不同点分开，按同一个项目逐项对照 | 只说了一方（LE02） |
| 评价、认识 | 依据课程标准和统编教材的评价口径，史论结合、全面客观 | 以论代史（LA02）；绝对化表述（LE05） |

通用规范：分点作答，每点一个意思；用历史术语；要点数量与分值怎么对应，以当地的评分细则为准。

## 三、课标样题拆解：从一首唐诗里读出科举

这道题出自《义务教育历史课程标准（2022 年版）》课程实施部分的考试样题 1。题干给出唐朝诗人刘禹锡的一首诗，前两句是"礼闱新榜动长安，九陌人人走马看"，问诗句描写的是什么，四个选项为：开放的社会风气、三省六部制的实施、科举考试后的盛况、长安城的节日气氛。

按四步法拆：

| 步骤 | 这道题里怎么做 |
|---|---|
| 读出处 | 唐朝诗人写的诗，属于文献史料；写的是作者看到的当时情景 |
| 提取信息 | 圈出"礼闱""新榜""人人走马看"：新榜是新公布的录取名单，礼闱与考试相关 |
| 结合所学 | 隋唐时期创立并完善了科举制，唐朝进士科放榜是社会关注的大事 |
| 得出结论 | 诗句写的是放榜之后的场面，对应"科举考试后的盛况"；课标给出的参考答案为 C |

课标的试题说明指出，这道题考查史料实证的水平，即能否从史料中提取有效信息，并作出正确判断。

示范用完即止：学生自己的题，仍按四步法由学生先做，本 SKILL 按提示阶梯逐级给提示。给同类练习时换一则材料，生成前按 `shared/ai-item-check.md` 自检，材料注明出处。

## 四、史料的类型与价值

| 类型 | 例子 | 读的时候注意 |
|---|---|---|
| 实物 | 遗址、器物、钱币 | 能证明"有这个东西"，用途和意义需要结合其他史料判断 |
| 文献 | 诏令、奏章、史书、书信、报刊、诗文 | 看作者、时间与立场；诗文有文学加工 |
| 图像 | 绘画、照片、漫画、历史地图 | 看图名、作者、时间；漫画带有作者态度 |
| 口述 | 亲历者回忆、访谈 | 回忆可能有偏差，需要与其他史料互证 |
| 统计 | 年表、数据表、统计图 | 看单位、时间范围、数据来源 |

同一个问题，能用两类以上史料互相印证的结论更可靠。

## 五、高中：材料解析题的升级

高中历史课标把史料实证与历史解释分成四个水平。材料解析题在高中的升级主要体现在：

- **多则、多类型史料综合判断**：学业质量水平 3 要求对于多则、多类型的史料所反映的复杂史事，能够综合判断其发生的时间、空间特征及变化，提炼出关键、有效的历史信息。
- **比较与互证**：史料实证水平 4 要求能够比较、分析不同来源、不同观点的史料，能够在辨别史料作者意图的基础上利用史料（对应子类型 LS07、LS08）。
- **区分史实与解释**：历史解释水平 1 要求能够辨别教材和教学中的历史解释（对应子类型 LK06）。

考试口径：学业水平合格性考试以学业质量水平 2 为合格要求，等级性考试以水平 4 为命题的最高参照。学生没有选考历史时，按合格考的深度讲，不推等级考难度的题。
