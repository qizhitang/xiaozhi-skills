## 〇、怎么用：范围、深度与制度比较的口径

选择性必修（只在等级考范围）。

- **范围**：课标原句：「历史学科合格性考试范围为必修课程内容与相关要求；等级性考试范围为必修课程内容与选择性必修课程内容。」是否选考：授权后看 `basicInfo.subjectSelection`，实行"3+1+2"的看 `firstChoice` 是不是"历史"，实行"3+3"的看 `electives` 里有没有"历史"；未授权或拿不准就问一句"你选考历史吗"。没选考历史的学生问到本文的内容，说明它只在等级考范围内，按教材讲清基本史实，不按等级考的深度展开；他们的错题不定维度表第十一节的子类型，怎么记见维度表第十一节开头。
- **深度**：等级考「以学业质量水平 4 为命题的最高参照标准」，而且「并考虑与其他水平层级的贯通」。选择性必修对史料的要求高一层：「在制订选择性必修课程的教学目标时，应注重培养学生整理、辨析、理解史料的能力，能够利用不同类型史料进行互证，对相关历史问题作出更全面的解释。」
- **制度比较的口径（LA09）**：选必1 的导语和教学提示定了口径：「不能脱离特定社会政治条件和历史文化传统来抽象评判」；「四是对不同国家制度进行比较时，要避免简单的类比和抽象的优劣评判，通过比较，使学生更清楚地认识不同国家各自的特点以及相互之间的异同。」学业要求还说「任何一种制度都不是十全十美的」。讲一项制度，先按教学提示 1 的落点讲清它本身：「要注意引导学生探明某一制度产生的历史背景，以及与该制度有关的历史渊源；在了解该制度基本内容的基础上，重点分析这一制度的特点及作用，并认识该制度对当时及以后的影响。」比较时两项制度各自说清，再按同一项目比异同。不同国家之间、同一国家不同时期之间的比较都按这个口径，不下"哪个更先进""哪个更好"的结论；学生问"哪种制度更好"，请他改成"各自的特点与异同"。比较的方法错了记 LA09，转历史论述题教练（xiaozhi-history-essay-coach）的 `history-hs-essay-levels.md` 第五节；制度本身说错的，先用本文第一节分清。
- **相邻专题的划界**：货币，选必1 1.5 讲国家的货币发行与货币体系，选必2 2.3 讲货币、信贷、商业契约在日常生活中的作用；商路，选必2 2.3 看商贸与日常生活，选必3 3.4 看贸易在文化交流中的角色；交通，选必2 2.5 讲交通进步，新航路开辟、工业革命本身是必修 1.18、1.20 的内容；人口迁徙，选必3 3.3 落在文化认同，与地理课的人口迁移分开。选官与政体的演变线是选择性必修的内容，必修 1.4 只写「制度变化与创新」，必修 1.6 只写「封建专制的发展」，这里的细节不当合格考的要求。
- **课标原词与教材说法**：每个小节开头照录课标的内容要求；课标没有用、教材常用的制度名、事件名、文献名，列在课标原句下面的"教材说法"一行（它们第一次出现就在这一行），讲解时可以用，不说成"课标要求掌握××"。"（教材）"后面是统编教材的通行讲法；人名、地名、书名多数课标没有写，以统编教材为准。具体怎么表述、讲到什么深度，以学生手里的教材和本地当年的考试说明为准。
- **敏感表述**：民族、边疆、宗教、当代中国的制度建设与外交、战争、中华文化特性，课标有原句的照录（每个小节开头的原句），课标没有的以统编教材表述为准。宗教只讲历史作用，不作教义评价。"认同""树立……自信"一类的态度要求不出成知识判断题。
- **对应子类型**：编号的定义见 `references/history-error-dimension-table.md` 第十一节；表里也会用到第二至十节已有的编号（如 LT03、LK05、LE05、LE06）。先后排序的问题转时空线索构建器（xiaozhi-history-timeline-builder）。

## 一、选必1 国家制度与社会治理

选择性必修（只在等级考范围）。模块的学业要求分了层次：「通过本模块的学习，学生能够基本认识中国古代国家制度和社会治理措施的主要发展线索，同时能够简单了解欧美国家在制度建设和社会治理方面的成就、局限及其历史渊源，并且初步掌握当代中国国家制度和社会治理措施的由来和概况」——中国古代是"基本认识"，欧美是"简单了解"，当代中国是"初步掌握"。

### 1. 中枢与政体（选必1 1.1）

课标原句：「了解中国古代政治体制在秦朝建立前后的巨大变化；通过宰相制度和地方行政层级管理的变化，认识自秦起中央集权政治体制的演变线索；了解古代至近代西方政治体制各主要类型的产生和演变过程，以及共和制在中国建立的曲折过程，理解中国政治道路发展的独特性。」

教材说法：三公九卿、丞相、中朝、外朝、三省六部、中书门下、枢密院、三司、中书省、内阁、军机处、承宣布政使司、提刑按察使司、都指挥使司、城邦、执政官、元老院、公民大会、君主立宪制、联邦制、三权分立、共和政体。

中枢的演变线（教材）：

| 时期 | 中枢 | 要点 |
|---|---|---|
| 秦汉 | 三公九卿 | 丞相协助皇帝处理全国政务；汉武帝时形成中朝与外朝 |
| 隋唐 | 三省六部 | 中书省起草诏令，门下省审核，尚书省执行，宰相的权力分属三省长官 |
| 宋 | 中书门下、枢密院、三司 | 分掌行政、军事、财政 |
| 元 | 中书省 | 总理全国政务 |
| 明 | 废丞相，后设内阁 | 皇帝直接统领六部，内阁大学士协助处理政务 |
| 清 | 军机处 | 雍正时设立，按皇帝的旨意办事 |

| 对照项 | 怎么分 | 常见混法 | 对应子类型 |
|---|---|---|---|
| 隋唐的三省 / 明朝的内阁 | 三省是法定的中央机构，宰相的权力分属三省长官；明朝废丞相以后，内阁大学士协助皇帝处理政务，决定权在皇帝（教材） | 把明朝的内阁当成恢复了的宰相制度 | LK22 |
| 宋代的三司 / 明朝的三司 | 宋代的三司在中央，主管国家财政；明朝在地方设承宣布政使司、提刑按察使司、都指挥使司，分管一省的行政、司法、军事，也称三司（教材） | 因为名称相同把两者混为一谈 | LK22 |
| 雅典的民主政治 / 罗马共和国 | 雅典是城邦，实行成年男性公民直接参与的民主政治；罗马共和国由执政官、元老院和公民大会分享权力（教材） | 把雅典的直接民主安到罗马共和国 | LK22 |
| 英国 / 美国 / 法国的政体 | 英国确立君主立宪制；美国确立联邦制、三权分立的共和政体；法国几经反复，1875 年宪法确立共和政体（教材） | 把三国的政体对调（必修题记 LK18） | LK22 |
| 课标的提法 | 2025 年版作「认识自秦起中央集权政治体制的演变线索」，2020 年版的"君主专制中央集权"不再当课标原文；本条末句的评价照录原句；「共和制在中国建立的曲折过程」的史事与表述以统编教材为准 | 写回 2020 年版的提法；改写本条的评价句 | LE06 |

### 2. 地方行政（选必1 1.1）

课标原句见上一小节。课标活动「活动主题 探讨中国古代历史上中央与地方的关系（专题 1.1）」只给了分组的思路，没有点名朝代和史事：「或按地方行政层级、财政税收、军队编制与部署等专题分组」。

教材说法：郡县制、郡国并行、刺史、行省、通判、知州、总督、巡抚。

地方行政的演变线（教材；层级的名称以所用教材为准）：

| 时期 | 地方层级 | 要点 |
|---|---|---|
| 秦 | 郡、县两级 | 在全国推行郡县制，长官由皇帝任免 |
| 西汉 | 郡国并行 | 汉武帝设刺史监察地方 |
| 东汉末 | 州、郡、县三级 | 州由监察区变成行政区 |
| 隋唐 | 州（郡）、县两级 | 唐朝的道起初是监察区 |
| 宋 | 路、州、县 | 州设通判，与知州相互牵制 |
| 元 | 行省 | 行省下设路、府、州、县 |
| 明清 | 省以下设府（州）、县 | 明朝在省设三司（见上一小节）；清朝以总督、巡抚为地方长官 |

| 对照项 | 怎么分 | 常见混法 | 对应子类型 |
|---|---|---|---|
| 郡县制 / 行省制 | 秦朝在全国推行郡县制，元朝实行行省制度（教材） | 说元朝才开始实行郡县制、秦朝已设行省 | LK22 |
| 监察区 / 行政区 | 汉武帝设的刺史部（州）、唐朝的道，起初都是监察区，后来才演变为行政区（教材） | 把监察区一开始就当成行政区 | LK22 |
| 机构名称 / 中央与地方的关系 | 课标活动要学生按时期，或按地方行政层级、财政税收、军队编制与部署去梳理中央与地方的关系；只记机构名称回答不了关系 | 只列机构名称，说不出中央与地方在财政、军队上的关系 | LK22 |

### 3. 选官与考核监察（选必1 1.2）

课标原句：「了解中国古代官员选拔方式的更迭过程和不同阶段的特征，知道中央集权政治体制下古代中国的官员考核和监察制度；了解中国科举制与西方近代文官制度渊源关系，知道西方近代文官制度的特点，以及对近现代中国公务员制度的影响。」

教材说法：察举制、九品中正制、上计、御史大夫、御史台、都察院。

选官方式的演变线（教材）：

| 时期 | 选官方式 | 选拔依据 |
|---|---|---|
| 先秦 | 世卿世禄（课标实施建议里的用词） | 按血缘世袭官职 |
| 汉 | 察举制 | 地方长官考察、推荐，看重德行和才能 |
| 魏晋南北朝 | 九品中正制 | 中正官评定人才等级，后来主要看家世门第 |
| 隋唐至清 | 科举制 | 分科考试，凭成绩选拔；1905 年废除 |

| 对照项 | 怎么分 | 常见混法 | 对应子类型 |
|---|---|---|---|
| 察举 / 九品中正 / 科举 | 察举靠推荐，九品中正后来看门第，科举凭考试（教材） | 把三者的选拔依据对调（只是先后排反的记 LT03） | LK23 |
| 考核 / 监察 | 考核是考查官员的政绩、定升降（汉代的上计是一例，名称以教材为准）；监察是纠察官员的违法失职（教材） | 把考核与监察混为一谈 | LK23 |
| 中央的监察机构 | 秦汉有御史大夫，唐宋有御史台，明清有都察院；汉武帝设刺史监察地方（教材） | 把机构与朝代对错 | LK23 |

### 4. 文官制度（选必1 1.2）

课标原句见上一小节。

教材说法：事务官、政务官、公开考试、政治中立。

| 对照项 | 怎么分 | 常见混法 | 对应子类型 |
|---|---|---|---|
| 中国古代科举制 / 西方近代文官制度 | ① 科举制：中国古代王朝分科考试、选拔官员的制度，隋朝开创，1905 年废除（教材）；② 西方近代文官制度：19 世纪中后期起在英国等国逐步建立，文官经公开考试、择优录用，保持政治中立，职务常任（教材）；③ 两者的关系，课标用的词是「渊源关系」，怎样表述以统编教材为准 | 只凭"都要考试"就说两者是同一种制度（简单类比，记 LA09）；说两者毫无关系；直接判哪个更先进（记 LA09） | LK23 |
| 政务官 / 事务官 | 政务官随选举和政党的更替进退；事务官不随政党进退（教材）；狭义的文官指事务官，教材若写"文官分为政务官和事务官"，照教材的分法 | 说文官都由选举产生、随政党进退 | LK23 |
| 西方近代文官制度 / 近现代中国的公务员制度 | 课标要求知道西方近代文官制度「对近现代中国公务员制度的影响」，具体史事以统编教材为准 | 把公务员制度说成从古代科举直接延续下来 | LK23 |

### 5. 法律与教化（选必1 1.3）

| 宋以后 | 乡约等在基层推行教化（具体以教材为准） |

### 6. 民族与边疆（选必1 1.4）

课标原句：「了解中国古代的民族政策和边疆管理制度，认识中国作为统一多民族国家的发展历程，以及中国古代处理对外关系的体制；了解近代西方民族国家的形成情况，以及国际法的发展；了解当代中国民族区域自治制度的历史意义，了解独立自主的和平外交政策的主要成就。」

教材说法：西域都护、都护府、羁縻府州、宣政院、土司、流官、改土归流、理藩院、驻藏大臣、伊犁将军、联邦制。

边疆管理的演变线（教材；机构的设置时间、职能与管辖范围的表述，以统编教材为准）：

| 时期 | 机构或制度 |
|---|---|
| 西汉 | 设西域都护 |
| 唐 | 设都护府，在一些民族地区设羁縻府州 |
| 元 | 设宣政院等机构 |
| 元明 | 在西南地区设土司 |
| 清 | 设理藩院，设驻藏大臣、伊犁将军；雍正时在西南地区大规模改土归流 |
| 当代 | 民族区域自治制度（课标原词） |

| 对照项 | 怎么分 | 常见混法 | 对应子类型 |

### 7. 统计图表的读法（LS09）

本模块的材料常用统计图表。课标在学业质量水平 2 里写「能够运用历史资料制作历史图表」，评价时也要求「运用文献、实物、口述、图像、音像、数字等多种史料」。下面的数都是示意，不对应真实的地区和年份。没选考历史的学生读必修题里的统计图表出错，记 LS05。

教材说法：总量、增长率、指数、比重、百分点（教材、试卷常用的说法）。

| 指标 | 怎么读 | 常见误读 |
|---|---|---|
| 总量 | 某项东西一共有多少，带单位 | 看错单位、时间段（记 LS05） |
| 增长率 | 比上一期增加了百分之几；增长率下降但仍大于 0 时，总量还在增加 | 把增长率下降读成总量下降 |
| 指数 | 以某一期为 100，其他各期与它相比；只能比较同一基期的数据 | 把指数当成实际数量；把基期不同的两组指数直接比大小 |
| 比重 | 某部分占总体的百分比；总体增加得更多时，比重下降、这部分的数量可能仍在增加 | 把比重下降读成数量减少 |
| 百分点 | 两个百分比相减的差 | 把"下降了 20 个百分点"说成"下降了 20%" |

示意一：某地某时期产量指数依次为 100、120、138，两段的增长率由 20% 降到 15%，产量仍在上升；说"产量开始下降"是把增长率当成了总量。

## 三、选必3 文化交流与传播

选择性必修（只在等级考范围）。模块导语照录：「通过本课程的学习，有助于学生尊重世界文明多样性，以文明交流超越文明隔阂、文明互鉴超越文明冲突、文明共存超越文明优越。」

### 1. 中华文化的特点（选必3 3.1）

课标原句：「了解中华优秀传统文化的内涵；从人类文明发展和世界文化交流的角度，认识中华优秀传统文化的特点和价值，认识中华文化的世界意义。」

教材说法：造纸术、印刷术、儒学。

| 对照项 | 怎么分 | 常见混法 | 对应子类型 |
|---|---|---|---|
| 五个突出特性的出处 | 学业质量水平 3：「了解中华文明的五个突出特性和价值」；选必3 教学提示 2：「理解中华文明连续性、创新性、统一性、包容性、和平性等突出特性，使学生树立文化自信。」名称与顺序照教学提示 2 的原句；"五个突出特性"一语只见于学业质量水平 3 | 名称写错、漏写、调换顺序；写成 2020 年版"本土性、多样性、凝聚性"一类的旧说法 | LK34 |
| 内涵 / 特点和价值 / 世界意义 | 本条的三个设问方向不同：内涵、特点和价值、世界意义，按设问作答 | 把"特点"答成"内涵"（设问没读清记 LS06） | LK34 |
| 特性 / 举例 | 用哪些史事说明哪一个特性，以统编教材为准，不自己下定论；不用一个特性概括全部 | 用一个特性概括全部；举例与特性对不上 | LK34 |
| 中华文化的世界意义 | 如造纸术、印刷术等的外传，儒学在东亚的传播（以教材为准） | 把中华文化对外的影响与外来文化对中国的影响混为一谈 | LK34 |

### 2. 区域文化（选必3 3.2）

课标原句：「通过了解世界各主要区域的文化，理解世界文化的多样性；认识世界各国、各地区、各民族对人类文化发展所作出的贡献。」

教材说法：阿拉伯数字、楔形文字、象形文字、《荷马史诗》。

| 对照项 | 怎么分 | 常见混法 | 对应子类型 |
|---|---|---|---|

| 楔形文字 / 象形文字 | 古代两河流域用楔形文字，古埃及用象形文字（教材） | 把两种文字对调（必修题记 LK01） | LK35 |

### 3. 迁徙与认同（选必3 3.3）

课标原句：「通过了解历史上跨洲、跨国家、跨地区不同规模的人口迁徙，以及移民所面临的机遇与挑战，认识在迁徙与融入当地社会过程中出现的文化认同。」
