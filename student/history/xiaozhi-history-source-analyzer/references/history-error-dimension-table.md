# 历史错因维度表

> 适用学段：初中历史；第七节为高中的子类型。
> 本文档是 `xiaozhi-history-source-analyzer` 的核心参考资源，定义历史五维错因、子类型、跨维度关联规则与交接契约；时空线索构建器、历史论述题教练随包带的是同一份副本。
> 词表与阈值以 `shared/vocab.md` 为唯一来源；本表只定义历史子类型 ID 的含义（`shared/vocab.md §2`）。
> 课程依据：《义务教育历史课程标准（2022 年版）》（2025 年日常修订版如有调整，以修订版为准）；《普通高中历史课程标准日常修订版（2017 年版 2025 年修订）》。
> 内容边界：本表只描述"错在哪里"，不评价历史人物与事件；涉及历史评价的表述以课程标准和统编教材为准（SECURITY_BASELINE.md 4.4）。
>
> ⚠️ **编码命名空间**：历史子类型一律用「L + 维度字母」两字母前缀（如 `LS03`），与语文的 `LG`（语病）不重名。

---

## 一、维度总览

| 维度 | 定义 | 交叉判定（怎么确认是这一维） | 通用四维 |
|---|---|---|---|
| 史料信息提取（LS） | 材料读不准、读不全 | 请学生复述材料的出处、时间和主要信息，复述有误 | 读题失误 |
| 时空定位（LT） | 史事放不进正确的时间与空间 | 请学生把事件放到时间轴或地图上，仍放错 | 概念模糊 |
| 史实与概念混淆（LK） | 史实、概念、人物、因果记混 | 换一个问法考同一史实，仍然错 | 概念模糊 |
| 论证结构（LA） | 观点与史实连不起来 | 史实都对，但观点立不住或论证脱节 | 方法用错 |
| 表述规范（LE） | 意思对，写法不合规范 | 口头能说对，写成答案就丢分 | 方法用错 |

**判定顺序**：先请学生复述材料（排除 LS）→ 再请学生定时间、定地点（排除 LT）→ 换问法测同一史实（LK）→ 史实都对，再看论证（LA）与表述（LE）。一道错题只记一个主维度。

历史里的计算失误很少见：公元纪年、世纪换算算错归 LT01、LT02，不归计算失误。

## 二、维度①：史料信息提取（LS）

**定义：** 从材料中读取信息时漏读、误读或读偏。**判断标准：** 请学生复述"材料说了什么"，复述本身就有误 → LS。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| LS01 | 漏读限定信息 | 没看材料的时间、地点、主体，答成了别的时期或别的国家的情况 | → LT01 |
| LS02 | 忽视出处与史料类型 | 不看作者和成文时间，把后人的追述当成当时的记录 | → LS03 |
| LS03 | 把观点当史实 | 把材料作者的评论或推测，当成确定的史实来用 | → LA03 |
| LS04 | 只读一句、断章取义 | 抓住材料里的一句话作答，忽略转折和整体意思 | → LE03 |
| LS05 | 图表信息读错 | 统计图表看错单位、趋势或时间段；历史地图看错图例 | → LT04 |
| LS06 | 设问指向没读清 | 问"变化"只答了一个时间点的情况；问"原因"答成了"影响" | → LE03 |

---

## 三、维度②：时空定位（LT）

**定义：** 史事的时间或空间定位出错。**判断标准：** 请学生把事件放到时间轴或地图上，仍然放错 → LT。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| LT01 | 世纪、年代换算错 | 把 1840 年说成 18 世纪 40 年代；把公元前 221 年说成公元前 22 世纪 | → 时空线索构建器的纪年换算规则 |
| LT02 | 跨公元的年数算错 | 计算公元前某年到公元某年相隔多少年时，把并不存在的公元 0 年算了进去 | → LT01 |
| LT03 | 先后顺序颠倒 | 朝代更替、事件先后排反 | → LK01 |
| LT04 | 历史地图识读错误 | 看错方位、古今地名或图例 | → LS05 |
| LT05 | 同期中外对应错 | 把不同时期的中外史事当成同一时期 | → 时空线索构建器的中外对照表 |
| LT06 | 时代错置 | 把后来才出现的事物、制度或说法放到更早的时代 | → LK05 |

---

## 四、维度③：史实与概念混淆（LK）

**定义：** 史实、历史概念、人物事迹或因果关系记混。**判断标准：** 换一个问法考同一史实（如从"谁提出"换成"提出了什么"），仍然错 → LK。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| LK01 | 相近史事混淆 | 两次相近的改革、会议或战役记混 | → LT03 |
| LK02 | 概念内涵不清 | 分不清分封制与郡县制、察举制与科举制的区别 | → LE01 |
| LK03 | 人物与事迹错配 | 把甲的主张或事迹安到乙身上 | — |
| LK04 | 因果倒置或错配 | 把结果当成原因；把长期背景当成直接原因 | → LA05 |
| LK05 | 以今度古 | 用今天的概念和标准去理解古代的制度与现象 | → LT06 |

---

## 五、维度④：论证结构（LA）

**定义：** 在开放性试题、论述题中，观点与史实的组织出错。**判断标准：** 所用史实本身都对，但观点立不住，或史实和观点连不起来 → LA。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| LA01 | 没有明确观点 | 只罗列史实，没有提出观点或论题（课标样题评分中"没有凝练出观点"一档） | → 历史论述题教练 |
| LA02 | 以论代史 | 只有观点和议论，没有具体史实支撑 | → LA04 |
| LA03 | 史论脱节 | 列了史实，但史实和观点之间没有关系 | → LS03 |
| LA04 | 史实不足或不典型 | 只用一个史实，或所选史实说明不了观点（课标样题最高一档要求运用两个以上的史实） | → LA02 |
| LA05 | 逻辑层次混乱 | 没有"观点—史实—分析—结论"的顺序，前后矛盾 | → LK04 |
| LA06 | 照搬材料、没有提炼 | 大段复述材料原文，没有概括出自己的认识（课标样题评分中"仅仅重复材料中的史实"一档） | → LE01 |

---

## 六、维度⑤：表述规范（LE）

**定义：** 意思基本对，但表述不符合历史学科的答题规范。**判断标准：** 请学生口头说一遍能说对，写成答案却丢分 → LE。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| LE01 | 口语化、不用历史术语 | "打了很多仗""皇帝很厉害"，不用教材中的历史术语 | → LK02 |
| LE02 | 不分点、要点混杂 | 几个要点写成一段，阅卷时找不到得分点 | — |
| LE03 | 答非所问 | 设问问"意义"，答成了"过程" | → LS06 |
| LE04 | 答题量与分值不匹配 | 6 分的题只写了一点，或堆了很多与设问无关的内容；要点数与分值的对应以当地评分细则为准 | — |
| LE05 | 评价片面或绝对化 | 评价只讲一个方面，或用"完全""彻底"这类绝对化表述；评价口径以课程标准和统编教材为准 | → LA05 |

## 七、高中：子类型的升级

以下子类型对应《普通高中历史课程标准》学科核心素养的较高水平，只在学生已进入高中时使用；编号接在初中子类型之后。

| 子类型ID | 名称 | 典型表现 | 对应的课标要求 |
|---|---|---|---|
| LS07 | 多则史料不会互证 | 只用其中一则材料，不比较不同来源、不同观点的史料 | 史料实证水平 4："能够比较、分析不同来源、不同观点的史料" |
| LS08 | 不辨作者意图 | 不考虑史料作者的立场和目的，直接采信 | 史料实证水平 4："在辨别史料作者意图的基础上利用史料" |
| LT07 | 时空尺度选择不当 | 用一个时间点上的事件，去概括一个长时段的特征 | 时空观念水平 4："能够选择恰当的时空尺度" |
| LK06 | 分不清史实与解释 | 把教材之外的某种说法当成定论，或把史实陈述和历史解释混为一谈 | 历史解释水平 1："能够辨别教材和教学中的历史解释" |
| LA07 | 论题不规范 | 小论文的论题没有时空限定或没有明确判断，写成了一个话题 | 历史解释水平 2："提出自己的解释" |

## 八、跨维度关联规则

```text
LS ↔ LA：把观点当史实（LS03），论证就建立在不可靠的依据上（LA03）
          → 先回到出处，分清哪句是史实、哪句是作者的看法

LT ↔ LK：先后顺序颠倒（LT03），常因为两件相近的史事记混了（LK01）
          → 先把两件事分清，再排顺序

LK ↔ LA：因果倒置（LK04），会让整段论证的方向反过来（LA05）

LS ↔ LE：设问没读清（LS06），答出来就是答非所问（LE03）
          → 作答前先圈出设问词

主维度判定仍以交叉判定为准；跨维度只作为突破时的联动线索。
```

## 九、与通用错题本的协作边界

### 9.1 职责分工

```text
通用错题本（表面层，唯一计数权威）：
  → 接收所有科目错题；基础四维分类（shared/vocab.md §1）
  → 28 天累计计数与"顽固"判定（shared/vocab.md §5）

历史材料解析题教练（深度层，持有本表）：
  → 历史五维深度分类与子类型定位
  → 跨维度关联分析；顽固弱项专项突破（计数不在本层）

时空线索构建器、历史论述题教练：
  → 在各自的练习里用本表定位 LT、LA、LE；学生同意后经错题本交接，不自行建错题档案
```

### 9.2 维度映射

```text
通用四维（basicDimension）  →  历史五维可能映射   →  判断依据
────────────────────────────────────────────────────────
读题失误                →  LS              →  复述材料有误
概念模糊                →  LT / LK         →  时空放错，还是史实记混？
方法用错                →  LA / LE         →  论证组织，还是表述规范？
计算失误                →  （少见）         →  纪年换算算错归 LT01、LT02
```

反向映射（写回通用层时用，`shared/vocab.md §2`）：历史 LS → 读题失误；LT、LK → 概念模糊；LA、LE → 方法用错。
通用四维与历史五维不是一一对应。本 SKILL 的判断写入 `historyDimension`，通用层的 `basicDimension` 保持错题本给出的值不变。

### 9.3 交接契约（以 handover-protocol.schema.json 为源）

**接收：`wrong_answer_handover`**

```json
{
  "sessionId": "sess-2026-09-23-07",
  "protocolVersion": "2.2.0",
  "handoverType": "wrong_answer_handover",
  "sender": "xiaozhi-correction-notebook",
  "recipient": "xiaozhi-history-source-analyzer",
  "consent": { "crossSkillSharing": true, "verifiedAt": "2026-09-23T20:10:00+08:00" },
  "payload": {
    "wrongAnswerData": {
      "errorId": "err-20260923-011",
      "subject": "history",
      "concept": "公元纪年与世纪的换算",
      "handoverTrigger": "new_error",
      "basicDimension": "概念模糊",
      "historyDimension": "时空定位(LT)",
      "subtypeId": "LT01",
      "judgmentClue": "复述材料无误；把 1840 年换算成 18 世纪，换算规则不清",
      "surfaceInfo": {
        "questionAbstract": "材料题：说出鸦片战争爆发于哪个世纪",
        "studentAnswer": "18 世纪 40 年代",
        "correctAnswer": "19 世纪 40 年代",
        "surfaceRootCause": "把年份的前两位数直接当成世纪"
      }
    }
  },
  "timestamp": "2026-09-23T20:10:00+08:00"
}
```

字段约束：
- `basicDimension` 必填，取通用四维
- `historyDimension` 取五维枚举原文：`史料信息提取(LS)` `时空定位(LT)` `史实与概念混淆(LK)` `论证结构(LA)` `表述规范(LE)`
- `subtypeId` 形如 `LT01`，即本表定义的历史子类型编码
- `new_error` 时 `judgmentClue` 必填，写清为什么归到这一维
- `occurrenceCountInWindow` 由通用错题本给出，本 SKILL 不改写、不重算

**回写：`deep_analysis_writeback`**，`payload.deepAnalysisData` 携带 `errorId`（原样带回）、`subject="history"`、`subtypeId`、`basicDimension`、`rootCause`（不超过 300 字，不含原始对话）、`status`、`recommendedAction`。

**写入学习 DNA**：`subject_profile_writeback`，`payload.profileData.updateTarget="subject_extension"`，`subjectExtensionPatch` 只带 `subjectExtensions.history` 分支；本 SKILL 只写其中的 `subtypes`。

**提醒**：`reminder_enqueue` + `payload.reminderData`，接收方固定为 `xiaozhi-im-reminder`。
