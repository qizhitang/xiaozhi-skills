# 化学错因维度表

> 适用学段：初中化学；第八节为高中必修起点（物质的量、氧化还原、电离与离子反应）。
> 本文档是 `xiaozhi-chemistry-error-dna` 的核心参考资源，定义化学六维错因、子类型、跨维度关联规则与交接契约。
> 词表与阈值以 `shared/vocab.md` 为唯一来源；本表只定义化学子类型 ID 的含义（`shared/vocab.md §2`）。
> 课程依据：《义务教育化学课程标准（2022 年版）》五个学习主题；《普通高中化学课程标准日常修订版（2017 年版 2025 年修订）》必修主题 1、主题 2。
>
> ⚠️ **编码命名空间**：化学子类型一律用「H + 维度字母」两字母前缀（如 `HS03`），与数学、物理的单字母编码不会混淆。

## 一、维度总览：宏观—微观—符号

化学学习有一个物理没有的难点：同一件事要在三个层面之间来回切换——

```
宏观（看得见的现象）  ：铁丝在氧气里剧烈燃烧、火星四射，生成黑色固体
微观（看不见的粒子）  ：铁原子和氧分子中的氧原子重新组合
符号（写出来的式子）  ：3Fe + 2O₂ ==点燃== Fe₃O₄
```

学生卡住，往往是三个层面之间断了一环。六个维度按这个三角组织：

```text
维度①  符号表征 (HS)   ── 化学用语写错：元素符号、化合价、化学式、方程式
维度②  微观表征 (HM)   ── 粒子观缺失：说不出微观发生了什么，或把宏观性质套到粒子上
维度③  宏观概念 (HC)   ── 物质、变化、性质层面的概念混淆
维度④  读题与条件 (HR) ── 漏读"足量""恰好完全反应""滴加顺序"等关键条件
维度⑤  实验与探究 (HE) ── 装置、操作顺序、现象与结论、检验与除杂、安全
维度⑥  定量计算 (HQ)   ── 相对分子质量、质量分数、按方程式计算

每道错题归入且只归入一个主维度；有跨维度因素时记为"主维度 + 次要维度"。

优先处理顺序：HS > HM > HC > HR > HE > HQ
→ 化学用语是整门课的"语言"，符号写不对，后面的推理与计算都无从谈起
```

判定时先做**纯净版测试**：把干扰条件去掉，只留一个知识点再问一次。纯净版也错 → 概念类（HS/HM/HC）；纯净版做对 → 看是不是读题（HR）、实验（HE）或计算（HQ）。

## 二、维度①：符号表征（HS）

**定义：** 化学用语的书写或含义出错。**判断标准：** 让学生单独写出这个化学式 / 方程式，仍然写错 → HS。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HS01 | 元素符号书写不规范 | Co 写成 CO；第二个字母大写（MG） | → HM02 物质构成粒子判断 |
| HS02 | 化合价或原子团记错 | 铝写成 +2 价；硫酸根记成 −1 价；铵根记成 −1 价 | → HS03 |
| HS03 | 化学式书写错误 | 正负化合价代数和不为零；原子团个数不加括号（CaOH₂） | → HS02 |
| HS04 | 方程式未配平或配平方法混乱 | 改化学式右下角的数字来"配平" | → HM03 化学变化的微观本质 |
| HS05 | 反应条件或 ↑ ↓ 标注错误 | 漏写"点燃""△""通电"；反应物中有气体时生成物的气体仍标 ↑ | → HE02 |
| HS06 | 化学符号中数字的含义混淆 | 分不清 2H、H₂、2H₂ 中各个"2"的含义；离子符号的电荷写成化合价的样子 | → HM05 原子结构与离子 |

## 三、维度②：微观表征（HM）

**定义：** 说不清微观粒子层面发生了什么，或把宏观性质强加给单个粒子。**判断标准：** 请学生用"粒子"讲一遍这个现象，讲不出或讲错 → HM。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HM01 | 宏观性质套到单个粒子上 | "受热膨胀是分子变大了"（实为分子间隔变大）；"铜原子是红色的" | → micro-analogy-bank §分子间隔 |
| HM02 | 物质构成粒子判断错 | 认为铁由分子构成；认为氯化钠由氯化钠分子构成 | → HS01 |
| HM03 | 化学变化的微观本质说不清 | 说不出"分子分成原子、原子重新组合成新分子" | → HS04 |
| HM04 | 质量守恒缺少微观解释 | 知道结论，说不出"原子的种类、数目、质量都不变" | → HQ03 |
| HM05 | 原子结构与离子形成混淆 | 最外层电子数与得失电子、所带电荷对不上 | → HS06 |
| HM06 | 反应微观示意图读图错误 | 没把未参加反应的分子扣除就数个数、写方程式 | → HR05 图像信息漏读 |

## 四、维度③：宏观概念（HC）

**定义：** 物质分类、变化类型、物质性质等宏观层面的概念混淆。**判断标准：** 换成纯净版概念判断题仍然错 → HC。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HC01 | 物理变化与化学变化判断错 | 把"有发光放热"当作化学变化的判据（灯泡发光是物理变化）；判据应是有无新物质生成 | → HM03 |
| HC02 | 物质分类混淆 | 含氧元素的化合物都当成氧化物；"由同种元素组成的物质一定是单质" | → HM02 |
| HC03 | 溶液概念混淆 | 饱和与浓、稀混为一谈；溶解度与溶质质量分数混用；以为升温一定能让饱和溶液变不饱和（氢氧化钙的溶解度随温度升高而减小） | → HQ04 |
| HC04 | 酸、碱、盐的性质与类别混淆 | 碳酸钠溶液显碱性就认定它是碱（它属于盐）；生成盐和水的反应都当成中和反应 | → HE04 |
| HC05 | 金属活动性顺序应用错误 | 忽略"前面的金属置换后面的金属"须在盐溶液中进行；钾、钙、钠直接与盐溶液反应时先和水反应 | → HE05 |
| HC06 | 燃烧条件与灭火原理混淆 | "降低着火点来灭火"（着火点是物质的固有属性，灭火是把温度降到着火点以下） | → HE05 |

## 五、维度④：读题与条件（HR）

**定义：** 概念会、方法会，但漏读或误读了题目的关键限定。**判断标准：** 让学生逐字复述题目条件后立刻会做 → HR。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HR01 | 用量限定词漏读 | 没注意"足量""过量""少量""适量"，反应后成分判断错 | → HC04 |
| HR02 | "恰好完全反应"漏读 | 反应后溶液中的溶质多写了剩余的反应物 | → HQ05 |
| HR03 | 滴加顺序与反应先后漏读 | 向盐酸与氯化钙的混合溶液中滴加碳酸钠溶液，没意识到碳酸钠先与盐酸反应 | → HC04 |
| HR04 | 题目限定条件漏读 | "常温""隔绝空气""除杂时不引入新杂质"等限定没用上 | → HE04 |
| HR05 | 图像与示意图信息漏读 | 坐标起点、拐点、平台的含义没读出来 | → HM06 |
| HR06 | 推断题的题眼没抓住 | 漏看特征颜色（蓝色溶液、红褐色沉淀）、特征现象（使澄清石灰水变浑浊） | → HC04 |

## 六、维度⑤：实验与探究（HE）

**定义：** 实验原理、装置、操作、现象描述、方案设计或安全规范出错。**判断标准：** 原理与概念能讲对，但一到"怎么做、看到什么、怎么证明"就出错 → HE。安全口径以实验安全约定为准（随化学实验探究教练、化学解题教练等涉及实验的技能分发）。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HE01 | 气体发生与收集装置选择错误 | 不按反应物状态与反应条件选发生装置；不按密度与溶解性选收集方法 | → lab-guide §气体制取 |
| HE02 | 操作顺序错误 | 先装药品后检查气密性；排水法收集结束先熄灯后撤导管；可燃性气体未验纯就点燃 | → HE06 |
| HE03 | 现象与结论混淆 | 把"生成二氧化碳"写成现象（现象应是"产生气泡、澄清石灰水变浑浊"） | → HM03 |
| HE04 | 检验与除杂试剂选择错误 | 除杂引入新杂质或把被提纯的物质也除掉；检验顺序互相干扰 | → HR04 |
| HE05 | 探究方案缺对照或变量控制不当 | 探究铁生锈条件时缺少只有水或只有氧气的对照组 | → HC05 |
| HE06 | 安全规范违背 | 把水倒进浓硫酸里稀释；向燃着的酒精灯里添加酒精 | → 化学实验探究教练（安全口径以实验安全约定为准） |

## 七、维度⑥：定量计算（HQ）

**定义：** 化学关系对、列式思路对，数值计算或计算格式出错。**判断标准：** 把化学部分讲清楚后仍算错 → HQ；若列式本身就错，回到 HS / HM / HC。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HQ01 | 相对分子质量计算错误 | 括号外的角标没乘进去：Ca(OH)₂ 算成 40 + 16 + 1 × 2 | → HS03 |
| HQ02 | 元素质量分数或质量比计算错误 | 忘记乘原子个数；质量比写成原子个数比 | → HQ01 |
| HQ03 | 按化学方程式计算的格式与比例错误 | 把混合物的质量直接代入；未知数带单位；比例的上下对应关系错 | → HM04 |
| HQ04 | 溶质质量分数计算错误 | 分母用了溶剂质量；稀释时没抓住"稀释前后溶质质量不变" | → HC03 |
| HQ05 | 反应后溶液质量计算错误 | 没减去逸出的气体或生成的沉淀；把不溶性杂质算进溶液 | → HR02 |

## 八、高中必修起点的子类型（高一衔接段）

本节子类型只在学生已进入高一，或初中毕业后做衔接预习时使用；编号接在初中子类型之后。内容范围对应高中必修主题 1「物质的量及其相关物理量」、主题 2「2.2 氧化还原反应」「2.3 电离与离子反应」。

| 子类型ID | 维度 | 名称 | 典型表现 |
|---|---|---|---|
| HS07 | 符号表征 | 离子方程式书写错误 | 该拆的没拆（可溶性强电解质）、不该拆的拆了（沉淀、气体、水、氧化物、单质）；电荷不守恒 |
| HS08 | 符号表征 | 电子转移的表示错误 | 双线桥的箭头方向或得失电子总数标错 |
| HM07 | 微观表征 | 电离的微观过程说不清 | 以为电离需要通电；说不清溶液导电是因为有自由移动的离子 |
| HC07 | 宏观概念 | 电解质概念混淆 | 铜能导电就认定它是电解质（电解质须是化合物）；二氧化碳的水溶液能导电就认定二氧化碳是电解质 |
| HC08 | 宏观概念 | 氧化剂与还原剂的角色颠倒 | "化合价升高的是氧化剂"（应为：化合价升高、失去电子、被氧化，是还原剂） |
| HE07 | 实验与探究 | 配制一定物质的量浓度溶液的操作与误差分析错误 | 未冷却就转移定容；定容时仰视或俯视刻度线对浓度的影响判断反 |
| HQ06 | 定量计算 | 物质的量相关换算错误 | 非标准状况下的气体也用 22.4 L/mol；c = n / V 里的 V 用了溶剂的体积 |

## 九、跨维度关联规则

```text
HS ↔ HM：方程式配不平（HS04），根子常在"原子重新组合"没想清楚（HM03）
          → 先用粒子图讲一遍，再回到配平

HM ↔ HQ：按方程式计算的比例列错（HQ03），常因为不理解质量守恒的微观含义（HM04）

HC ↔ HR：酸碱盐推断题失分，先分清是性质不会（HC04）还是题眼没抓住（HR06）
          → 纯净版性质题做对 → HR；做错 → HC

HE ↔ HC：除杂方案错（HE04），先确认物质性质（HC04）是否掌握

主维度判定仍以"纯净版测试"为准；跨维度只作为突破时的联动线索。
```

## 十、与通用错题本的协作边界

### 10.1 职责分工

```text
通用错题本（表面层，唯一计数权威）：
  → 接收所有科目错题；基础四维分类（shared/vocab.md §1）
  → 28 天累计计数与"顽固"判定（shared/vocab.md §5）

化学错误DNA（深度层，本维度表）：
  → 化学六维深度分类与子类型定位
  → 跨维度关联分析；顽固弱项专项突破（计数不在本层）
  → 化学焦虑处理（先过危机例外）；学生要求时生成化学弱项月报
```

### 10.2 维度映射

```text
通用四维（basicDimension）  →  化学六维可能映射      →  判断依据
────────────────────────────────────────────────────────────
概念模糊                →  HS / HM / HC         →  错在符号、粒子还是宏观概念？
计算失误                →  HQ                   →  化学关系对、算错
读题失误                →  HR                   →  复述条件后立刻会做
方法用错                →  HE（实验类）或 HS    →  实验方案/操作 → HE；方程式配平策略 → HS
```

反向映射（写回通用层时用，`shared/vocab.md §2`）：化学 HS、HM、HC → 概念模糊；HQ → 计算失误；HR → 读题失误；HE → 方法用错。
通用四维与化学六维不是一一对应，本 SKILL 的判断写入 `chemistryDimension`，通用层字段 `basicDimension` 保持错题本给出的值不变。
