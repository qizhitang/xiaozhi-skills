# 化学错因维度表

> 适用学段：初中化学；第八、十一、十二节为高中内容（第八节必修起点：物质的量、氧化还原、电离与离子反应；第十一节必修其余；第十二节选择性必修）。
> 本文档是 `xiaozhi-chemistry-error-dna` 的核心参考资源，定义化学六维错因、子类型、跨维度关联规则与交接契约。化学用语与方程式教练、化学解题教练、化学实验探究教练与微观世界想象器随包带的是同一份副本，用来查子类型的定义；第十节（与通用错题本的协作边界）只由化学错误DNA 执行。
> 词表与阈值以 `shared/vocab.md` 为唯一来源；本表只定义化学子类型 ID 的含义（`shared/vocab.md §2`）。
> 课程依据：《义务教育化学课程标准（2022 年版）》五个学习主题；《普通高中化学课程标准日常修订版（2017 年版 2025 年修订）》必修与选择性必修。
>
> ⚠️ **编码命名空间**：化学子类型一律用「H + 维度字母」两字母前缀（如 `HS03`），与数学、物理的单字母编码不会混淆。

## 一、维度总览：宏观—微观—符号

化学学习有一个物理没有的难点：同一件事要在三个层面之间来回切换——

```
宏观（看得见的现象）  ：铁丝在氧气里剧烈燃烧、火星四射，生成黑色固体
微观（看不见的粒子）  ：铁原子和氧分子中的氧原子重新组合
符号（写出来的式子）  ：3Fe + 2O₂ ==点燃== Fe₃O₄
```

学生卡住，往往是三个层面之间断了一环。六个维度按这个三角组织：

```text
维度①  符号表征 (HS)   ── 化学用语写错：元素符号、化合价、化学式、方程式
维度②  微观表征 (HM)   ── 粒子观缺失：说不出微观发生了什么，或把宏观性质套到粒子上
维度③  宏观概念 (HC)   ── 物质、变化、性质层面的概念混淆
维度④  读题与条件 (HR) ── 漏读"足量""恰好完全反应""滴加顺序"等关键条件
维度⑤  实验与探究 (HE) ── 装置、操作顺序、现象与结论、检验与除杂、安全
维度⑥  定量计算 (HQ)   ── 相对分子质量、质量分数、按方程式计算

每道错题归入且只归入一个主维度；有跨维度因素时记为"主维度 + 次要维度"。

优先处理顺序：HS > HM > HC > HR > HE > HQ
→ 化学用语是整门课的"语言"，符号写不对，后面的推理与计算都无从谈起
```

判定时先做**纯净版测试**：把干扰条件去掉，只留一个知识点再问一次。纯净版也错 → 概念类（HS/HM/HC）；纯净版做对 → 看是不是读题（HR）、实验（HE）或计算（HQ）。

## 二、维度①：符号表征（HS）

**定义：** 化学用语的书写或含义出错。**判断标准：** 让学生单独写出这个化学式 / 方程式，仍然写错 → HS。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HS01 | 元素符号书写不规范 | Co 写成 CO；第二个字母大写（MG） | → HM02 物质构成粒子判断 |
| HS02 | 化合价或原子团记错 | 铝写成 +2 价；硫酸根记成 −1 价；铵根记成 −1 价 | → HS03 |
| HS03 | 化学式书写错误 | 正负化合价代数和不为零；原子团个数不加括号（CaOH₂） | → HS02 |
| HS04 | 方程式未配平或配平方法混乱 | 改化学式右下角的数字来"配平" | → HM03 化学变化的微观本质 |
| HS05 | 反应条件或 ↑ ↓ 标注错误 | 漏写"点燃""△""通电"；反应物中有气体时生成物的气体仍标 ↑ | → HE02 |
| HS06 | 化学符号中数字的含义混淆 | 分不清 2H、H₂、2H₂ 中各个"2"的含义；离子符号的电荷写成化合价的样子 | → HM05 原子结构与离子 |

## 三、维度②：微观表征（HM）

**定义：** 说不清微观粒子层面发生了什么，或把宏观性质强加给单个粒子。**判断标准：** 请学生用"粒子"讲一遍这个现象，讲不出或讲错 → HM。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HM01 | 宏观性质套到单个粒子上 | "受热膨胀是分子变大了"（实为分子间隔变大）；"铜原子是红色的" | → micro-analogy-bank §分子间隔 |
| HM02 | 物质构成粒子判断错 | 认为铁由分子构成；认为氯化钠由氯化钠分子构成 | → HS01 |
| HM03 | 化学变化的微观本质说不清 | 说不出"分子分成原子、原子重新组合成新分子" | → HS04 |
| HM04 | 质量守恒缺少微观解释 | 知道结论，说不出"原子的种类、数目、质量都不变" | → HQ03 |
| HM05 | 原子结构与离子形成混淆 | 最外层电子数与得失电子、所带电荷对不上 | → HS06 |
| HM06 | 反应微观示意图读图错误 | 没把未参加反应的分子扣除就数个数、写方程式 | → HR05 图像信息漏读 |

## 四、维度③：宏观概念（HC）

**定义：** 物质分类、变化类型、物质性质等宏观层面的概念混淆。**判断标准：** 换成纯净版概念判断题仍然错 → HC。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HC01 | 物理变化与化学变化判断错 | 把"有发光放热"当作化学变化的判据（灯泡发光是物理变化）；判据应是有无新物质生成 | → HM03 |
| HC02 | 物质分类混淆 | 含氧元素的化合物都当成氧化物；"由同种元素组成的物质一定是单质" | → HM02 |
| HC03 | 溶液概念混淆 | 饱和与浓、稀混为一谈；溶解度与溶质质量分数混用；以为升温一定能让饱和溶液变不饱和（氢氧化钙的溶解度随温度升高而减小） | → HQ04 |
| HC04 | 酸、碱、盐的性质与类别混淆 | 碳酸钠溶液显碱性就认定它是碱（它属于盐）；生成盐和水的反应都当成中和反应 | → HE04 |
| HC05 | 金属活动性顺序应用错误 | 忽略"前面的金属置换后面的金属"须在盐溶液中进行；钾、钙、钠直接与盐溶液反应时先和水反应 | → HE05 |
| HC06 | 燃烧条件与灭火原理混淆 | "降低着火点来灭火"（着火点是物质的固有属性，灭火是把温度降到着火点以下） | → HE05 |

## 五、维度④：读题与条件（HR）

**定义：** 概念会、方法会，但漏读或误读了题目的关键限定。**判断标准：** 让学生逐字复述题目条件后立刻会做 → HR。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HR01 | 用量限定词漏读 | 没注意"足量""过量""少量""适量"，反应后成分判断错 | → HC04 |
| HR02 | "恰好完全反应"漏读 | 反应后溶液中的溶质多写了剩余的反应物 | → HQ05 |
| HR03 | 滴加顺序与反应先后漏读 | 向盐酸与氯化钙的混合溶液中滴加碳酸钠溶液，没意识到碳酸钠先与盐酸反应 | → HC04 |
| HR04 | 题目限定条件漏读 | "常温""隔绝空气""除杂时不引入新杂质"等限定没用上 | → HE04 |
| HR05 | 图像与示意图信息漏读 | 坐标起点、拐点、平台的含义没读出来 | → HM06 |
| HR06 | 推断题的题眼没抓住 | 漏看特征颜色（蓝色溶液、红褐色沉淀）、特征现象（使澄清石灰水变浑浊） | → HC04 |

## 六、维度⑤：实验与探究（HE）

**定义：** 实验原理、装置、操作、现象描述、方案设计或安全规范出错。**判断标准：** 原理与概念能讲对，但一到"怎么做、看到什么、怎么证明"就出错 → HE。安全口径以实验安全约定为准（随化学实验探究教练、化学解题教练等涉及实验的技能分发）。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HE01 | 气体发生与收集装置选择错误 | 不按反应物状态与反应条件选发生装置；不按密度与溶解性选收集方法 | → lab-guide §气体制取 |
| HE02 | 操作顺序错误 | 先装药品后检查气密性；排水法收集结束先熄灯后撤导管；可燃性气体未验纯就点燃 | → HE06 |
| HE03 | 现象与结论混淆 | 把"生成二氧化碳"写成现象（现象应是"产生气泡、澄清石灰水变浑浊"） | → HM03 |
| HE04 | 检验与除杂试剂选择错误 | 除杂引入新杂质或把被提纯的物质也除掉；检验顺序互相干扰 | → HR04 |
| HE05 | 探究方案缺对照或变量控制不当 | 探究铁生锈条件时缺少只有水或只有氧气的对照组 | → HC05 |
| HE06 | 安全规范违背 | 把水倒进浓硫酸里稀释；向燃着的酒精灯里添加酒精 | → 化学实验探究教练（安全口径以实验安全约定为准） |

## 七、维度⑥：定量计算（HQ）

**定义：** 化学关系对、列式思路对，数值计算或计算格式出错。**判断标准：** 把化学部分讲清楚后仍算错 → HQ；若列式本身就错，回到 HS / HM / HC。

| 子类型ID | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|
| HQ01 | 相对分子质量计算错误 | 括号外的角标没乘进去：Ca(OH)₂ 算成 40 + 16 + 1 × 2 | → HS03 |
| HQ02 | 元素质量分数或质量比计算错误 | 忘记乘原子个数；质量比写成原子个数比 | → HQ01 |
| HQ03 | 按化学方程式计算的格式与比例错误 | 把混合物的质量直接代入；未知数带单位；比例的上下对应关系错 | → HM04 |
| HQ04 | 溶质质量分数计算错误 | 分母用了溶剂质量；稀释时没抓住"稀释前后溶质质量不变" | → HC03 |
| HQ05 | 反应后溶液质量计算错误 | 没减去逸出的气体或生成的沉淀；把不溶性杂质算进溶液 | → HR02 |

## 八、高中必修起点的子类型（高一衔接段）

本节子类型只在学生已进入高一，或初中毕业后做衔接预习时使用；编号接在初中子类型之后。内容范围对应高中必修主题 1「物质的量及其相关物理量」、主题 2「2.2 氧化还原反应」「2.3 电离与离子反应」。

| 子类型ID | 维度 | 名称 | 典型表现 |
|---|---|---|---|
| HS07 | 符号表征 | 离子方程式书写错误 | 该拆的没拆（可溶性强电解质）、不该拆的拆了（沉淀、气体、水、氧化物、单质）；电荷不守恒 |
| HS08 | 符号表征 | 电子转移的表示错误 | 双线桥的箭头方向或得失电子总数标错 |
| HM07 | 微观表征 | 电离的微观过程说不清 | 以为电离需要通电；说不清溶液导电是因为有自由移动的离子 |
| HC07 | 宏观概念 | 电解质概念混淆 | 铜能导电就认定它是电解质（电解质须是化合物）；二氧化碳的水溶液能导电就认定二氧化碳是电解质 |
| HC08 | 宏观概念 | 氧化剂与还原剂的角色颠倒 | "化合价升高的是氧化剂"（应为：化合价升高、失去电子、被氧化，是还原剂） |
| HE07 | 实验与探究 | 配制一定物质的量浓度溶液的操作与误差分析错误 | 未冷却就转移定容；定容时仰视或俯视刻度线对浓度的影响判断反 |
| HQ06 | 定量计算 | 物质的量相关换算错误 | 非标准状况下的气体也用 22.4 L/mol；c = n / V 里的 V 用了溶剂的体积 |

## 九、跨维度关联规则

```text
HS ↔ HM：方程式配不平（HS04），根子常在"原子重新组合"没想清楚（HM03）
          → 先用粒子图讲一遍，再回到配平

HM ↔ HQ：按方程式计算的比例列错（HQ03），常因为不理解质量守恒的微观含义（HM04）

HC ↔ HR：酸碱盐推断题失分，先分清是性质不会（HC04）还是题眼没抓住（HR06）
          → 纯净版性质题做对 → HR；做错 → HC

HE ↔ HC：除杂方案错（HE04），先确认物质性质（HC04）是否掌握

主维度判定仍以"纯净版测试"为准；跨维度只作为突破时的联动线索。
```

### 10.1 职责分工

```text

```

### 10.2 维度映射

```text
通用四维（basicDimension）  →  化学六维可能映射      →  判断依据
────────────────────────────────────────────────────────────
概念模糊                →  HS / HM / HC         →  错在符号、粒子还是宏观概念？
计算失误                →  HQ                   →  化学关系对、算错
读题失误                →  HR                   →  复述条件后立刻会做
方法用错                →  HE（实验类）或 HS    →  实验方案/操作 → HE；方程式配平策略 → HS
```

反向映射（写回通用层时用，`shared/vocab.md §2`）：化学 HS、HM、HC → 概念模糊；HQ → 计算失误；HR → 读题失误；HE → 方法用错。
通用四维与化学六维不是一一对应，本 SKILL 的判断写入 `chemistryDimension`，通用层字段 `basicDimension` 保持错题本给出的值不变。

## 十一、高中：必修其余的子类型

本节子类型用于学习高中必修的学生：主题 2 的元素与物质、钠铁氯氮硫及其化合物，主题 3 的原子结构与元素周期律、化学键、化学反应的限度与快慢、化学反应与能量转化，主题 4 的简单有机化合物。编号接在第八节之后，六个维度的定义不变。主题 5「化学与社会发展」以认识、了解为主，不单设子类型，遇到时只做通用四维分类。学业水平合格性考试考必修与 9 个学生必做实验（含独立设置的实验操作考试），没有选考化学的学生按合格考的深度分析。

必修的化学反应速率只讲表示方法与影响因素的探究，化学平衡只讲描述平衡状态、判断是否达到平衡，电化学只讲原电池的构成要素与工作原理；速率计算、平衡常数、焓变与不同介质的电极反应式在第十二节。必修的丁烷、戊烷同分异构体，以及所用教材在必修已讲的速率简单计算（v = Δc/Δt）、铜锌原电池两极的反应，出错时记第十二节开头所列的 HM15、HQ09、HS12。写错铜锌原电池两极的反应时，先请学生说出哪一极失电子、电子怎样流动：说错记本节的 HC14，说对、式子写错才记 HS12。

| 子类型ID | 维度 | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|---|
| HS09 | 符号表征 | 原子结构示意图与电子式书写错误 | 1~20 号元素的核外电子排布画错（如把钾画成 2、8、9）；离子化合物的电子式不写方括号和电荷；共价分子的电子式漏写未成键电子 | → HM05 原子结构与离子形成混淆 |
| HS10 | 符号表征 | 有机反应式书写错误（必修） | 乙烯写成 CH₂CH₂（漏写碳碳双键）；乙醇的催化氧化写成生成乙酸（应为乙醛）；酯化反应漏写可逆符号或"浓硫酸、△" | → HC15 |
| HM08 | 微观表征 | 元素周期律说不清结构原因 | 只背结论，说不出同周期从左到右核电荷数增大、原子半径减小、得电子能力增强；同主族从上到下的解释颠倒 | → HR08 |
| HM09 | 微观表征 | 化学键类型判断错误 | "含金属元素的化合物一定是离子化合物"（AlCl₃ 是共价化合物）；"NH₄Cl 只含共价键"（它含离子键）；把分子间作用力当成化学键 | → HM02 物质构成粒子判断错 |
| HM10 | 微观表征 | 反应热效应的化学键解释说不清 | 说不出"断键吸收能量、成键放出能量"，只会背"燃烧是放热反应" | → HM03 化学变化的微观本质说不清 |
| HC09 | 宏观概念 | 胶体的概念混淆 | "丁达尔效应是胶体与溶液的本质区别"（本质区别是分散质粒子直径在 1~100 nm）；把 Fe(OH)₃ 沉淀当成胶体 | → HC02 物质分类混淆 |
| HC10 | 宏观概念 | 钠及其化合物的性质混淆 | Na₂O 与 Na₂O₂ 混为一谈（Na₂O₂ 与水反应放出 O₂）；Na₂CO₃ 与 NaHCO₃ 的热稳定性、与盐酸反应的快慢记反 | → HC04 酸、碱、盐的性质与类别混淆 |
| HC11 | 宏观概念 | 铁的价态转化与检验混淆 | "铁与盐酸反应生成 FeCl₃"；检验 Fe²⁺ 时先加氧化剂再加 KSCN 溶液（应先加 KSCN 溶液不变红，再加氧化剂变红） | → HE04 检验与除杂试剂选择错误 |
| HC12 | 宏观概念 | 氯、硫、氮及其化合物的性质混淆 | SO₂ 使品红溶液褪色与氯水使品红溶液褪色的原理混为一谈（前者可逆，后者是氧化）；"浓硫酸、硝酸与金属反应放出氢气" | → HC08 氧化剂与还原剂的角色颠倒 |
| HC13 | 宏观概念 | 化学反应速率与限度混淆 | "加催化剂能提高反应物的转化率"（只改变速率，不改变限度）；"达到限度时反应停止了"（正、逆反应速率相等且不为零） | → HE09 |
| HC14 | 宏观概念 | 原电池的构成与正负极判断错误 | 两极用同种金属或没有形成闭合回路也判为原电池；电子流向、溶液中离子的移动方向判断反 | → HC08 |
| HC15 | 宏观概念 | 常见有机物的性质与反应类型混淆 | 乙烯使溴水褪色（加成）与使酸性 KMnO₄ 溶液褪色（氧化）混为一谈；"甲烷能使酸性高锰酸钾溶液褪色" | → HS10 |
| HR07 | 读题与条件 | 离子共存与用量条件漏读 | 没注意"无色溶液"（排除 Cu²⁺、Fe³⁺ 等有色离子）、"酸性溶液"（隐含大量 H⁺）；少量与过量 CO₂ 通入澄清石灰水的产物不同 | → HR01 用量限定词漏读 |
| HR08 | 读题与条件 | 元素推断的题眼没抓住 | 漏用"短周期""原子序数依次增大""最外层电子数是次外层的 3 倍"等关键信息 | → HR06 推断题的题眼没抓住 |
| HE08 | 实验与探究 | 物质性质实验的操作错误（铁、硫） | 制备 Fe(OH)₂ 时不隔绝空气（白色沉淀很快变成灰绿色，最后变成红褐色）；含硫物质转化的实验不做尾气处理 | → HE02 操作顺序错误 |
| HE09 | 实验与探究 | 控制变量的对比实验设计错误 | 探究温度对速率的影响时同时改变了浓度；对比实验不写明"其他条件相同" | → HE05 探究方案缺对照或变量控制不当 |
| HQ07 | 定量计算 | 得失电子守恒计算错误 | 不用得失电子守恒列式，逐步按方程式算时出错；忘记乘原子个数或离子个数 | → HS08 电子转移的表示错误 |

**跨维度判断**（判断顺序仍按第一节：HS > HM > HC > HR > HE > HQ）

```text
HM08(元素周期律说不清结构原因) + HR08(元素推断的题眼没抓住)
  → 判断：先把元素直接告诉学生，请他比较两种元素的金属性（或非金属性）并说出原因
    比较错，或原因说不清、说反 → HM08
    告诉元素后能答对，自己推不出是哪种元素 → HR08

HC11(铁的价态转化与检验混淆) + HE08(物质性质实验的操作错误)
  → 判断：请学生说出检验 Fe²⁺ 的试剂顺序和每一步的现象
    顺序或现象说错 → HC11
    说得对，实验题里的操作（如制 Fe(OH)₂ 不隔绝空气）出错 → HE08

HC13(化学反应速率与限度混淆) + HE09(控制变量的对比实验设计错误)
  → 判断：请学生说出催化剂改变的是反应速率还是反应限度
    说成改变限度或转化率 → HC13
    概念说得对，设计对比实验时同时改了两个条件 → HE09

HS10(有机反应式书写错误) + HC15(常见有机物的性质与反应类型混淆)
  → 判断：先请学生说出乙烯与溴水、与酸性高锰酸钾溶液各发生什么类型的反应
    类型说错 → HC15
    类型说对，写出的反应式或结构简式有误 → HS10

HC14(原电池的构成与正负极判断错误) + HQ07(得失电子守恒计算错误)
  → 判断：请学生说出负极上失去电子的物质和外电路中电子的流向
    说错 → HC14

```

## 十二、高中：选择性必修的子类型

本节子类型用于选考化学的学生（学业水平等级性考试考必修与选择性必修及 18 个学生必做实验，只有纸笔考试）；编号接在第十一节之后，六个维度的定义不变。内容范围对应选择性必修 1「化学反应原理」、选择性必修 2「物质结构与性质」、选择性必修 3「有机化学基础」。没有选考化学的学生遇到这些内容，说明它属于选择性必修，只做通用四维分类。例外：必修也要求写出丁烷和戊烷的同分异构体，必修学生在这里出错同样记 HM15；所用教材在必修已讲的速率简单计算（v = Δc/Δt）、铜锌原电池两极的反应，必修学生出错时同样记 HQ09、HS12。

课标明文要求的简单计算是反应焓变、平衡常数与平衡转化率、化学反应速率与溶液 pH（HQ08—HQ10）；晶胞计算（HQ11）与溶度积属教材内容，按所用教材例题的深度处理，不说成课标要求。

| 子类型ID | 维度 | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|---|
| HS11 | 符号表征 | 热化学方程式书写错误 | 漏标物质的聚集状态；ΔH 的正负号、单位写错；ΔH 与化学计量数不对应（计量数加倍，ΔH 没有加倍） | → HQ08 |
| HS12 | 符号表征 | 电极反应式书写错误 | 碱性介质中的负极反应写成生成 H⁺；电解池的阴、阳极写反；电极反应式电荷不守恒 | → HC18 |
| HS13 | 符号表征 | 电离、水解方程式混淆 | HCO₃⁻ 的电离与水解写混；多元弱酸根一步写完水解；水解方程式写成"="并标"↓" | → HS07 离子方程式书写错误 |
| HS14 | 符号表征 | 核外电子排布式与轨道表示式书写错误 | 违反洪特规则（N 的 2p³ 画成 [↑↓][↑][ ]，没有分占不同轨道）、泡利不相容原理（一个轨道里画两个自旋相同的电子）；Cr、Cu 按常规写成 3d⁴4s²、3d⁹4s² | → HS09 |
| HS15 | 符号表征 | 结构简式与命名错误 | 主链选错、编号方向错；键线式漏写官能团 | → HS10 |
| HM11 | 微观表征 | 分子空间结构判断错误 | 不数孤电子对就定构型（把 H₂O 判成直线形）；把杂化类型与分子的空间结构混为一谈（教材用价层电子对互斥模型、杂化轨道理论解释） | → HM12 |
| HM12 | 微观表征 | 键的极性与分子的极性混淆 | "含极性键的分子一定是极性分子"（CO₂、CH₄ 是非极性分子） | → HM11 |
| HM13 | 微观表征 | 氢键、范德华力与化学键混淆 | "氢键是化学键"；用氢键解释分子的稳定性（稳定性由共价键的强弱决定） | → HM09 |
| HM14 | 微观表征 | 配合物的成键判断错误 | 中心离子、配体、配位数分不清；"配位键不是共价键"（配位键是一类特殊的共价键） | → HM09 |
| HM15 | 微观表征 | 同分异构体遗漏或重复 | 不按对称性找等效氢，重复计数或漏计；只写碳链异构，漏写官能团的位置异构；必修的丁烷、戊烷同分异构体也记本子类型 | → HS15 |
| HC16 | 宏观概念 | 平衡移动原理误用 | "加催化剂平衡移动"；气体分子数不变的反应仍说"加压平衡正向移动"；把"减弱这种改变"理解成"抵消这种改变" | → HC13 |
| HC17 | 宏观概念 | 弱电解质电离与盐类水解的判断错误 | "pH 相同的醋酸与盐酸稀释相同倍数后 pH 仍相同"；判断盐溶液的酸碱性时不看组成盐的酸、碱的强弱 | → HC07 电解质概念混淆 |
| HC18 | 宏观概念 | 原电池、电解池与金属腐蚀的原理混淆 | 把电解池的阳极当成负极；牺牲阳极法中把被保护的金属当成阳极 | → HC14 |
| HC19 | 宏观概念 | 沉淀溶解平衡的概念混淆 | "沉淀完全就是溶液中不再有这种离子"；不同类型的难溶物直接比溶度积来判断溶解度（溶度积属教材内容） | → HC03 溶液概念混淆 |
| HC20 | 宏观概念 | 元素性质的周期性规律应用错误 | 第一电离能的反常判断错（Mg > Al、N > O）；用电负性判断键的极性时方向弄反 | → HM08 |
| HC21 | 宏观概念 | 晶体类型与性质对应错误 | 比较熔点时不先判断晶体类型（SiO₂ 是共价晶体，熔点远高于 CO₂）；"分子晶体中共价键越强，熔点越高" | → HM13 |
| HC22 | 宏观概念 | 官能团的性质混淆 | 醇羟基与酚羟基的酸性混淆（乙醇不与 NaOH 溶液反应）；醛基检验的条件记错（银镜反应要水浴加热，新制 Cu(OH)₂ 要碱性、加热） | → HC15 |
| HC23 | 宏观概念 | 有机反应类型判断错误 | 卤代烃在 NaOH 水溶液中（取代）与 NaOH 醇溶液中（消去）混淆；把酯的水解当成加成 | → HC15 |
| HC24 | 宏观概念 | 单体与高分子的相互推断错误 | 加聚与缩聚分不清；由链节找单体时断错键 | → HC23 |
| HR09 | 读题与条件 | 速率与平衡图像信息漏读 | 没看横、纵坐标，起点、拐点的先后（"先拐先平，数值大"）和平台的含义 | → HR05 图像与示意图信息漏读 |
| HR10 | 读题与条件 | 有机推断的隐含信息漏读 | 没从分子式算不饱和度；没用反应条件（浓硫酸加热、NaOH 醇溶液加热）锁定反应类型；图谱信息没用上 | → HR06 |
| HE10 | 实验与探究 | 中和滴定的操作与误差分析错误 | 滴定管未用标准溶液润洗；锥形瓶用待测液润洗；读数时视线造成的误差方向判断反 | → HE07 |
| HE11 | 实验与探究 | 电镀与电解装置连接错误 | 镀件接电源正极（应作阴极、接负极）；电镀液不含镀层金属的离子 | → HE01 气体发生与收集装置选择错误 |
| HE12 | 实验与探究 | 有机实验与官能团检验的操作错误 | 导管伸入饱和碳酸钠溶液液面以下（倒吸）；检验碳碳双键前没排除醛基的干扰；蔗糖的水解液没有先中和就加新制 Cu(OH)₂ | → HE02 |
| HQ08 | 定量计算 | 反应焓变的计算错误 | 用盖斯定律叠加时，方程式反写后 ΔH 不变号、乘系数后 ΔH 没有同乘；用键能算 ΔH 时写成生成物键能总和减反应物键能总和（应为反应物减生成物） | → HS11 |
| HQ09 | 定量计算 | 化学反应速率、平衡常数与平衡转化率的计算错误 | 用物质的量的变化代替浓度的变化；把物质的量直接代入 K 的表达式；K 的表达式里写了固体或纯液体 | → HQ06 物质的量相关换算错误 |
| HQ10 | 定量计算 | 溶液 pH 的计算错误 | 强碱溶液直接用 c(OH⁻) 求 pH（应先由 Kw 求 c(H⁺)）；强酸稀释 10ⁿ 倍后算出的 pH 超过 7 | → HC17 |
| HQ11 | 定量计算 | 晶胞计算错误（教材内容） | 均摊法中顶点、棱上、面心的微粒贡献（1/8、1/4、1/2）算错；求密度时 pm 与 cm 没有换算 | → HQ06 |

**跨维度判断**（判断顺序仍按第一节：HS > HM > HC > HR > HE > HQ）

```text
HS11(热化学方程式书写错误) + HQ08(反应焓变的计算错误)
  → 判断：先请学生单独写出一个给定反应的热化学方程式（标聚集状态，ΔH 的符号与单位）
    写错 → HS11
    写得对，用盖斯定律叠加时 ΔH 的符号或倍数出错 → HQ08

HM11(分子空间结构判断错误) + HM12(键的极性与分子的极性混淆)
  → 判断：请学生先画出分子的空间结构
    构型画错（如把 H₂O 画成直线形） → HM11
    构型画对，仍把"含极性键"当成"极性分子" → HM12

HS12(电极反应式书写错误) + HC18(原电池、电解池与金属腐蚀的原理混淆)
  → 判断：请学生先说出哪一极发生氧化反应、电子从哪一极流出
    说错 → HC18
    说得对，写电极反应式时介质处理错或电荷不守恒 → HS12

HC16(平衡移动原理误用) + HR09(速率与平衡图像信息漏读)
  → 判断：去掉图像，直接问"升高温度，这个放热反应的平衡向哪边移动"
    答错 → HC16
    答对，看图时读错坐标、拐点或平台 → HR09

HC17(弱电解质电离与盐类水解的判断错误) + HQ10(溶液 pH 的计算错误)
  → 判断：请学生先判断溶液显酸性、碱性还是中性，再计算
    酸碱性判断错 → HC17
```
