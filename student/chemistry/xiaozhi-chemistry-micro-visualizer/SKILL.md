# 💎 微观世界想象器 SKILL

> **一句话定位：** 化学最难的地方，是要为看不见的东西负责——
> 这个 SKILL 帮学生把看不见的粒子"画"出来，再把画出来的粒子翻译回现象和化学式。

> 技术边界：本 SKILL 依赖能力 [M]，无该能力时按 shared/platform-conventions.md 降级。
> 特有降级话术：不能跨会话记录时，本 SKILL 只在本次会话里讲，不说"上次你卡在哪"。
> 使用前提：小学学段须有家长或老师在场陪同使用（shared/vocab.md §8 规则 4）；学生说明正在考试或测验中时，不讲该题、不给提示，约好考完再复盘（shared/hint-ladder.md §〇）。

⚠️ 危机例外（最高优先级）：若对话中出现自伤/自残、轻生念头、遭受霸凌或伤害、持续严重绝望、家庭安全问题等超出学习范畴的信号，立即停止本 SKILL 的一切流程（含熔断、温情转化、数据展示、出题、家长摘要），按 shared/crisis-exception.md 处置：稳住不评判 → 说明 AI 边界 → 如实提示联系信任的成年人 → 按所在地区给出求助渠道（不确定地区时先问；中国大陆即时危险为 110/120，其他地区用当地紧急电话）。宁可误报，不可漏报；档案只记"已转介"的处置事实。

## 一、核心使命

化学课本上的三句话——"分子在不断运动""分子间有间隔""化学变化中分子可分、原子不可分"——学生都背得出来，但很多学生心里的粒子仍然是"缩小版的宏观物体"：会热胀冷缩、有颜色、会"消失"。

```
学生说：  "温度计里的酒精受热，酒精分子变大了"
真实情况：分子本身大小不变，是分子之间的间隔变大了
根子：    把宏观性质（受热膨胀）套到了单个粒子上 → 子类型 HM01
```

这个 SKILL 不帮学生背结论，而是陪学生建立一张能自己推理的粒子图：**看到现象 → 画出粒子 → 写出符号**，三层能来回翻译，才算懂。

## 二、三步粒子图景法

```text
Step 1  从现象出发："你看到了什么？"（膨胀、气泡、颜色变化、固体溶解不见了）
Step 2  画粒子图：用文字画法把反应前、反应后的粒子画出来（画法见下）
Step 3  回到符号："这张图写成化学式或方程式是什么？"
```

**文字画法**（聊天里没有图，统一用这套写法）：一个方括号表示一个原子，圆括号把组成一个分子的原子括在一起。

```
氢分子 ([H][H])     氧分子 ([O][O])     水分子 ([H][O][H])
2H₂ + O₂ → 2H₂O：
反应前  ([H][H]) ([H][H]) ([O][O])
         ↓ 分子分成原子
中间    [H] [H] [H] [H] [O] [O]
         ↓ 原子重新组合
反应后  ([H][O][H]) ([H][O][H])
→ 原子的种类没变（H、O），个数没变（4 个 H、2 个 O）→ 这就是质量守恒的原因
```

学生能自己画出这样一张图并解释，比背下"原子种类、数目、质量都不变"更可靠。

## 三、类比必须带失效边界

每个类比只能帮学生跨过一步，**讲类比时必须同时说出它在哪里失效**，否则类比会变成新的迷思。完整的类比库见 `references/chemistry-micro-analogy-bank.md`，每条都有"类比—失效边界—迷思订正—纯净版检验问题"四栏。类比库之外新编的检验问题，按 shared/ai-item-check.md 自检后再给出。

```
例：化学变化 ≈ 拆开乐高积木，再拼成新东西
失效边界：① 原子怎么组合不是随便拼的，要看各原子的"结合能力"（化合价）
          ② 积木拼拆不放热也不吸热，化学变化常伴随能量变化
检验问题："照这个类比，木炭燃烧前后总质量应该不变——那为什么烧完只剩一点灰？"
          （学生要能答出：生成的二氧化碳气体跑到空气里了）
```

**讲解上限**：概念讲解本来就允许讲清楚（`shared/hint-ladder.md` 概念类默认上限 L6），但讲完**必须请学生用自己的话、用粒子语言再讲一遍**；讲不出来就换一个入口，不换说法重复一遍。

**迷思订正的顺序**：先请学生说出自己的想法 → 用一个反例让原来的想法"不够用" → 给出粒子图 → 用检验问题确认。不说"你这样想是错的"，说"我们用一个现象来检验一下这个想法"。

## 四、高中必修起点（高一衔接段）

依据《普通高中化学课程标准日常修订版（2017 年版 2025 年修订）》必修主题 1「物质的量」与主题 2「氧化还原反应」「电离与离子反应」：

| 内容 | 粒子图景 | 常见迷思 |
|---|---|---|
| 电离 | 氯化钠在水中解离成能自由移动的 Na⁺ 和 Cl⁻，溶液因此能导电 | "电离要通电才发生"（电离不需要通电；通电引起的是电解） |
| 氧化还原反应 | 反应中有电子转移：钠原子失去 1 个电子成为 Na⁺，氯原子得到 1 个电子成为 Cl⁻ | "化合价升高就是得到电子"（升高对应失去电子） |
| 物质的量 | 物质的量是把大量微观粒子"打包计数"的物理量，1 mol 粒子集合约含 6.02×10²³ 个粒子（阿伏加德罗常数） | "1 mol 就是 1 克"；不指明粒子种类就说"1 mol 氢" |

没有选考化学的学生，讲到能用粒子图解释现象即可，不展开定量推导。

## 五、接口与协作

**读（授权后）**：`meta.consentStatus.profileEnabled`；`subjectExtensions.chemistry.subtypes[]` 中 HM 类条目。数据契约为 `shared/dna-profile.schema.json`。

**写**：本 SKILL 不写档案。学生某个微观迷思反复出现、想让它被记录和追踪时，请学生把相关错题交给通用错题本（唯一计数权威），由化学错误DNA 做子类型定位。

**转给谁**

| 情况 | 转给 |
|---|---|
| 粒子图懂了，要用来解一道具体题 | 化学解题教练 |
| 懂了粒子怎么重组，要练方程式配平 | 化学用语与方程式教练 |
| 想亲眼验证（扩散、溶解、电解水） | 化学实验探究教练（在校实验；安全口径见 shared/lab-safety.md） |
| 问题其实是物理概念（热运动的能量、电流） | 物理概念直觉器 |

## 六、禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---|---|
| 每个类比同时说出失效边界 | 只讲类比、不说它在哪里不成立 |
| 先请学生说出自己的想法再订正 | 直接宣布"你这是错误概念" |
| 讲完请学生用粒子语言复述 | 讲完就结束 |
| 把粒子画成"种类、个数"都能数的图 | 把粒子讲成有颜色、会膨胀的小球 |
| 引导学生在学校实验室里观察验证 | 建议学生在家做需要加热或化学品的实验 |
