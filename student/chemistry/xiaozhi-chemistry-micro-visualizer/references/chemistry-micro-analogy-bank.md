# 化学粒子类比库

> 适用学段：初中化学；第三节为高中必修起点。
> 本文件是 `xiaozhi-chemistry-micro-visualizer` 的参考资源。每条类比都有四栏：**类比**（帮学生跨过哪一步）、**失效边界**（在哪里会讲错）、**迷思订正**（学生最常见的错误想法）、**纯净版检验问题**（讲完用来确认的问题）。
> 讲类比时必须同时讲失效边界；检验问题由学生回答，AI 不代答。

---

## 一、分子、原子、离子（初中）

### 1.1 分子在不断运动

| 栏目 | 内容 |
|---|---|
| 类比 | 教室里的同学下课后散开，最终均匀分布在走廊里——香味、墨水就是这样扩散开的 |
| 失效边界 | 同学"想去哪就去哪"，分子的运动没有目的，是永不停止的无规则运动；温度越高运动越快 |
| 迷思订正 | "分子只有在被搅拌时才运动" → 静置时也在运动，搅拌只是加快混合 |
| 纯净版检验问题 | "把品红分别滴进冷水和热水，哪杯先变均匀？用粒子解释为什么。" |

### 1.2 分子间有间隔

| 栏目 | 内容 |
|---|---|
| 类比 | 同样多的人，站成密集的队形或散开站，占的地方不一样——物质的三态、热胀冷缩都是粒子间隔在变 |
| 失效边界 | 队形变了人没变胖；**受热时变大的是分子之间的间隔，不是分子本身** |
| 迷思订正 | "温度计里的酒精受热，酒精分子变大了"（子类型 HM01） |
| 纯净版检验问题 | "水结成冰，水分子的大小变了吗？变的是什么？" |

### 1.3 物质由哪种粒子构成

| 栏目 | 内容 |
|---|---|
| 类比 | 有的东西由"一对一对的组合"构成（分子），有的由"单个的零件"直接堆成（原子），有的由"带正电和带负电的两种零件"交替排成（离子） |
| 失效边界 | 类比只帮助分类，不能靠类比判断具体物质属于哪一类，要记住课本给的典型例子 |
| 迷思订正 | "氯化钠由氯化钠分子构成"（由 Na⁺ 和 Cl⁻ 构成）；"铁由铁分子构成"（金属由原子直接构成）（子类型 HM02） |
| 纯净版检验问题 | "水、铁、氯化钠，分别由什么粒子构成？" |

### 1.4 原子结构与离子的形成

| 栏目 | 内容 |
|---|---|
| 类比 | 原子像一个"电子账户"：金属原子最外层电子一般少于 4 个，容易"转出"电子；非金属原子最外层一般多于 4 个，容易"转入"电子 |
| 失效边界 | 电子不是"愿意给才给"，得失由原子结构决定；得失电子后原子核（质子数）不变，所以元素种类不变 |
| 迷思订正 | "钠原子失去电子后变成了别的元素"；"Na⁺ 的 + 表示它多了一个质子"（子类型 HM05） |
| 纯净版检验问题 | "钠原子变成钠离子，质子数变了吗？电子数变了吗？为什么带正电？" |

## 二、化学变化与溶解（初中）

### 2.1 化学变化的本质

| 栏目 | 内容 |
|---|---|
| 类比 | 把乐高作品拆成零件，再拼成新的作品 |
| 失效边界 | ① 原子怎么组合要看各原子的结合能力（化合价），不能随便拼；② 拼积木不放热也不吸热，化学变化常伴随能量变化 |
| 迷思订正 | "化学变化中原子也变了"（原子是化学变化中的最小粒子，种类不变）（子类型 HM03） |
| 纯净版检验问题 | "用粒子图画出氢气在氧气中燃烧：反应前后，哪些变了，哪些没变？" |

### 2.2 质量守恒的微观原因

| 栏目 | 内容 |
|---|---|
| 类比 | 教室里换座位：座位怎么换，教室里的总人数和每个人的体重都不变 |
| 失效边界 | 如果有人走出了教室（气体逸出），留在教室里的"总体重"就会变少——这不是守恒被打破，是没把离开的人算进去 |
| 迷思订正 | "蜡烛燃烧后变轻了，所以不符合质量守恒"（生成的二氧化碳和水蒸气散到空气中了）（子类型 HM04） |
| 纯净版检验问题 | "铁丝在氧气中燃烧后，生成物比原来的铁丝重，这违反质量守恒吗？" |

### 2.3 溶解

| 栏目 | 内容 |
|---|---|
| 类比 | 一把糖撒进一群人中间，每颗糖粒都被人群分开、藏在人和人之间，看不见了但还在 |
| 失效边界 | 蔗糖以分子形式分散；氯化钠以 Na⁺ 和 Cl⁻ 的形式分散——不同物质分散成的粒子不一样 |
| 迷思订正 | "盐溶进水里就消失了"（称一称：溶液质量 = 水的质量 + 盐的质量） |
| 纯净版检验问题 | "把 5 g 食盐完全溶于 50 g 水，溶液的质量是多少？食盐去哪了？" |

### 2.4 饱和溶液

| 栏目 | 内容 |
|---|---|
| 类比 | 电影院的座位坐满了，再来的人进不去 |
| 失效边界 | ① "座位数"（溶解度）会随温度变，大多数固体温度升高溶解度增大，但氢氧化钙相反；② 某种物质的饱和溶液，仍然可以溶解别的物质 |
| 迷思订正 | "饱和溶液一定是浓溶液"（饱和看还能不能继续溶解，浓稀看溶质多少，两件事）（子类型 HC03） |
| 纯净版检验问题 | "一杯饱和的食盐水，还能溶解蔗糖吗？" |

### 2.5 酸和碱的共性

| 栏目 | 内容 |
|---|---|
| 类比 | 不同品牌的汽水都含"气泡"这种共同成分，所以喝起来都有刺激感 |
| 失效边界 | 汽水的比喻只说明"共同成分带来共同性质"；酸的共同成分是溶液中的 H⁺，碱是 OH⁻，而不同的酸根、金属离子又带来各自的特性 |
| 迷思订正 | "碳酸钠溶液能使酚酞变红，所以碳酸钠是碱"（它是盐，溶液显碱性）（子类型 HC04） |
| 纯净版检验问题 | "稀盐酸和稀硫酸为什么都能使紫色石蕊溶液变红？" |

### 2.6 中和反应

| 栏目 | 内容 |
|---|---|
| 类比 | 一个正电荷"小球"和一个负电荷"小球"配对，变成一个不带电的水分子 |
| 失效边界 | 配对的只是 H⁺ 和 OH⁻，溶液中的其他离子（如 Na⁺、Cl⁻）没有参与，仍在溶液中 |
| 迷思订正 | "氢氧化钠和盐酸反应后，溶液里什么都没有了，只剩水"（还有 Na⁺ 和 Cl⁻，即氯化钠） |
| 纯净版检验问题 | "画出稀盐酸与氢氧化钠溶液恰好反应前后溶液中的粒子，哪些粒子数量变了？" |

## 三、高中必修起点（高一衔接段）

依据《普通高中化学课程标准日常修订版（2017 年版 2025 年修订）》必修主题 1、主题 2。

### 3.1 电离

| 栏目 | 内容 |
|---|---|
| 类比 | 手拉手的队伍（离子晶体中的 Na⁺ 与 Cl⁻）被一群水分子"拉开"，各自自由走动 |
| 失效边界 | 水分子不是有意"拉"，是离子与水分子之间的相互作用；共价化合物（如 HCl）在水中也能电离，但它原本不是离子构成的 |
| 迷思订正 | "电离要通电才发生"（电离不需要通电；通电引起的是电解）（子类型 HM07） |
| 纯净版检验问题 | "氯化钠固体不导电，氯化钠溶液能导电，粒子层面的区别是什么？" |

### 3.2 氧化还原反应的电子转移

| 栏目 | 内容 |
|---|---|
| 类比 | 传球：一个队员把球传出去（失去电子），另一个接住（得到电子），场上的球数不变 |
| 失效边界 | 在共价化合物形成的反应里，多数情况不是整个电子"传走"，而是共用电子对偏向一方；化合价的升降反映的是这种偏移 |
| 迷思订正 | "化合价升高是因为得到了电子"（升高对应失去电子、被氧化）（子类型 HC08） |
| 纯净版检验问题 | "钠在氯气中燃烧，谁失去电子、谁得到电子？失去和得到的电子数是什么关系？" |

### 3.3 物质的量

| 栏目 | 内容 |
|---|---|
| 类比 | "一打"是 12 个，"一箱"是固定数目的瓶子——把很多个体打包成一个单位来计数 |
| 失效边界 | ① 1 mol 的粒子数约为 6.02×10²³（阿伏加德罗常数），大得无法和生活中的"打""箱"相比；② 只用于原子、分子、离子等微观粒子，并且要指明是哪种粒子（1 mol H 与 1 mol H₂ 不同） |
| 迷思订正 | "1 mol 就是 1 g"；"物质的量就是物质的质量"（子类型 HQ06） |
| 纯净版检验问题 | "1 mol 水和 1 mol 氧气，所含分子数相同吗？质量相同吗？" |
