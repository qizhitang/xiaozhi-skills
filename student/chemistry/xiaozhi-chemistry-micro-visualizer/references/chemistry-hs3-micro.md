## 一、化学反应原理（选择性必修 1）

### 1.1 焓变的键能解释

| 栏目 | 内容 |
|---|---|
| 现象 | 课标选择性必修 1 情境素材「氢气与氧气反应生成液态水或气态水的能量变化」（课本数据）：1 mol H₂ 与 ½ mol O₂ 反应生成液态水，放出 285.8 kJ 热量；生成水蒸气，只放出 241.8 kJ |
| 类比（给出模型之后） | 焓变像体系"能量账户"余额的变化：拆开反应物中的化学键，体系从外界吸收能量，像往账户里存钱；形成生成物中的化学键，体系向外界放出能量，像从账户里取钱；取出的多于存入的，余额减少——体系的焓减少，反应放热，ΔH 为负。用键能估算：ΔH = 反应物的键能总和 − 生成物的键能总和，如 H₂(g) + Cl₂(g) = 2HCl(g)，ΔH = 436 + 243 − 2 × 431 = −183 kJ/mol |
| 失效边界 | ① 用总能量（焓）算是"生成物 − 反应物"，用键能算是"反应物 − 生成物"，两个减法方向相反；② 一般来说，键能越大，化学键越牢固，含这种键的物质越稳定、本身的能量越低；③ 焓变与物质的聚集状态有关：生成液态水比生成水蒸气多放出 44.0 kJ，正是水蒸气液化放出的热量；④ 用平均键能算出的是估算值，课本给出的焓变数据来自实验测定 |
| 迷思订正 | 用键能算 ΔH 时写成"生成物键能总和 − 反应物键能总和"（子类型 HQ08）；"键能越大，物质具有的能量越高"（键能越大越稳定，能量越低）（子类型 HM10） |
| 纯净版检验问题 | "同样是 1 mol 氢气燃烧，生成液态水和生成水蒸气，哪个放热多？多出来的热量从哪里来？" |

{"claim": "1.1：H₂(g) + Cl₂(g) = 2HCl(g) 的 ΔH = 436 + 243 − 2 × 431 = −183 kJ/mol，减反了会得到 +183；生成液态水比生成水蒸气多放出 285.8 − 241.8 = 44.0 kJ", "expr": "[436 + 243 - 2 * 431, 2 * 431 - (436 + 243), Math.round((285.8 - 241.8) * 10) / 10]", "expect": [-183, 183, 44]}

### 1.2 平衡的动态本质

| 栏目 | 内容 |
|---|---|
| 现象 | 教材中的同位素示踪资料：2SO₂ + O₂ ⇌ 2SO₃（条件：催化剂、△）达到平衡后，向体系中充入由 ¹⁸O 组成的氧气，一段时间后，SO₂、O₂、SO₃ 中都含有 ¹⁸O |
| 类比（给出模型之后） | 平衡像一个进出人数相等的商场：每分钟进 100 人、出 100 人，商场里的总人数不变，里面的人却一直在换——正反应把 ¹⁸O 带进 SO₃，逆反应又把它带回 SO₂ |
| 失效边界 | ① 平衡常数 K 表征反应的限度：K 越大，正反应进行得越完全；一个确定的反应，K 只随温度变化；② 写 K 的表达式时，固体和纯液体不写进去：C(s) + H₂O(g) ⇌ CO(g) + H₂(g) 的 K = c(CO)·c(H₂)/c(H₂O)；③ 用浓度商 Q 与 K 比较判断方向：Q < K 正向进行，Q = K 处于平衡，Q > K 逆向进行（课标选择性必修 1 内容要求「了解浓度商和化学平衡常数的相对大小与反应方向间的联系」） |
| 迷思订正 | "达到平衡后，正、逆反应都停止了"（子类型 HC13）；把固体 C 或纯液体写进 K 的表达式（子类型 HQ09） |
| 纯净版检验问题 | "如果平衡时反应真的'停止'了，充入 ¹⁸O₂ 后 ¹⁸O 会出现在哪些物质里？实际观察到的结果说明了什么？" |

### 1.3 条件改变与平衡移动

| 栏目 | 内容 |
|---|---|
| 现象 | 学生必做实验「探究影响化学平衡移动的因素」：FeCl₃ 与 KSCN 的混合溶液呈红色，再加入少量 FeCl₃ 浓溶液或 KSCN 浓溶液，红色加深；老师预先封装好的 NO₂ 与 N₂O₄ 平衡球（学生不打开），放进热水中颜色变深，放进冰水中颜色变浅 |
| 类比（给出模型之后） | 平衡被打破后，体系向"减弱这种改变"的方向移动，像用手按压一根弹簧：手往下压（外界施加改变），弹簧往上顶（平衡向减弱这种改变的方向移动），但只要手还压着，弹簧就回不到原来的长度——只能减弱，不能完全抵消：加进去的 SCN⁻ 被消耗掉一部分，新平衡时 c(SCN⁻) 仍比原来大 |
| 失效边界 | ① 催化剂同等程度地加快正、逆反应，平衡不移动；② 反应前后气体分子数相等的反应（如 H₂(g) + I₂(g) ⇌ 2HI(g)），改变压强平衡不移动——压缩体积后颜色加深，是 I₂ 的浓度变大了，不是平衡移动了；③ 加入不参加反应的离子（如向 Fe³⁺ + 3SCN⁻ ⇌ Fe(SCN)₃ 的体系中加入 KCl 固体），平衡不移动；④ 只有温度改变 K |
| 迷思订正 | "加催化剂，平衡正向移动"；"压缩 H₂ + I₂ ⇌ 2HI 的容器，颜色变深，说明平衡逆向移动"；"'减弱这种改变'就是把改变完全抵消"（子类型 HC16） |

### 1.4 弱电解质的电离平衡

| 栏目 | 内容 |
|---|---|

| 类比（给出模型之后） | 醋酸分子在水中大多保持分子状态，只有少数电离成 CH₃COO⁻ 和 H⁺，而且电离和离子重新结合同时在进行——像一群牵着手的人，每时每刻都有少数人松手、也有少数人重新牵手，松手的总是只占一小部分 |

### 1.5 水的电离

| 栏目 | 内容 |
|---|---|
| 现象 | 课本资料：用精密仪器测定，纯水有极微弱的导电性 |
| 类比（给出模型之后） | 水分子之间偶尔"递过去"一个 H⁺：H₂O + H₂O ⇌ H₃O⁺ + OH⁻（常简写为 H₂O ⇌ H⁺ + OH⁻）。每时每刻只有极少数水分子处在电离状态，就像一座城市里任何时候只有极少数人在搬家 |
| 失效边界 | ① 25 ℃ 时 Kw = c(H⁺)·c(OH⁻) = 1.0×10⁻¹⁴，任何水溶液里 H⁺ 和 OH⁻ 同时存在；② 溶液的酸碱性看 c(H⁺) 与 c(OH⁻) 的相对大小，pH = 7 为中性只适用于 25 ℃：Kw 随温度升高而增大，若某温度下 Kw = 1×10⁻¹²（习题常用的设定），中性溶液的 pH = 6；③ 酸、碱抑制水的电离：25 ℃ 时 0.01 mol/L 盐酸中，由水电离出的 c(H⁺) = c(OH⁻) = 1×10⁻¹² mol/L；④ 强酸溶液无限稀释，pH 只会接近 7，不会超过 7 |
| 迷思订正 | "pH = 5 的盐酸稀释 1000 倍，pH = 8"（酸溶液稀释后仍呈酸性，pH 接近 7）（子类型 HQ10）；"酸溶液里没有 OH⁻"（任何水溶液里都有，只是 c(OH⁻) 很小） |
| 纯净版检验问题 | "25 ℃ 时 0.01 mol/L NaOH 溶液中，c(H⁺) 是多少？这些 H⁺ 是从哪里来的？" |

### 1.6 盐类水解

| 栏目 | 内容 |
|---|---|
| 现象 | 课标选择性必修 1 情境素材「不同盐溶液的酸碱性」（课堂上用 pH 试纸测）：NaCl 溶液 pH = 7，CH₃COONa、Na₂CO₃ 溶液 pH > 7，NH₄Cl 溶液 pH < 7；学生必做实验「盐类水解的应用」：加热 FeCl₃ 溶液，颜色变深；热的纯碱溶液去油污的效果比冷的好 |

### 1.7 沉淀溶解平衡

| 栏目 | 内容 |
|---|---|
| 现象 | 课标选择性必修 1 学习活动「沉淀的转化」与情境素材「氯化银与碘化银、硫化锌与硫化银、氢氧化镁与氢氧化铁沉淀的转化」（课堂实验）：向 NaCl 溶液中滴加少量 AgNO₃ 溶液，得到白色沉淀；再滴加 KI 溶液，白色沉淀逐渐变成黄色 |
