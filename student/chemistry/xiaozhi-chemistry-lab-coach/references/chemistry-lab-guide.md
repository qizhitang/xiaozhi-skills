## 一、实验操作考试的五个评分维度（通用）

多地把化学实验操作考试计入中考总分，考查清单、评分细则与分值以本地当年的考试说明为准。各地细则大多落在这五个维度上：

| 维度 | 看什么 | 常见扣分 |
|---|---|---|
| ① 仪器与药品检查 | 仪器是否齐全完好；药品标签是否与要求一致 | 拿错药品；不检查气密性 |
| ② 规范操作 | 药品取用、加热、连接仪器是否规范 | 用手接触药品；瓶塞正放在桌上；试管口对着人 |
| ③ 观察与记录 | 现象描述准确、完整 | 现象里写生成物名称；漏写颜色变化 |
| ④ 结论 | 结论与现象对应、表述规范 | 结论超出现象能支持的范围 |
| ⑤ 整理 | 废液倒入指定容器，洗涤仪器，熄灭酒精灯 | 废液倒进水槽；酒精灯未熄灭 |

备考方法：学生按顺序口述完整步骤 → 对照五个维度逐项追问"为什么" → 用"如果不这样做会怎样"追问扣分点。

## 二、常见气体的制取、检验与验满

| 气体 | 药品 | 发生装置 | 收集方法 | 检验 | 验满 |
|---|---|---|---|---|---|
| 氧气 | 过氧化氢溶液与二氧化锰（二氧化锰作催化剂） | 固液常温型 | 排水法；向上排空气法 | 带火星的木条伸入瓶内，木条复燃 | 带火星的木条放在瓶口，木条复燃 |
| 氧气 | 高锰酸钾（试管口放一团棉花） | 固体加热型 | 同上 | 同上 | 同上 |
| 二氧化碳 | 大理石或石灰石与稀盐酸 | 固液常温型 | 向上排空气法（二氧化碳能溶于水，一般不用排水法） | 通入澄清石灰水，石灰水变浑浊 | 燃着的木条放在瓶口，木条熄灭 |

**为什么这样选药品**

- 制二氧化碳**不用稀硫酸**：生成的硫酸钙微溶于水，覆盖在大理石表面，阻止反应继续进行。
- 制二氧化碳**不用浓盐酸**：浓盐酸易挥发，使制得的气体中混有氯化氢。
- 制二氧化碳**不用碳酸钠粉末**：反应太快，不便控制和收集。
- 加热高锰酸钾时**试管口放一团棉花**：防止加热时试管内的粉末进入导管。
- 使用长颈漏斗时**下端要伸入液面以下**：形成液封，防止生成的气体从漏斗逸出。

## 三、初中 8 个学生必做实验

### 1. 粗盐中难溶性杂质的去除（safetyLevel：中）

- **步骤**：溶解 → 过滤 → 蒸发 → 计算产率。
- **玻璃棒的作用**：溶解时搅拌，加速溶解；过滤时引流；蒸发时搅拌，防止局部温度过高造成液滴飞溅。
- **过滤"一贴二低三靠"**：滤纸紧贴漏斗内壁；滤纸边缘低于漏斗边缘，液面低于滤纸边缘；盛液烧杯紧靠玻璃棒，玻璃棒下端轻靠三层滤纸一边，漏斗下端管口紧靠烧杯内壁。
- **蒸发**：蒸发皿中出现较多固体时停止加热，利用余热蒸干。
- **易错**：滤液仍浑浊的原因（滤纸破损、液面高于滤纸边缘、仪器不干净）；产率偏低的原因（溶解不充分、蒸发时液滴飞溅、转移固体时有损失）。

### 2. 氧气的实验室制取与性质（safetyLevel：中）

- **制取**：见第二节；排水法收集时，导管口有连续、均匀的气泡冒出再开始收集；结束时先把导管移出水面，再熄灭酒精灯。
- **性质**：木炭在氧气中燃烧，发出白光、放出热量，生成使澄清石灰水变浑浊的气体；铁丝在氧气中剧烈燃烧、火星四射、放出大量的热、生成黑色固体（集气瓶底预先放少量水或铺一层细沙，防止高温熔融物溅落使瓶底炸裂）。
- **说明**：硫在氧气中燃烧发出明亮的蓝紫色火焰，生成有刺激性气味的二氧化硫（有毒），多由老师演示并在通风处进行，瓶中预先放少量水吸收二氧化硫。

### 3. 二氧化碳的实验室制取与性质（safetyLevel：中）

- **制取**：见第二节。
- **性质**：向放有高低两支燃着蜡烛的烧杯中倾倒二氧化碳，下层蜡烛先熄灭 → 密度比空气大，不能燃烧也不支持燃烧；通入紫色石蕊溶液，溶液变红 → 二氧化碳与水反应生成碳酸，是碳酸使石蕊变红（加热后碳酸分解，溶液又变回紫色）；通入澄清石灰水，石灰水变浑浊。
- **易错**："二氧化碳使紫色石蕊变红"（应为二氧化碳与水反应生成的碳酸使其变红）。

### 4. 常见金属的物理性质和化学性质（safetyLevel：中）

- **物理性质**：观察颜色和光泽；用电池、导线和小灯泡检验导电性；导热性、延展性。
- **与氧气反应**：镁条在空气中燃烧，发出耀眼的白光（不要直视），生成白色固体；铜片在空气中加热，表面变黑（生成氧化铜）。
- **与稀酸反应**：镁、锌、铁分别与稀盐酸反应，比较产生气泡的快慢；铜不反应。铁与稀盐酸反应生成氯化亚铁，溶液呈浅绿色。
- **与金属化合物溶液反应**：铁丝放入硫酸铜溶液，表面覆盖红色物质，溶液由蓝色逐渐变为浅绿色；铜丝放入硝酸银溶液，表面覆盖银白色物质，溶液由无色逐渐变为蓝色。
- **结论**：由此排出金属活动性顺序的一部分；金属与化合物溶液的反应在溶液中进行。

### 5. 常见酸、碱的化学性质（safetyLevel：中，全程戴护目镜）

- **与指示剂**：紫色石蕊溶液遇酸变红、遇碱变蓝；无色酚酞溶液遇酸不变色、遇碱变红。
- **酸的性质**：与活泼金属反应产生氢气；与金属氧化物反应（生锈的铁钉放入稀盐酸中，铁锈逐渐消失，溶液由无色变为黄色）；与碱发生中和反应；与某些盐反应（碳酸钠与稀盐酸反应产生气泡）。
- **碱的性质**：与指示剂；与某些非金属氧化物反应；与酸反应；与某些盐反应（硫酸铜溶液与氢氧化钠溶液反应，生成蓝色沉淀）。
- **无明显现象的反应怎么证明**：氢氧化钠溶液与稀盐酸反应无明显现象——先向氢氧化钠溶液中滴入酚酞使其变红，再逐滴加入稀盐酸，红色恰好褪去时说明二者恰好反应；二氧化碳与氢氧化钠溶液反应无明显现象——设计与等体积水作对照的实验，或向反应后的溶液中加稀盐酸看是否产生气泡。
- **安全**：酸或碱溅到皮肤或眼睛上，立即用大量流动的水冲洗并报告老师。

### 6. 一定溶质质量分数的氯化钠溶液的配制（safetyLevel：低）

- **步骤**：计算 → 称量（托盘天平，左物右码）→ 量取（量筒，视线与凹液面最低处保持水平）→ 溶解（玻璃棒搅拌）→ 装瓶贴标签。
- **计算举例**：配制 50 g 质量分数为 6% 的氯化钠溶液，需氯化钠 50 g × 6% = 3 g，水 47 g（水的密度按 1 g/mL，量取 47 mL）。
- **误差分析**：量水时仰视读数 → 实际量取的水偏多 → 质量分数偏小；俯视 → 偏大；称量时物码放反且使用了游码 → 实际称得的氯化钠偏少 → 偏小；配好后装瓶时洒出少量 → 质量分数不变（溶液是均一的）。

### 7. 水的组成及变化的探究（safetyLevel：中）

- **电解水**：水中加入少量硫酸钠或氢氧化钠以增强导电性；正极产生氧气，负极产生氢气，氧气与氢气的体积比约为 1 : 2。
- **检验**：正极气体使带火星的木条复燃；负极气体（少量、验纯后）点燃，产生淡蓝色火焰。
- **结论**：水由氢元素和氧元素组成。
- **易错**："水由氢气和氧气组成"（水是纯净物，由氢、氧两种元素组成）。

### 8. 燃烧条件的探究（safetyLevel：白磷的取用与切割为高，由老师操作或用封闭装置演示）

- **对比设计**：铜片上的白磷燃烧、红磷不燃烧 → 温度需要达到着火点（白磷的着火点约 40 ℃，红磷约 240 ℃）；铜片上的白磷燃烧、热水中的白磷不燃烧 → 需要与氧气接触；向热水中的白磷通入氧气，白磷燃烧 → 印证上一条。
- **结论**：燃烧需要可燃物、与氧气（或空气）接触、温度达到可燃物的着火点，三个条件同时具备。
- **灭火原理**：清除或隔离可燃物；隔绝氧气（或空气）；使温度降到着火点以下。
- **易错**："降低着火点来灭火"（着火点是物质本身的性质，一般不能改变）。
- **安全**：白磷有毒、在空气中易自燃，学生不直接接触白磷。

## 四、高中必修起点的两个必做实验（高一衔接段）

### 4.1 配制一定物质的量浓度的溶液

- **仪器**：与所配体积相同规格的容量瓶（使用前检查是否漏水）、天平、烧杯、玻璃棒、胶头滴管。
- **步骤**：计算 → 称量 → 溶解（在烧杯中溶解，冷却至室温）→ 转移（玻璃棒引流）→ 洗涤（洗涤烧杯和玻璃棒 2～3 次，洗涤液一并转入容量瓶）→ 定容（加水至离刻度线 1～2 cm 时，改用胶头滴管滴加至凹液面最低处与刻度线相切）→ 摇匀 → 装瓶贴标签。
- **误差分析**（依据 c = n / V）：未洗涤烧杯和玻璃棒 → n 偏小 → c 偏小；未冷却就定容 → 冷却后 V 偏小 → c 偏大；定容时仰视刻度线 → V 偏大 → c 偏小；俯视 → c 偏大；摇匀后液面低于刻度线又加水 → V 偏大 → c 偏小。
- **与初中的衔接**：初中配制的是"一定溶质质量分数"的溶液，看的是质量；这里看的是物质的量与溶液体积，定容这一步决定成败。

### 4.2 用化学沉淀法去除粗盐中的杂质离子

- **目标**：去除粗盐溶液中可溶的 Ca²⁺、Mg²⁺、SO₄²⁻。
- **试剂与顺序**：加过量 BaCl₂ 溶液（除 SO₄²⁻）、过量 NaOH 溶液（除 Mg²⁺）、过量 Na₂CO₃ 溶液（除 Ca²⁺ 和过量的 Ba²⁺）→ 过滤 → 向滤液中加适量稀盐酸（除去过量的 OH⁻ 和 CO₃²⁻）→ 蒸发结晶。
- **顺序的两个关键**：Na₂CO₃ 溶液必须在 BaCl₂ 溶液之后加，才能把过量的 Ba²⁺ 除掉；稀盐酸必须在过滤之后加，否则 Mg(OH)₂、CaCO₃、BaCO₃ 沉淀会重新溶解。
- **与初中的衔接**：初中只去除难溶性杂质（溶解、过滤、蒸发），这里用化学反应把可溶的杂质离子变成沉淀或气体，正好用上"除杂不引入新杂质"的原则。
