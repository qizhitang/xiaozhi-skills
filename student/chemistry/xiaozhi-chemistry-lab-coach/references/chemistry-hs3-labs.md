## 一、高中·选必实验 1：简单的电镀实验（safetyLevel：中）

**器材与安全**：学生电源、带鳄鱼夹的导线、烧杯、铜片、铁钉（或铁片）、砂纸、镊子；CuSO₄ 溶液（电镀液）、NaOH 溶液（除油）、稀硫酸（除锈），都由老师配好分装。学生电源的插头由老师插拔，学生只在低压直流输出端接线、操作开关和旋钮；接好线请老师检查后再通电，改接导线前先断电。NaOH 溶液、稀硫酸有腐蚀性，戴护目镜，铁钉用镊子夹取；含铜离子的废液倒进指定容器。

**操作（步骤与原因）**
1. 铁钉用砂纸打磨 → 放入 NaOH 溶液中除油 → 水洗 → 放入稀硫酸中除锈 → 水洗——除去油污和铁锈，镀层才附着牢固、均匀；除锈后立即电镀，免得又生锈。
2. 铁钉接电源负极（作阴极），铜片接电源正极（作阳极），两者平行浸入 CuSO₄ 溶液、互不接触——镀件作阴极，镀层金属作阳极，含镀层金属离子的溶液作电镀液。
3. 铁钉放入电镀液后尽快通电，调到较低的电压，几分钟后断电，取出铁钉水洗——铁能直接从 CuSO₄ 溶液中置换出铜，置换出的铜疏松、附着不牢；电流过大时，镀层也会粗糙、发黑、不牢固。

**现象与结论**

| 现象 | 结论 |
|---|---|
| 铁钉表面逐渐覆盖一层红色物质 | 阴极：Cu²⁺ + 2e⁻ = Cu |
| 通电较久后铜片变薄 | 阳极：Cu − 2e⁻ = Cu²⁺ |
| 电镀液的蓝色基本不变 | 阳极溶解的铜与阴极析出的铜相当，c(Cu²⁺) 基本不变 |

**常见错误**
- 镀件接电源正极、铜片接负极——铁钉被溶解，镀不上铜（子类型 HE11）。
- 用 NaCl 或 ZnSO₄ 溶液作镀铜的电镀液（不含镀层金属的离子）（子类型 HE11）。
- 把电镀池的阳极说成"负极"（子类型 HC18）。
- 把阴极反应写成 Cu − 2e⁻ = Cu²⁺，阴、阳极写反（子类型 HS12）。

## 二、高中·选必实验 2：制作简单的燃料电池（safetyLevel：中）

**器材与安全**：U 形管、两根石墨棒、学生电源、导线、开关、电流表（灵敏电流计）；稀 Na₂SO₄ 溶液。学生电源的插头由老师插拔，学生只在低压直流输出端接线、操作开关和旋钮。电解产生的 H₂ 是可燃性气体：只电解很短时间、产生少量，远离明火，不收集、不点燃；实验台上不点酒精灯。戴护目镜；老师改用稀硫酸或 NaOH 溶液作电解质时，按腐蚀性溶液处理。

**操作（步骤与原因）**
1. U 形管中加入 Na₂SO₄ 溶液，两边各插一根石墨棒——Na₂SO₄ 增强导电性，本身不在电极上反应；石墨导电、性质稳定，多孔的表面能吸附气体。
2. 两根石墨棒分别接学生电源的正、负极，用低压直流电解 1～2 min——在两极上生成少量 H₂ 和 O₂。
3. 断开电源，把两根石墨棒改接电流表——吸附着 H₂、O₂ 的两根石墨棒构成氢氧燃料电池；先断电源，否则测到的是学生电源的电流。改用小灯泡或发光二极管时，电流太小可能不亮，以电流表为准。
4. 对照：换两根没有电解过的石墨棒，直接接电流表，指针不偏转——说明电流来自 H₂ 与 O₂ 的反应。

**现象与结论**

| 步骤 | 现象 | 结论 |
|---|---|---|
| 2 | 两根石墨棒表面都有气泡，接负极的一根气泡较多 | 阴极 2H₂O + 2e⁻ = H₂↑ + 2OH⁻，阳极 2H₂O − 4e⁻ = O₂↑ + 4H⁺ |
| 3 | 电流表指针偏转，一段时间后偏转逐渐变小 | 原来生成 H₂ 的一极是负极，生成 O₂ 的一极是正极；总反应 2H₂ + O₂ = 2H₂O |

氢氧燃料电池的电极反应随电解质而变：酸性时负极 H₂ − 2e⁻ = 2H⁺、正极 O₂ + 4H⁺ + 4e⁻ = 2H₂O；碱性时负极 H₂ + 2OH⁻ − 2e⁻ = 2H₂O、正极 O₂ + 2H₂O + 4e⁻ = 4OH⁻。

**数据与验算**

```verify
{"claim": "电解时每转移 4 个电子，阴极生成 2 个 H₂、阳极生成 1 个 O₂，V(H₂)∶V(O₂) ≈ 2∶1；燃料电池放电时 2H₂ + O₂ = 2H₂O 也按这个比例消耗", "expr": "[4 / 2, 4 / 4]", "expect": [2, 1]}
```

**常见错误**
- 把电解时的阴极（生成 H₂ 的一极）当成燃料电池的正极（子类型 HC18）。
- 碱性电解质中把负极反应写成 H₂ − 2e⁻ = 2H⁺（子类型 HS12）。
- 不断开电源就接电流表（子类型 HE11）。
- 想"验证"一下而点燃生成的氢气，或把装置靠近火焰（子类型 HE06）。

## 三、高中·选必实验 3：探究影响化学平衡移动的因素（safetyLevel：中）

**器材与安全**：试管、胶头滴管、盛热水和冰水的烧杯；稀的 FeCl₃ 溶液与 KSCN 溶液、少量较浓的 FeCl₃ 溶液与 KSCN 溶液、铁粉、NaOH 溶液；老师预先封装好的 NO₂—N₂O₄ 平衡球；K₂Cr₂O₇ 溶液（老师配制）、稀硫酸。NO₂ 有毒：只用老师预先封装的平衡球，学生不打开，只放进热水或冰水、不用火直接加热，玻璃球轻拿轻放，破损时立即远离并报告老师；压强对平衡的影响（注射器中的 NO₂ 与 N₂O₄）由老师演示或看视频，学生不接触 NO₂。K₂Cr₂O₇ 溶液有毒：由老师配制，学生少量取用、戴手套，废液交老师回收。所用的 NaOH 溶液和硫酸由老师分装，浓度较大的由老师滴加。热水防烫，酸、碱溶液戴护目镜。

**操作（步骤与原因）**
1. 浓度：稀的 FeCl₃ 溶液与 KSCN 溶液混合，得到浅红色溶液，分装到 4 支试管：① 不加（对照）；② 滴几滴较浓的 FeCl₃ 溶液；③ 滴几滴较浓的 KSCN 溶液；④ 加少量铁粉（或滴几滴 NaOH 溶液）——原溶液用稀的，颜色浅，加深或变浅都看得清；只滴几滴较浓的溶液，体积几乎不变，避免稀释的干扰；铁粉把 Fe³⁺ 还原、NaOH 使 Fe³⁺ 沉淀，都减小 c(Fe³⁺)。
2. 温度：平衡球的两个球分别浸入热水和冰水——2NO₂（红棕色）⇌ N₂O₄（无色），正反应放热。
3. K₂Cr₂O₇ 溶液中滴几滴 NaOH 溶液，再逐滴加入稀硫酸至过量——Cr₂O₇²⁻（橙色）+ H₂O ⇌ 2CrO₄²⁻（黄色）+ 2H⁺，改变的是 c(H⁺)。

**现象与结论**

| 步骤 | 现象（与对照比较） | 结论 |
|---|---|---|
| 1 ②③ | 红色加深 | 增大反应物浓度，平衡正向移动 |
| 1 ④ | 红色变浅（加 NaOH 溶液的还生成红褐色沉淀） | 减小反应物浓度，平衡逆向移动 |
| 2 | 热水中的球颜色变深，冰水中的变浅 | 升高温度，平衡向吸热方向（生成 NO₂ 的方向）移动；降低温度，向放热方向移动 |
| 3 | 橙色变为黄色，加稀硫酸后又变为橙色 | 减小 c(H⁺) 平衡正向移动，增大 c(H⁺) 平衡逆向移动 |

平衡移动原理：改变影响平衡的一个因素，平衡就向能够减弱这种改变的方向移动——"减弱"不是"抵消"。催化剂同等程度地改变正、逆反应速率，平衡不移动。

**数据与验算**（浓度商 Q 与平衡常数 K）：Fe³⁺ + 3SCN⁻ ⇌ Fe(SCN)₃，K = c[Fe(SCN)₃] / [c(Fe³⁺)·c³(SCN⁻)]。

```verify
{"claim": "只把 c(Fe³⁺) 加倍：Q = K/2 < K，平衡正向移动；整体加水稀释到 2 倍体积，各浓度都减半：Q = (1/2)/[(1/2)×(1/2)³]·K = 8K > K，平衡逆向移动", "expr": "[1 / 2, (1 / 2) / ((1 / 2) * Math.pow(1 / 2, 3))]", "expect": [0.5, 8]}
```

**常见错误**
- "加催化剂，平衡正向移动"；把"减弱这种改变"理解成"抵消这种改变"（子类型 HC16）。
- 向这个平衡体系中加 KCl 固体，以为平衡会移动（K⁺、Cl⁻ 不参与这个平衡）（子类型 HC16）。
- 不留对照就说"颜色变深了"；滴加的溶液太稀、加得太多，颜色变化被稀释掩盖（子类型 HE09）。
- 把 H₂O 写进 Cr₂O₇²⁻ 平衡的 K 表达式（稀溶液中作溶剂的水不写入）（子类型 HQ09）。

## 四、高中·选必实验 4：强酸与强碱的中和滴定（safetyLevel：中）

**器材与安全**：酸式滴定管、碱式滴定管（或聚四氟乙烯活塞的滴定管，酸、碱都能装）、滴定管夹、铁架台、锥形瓶、烧杯；0.1000 mol/L 标准盐酸（老师配制并标定）、待测 NaOH 溶液（0.1 mol/L 左右）、酚酞溶液或甲基橙溶液。两种溶液都在 0.1 mol/L 左右，仍有腐蚀性，戴护目镜；滴定管是细长的玻璃器皿，装液时从滴定管夹上取下操作，轻拿轻放，破损时报告老师，不徒手收拾碎玻璃。

**操作（步骤与原因）**
1. 查漏——活塞处漏液，读出的体积就不准。
2. 蒸馏水洗净后，用待装的溶液润洗 2～3 次（酸式滴定管用标准盐酸，碱式滴定管用待测 NaOH 溶液）——否则管壁残留的水会稀释溶液。
3. 装液，排出尖嘴部分的气泡，调液面到 0 或 0 以下某一刻度，记下初读数（读到 0.01 mL）——尖嘴有气泡，读出的体积会偏大。
4. 从碱式滴定管放出 20.00 mL NaOH 溶液到锥形瓶，滴 2～3 滴酚酞溶液——锥形瓶**不**用待测液润洗；瓶里原有少量蒸馏水不影响结果，因为 n(NaOH) 已由滴定管量定。强酸与强碱的滴定可用酚酞或甲基橙，不用石蕊（颜色变化不明显）。
5. 左手控制活塞，右手摇动锥形瓶，眼睛注视锥形瓶中溶液颜色的变化；接近终点时一滴一滴、最后半滴地加——盯着锥形瓶，才能及时发现变色。
6. 滴入最后半滴，溶液由浅红色变为无色，且半分钟内不恢复红色，记下终读数——半分钟内又变红，说明还没到终点。
7. 重复 2～3 次取平均值，与其他几次相差明显的数据舍去——减小偶然误差。

**现象与结论**：滴入酚酞后待测液变红（显碱性）；滴到终点，溶液由浅红色变为无色、半分钟内不恢复——n(HCl) = n(NaOH)，恰好完全中和。

**数据处理**（示意数据，V(NaOH) = 20.00 mL）

| 次 | 初读数/mL | 终读数/mL | V(盐酸)/mL |
|---|---|---|---|
| 1 | 0.50 | 20.62 | 20.12 |
| 2 | 1.20 | 21.28 | 20.08 |
| 3 | 0.30 | 21.80 | 21.50（与前两次相差明显，舍去） |

c(NaOH) = c(HCl)·V(HCl) / V(NaOH) = 0.1000 × 20.10 / 20.00 = 0.1005 mol/L。

```verify
{"claim": "三次消耗盐酸 20.12、20.08、21.50 mL，第 3 次舍去；平均 20.10 mL，c(NaOH) = 0.1000 × 20.10 / 20.00 = 0.1005 mol/L", "expr": "[Math.round((20.62 - 0.50) * 100) / 100, Math.round((21.28 - 1.20) * 100) / 100, Math.round((21.80 - 0.30) * 100) / 100, Math.round((20.12 + 20.08) / 2 * 100) / 100, Math.round(0.1000 * 20.10 / 20.00 * 10000) / 10000]", "expect": [20.12, 20.08, 21.5, 20.1, 0.1005]}
```

**为什么终点变色那么突然**（溶液 pH 的简单计算）：用 0.1000 mol/L 盐酸滴定 20.00 mL 0.1000 mol/L NaOH 溶液，加到 19.98 mL（差 0.02 mL，约半滴）时 pH ≈ 9.7，加到 20.02 mL（多半滴）时 pH ≈ 4.3——相差约一滴，pH 突变 5 个多单位，酚酞（变色范围 8.2～10.0）与甲基橙（3.1～4.4）都在这个突变范围内变色。

```verify
{"claim": "25 ℃，加到 19.98 mL 时 c(OH⁻) = 0.1000 × 0.02 / 39.98 ≈ 5.0×10⁻⁵ mol/L，pH ≈ 9.7；加到 20.02 mL 时 c(H⁺) = 0.1000 × 0.02 / 40.02 ≈ 5.0×10⁻⁵ mol/L，pH ≈ 4.3", "expr": "[Math.round((14 + Math.log10(0.1000 * 0.02 / 39.98)) * 10) / 10, Math.round(-Math.log10(0.1000 * 0.02 / 40.02) * 10) / 10]", "expect": [9.7, 4.3]}
```

**误差分析**：依据 c(NaOH) = c(HCl)·V(HCl) / V(NaOH)，看每个操作让 V(HCl) 怎样变。滴定管的 0 刻度在上方、越往下读数越大，俯视时读数偏小——与量筒（刻度由下往上增大，俯视读数偏大）正好相反。

| 操作 | V(HCl) | c(NaOH) |
|---|---|---|

## 五、高中·选必实验 5：盐类水解的应用（safetyLevel：中）

**器材与安全**：试管、试管夹、小烧杯、陶土网、酒精灯、玻璃棒、表面皿、pH 试纸、激光笔（可选）、盛热水的烧杯；饱和 FeCl₃ 溶液（老师配制）、FeCl₃ 稀溶液、稀盐酸、Na₂CO₃ 溶液、NH₄Cl 溶液、NaCl 溶液、蒸馏水、内壁沾有少量植物油的试管。酒精灯加热试管、烧杯按规范，加热的液体不超过试管容积的三分之一；沸水、热的纯碱溶液防烫、防溅，热的试管用试管夹拿，管口不对着人；FeCl₃ 溶液有腐蚀性、会染色；激光笔不对着人眼；戴护目镜。

**操作（步骤与原因）**
1. 用洁净、干燥的玻璃棒分别蘸取 Na₂CO₃、NH₄Cl、NaCl 溶液，点在 pH 试纸上，与标准比色卡对照——试纸不伸进溶液（会污染试剂），不先用水润湿（会稀释待测液）。
2. 三支试管各加少量 FeCl₃ 稀溶液：① 不处理（对照）；② 加热；③ 滴几滴稀盐酸——看温度与 c(H⁺) 对 Fe³⁺ 水解的影响。
3. 小烧杯中的蒸馏水加热至沸腾，逐滴加入 5～6 滴饱和 FeCl₃ 溶液，继续煮沸至液体呈红褐色，停止加热；用激光笔从侧面照射——沸水促进 Fe³⁺ 水解；不能用 NaOH 溶液（得到的是沉淀），也不能长时间加热（胶体会聚沉）。
4. 两支沾有植物油的试管各加入等体积的 Na₂CO₃ 溶液，一支放进热水中，一支留在室温，几分钟后把溶液倒进指定容器，用水冲洗，比较管壁上残留的油——只改变温度一个条件。

**现象与结论**

| 1 | 与比色卡对照：Na₂CO₃ 溶液的 pH 约为 11，NH₄Cl 溶液约为 5，NaCl 溶液约为 7 | 强碱弱酸盐的溶液显碱性，强酸弱碱盐的显酸性，强酸强碱盐的显中性 |
| 2 | 加热的一支颜色加深，滴稀盐酸的一支颜色变浅 | Fe³⁺ + 3H₂O ⇌ Fe(OH)₃ + 3H⁺：水解吸热，升温促进水解；增大 c(H⁺) 抑制水解（配制 FeCl₃ 溶液时加少量盐酸就是这个道理） |
| 3 | 得到红褐色的透明液体；激光笔照射时，从侧面看到一条光亮的"通路" | FeCl₃ + 3H₂O ==△== Fe(OH)₃（胶体）+ 3HCl |

## 六、高中·选必实验 6：简单配合物的制备（safetyLevel：中）

**器材与安全**：试管、胶头滴管、玻璃棒；CuSO₄ 溶液、氨水（老师分装）、95% 乙醇、FeCl₃ 溶液、KSCN 溶液、NaCl 溶液、AgNO₃ 溶液。浓氨水有强烈的刺激性气味，由老师分装（浓氨水只由老师取用），学生在通风处取用分装好的氨水，闻气味用扇闻法；加乙醇析出晶体时远离明火（本实验不点酒精灯）；AgNO₃ 溶液沾到皮肤会变黑，立即冲洗；含 [Ag(NH₃)₂]⁺ 的溶液现配现用，用后立即按老师要求处理，不存放（久置可能生成易爆物）；含铜、银的废液倒进指定容器。

**操作（步骤与原因）**
1. CuSO₄ 溶液中逐滴加入氨水，边加边振荡，先看沉淀的生成，再继续滴加至沉淀恰好溶解——逐滴加，才能看清两步变化。
2. 向得到的深蓝色溶液中沿试管壁慢慢加入乙醇，静置——乙醇的极性比水小，配合物在其中的溶解度小，因而析出。
3. FeCl₃ 溶液中滴 KSCN 溶液——选必实验 3 里的红色物质也是配合物。
4. NaCl 溶液中滴几滴 AgNO₃ 溶液，再逐滴加氨水并振荡——难溶的 AgCl 能否溶于氨水；做完立即按老师要求处理。

**现象与结论**

| 步骤 | 现象 | 结论 |
|---|---|---|
| 1 | 先生成蓝色沉淀；继续滴加，沉淀溶解，得到深蓝色透明溶液 | Cu²⁺ + 2NH₃·H₂O = Cu(OH)₂↓ + 2NH₄⁺；Cu(OH)₂ + 4NH₃ = [Cu(NH₃)₄]²⁺ + 2OH⁻ |
| 2 | 析出深蓝色晶体 | 晶体为 [Cu(NH₃)₄]SO₄·H₂O |
| 3 | 溶液变红 | Fe³⁺ 与 SCN⁻ 形成红色的配合物 |
| 4 | 先生成白色沉淀；滴加氨水后沉淀溶解，得到无色溶液 | AgCl + 2NH₃ = [Ag(NH₃)₂]⁺ + Cl⁻ |

**结构解释**：[Cu(NH₃)₄]²⁺ 中，NH₃ 的 N 原子提供孤电子对，Cu²⁺ 提供空轨道，形成配位键；中心离子 Cu²⁺，配体 NH₃，配位数 4。配位键是一类特殊的共价键；[Cu(NH₃)₄]²⁺ 与外界的 SO₄²⁻ 之间是离子键。配离子的电荷等于中心离子的电荷加各配体的电荷：NH₃ 不带电，所以 [Cu(NH₃)₄]²⁺ 带 2 个单位正电荷。

**常见错误**
- 中心离子、配体、配位数分不清，如说 [Cu(NH₃)₄]²⁺ 的配位数是 1；"配位键不是共价键"（子类型 HM14）。
- 一次倒入大量氨水，看不到先生成沉淀、再溶解的过程。
- 对着试管口直接闻氨气；把用剩的含银氨溶液留到下次再用（子类型 HE06）。

## 七、高中·选必实验 7：乙酸乙酯的制备与性质（safetyLevel：中；浓硫酸的取用为高，只由老师加入）

**器材与安全**：大试管、带长导管的单孔塞、试管、铁架台、酒精灯、碎瓷片、分液漏斗、盛热水的烧杯；乙醇、乙酸（有腐蚀性，老师分装少量）、浓硫酸（由老师加入）、饱和 Na₂CO₃ 溶液、稀硫酸与 NaOH 溶液（老师分装）。**浓硫酸的取用为高，只由老师做**：老师边振荡边把浓硫酸慢慢加入乙醇中，学生不取用浓硫酸。乙醇、乙酸、乙酸乙酯易燃：试剂加完、试剂瓶盖好移开，再点燃酒精灯，点燃的酒精灯旁不倾倒这些液体。加热前加入碎瓷片防暴沸，忘了加要停止加热、冷却后再补加，不往热的液体里加；小火加热，试管口不对着人；导管口在饱和 Na₂CO₃ 溶液液面上方，不伸入液面以下。水解实验用热水浴（热水由老师准备，或用恒温水浴锅，插头由老师插拔），不在火焰旁直接加热乙酸乙酯。

**操作（步骤与原因）**
1. 大试管中加入 3 mL 乙醇；老师边振荡边慢慢加入 2 mL 浓硫酸；冷却后加入 2 mL 乙酸，再加几片碎瓷片——浓硫酸密度大、与乙醇混合时放热，加到乙醇中并振荡散热，防止液体飞溅（与稀释浓硫酸时"酸入水"同理）；冷却后再加乙酸，减少乙酸挥发。
2. 连好装置，导管口对准另一支试管中饱和 Na₂CO₃ 溶液的液面上方——防止倒吸。
3. 小火加热，产生的蒸气经长导管通到饱和 Na₂CO₃ 溶液的液面上——小火可减少乙醇、乙酸的挥发和副反应；长导管兼起冷凝作用。
4. 停止加热（用灯帽盖灭酒精灯），取下盛饱和 Na₂CO₃ 溶液的试管，振荡、静置，用扇闻法闻气味。
5. 用分液漏斗分离：下层液体从下口放出，上层液体从上口倒出——互不相溶的两层液体，这样分离才不互相混入。
6. 性质：三支试管各加几滴乙酸乙酯，分别加入等体积的蒸馏水、稀硫酸、NaOH 溶液，振荡后放进同一个热水浴，比较酯层（香味）消失的快慢——只改变溶液的酸碱性。

**现象与结论**

| 步骤 | 现象 | 结论 |
|---|---|---|
| 3、4 | 饱和 Na₂CO₃ 溶液的液面上出现一层无色透明的油状液体，有香味；振荡时有气泡产生；静置后分为两层，油状液体在上层 | CH₃COOH + CH₃CH₂OH ⇌ CH₃COOCH₂CH₃ + H₂O（条件：浓硫酸、△）；乙酸乙酯难溶于水、密度比水小；气泡是挥发出的乙酸与 Na₂CO₃ 反应生成的 CO₂ |
| 6 | 加 NaOH 溶液的酯层消失最快，加稀硫酸的次之，加蒸馏水的几乎不变 | 酯在酸或碱存在时水解；碱性条件下生成的乙酸被中和，水解趋于完全 |

浓硫酸的作用：催化剂、吸水剂。饱和 Na₂CO₃ 溶液的作用：中和乙酸、溶解乙醇、降低乙酸乙酯的溶解度，便于分层。用含 ¹⁸O 的乙醇做实验，¹⁸O 出现在乙酸乙酯中——酯化时酸脱羟基、醇脱氢。乙醇过量，可使平衡正向移动，提高乙酸的转化率。

**常见错误**
- 检验碳碳双键前没排除醛基的干扰；卤代烃水解后没加稀硝酸酸化就滴 AgNO₃ 溶液（子类型 HE12）。
- "乙醇能与 NaOH 溶液反应"（醇羟基不能，酚羟基能）；银镜反应振荡试管或用酒精灯直接加热；配制新制 Cu(OH)₂ 时 CuSO₄ 过量（子类型 HC22）。
- 把卤代烃与 NaOH 醇溶液共热也当成水解（那是消去反应）（子类型 HC23）。

## 九、高中·选必实验 9：糖类的性质（safetyLevel：中）

**器材与安全**：试管、试管夹、胶头滴管、酒精灯、盛热水的烧杯；葡萄糖溶液、蔗糖溶液、淀粉溶液、稀硫酸、NaOH 溶液、CuSO₄ 溶液、碘水、pH 试纸。水浴或酒精灯加热按规范，热水浴防烫；稀硫酸、NaOH 溶液有腐蚀性，戴护目镜；做银镜反应时，银氨溶液同第六节的规矩。

**操作（步骤与原因）**
1. 新制 Cu(OH)₂（NaOH 溶液过量）中加葡萄糖溶液，加热——葡萄糖分子中有醛基。
2. 蔗糖：① 蔗糖溶液直接加新制 Cu(OH)₂，加热（对照）；② 蔗糖溶液加几滴稀硫酸，热水浴加热几分钟，冷却后滴 NaOH 溶液至溶液呈碱性（用 pH 试纸检验），再加新制 Cu(OH)₂ 加热——稀硫酸是催化剂；先中和，是因为新制 Cu(OH)₂ 要在碱性条件下检验醛基，酸会把它溶解。
3. 淀粉：淀粉溶液加稀硫酸，加热一段时间，冷却后分成两份：一份直接滴碘水；另一份先加 NaOH 溶液中和至碱性，再加新制 Cu(OH)₂ 加热——碘水检验淀粉有没有剩余，要加在没有中和的那份里（碘会与碱反应）；新制 Cu(OH)₂ 检验葡萄糖。

**现象与结论**

| 步骤 | 现象 | 结论 |
|---|---|---|
| 1 | 生成砖红色沉淀 | 葡萄糖有还原性，Cu(OH)₂ 被还原为 Cu₂O |
| 2 ① | 没有砖红色沉淀 | 蔗糖本身不是还原糖 |
| 2 ② | 生成砖红色沉淀 | C₁₂H₂₂O₁₁（蔗糖）+ H₂O → C₆H₁₂O₆（葡萄糖）+ C₆H₁₂O₆（果糖）（条件：稀硫酸、△），生成了还原糖 |

淀粉的水解：(C₆H₁₀O₅)ₙ + nH₂O → nC₆H₁₂O₆（条件：稀硫酸、△）。水解程度的判断：

| 滴碘水 | 中和后加新制 Cu(OH)₂ 加热 | 结论 |
|---|---|---|
| 变蓝 | 没有砖红色沉淀 | 淀粉没有水解 |
| 变蓝 | 生成砖红色沉淀 | 部分水解 |
| 不变蓝 | 生成砖红色沉淀 | 完全水解 |

**常见错误**
- 蔗糖或淀粉的水解液没有先加 NaOH 溶液中和，就加新制 Cu(OH)₂；把碘水加进已中和成碱性的溶液里，看不到蓝色（子类型 HE12）。
- 新制 Cu(OH)₂ 检验葡萄糖时不加热，或配制时 CuSO₄ 过量（子类型 HC22）。
- 只看到砖红色沉淀，就说"淀粉已完全水解"——还要用碘水检验是否有淀粉剩余。
