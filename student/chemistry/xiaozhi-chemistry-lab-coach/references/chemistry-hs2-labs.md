## 一、高中·必修实验 2：铁及其化合物的性质（safetyLevel：中）

**器材与安全**：试管、胶头滴管（另备一支长胶头滴管）；铁粉、铜片，FeCl₃ 溶液、新制的 FeSO₄ 溶液（瓶中放少量铁粉）、KSCN 溶液、KI 溶液、淀粉溶液、NaOH 溶液、3% 过氧化氢溶液、酸性 KMnO₄ 溶液（老师配好分装）。NaOH 溶液有腐蚀性，戴护目镜；把 Fe²⁺ 氧化成 Fe³⁺ 优先用 3% 过氧化氢溶液，老师改用氯水时只取少量、在通风处操作。

**操作（步骤与原因）**
1. FeCl₃ 溶液中滴 1～2 滴 KSCN 溶液——认识检验 Fe³⁺ 的特征反应。
2. 另取 FeCl₃ 溶液，加过量铁粉振荡，静置后取上层清液，滴 KSCN 溶液——铁能把 Fe³⁺ 还原；取清液，是为了不让剩下的铁粉干扰下一步。
3. 向第 2 步的清液中滴几滴 3% 过氧化氢溶液——把 Fe²⁺ 氧化成 Fe³⁺。第 2、3 步连起来就是检验 Fe²⁺ 的顺序：先加 KSCN 溶液不变红，再加氧化剂变红。
4. FeCl₃ 溶液中放一小块铜片；另取 FeCl₃ 溶液，加 KI 溶液和淀粉溶液——看 Fe³⁺ 的氧化性（前者是印刷电路板的原理）。
5. FeSO₄ 溶液中滴酸性 KMnO₄ 溶液——看 Fe²⁺ 的还原性。用 FeSO₄ 而不用 FeCl₂，是因为 Cl⁻ 也能使酸性 KMnO₄ 溶液褪色，会干扰判断。
6. FeCl₃ 溶液中滴 NaOH 溶液。
7. 用长胶头滴管吸取 NaOH 溶液（老师预先煮沸除去了溶解的氧气），伸到新制 FeSO₄ 溶液的液面以下再挤出——Fe(OH)₂ 极易被空气氧化，伸到液面下是为了隔绝空气。平时"胶头滴管不伸入试管"，这里是有理由的例外。

**现象与结论**

| 步骤 | 现象 | 结论 |
|---|---|---|
| 1 | 溶液变红 | 溶液中有 Fe³⁺ |
| 2 | 溶液由棕黄色变为浅绿色；清液滴 KSCN 溶液不变红 | 2Fe³⁺ + Fe = 3Fe²⁺ |
| 3 | 溶液变红 | 2Fe²⁺ + H₂O₂ + 2H⁺ = 2Fe³⁺ + 2H₂O |
| 4 | 溶液由棕黄色逐渐变为蓝绿色，铜片慢慢溶解（时间长了明显变薄）；加 KI 溶液和淀粉溶液的一支变蓝 | 2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺；2Fe³⁺ + 2I⁻ = 2Fe²⁺ + I₂ |
| 5 | 紫红色褪去 | Fe²⁺ 被氧化，有还原性 |
| 6 | 生成红褐色沉淀 | Fe³⁺ + 3OH⁻ = Fe(OH)₃↓ |
| 7 | 生成白色絮状沉淀，接触空气后迅速变成灰绿色，最后变成红褐色 | Fe²⁺ + 2OH⁻ = Fe(OH)₂↓；4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃ |

**数据与验算**

```verify
{"claim": "2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺：两边电荷都是 +6；2 个 Fe³⁺ 共得 2 个电子，Cu 失 2 个电子。漏写 Fe³⁺、Fe²⁺ 前的 2，左边 +3、右边 +4，电荷不守恒", "expr": "[2 * 3, 2 * 2 + 2, 2 * (3 - 2), 2 - 0, 3, 2 + 2]", "expect": [6, 6, 2, 2, 3, 4]}
```

**常见错误**
- 制 Fe(OH)₂ 时滴管在液面上方滴加，或用放置已久的 FeSO₄ 溶液——沉淀一出现就是灰绿色，看不到白色（子类型 HE08）。
- 检验 Fe²⁺ 时先加氧化剂再加 KSCN 溶液，变红也分不清是原来就有 Fe³⁺ 还是刚氧化出来的（子类型 HC11）。
- "铁与盐酸反应生成 FeCl₃"（生成的是 FeCl₂）（子类型 HC11）。
- 离子方程式写成 Fe³⁺ + Cu = Fe²⁺ + Cu²⁺，电荷不守恒（子类型 HS07）。
- 现象栏写"生成了 Fe(OH)₃"——应写"生成红褐色沉淀"（子类型 HE03）。

## 二、高中·必修实验 3：不同价态含硫物质的转化（safetyLevel：学生的稀溶液微型实验为中；铜与浓硫酸反应、硫粉与铁粉加热为高，由老师在通风处演示）

**器材与安全**：试管、胶头滴管、镊子、浸有 NaOH 溶液的棉团；Na₂S 溶液、Na₂SO₃ 溶液、稀硫酸、酸性 KMnO₄ 溶液（都是老师分装的稀溶液）。
- 学生只做稀溶液的微型实验：每种溶液取少量；稀硫酸逐滴加、不过量——酸多了，Na₂S 会放出有毒的 H₂S，Na₂SO₃ 会放出 SO₂。在通风处做，试管口塞浸有 NaOH 溶液的棉团吸收逸出的气体（棉团用镊子取放）。
- 需要闻气味时用扇闻法（用手在试管口轻轻扇动，让极少量气体飘进鼻孔），不把鼻子凑到试管口。
- 铜与浓硫酸的反应要用浓硫酸，还会放出有毒的 SO₂；硫粉与铁粉加热剧烈放热，硫还可能燃烧放出 SO₂。这两个为高，由老师在通风处演示，学生保持距离观察，不取用浓硫酸。

**操作（步骤与原因）**
1. Na₂SO₃ 溶液中滴酸性 KMnO₄ 溶液，振荡——看 +4 价的硫能否被氧化到 +6 价。
2. Na₂SO₃ 溶液中滴加少量 Na₂S 溶液，振荡后逐滴加稀硫酸——酸性条件下，−2 价与 +4 价的硫反应生成 0 价的硫（同种元素的两种价态向中间价态转化）。
3. （老师演示）铜片与浓硫酸共热，产生的气体通入品红溶液，尾气用 NaOH 溶液吸收；再把褪色的品红溶液加热——看 +6 价的硫能否被还原到 +4 价，并认识 SO₂ 的漂白作用。
4. （老师演示）硫粉与铁粉混匀，在陶土网上用灼热的玻璃棒引发反应——看 0 价的硫能否被还原到 −2 价。

**现象与结论**

| 步骤 | 现象 | 结论 |
|---|---|---|
| 1 | 紫红色褪去 | 5SO₃²⁻ + 2MnO₄⁻ + 6H⁺ = 5SO₄²⁻ + 2Mn²⁺ + 3H₂O，+4 → +6 |
| 2 | 出现淡黄色浑浊 | 2S²⁻ + SO₃²⁻ + 6H⁺ = 3S↓ + 3H₂O，−2 与 +4 → 0 |
| 3 | 铜片表面有气泡，品红溶液褪色，加热后恢复红色；老师把反应后的液体冷却、慢慢倒入水中，溶液呈蓝色 | Cu + 2H₂SO₄(浓) ==△== CuSO₄ + SO₂↑ + 2H₂O，+6 → +4；SO₂ 的漂白作用可逆 |
| 4 | 混合物红热，移开玻璃棒后红热继续向前蔓延，最后得到黑色固体 | Fe + S ==△== FeS，0 → −2；反应放热 |

```text
硫元素的价态转化（升价要加氧化剂，降价要加还原剂）
  −2            0        +4                  +6
  H₂S、Na₂S  ⇄  S  ⇄  SO₂、Na₂SO₃  ⇄  H₂SO₄、Na₂SO₄
```

**数据与验算**（得失电子守恒）

```verify
{"claim": "2S²⁻ + SO₃²⁻ + 6H⁺ = 3S↓ + 3H₂O：2 个 S²⁻ 共失 4 个电子，1 个 SO₃²⁻ 得 4 个电子；左边电荷 2×(−2) + (−2) + 6 = 0，与右边相同", "expr": "[2 * (0 - (-2)), 1 * (4 - 0), 2 * (-2) + (-2) + 6]", "expect": [4, 4, 0]}
```

```verify
{"claim": "5SO₃²⁻ + 2MnO₄⁻ + 6H⁺ = 5SO₄²⁻ + 2Mn²⁺ + 3H₂O：S 共失 5×2 = 10 个电子，Mn 共得 2×5 = 10 个电子；两边电荷都是 −6", "expr": "[5 * (6 - 4), 2 * (7 - 2), 5 * (-2) + 2 * (-1) + 6, 5 * (-2) + 2 * 2]", "expect": [10, 10, -6, -6]}
```

**常见错误**
- 不塞浸有 NaOH 溶液的棉团、不在通风处做，让气体逸出（子类型 HE08）。
- 把 SO₂ 使品红溶液褪色与氯水使品红溶液褪色当成一回事：前者加热后恢复红色，后者不恢复（子类型 HC12）。
- "铜与浓硫酸反应放出氢气"（放出的是 SO₂，是 +6 价的硫被还原）（子类型 HC12）。
- 配平氧化还原离子方程式时只凑原子个数，不按得失电子守恒列式（子类型 HS04；写成离子方程式后电荷不守恒记 HS07）。
- 为了"看得更明显"多加稀硫酸，或把鼻子凑到试管口闻气味（子类型 HE06）。

## 三、高中·必修实验 5：同周期、同主族元素性质的递变（safetyLevel：中；钾与水的反应为高，只看老师演示或视频）

**器材与安全**：小烧杯、试管、胶头滴管、镊子、滤纸、酒精灯、试管夹；钠（老师切取）、镁条、酚酞溶液、MgCl₂ 溶液、AlCl₃ 溶液、NaOH 溶液、稀盐酸、新制氯水、溴水（老师分装）、NaBr 溶液、KI 溶液、淀粉溶液。
- 钠由老师切取；学生用镊子取绿豆大小的一块，用滤纸吸干表面的煤油，不用手接触（钠会与皮肤上的水分反应）；剩余的钠交老师放回，不扔进水槽或废液缸。钠与水反应时眼睛不凑到烧杯口正上方。
- 氯水、溴水只取少量，在通风处操作；溴水沾到皮肤立即用大量水冲洗并报告老师。
- 加热镁条与水按试管加热的规范：外壁擦干、先预热，试管口不对着人，液体不超过试管容积的三分之一。
- 钾与水的反应比钠剧烈得多，可能起火、飞溅，为高：教材安排时只看老师演示或视频，学生不取用钾。

**操作（步骤与原因）**
1. 小烧杯中加水、滴几滴酚酞溶液，放入钠——比较金属与水反应的难易；酚酞变红说明生成了碱。
2. 试管中加少量水、滴酚酞溶液，放入用砂纸打磨过的镁条，先观察，再加热——打磨是为了除去表面的氧化膜。
3. MgCl₂ 溶液、AlCl₃ 溶液中分别逐滴加 NaOH 溶液，至生成白色沉淀；每支的沉淀分成两份，一份加稀盐酸，一份继续加 NaOH 溶液——比较两种氢氧化物的碱性。逐滴加，才能看到 AlCl₃ 溶液中先生成、后溶解的过程。
4. NaBr 溶液中滴少量氯水；KI 溶液中滴少量氯水，再滴淀粉溶液——比较 Cl₂ 与 Br₂、I₂ 的氧化性。氯水要少量：过量的氯水会把生成的 I₂ 继续氧化，蓝色变浅。
5. KI 溶液中滴少量溴水，再滴淀粉溶液——有了这一组，才能比较 Br₂ 与 I₂。

**现象与结论**

| 步骤 | 现象 | 结论 |
|---|---|---|
| 1 | 钠浮在水面上，熔成闪亮的小球，四处游动，发出"嘶嘶"声，溶液变红 | 2Na + 2H₂O = 2NaOH + H₂↑，钠与冷水剧烈反应 |
| 2 | 冷水中几乎没有明显现象；加热后镁条表面有气泡，溶液变为浅红色 | Mg + 2H₂O ==△== Mg(OH)₂ + H₂↑，镁与冷水几乎不反应 |
| 3 | 两支都生成白色沉淀；加稀盐酸都溶解；加过量 NaOH 溶液，Mg(OH)₂ 不溶，Al(OH)₃ 溶解 | 碱性 Mg(OH)₂ > Al(OH)₃，Al(OH)₃ 是两性氢氧化物 |
| 4 | NaBr 溶液变为橙黄色；KI 溶液变为棕黄色，加淀粉溶液后变蓝 | Cl₂ + 2Br⁻ = 2Cl⁻ + Br₂；Cl₂ + 2I⁻ = 2Cl⁻ + I₂ |
| 5 | 溶液变为棕黄色，加淀粉溶液后变蓝 | Br₂ + 2I⁻ = 2Br⁻ + I₂ |

**归纳**
- 同周期（Na → Mg → Al）：与水反应越来越难，最高价氧化物对应水化物的碱性 NaOH > Mg(OH)₂ > Al(OH)₃，金属性减弱；教材给出的 Si、P、S、Cl 最高价含氧酸的酸性依次增强，非金属性增强。原因：电子层数相同，核电荷数增大、原子半径减小，原子核对最外层电子的吸引增强，失电子能力减弱、得电子能力增强。
- 同主族（Cl → Br → I）：单质的氧化性 Cl₂ > Br₂ > I₂，非金属性减弱。原因：最外层电子数相同，电子层数增多、原子半径增大，得电子能力减弱。

**常见错误**
- 只会说"钠比镁活泼"，说不出结构原因；或把同主族从上到下说成原子半径减小（子类型 HM08）。
- 用失去电子的多少判断金属性（铝失 3 个电子、钠失 1 个，却是钠更活泼）——金属性看失电子的难易（子类型 HM08）。
- 只做氯水与 NaBr、氯水与 KI 两组，就排出 Cl > Br > I——缺少溴与碘的比较（子类型 HE05）。
- 用手拿钠，或把剩余的钠扔进水槽、废液缸（子类型 HE06）。

## 四、高中·必修实验 6：化学反应速率的影响因素（safetyLevel：中）

**器材与安全**：锥形瓶、量筒、秒表、画有"+"字的白纸、试管、盛冷水与热水的烧杯；Na₂S₂O₃ 溶液与稀硫酸（老师配好，如都是 0.1 mol/L）、稀的过氧化氢溶液、MnO₂ 粉末、大理石块与大理石粉末、稀盐酸。稀酸、过氧化氢溶液有腐蚀性，戴护目镜；Na₂S₂O₃ 与稀硫酸反应会放出少量 SO₂，在通风处做，反应后的液体倒进指定容器；热水浴由老师准备，从热水中取放容器时防烫；用接 220 V 的恒温水浴锅时，插头由老师插拔。

**操作（步骤与原因）**

浓度与温度：按下表在锥形瓶中混合，锥形瓶下垫画有"+"字的白纸，从混合开始计时，记下从上方看不见"+"字所用的时间。

| 组 | Na₂S₂O₃ 溶液 | 水 | 稀硫酸 | 温度 | 与 ① 相比改变的量 |
|---|---|---|---|---|---|
| ① | 6 mL | 0 | 6 mL | 室温 | —（对照） |
| ② | 3 mL | 3 mL | 6 mL | 室温 | Na₂S₂O₃ 的浓度 |
| ③ | 6 mL | 0 | 6 mL | 热水浴 | 温度 |

- ② 补 3 mL 水：让总体积与 ① 相同，稀硫酸的浓度才不变，只改变 Na₂S₂O₃ 的浓度。
- ③ 两种溶液先分别在热水浴中放一会儿再混合：混合时的温度就是要比较的温度。
- 催化剂：两支试管各加 2 mL 过氧化氢溶液，一支加少量 MnO₂ 粉末，另一支不加——不加的一支是对照。
- 表面积：等质量的大理石块和大理石粉末，分别加入等体积、同浓度的稀盐酸——只改变固体的表面积。

**现象与结论**

| 对比 | 现象 | 结论（其他条件相同时） |
|---|---|---|
| ① 与 ② | ① 中"+"字先看不见（先出现淡黄色浑浊） | 反应物浓度越大，反应越快 |
| ① 与 ③ | ③ 中"+"字先看不见 | 温度越高，反应越快 |
| 加与不加 MnO₂ | 加 MnO₂ 的迅速产生大量气泡，不加的只有少量气泡 | 催化剂能加快反应 |
| 块状与粉末 | 粉末产生气泡更快 | 固体的表面积越大，反应越快 |

反应：Na₂S₂O₃ + H₂SO₄ = Na₂SO₄ + S↓ + SO₂↑ + H₂O；2H₂O₂ ==MnO₂== 2H₂O + O₂↑。

**数据处理**（示意数据：① 42 s，② 95 s，③ 11 s）：用时越短，反应越快。课标对必修只要求比较快慢，速率的简单计算在选择性必修 1（所用教材在必修已给出 v = Δc/Δt 的，按教材讲；这组数据只记了时间，比较快慢就够）。

**常见错误**
- 探究浓度时不补水，使总体积不同、另一种反应物的浓度也变了；探究温度时先混合再放进热水浴（子类型 HE09）。

## 五、高中·必修实验 7：化学能转化成电能（safetyLevel：中；用水果、盐水做电池时为低）

**器材与安全**：锌片、铜片、烧杯、稀硫酸、带鳄鱼夹的导线、电流表（灵敏电流计；一个电池的电压和电流都很小，一般点不亮小灯泡）；作对照用的另一片锌片、蔗糖溶液。稀硫酸有腐蚀性，戴护目镜；金属片边缘可能割手。电池只靠自身产生的低电压工作，**不接 220 V**，也不接学生电源；用接 220 V 的电流传感器或数据采集器时，插头由老师插拔。改用柠檬等水果或食盐水作电解质时没有腐蚀性试剂，为低，同样在课上由老师组织。

**操作（步骤与原因）**
1. 锌片、铜片分别插入稀硫酸，互不接触、不连导线——先看各自的现象，作为对照。
2. 用导线把锌片、铜片与电流表连成闭合回路（两片仍在稀硫酸中、互不接触）。
3. 对照：换成两片锌片；把稀硫酸换成蔗糖溶液；断开导线——逐一找出原电池的构成条件。
4. 把锌片、铜片插入柠檬或食盐水中，接电流表——电解质溶液可以换成别的。

**现象与结论**

| 步骤 | 现象 | 结论 |
|---|---|---|
| 1 | 锌片表面有气泡，铜片没有明显现象 | 锌能与稀硫酸反应，铜不能 |
| 2 | 电流表指针偏转；铜片表面有大量气泡，锌片逐渐溶解 | 产生了电流，化学能转化成电能 |
| 3 | 三种情况电流表指针都不偏转 | 需要活泼性不同的两个电极、电解质溶液和闭合回路 |
| 4 | 电流表指针偏转 | 水果汁、食盐水也能充当电解质溶液 |

**工作原理**（从氧化还原的角度）：锌比铜活泼，锌失去电子变成 Zn²⁺ 进入溶液（发生氧化反应，锌是负极）；电子经导线流向铜片；溶液中的 H⁺ 在铜片表面得到电子生成 H₂（发生还原反应，铜是正极）。总反应 Zn + 2H⁺ = Zn²⁺ + H₂↑。电子不进入溶液，溶液中靠离子移动导电：阳离子移向正极，阴离子移向负极。原电池的构成：两个电极（活泼性不同的金属，或金属与石墨等导体）、电解质溶液、闭合回路，以及能自发进行的氧化还原反应。不同介质的电极反应式与电解池在选择性必修 1。

**常见错误**
- 两片都用锌、或没有接成闭合回路，也判断为原电池（子类型 HC14）。
- 把电子流向说成"从铜片经导线流向锌片"，或说"电子通过溶液流回锌片"（子类型 HC14）。
- 看到铜片表面有气泡，就认为铜与稀硫酸反应了（气泡是 H⁺ 在铜片上得电子产生的）（子类型 HC14）。
- 现象栏写"铜片上生成了氢气"——应写"铜片表面有大量气泡"（子类型 HE03）。

## 六、高中·必修实验 8：搭建球棍模型认识有机化合物分子结构的特点（safetyLevel：低）

**器材与安全**：球棍模型一套（代表碳原子的球有 4 个孔；双键、三键用可弯曲的棍，以所用模型的说明为准）。不用化学试剂，常温操作。

**操作（步骤与原因）**
1. 搭甲烷 CH₄：碳原子连 4 个氢原子，4 根棍尽量均匀地分开——看碳原子形成 4 个共价键时的空间取向。
2. 在甲烷模型上把两个氢换成另一种颜色的球（代表氯），搭 CH₂Cl₂，试着搭出两种不同的结构——用来判断甲烷是平面正方形还是正四面体。
3. 搭乙烷 C₂H₆，转动碳碳单键——看单键能不能旋转。
4. 搭乙烯 C₂H₄（碳碳双键）、乙炔 C₂H₂（碳碳三键）——比较不同的碳碳键与分子形状。
5. 用 4 个碳搭出所有不同的 C₄H₁₀，再用 5 个碳搭 C₅H₁₂——判断两个模型是否相同，看能否通过转动单键、整体翻转而完全重合。

**观察与结论**

| 模型 | 看到的空间结构 | 结论 |
|---|---|---|
| CH₄、CH₂Cl₂ | CH₄ 为正四面体，键角约 109°28′；CH₂Cl₂ 是四面体（不是正四面体），怎样搭都只有一种 | 甲烷是正四面体，不是平面正方形（平面正方形的 CH₂Cl₂ 会有两种） |
| C₂H₆ | 碳碳单键可以旋转 | 每个碳原子仍形成 4 个共价键 |
| C₂H₄ | 平面形，键角约 120° | 6 个原子在同一平面，双键不能自由旋转 |
| C₂H₂ | 直线形，键角 180° | 4 个原子在同一直线上 |
| C₄H₁₀、C₅H₁₂ | 分别只能搭出 2 种、3 种不同的结构 | 正丁烷与异丁烷；正戊烷、异戊烷与新戊烷，互为同分异构体 |

苯分子是平面正六边形，12 个原子在同一平面，6 个碳碳键完全相同（介于单键和双键之间）——用单、双键交替的模型搭出来的只是近似。

**数据与验算**

```verify
{"claim": "烷烃通式 CₙH₂ₙ₊₂：丁烷 C₄H₁₀、戊烷 C₅H₁₂；C₄H₁₀ 的共价键总数 = (4×4 + 10×1)/2 = 13，正好是 3 个 C—C 加 10 个 C—H，模型上没有空着的孔", "expr": "[2 * 4 + 2, 2 * 5 + 2, (4 * 4 + 10 * 1) / 2, 3 + 10]", "expect": [10, 12, 13, 13]}
```

**常见错误**
- 把甲烷搭成平面正方形，说不出 CH₂Cl₂ 只有一种结构这个证据。
- 把同一个分子换个摆法、把碳链弯一下，就当成新的同分异构体——判断是否相同，看能否通过转动单键、整体翻转完全重合（子类型 HM15）。
- 把乙烯写成 CH₂CH₂（漏写碳碳双键）（子类型 HS10）。

## 七、高中·必修实验 9：乙醇、乙酸的主要性质（safetyLevel：中）

**器材与安全**：试管、试管架、试管夹、酒精灯、螺旋状铜丝、镊子、滤纸；无水乙醇、钠（老师切取）、乙酸溶液（老师分装）、紫色石蕊溶液、Na₂CO₃ 溶液、酸性重铬酸钾溶液（含浓硫酸，由老师配制与滴加）。
- 乙醇、乙酸易燃，乙酸有腐蚀性和强烈的刺激性气味：先取好少量乙醇、盖好试剂瓶并移开，再点燃酒精灯；点燃的酒精灯旁不放乙醇、乙酸等易燃物。洒出的乙醇着火，用湿抹布盖灭并报告老师。
- 铜丝在酒精灯上加热后先离开火焰，再插入盛少量乙醇的试管；盛乙醇的试管放在试管架上、远离酒精灯。
- 钠的规矩同实验 5（老师切取，镊子取绿豆大小，滤纸吸干煤油，不用手接触，剩余的交老师）。
- 钠与乙醇反应放出可燃的 H₂：这一步在点燃酒精灯之前做完，剩余的钠交回老师后，再点灯做铜丝的实验。
- 酸性重铬酸钾溶液含浓硫酸，配制与滴加都由老师完成，学生只观察颜色变化。闻气味用扇闻法。

**操作（步骤与原因）**
1. 观察乙醇、乙酸的颜色、状态，用扇闻法闻气味。
2. 干燥的试管中加少量无水乙醇，放入钠——与实验 5 中钠与水的反应比较；用干燥试管和无水乙醇，是因为有水时钠会先与水反应，干扰比较。产生的气体点燃检验（先验纯）由老师演示。
3. 铜丝在酒精灯外焰上加热至红热，离开火焰后立即插入乙醇中，反复几次，再用扇闻法闻试管中的气味——看铜丝颜色的变化与气味。
4. （老师滴加）乙醇中加入酸性重铬酸钾溶液——看乙醇能否被强氧化剂氧化。
5. 乙酸溶液中滴紫色石蕊溶液；Na₂CO₃ 溶液中加乙酸溶液——看乙酸的酸性，并与碳酸比较。
6. 有的教材在本实验中还安排乙酸与乙醇的酯化反应：浓硫酸由老师加入，操作要点与安全见 `references/chemistry-hs3-labs.md` 第七节（选择性必修的必做实验「乙酸乙酯的制备与性质」）。

**现象与结论**

| 步骤 | 现象 | 结论 |
|---|---|---|
| 1 | 乙醇是无色透明液体，有特殊香味；乙酸是无色液体，有强烈的刺激性气味 | — |
| 2 | 钠沉在试管底部，表面缓慢产生气泡，比钠与水的反应缓和 | 2CH₃CH₂OH + 2Na → 2CH₃CH₂ONa + H₂↑；羟基中的氢不如水中的氢活泼 |
| 3 | 铜丝在火焰上变黑，插入乙醇后变红；反复几次后闻到刺激性气味 | 2CH₃CH₂OH + O₂ → 2CH₃CHO + 2H₂O（条件：Cu、△），乙醇被氧化为乙醛 |
| 4 | 溶液由橙色变为绿色 | 乙醇被酸性重铬酸钾溶液氧化（检测酒驾的一种原理） |
| 5 | 滴石蕊溶液的一支变红；Na₂CO₃ 溶液中加乙酸溶液后产生气泡 | 2CH₃COOH + Na₂CO₃ → 2CH₃COONa + H₂O + CO₂↑，乙酸的酸性比碳酸强 |
