## 高中·示例 19：盖斯定律——反写要变号，乘系数要同乘（HQ08）

> 25 ℃、101 kPa 时，已知：① C(s，石墨) + O₂(g) = CO₂(g) ΔH₁ = −393.5 kJ/mol；② H₂(g) + ½O₂(g) = H₂O(l) ΔH₂ = −285.8 kJ/mol；③ C₂H₂(g) + 5/2 O₂(g) = 2CO₂(g) + H₂O(l) ΔH₃ = −1299.6 kJ/mol。求 2C(s，石墨) + H₂(g) = C₂H₂(g) 的 ΔH。

- 定物质：目标式中 C(s，石墨) 和 H₂(g) 在左边，C₂H₂(g) 在右边。反应热只与反应体系的始态和终态有关，与途径无关，所以可以用已知的三个反应"拼"出目标反应。
- 三重表征：宏观上石墨和氢气很难直接化合成乙炔，这个反应的反应热无法直接测定；符号上把已知式"搬"成目标式——C 在 ① 左边、需要 2 个，① × 2；H₂ 在 ② 左边，② 照用；C₂H₂ 在 ③ 左边、目标要它在右边，③ 反写。
- 写式列式：目标式 = 2 × ① + ② − ③，ΔH = 2 × (−393.5) + (−285.8) − (−1299.6) = +226.8 kJ/mol。
- 守恒检验：把 2 × ① + ② − ③ 两边相加，2CO₂、H₂O 和 5/2 O₂ 都消去，只剩目标式；ΔH > 0，是吸热反应。

**错解**：③ 反写后 ΔH₃ 不变号，算成 2 × (−393.5) + (−285.8) + (−1299.6) = −2372.4 kJ/mol（HQ08）——连吸热、放热都判断反了。另一种常见错：① 乘 2 而 ΔH₁ 没有乘 2，得 +620.3 kJ/mol。

```verify
{"claim": "示例19：ΔH = 2×(−393.5) + (−285.8) − (−1299.6) = +226.8 kJ/mol，O₂ 两边都是 2 + 1/2 = 5/2；错解 ③ 不变号得 −2372.4 kJ/mol，① 不乘 2 得 +620.3 kJ/mol", "expr": "[Math.round((2 * -393.5 + -285.8 - -1299.6) * 10) / 10, 2 * 1 + 1 / 2, Math.round((2 * -393.5 + -285.8 + -1299.6) * 10) / 10, Math.round((-393.5 + -285.8 - -1299.6) * 10) / 10]", "expect": [226.8, 2.5, -2372.4, 620.3]}
```

## 高中·示例 20：用键能估算合成氨的 ΔH（HQ08）

> 已知键能：N≡N 946 kJ/mol，H—H 436 kJ/mol，N—H 391 kJ/mol。估算 N₂(g) + 3H₂(g) ⇌ 2NH₃(g) 的 ΔH。

- 定物质：反应物中有 1 个 N≡N、3 个 H—H；生成物 2 个 NH₃ 共有 2 × 3 = 6 个 N—H。
- 三重表征：微观上先断开旧键（吸收能量），再形成新键（放出能量）。
- 写式列式：ΔH = 反应物的键能总和 − 生成物的键能总和 = (946 + 3 × 436) − 6 × 391 = 2254 − 2346 = −92 kJ/mol。
- 守恒检验：成键放出的 2346 kJ 多于断键吸收的 2254 kJ，净放热，ΔH 为负，与合成氨是放热反应相符；键能是平均值，所以只是估算。

**错解**：写成"生成物的键能总和 − 反应物的键能总和"，得 +92 kJ/mol（HQ08）——符号反了，把放热反应算成了吸热反应。

追问：在密闭容器中充入 1 mol N₂ 和 3 mol H₂，充分反应后放出的热量是 92 kJ 吗？（小于 92 kJ：可逆反应不能进行到底，ΔH 对应的是按方程式完全反应）

```verify
{"claim": "示例20：断键吸收 946 + 3×436 = 2254 kJ，成键放出 6×391 = 2346 kJ，ΔH = −92 kJ/mol；错解用生成物减反应物得 +92 kJ/mol", "expr": "[946 + 3 * 436, 2 * 3 * 391, 946 + 3 * 436 - 2 * 3 * 391, 2 * 3 * 391 - (946 + 3 * 436)]", "expect": [2254, 2346, -92, 92]}
```

## 高中·示例 21：热化学方程式——状态、符号、计量数（HS11）

> 25 ℃、101 kPa 时，1 g 甲烷完全燃烧生成 CO₂ 和液态水，放出 55.6 kJ 热量。写出表示这一反应的热化学方程式。

- 定物质：反应物 CH₄(g)、O₂(g)，生成物 CO₂(g)、H₂O(l)——题目说水是液态，要标 (l)。
- 三重表征：放热反应，ΔH 为负；ΔH 的数值要与方程式中的化学计量数对应，按 1 mol CH₄ 来写。
- 写式列式：1 mol CH₄ 为 16 g，放热 16 × 55.6 kJ = 889.6 kJ：CH₄(g) + 2O₂(g) = CO₂(g) + 2H₂O(l) ΔH = −889.6 kJ/mol。
- 守恒检验：计量数全部乘 2 时 ΔH 也乘 2：2CH₄(g) + 4O₂(g) = 2CO₂(g) + 4H₂O(l) ΔH = −1779.2 kJ/mol。

**错解**：直接写 ΔH = −55.6 kJ/mol（HS11）——55.6 kJ 是 1 g 甲烷放出的热量，而方程式表示 1 mol（16 g）甲烷反应，差了 16 倍。漏标聚集状态、把 ΔH 写成正值，也属这一类。

追问：若生成的是气态水，放出的热量比 889.6 kJ 多还是少？（少：气态水变成液态水还要放出热量）

```verify
{"claim": "示例21：M(CH₄) = 16 g/mol，放热 16×55.6 = 889.6 kJ，ΔH = −889.6 kJ/mol；计量数乘 2 时 ΔH = −1779.2 kJ/mol；错解 −55.6 kJ/mol 差了 16 倍", "expr": "[12 + 1 * 4, Math.round(16 * 55.6 * 10) / 10, Math.round(2 * 16 * 55.6 * 10) / 10, Math.round(889.6 / 55.6)]", "expect": [16, 889.6, 1779.2, 16]}
```

## 高中·示例 22：三段式求速率、平衡常数与转化率（HQ09）

> 在容积为 2 L 的恒温密闭容器中投入 2 mol SO₂ 和 1 mol O₂，发生 2SO₂(g) + O₂(g) ⇌ 2SO₃(g)。2 min 时 SO₃ 为 1.2 mol，4 min 时达到平衡，SO₃ 为 1.6 mol。求：（1）0～2 min 内 v(SO₂) 与 v(O₂)；（2）该温度下的平衡常数 K 与 SO₂ 的平衡转化率。

这组数据与示例 17（`references/chemistry-hs2-worked-examples.md`）相同：示例 17 只判断是否达到平衡；给出容积后，这里接着算速率、K 与转化率（课标把这两类简单计算放在选择性必修 1；所用教材在必修已讲 v = Δc/Δt 的，速率这一问按教材处理）。

- 定物质：速率和 K 都用浓度，先把物质的量除以容积 2 L。
- 三重表征：用三段式把"起始—转化—平衡"写清（单位 mol/L），转化量之比等于化学计量数之比：

| | 2SO₂(g) | O₂(g) | 2SO₃(g) |
|---|---|---|---|
| 起始 | 1.0 | 0.5 | 0 |
| 转化 | 0.8 | 0.4 | 0.8 |
| 平衡 | 0.2 | 0.1 | 0.8 |

- 写式列式：
  - （1）0～2 min 内 Δc(SO₃) = 1.2 mol ÷ 2 L = 0.6 mol/L，v(SO₂) = v(SO₃) = 0.6 mol/L ÷ 2 min = 0.3 mol/(L·min)，v(O₂) = 0.15 mol/(L·min)。
  - （2）K = c²(SO₃) / [c²(SO₂)·c(O₂)] = 0.8² / (0.2² × 0.1) = 160；SO₂ 的平衡转化率 = 0.8 / 1.0 × 100% = 80%。
- 守恒检验：v(SO₂) ∶ v(O₂) ∶ v(SO₃) = 0.3 ∶ 0.15 ∶ 0.3 = 2 ∶ 1 ∶ 2，等于化学计量数之比。

**错解**：用物质的量代替浓度——v 算成 1.2 mol ÷ 2 min = 0.6 mol/(L·min)，K 算成 1.6² / (0.4² × 0.2) = 80（HQ09），分别是正确值的 2 倍和一半。

追问：写出 C(s) + H₂O(g) ⇌ CO(g) + H₂(g) 的平衡常数表达式。（K = c(CO)·c(H₂) / c(H₂O)：固体不写入 K；水溶液中的反应，作溶剂的水也不写入）

## 高中·示例 23：平衡移动——"减弱"不是"抵消"（HC16）

> 一定温度下，密闭容器中存在平衡 2NO₂(g)（红棕色）⇌ N₂O₄(g)（无色） ΔH < 0，平衡时 c(NO₂) = 0.2 mol/L，c(N₂O₄) = 0.4 mol/L。（1）温度不变，把容器容积迅速压缩为原来的一半，平衡向哪个方向移动？达到新平衡时，c(NO₂) 比原平衡大还是小？（2）升高温度，颜色怎样变化？加入催化剂呢？

- 定物质：正反应是气体分子数减少（2 → 1）的放热反应。
- 三重表征：压缩的一瞬间，各物质的浓度都变为原来的 2 倍，颜色立即加深；随后平衡移动，颜色又变浅一些，但比原平衡深。（NO₂ 有毒：压缩的现象看老师演示或视频；温度的影响在课堂上用老师预先封装好的 NO₂ 平衡球观察，学生不打开。）
- 写式列式：
  - （1）K = c(N₂O₄) / c²(NO₂) = 0.4 / 0.2² = 10。压缩瞬间 c(NO₂) = 0.4 mol/L、c(N₂O₄) = 0.8 mol/L，浓度商 Q = 0.8 / 0.4² = 5 < K，平衡正向（气体分子数减少的方向）移动。假如 c(NO₂) 回到 0.2 mol/L，则 c(N₂O₄) = 0.8 + 0.1 = 0.9 mol/L，Q = 0.9 / 0.2² = 22.5 ≠ K，不可能。所以新平衡的 c(NO₂) 介于 0.2 与 0.4 mol/L 之间（解方程约为 0.29 mol/L，不要求），比原平衡大。
  - （2）升温，平衡向吸热方向（逆向）移动，NO₂ 增多，颜色加深；催化剂同等程度地改变正、逆反应速率，平衡不移动，颜色不变。
- 守恒检验：新平衡的 Q 又等于 K = 10；平衡移动原理说的是"减弱这种改变"，不是"抵消"。

**错解**：认为平衡移动把增大的 NO₂ 浓度全部抵消，新平衡 c(NO₂) 回到 0.2 mol/L、颜色和原来一样（HC16）——用 K 一验就不成立。

追问：H₂(g) + I₂(g)（紫色）⇌ 2HI(g)，压缩容积后颜色加深，是平衡移动了吗？（不是：反应前后气体分子数相等，压缩后平衡不移动；颜色加深是因为 I₂ 的浓度变大了）

```verify
{"claim": "示例23：K = 0.4/0.2² = 10；压缩瞬间 Q = 0.8/0.4² = 5 < K，正向移动；错解（c(NO₂) 回到 0.2 mol/L）时 c(N₂O₄) = 0.9 mol/L、Q = 22.5 ≠ K；解 (0.8 + x)/(0.4 − 2x)² = 10 得新平衡 c(NO₂) ≈ 0.29 mol/L，代回 Q = 10", "expr": "[Math.round(0.4 / (0.2 * 0.2)), Math.round(0.8 / (0.4 * 0.4)), Math.round((0.8 + (0.4 - 0.2) / 2) / (0.2 * 0.2) * 10) / 10, Math.round((0.4 - 2 * (17 - Math.sqrt(161)) / 80) * 100) / 100, Math.round((0.8 + (17 - Math.sqrt(161)) / 80) / Math.pow(0.4 - 2 * (17 - Math.sqrt(161)) / 80, 2) * 1000) / 1000]", "expect": [10, 5, 22.5, 0.29, 10]}
```

## 高中·示例 24：强酸、强碱溶液的 pH 与稀释（HQ10）

> 25 ℃ 时：（1）0.005 mol/L 的 H₂SO₄ 溶液和 0.001 mol/L 的 NaOH 溶液，pH 各是多少？（2）pH = 2 的盐酸加水稀释到原体积的 1000 倍，pH 是多少？pH = 5 的盐酸同样稀释 1000 倍呢？

- 定物质：H₂SO₄、HCl、NaOH 都是强电解质，在水中完全电离；pH = −lg c(H⁺)，碱溶液要先由 Kw 求 c(H⁺)。
- 三重表征：H₂SO₄ = 2H⁺ + SO₄²⁻，1 个 H₂SO₄ 电离出 2 个 H⁺；水本身也电离出少量 H⁺ 和 OH⁻。
- 写式列式：
  - （1）c(H⁺) = 2 × 0.005 mol/L = 0.01 mol/L，pH = 2；NaOH 溶液中 c(OH⁻) = 1×10⁻³ mol/L，c(H⁺) = Kw / c(OH⁻) = 1.0×10⁻¹¹ mol/L，pH = 11。
  - （2）pH = 2 的盐酸稀释 1000 倍，c(H⁺) 由 10⁻² 降到 10⁻⁵ mol/L，pH = 5。pH = 5 的盐酸稀释 1000 倍，盐酸提供的 H⁺ 只有 10⁻⁸ mol/L，比水电离出的还少，不能再忽略水的电离：溶液仍呈酸性，pH 接近 7 但小于 7（约 6.98）。
- 守恒检验：酸溶液 pH < 7，碱溶液 pH > 7；酸溶液加水稀释，pH 只会无限接近 7。

**错解**：NaOH 溶液直接按 −lg c(OH⁻) 算出 pH = 3（HQ10）——碱溶液的 pH 小于 7，自相矛盾；pH = 5 的盐酸稀释 1000 倍算成 pH = 8，酸溶液变成了碱性，也属这一类。

```verify
{"claim": "示例24：0.005 mol/L H₂SO₄ 的 c(H⁺) = 0.01 mol/L，pH = 2；0.001 mol/L NaOH 的 c(H⁺) = 1.0×10⁻¹¹ mol/L，pH = 11；pH = 2 的盐酸稀释 1000 倍 pH = 5；pH = 5 的盐酸稀释 1000 倍，由 c(H⁺) = 10⁻⁸ + Kw/c(H⁺) 得 pH ≈ 6.98；错解 pH = 3（碱溶液）与 pH = 8（酸溶液）", "expr": "[Math.round(-Math.log10(2 * 0.005) * 100) / 100, Math.round(-Math.log10(1.0e-14 / 0.001) * 100) / 100, Math.round(-Math.log10(1e-2 / 1000) * 100) / 100, Math.round(-Math.log10((1e-8 + Math.sqrt(1e-16 + 4 * 1.0e-14)) / 2) * 100) / 100, Math.round(-Math.log10(0.001) * 100) / 100, 5 + 3]", "expect": [2, 11, 5, 6.98, 3, 8]}
```

## 高中·示例 25：pH 相同的醋酸和盐酸，稀释后不再相同（HC17）

> 25 ℃ 时，pH 均为 3 的盐酸和醋酸溶液各 10 mL：（1）分别加水稀释到 1000 mL，pH 各约为多少？谁大？（2）稀释前，两者分别与足量锌粉反应，产生的 H₂ 谁多？

- 定物质：HCl 是强电解质，完全电离；CH₃COOH 是弱电解质，部分电离：CH₃COOH ⇌ CH₃COO⁻ + H⁺。
- 三重表征：pH 相同只说明 c(H⁺) 相同；醋酸溶液里还有大量没有电离的 CH₃COOH 分子，加水稀释时电离平衡正向移动，又电离出 H⁺。
- 写式列式：
  - （1）盐酸稀释 100 倍，c(H⁺) 由 10⁻³ 降到 10⁻⁵ mol/L，pH = 5；醋酸边稀释边电离，c(H⁺) 大于 10⁻⁵ mol/L，pH 在 3 与 5 之间（取 Ka(CH₃COOH) = 1.8×10⁻⁵ 估算约为 4.0；用电离常数计算是教材内容，课标未作计算要求）。盐酸的 pH 更大。
  - （2）pH 相同时醋酸的浓度远大于盐酸（按上面的 Ka 估算约为 0.057 mol/L，盐酸是 0.001 mol/L），与足量锌反应，醋酸产生的 H₂ 多。
- 守恒检验：稀释 100 倍，强酸的 pH 增大 2，弱酸的 pH 增大不到 2。

**错解**：认为"pH 相同的醋酸和盐酸稀释相同倍数后 pH 仍相同，都是 5"（HC17），并由此认为两者产生的 H₂ 一样多。

追问：CH₃COONa 溶液和 NH₄Cl 溶液各显什么性？（CH₃COONa 溶液显碱性，NH₄Cl 溶液显酸性——谁弱谁水解，谁强显谁性）

## 高中·示例 26：燃料电池作电源电解饱和食盐水（HS12、HC18）

> 以 KOH 溶液为电解质溶液的氢氧燃料电池作电源，用石墨作电极电解饱和食盐水。（1）写出燃料电池两极的电极反应式。（2）电解池中，与燃料电池负极相连的电极叫什么极？两极各生成什么？（3）燃料电池消耗标准状况下 1.12 L O₂ 时，电解池阳极生成 Cl₂ 多少摩尔？

- 写式列式：

## 高中·示例 27：沉淀的转化与"沉淀完全"（HC19）

> 25 ℃ 时，Ksp(AgCl) = 1.8×10⁻¹⁰，Ksp(AgI) = 8.5×10⁻¹⁷，Ksp[Mg(OH)₂] = 5.6×10⁻¹²（溶度积是教材内容，课标未作计算要求）。（1）向 AgNO₃ 溶液中加入过量 NaCl 溶液，充分反应后 c(Cl⁻) = 0.01 mol/L，此时溶液中 c(Ag⁺) 是零吗？再滴加 KI 溶液，白色沉淀逐渐变成黄色，为什么？（2）Ksp[Mg(OH)₂] 比 Ksp(AgCl) 小，能说明 Mg(OH)₂ 更难溶吗？

- 定物质：AgCl、AgI、Mg(OH)₂ 都是难溶电解质，在水中存在沉淀溶解平衡，如 AgCl(s) ⇌ Ag⁺(aq) + Cl⁻(aq)。
- 三重表征：白色 AgCl 表面始终有少量 Ag⁺ 溶解下来；滴入 I⁻ 后，Ag⁺ 与 I⁻ 结合成更难溶的黄色 AgI，c(Ag⁺) 降低，AgCl 的溶解平衡正向移动，沉淀逐渐转化：AgCl(s) + I⁻(aq) ⇌ AgI(s) + Cl⁻(aq)。
- 写式列式：
  - （1）c(Ag⁺) = Ksp(AgCl) / c(Cl⁻) = 1.8×10⁻¹⁰ ÷ 0.01 = 1.8×10⁻⁸ mol/L，很小，但不是零。若加 KI 使 c(I⁻) 达到 0.01 mol/L，c(Ag⁺)·c(I⁻) = 1.8×10⁻¹⁰，远大于 Ksp(AgI)，生成 AgI。
  - （2）不能。AgCl 是 1 ∶ 1 型，饱和溶液中溶解的量 s = √Ksp ≈ 1.3×10⁻⁵ mol/L；Mg(OH)₂ 是 1 ∶ 2 型，Ksp = s·(2s)² = 4s³，s ≈ 1.1×10⁻⁴ mol/L——Ksp 小的 Mg(OH)₂ 反而更易溶。组成类型相同（如 AgCl 与 AgI）才能直接比较 Ksp。
- 守恒检验：达到溶解平衡时 c(Ag⁺)·c(Cl⁻) = Ksp，离子浓度不会是零；"沉淀完全"通常指离子浓度小于 1×10⁻⁵ mol/L。

**错解**：认为"Cl⁻ 过量，Ag⁺ 已经沉淀完全，浓度为零，加 KI 不会有变化"（HC19）；或认为"Ksp 小的一定更难溶"，得出 Mg(OH)₂ 比 AgCl 难溶——与估算的结论相反。

## 高中·示例 28：核外电子排布与第一电离能的"反常"（HS14、HC20）
