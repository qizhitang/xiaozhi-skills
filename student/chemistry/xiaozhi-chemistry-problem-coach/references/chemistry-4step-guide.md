# 四步化学解题法细则

> 示例题验算：2026-09-23
> 适用学段：初中化学；第五节为高中必修起点。
> 本文件是 `xiaozhi-chemistry-problem-coach` 的参考资源。示例题按 `shared/ai-item-check.md` 验算，关键数值写成 `verify` 断言，由 CI 每次重算。
> 相对原子质量取课本常用值：H 1，C 12，N 14，O 16，Na 23，Cl 35.5，K 39，Ca 40，Mn 55。

---

## 一、四步状态机

| 步骤 | 进入条件 | 追问 | 退出条件 |
|---|---|---|---|
| Step 1 定物质 | 学生发来题目 | "一共有几种物质？各写出化学式、标出类别""有没有'足量''恰好'这样的词？" | 学生能列出全部物质与限定词 |
| Step 2 三重表征 | 物质已定 | "放在一起会看到什么？粒子层面发生了什么？写成方程式" | 学生写出正确的方程式并说出现象 |
| Step 3 写式列式 | 方程式正确 | "要求的量和已知的量，在方程式里是什么关系？" | 列出正确的比例式或守恒式 |
| Step 4 守恒检验 | 得出结果 | "原子守恒吗？溶液质量减去气体和沉淀了吗？结果合理吗？" | 学生自己完成一次检验 |

任何一步卡住，按 `shared/hint-ladder.md` 逐级给提示，不跳步。Step 2 写不出方程式时，先判断是用语问题（转化学用语与方程式教练）还是性质不熟（本 SKILL 用 L2—L3 提示性质）。

---

## 二、按方程式计算的标准格式

```text
设：设未知量（不带单位）
写：写出配平的化学方程式
找：在相关物质下方写出"相对分子质量 × 化学计量数"，再下方写出已知量与未知量
列：列比例式
求：求出未知量
答：简明作答
```

两条最常见的失分：
- 把**混合物**的质量直接代入方程式（应先换算成纯净物的质量）；
- 求反应后溶液质量时，没有减去**逸出的气体**和**生成的沉淀**，或把**不溶性杂质**算了进去。

## 三、推断题题眼清单

**特征颜色**

| 类别 | 颜色 | 物质或离子 |
|---|---|---|
| 溶液 | 蓝色 | 含 Cu²⁺ |
| 溶液 | 浅绿色 | 含 Fe²⁺ |
| 溶液 | 黄色 | 含 Fe³⁺ |
| 溶液 | 紫红色 | 高锰酸钾溶液 |
| 沉淀 | 蓝色 | Cu(OH)₂ |
| 沉淀 | 红褐色 | Fe(OH)₃ |
| 沉淀 | 白色，溶于稀盐酸并放出气体 | CaCO₃、BaCO₃ |
| 沉淀 | 白色，不溶于稀硝酸 | BaSO₄、AgCl |
| 固体 | 黑色 | CuO、Fe₃O₄、MnO₂、木炭粉、铁粉 |
| 固体 | 红色 / 红棕色 | Cu / Fe₂O₃ |

**特征现象与特征反应**

| 现象或反应 | 指向 |
|---|---|
| 使澄清石灰水变浑浊的气体 | CO₂ |
| 使带火星的木条复燃的气体 | O₂ |
| 能使黑色 CuO 变红的物质 | C、CO、H₂ |
| 与碱混合研磨放出有刺激性气味、能使湿润的红色石蕊试纸变蓝的气体 | 铵态氮肥（含 NH₄⁺） |
| 组成元素相同的两种物质 | H₂O 与 H₂O₂；CO 与 CO₂；Fe₂O₃ 与 Fe₃O₄ |

推断完成后，**必须把推出的物质代回原框图逐一检验**，这一步由学生来做。

## 四、初中示例题

### 示例 1：石灰石纯度与反应后溶液（HQ03、HQ05）

> 12.5 g 石灰石样品（杂质不溶于水，也不与盐酸反应）与 100 g 稀盐酸恰好完全反应，生成 4.4 g 二氧化碳。求：（1）样品中碳酸钙的质量分数；（2）反应后所得溶液中溶质的质量分数（结果精确到 0.1%）。

CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑；质量关系 CaCO₃ : CaCl₂ : CO₂ = 100 : 111 : 44。

- 碳酸钙质量 = 4.4 g × 100 / 44 = 10 g，质量分数 = 10 / 12.5 = 80%
- 氯化钙质量 = 4.4 g × 111 / 44 = 11.1 g
- 反应后溶液质量 = 10 g + 100 g − 4.4 g = 105.6 g（杂质不溶，不计入）
- 溶质质量分数 = 11.1 / 105.6 ≈ 10.5%

```verify
{"claim": "示例1：碳酸钙 10 g，质量分数 80%", "expr": "[Math.round(4.4 * 100 / 44 * 100) / 100, Math.round(4.4 * 100 / 44 / 12.5 * 100)]", "expect": [10, 80]}
```

```verify
{"claim": "示例1：氯化钙 11.1 g，溶液 105.6 g，溶质质量分数约 10.5%", "expr": "[Math.round(4.4 * 111 / 44 * 10) / 10, Math.round((10 + 100 - 4.4) * 10) / 10, Math.round(11.1 / 105.6 * 1000) / 10]", "expect": [11.1, 105.6, 10.5]}
```

易错：溶液质量写成 12.5 g + 100 g − 4.4 g = 108.1 g（把不溶性杂质算进了溶液）。

```verify
{"claim": "示例1 易错：把杂质算进溶液会得到 108.1 g", "expr": "Math.round((12.5 + 100 - 4.4) * 10) / 10", "expect": 108.1}
```

### 示例 2：加热高锰酸钾制氧气（HQ03）

> 加热 15.8 g 高锰酸钾至完全分解，最多可得氧气多少克？

2KMnO₄ ==△== K₂MnO₄ + MnO₂ + O₂↑；Mr(KMnO₄) = 39 + 55 + 16 × 4 = 158；质量关系 2 × 158 : 32 = 316 : 32。

氧气质量 = 15.8 g × 32 / 316 = 1.6 g。

```verify
{"claim": "示例2：KMnO4 相对分子质量 158，可得氧气 1.6 g", "expr": "[39 + 55 + 16 * 4, Math.round(15.8 * 32 / 316 * 100) / 100]", "expect": [158, 1.6]}
```

### 示例 3：浓硫酸稀释（HQ04）

> 把 50 g 质量分数为 98% 的浓硫酸稀释成质量分数为 20% 的稀硫酸，需要加水多少克？

抓不变量：稀释前后溶质质量不变。溶质 = 50 g × 98% = 49 g；稀释后溶液 = 49 g / 20% = 245 g；加水 = 245 g − 50 g = 195 g。

```verify
{"claim": "示例3：稀释后溶液 245 g，需加水 195 g", "expr": "[Math.round(50 * 0.98 / 0.2), Math.round(50 * 0.98 / 0.2 - 50)]", "expect": [245, 195]}
```

操作上必须把浓硫酸沿器壁缓慢注入水中并不断搅拌，见 `shared/lab-safety.md` 第三节。

### 示例 4：元素质量分数（HQ02）

> 求硝酸铵（NH₄NO₃）中氮元素的质量分数。

Mr(NH₄NO₃) = 14 × 2 + 1 × 4 + 16 × 3 = 80；氮元素质量分数 = 28 / 80 = 35%。易错：只数一个氮原子，得到 17.5%。

```verify
{"claim": "示例4：NH4NO3 相对分子质量 80，氮元素质量分数 35%（只数一个 N 会得 17.5%）", "expr": "[14 * 2 + 1 * 4 + 16 * 3, Math.round(28 / 80 * 1000) / 10, Math.round(14 / 80 * 1000) / 10]", "expect": [80, 35, 17.5]}
```

### 示例 5：反应后溶液中的溶质（HR02）

> 向一定量稀盐酸中加入氢氧化钠溶液，反应后向所得溶液中滴加紫色石蕊溶液，溶液变红。反应后溶液中的溶质是什么？

石蕊变红 → 溶液显酸性 → 盐酸有剩余；溶质为生成的 NaCl 和剩余的 HCl。若题目给的是"恰好完全反应"，溶质只有 NaCl。
追问顺序：先问"生成物是什么"（一定有），再问"哪种反应物可能有剩余、题目里哪个信息告诉你的"。

## 五、高中必修起点示例题

依据《普通高中化学课程标准日常修订版（2017 年版 2025 年修订）》必修主题 1「了解物质的量及其相关物理量的含义和应用」与主题 2「氧化还原反应」「电离与离子反应」。

### 示例 6：气体体积与质量（HQ06）

> 标准状况下 11.2 L 氧气的物质的量和质量各是多少？

n = V / Vm = 11.2 L ÷ 22.4 L/mol = 0.5 mol；m = n × M = 0.5 mol × 32 g/mol = 16 g。
易错：题目不是标准状况时仍用 22.4 L/mol。

```verify
{"claim": "示例6：标准状况下 11.2 L O2 为 0.5 mol、16 g", "expr": "[11.2 / 22.4, 11.2 / 22.4 * 32]", "expect": [0.5, 16]}
```

### 示例 7：配制溶液所需溶质（HQ06、HE07）

> 配制 250 mL 0.1 mol/L 的 NaCl 溶液，需要 NaCl 多少克？

n = c × V = 0.1 mol/L × 0.25 L = 0.025 mol；m = 0.025 mol × 58.5 g/mol = 1.4625 g。用托盘天平（精确到 0.1 g）时称取 1.5 g。
易错：V 用成水的体积，或忘记把 mL 换成 L。

```verify
{"claim": "示例7：需 NaCl 0.025 mol、1.4625 g，托盘天平称 1.5 g", "expr": "[Math.round(0.1 * 0.25 * 1000) / 1000, Math.round(0.1 * 0.25 * 58.5 * 10000) / 10000, Math.round(0.1 * 0.25 * 58.5 * 10) / 10]", "expect": [0.025, 1.4625, 1.5]}
```

### 示例 8：氧化还原分析（HC08、HS08）

> 分析反应 Fe₂O₃ + 3CO ==高温== 2Fe + 3CO₂ 中的氧化剂、还原剂和电子转移数目。

标化合价：Fe 由 +3 降到 0，得电子，被还原，Fe₂O₃ 是氧化剂；C 由 +2 升到 +4，失电子，被氧化，CO 是还原剂。
得电子：2 个 Fe 原子 × 3 = 6；失电子：3 个 C 原子 × 2 = 6。得失电子总数相等。

```verify
{"claim": "示例8：得电子 2×3 与失电子 3×2 相等，均为 6", "expr": "[2 * 3, 3 * 2, 2 * 3 === 3 * 2]", "expect": [6, 6, true]}
```

## 六、检验清单（Step 4 用）

```text
□ 原子守恒：方程式两边每种原子个数相等
□ 质量守恒：反应后溶液质量 = 加入物质总质量 − 逸出气体 − 生成沉淀 − 不溶杂质
□ 电荷守恒（⚠高中 离子方程式）：两边离子所带电荷总数相等
□ 合理性：质量分数在 0～100% 之间；数量级与题目数据相符
```
