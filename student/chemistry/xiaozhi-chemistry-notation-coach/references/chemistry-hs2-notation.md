## 一、原子结构示意图（1～20 号）

**规则**

1. 圆圈表示原子核，圈内写"+核电荷数"；弧线表示电子层，弧线上的数字是该层的电子数。聊天里用文字画法：`(+11) 2 8 1` 表示核电荷数为 11，由内向外各层依次有 2、8、1 个电子。
2. 由内向外排：第 1 层最多 2 个，第 2 层最多 8 个（每层最多 2n² 个）；最外层不超过 8 个（第 1 层是最外层时不超过 2 个）。1～20 号中，钾、钙的第 3 层排满 8 个后，其余电子进入第 4 层。
3. 离子的结构示意图：核电荷数不变，只改核外电子——阳离子失去最外层电子，阴离子把最外层补到 8 个。
4. 主族元素：电子层数 = 周期序数，最外层电子数 = 主族序数。

**例子**

| 粒子 | 文字画法 | 说明 |
|---|---|---|
| O | (+8) 2 6 | 第二周期、ⅥA 族 |
| Na | (+11) 2 8 1 | 第三周期、ⅠA 族 |
| Na⁺ | (+11) 2 8 | 失去最外层 1 个电子，核电荷数仍是 +11 |
| Cl | (+17) 2 8 7 | 第三周期、ⅦA 族 |
| Cl⁻ | (+17) 2 8 8 | 得到 1 个电子，最外层补到 8 个 |
| K | (+19) 2 8 8 1 | 不是 2 8 9 |
| Ca²⁺ | (+20) 2 8 8 | 失去最外层 2 个电子 |
| S²⁻ | (+16) 2 8 8 | 与 Cl⁻、K⁺、Ca²⁺ 的核外电子排布相同，都和氩原子一样 |

**常见错误**（子类型 HS09）

- 钾画成 (+19) 2 8 9，钙画成 (+20) 2 8 10（最外层超过 8 个）。
- 离子的结构示意图把核电荷数也改了：Na⁺ 画成 (+10) 2 8。
- Cl⁻ 仍画成 2 8 7，只在旁边标一个"−"；或把氯原子画成 (+17) 2 8 8（那是 Cl⁻）。

## 二、电子式

**规则**（深度按所用教材）

1. 在元素符号周围用"·"或"×"表示原子的最外层电子。聊天里用等宽文字画：`:` 写在两个原子之间表示一对共用电子（为了看清可以加空格），写在原子外侧表示那一侧的一对未成键电子；`..` 写在元素符号正上方或正下方：夹在上下两个原子之间的是一对共用电子（如 NH₃、CH₄ 中竖着连的 H），否则是那一侧的一对未成键电子。
2. 简单阳离子直接写离子符号（Na⁺、Mg²⁺），不画电子、不加方括号。
3. 阴离子画出最外层的全部电子（一般是 8 个），加方括号，在方括号右上角标电荷。
4. 离子化合物：阴、阳离子的电子式按相邻关系排开，相同的离子不合并（MgCl₂ 的两个 Cl⁻ 分写在 Mg²⁺ 两侧）。
5. 共价分子：共用电子对写在两个原子之间，未成键的电子也要画全；不加方括号、不标电荷。
6. 写之前先判断是离子化合物还是共价化合物（含金属元素的不一定是离子化合物，如 AlCl₃）。
7. 用电子式表示形成过程（按教材要求时）：左边写各原子的电子式，中间用"→"，不用"="；离子化合物要用弯箭头表示电子转移的方向，右边写离子化合物的电子式；共价分子不画弯箭头，右边写成共用电子对。

**例子**

离子化合物（MgCl₂ 中两个 Cl⁻ 分写两侧；Na₂O₂ 中两个 O 之间的 `:` 是一对共用电子，O₂²⁻ 内是共价键）：

```text
NaCl
       ..
 Na⁺ [:Cl:]⁻
       ..

MgCl₂
   ..         ..
 [:Cl:]⁻Mg²⁺[:Cl:]⁻
   ..         ..

NaOH
       ..
 Na⁺ [:O:H]⁻
       ..

Na₂O₂
       ..  ..
 Na⁺ [:O : O:]²⁻ Na⁺
       ..  ..
```

共价分子（未成键电子一个都不能少）：

```text
HCl
   ..
 H:Cl:
   ..

H₂O
   ..
 H:O:H
   ..

NH₃
   ..
 H:N:H
   ..
   H

CH₄
   H
   ..
 H:C:H
   ..
   H

CO₂
 ..    ..
 O::C::O
 ..    ..

N₂
 :N:::N:
```

**常见错误**（子类型 HS09）

- 离子化合物写成共价分子的样子：NaCl 写成 `Na:Cl`，没有方括号和电荷。
- 共价分子写成离子化合物的样子：HCl 写成 `H⁺[:Cl:]⁻`。
- 漏写未成键电子：HCl 写成 `H:Cl`；N₂ 写成 `N:::N`；NH₃ 漏掉 N 上方的一对电子。
- CO₂ 写成 `O:C:O`（只有单键，C、O 周围都不是 8 个电子）。
- 相同离子合并：MgCl₂ 写成 `Mg²⁺2[:Cl:]⁻` 或把两个 Cl⁻ 合进一个方括号。
- 阳离子也画电子、加方括号，如 `[Na]⁺`。
- 形成过程用"="连接；离子化合物漏画弯箭头，或共价分子画了弯箭头。

## 三、必修有机反应式

**规则**

1. 反应式里的有机物按教材写结构简式：碳碳双键不能省略（乙烯写 CH₂=CH₂，不写 CH₂CH₂）；官能团写清楚——乙醇 CH₃CH₂OH，乙醛 CH₃CHO，乙酸 CH₃COOH，乙酸乙酯 CH₃COOCH₂CH₃。
2. 有机反应用"→"，条件不能漏；酯化反应是可逆反应，用"⇌"。
3. 和无机方程式一样要配平，生成气体要标 ↑（乙醇与钠放出 H₂↑）。
4. 先想清楚哪根键断开、连上了什么，再写产物：加成是双键中的一根键断开，两端的碳原子各连上一个原子或原子团；加聚是许多个双键打开、首尾相连；酯化是"酸脱羟基、醇脱氢"。

**例子**

| 反应 | 反应式 | 类型 |
|---|---|---|
| 乙烯与溴 | CH₂=CH₂ + Br₂ → CH₂BrCH₂Br | 加成 |
| 乙烯与氢气 | CH₂=CH₂ + H₂ → CH₃CH₃（条件：催化剂、△） | 加成 |
| 乙烯与氯化氢 | CH₂=CH₂ + HCl → CH₃CH₂Cl（条件：催化剂、△） | 加成 |
| 乙烯与水 | CH₂=CH₂ + H₂O → CH₃CH₂OH（条件：催化剂、加热、加压） | 加成 |
| 乙烯的加聚 | nCH₂=CH₂ → [CH₂—CH₂]ₙ（条件：催化剂）；课本上方括号两侧各有一条短线穿过，表示链节与相邻链节相连 | 加聚 |
| 乙烯燃烧 | CH₂=CH₂ + 3O₂ → 2CO₂ + 2H₂O（条件：点燃） | 氧化 |
| 乙醇与钠 | 2CH₃CH₂OH + 2Na → 2CH₃CH₂ONa + H₂↑ | 羟基上的氢被钠置换 |
| 乙醇燃烧 | CH₃CH₂OH + 3O₂ → 2CO₂ + 3H₂O（条件：点燃） | 氧化 |
| 乙醇的催化氧化 | 2CH₃CH₂OH + O₂ → 2CH₃CHO + 2H₂O（条件：Cu 或 Ag、△） | 氧化 |
| 铜丝的变化（分步） | 2Cu + O₂ ==△== 2CuO（铜丝变黑）；CH₃CH₂OH + CuO → CH₃CHO + Cu + H₂O（条件：△；铜丝又变红） | 铜在反应前后不变，起催化作用 |
| 乙酸与碳酸钠 | 2CH₃COOH + Na₂CO₃ → 2CH₃COONa + H₂O + CO₂↑ | 乙酸的酸性比碳酸强 |
| 酯化 | CH₃COOH + CH₃CH₂OH ⇌ CH₃COOCH₂CH₃ + H₂O（条件：浓硫酸、△） | 酯化（属取代） |

酯化的断键：用含 ¹⁸O 的乙醇（CH₃CH₂¹⁸OH）与乙酸反应，¹⁸O 只出现在乙酸乙酯中，生成的水里没有——酸脱羟基、醇脱氢。

**常见错误**（子类型 HS10）

- 乙烯写成 CH₂CH₂（漏写碳碳双键）。
- 加成产物写成 CH₃CHBr₂（两个 Br 连到了同一个碳原子上），或写成 CH₂=CHBr + HBr（把加成写成了取代）。
- 聚乙烯的链节里仍写双键 [CH₂=CH₂]ₙ；漏写 n 或催化剂。
- 乙醇与钠的产物写成 NaOH 或 CH₃CH₂Na，漏标 H₂↑。
- 乙醇催化氧化写成生成乙酸（应为乙醛）；乙醛写成 CH₃COH（应为 CH₃CHO）；漏写"Cu 或 Ag、△"。
- 酯化反应用"="或漏写"浓硫酸、△"；漏写生成的 H₂O；乙酸乙酯写成 CH₃CH₂COOCH₃（那是丙酸甲酯）。

## 四、第 6 级过关参考（经验值，可与学生商量调整）

| 内容 | 过关参考 |
|---|---|
| 原子结构示意图 | 随机 5 个 1～20 号元素的原子或简单离子，全对 |
| 电子式 | 随机 3 个全对，至少含 1 个离子化合物、1 个含双键或三键的共价分子 |
| 必修有机反应式 | 随机 3 个全对，条件、可逆符号与 ↑ 都不漏 |

和第 1～5 级一样按"说规则 → 自己写 → 我检查 → 错在哪一步"的顺序练，一次只练一项、一组不超过 5 道；练习题生成前按 `shared/ai-item-check.md` 自检，式子按本文件的规则逐项核对后再给出。
