## 一、第 7 级：热化学方程式

依据：课标选择性必修 1 学业要求「能进行反应焓变的简单计算，能用热化学方程式表示反应中的能量变化」。

**规则**

1. 注明每种物质的聚集状态：气态 g、液态 l、固态 s、溶液 aq；不标 ↑、↓，一般不写"点燃"等条件；25 ℃、101 kPa 下的反应可以不注明温度和压强。
2. ΔH 写在方程式右边，与方程式空开：放热 ΔH < 0，写"−"；吸热 ΔH > 0，写"+"，"+"不能省略；单位是 kJ/mol（kJ·mol⁻¹），指每摩尔反应——按方程式所写的化学计量数完成一次反应。
3. 化学计量数只表示物质的量，可以是分数；ΔH 与化学计量数对应：化学计量数加倍，ΔH 加倍；方程式反过来写，ΔH 变号。
4. 盖斯定律：总反应的 ΔH 等于各步 ΔH 的代数和——方程式怎样加减、乘系数，ΔH 就怎样加减、乘系数。

**例子**

| 说明 | 热化学方程式 |
|---|---|
| 氢气燃烧生成液态水 | H₂(g) + ½O₂(g) = H₂O(l)　ΔH = −285.8 kJ/mol |
| 化学计量数加倍 | 2H₂(g) + O₂(g) = 2H₂O(l)　ΔH = −571.6 kJ/mol |
| 生成水蒸气 | H₂(g) + ½O₂(g) = H₂O(g)　ΔH = −241.8 kJ/mol |
| 反过来写 | H₂O(l) = H₂(g) + ½O₂(g)　ΔH = +285.8 kJ/mol |
| 甲烷燃烧 | CH₄(g) + 2O₂(g) = CO₂(g) + 2H₂O(l)　ΔH = −890.3 kJ/mol |
| 盖斯定律 | 已知 C(s) + O₂(g) = CO₂(g)　ΔH₁ = −393.5 kJ/mol，CO(g) + ½O₂(g) = CO₂(g)　ΔH₂ = −283.0 kJ/mol；第一式减去第二式：C(s) + ½O₂(g) = CO(g)　ΔH = ΔH₁ − ΔH₂ = −110.5 kJ/mol |
| 用键能估算 | H₂(g) + Cl₂(g) = 2HCl(g)　ΔH = 436 + 243 − 2 × 431 = −183 kJ/mol（反应物的键能总和 − 生成物的键能总和） |

**常见错误**

- 漏标聚集状态，或把"点燃"、↑ 写进热化学方程式（子类型 HS11）。
- 放热反应的 ΔH 写成正值，吸热反应省略"+"，单位写成 kJ（子类型 HS11）。
- 化学计量数加倍后 ΔH 没有加倍，ΔH 与化学计量数不对应（子类型 HS11）。
- 用盖斯定律时方程式反写后 ΔH 不变号、乘系数后 ΔH 没有同乘；用键能算 ΔH 时写成"生成物键能总和 − 反应物键能总和"（子类型 HQ08）。

## 二、第 7 级：电极反应式

依据：课标选择性必修 1 学业要求「能分析、解释原电池和电解池的工作原理，能设计简单的原电池和电解池」；教学提示「利用锌铜双液原电池、铅酸蓄电池、氢氧燃料电池、电解熔融氯化钠和电解饱和食盐水等案例素材」，学习活动「电解氯化铜溶液；电解饱和食盐水」，情境素材「电解精炼铜」。

**规则**

1. 原电池：负极失去电子、发生氧化反应，正极得到电子、发生还原反应。电解池：与电源正极相连的是阳极，发生氧化反应；与电源负极相连的是阴极，发生还原反应。电解池只说阴极、阳极，不说正极、负极。
2. 四步写法：① 写出这一极的反应物、产物和得失电子数；② 用介质中能大量存在的离子配电荷——酸性介质用 H⁺，碱性介质用 OH⁻，碱性溶液里不写 H⁺，酸性溶液里不写 OH⁻；③ 用 H₂O 配平 H、O 原子；④ 检查原子守恒与电荷守恒。
3. 两极得失电子数相等；统一电子数后，两个电极反应式相加得到总反应式。
4. 电解水溶液时看谁先得失电子：阴极上 Cu²⁺ 比水电离出的 H⁺ 先得电子，水电离出的 H⁺ 比 Na⁺ 先得电子；惰性电极作阳极时，Cl⁻ 比水电离出的 OH⁻ 先失电子；铜等活性金属作阳极时，电极本身先失电子。

**例子**

| 装置 | 电极反应式 | 总反应 |
|---|---|---|
| 锌铜双液原电池（ZnSO₄、CuSO₄ 溶液，盐桥相连） | 负极：Zn − 2e⁻ = Zn²⁺；正极：Cu²⁺ + 2e⁻ = Cu | Zn + Cu²⁺ = Zn²⁺ + Cu |
| 氢氧燃料电池（酸性，如稀硫酸） | 负极：2H₂ − 4e⁻ = 4H⁺；正极：O₂ + 4H⁺ + 4e⁻ = 2H₂O | 2H₂ + O₂ = 2H₂O |
| 氢氧燃料电池（碱性，如 KOH 溶液） | 负极：2H₂ + 4OH⁻ − 4e⁻ = 4H₂O；正极：O₂ + 2H₂O + 4e⁻ = 4OH⁻ | 2H₂ + O₂ = 2H₂O |
| 铅酸蓄电池放电（可选，按教材） | 负极：Pb + SO₄²⁻ − 2e⁻ = PbSO₄；正极：PbO₂ + 4H⁺ + SO₄²⁻ + 2e⁻ = PbSO₄ + 2H₂O | Pb + PbO₂ + 2H₂SO₄ = 2PbSO₄ + 2H₂O |
| 电解 CuCl₂ 溶液（石墨电极） | 阳极：2Cl⁻ − 2e⁻ = Cl₂↑；阴极：Cu²⁺ + 2e⁻ = Cu | CuCl₂ ==通电== Cu + Cl₂↑ |
| 电解饱和食盐水（惰性阳极） | 阳极：2Cl⁻ − 2e⁻ = Cl₂↑；阴极：2H₂O + 2e⁻ = H₂↑ + 2OH⁻（有的教材写成 2H⁺ + 2e⁻ = H₂↑） | 2NaCl + 2H₂O ==通电== 2NaOH + H₂↑ + Cl₂↑ |
| 电镀铜（铁制镀件） | 阳极（铜片，接电源正极）：Cu − 2e⁻ = Cu²⁺；阴极（镀件，接电源负极）：Cu²⁺ + 2e⁻ = Cu | 电镀液（CuSO₄ 溶液）的浓度基本不变 |
| 电解精炼铜 | 阳极（粗铜）：Cu − 2e⁻ = Cu²⁺，比铜活泼的杂质也失电子（如 Zn − 2e⁻ = Zn²⁺、Fe − 2e⁻ = Fe²⁺），比铜不活泼的 Ag、Au 等沉积为阳极泥；阴极（纯铜）：Cu²⁺ + 2e⁻ = Cu | 电解液中 c(Cu²⁺) 略有减小 |

双液原电池中，盐桥里的阳离子移向正极一侧（CuSO₄ 溶液），阴离子移向负极一侧（ZnSO₄ 溶液）。

**常见错误**

- 碱性介质的负极写成生成 H⁺：碱性氢氧燃料电池的负极写成 H₂ − 2e⁻ = 2H⁺（子类型 HS12）。
- 电荷不守恒：碱性燃料电池的正极写成 O₂ + 2H₂O + 2e⁻ = 4OH⁻（左边 −2、右边 −4，应为 4e⁻）（子类型 HS12）。
- 电解池的阴、阳极写反（子类型 HS12）；把电解池的阳极叫成"负极"，属概念混淆（子类型 HC18）。
- 电解饱和食盐水的阴极写成 Na⁺ + e⁻ = Na（水溶液中是水得电子）（子类型 HS12）。
- 两极反应式相加前没有统一得失电子数（子类型 HS12）。
- 电镀时镀件接电源正极，或电镀液里没有镀层金属的离子（子类型 HE11）。

## 三、第 7 级：电离方程式与水解方程式

依据：课标选择性必修 1 学业要求「能用化学用语正确表示水溶液中的离子反应与平衡」。

**规则**

1. 强电解质完全电离，用"="：NaHSO₄ 在水溶液中 NaHSO₄ = Na⁺ + H⁺ + SO₄²⁻（熔融时 NaHSO₄ = Na⁺ + HSO₄⁻）；NaHCO₃ = Na⁺ + HCO₃⁻（HCO₃⁻ 不拆开）。
2. 弱电解质部分电离，用"⇌"：CH₃COOH ⇌ CH₃COO⁻ + H⁺；NH₃·H₂O ⇌ NH₄⁺ + OH⁻。多元弱酸分步电离、分步书写，以第一步为主：H₂CO₃ ⇌ H⁺ + HCO₃⁻，HCO₃⁻ ⇌ H⁺ + CO₃²⁻；多元弱碱按教材一步写：Fe(OH)₃ ⇌ Fe³⁺ + 3OH⁻。
3. 盐类水解用"⇌"，产物不标 ↑、↓：NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺。多元弱酸根分步水解、分步书写：CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻（主要），HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻；多元弱碱的阳离子一步写：Fe³⁺ + 3H₂O ⇌ Fe(OH)₃ + 3H⁺。
4. 分清电离和水解，有水参加的不一定是水解：HCO₃⁻ + H₂O ⇌ H₃O⁺ + CO₃²⁻ 生成 H₃O⁺，是电离（即 HCO₃⁻ ⇌ H⁺ + CO₃²⁻）；HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻ 结合 H⁺ 生成弱酸，是水解。
5. 相互促进、进行得很彻底的水解（教材内容）用"="并标 ↑、↓：Al³⁺ + 3HCO₃⁻ = Al(OH)₃↓ + 3CO₂↑（泡沫灭火器的原理）。
6. 沉淀溶解平衡标明状态、用"⇌"：AgCl(s) ⇌ Ag⁺(aq) + Cl⁻(aq)。

**常见错误**（子类型 HS13）

- 弱电解质的电离用"="；H₂CO₃ 一步写成 H₂CO₃ ⇌ 2H⁺ + CO₃²⁻。
- NaHCO₃ 的电离写成 NaHCO₃ = Na⁺ + H⁺ + CO₃²⁻。
- HCO₃⁻ 的电离和水解写混：把 HCO₃⁻ + H₂O ⇌ H₃O⁺ + CO₃²⁻ 当成水解。
- 多元弱酸根一步水解：CO₃²⁻ + 2H₂O ⇌ H₂CO₃ + 2OH⁻。
- 水解方程式写"="和"↓"：Fe³⁺ + 3H₂O = Fe(OH)₃↓ + 3H⁺。

## 四、第 8 级：核外电子排布式、轨道表示式与价电子排布

依据：课标选择性必修 2 学业要求「能结合能量最低原理、泡利不相容原理、洪特规则书写 1~36 号元素基态原子的核外电子排布式和轨道表示式，并说明含义」。

**规则**

1. 填充顺序：基态原子的电子遵循能量最低原理，按构造原理的顺序填入 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p；书写顺序按能层：Fe 写成 1s²2s²2p⁶3s²3p⁶3d⁶4s²（3d 写在 4s 前面）。
2. 简化写法：用上一周期稀有气体的元素符号加方括号代替内层电子，Fe 为 [Ar]3d⁶4s²。
3. 价电子排布式（教材也叫价层电子排布式）：主族元素写最外层，Cl 为 3s²3p⁵；过渡元素还要写 (n−1)d，Fe 为 3d⁶4s²。
4. 轨道表示式：一个方框表示一个原子轨道，箭头表示电子及其自旋。泡利不相容原理：一个轨道最多容纳 2 个电子，而且自旋相反（[↑↓]）；洪特规则：电子填入能量相同的几个轨道时，优先分占不同的轨道，而且自旋平行（N 的 2p 为 [↑][↑][↑]）。聊天里写成 `2p [↑][↑][↑]`，空轨道写 `[ ]`。
5. 特例：Cr 为 [Ar]3d⁵4s¹，Cu 为 [Ar]3d¹⁰4s¹（3d 半充满、全充满时能量较低，更稳定）。
6. 离子先失去最外层电子：Fe²⁺ 为 [Ar]3d⁶，Fe³⁺ 为 [Ar]3d⁵，Cu²⁺ 为 [Ar]3d⁹。

**例子**

| 元素 | 核外电子排布式 | 价电子的轨道表示式 |
|---|---|---|
| N（7 号） | 1s²2s²2p³ | 2s [↑↓]　2p [↑][↑][↑] |
| O（8 号） | 1s²2s²2p⁴ | 2s [↑↓]　2p [↑↓][↑][↑] |
| Cl（17 号） | 1s²2s²2p⁶3s²3p⁵，即 [Ne]3s²3p⁵ | 3s [↑↓]　3p [↑↓][↑↓][↑] |
| K（19 号） | 1s²2s²2p⁶3s²3p⁶4s¹，即 [Ar]4s¹ | 4s [↑] |
| Cr（24 号） | [Ar]3d⁵4s¹ | 3d [↑][↑][↑][↑][↑]　4s [↑] |
| Fe（26 号） | [Ar]3d⁶4s² | 3d [↑↓][↑][↑][↑][↑]　4s [↑↓] |
| Cu（29 号） | [Ar]3d¹⁰4s¹ | 3d [↑↓][↑↓][↑↓][↑↓][↑↓]　4s [↑] |
| Br（35 号） | [Ar]3d¹⁰4s²4p⁵ | 4s [↑↓]　4p [↑↓][↑↓][↑] |

**常见错误**（子类型 HS14）

- 违反洪特规则：N 的 2p 画成 [↑↓][↑][ ]。
- 违反泡利不相容原理：一个轨道里画两个同向的箭头。
- Cr、Cu 按常规写成 3d⁴4s²、3d⁹4s²。
- K 写成 [Ne]3s²3p⁶3d¹（第 19 个电子进入 4s，不进入 3d）。
- Fe²⁺ 写成 [Ar]3d⁴4s²（应先失去 4s 电子）。
- 3d 只画 3 个方框（d 能级有 5 个轨道）。
- 按填充顺序写成 …3p⁶4s²3d⁶，书写不规范：教材要求按能层顺序写成 …3p⁶3d⁶4s²。

## 五、第 8 级：结构简式与简单有机物的命名

依据：课标选择性必修 3 学业要求「能写出烃及其衍生物的官能团、简单代表物的结构简式和名称」，内容要求「知道简单有机化合物的命名」。

**规则**

1. 结构简式可以省略部分 C–H 键和碳碳单键，但碳碳双键、碳碳三键和官能团不能省略：丙烯 CH₂=CHCH₃，乙炔 CH≡CH，乙醛 CH₃CHO，丙酮 CH₃COCH₃（官能团是酮羰基），乙酸乙酯 CH₃COOCH₂CH₃。
2. 键线式：每个拐点和端点表示一个碳原子，碳原子上的氢不写；但官能团以及碳、氢以外的原子（如羟基、酮羰基中的 O、碳卤键中的 Cl 或 Br）必须写出。
3. 烷烃的系统命名：选最长的碳链作主链 → 从离支链最近的一端给主链碳原子编号，使支链的位次尽可能小 → 写名称：支链位次-支链名称 + 主链名称；相同的支链合并，用"二、三"表示个数，位次之间用","隔开；不同的支链，简单的写在前面。
4. 含官能团的有机物：选含官能团（如碳碳双键、羟基）的最长碳链作主链，从离官能团最近的一端编号，在名称中标出官能团的位次。

**例子**

| 结构简式 | 名称 | 说明 |
|---|---|---|
| CH₃CH(CH₃)CH₂CH₃ | 2-甲基丁烷 | 从左端编号，甲基在 2 号碳 |
| CH₃CH(CH₃)CH(CH₃)CH₃ | 2,3-二甲基丁烷 | 相同的支链合并 |
| CH₃C(CH₃)₂CH₂CH₃ | 2,2-二甲基丁烷 | 同一个碳上两个甲基，位次写两遍 |
| CH₃CH(C₂H₅)CH₂CH₃ | 3-甲基戊烷 | 最长的碳链经过乙基，有 5 个碳 |
| CH₂=CHCH₂CH₃ | 1-丁烯 | 双键从 1 号碳开始 |
| CH₃CH=CHCH₃ | 2-丁烯 | 双键从 2 号碳开始 |
| CH₃CH(OH)CH₂CH₃ | 2-丁醇 | 羟基在 2 号碳 |

**常见错误**（子类型 HS15）

- 主链选错：CH₃CH(C₂H₅)CH₂CH₃ 命名为 2-乙基丁烷（应为 3-甲基戊烷）。
- 编号方向错：CH₃CH(CH₃)CH₂CH₃ 命名为 3-甲基丁烷。
- 格式错：2,3-二甲基丁烷写成"2,3-甲基丁烷""二甲基丁烷""2-二甲基丁烷"。
- 烯烃、醇漏标官能团的位次（CH₃CH=CHCH₃ 只写"丁烯"），或选的主链不含官能团。
- 结构简式漏写双键（丙烯写成 CH₂CHCH₃）；醛基写成 −COH（乙醛应为 CH₃CHO）。
- 键线式漏写官能团，如漏画羟基，或漏写碳卤键中的 Cl、Br。

## 六、第 8 级：有机反应式

依据：课标选择性必修 3 学业要求「能描述和分析各类有机化合物的典型代表物的重要反应，能书写相应的反应式」，以及主题 3 学业要求中的「能写出典型的加聚反应和缩聚反应的反应式」。

**规则**

1. 条件决定反应类型，条件必须写全：卤代烃与"NaOH 水溶液、△"是取代（水解），与"NaOH 乙醇溶液、△"是消去；乙醇在"浓硫酸、170 ℃"下是消去（140 ℃ 时主要生成乙醚）。
2. 消去要求与碳卤键（或羟基）所在碳原子相邻的碳原子上有氢；醇的催化氧化要求与羟基相连的碳原子上有氢：这个碳上有 2 个氢的醇氧化成醛，有 1 个氢的氧化成酮，没有氢的不能被催化氧化。
3. 醛基的检验都在碱性条件下加热：银镜反应用银氨溶液、水浴加热；与新制 Cu(OH)₂ 反应要 NaOH 过量、加热，生成砖红色沉淀。
4. 酯在酸性条件下水解是可逆的，用"⇌"；在碱性条件下水解生成羧酸盐，进行到底，用"→"。
5. 加聚：双键打开，链节的主链只有碳，支链（如 −CH₃、−Cl）挂在主链上；缩聚：生成高分子的同时生成小分子（如 H₂O），要写出端基和小分子的数目。

**例子**

| 反应 | 反应式 | 类型 |
|---|---|---|
| 溴乙烷与 NaOH 水溶液 | CH₃CH₂Br + NaOH → CH₃CH₂OH + NaBr（条件：水、△） | 取代（水解） |
| 溴乙烷与 NaOH 乙醇溶液 | CH₃CH₂Br + NaOH → CH₂=CH₂↑ + NaBr + H₂O（条件：乙醇、△） | 消去 |
| 乙醇的消去 | CH₃CH₂OH → CH₂=CH₂↑ + H₂O（条件：浓硫酸、170 ℃） | 消去 |
| 2-丙醇的催化氧化 | 2CH₃CH(OH)CH₃ + O₂ → 2CH₃COCH₃ + 2H₂O（条件：Cu、△） | 氧化（生成酮） |
| 乙醛的银镜反应 | CH₃CHO + 2[Ag(NH₃)₂]OH → CH₃COONH₄ + 2Ag↓ + 3NH₃ + H₂O（条件：水浴加热） | 氧化 |
| 乙醛与新制 Cu(OH)₂ | CH₃CHO + 2Cu(OH)₂ + NaOH → CH₃COONa + Cu₂O↓ + 3H₂O（条件：△） | 氧化 |
| 酯化 | CH₃COOH + CH₃CH₂OH ⇌ CH₃COOCH₂CH₃ + H₂O（条件：浓硫酸、△） | 酯化（属取代） |
| 酯的酸性水解 | CH₃COOCH₂CH₃ + H₂O ⇌ CH₃COOH + CH₃CH₂OH（条件：稀硫酸、△） | 水解（属取代） |
| 酯的碱性水解 | CH₃COOCH₂CH₃ + NaOH → CH₃COONa + CH₃CH₂OH（条件：△） | 水解（属取代） |
| 氯乙烯加聚 | nCH₂=CHCl → [CH₂—CHCl]ₙ（条件：催化剂；聚氯乙烯） | 加聚 |
| 丙烯加聚 | nCH₂=CHCH₃ → [CH₂—CH(CH₃)]ₙ（条件：催化剂；聚丙烯，甲基是支链） | 加聚 |
| 乳酸缩聚 | nCH₃CH(OH)COOH → H[OCH(CH₃)CO]ₙOH + (n−1)H₂O（条件：催化剂、△；聚乳酸） | 缩聚 |
| 对苯二甲酸与乙二醇缩聚 | nHOOC−C₆H₄−COOH（对位）+ nHOCH₂CH₂OH → HO[OC−C₆H₄−COOCH₂CH₂O]ₙH + (2n−1)H₂O（条件：催化剂、△） | 缩聚 |

新制 Cu(OH)₂ 的反应式，有的教材写成 CH₃CHO + 2Cu(OH)₂ → CH₃COOH + Cu₂O↓ + 2H₂O（条件：△），以所用教材为准。聚合物方括号两侧的短线在课本上穿过括号，表示链节与相邻链节相连。

**常见错误**

- 卤代烃水解与消去的条件写混，或把"NaOH 水溶液""NaOH 乙醇溶液"都只写成"NaOH"（子类型 HC23）。
- 乙醇消去的温度写成 140 ℃，或漏写浓硫酸（子类型 HC23）。
- 银镜反应漏写"水浴加热"，与新制 Cu(OH)₂ 反应写成常温下或酸性条件下进行（子类型 HC22）；Ag、Cu₂O 不标 ↓（子类型 HS05），配平错（子类型 HS04）。
- 酯的碱性水解用"⇌"或写成生成 CH₃COOH；把酯的水解当成加成（子类型 HC23）。
- 聚丙烯写成 [CH₂—CH₂—CH₂]ₙ（把甲基写进主链）；缩聚漏写端基和小分子，或小分子数写成 n（应为 n − 1 或 2n − 1）；加聚与缩聚分不清（子类型 HC24）。
- 结构简式写错，整个反应式跟着错，如乙醛写成 CH₃COH（子类型 HS15）。
