## 一、常见元素的化合价（初中常用）

| 化合价 | 元素 |
|---|---|
| +1 | 钾 K、钠 Na、银 Ag、氢 H |
| +2 | 钙 Ca、镁 Mg、钡 Ba、锌 Zn；铜 Cu 常见 +2；汞 Hg 常见 +2 |
| +3 | 铝 Al |
| +2、+3 | 铁 Fe（亚铁 +2，铁 +3） |
| −2 | 氧 O |
| −1 | 氯 Cl（在金属氯化物中）、氟 F |
| 可变 | 碳 C（+2、+4）；硫 S（−2、+4、+6）；氮 N（−3、+2、+4、+5） |

**单质中元素的化合价为 0。** 化合物中各元素正负化合价的代数和为 0。

## 二、常见原子团

| 名称 | 符号 | 化合价 |
|---|---|---|
| 铵根 | NH₄ | +1 |
| 氢氧根 | OH | −1 |
| 硝酸根 | NO₃ | −1 |
| 碳酸氢根 | HCO₃ | −1 |
| 硫酸根 | SO₄ | −2 |
| 碳酸根 | CO₃ | −2 |
| 高锰酸根 / 锰酸根 | MnO₄ | −1 / −2 |

原子团在化学式中作为一个整体；个数大于 1 时加括号，括号外写个数：Ca(OH)₂、Al₂(SO₄)₃、(NH₄)₂SO₄。

## 三、化学式的书写与读法

**书写四步**：正价在前、负价在后 → 化合价绝对值交叉写在右下角 → 能约简的约简 → 检查代数和为 0。

| 物质 | 推导 | 化学式 |
|---|---|---|
| 氧化铝 | Al +3，O −2 → 交叉得 Al₂O₃ | Al₂O₃ |
| 硫酸铝 | Al +3，SO₄ −2 → Al₂(SO₄)₃ | Al₂(SO₄)₃ |
| 氢氧化钙 | Ca +2，OH −1 → Ca(OH)₂ | Ca(OH)₂ |
| 氯化亚铁 / 氯化铁 | Fe +2 / +3，Cl −1 | FeCl₂ / FeCl₃ |
| 硫酸铵 | NH₄ +1，SO₄ −2 | (NH₄)₂SO₄ |
| 碳酸钠 | Na +1，CO₃ −2 | Na₂CO₃ |

**读法**：两种元素组成的化合物一般读作"某化某"（如 NaCl 氯化钠），含原子团的读作"某酸某"（如 CuSO₄ 硫酸铜）或"氢氧化某"（如 NaOH 氢氧化钠）；铁显 +2 价时读"亚铁"。

**化学符号中数字的含义**（子类型 HS06）

| 符号 | 数字的位置 | 含义 |
|---|---|---|
| 2H | 符号前 | 2 个氢原子 |
| H₂ | 右下角 | 1 个氢分子中含 2 个氢原子（H₂ 也表示氢气） |
| 2H₂ | 符号前 + 右下角 | 2 个氢分子，每个分子含 2 个氢原子 |
| Mg²⁺ | 右上角 | 1 个镁离子带 2 个单位正电荷（数字在前、正负号在后） |
| 化合价 +2 标在 Mg 正上方 | 正上方 | 镁元素的化合价为 +2（正负号在前、数字在后） |

## 四、配平方法

**铁律：只改化学计量数（式子前面的数字），不改化学式。**

**1. 最小公倍数法**：找两边各出现一次、个数相差较大的原子，取最小公倍数。

> P + O₂ → P₂O₅：氧原子 2 与 5 的最小公倍数是 10 → P₂O₅ 配 2、O₂ 配 5 → P 配 4
> 4P + 5O₂ ==点燃== 2P₂O₅

**2. 奇数配偶法**：某种原子在一边是奇数、另一边是偶数，先把奇数配成偶数。

> KClO₃ → KCl + O₂：氧原子左边 3（奇数）→ KClO₃ 配 2 → 氧原子 6 → O₂ 配 3 → KCl 配 2
> 2KClO₃ ==MnO₂、△== 2KCl + 3O₂↑

**3. 观察法**：从化学式比较复杂的物质入手推其他物质。

> Fe₂O₃ + CO → Fe + CO₂：每个 CO 夺取 1 个氧原子变成 CO₂，Fe₂O₃ 有 3 个氧原子 → CO、CO₂ 各配 3 → Fe 配 2
> Fe₂O₃ + 3CO ==高温== 2Fe + 3CO₂

**4. 定一法**：把最复杂的物质的计量数定为 1，依次推出其他物质（出现分数时最后同乘分母）。

> C₂H₅OH + O₂ → CO₂ + H₂O：定 C₂H₅OH 为 1 → CO₂ 为 2、H₂O 为 3 → 右边氧原子 2×2 + 3 = 7，左边乙醇已有 1 个 → O₂ 为 3
> C₂H₅OH + 3O₂ ==点燃== 2CO₂ + 3H₂O

## 五、初中常见化学方程式

**条件与符号规则**（子类型 HS05）：反应物中没有气体而生成物中有气体时，生成物中的气体标 ↑；溶液中的反应，反应物中没有固体而生成物中有固体时，固体标 ↓。反应物中已有气体（或固体），生成物中同状态的物质不标。

| 类别 | 化学方程式 |
|---|---|
| 制取氧气 | 2H₂O₂ ==MnO₂== 2H₂O + O₂↑ |
| 制取氧气 | 2KMnO₄ ==△== K₂MnO₄ + MnO₂ + O₂↑ |
| 燃烧 | C + O₂ ==点燃== CO₂ |
| 燃烧 | S + O₂ ==点燃== SO₂ |
| 燃烧 | 3Fe + 2O₂ ==点燃== Fe₃O₄ |
| 燃烧 | 2Mg + O₂ ==点燃== 2MgO |
| 燃烧 | CH₄ + 2O₂ ==点燃== CO₂ + 2H₂O |
| 燃烧 | 2H₂ + O₂ ==点燃== 2H₂O |
| 燃烧 | 2CO + O₂ ==点燃== 2CO₂ |
| 水的分解 | 2H₂O ==通电== 2H₂↑ + O₂↑ |
| 二氧化碳 | CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑ |
| 二氧化碳 | CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O |
| 二氧化碳 | CO₂ + H₂O = H₂CO₃ |
| 二氧化碳 | CaCO₃ ==高温== CaO + CO₂↑ |

| 金属 | Fe + CuSO₄ = FeSO₄ + Cu |

| 金属 | Fe + 2HCl = FeCl₂ + H₂↑（生成的是氯化亚铁，溶液呈浅绿色） |

## 六、高中必修起点（高一衔接段）

依据《普通高中化学课程标准日常修订版（2017 年版 2025 年修订）》必修主题 2「2.2 氧化还原反应」「2.3 电离与离子反应」。

### 6.1 离子方程式的书写：写、拆、删、查

| 步骤 | 做法 |
|---|---|
| 写 | 写出正确的化学方程式 |
| 拆 | 可溶性的强酸（HCl、H₂SO₄、HNO₃）、强碱（NaOH、KOH、Ba(OH)₂）、可溶性盐拆成离子；单质、氧化物、气体、沉淀、弱酸、弱碱、水写化学式 |
| 删 | 删去两边相同的离子 |
| 查 | 原子守恒、电荷守恒；化学计量数化为最简 |

| 反应 | 离子方程式 |
|---|---|
| 碳酸钙与稀盐酸 | CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑ |
| 铁与硫酸铜溶液 | Fe + Cu²⁺ = Fe²⁺ + Cu |
| 铁与稀盐酸 | Fe + 2H⁺ = Fe²⁺ + H₂↑（不是 Fe³⁺） |
| 氯化铁溶液腐蚀铜 | 2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺ |
| 氯化钡与硫酸钠溶液 | Ba²⁺ + SO₄²⁻ = BaSO₄↓ |
| 强酸与强碱生成可溶性盐和水 | H⁺ + OH⁻ = H₂O |

常见错误（子类型 HS07）："Fe³⁺ + Cu = Fe²⁺ + Cu²⁺"原子守恒但电荷不守恒（左 +3、右 +4）；碳酸钙拆成 Ca²⁺ 和 CO₃²⁻（碳酸钙是沉淀，不拆）。

### 6.2 电子转移的表示：双线桥（子类型 HS08）

> 2Na + Cl₂ ==点燃== 2NaCl：Na 由 0 升到 +1，失去 2 × e⁻；Cl 由 0 降到 −1，得到 2 × e⁻。

线桥从反应物中的某元素指向生成物中的同种元素，桥上注明"得到"或"失去"与电子数；得失电子总数必须相等。
