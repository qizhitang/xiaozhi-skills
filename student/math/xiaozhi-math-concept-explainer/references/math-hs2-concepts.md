## 一、高中必修·平面向量及其应用

**1. 数量积的结果是一个数（B19）**

```
类比：力做的功
  用力 F 拉箱子移动了位移 s，力做的功 W = |F||s|cos θ（θ 是力与位移的夹角）
  力、位移都是向量，功却只有大小、没有方向——数量积 a·b = |a||b|cos θ 也是这样，结果是一个数

检验："a·b 的结果是向量还是数？由 a·b = 0 能推出 a = 0 或 b = 0 吗？"
  （是数；不能——两个非零向量互相垂直时，数量积也是 0）

⚠️ 边界：实数乘法的规律不能全搬过来。
   消去律不成立：a·b = a·c（a ≠ 0）推不出 b = c，只能推出 a 与 b − c 垂直；
   结合律不成立：(a·b)c 是与 c 共线的向量，a(b·c) 是与 a 共线的向量，一般不相等。
```

```verify
{"claim": "a = (1, 0)、b = (0, 1)、c = (1, 1)：(a·b)c = (0, 0)，a(b·c) = (1, 0)，两者不等；a = (1, 0)、b = (2, 3)、c = (2, −5) 时 a·(b − c) = 0", "expr": "[(1 * 0 + 0 * 1) * 1, (1 * 0 + 0 * 1) * 1, 1 * (0 * 1 + 1 * 1), 0 * (0 * 1 + 1 * 1), 1 * (2 - 2) + 0 * (3 - -5)]", "expect": [0, 0, 1, 0, 0]}
```

**2. 投影向量：向量的"影子"（B19）**

```
图解：把 a、b 的起点放在一起，从 a 的终点向 b 所在的直线作垂线，
  从起点到垂足的向量，就是 a 在 b 上的投影向量，等于 (|a|cos θ)·e（e 是与 b 同方向的单位向量）

检验："a = (2, 1)，b = (3, 0)，a 在 b 上的投影向量是什么？"（(2, 0)）

⚠️ 边界：夹角是钝角时 cos θ < 0，投影向量与 b 方向相反——影子落到了反方向。
   课标把投影放在数量积之后，建议借助几何直观理解（课标案例 9 向量投影）。
```

```verify
{"claim": "a = (2, 1)、b = (3, 0)：|a|cos θ = a·b/|b| = 6/3 = 2，投影向量为 2e = (2, 0)", "expr": "(2 * 3 + 1 * 0) / 3", "expect": 2}
```

**3. 夹角为钝角：还要排除反向共线（B19）**

```
逐步拆分：
  ① 向量夹角 θ 的范围是 [0, π]
  ② a·b < 0 ⇔ cos θ < 0 ⇔ θ ∈ (π/2, π]——这里包含了 θ = π，也就是两个向量反向共线
  ③ 所以"夹角为钝角" ⇔ a·b < 0，且 a、b 不反向共线

检验："a = (1, 1)，b = (λ, −2)，a 与 b 的夹角为钝角，λ 的取值范围是什么？"
  （a·b = λ − 2 < 0，得 λ < 2；λ = −2 时 b = −2a，两个向量反向，要去掉。所以 λ < 2 且 λ ≠ −2）
```

```verify
{"claim": "λ = −2 时 a·b = −4 < 0，但 x₁y₂ − x₂y₁ = 0，两向量反向共线；λ = 0 时 a·b = −2 < 0 且不共线，夹角是钝角", "expr": "[1 * -2 + 1 * -2, 1 * -2 - -2 * 1, 1 * 0 + 1 * -2, 1 * -2 - 0 * 1]", "expect": [-4, 0, -2, -2]}
```

**4. 共线与垂直的坐标条件（B19）**

```
对照：a = (x₁, y₁)，b = (x₂, y₂)
  共线：x₁y₂ − x₂y₁ = 0   ——由 b = λa（a ≠ 0）推出
  垂直：x₁x₂ + y₁y₂ = 0   ——由 a·b = 0 推出

检验："(1, 2) 与 (2, 4)、(1, 2) 与 (−2, 1)，哪一对共线，哪一对垂直？"（前一对共线，后一对垂直）

⚠️ 边界：零向量与任何向量都共线；两个条件记混时，回到它们各自的来源重推一遍，比背口诀可靠。
```


**5. 已知两边和其中一边的对角：可能有两个解（B20）**

```
图解：已知角 A、边 b（= AC）和边 a（= BC）
  先画出角 A 和边 AC，再以 C 为圆心、a 为半径画弧，弧与角 A 的另一边有几个交点，三角形就有几个
  A 为锐角时，C 到那条边的距离是 b sin A：
    a < b sin A：没有交点，无解
    a = b sin A：相切，一解（直角三角形）
    b sin A < a < b：两个交点，两解
    a ≥ b：一解

检验："A = 30°，a = 1，b = √3，B 等于多少？"（b sin A = √3/2 < 1 < √3，两解：B = 60° 或 120°）

⚠️ 边界：从代数上看，sin 在 (0, π) 上不是一一对应的，sin B = √3/2 对应 60° 和 120° 两个角；
   求出以后用"大边对大角"或内角和小于 180° 检验，不能只取锐角。
```

```verify
{"claim": "A = 30°、a = 1、b = √3：b sin A = √3/2，介于 a 与 b 之间的条件 b sin A < a < b 成立，两解", "expr": "[Math.sqrt(3) * Math.sin(Math.PI / 6), Math.sqrt(3) * Math.sin(Math.PI / 6) < 1, 1 < Math.sqrt(3)]", "expect": [0.8660254037844386, true, true]}
```

**6. 余弦定理：勾股定理的推广（B20）**

```
逐步拆分：
  ① 直角三角形：C = 90° 时，c² = a² + b²
  ② 一般三角形：c² = a² + b² − 2abcos C；C = 90° 时 cos C = 0，就回到勾股定理
  ③ 什么时候用：已知两边及其夹角求第三边，或已知三边求角
  ④ 从哪里来（课标：借助向量的运算，探索三角形边长与角度的关系）：
     AB = CB − CA，两边平方，得 |AB|² = a² + b² − 2abcos C

检验："a = 3，b = 5，C = 60°，c 等于多少？C 是钝角时，c² 比 a² + b² 大还是小？"
  （c² = 19，c = √19；钝角时 cos C < 0，c² 比 a² + b² 大）

⚠️ 边界：记不清中间是加还是减时，拿 C = 90°（回到勾股定理）和 C 为钝角（c 应当最长）检查一下，就能找回来。
```

```verify
{"claim": "a = 3、b = 5：C = 60° 时 c² = 19；C = 120° 时 c² = 49，大于 a² + b² = 34", "expr": "[9 + 25 - 2 * 3 * 5 * Math.cos(Math.PI / 3), 9 + 25 - 2 * 3 * 5 * Math.cos((2 * Math.PI) / 3), 9 + 25]", "expect": [19, 49, 34]}
```

## 二、高中必修·复数

**7. 复数：让 x² = −1 有解（B21）**

```
类比：数系的扩充
  自然数里 2 − 3 没有结果   → 引进负数，有了整数
  整数里 1 ÷ 3 没有结果     → 引进分数，有了有理数
  有理数里 x² = 2 没有解   → 引进无理数，有了实数
  实数里 x² = −1 没有解    → 引进虚数单位 i（i² = −1），有了复数
  每一次扩充，原来的运算规律都尽量保留下来

检验："z = 3 − 4i 的实部、虚部各是多少？a + bi 什么时候是纯虚数？"
  （实部 3，虚部 −4；a = 0 且 b ≠ 0 时）

⚠️ 边界：扩充到复数以后，"比大小"没有保留下来——两个复数只能说相等或不相等，
   都是实数时才比较大小。复数的引入过程见课标案例 10。
```

```verify
{"claim": "i² = (0 + 1i)(0 + 1i) = −1 + 0i", "expr": "[0 * 0 - 1 * 1, 0 * 1 + 1 * 0]", "expect": [-1, 0]}
```

**8. 复数的几何意义（B21）**

```
图解：复数 z = a + bi ↔ 复平面内的点 Z(a, b) ↔ 向量 OZ
  |z| 就是点 Z 到原点的距离：|3 + 4i| = 5
  共轭复数 a − bi 对应的点与 Z 关于实轴对称
  复数的加法、减法对应向量的加法、减法

检验："复数 −2 + i 对应的点在第几象限？它的模是多少？"（第二象限，√5）
```

```verify
{"claim": "|3 + 4i| = 5；|−2 + i|² = 5", "expr": "[Math.hypot(3, 4), Math.hypot(-2, 1) ** 2]", "expect": [5, 5]}
```

**9. 复数的除法：把分母变成实数（B21）**

```
类比：初中的分母有理化
  1/(√2 − 1)：分子分母同乘 √2 + 1，分母变成 (√2)² − 1 = 1
  (1 + i)/(1 − i)：分子分母同乘分母的共轭复数 1 + i，分母变成 1² − i² = 2，结果是 2i/2 = i

检验："(3 + i)/(1 + i) 等于多少？"（分子分母同乘 1 − i：(4 − 2i)/2 = 2 − i）

⚠️ 边界：分子也要乘；(a + bi)(a − bi) = a² + b²，是一个非负实数。
   可以把结果乘回去检查：(2 − i)(1 + i) = 3 + i。
```

```verify
{"claim": "(3 + i)(1 − i) = 4 − 2i，除以 2 得 2 − i；回代 (2 − i)(1 + i) = 3 + i", "expr": "[3 * 1 - 1 * -1, 3 * -1 + 1 * 1, 2 * 1 - -1 * 1, 2 * 1 + -1 * 1]", "expect": [4, -2, 3, 1]}
```

## 三、高中必修·立体几何初步

**10. 判定定理的条件为什么缺一不可（B22）**

```
借助长方体和身边的实物（课标：借助长方体，通过直观感知、操作确认了解判定定理）
  线面垂直：直线要垂直于平面内的两条"相交"直线
    反例：地面上画两条平行线，一根斜靠的木棍可以同时与这两条线垂直，却不垂直于地面
  线面平行：平面"外"的一条直线与平面内的一条直线平行
    如果这条直线本来就在平面内，就谈不上与平面平行

检验："一条直线垂直于平面内的两条直线，它一定垂直于这个平面吗？"（不一定，这两条直线必须相交）

⚠️ 边界：必修阶段，判定定理只要求直观感知、操作确认，性质定理要求证明；
   判定定理的论证放在选择性必修，用向量方法完成。
```

**11. 平面里成立的，空间里不一定成立（B22）**


**12. 锥体体积的 1/3，以及球的两个公式（B23）**

```
类比：倒水实验
  等底等高的圆锥形杯子装满水，倒进圆柱形杯子，倒三次正好倒满——圆锥的体积是圆柱的 1/3
  棱锥与等底等高的棱柱也是这样：V锥 = (1/3)Sh，V柱 = Sh

球的两个公式可以一起记：
  把球面分成很多很小的块，每一块和球心连成一个"小锥体"，高都约等于半径 R
  体积 ≈ (1/3) × 表面积 × R：(4/3)πR³ = (1/3) × 4πR² × R

检验："底面半径 3、高 4 的圆锥，体积与侧面积各是多少？"（体积 12π；母线长 5，侧面积 15π）

⚠️ 边界：倒水实验和"小锥体"只帮助记忆，不是证明；课标对这些公式的要求是"知道"并会用。
   圆锥的侧面展开图是扇形，扇形的半径是母线 l，不是高 h：侧面积 = (1/2) × 2πr × l = πrl。
```


## 四、高中必修·概率

**13. 列样本点：先让它们等可能（B24）**

```
类比：给两枚硬币编号
  一枚一元、一枚五角，"一元正、五角反"和"一元反、五角正"是两件不同的事
  所以样本空间是 {正正, 正反, 反正, 反反}，四个样本点等可能

检验："掷两枚均匀的硬币，'一正一反'的概率是多少？"（1/2）

⚠️ 边界：古典概型要求样本点有限、等可能；把"一正一反"合成一个样本点以后，三个样本点不再等可能，
   就不能用"个数之比"算概率。掷骰子问题见课标案例 12。
```

```verify
{"claim": "四个等可能的样本点中，一正一反占两个，概率 1/2", "expr": "2 / 4", "expect": 0.5}
```

**14. 互斥与独立：两回事（B25）**

```
对照：
  互斥：A、B 不能同时发生，P(AB) = 0，此时 P(A ∪ B) = P(A) + P(B)
  对立：互斥，并且两者必有一个发生，P(A) + P(B) = 1
  独立：一个发生与否不影响另一个的概率，P(AB) = P(A)P(B)

检验："两个概率都大于 0 的事件如果互斥，它们可能相互独立吗？"
  （不可能：互斥时 P(AB) = 0，而 P(A)P(B) > 0）

⚠️ 边界：生活里说的"没关系"不能代替定义，要用 P(AB) = P(A)P(B) 验证（课标：结合有限样本空间，了解两个随机事件独立性的含义）。
```

```verify
{"claim": "掷一枚骰子，A = 偶数、B = 不超过 2：P(AB) = 1/6 = P(A)P(B)，独立而不互斥；C = 1 点、D = 2 点：互斥，P(C)P(D) = 1/36 ≠ 0，不独立", "expr": "[(1 / 2) * (1 / 3), 1 / 6, (1 / 6) * (1 / 6) === 0]", "expect": [0.16666666666666666, 0.16666666666666666, false]}
```

**15. 频率与概率（—）**

```
类比：抛硬币
  抛 10 次，可能 6 次正面（频率 0.6），再抛 10 次，可能只有 4 次（频率 0.4）——频率随试验而变
  概率是一个确定的数；试验次数很多时，频率会稳定在概率附近，所以可以用频率估计概率

检验："抛一枚均匀的硬币 10 次，一定正好 5 次正面吗？"（不一定；抛的次数越多，正面出现的频率一般会越稳定地在 0.5 附近摆动，但不保证每多抛一次就更接近）

⚠️ 边界：用频率估计概率要有足够多的试验次数；可以用计算器或计算机产生随机数来模拟（课标教学提示）。
```

## 五、高中必修·统计

**16. 直方图的纵轴是"频率/组距"（B26）**

```
图解：频率分布直方图里，小矩形的面积 = 组距 × 高 = 频率
  所以高 = 频率/组距；所有小矩形的面积加起来等于 1

检验："组距为 5，某一组小矩形的高是 0.04，这一组的频率是多少？"（5 × 0.04 = 0.2）

⚠️ 边界：直接把"高"读成频率，会把频率读错；组距不同的两组，更不能靠比高度来比频率。
```

```verify
{"claim": "组距 5、高 0.04 的小矩形表示频率 0.2", "expr": "5 * 0.04", "expect": 0.2}
```

**17. 百分位数（B26）**

```
逐步拆分（取法以学生所用教材为准，下面是常见教材的取法）：
  ① 把 n 个数据从小到大排列
  ② 计算 i = n × p%
  ③ i 不是整数：比 i 大的最小整数为 j，第 j 个数据就是第 p 百分位数
     i 是整数：取第 i 个与第 i + 1 个数据的平均数
  中位数就是第 50 百分位数

检验："数据 3, 5, 6, 8, 9, 10, 12, 15 的第 25 百分位数与第 70 百分位数各是多少？"
  （n = 8：8 × 25% = 2，取第 2、3 个数的平均数 5.5；8 × 70% = 5.6，取第 6 个数 10）

⚠️ 边界：百分位数的含义是"大约有 p% 的数据不超过它"（课标：理解百分位数的统计含义，参见案例 14 阶梯电价的设计）。
```

**18. 分层随机抽样估计总体均值：按样本量加权（B08）**
