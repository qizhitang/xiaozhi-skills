# 五大应用题题型建模框架与数量关系速查表

> 适用学段：初中（7-9 年级）。
> 示例题验算：2026-09-03
> 本表只解决"文字→等式"这一步；等式列出来之后的解与验算转 `xiaozhi-math-problem-solving-coach`。

---

## 一、建模通用三步框架（每种题型都适用）

```
Step 1  识别数量
  → 列出题目中所有出现的"量"（速度/时间/路程/浓度/人数……）
  → 标出哪些已知，哪些未知

Step 2  用文字描述关系
  → 不写公式，用普通话描述两个量之间的关系
  → 示例："甲的路程加上乙的路程等于总距离"

Step 3  翻译成数学表达式
  → 设未知数 → 用Step 2的文字关系写等式
  → 列出方程
```

## 二、行程问题建模框架

### 核心公式
```
路程 = 速度 × 时间
```

### 三种经典情形

| 情形 | 关系式 | 示意 |
|-----|-------|-----|
| 相向而行（相遇） | 甲路程 + 乙路程 = 总距离 | ←A  B→ |
| 同向而行（追及） | 快者路程 - 慢者路程 = 初始差距 | →A  →B（A追B） |
| 来回同一地点 | 去程路程 = 回程路程 | 特殊：速度不同时间不同 |

### 设元建议
- 设"时间"为x：当速度已知，求相遇/追及时间
- 设"距离"为x：当速度和时间已知，求某段距离
- 设"速度"为x：当距离和时间已知，求速度

### 常见陷阱
```
陷阱①：单位不统一（小时vs分钟，km/h vs m/s）
检验："题目里时间用的是什么单位？速度用的是什么单位？统一了吗？"

陷阱②：顺流/逆流（水流问题变体）
顺流速度 = 船速 + 水速
逆流速度 = 船速 - 水速
```

## 三、工程问题建模框架

### 核心公式
```
工作量 = 工作效率 × 工作时间
（设总工作量为1）
```

### 关键设定
```
设总工作量 = 1（标准做法）
→ 甲独立完成需N天，甲每天效率 = 1/N
→ 甲乙合作每天效率 = 1/N₁ + 1/N₂
```

### 建模步骤
```
① 设总工作量为1
② 写出每个人（或每台机器）的日效率 = 1/完成天数
③ 写出合作效率 = 各效率之和
④ 等式：合作效率 × 合作天数 = 1（总工作量）
```

### 常见变体
| 变体类型 | 关系式调整 |
|---------|----------|
| 甲做了一部分后乙加入 | 甲×t₁ + (甲+乙)×t₂ = 1 |
| 交替工作 | 每轮完成量 × 轮数 = 1 |
| 甲比乙快N天 | 设乙需要t天，甲需要t-N天 |

## 四、浓度（混合）问题建模框架

### 核心关系
```
溶质量 = 溶液量 × 浓度

守恒的总原则：**溶质守恒 + 溶液守恒**
  混合前各溶液的溶质之和 = 混合后的溶质总量
  混合前各溶液的质量之和 = 混合后的溶液总量

三种操作各自守恒的量不同——不要一律套"只加水不加溶质"：
  ① 加水稀释   → 溶质不变，溶液变大
  ② 加纯溶质   → 溶剂不变，溶质变大、溶液也变大
  ③ 两种溶液混合 → 溶质**相加**（不是不变），溶液也相加
  ④ 蒸发水     → 溶质不变，溶液变小
```

### 建模步骤
```
① 识别：操作前后各有多少溶液？各是什么浓度？
② 判断操作属于上面①②③④中的哪一种
③ 按该操作真正守恒的量列方程：
   加水/蒸发：操作前溶质量 = 操作后溶质量
   加纯溶质：操作前溶质量 + 加入量 = 操作后溶质量
   两液混合：溶液1溶质 + 溶液2溶质 = 混合后溶质
             且 溶液1质量 + 溶液2质量 = 混合后质量（两个式子常要联立）
```

### 追问检验
```
"这道题是加水、加纯溶质、还是把两种溶液倒在一起？
 这三种情况里，溶质的总量分别是不变、变大、还是相加？
 溶液的总量呢？
 先把这两句答出来，再列式。"

⚠️ 最常见的错法：两种溶液混合时套用"溶质不变"，
   得到一个恒等式或矛盾式。混合题的溶质是**相加**。
```

## 五、利润问题建模框架

### 核心公式链
```
利润 = 售价 - 成本
利润率 = 利润 ÷ 成本 × 100%
售价 = 成本 × (1 + 利润率)
折扣后售价 = 标价 × 折扣系数（如八折 = ×0.8）
```

### 常见混淆点
| 概念 | 说明 | 追问 |
|-----|-----|-----|
| 成本 vs 标价 | 标价≠成本，标价是定的价，成本是买入价 | "题目说的是在什么价格基础上打折？" |
| 利润 vs 利润率 | 利润是金额，利润率是百分比 | "题目求的是赚了多少钱还是赚了百分之几？" |
| 亏损 | 利润为负数 | "售价小于成本时，利润是正还是负？" |

## 六、增长率问题建模框架

### 增长率题的唯一模型（初中）

```
连续增长（每次以上一次的量为基数）：
  增长 n 次后的量 = 原量 × (1+增长率)ⁿ

```verify
{"claim": "复利模型：100 连续两次增长 10% 得 121", "expr": "100 * Math.pow(1 + 0.1, 2)", "expect": 121}
```

```verify
{"claim": "错误模型 原量×增长率×次数 得不到 121（中考高频错误 a(1+2x)）", "expr": "100 * (1 + 0.1 * 2) === 121", "expect": false}
```
  下降就把 + 换成 −：原量 × (1−下降率)ⁿ

初中出现的"平均增长率""年均增长率"题**一律是这一种**。
n=2 时列出的是 a(1+x)² = b。
```

> ⚠️ **不要写"简单增长 = 原量 × 增长率 × 次数"这条公式。**
> 它会把学生引向 a(1+2x) = b 这个高频错解。
> 展开对比：a(1+x)² = a(1+2x+x²)，比 a(1+2x) 多出 ax²，
> 多出来的正是"第一次增长出来的那部分在第二次也参与了增长"。
>
> 确实按固定数额叠加的题（如"每年固定增加 5 万件"），题目会直接给**增加的数量**而不是**增长率**，
> 那时用 a + 5n，不涉及增长率，不属于本节模型。

### 建模步骤
```
① 确认题目给的是"增长率"（百分数/字母 x）还是"每次固定增加的数量"
   → 给增长率 → 用 a(1+x)ⁿ
   → 给固定数量 → 直接加，不用本节公式
② 设增长率为 x（或设初始量为 x）
③ 写出 n 次增长后的量：a(1+x)ⁿ
④ 令它等于已知的最终量，列方程
⑤ 解出后检验：增长率应为正且合理（如 x=−3 这类要舍去）
```

### 追问
```
"第二次增长的时候，基数是最开始的量，还是第一次增长完的量？"
（初中题一律是后者）

"那 a(1+2x) 算的是什么？它和 a(1+x)² 差在哪一块？"
（让学生自己展开一次，看到差的是 ax²）
```

## 七、数量关系识别速查卡

收到应用题后，30秒内完成以下识别：

```
□ 有没有"运动/速度/时间"相关词？→ 行程类
□ 有没有"完成/效率/共同"相关词？→ 工程类
□ 有没有"浓度/溶液/加水/混合"相关词？→ 浓度类
□ 有没有"进价/售价/利润/折扣"相关词？→ 利润类
□ 有没有"增长/减少/每年"相关词？→ 增长率类
□ 以上都不是？→ 设元找等量关系，用通用三步框架
```
