## 一、高中选择性必修·数列

**例 1　由 Sₙ 求 aₙ，再用错位相减求和**

题目：数列 {aₙ} 的前 n 项和 Sₙ = 2ⁿ − 1。(1) 求 aₙ；(2) 求数列 {n·aₙ} 的前 n 项和 Tₙ。

- 最容易卡：直接写 aₙ = Sₙ − Sₙ₋₁，不检验 n = 1（B27）；想不到错位相减（M16）。
- 追问："aₙ = Sₙ − Sₙ₋₁ 对 n = 1 成立吗？a₁ 怎么求？{n·aₙ} 是一个等差数列与一个等比数列对应项相乘，把 Tₙ 乘以公比 2 再相减，会怎样？"
- 要点：(1) a₁ = S₁ = 1；n ≥ 2 时 aₙ = (2ⁿ − 1) − (2ⁿ⁻¹ − 1) = 2ⁿ⁻¹；a₁ = 1 也满足，所以 aₙ = 2ⁿ⁻¹（这一题 a₁ 恰好满足；如果 Sₙ = 2ⁿ，a₁ = 2 就不满足 aₙ = 2ⁿ⁻¹，要分段写）。(2) Tₙ = 1 × 1 + 2 × 2 + … + n × 2ⁿ⁻¹，2Tₙ = 1 × 2 + 2 × 2² + … + n × 2ⁿ，两式相减得 −Tₙ = (1 + 2 + … + 2ⁿ⁻¹) − n × 2ⁿ = 2ⁿ − 1 − n × 2ⁿ，所以 Tₙ = (n − 1) × 2ⁿ + 1。

```verify
{"claim": "例 1：由 Sₙ 算出的 a₁～a₃ 为 1、2、4；n = 1～6 时 Σk·2ᵏ⁻¹ 都等于 (n − 1)·2ⁿ + 1", "expr": "[[1, 2, 3].map((n) => (2 ** n - 1) - (2 ** (n - 1) - 1)), [1, 2, 3, 4, 5, 6].every((n) => Array.from({ length: n }, (_, i) => (i + 1) * 2 ** i).reduce((s, x) => s + x, 0) === (n - 1) * 2 ** n + 1)]", "expect": [[1, 2, 4], true]}
```

## 二、高中选择性必修·一元函数导数及其应用

**例 2　"在点 P 处"与"过点 P"的切线**

题目：已知曲线 y = x³。(1) 求曲线在点 (1, 1) 处的切线方程；(2) 求曲线过点 (1, 1) 的切线方程。

- 最容易卡：(2) 直接照抄 (1) 的答案。先请学生复述两问分别问的是什么：复述时把"过点"说成"在点"、指出后立刻会做的归 R10；复述对、却说不出两种切线有什么不同的归 B28。
- 追问："(1) 和 (2) 的说法有什么不同？(2) 里点 (1, 1) 一定是切点吗？如果切点是 (t, t³)，切线方程怎么写？"
- 要点：(1) y′ = 3x²，斜率为 3，切线为 y = 3x − 2。(2) 设切点 (t, t³)，切线 y − t³ = 3t²(x − t) 过 (1, 1)：1 − t³ = 3t²(1 − t)，整理得 2t³ − 3t² + 1 = 0，即 (t − 1)²(2t + 1) = 0，t = 1 或 t = −1/2。切线为 y = 3x − 2 或 y = (3/4)x + 1/4。

题目：讨论函数 f(x) = x − aln x 的单调性。

**例 4　恒成立问题**

题目：若不等式 eˣ ≥ ax 对任意 x ∈ (0, +∞) 恒成立，求实数 a 的取值范围。

- 最容易卡：把"恒成立"当成"存在"（R08）；不会分离参数，或分离后比错了最大值与最小值（M13）。

## 三、高中选择性必修·空间向量与立体几何

**例 6　用空间向量求线面角**

题目：在直三棱柱 ABC-A₁B₁C₁ 中，∠BAC = 90°，AB = AC = AA₁ = 2。求直线 A₁B 与平面 BCC₁B₁ 所成角的正弦值。

- 最容易卡：没有说明三条棱两两垂直就建系（M11）；法向量解错（C16）；把 1/2 当成了余弦（B31）。
- 追问："哪三条直线两两垂直？凭什么？平面 BCC₁B₁ 里取哪两个不共线的向量？求出来的 |cos⟨A₁B, n⟩| 是线面角的正弦还是余弦？"
- 要点：直三棱柱中 AA₁ ⊥ 底面，又 AB ⊥ AC，所以 AB、AC、AA₁ 两两垂直，以 A 为原点建系：B(2, 0, 0)、C(0, 2, 0)、A₁(0, 0, 2)、B₁(2, 0, 2)。A₁B = (2, 0, −2)；BC = (−2, 2, 0)，BB₁ = (0, 0, 2)，取法向量 n = (1, 1, 0)。sin θ = |A₁B·n| / (|A₁B||n|) = 2/(2√2 × √2) = 1/2。


**例 7　用空间向量求二面角**

题目：在棱长为 2 的正方体 ABCD-A₁B₁C₁D₁ 中，求二面角 A₁-BD-C 的余弦值。

- 最容易卡：直接把两个法向量夹角的余弦当答案，不判断二面角是锐角还是钝角（B31）；法向量解错（C16）。
- 追问："两个半平面各取什么法向量？从图上看，二面角 A₁-BD-C 是锐角还是钝角？法向量的夹角和二面角是相等还是互补？"

## 四、高中选择性必修·平面解析几何

**例 8　过圆外一点作圆的切线**

题目：过点 P(1, 2) 作圆 x² + y² = 1 的切线，求切线方程。

- 最容易卡：设 y − 2 = k(x − 1)，只求出一条——说不清斜率不存在的直线写不成这种形式的归 B32，说得清、仍然漏掉 x = 1 的归 M14。
- 追问："点 P 在圆外，过它的切线应该有几条？斜率不存在的直线 x = 1 满足条件吗？"
- 要点：1² + 2² > 1，点 P 在圆外，切线有两条。斜率不存在时，直线 x = 1 到圆心的距离是 1，等于半径，是切线；斜率存在时，由 |2 − k|/√(k² + 1) = 1 得 k = 3/4，切线为 3x − 4y + 5 = 0。

**例 9　直线与椭圆：设而不求，别忘了判别式**

题目：已知椭圆 x²/4 + y² = 1，直线 y = x + m 与椭圆交于 A、B 两点。(1) 求 m 的取值范围；(2) 是否存在 m，使线段 AB 中点的横坐标为 −2？

- 最容易卡：联立后硬解交点坐标（M14）；求出 m = 5/2 就作答，不检验判别式（M14）；消元、去括号时算错（纯净版会做的沿用第二节的 C01—C05）。
- 追问："联立以后，x₁ + x₂ 能不能不解方程就写出来？求出的 m 能保证直线与椭圆有两个交点吗？"
- 要点：联立得 5x² + 8mx + 4m² − 4 = 0。(1) Δ = 64m² − 20(4m² − 4) = 80 − 16m² > 0，得 −√5 < m < √5。(2) 中点横坐标 (x₁ + x₂)/2 = −4m/5 = −2，得 m = 5/2；但 (5/2)² = 25/4 > 5，此时 Δ < 0，直线与椭圆没有交点，所以不存在这样的 m。

## 五、高中选择性必修·计数原理

**例 10　相邻、不相邻与"有没有顺序"**

题目：5 名同学站成一排照相。(1) 甲、乙必须相邻，有多少种站法？(2) 甲、乙不相邻，有多少种站法？(3) 从这 5 人中选 3 人参加座谈会，甲必须参加，有多少种选法？如果选出的 3 人分别担任三项不同的工作，甲必须入选，有多少种安排？

- 最容易卡：相邻、不相邻用错方法（M15）；(3) 两问都用组合或都用排列（B34）。
- 追问："把甲、乙'捆'在一起，算几个元素？他们俩内部还能换位置吗？不相邻时，先排谁、再把甲乙插到哪里？(3) 交换选出的人的顺序，算不算不同的结果？"
- 要点：(1) 捆绑：2 × 4! = 48。(2) 插空：先排其余 3 人，3! = 6，再把甲、乙插进 4 个空中的 2 个，4 × 3 = 12，共 72（也可以 120 − 48 = 72）。(3) 座谈会与顺序无关：C₄² = 6；三项不同工作与顺序有关：先给甲安排工作 3 种，再从其余 4 人中选 2 人担任另两项 A₄² = 12，共 36。

```verify
{"claim": "例 10：48；72 = 120 − 48；C₄² = 6；3 × A₄² = 36", "expr": "[2 * 24, 6 * 4 * 3, 120 - 48, (4 * 3) / 2, 3 * 4 * 3]", "expect": [48, 72, 72, 6, 36]}
```

## 六、高中选择性必修·概率与统计
