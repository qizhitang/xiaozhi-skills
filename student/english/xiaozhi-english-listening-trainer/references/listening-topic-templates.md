# 听力话题模板与材料生成指南

> 适用学段：小学高段与初中（7-9 年级）。语速与生词密度以中考听力为锚，不使用高中/母语者语速档。

> 本文档为 `xiaozhi-english-listening-trainer` 的配套参考资源，提供分学段分兴趣话题的听力材料生成模板、调节维度参数与提示词框架。
>
> **两个参数只有一套口径，见 §五：**
> - 生词密度：≤ 2-3%（换算成个数：3-8 个新词/次）
> - 语速：小学高段 90-100 / 初一 100 / 初二 110 / 初三 120 wpm

---

## 一、话题分类体系

### 三大场景分类

```
场景①：校园场景（最熟悉、最常见）
  → 学生每天接触，词汇可及度高
  → 适合入门级和日常练习

场景②：生活场景（较熟悉、需一定策略表达）
  → 购物/家庭/出行等日常活动
  → 适合进阶级练习

场景③：信息获取场景（有认知挑战）
  → 天气预报/学校通知/旅行公告
  → 适合训练"从听中提取关键信息"的能力
```

## 二、校园场景话题模板

### 话题①：课堂讨论（Classroom Discussion）

**适用学段：** 初中及以上

**材料生成参数：**

```
话题关键词：teacher, student, question, discuss, opinion, explain
语速：初一100词/分 | 初二110词/分 | 初三120词/分
句长：初一8-12词/句 | 初二10-14词/句 | 初三12-16词/句
生词密度：≤2-3%（约 3-8 个新词，见 §五维度②）
```

**材料结构模板：**

```
开头（30秒）：引入话题
  "Today in class, we're going to talk about [topic].
   Let me first ask—what do you already know about this?"

主体（2分钟）：讨论展开
  - 老师提出问题
  - 学生A回答（简单观点）
  - 老师追问或补充
  - 学生B提出不同意见
  - 讨论逐步深入

结尾（30秒）：总结或思考题
  "So, what we discussed today is...
   Think about this question for next time: [问题]"
```

**示例片段（初二难度）：**

```
Teacher: "Today we're talking about technology in education.
          Do you think computers help students learn better?"

Student A: "Yes, I think so. We can find information quickly
           and watch educational videos online."

Teacher: "That's a good point. But Student B, you seem
          to disagree. What's your opinion?"

Student B: "I think computers can be distracting.
           Sometimes students play games instead of
           doing their homework."

Teacher: "Both sides make sense. The key question is:
          How can we use technology wisely without
          letting it distract us? Think about that
          for our next class."
```

**适用学段：** 初中

```

语速：初一100词/分 | 初二110词/分

```

```
  "I think I'll join the [X] club. I'm excited to start!"
```

```
  "I'll take this one. It's perfect!
   Thank you for your help."
```

## 四、信息获取场景话题模板

### 话题⑦：天气预报（Weather Report）

**适用学段：** 初中及以上

**材料生成参数：**

```
话题关键词：temperature, sunny, cloudy, rain, forecast, degree, weekend, condition
语速：初二110词/分 | 初三120词/分
句长：初二8-12词/句 | 初三10-15词/句
生词密度：≤2%（信息密集，新词更要少，约 3-4 个）
特点：信息密集，需要快速提取关键数据
```

**材料结构模板：**

```
开头：播报格式
  "Good morning. Here's your weather forecast for today
   and the coming weekend."

主体：逐天播报
  - Today: [温度]°C, [天气状况], [特殊提醒]
  - Tomorrow: [温度]°C, [天气状况]
  - Weekend: [温度]°C, [天气状况], [出行建议]

结尾：总结提醒
  "Remember to bring an umbrella on Thursday.
   Have a great day!"
```

**训练重点：** 数字听辨（温度、时间）+ 天气词汇

## 五、调节维度详解

### 维度①：句长调节

```
句长分级标准：
  入门级（小学/初一）：6-8词/句 → 简单句为主
    例："I like basketball. It is fun."

  中级（初二）：10-14词/句 → 含1个复合句
    例："I like basketball because it helps me stay healthy and active."

  高级（初三）：12-16词/句 → 含 1-2 个从句
    例："Although I used to watch sports on TV,
         I have started playing basketball every weekend,
         and it has made me much more active."
    （超过 16 词/句、三层以上嵌套已越出中考听力语料，不用于初中训练）

调节方法：
  → 降低句长：拆分复合句为2-3个简单句
  → 提高句长：合并简单句，添加连接词（because, although, while）
```

### 维度②：生词密度调节（全库唯一口径）

```
生词密度上限：≤ 2-3%，任何学段都不超过。
  依据：可理解输入要求词汇覆盖率 95-98%；覆盖率低于 95%，
        学生无法靠上下文猜词，只能猜整段大意，练的不再是听力。

按材料长度换算成"新词个数"（比百分比好执行）：
  150 词材料 → 3-4 个新词
  200 词材料 → 4-6 个新词
  250 词材料 → 5-8 个新词
  一次练习的新词上限：8 个

⚠️ 不存在"初三可以到 10-15%"这一档。旧版的 8-10% / 10-15% 已废弃：
   350 词材料放 35-50 个新词，等于每两行冒出一个生词，无法完成听的任务。

调节方法：
  → 降低密度：用已学词替换新词（如 "exquisite" → "very beautiful"）
  → 提高挑战：不加新词，改为提高语速一档、或加长句子、或换成信息密集话题
  → 新词必须有上下文线索（同位解释 / 举例 / 对比 / 重复），不能孤立出现
```

### 维度③：话题熟悉度调节

```
熟悉度分级：
  高（学生日常接触的话题）：
    → 校园生活、家庭、日常活动
    → 理解难度低，适合训练流利度

  中（学生了解但不常接触的话题）：
    → 科技、环保、社会问题
    → 需要一定背景知识，适合训练推断能力

  低（学生很少接触的话题）：
    → 专业领域、抽象哲学、国际政治
    → 除非学生特别感兴趣，不建议使用

调节方法：
  → 降低难度：将话题与学生的日常生活建立连接
    例：讲"环保" → 从"你每天看到的垃圾分类"切入
  → 提高难度：引入更多专业术语和抽象概念
```

### 维度④：语速调节（以中考听力为锚，全库唯一口径）

```
锚点：各地中考听力音频普遍在 100-120 词/分钟，
      比英美母语者日常语速（约 150-180 wpm）慢一档。
      训练语速长期高于中考语速没有意义——练的是"扛难度"，不是"听懂"。

语速分级：
  小学高段：约 90-100 词/分钟
    → 短句、停顿明显、重复关键信息
  初一：约 100 词/分钟
  初二：约 110 词/分钟
  初三：约 120 词/分钟（等同中考上限）
  初三冲刺：约 120-130 词/分钟，只在学生主动要求"再快一点"时用

⚠️ 旧版的 140/160/180 词/分钟档位已废弃：160 wpm 高于中考听力语速，
   180 wpm 是母语者语速，不作为初中训练目标。

调节方法：
  → 降低语速：在关键信息前加停顿、重复核心词
  → 提高语速：减少重复、增加句子间的连接（先别急着加新词）
```

## 六、材料生成提示词框架

### 标准生成提示词

```
请生成一段英语听力材料。

参数（词数与时长必须自洽：词数 ÷ 语速 = 时长）：
- 目标学段：[小学高段/初一/初二/初三]
- 话题：[话题名称]
- 语速：[90-100 / 100 / 110 / 120 词/分钟]
- 词数：初中一次 200-250 词（约 2 分钟）；小学高段 120-150 词（约 1.5 分钟）
- 词汇范围：核心词来自学生已学词汇；生词密度 ≤2-3%
- 新词数量：[3-8] 个（按词数换算，见 §五维度②），必须在上下文中可推断含义
- 句长：[6-8 / 8-12 / 10-14 / 12-16 词/句]

结构要求：
- 开头（约 15%）：引入话题，只用熟悉词汇
- 主体（约 70%）：展开内容，新词集中在这里，每个都有上下文线索
- 结尾（约 15%）：总结或提出一个问题

输出格式：
1. 完整材料文本（末尾标注实际词数）
2. 新词注释（每个新词一句释义 + 例句）
3. 理解题 3 道（1 主旨 + 1 细节 + 1 推断），生成前按 shared/ai-item-check.md 自检：
   答案在材料中能听到、唯一、不超出该学段词汇
4. 关键句标注（2-3 个值得关注的句子结构）
```

### 卡壳诊断专用提示词

```
当学生反馈"没听懂"时，生成诊断版材料：

请将刚才的听力材料按以下方式拆解：
- 将材料分成4-5个片段，每个片段独立播放
- 每个片段标注难度级别（入门/中级/高级）
- 标注每个片段可能卡壳的原因：
  ① 词义不明（新词导致）
  ② 句子结构复杂（长句导致）
  ③ 语速/连读问题（节奏导致）
- 提供每个片段的慢速版本（在原语速上降一档，如 120 → 110 wpm）
```

## 七、话题选择决策流程

```
听力材料话题选择流程：

① 检查学习DNA → 有记录的兴趣话题？
   → YES：使用档案话题（兴趣匹配度最高）
   → NO：进入②

② 检查 growthMap.oralGrowthTrack（口语档案）→ 有最近聊过的话题？
   → YES：用同话题但不同角度的听力材料（复习+延伸）
   → NO：进入③

③ 使用本话题库 → 按学生年级选择场景类别
   → 小学高段/初一：优先校园场景①②③
   → 初二：校园+生活场景混合
   → 初三：三个场景轮换，增加信息获取场景比重（中考听力的短文理解与听填信息多取自此类）

④ 生成参数调整：
   → 第一次练习：降低难度（入门级参数）
   → 学生反馈"太简单"：提高一个难度级别
   → 学生反馈"太难"：降低难度+增加上下文线索
```
