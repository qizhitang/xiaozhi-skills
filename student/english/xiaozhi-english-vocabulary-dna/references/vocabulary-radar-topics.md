# 词汇雷达话题模板

> 适用学段：小学高段与初中（7-9 年级）。词表分档按 2022 版义教课标（1600 词）；标 ⚠高中 的分档不作为初中目标。

> 本文档为 `xiaozhi-english-vocabulary-dna` 的配套参考资源，提供新词汇雷达（模块C：课前预热）的话题分类模板、词汇分组策略与四阶段预热内容生成指南。
>
> ⚠️ **不绑定任何一版教材的单元编号与单元名**：各地在用的教材版本与修订年份不同
> （2024 秋起多地启用新版），把单元名写死会在换版后立刻失效。

> 让他把**单元词表本身**发过来，本文件只负责按话题给出扩展词与预热模板。

## 一、话题分类体系

### 分类原则

```
词汇雷达话题分类的三个维度：
  ① 课内话题：按学生发来的单元词表所属**话题**分组（最精准的课前预热来源）
  ② 考试高频：按中考高频话题分组（备考优先）
  ③ 兴趣拓展：按学生兴趣档案分组（主动学习时使用）

优先级：课内话题 > 考试高频 > 兴趣拓展
  → 学生说"下周学新课"时 → 请他发单元词表，再按话题补语境
  → 学生说"帮我备考"时 → 使用考试高频组
  → 学生主动存词/兴趣探索时 → 使用兴趣拓展组

⚠️ 任何一组都不写死教材版本或单元编号。
```

## 三、考试高频话题组

### 中考高频话题（5大类）

> 分档说明：**基础层 / 进阶层**均在 2022 版课标 1600 词范围内（中考目标）；
> **拓展层**为高考 3000 词范围 ⚠高中，初中只在学生主动问到时说明，不作为记忆目标。

#### 1. 校园与学习

```
核心词汇层：
  基础层（课标 1600 词内，必备）：class, subject, teacher, homework, exam, grade, school
  进阶层（课标 1600 词内，中考常考）：schedule, curriculum, extracurricular, scholarship, assignment
```

## 四、兴趣拓展话题组

### 动态话题库规则

```
兴趣拓展组不是固定的——它的内容来自：
  ① 学习DNA中的"兴趣DNA"字段
  ② 口语DNA中的"话题偏好"字段
  ③ 学生对话中自发提到的新兴趣

当学生存入一个新词，但这个词不属于当前任何话题组时：
  → 自动创建新话题组
  → 以该词为种子，向上扩展同领域词汇
  → 标记来源为"兴趣拓展"
```

### 常见兴趣话题模板

```
向上扩展：
```

## 五、四阶段预热内容生成模板

### Day 7（第一次见面）生成模板

```
模板：
  "📡 新词预热 · 第1天（距上课还有7天）

   下周你会遇到这些词，我们先认识一下：

   [词汇1] /[IPA 音标]/  口型提示：[一句话说清舌位/唇形]
   [词汇2] /[IPA 音标]/  口型提示：[…]
   ...

   今天任务：把这些词的发音读三遍——
   不需要记意思，只是让它们变得不陌生。"

注音规则（只有一种做法）：
  → 只用 IPA 音标
  → 音标后加一句**口型/舌位提示**，帮学生找到发音动作
  → ❌ 禁止用拼音或汉字近似音注音（"丝-ing-k""爱普"）：
     这类注音会把 /θ/ 直接教成 /s/、把词尾辅音教成带元音，
     等于亲手制造 P01（th 音替代）、P05（词尾辅音）两个顽固发音弱项
  → 学生说"我读不出来"时，给的是更细的口型说明，不是汉字谐音

示例（正确写法）：
  think /θɪŋk/    舌尖轻轻伸到上下门牙之间送气；不是 s 的位置
  very  /ˈveri/   上牙轻咬下唇内侧再送气；不是 w 的圆唇
  sit   /sɪt/     舌位比 see 低一点、放松，嘴角别拉开；结尾 t 要发出来，别加"呃"
```

### Day 5（场景联想）生成模板

```
模板：
  "📡 新词预热 · 第2天

   给这几个词配上画面——

   [词汇1]：[场景描述]
     例：achievement → 想象你站在山顶，手里举着奖杯
   [词汇2]：[场景描述]
     例：perseverance → 想象你跑了很久，终于到达终点线
   ...

   想象这个场景，把词和画面连在一起。
   下次见到这个词，画面会先出现，意思就跟着来了。"

场景联想生成规则：
  → 每个词配一个具体可感知的画面（不是抽象定义）
  → 画面要与学生日常生活可关联
  → 不使用"记住定义是XXX"的方式，而是"想象XXX场景"
```

### Day 3（轻松使用）生成模板

```
模板：
  "📡 新词预热 · 第3天

   用这3个词，和我聊3-5句话——
   随便聊，不用都用上，用到哪个算哪个：
   [词汇1] / [词汇2] / [词汇3]"

对话引导（小智侧）：
  → 开启简短英语对话，话题与词汇语义相关
  → 不强制学生必须用到所有词
  → 学生自然用到了 → 肯定："你用了[X]！这个词你已经会用了"
  → 学生没用到 → 温和提示："这里其实可以用[X]——试试？"
```

### 上课前（自信提醒）生成模板

```
模板：
  "📡 新词预热 · 最后提醒

   今天上课会遇到这些词——
   你已经见过它们[3]次了，不会陌生的。

   特别提示：[2-3个最重要的词] 可能是这节课的重点，
   注意听老师怎么用它们造句。

   加油！你已经准备好了。"
```

## 六、词汇分组策略

### 分组规则

```
每次预热最多包含 8-12 个新词：
  → 分为3组，难度递进
  → 第一组（4-5词）：最基础、最常用的词 → Day 7 必出
  → 第二组（3-4词）：进阶词，需要语境理解 → Day 5 重点
  → 第三组（2-3词）：高阶词或特殊搭配 → Day 3 深度使用

如果单元新词超过12个：
  → 分成两轮预热（Day 7-0 和 Day 7-3）
  → 第一轮：核心高频词（8个）
  → 第二轮：补充和搭配词（余下）
```

### 与"每日到期词卡"的关系

```
词汇雷达预热 ≠ 到期词卡

词汇雷达：课前几天的预热（"还没学就开始见"）
  → 目标：建立"见过"的印象，降低首次学习负担
  → 上课后：这批词进入正常的间隔重复排程

每日到期词卡：学完之后的巩固（"学了之后别忘掉"）
  → 到期日由 SM-2 按学生表现维护
  → 对外每天只有 1 张卡（shared/vocab.md §9）

衔接流程（预热内容并入当日那张词卡，不额外多发消息）：
  预热 D-7 → 预热 D-5 → 预热 D-3 → 上课当天早上一句提醒 → 上课学习
  → 之后按各词自己的 dueDate 出现在每日词卡上

⚠️ 全流程中，本 SKILL 每天对外仍然只贡献 1 张词卡；
   预热期不新增提醒条数，只改变当天词卡的内容。
```
