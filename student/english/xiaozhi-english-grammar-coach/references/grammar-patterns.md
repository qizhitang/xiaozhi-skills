# 五类语法错误详细分析与追问话术扩展库

> 适用学段：初中（7-9 年级）为主，小学高段可用其中的时态与主谓一致部分；标 ⚠高中 的条目仅供初高衔接了解，不进初中练习与档案。

---

## 一、时态系统完整追问库

### 一般过去时（最高频错误）

**触发词识别：** yesterday, last week/month/year, ago, in [过去年份]

```
标准追问：
"你说的这件事，发生在什么时候？"
→ "那动词应该用什么形式——原形、过去式、还是过去分词？"
→ "[动词]的过去式是什么？"

快速确认：
"一句话确认：这件事已经发生了，对吗？
 已经发生的事，英语动词要用[?]"
```

**高频不规则动词速查（追问时可提示）：**

| 原形 | 过去式 | 过去分词 |
|-----|-------|---------|
| go | went | gone |
| see | saw | seen |
| eat | ate | eaten |
| write | wrote | written |
| come | came | come |
| run | ran | run |
| take | took | taken |
| give | gave | given |

---

### 现在完成时（初中高频难点）

**核心区别：** 一般过去时 vs 现在完成时

```
一般过去时：强调动作发生在过去某个具体时间点
现在完成时：强调过去的动作对现在的影响/结果

追问话术：
"你想强调的是：这件事发生在什么时候（具体时间），
 还是：这件事到现在为止已经发生了（不指定时间）？"

→ 有具体时间：一般过去时（I went to Beijing last year.）
→ 强调已经发生/目前状态：现在完成时（I have been to Beijing.）
```

**追问示例（注意：不要把 already + 过去时判为错）：**

```
学生：I already finished my homework.

判定口径：这句话本身不是错句——美式英语里 already/just/yet 完全可以配一般过去时。
  但国内教材与中考语料以英式用法为主，already/just/yet 倾向搭配现在完成时。
  所以这里不说"你错了"，说的是"考试更倾向哪一种"。

追问1："already 在你的课本里一般和哪个时态一起出现？
       如果按课本的习惯写，'finish' 要变成什么形式？"
→ have finished

追问2："'I already finished'和'I have already finished'——
       感觉上有什么区别？
       （提示：前者是在陈述一件过去发生的事，后者强调它对现在的影响）"

追问3："用现在完成时造一个句子——
       说你已经完成了某件事，用 'already'。"
```

---

### 将来时（will vs be going to）

```
区别追问：
"你要表达的是：
 A. 临时决定，刚才才想到要做这件事
 B. 已经计划好了，早就打算要做

→ A用 will（spontaneous decision）
→ B用 be going to（prior plan）"

追问：
"这个计划是你早就有的，还是刚想到的？"
```

## 二、主谓一致追问扩展

### 三步检查链（植入到直觉层）

```
每次写句子前，先走三步：
Step 1：找主语（谁/什么是句子的主角？）
Step 2：判断人称和单复数（第几人称？单数还是复数？）
Step 3：确认动词形式（现在时第三人称单数加s/es）

追问植入练习：
"在你说这个句子之前，先告诉我：
 ① 主语是什么？
 ② 它是第几人称，单数还是复数？
 ③ 动词现在应该是什么形式？"
```

### 常见复杂情况追问

```
情况①：不定式/动名词作主语（单数）
错误：Swimming are good for health.
追问："'Swimming'是什么词性？它是单数还是复数？
     谓语动词应该是 are 还是 is？"

情况②：集合名词（视语义而定）
错误：The team are winning. （英式英语接受，美式不接受）
追问："这里'team'作为一个整体还是一群个体？
     （美式：团队作为整体=单数=is；
      英式：团队成员作为个体=复数=are）"

情况③：there is/are 倒装
错误：There is many students in the classroom.
追问："'students'是单数还是复数？
     'there is'后面跟单数，'there are'后面跟什么？"
```

## 三、介词搭配追问扩展

### 场景联想法（记忆钩子，不是语法规则）

> ⚠️ 使用说明：下面这些"空间感"说法是**帮助记忆的钩子**，不是可以推导搭配的规则。
> 大量介词搭配无法用空间联想解释（interested **in** 与 good **at** 的差别、
> depend **on** 与 rely **on** 的一致、married **to** 与中文"和…结婚"的错位），
> 只能作为固定搭配记住。追问时可以用钩子帮学生留住印象，
> **不要**告诉学生"按空间逻辑就能推出来"，也不要让学生用钩子去猜没学过的搭配。

```
in：沉浸进去，在某个空间/时间范围内
  → interested in（兴趣沉浸其中）
  → in the morning（在早上这个时间段内）
  → in the classroom（在教室这个空间内）

at：指向一个点/位置
  → arrive at（到达某个点）
  → good at（擅长某个具体技能）
  → at school（在学校这个位置）

on：接触表面，在某天
  → depend on（依靠在...上面）
  → on Monday（在星期一这个点上）
  → on the table（在桌面上）

for：为了，持续时间
  → wait for（为...等待）
  → for two hours（持续两小时）
```

### 高频错误介词对速查

| 错误搭配 | 正确搭配 | 记忆钩子（仅助记） |
|---------|---------|------------|
| interested at | interested in | "兴趣是沉浸进去" |
| arrive to | arrive at/in | "小地点用 at，大地点用 in" |
| good on | good at | "擅长的是一个具体技能点" |
| married with | married to | 无钩子，直接记：**married to**（中文"和…结婚"会误导成 with） |
| depend in | depend on | "依靠是站在…上面" |

## 四、定语从句追问话术完整版

### 关系词选择的判断顺序：先看成分，再看先行词

> ❌ 常见伪规则："先行词是地点就用 where、是时间就用 when"。
> 按这条规则会把 `The city that I visited is beautiful.` 判成错句（其实是对的），
> 也会让学生写出 `The day where I was born…`。
> ✅ 正确顺序：**第一步永远是把从句单独拿出来，看它缺什么成分**；先行词只在第二步用来决定"人还是物"。

```
Step 1（决定性）：把从句单独拿出来，看它缺哪个成分
├── 缺主语位        → 关系词作主语      → 走 Step 2 选 who / which / that（不可省略）
├── 缺宾语位        → 关系词作宾语      → 走 Step 2 选 whom/who/that / which/that（口语常省略）
├── 缺介词的宾语    → 关系词作介词宾语  → 走 Step 2，或把介词提前（in which / with whom）
├── 主语宾语都不缺，
│   但缺"在哪儿/在何时/为什么"（状语）→ 关系副词 where / when / why（= 介词 + which）
└── 主语宾语都不缺，也不缺状语        → 从句里有多余代词，删掉它

Step 2（只决定用哪个词，不决定要不要 where/when）：先行词是人还是物？
├── 人 → who / whom / that
└── 物、事、地点、时间 → which / that
```

**同一个地点先行词，成分不同，关系词就不同：**

```
The city that I visited is beautiful.
  从句 "I visited ___"：visited 是及物动词，缺宾语 → 关系词作宾语 → that/which（可省略）
  ✅ 地点先行词照样用 that，不用 where

The city where I was born is beautiful.
  从句 "I was born"：主语有、动词不带宾语，缺的是"在哪儿" → 关系副词 where（= in which）
  也可写成 The city that I was born in / The city in which I was born

The day when we met was rainy.   （缺"在何时" → when）
The day that we spent together was long.   （spent 缺宾语 → that）
```

### 从句中关系词充当成分的判断

```
关键追问："把从句单独拿出来看，它缺主语，还是缺宾语？
          → 缺主语位 → 关系词作主语（不可省略）
          → 缺宾语位 → 关系词作宾语（可省略）
          → 主语、宾语都不缺 → 句中有多余代词，删掉它"

示例：
The book that I borrowed...
拿出从句："I borrowed ___"→ 及物动词 borrow 后缺宾语
→ 关系词 that 作宾语 → 可省略（The book I borrowed...）

The book that I borrowed it...（常见错误）
拿出从句："I borrowed it"→ 主语、宾语都不缺，it 多余
→ 删掉 it

The girl who won the prize...
拿出从句："___ won the prize"→ 缺主语
→ 关系词 who 作主语 → 不可省略
```
（注：仅凭"去掉关系词后句子是否完整"无法区分主/宾——正常宾语从句去掉关系词后同样不完整；须看从句缺的是主语位还是宾语位。）

## 五、长难句追问话术

### 句子解剖五步法

```
Step 1：找谓语动词（中心动词）
追问："这个句子里，最核心的动作/状态词是什么？"

Step 2：通过谓语找主语
追问："是谁/什么在做这个动作，或处于这个状态？"

Step 3：找宾语/表语
追问："这个动作/状态的对象是什么？"

Step 4：把修饰成分括号化
追问："哪些部分是在修饰主语/动词/宾语的？用括号括起来。"

Step 5：读主干验证
"只读主语+谓语+宾语，意思通顺吗？"
```

### 四种常见复杂结构识别

```
结构①：主语较长（含修饰从句）
The discovery（which was made by scientists）changed everything.
→ 括号括起来，主干是：The discovery changed everything.

结构②：插入语/同位语
My teacher, （a well-known poet）, writes beautifully.
→ 括号括起来，主干是：My teacher writes beautifully.

结构③：多重定语从句嵌套
The city where I was born, which is now very developed, has changed a lot.
→ 从内到外逐层剥离

结构④：分词短语 ⚠高中（初中只作阅读时的识别，不要求学生写出来）
（Having finished his homework）, he went out to play.
→ 分词短语表示"作业已经写完了"，动作发生在主句之前，用 having done
→ 主语必须和主句一致：这里做作业的和出去玩的都是 he
→ ❌ 不要示范 "Finishing his homework, he went out"：
   现在分词表示同时发生，"一边写作业一边出去玩"逻辑不通
→ 初中阶段等价说法：After he finished his homework, he went out to play.
```
