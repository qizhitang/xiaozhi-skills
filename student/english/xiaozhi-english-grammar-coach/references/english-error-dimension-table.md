# 英语错因维度表

> 适用学段：初中（7-9 年级）为主，小学高段只用 G01/G02/G06/V03/P 类；标 ⚠高中 的子类型不进初中档案，只在学生自己问到时说明。

> 本文档为 `xiaozhi-english-grammar-coach` 的核心参考资源，定义英语学科包的五类错因维度体系、子类型分类、跨维度关联规则与追踪标准。同时为英语口语陪练、写作教练、听力训练师等英语专项SKILL提供统一的错因分类框架。
>
> **词表依赖**：弱项状态五档、"3 次顽固"口径、掌握度、置信度一律按 `shared/vocab.md` §4-§7，本文件不另立标准。

## 一、维度总览

```
英语错因维度体系（五维×多子类型）

维度①  语法结构错误 ── 规则层（英语语法规则违反）
维度②  词汇应用错误 ── 语义层（词汇选择/搭配/词性偏差）
维度③  发音表达错误 ── 语音层（发音/流利度/语调问题）
维度④  听力理解错误 ── 接收层（听的信息获取偏差）
维度⑤  读写逻辑错误 ── 思维层（中式思维/答题逻辑偏差）

每道错题必须归入且只归入一个主维度。
如存在跨维度因素，记录为"主维度+次要维度"。

说明：本五维是按"英语课堂里可观察到的错误表现"划分的自定义分类，
  与 shared/vocab.md §1 的通用四维映射见 §2 表；不引用特定学术模型。
```

## 二、维度①：语法结构错误

**定义：** 英语语法规则违反——时态、主谓一致、从句结构、介词搭配等方面的技术性错误。

**判断标准：** 学生知道想表达什么意思，但在用英语表达时违反了语法规则。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发学段 | 关联参考 |
|---------|------|---------|---------|---------|
| G01 | 时态混用 | 用一般现在时描述过去事件；过去时和完成时混用 | 初中全段 | → grammar-patterns §一 |
| G02 | 主谓一致 | 三单现在式遗漏；集合名词单复数不确定 | 初一-初二 | → grammar-patterns §二 |
| G03 | 定语从句错误 | 关系词误用(who/which)；多余代词 | 初三 | → grammar-patterns §四 |
| G04 | 介词搭配错误 | interested at→in；arrive to→at/in | 初中全段 | → grammar-patterns §三 |
| G05 | 长难句结构混乱 | 从句嵌套错误；句子成分不完整 | 初三 | → grammar-patterns §五 |
| G06 | 冠词使用混乱 | a/an/the遗漏或多余；泛指误加 the | 初一-初三 | — |
| G07 | 比较级/最高级错误 | double comparative；比较对象不对 | 初一-初二 | — |
| G08 | 被动语态错误 | 被动句结构搭错；被动与主动混用 | 初二-初三 | — |
| G11 | 名词单复数错误 | 可数名词漏 -s；不可数名词加 -s | 初一-初三 | — |
| G12 | 代词错误 | 主格/宾格/形容词性物主代词混用 | 初一-初三 | — |
| G09 | 非谓语动词错误 ⚠高中 | to do vs doing 系统辨析；分词短语作状语 | ⚠高中（初中只识别不产出） | — |
| G10 | 虚拟语气错误 ⚠高中 | 条件句虚拟与现实混用 | ⚠高中（不进初中档案） | — |

**严重程度分级（按"是否影响中考得分与可理解性"，不按"错误看起来大不大"）：**

```
中度：G01、G02、G04、G06、G11、G12
  → 冠词、名词单复数、代词、三单都是中考单选/短文填空/写作的高频扣分点，
    出现即记录，不按"轻度"放过。
  → 这几类属于**形式类错误**：研究支持显性纠正。
    追问一轮学生仍答不出 → 按 shared/hint-ladder.md 直接给 L5（同型例句示范）→ 让学生改原句。
  → 处理：四步追问 → 确认理解 → 造句验证；工具见 grammar-patterns.md 对应章节

中度（规则类）：G07、G08
  → 有明确规则可讲，追问后一般能自行修正 → 从 L1 起逐级升

重度：G03、G05 → 结构层面系统性偏差
  → 处理：专项训练营（定语从句成分判断五步法 / 长难句解剖法）
  → 通常需要多次追问才能建立稳定判断（经验值，因人而异）

⚠高中：G09、G10 → 初中出现时只说明"这是高中内容，先不练"，不记入弱项状态
```

**根因分析层：**

```
G01 时态混用的深层根因：
  → 中文没有时态标记（"我昨天去"和"我明天去"动词相同）
  → 学生大脑默认用中文思维 → 时态意识缺失
  → 不是"不知道规则"，而是"来不及想规则"
  → 治法：不背规则，而是在每次说话/写作前先问"这件事发生在什么时候？"

G02 主谓一致的深层根因：
  → 中文没有主谓一致要求（"他喜欢"和"他们喜欢"动词相同）
  → 三步检查链植入：找主语→判断人称/单复数→确认动词形式

G04 介词搭配的深层根因：
  → 中文介词系统与英语不对应，很多搭配没有可推导的道理，只能作为固定搭配记
  → 场景联想（in=沉浸/at=指向/on=接触表面）是**记忆钩子**，不是能推出新搭配的规则；
    见 grammar-patterns.md §三的使用说明
  → 做法：把高频搭配当词汇处理（V03 固定搭配），并入当日到期词卡
```

## 三、维度②：词汇应用错误

**定义：** 词汇选择、搭配、词性使用偏差——不是"不认识这个词"，而是"认识但用错了"。

**判断标准：** 学生认识这个词的意思，但在具体使用时选择了错误的近义词、搭配或词性。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发学段 | 关联SKILL |
|---------|------|---------|---------|----------|
| V01 | 近义词辨析错误 | make/have/take/get混用；careful/meticulous辨析 | 初中+ | → vocabulary-dna |
| V02 | 词性使用错误 | 把形容词用在动词位置；名词当动词用 | 初一-初二 | → grammar-coach |
| V03 | 固定搭配错误 | do homework→make homework；listen music→listen to music | 初中全段 | → vocabulary-dna |
| V04 | 词汇量不足导致的绕路表达 | 想表达"frustrated"但只能说出"angry and sad" | 初中+ | → vocabulary-dna |
| V05 | 抽象词理解偏差 | 知道success的意思但不知道如何正确使用 | 初三+ | → vocabulary-dna |
| V06 | 词根词缀推断错误 | 把un-开头的词全部理解为"否定" | 初三+ | — |

**严重程度分级：**

```
轻度：V04、V06 → 表达不够精确但不影响理解
  → 处理：词汇升级建议（"这里可以换个更精确的词"）
  → 联动词汇DNA：存入推荐升级词

中度：V01、V02、V03 → 使用偏差导致含义变化或语法错误
  → 处理：辨析练习 + 搭配训练
  → 联动词汇DNA：存入正确搭配，并入当日到期词卡（shared/vocab.md §9）
  → 注意：V02词性错误可能同时也是G类语法错误 → 记录交叉维度

重度：V05 → 抽象词长期停留在"认识"层面，无法主动使用
  → 处理：掌握度从"会复述"推进到"会解释/真正掌握"（shared/vocab.md §6）
  → 联动词汇DNA：到期词卡改用造句/对话植入形式，而不是只做认词
```

**与语法维度(G)的交叉判断：**

```
V02(词性使用错误) vs G02(主谓一致)：
  → 学生用了形容词代替动词 → 既是词性错误(V02)又是语法错误(G02)
  → 判断标准：如果把词性换成正确的，主谓一致还有问题吗？
    没有 → V02为主（词性搞错导致连带语法问题）
    还有 → G02为主（即使词性对了，主谓一致规则还是没掌握）

V03(固定搭配错误) vs G04(介词搭配错误)：
  → "listen music" → 是V03(搭配错)还是G04(介词遗漏)？
  → 判断：学生是否知道"listen to"这个搭配？
    不知道 → V03为主（词汇搭配不熟）
    知道但忘了用 → G04为主（语法规则应用失误）
```

## 四、维度③：发音表达错误

**定义：** 口语发音、流利度、语调方面的错误——不是"说错了内容"，而是"说错了声音/节奏"。

**判断标准：** 学生说的话在文字层面正确，但发音/节奏/语调层面有问题。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发学段 | 关联参考 |
|---------|------|---------|---------|---------|
| P01 | th音替代 | think→sink；this→zis | 全学段 | → pronunciation-issues §2.1 |
| P02 | r/l混淆 | right→light；red→led | 全学段(尤其南方) | → pronunciation-issues §2.2 |
| P03 | 长短元音不分 | sit→seat；live→leave | 初中+ | → pronunciation-issues §2.3 |
| P04 | v/w混淆 | very→wery；vest→west | 全学段 | → pronunciation-issues §2.4 |
| P05 | 词尾辅音遗漏 | and→an；test→tes | 全学段(极高频) | → pronunciation-issues §2.9 |
| P06 | 梅花音/短e不分 | bad→bed；cat→ket | 初中+ | → pronunciation-issues §2.5 |
| P07 | 语调模式错误 | 陈述句用升调；疑问句用降调 | 初三+ | → pronunciation-issues §五 |
| P08 | 连读/弱化不足 | 逐词读出，没有英语节奏感 | 初三+ | → pronunciation-issues §五 |
| P09 | 重音位置错误 | important重音放错位置 | 初中+ | → pronunciation-issues §五 |

> ⚠️ 记录前提：P 类只在具备**语音评测能力**（`shared/platform-conventions.md` 能力代号 `S`）时才可判定与记录。
> 只有语音转写（`A`）而无 `S` 时，转写会把发音归一化掉，**不得**做音素级判断，也不得写入 P 类子类型。

**严重程度分级：**

```
轻度：P07、P08、P09 → 不影响理解但影响自然度
  → 处理：在口语热身复盘时温和指出
  → 记录但不启动专项纠音

中度：P03、P06 → 音位混淆导致含义变化
  → sit/seat；bad/bed → 听者可能误解
  → 处理：纠音闭环训练（确认→练习句→跟读→反馈循环）

重度：P01、P02、P05 → 影响可理解性的高频偏差
  → 处理：每次热身前提醒重点发音 → 专项纠音训练
```

**发音追踪标准：一律按 shared/vocab.md §4-§5**

```
状态五档：待处理 / 初步弱项 / 顽固弱项 / 突破中 / 已攻克
计数口径：同一子类型 ID + 同一通用维度，28 天滚动窗口，累计（同日多次只计 1 次）
攻克标准：连续 2 次独立验证做对，两次间隔 ≥ 3 天
档案落点：growthMap.oralGrowthTrack.pronunciationWeaknesses[]，subtypeId 用 P01-P09
置信度：🟢/🟡/🔴 按 shared/vocab.md §7；🔴 只在会话内使用，不写入长期档案
```

## 五、维度④：听力理解错误

**定义：** 听的信息获取偏差——不是"听到的词不懂"，而是"听的方式有问题"。

**判断标准：** 学生听了一段材料后理解偏差，需要区分是词汇/语法/语速哪一层面的问题。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发学段 | 关联SKILL |
|---------|------|---------|---------|----------|
| L01 | 词义不明 | 听清了声音但不知道意思 | 初中全段 | → vocabulary-dna |
| L02 | 语速/连读跟不上 | 词和词连在一起没反应过来 | 初二+ | → speaking-coach |
| L03 | 句子结构听不懂 | 每个词都认识但整句不理解 | 初三+ | → grammar-coach |
| L04 | 关键信息遗漏 | 听了整段但没抓住核心数据/时间/地点 | 初中全段 | → listening-trainer |
| L05 | 信息顺序错乱 | 听到的信息在脑海中的顺序与原文不同 | 初中+ | — |
| L06 | 注意力涣散 | 因话题不感兴趣导致后半段没听进去 | 全学段 | → learning-dna(兴趣) |

**严重程度分级：**

```
轻度：L06 → 注意力问题而非能力问题
  → 处理：调整话题匹配度（使用学生兴趣话题）
  → 联动学习DNA：读取兴趣档案优化话题选择

中度：L01、L04 → 词汇或信息提取层面问题
  → 处理：L01→存入词汇DNA(听力生词入库)
         L04→训练"先听核心信息"的注意力分配
  → 联动听力训练师：卡壳点精准追问(词义/结构/语速判断)

重度：L02、L03 → 语速或结构层面系统性障碍
  → L02→慢速拆解训练 + 连读规律讲解
  → L03→联动语法教练(长难句解剖法)
  → 需要专项训练突破
```

**与语法维度(G)和词汇维度(V)的交叉：**

```
L01(词义不明) vs V04(词汇量不足)：
  → 听力中遇到不认识的词 → 属于L01（听力层面获取问题）
  → 该词存入词汇DNA后 → 如果再次听到还是认不出 → 转为V01/V04（词汇应用问题）

L03(句子结构听不懂) vs G05(长难句结构混乱)：
  → 听不懂长句 → 先判断：看文字版本能理解吗？
    能理解 → L03为主（语速/节奏导致听不懂，不是结构问题）
    不能理解 → G05为主（结构本身理解有偏差）
```

## 六、维度⑤：读写逻辑错误

**定义：** 中式思维导致的表达逻辑偏差——不是"语法错"或"词汇错"，而是"思维模式错"。

**判断标准：** 学生用了正确的语法和词汇，但表达逻辑是中文式的，不符合英语思维习惯。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发学段 | 关联SKILL |
|---------|------|---------|---------|----------|
| T01 | 中式英语表达 | "I very like it"；"open the light" | 初中全段 | → writing-coach |
| T02 | 段落结构中文式 | 先铺垫再结论（英语书面表达习惯先结论再展开） | 初三+ | → writing-coach |
| T03 | 论证逻辑偏差 | 只举例不分析；列举事实不建立因果链 | 初三+ | → writing-coach |
| T04 | 英语阅读定位错误 | 在英语原文中找不到题目对应位置（题干关键词与原文同义替换没对上） | 初中全段 | → 本 SKILL §七长难句拆解 + writing-coach |
| T05 | 完形填空语境忽视 | 只看单句不考虑上下文逻辑 | 初二+ | — |
| T06 | 写作审题偏差 | 偏离题目要求的主题/格式 | 初中+ | → writing-coach |

> T04 只处理**英语**阅读的定位问题（同义替换、指代还原、题文顺序一致性），
> 不转给语文的阅读拆解 SKILL——两者的文本、题型与设问方式都不通用。

**严重程度分级：**

```
轻度：T01 → 常见中式表达，可快速纠正
  → 处理：指出地道表达方式，在用户同意时存入词汇DNA

中度：T04、T05 → 读写方法层面问题
  → 处理：T04→用"题干关键词 → 原文同义替换"两步定位训练（本 SKILL 内完成）
         T05→训练"先读全文再逐空填写"的做题习惯

重度：T02、T03 → 书面表达逻辑层面系统性偏差
  → 处理：需要写作教练介入
  → 英语书面表达习惯：先结论→再展开→最后总结
  → 中文写作习惯：先铺垫→逐步展开→结论在最后
  → 需要多次训练才能稳定（经验值，因人而异）
```

## 七、跨维度关联规则

```
维度间常见交叉（英语特别多交叉）：

G01(时态混用) + V04(词汇量不足导致绕路)：
  → 学生用简单词汇描述过去事件，时态也跟着简化
  → 判断：给了高级词汇后，时态问题是否改善？
    改善 → V04为主（词汇量不足导致简化表达→连带时态简化）
    没改善 → G01为主（时态规则本身没建立直觉）

V02(词性使用错误) + G02(主谓一致)：
  → 用形容词代替动词 → 词性和主谓一致双重问题
  → 判断：纠正词性后主谓一致还有问题吗？
    没有 → V02为主
    还有 → G02为主

P01(th音替代) + L01(词义不明)：
  → 自己发音不准 → 听到正确发音时无法识别
  → 发音问题和听力问题互相强化
  → 处理：同时纠音+听力训练

T01(中式英语) + G类(语法错误)：
  → "I very like it" → 既是中式思维(T01)也是语法错误(G类)
  → 判断：学生是否知道"very"不能直接修饰动词？
    不知道 → G类为主（语法规则缺失）
    知道但习惯性犯 → T01为主（中式思维惯性）

跨维度记录格式：
  主维度：[维度ID+子类型ID]
  次要维度：[维度ID+子类型ID]（如有）

优先处理顺序：
  → G类(语法) > V类(词汇) > T类(逻辑) > P类(发音) > L类(听力)
  → 语法是骨架 → 词汇是砖块 → 逻辑是蓝图 → 发音是外观 → 听力是验收
  → 先修骨架(G) → 再补砖块(V) → 再调蓝图(T)
```

## 八、英语专项SKILL维度分配

```
各英语SKILL主要负责的维度：

  → 档案落点：subjectExtensions.english.grammarProfile[]（G01-G12）

  → 档案落点：growthMap.oralGrowthTrack.pronunciationWeaknesses[]（subtypeId P01-P09）

听力训练师：L类（主） + V01（辅，听力生词）
  → 档案落点：subjectExtensions.english.listeningProfile（舒适语速 + 弱微技能）

写作教练：T类（主） + G类（辅，写作中的语法问题） + V类（辅，词汇升级）
  → 档案落点：subjectExtensions.english.writingProfile（strengths / recurringIssues）

词汇DNA系统：V类（主） + G04（辅，介词搭配属于跨领域）
  → 档案落点：subjectExtensions.english.vocabulary[]（word/dueDate/intervalDays/status）

数据流转规则：
  → 各SKILL发现非本职维度的错误 → 推送到对应SKILL
  → 口语中发现语法错误 → 推送到语法突破教练
  → 写作中发现发音相关错误（拼写反映发音） → 推送到口语陪练
  → 听力中发现词汇不足 → 推送到词汇DNA系统

不产生重复记录：
  → 语法DNA只记录G类错误（语法层）
  → 口语DNA只记录P类错误（发音层）
  → 词汇DNA只记录V类错误（词汇层）
  → 跨维度问题 → 主维度SKILL记录完整，辅维度SKILL只标记关联
```

## 九、弱项状态与顽固口径（唯一来源：shared/vocab.md）

```
状态五档与进入/离开条件：按 shared/vocab.md §4
  待处理 → 初步弱项 → 顽固弱项 → 突破中 → 已攻克

"3 次顽固"口径：按 shared/vocab.md §5
  粒度 = 同一知识点标签 + 同一通用四维；子类型 ID 不同但通用维度相同仍计同一计数
  时间窗 = 滚动 28 天；累计（不要求连续），同一天多次只计 1 次
  计数权威 = 学生同时使用错题本时以错题本为准，本 SKILL 只接收"顽固"事件

攻克标准（按 shared/vocab.md §5，五维通用）：
  连续 2 次独立验证做对，两次间隔 ≥ 3 天，且至少 1 次为"换题型/纯净版"验证
  各维度的"独立验证"具体形态：
    G类：不给提醒的情况下，在新句子里自发用对
    V类：到期词卡上能造句使用（不是只认词）
    P类：需具备语音评测能力（S）时才可判定；无 S 时不判定、不记录
    L类：同一语速档的新材料上仍能听出目标信息
    T类：新一篇写作中未再出现该逻辑偏差

顽固弱项的处理方式（按维度）：
  G类 → 四步追问 + 专项训练营；形式类错误按 shared/hint-ladder.md 可直接 L5
  V类 → 到期词卡形式升级（认词 → 造句 → 对话植入）
  P类 → 纠音闭环训练 + 每次热身前提醒
  L类 → 降速训练 → 逐步提速
  T类 → 写作教练介入 + 多次对比练习

进步报告统计维度（学生要求时生成，不按月自行生成）：
  → 五维度各自的错误条数（本期 vs 上期）
  → 各维度内子类型排序
  → 顽固弱项清单（含出现次数 + 状态 + 处理方式）
  → 跨维度交叉分析（如有）
  → 无跨会话统计能力（X）时只报本次会话内计数，并标 🟡
```
