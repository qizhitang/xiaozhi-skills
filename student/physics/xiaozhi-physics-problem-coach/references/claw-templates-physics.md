# 物理意图识别模板（CLAW 内部化）

> 适用学段：初中（7-9 年级）。
> 本文档为 `xiaozhi-physics-problem-coach` 的配套参考资源，定义 5 类物理场景的**内部**意图识别模板。
> 与数学同类模板的核心区别：物理的第一步永远是"画图"。

---

## 一、CLAW 是 AI 的内部槽位，不是学生的发言格式

**学生不需要背格式、不需要照着模板打字。** 学生只要用自己的话说"这道题不会"就够了；四个槽位由 AI 从对话中自行判断，缺哪个就问哪个，一次只问一句。

```
C - Condition：什么题、什么物理情境、画图了没有
L - Law/Logic：学生打算用哪条物理规律（不是数学公式）
A - Attempt：学生走到了哪一步（必须包含图景建立进度）
W - Want：学生要的是"引导"还是"直接讲"（按 shared/hint-ladder.md 决定阶梯位置）
```

**唯一需要学生回答的问题**：

```
"这道题你试到哪一步了？——画图了吗？还是看完题就卡住了？"
（学生答一句即可；其余槽位由 AI 从题面和这句话推断）
```

**补槽规则（每类模板最多补问 1 次，每次 ≤ 30 字）**：

| 缺的槽位 | 补问话术 | 补不到时的默认值 |
|---|---|---|
| C | "题目里出现的是力、电流，还是光线？" | 从题面关键词自动归类 |
| L | 不问。学生说不出规律本身就是信息 | 记为"规律未定位" |
| A | "画图了吗？画到哪一步？" | 记为"未画图" |
| W | 不问。默认从 L1（方向）起步 | L1；新手（弱项状态为"待处理/初步弱项"）从 L5 起 |

**轮次预算**：意图识别 ≤ 2 轮；进入四步法后每步 ≤ 3 轮。
**退出规则**：学生连续两轮无实质回复 → 一句话收尾（"这道我们先放着，你想继续时把题再发我一次"）并结束会话，不追问。
**快速模式**：学生说"我赶时间/明天就考"→ 跳过意图识别，直接进模板⑤。

## 模板① 图景建立类

### 触发短语

```
"我画不出受力分析图"
"我不知道电路图怎么画"
"我不会画光路图"
"这道题我不知道该画什么图"
"我看了题但脑子一片空白"
"我不知道从哪里开始分析"
"这道力学题我找不到受力对象"
```

### AI 内部槽位（学生不必照此发言）

| 槽位 | AI 从哪里判断 |
|---|---|
| C | 题面关键词（力/电流/光线/物态）→ 图景类型 |
| L | 学生是否说得出"先画图再分析" |
| A | 学生是否已动笔：未画 / 画了漏力 / 画了不确定 |
| W | 默认"分步引导我自己画"，即提示阶梯 L1-L4 |

**对学生只说一句**："先告诉我，这道题里你看到哪些东西在互相作用？"

### 适配响应流程

```
Step 1：确认图景类型
  AI话术："这道题属于[力学/电学/光学]题，我们需要先画[图景类型]。"

Step 2：分步引导画图（严格按physics-diagram-guide.md）
  受力分析图：
    → "第一步：确定分析对象——这道题分析的是哪个物体？"
    → "第二步：画重力——竖直向下，标G。"
    → "第三步：找接触面——和哪些东西接触？每个接触面可能产生什么力？"
    → "第四步：检验平衡——水平方向和竖直方向力分别平衡了吗？"

  等效电路图：
    → "第一步：从正极出发，电流有几条路径？"
    → "第二步：电压表当断路、电流表当导线，画出简化电路。"
    → "第三步：标出电流方向和各部分电压关系。"

  光路图：
    → "第一步：光线从什么介质进入什么介质？"
    → "第二步：画出法线，标注入射角。"
    → "第三步：根据反射/折射定律画出光线路径。"

Step 3：检查图景完整性
  AI话术："你的图画好了——我们检查一下：
   [重力画了吗？/每个开关状态都画了吗？/法线画了吗？]"

Step 4：进入四步法S2（物理建模）
  图景正确 → "图画对了，接下来我们根据图景选择物理模型。"

Step 5：错误归类（**会话内标记，默认不归档**）
  → 图景建立失败 → 在本次会话内标记为 P 类
  → 具体子类型：P01/P02/P03/P04（按图景类型）
  → 这只是当场分类，用来决定接下来怎么讲；**不写档案、不发交接**。
    学生主动说“帮我记下来”时才走 S6_ASK_ARCHIVE。
```

### 变体场景

```
变体A：多对象图景
  触发："两个物体叠在一起，我不知道分析哪个"
  处理："分别画！先画上面的物体受力图，再画下面的物体受力图。
         两张图用'力的作用是相互的'联系起来——上面物体压下面物体的力，
         与下面物体支持上面物体的力，大小相等、方向相反。"

变体B：多状态电路
  触发："开关有好几种状态，我不知道怎么处理"
  处理："每种状态画一张等效电路图。
         开关S1闭合S2断开→画一张；S1断开S2闭合→再画一张。
         不能混在一起画。"

变体C：完全空白
  触发："我完全不知道该画什么"
  处理：降级引导→"这道题提到了什么物理现象？[力/运动/电流/光线]
         → 有力→画受力分析图；有运动→画运动过程图；
           有电流→画等效电路图；有光线→画光路图。
         先告诉我题目描述了什么，我帮你判断。"
```

## 模板② 错题分析类

### 触发短语

```
"这道力学题我做错了"
"这道电学题我算的结果不对"
"我物理考试扣了很多分"
"这道题我选了B但答案是C"
"我的计算结果和答案不一样"
"这道浮力题我做错了但不知道哪里错了"
```

### AI 内部槽位（学生不必照此发言）

| 槽位 | AI 从哪里判断 |
|---|---|
| C | 学生答案 vs 正确答案（学生只需报这两个数） |
| L | 学生用了哪条规律——说不出即"规律未定位" |
| A | 是否画图、是否列式 |
| W | 默认"帮我自己找出错在哪"，即提示阶梯 L3（指出哪个条件没用到）起步 |

**对学生只说一句**："你的答案是多少？正确答案是多少？画图了吗？"

### 适配响应流程

```
Step 1：定位错误步骤（按四步法逐步骤回溯）
  AI话术："我们按步骤来检查——你画图了吗？画完图列的式子还是直接列的？"

  检查顺序（按优先级）：
  ① 图景是否正确？→ 不画图就列式 → P类错误（最高优先级）
  ② 物理模型是否正确？→ 模型选错 → C类错误
  ③ 公式是否正确？→ 公式用错/条件不满足 → F类错误
  ④ 计算过程是否正确？→ 数学执行错误 → T类错误

Step 2：逐步还原学生的解题过程
  AI话术："把你做的每一步说给我听——
   第一步你画了什么图？第二步你选了什么模型？
   第三步你列了什么公式？第四步你怎么算的？"

Step 3：定位分歧点
  AI话术："你的过程到第[N]步之前都是对的，
   第[N]步开始出了问题——这一步你是怎么想的？"

Step 4：根因追问（不用三层次追问，用简化版）
  "你第[N]步漏了[摩擦力/某个过程/某个开关状态]——
   为什么会漏？是因为没画图，还是画了图没看仔细？"
  → 没画图 → P类根因
  → 画了图但看漏 → P类（图景意识不足）
  → 画了图但概念理解错 → C类根因

Step 5：针对性修复
  → P类：重画图景，建立图景意识
  → C类：概念澄清（联动概念直觉器）
  → F类：公式适用条件检查
  → T类：数学计算自检

Step 6：出同类题验证
  "我出一道类似的题，你用正确的方法做一遍——
   注意刚才出错的那一步。"
  → 生成前按 shared/ai-item-check.md 自检（有解且唯一、条件充分、
    数值友好、不超初中学段、与原题同维度同子类型）

Step 7：归档（**可选加项，默认不做**）
  → 默认行为是：讲完就结束，不归档、不交接、不留存。
  → 只有三个条件同时成立才发交接：学生本轮明确说要记 + `crossSkillSharing` 为 true
    + 平台要求监护人同意时该同意位也为 true。任一不满足就跳过，本次分析只留在会话里。
  → 满足后生成 wrong_answer_handover 交接给通用错题本（唯一计数权威）：
    subject="physics"、basicDimension（四维）、physicsBasicDimension（五维）、
    subtypeId（如 P02）、surfaceInfo
  → 需要五维深度归因时再转物理错误DNA；本模板不自行统计次数
```

## 模板③ 建模卡壳类

### 触发短语

```
"我知道用二力平衡但不知道怎么列式"
"我知道是欧姆定律但不知道怎么设未知数"
"我画了受力图但不知道怎么算"
"我知道是串联分压但不知道从哪入手"
"公式都认识但不知道怎么组合"
"图景画出来了但不知道下一步做什么"
```

### AI 内部槽位（学生不必照此发言）

| 槽位 | AI 从哪里判断 |
|---|---|
| C | 图已画出，卡在"图 → 式" |
| L | 学生能报出规律名（二力平衡/欧姆定律/杠杆平衡条件…）说明 L 槽已满 |
| A | 列了几个式子、缺几个 |
| W | 默认"引导我自己列式"，提示阶梯 L2-L4 |

**对学生只说一句**："图画好了——那你要求的是哪个量？先把它写出来。"

### 适配响应流程

```
Step 1：确认图景正确性
  AI话术："先确认你的图景画对了——[展示图景检查点]。
   图景对了才能列式，图景错了列出来的式子肯定不对。"

Step 2：从图景中提取物理关系
  AI话术："看看你的图——
   受力图：哪两个力在同一直线上、方向相反？→ 二力平衡式 F₁=F₂
   电路图：串并联关系？各部分电压电流关系？→ 欧姆定律+串并联规律
   运动图：这一段的路程和时间是多少？→ v=s/t；全程用 v̄=s总/t总"

Step 3：引导设未知数
  AI话术："要求什么？——把它设为未知数。
   还需要什么中间量？——也设出来。
   你有几个未知数？需要几个方程？"

Step 4：逐个列方程
  AI话术："从图景中，你能找到几个独立的物理关系？
   每个关系写一个式子。初中常见的三类：
     同一直线上的二力平衡 → F拉 = G，或 F支 = G
     浮体/悬浮 → F浮 = G物；浸没 → F浮 = ρ液·g·V排
     串联电路 → U总 = U₁ + U₂，I 处处相等
   你自己找找看。"
  （斜面上的力沿两个方向分解属于 ⚠高中 内容，初中不列这类式子）

Step 5：检查方程数量
  AI话术："你有[N]个未知数，[M]个式子——够吗？
   不够的话，图景里还有没用的信息。回去看看图。"

Step 6：引导求解（不直接算）
  AI话术："方程列好了——你自己解解看。
   解到哪一步卡住了告诉我。"

Step 7：如果反复卡壳
  → 联动物理建模教练SKILL
  → 在会话内标记为 C 类或 F 类（概念理解不足或公式应用困难），用于决定转给谁；
    **不因为“反复卡壳”就自动归档**——归档一律走 S6_ASK_ARCHIVE 的同意门。
```

## 模板④ 实验类请求 —— **转介模板，不是解答模板**

> SKILL.md 的边界写明：**实验设计、实验方法选择、数据处理、找规律、误差分析不由本 SKILL 处理**，
> 一律转 `xiaozhi-physics-lab-coach`（物理实验思维教练）。
> 本模板只负责**认出来并转过去**，不在这里教实验方法——
> 下面没有"实验目的引导""控制变量法讲解""数据处理引导""误差来源清单"这类步骤，是有意删掉的。

### 转出去（本 SKILL 不处理）

```
"我不知道怎么设计实验验证结论"
"控制变量法我不太会用"
"实验数据的规律我找不出来"
"这个实验的误差分析怎么做"
"我不知道怎么从实验数据得出结论"
"这个实验该用什么方法"

→ 统一回应，不先讲一点再转：
  "这是实验设计和数据处理的问题，物理实验思维教练比我在行——
   我把你转过去，那边会带你从实验目的一路理到误差。"
→ 交给 xiaozhi-physics-lab-coach，本 SKILL 到此为止。
```

### 留下来（其实是常规计算题，只是背景是实验）

```
"伏安法测电阻，电压表读数 3V、电流表 0.3A，电阻是多少"
"测密度实验里量筒读数是这些，密度怎么算"
"这道题给了实验数据表，问小灯泡的电功率"

→ 判断依据：问的是**列式与计算**，实验只是题面背景，
  方法已经定了、数据已经给了、不需要评价实验方案。
→ 按模板①/②的常规四步法处理（读题画图→建模→列式→检验）。
```

### 分不清时怎么办

```
按"转出去"处理。宁可多转一次，不要越界讲实验方法。
话术："你这道题是想让我帮你算，还是想搞懂这个实验该怎么做？
       想搞懂实验的话我转给实验思维教练；只是算数的话我们现在就开始。"
```

## 模板⑤ 考前突击类

### 触发短语

```
"明天考物理帮我复习"
"后天考试帮我梳理电学"
"物理考试前我想快速过一遍"
"帮我列出力学必考知识点"
"考前帮我检查还有什么弱项"
"明天考试但我电学还不会"
```

### AI 内部槽位（学生不必照此发言）

| 槽位 | AI 从哪里判断 |
|---|---|
| C | 距考试还有几天、范围（力学/电学/全册） |
| L | 学生自报"公式记不清"还是"方法不会用" |
| A | 复习进度 |
| W | 默认"有针对性地过一遍，不要从头讲" |

**对学生只说一句**："几天后考？考哪块？"（这是快速模式入口，其余槽位一律用默认值）

### 适配响应流程

```
Step 1：确定考试范围和时间
  AI话术："考试范围是什么？还有多少时间？
   → 明天考：只做核心梳理+高频错题
   → 3天后考：核心梳理+弱项专练
   → 一周后考：完整复习+系统训练"

Step 2：知识框架快速梳理（不从头讲）
  力学框架：
    "力学核心三条线：
     ① 力线：重力→弹力→摩擦力→力的合成与平衡
     ② 运动线：匀速→变速→v-t图→运动过程分析
     ③ 应用线：压强→浮力→简单机械→功和功率
     你哪条线最弱？"

  电学框架：
    "电学核心三条线：
     ① 电路线：串并联→等效电路→动态电路
     ② 规律线：欧姆定律→电功率→焦耳定律
     ③ 实验线：探究电流与电压/电阻的关系→伏安法测电阻→测小灯泡电功率
        （这条线只用来定位薄弱环节；真要复习实验方法与数据处理，转物理实验思维教练）
     你哪条线最弱？"

Step 3：图景绘制自查表
  "考试前检查——
   □ 力学题：看到力就先画受力分析图
   □ 电路题：看到开关就画等效电路图
   □ 运动题：看到过程就画运动过程图
   □ 光学题：看到光线就画光路图
   不画图就列公式 → 必扣分"

Step 4：公式适用条件速查
  "考试常考的公式适用条件——
   □ 欧姆定律：只适用于纯电阻电路
   □ 密度公式：只适用于均匀物质
   □ 阿基米德原理 F浮=ρ液gV排：普遍适用；F浮=G物 只在漂浮/悬浮时成立
   □ 功的公式W=Fs：F和s必须同方向
   □ 杠杆平衡条件 F₁L₁=F₂L₂：力臂是支点到力的作用线的**垂直**距离"

Step 5：单位统一检查
  "考试最容易扣分的地方——单位不统一：
   □ km/h → m/s（÷3.6）
   □ cm² → m²（÷10000，不是÷100！）
   □ g → kg（÷1000）
   □ kW·h → J（×3.6×10⁶）
   □ mm → m（÷1000）"

Step 6：错误档案对照（**读档案前先过授权门**）
  前置：本 SKILL 默认不读长期档案。只有同时满足才读——
    · 学生本轮明确同意“看一下我以前的错误”（或此前已开启并未撤回）
    · dna-profile 的 crossSkillSharing 为 true
  读之前先说清读什么、为什么读："我看一眼你的物理错误记录，只看错在哪类，行吗？"
  未同意 / 未授权 / 无档案 → **跳过本步**，只用本次会话内的观察，
  并说明"这是我这次看到的，不代表长期情况"。不要为了凑这一步去读档案。

  同意后：
  "从你的档案看——近期最频繁的错误是[维度+子类型]。
   考试时特别注意[具体提醒]。"
  → 读 dna-profile 的 subjectExtensions.physics.subtypes[] 与 subjectMap.weakKnowledgePoints[]
  → 重点标注状态为"顽固弱项 / 突破中"的条目（shared/vocab.md §4）
  → 全程只读不写；本 SKILL 在任何状态下都不更新 DNA、不归档（见 physics-4step-statemachine.md）

Step 7：3道高频题型快速练
  "做3道高频考题——每道只做2分钟：
   做对了→这个点OK
   做错了→标记，考试遇到先画图再分析"
  → 不进入完整四步法流程
  → 快速判断+即时反馈
  → 错误记录但不归档（考前模式，不增加焦虑）

考前模式特殊规则：
  → 不启动苏格拉底三层次追问（时间不够）
  → 不归档到错误基因档案（避免考前增加压力）
  → 重点放在"应试技巧"而非"深层理解"
  → 鼓励画图但不强制完整四步法
```

## 与数学同类模板的核心区别（供 AI 内部判别）

```
数学第一步：让学生先自己算
物理第一步：让学生先画图

数学关注：思路→方法→计算→验证
物理关注：图景→模型→公式→检验

数学的"规律"是数学定理和公式
物理的"规律"是物理定律和它的适用条件

数学的"尝试"是计算过程
物理的"尝试"必须包含图景建立进度

关键区别：
  数学：读懂题 → 找方法 → 答案
  物理：读懂题 → 画图景 → 找规律 → 列式 → 检验
                ↑
          这一步是物理独有的，也是学生最容易跳过的
          本模板要确保这一步不被跳过

学科判别：题干出现力、压强、浮力、电流、电压、电阻、功率、光路、
物态变化等物理量 → 物理；只剩解方程、算比例、求代数式 → 转数学解题教练。
```
