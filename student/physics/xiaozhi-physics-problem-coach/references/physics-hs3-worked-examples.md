## 高中·示例 1：碰撞——先判守恒，再验合理（F14、R13、C16）

> 光滑水平面上，质量 2 kg 的小球 A 以 3 m/s 的速度与静止的 1 kg 小球 B 正碰。（1）若碰后粘在一起，求共同速度和损失的动能；（2）若发生弹性碰撞，求碰后两球的速度。

先判断：水平面光滑，碰撞时间极短，系统动量守恒。规定 A 的初速度方向为正方向（P13）。
（1）2 × 3 = 3v，v = 2 m/s；碰前动能 9 J，碰后 6 J，损失 3 J。
（2）联立动量守恒和动能守恒：v_A = 1 m/s，v_B = 4 m/s，都沿原方向。
检验（R13）：碰后 B 在前、A 在后，v_B > v_A，合理；总动能没有增加。
**错解**：（1）认为粘在一起后动能不变，由 ½ × 3 × v² = 9 J 得 v ≈ 2.45 m/s——完全非弹性碰撞中动能不守恒，这个结果也违反动量守恒（C16）。

```verify
{"claim": "示例1：共同速度 2 m/s，损失动能 3 J；弹性碰撞后 v_A = 1 m/s、v_B = 4 m/s，动量 6、动能 9 J 不变", "expr": "[2 * 3 / 3, 0.5 * 2 * 9 - 0.5 * 3 * 4, (2 - 1) / (2 + 1) * 3, 2 * 2 / (2 + 1) * 3, 2 * 1 + 1 * 4, 0.5 * 2 * 1 + 0.5 * 1 * 16]", "expect": [2, 3, 1, 4, 6, 9]}
```

```verify
{"claim": "示例1错解：按动能守恒 v = √(2 × 9/3) ≈ 2.45 m/s，此时动量 3 × 2.45 ≈ 7.35 ≠ 6", "expr": "[Math.round(Math.sqrt(2 * 9 / 3) * 100) / 100, Math.round(3 * Math.sqrt(2 * 9 / 3) * 100) / 100]", "expect": [2.45, 7.35]}
```

## 高中·示例 2：动量定理——落地时的缓冲（F20、P13）

> 质量 60 kg 的人从 0.8 m 高处跳下，双脚着地后屈膝缓冲，经 0.2 s 停下。求地面对人的平均作用力。

落地速度 v = √(2gh) = 4 m/s。以竖直向上为正方向，对人：(F − mg)t = 0 − (−mv)，F = mg + mv/t = 600 + 1200 = 1800 N。
**错解**：忘了重力，F = mv/t = 1200 N（F20）；或不规定正方向，把落地速度当正值代入（P13）。追问：如果不屈膝，0.02 s 就停下，平均作用力变为多少？

```verify
{"claim": "示例2：v = 4 m/s，F = 600 + 1200 = 1800 N；漏掉重力得 1200 N；不屈膝（0.02 s）时 F = 12600 N", "expr": "[Math.sqrt(2 * 10 * 0.8), 60 * 10 + 60 * 4 / 0.2, 60 * 4 / 0.2, Math.round(60 * 10 + 60 * 4 / 0.02)]", "expect": [4, 1800, 1200, 12600]}
```

## 高中·示例 3：单摆测重力加速度——摆长要加半径（F19）

> 用单摆测重力加速度：摆线长 99.0 cm，摆球直径 2.0 cm，摆球完成 50 次全振动用时 100.0 s。求重力加速度（π² 取 9.87）。

摆长 L = 99.0 cm + 1.0 cm = 1.000 m；周期 T = 100.0/50 = 2.00 s；g = 4π²L/T² = π² ≈ 9.87 m/s²。
**错解**：摆长取线长 0.990 m，得 g ≈ 9.77 m/s²，偏小。

```verify
{"claim": "示例3：L = 1.000 m，T = 2 s，g = 4π²L/T² ≈ 9.87 m/s²；用线长 0.990 m 得 9.77 m/s²", "expr": "[0.99 + 0.01, 100 / 50, Math.round(4 * 9.87 * 1.0 / 4 * 100) / 100, Math.round(4 * 9.87 * 0.99 / 4 * 100) / 100]", "expect": [1, 2, 9.87, 9.77]}
```

## 高中·示例 4：机械波——波形图与振动（P14）

> 一列简谐横波沿 x 轴正方向传播，波速 2 m/s，波长 4 m。x = 0 处的质点在 t = 0 时位于平衡位置并向上振动。求：（1）波的周期；（2）x = 0 处的质点经过多长时间第一次到达波峰；（3）t = 0 时 x = 1 m 处的质点在什么位置。

（1）T = λ/v = 2 s。（2）从平衡位置向上振动到波峰用 T/4 = 0.5 s。（3）波沿 x 轴正方向传播，x = 1 m 处的振动比 x = 0 处落后四分之一个周期，t = 0 时它在波谷。
**错解**：把题里描述的某个质点的振动当成整条波形，或判断质点振动方向时不看传播方向。

```verify
{"claim": "示例4：T = 2 s，第一次到波峰用 0.5 s；y = A sin(ωt − kx) 在 t = 0、x = 1 m 处为 −A（波谷）", "expr": "[4 / 2, 4 / 2 / 4, Math.round(Math.sin(-2 * Math.PI * 1 / 4) * 1000) / 1000]", "expect": [2, 0.5, -1]}
```

## 高中·示例 5：折射与全反射——先判断临界角（P16）

> 光从折射率为 √3 的玻璃射向空气。（1）入射角为 30° 时，折射角多大？（2）入射角为 45° 时会发生什么？

（1）n = sin r / sin i（光从玻璃射入空气，r 是空气中的折射角），sin r = √3 × 0.5 = √3/2，r = 60°，折射光线偏离法线。
（2）临界角 sin C = 1/√3，C ≈ 35.3°；45° > C，发生全反射，没有折射光线。
**错解**：（2）照样用 sin r = √3 sin45° 求折射角——sin r > 1，本身就说明发生了全反射。

```verify
{"claim": "示例5：入射角 30° 时折射角 60°；临界角约 35.3°；入射角 45° 时 √3 sin45° > 1，发生全反射", "expr": "[Math.round(Math.asin(Math.sqrt(3) * 0.5) * 180 / Math.PI), Math.round(Math.asin(1 / Math.sqrt(3)) * 180 / Math.PI * 10) / 10, Math.sqrt(3) * Math.sin(Math.PI / 4) > 1]", "expect": [60, 35.3, true]}
```

## 高中·示例 6：带电粒子在匀强磁场中的圆周运动（P15、T11）

> 比荷为 1×10⁸ C/kg 的带正电粒子（不计重力），以 1×10⁶ m/s 的速度垂直射入磁感应强度为 0.1 T 的匀强磁场。求轨道半径和周期；若粒子在磁场中偏转了 60°，求它在磁场中运动的时间。

洛伦兹力提供向心力：qvB = mv²/r，r = mv/(qB) = 0.1 m；T = 2πm/(qB) ≈ 6.28×10⁻⁷ s。偏转 60° 即圆心角 60°，t = (60°/360°)T ≈ 1.05×10⁻⁷ s。
先定圆心：入射点和出射点的速度方向各作垂线，交点就是圆心（P15）。
**错解**：把 60° 直接代进 t = (θ/2π)T，得 t = (60/2π)T = 6.0×10⁻⁶ s，比一个周期还长——θ 用弧度时分母是 2π，用角度时分母是 360°（T11）。求出的时间要和周期比一比：偏转 60° 只转了 1/6 圈。

```verify
{"claim": "示例6：r = 0.1 m，T = 2π×10⁻⁷ s ≈ 6.28×10⁻⁷ s，偏转 60° 用时 T/6 ≈ 1.05×10⁻⁷ s", "expr": "[1e6 / (1e8 * 0.1), Math.round(2 * Math.PI / (1e8 * 0.1) * 1e9) / 100, Math.round(2 * Math.PI / (1e8 * 0.1) / 6 * 1e9) / 100]", "expect": [0.1, 6.28, 1.05]}
```

```verify
{"claim": "示例6错解：把 60° 直接代进 t = (θ/2π)T，得 (60/2π) × 2π×10⁻⁷ s = 6.0×10⁻⁶ s，大于周期 6.28×10⁻⁷ s，不合理", "expr": "[60 / (2 * Math.PI) * (2 * Math.PI / (1e8 * 0.1)), 60 / (2 * Math.PI) * (2 * Math.PI / (1e8 * 0.1)) > 2 * Math.PI / (1e8 * 0.1)]", "expect": [6e-6, true]}
```

## 高中·示例 7：楞次定律判断感应电流的方向（C17）

> 一个水平放置的闭合线圈，条形磁铁 N 极朝下：（1）从线圈正上方插入线圈；（2）再向上抽出。从上往下看，两次线圈中的感应电流各是顺时针还是逆时针？

分四步：① 原磁场：N 极朝下，线圈内的磁场方向向下；② 磁通量怎样变；③ 感应电流的磁场阻碍这个变化；④ 用安培定则由感应电流的磁场方向定电流方向。
（1）插入：磁通量增加，"增反"——感应电流的磁场在线圈内向上，从上往下看电流是逆时针。
（2）抽出：磁通量减少，"减同"——感应电流的磁场在线圈内向下，从上往下看电流是顺时针。
**错解**：第（2）问仍答逆时针——认为"感应电流的磁场总和原磁场相反"（C17）。第（1）问按这个迷思也能答对，所以要两问一起问。

## 高中·示例 8：导体棒切割——电动势、电流、安培力与能量（F15、R14、R15）

> 光滑水平导轨间距 0.5 m，处在竖直方向、磁感应强度为 0.4 T 的匀强磁场中，导轨左端接 0.2 Ω 的电阻（导轨与导体棒的电阻不计）。导体棒在水平外力作用下以 5 m/s 的速度向右匀速运动。求感应电动势、电流、所需外力和电阻的发热功率。

E = BLv = 1 V；I = E/R = 5 A；匀速时外力等于安培力 F = BIL = 1 N；外力的功率 Fv = 5 W，电阻的发热功率 I²R = 5 W——外力做的功全部转化为电能，再转化为焦耳热（R15）。
追问（R14）：撤去外力后，导体棒做什么运动？（速度减小 → 电动势减小 → 电流减小 → 安培力减小，做加速度逐渐减小的减速运动）
**错解**：认为光滑导轨上匀速运动不需要外力——导体棒受到与运动方向相反的安培力，外力要与它平衡，等于 1 N（R14）。

```verify
{"claim": "示例8：E = 1 V，I = 5 A，安培力 1 N，外力功率与发热功率都是 5 W", "expr": "[0.4 * 0.5 * 5, 0.4 * 0.5 * 5 / 0.2, 0.4 * 5 * 0.5, 1 * 5, 5 * 5 * 0.2]", "expect": [1, 5, 1, 5, 5]}
```

## 高中·示例 9：交变电流算电热用有效值（C19）

> 电压的瞬时值 u = 311 sin(100πt) V，把它加在 100 Ω 的电阻两端。求交流电的频率、电压的有效值和电阻 1 min 内产生的热量。


## 高中·示例 10：理想变压器（F16）

> 理想变压器原、副线圈的匝数比为 20 ∶ 1，原线圈接 220 V 的交流电，副线圈接 11 Ω 的电阻。求副线圈的电压、电流和原线圈的电流。

U₂ = U₁ × n₂/n₁ = 11 V；I₂ = U₂/R = 1 A；由 P₁ = P₂，I₁ = I₂ × n₂/n₁ = 0.05 A。
**错解**：I₁ = I₂ × n₁/n₂ = 20 A——把电流关系写成了与匝数成正比。

```verify
{"claim": "示例10：U₂ = 11 V，I₂ = 1 A，I₁ = 0.05 A，输入功率 = 输出功率 = 11 W；错解 20 A", "expr": "[220 / 20, 220 / 20 / 11, 1 / 20, 220 * (1 / 20), 1 * 20]", "expect": [11, 1, 0.05, 11, 20]}
```

## 高中·示例 12：光电效应——最大初动能由频率决定（C21、F18）

> 用波长为 400 nm 的光照射逸出功为 2.25 eV 的金属。求光子的能量（用 eV 表示）、光电子的最大初动能和遏止电压。

课标对光电效应方程是"知道"，按教材例题的深度逐步代入：光子能量 → 换算成 eV → 最大初动能 → 遏止电压。
ε = hc/λ = 6.63×10⁻³⁴ × 3×10⁸ / (4×10⁻⁷) J ≈ 4.97×10⁻¹⁹ J ≈ 3.11 eV；E_k = ε − W₀ ≈ 0.86 eV；遏止电压 U_c = E_k/e ≈ 0.86 V。
追问：换用同样波长、强度加倍的光，最大初动能变不变？（不变，只是单位时间打出的光电子更多）

```verify
{"claim": "示例12：ε ≈ 3.11 eV，E_k ≈ 0.86 eV，U_c ≈ 0.86 V", "expr": "[Math.round(6.63e-34 * 3e8 / 4e-7 / 1.6e-19 * 100) / 100, Math.round((6.63e-34 * 3e8 / 4e-7 / 1.6e-19 - 2.25) * 100) / 100]", "expect": [3.11, 0.86]}
```

## 高中·示例 13：半衰期与核反应方程（C22、T12）

> （1）碘-131 的半衰期约为 8 天，一批含碘-131 的样品，24 天后碘-131 还剩原来的几分之几？（2）写出铀-238 发生 α 衰变的核反应方程。

（1）24 天是 3 个半衰期，剩下 (1/2)³ = 1/8。这是对大量原子核的统计结论，对几个原子核不适用（C22）。
（2）²³⁸₉₂U → ²³⁴₉₀Th + ⁴₂He：质量数 238 = 234 + 4，电荷数 92 = 90 + 2。

```verify
{"claim": "示例13：24 天 = 3 个半衰期，剩 1/8；质量数、电荷数守恒", "expr": "[24 / 8, Math.pow(0.5, 24 / 8), 234 + 4, 90 + 2]", "expect": [3, 0.125, 238, 92]}
```
