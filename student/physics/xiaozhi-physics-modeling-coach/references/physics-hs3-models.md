## 高中·1. 碰撞与反冲（F14、R13）

- **识别特征**：碰撞、爆炸、反冲（火箭、人在船上走动）。
- **关键判断**：先判条件——系统所受外力的合力为零，或内力远大于外力；规定正方向；弹性碰撞再加动能守恒；解出的结果检验"动能不增加、后面的物体不穿越前面的物体"。
- **数学表达**：m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′；人船模型 m人 x人 = M船 x船。
- **算例**：长 3 m 的小船静止在水面上，质量 120 kg；质量 60 kg 的人从船头走到船尾（不计水的阻力）。系统动量守恒，m人 x人 = M船 x船，x人 + x船 = 3 m，得船后退 1 m，人相对地面前进 2 m。

```verify
{"claim": "人船算例：x船 = 60 × 3/(60 + 120) = 1 m，x人 = 2 m，且 60 × 2 = 120 × 1", "expr": "[60 * 3 / (60 + 120), 3 - 60 * 3 / (60 + 120), 60 * 2 === 120 * 1]", "expect": [1, 2, true]}
```

## 高中·2. 动量定理（F20、P13）

- **识别特征**：打击、缓冲、碰撞中的平均作用力；时间短、力变化复杂。
- **关键判断**：合力的冲量等于动量的变化，两边都是矢量，先规定正方向；竖直方向的碰撞不能漏掉重力。
- **数学表达**：F合 t = mv′ − mv。
- **算例**：质量 0.1 kg 的小球从 5 m 高处自由下落，与地面作用 0.1 s 后以 6 m/s 的速度反弹。取向上为正方向，碰前速度 −10 m/s，Δp = 0.1 × [6 − (−10)] = 1.6 kg·m/s；(F − mg) × 0.1 s = 1.6，地面的平均作用力 F = 17 N。

```verify
{"claim": "动量定理算例：碰前 10 m/s，Δp = 1.6 kg·m/s，F = 16 + 1 = 17 N", "expr": "[Math.sqrt(2 * 10 * 5), 0.1 * (6 - -10), 0.1 * (6 - -10) / 0.1 + 0.1 * 10]", "expect": [10, 1.6, 17]}
```

## 高中·3. 简谐运动与单摆（F19、C23）

- **识别特征**：弹簧振子；摆角很小的单摆；摆钟。
- **关键判断**：回复力与位移成正比、方向相反；单摆周期只与摆长和重力加速度有关，摆长从悬点量到球心。
- **数学表达**：F = −kx；T = 2π√(L/g)。
- **算例**：周期为 2 s 的单摆叫"秒摆"（每次经过平衡位置间隔 1 s）。g 取 9.8 m/s² 时，秒摆的摆长 L = gT²/(4π²) ≈ 0.99 m。

```verify
{"claim": "秒摆算例：L = 9.8 × 4/(4π²) ≈ 0.99 m", "expr": "Math.round(9.8 * 4 / (4 * Math.PI * Math.PI) * 100) / 100", "expect": 0.99}
```

## 高中·4. 机械波（P14、C23）

- **识别特征**：绳波、水波、声波；给出波形图或某个质点的振动情况。
- **关键判断**：波形图是某一时刻各质点的位置，振动图像是某一质点在各时刻的位置；波沿传播方向平移，由此判断质点的振动方向；质点只在各自的平衡位置附近振动，不随波迁移（C23）；波速由介质决定。
- **数学表达**：v = λ/T = λf。
- **算例**：一列简谐横波的波长为 4 m，某质点从波峰第一次回到平衡位置用了 0.25 s，即 T/4 = 0.25 s，T = 1 s，波速 v = λ/T = 4 m/s。

```verify
{"claim": "机械波算例：T = 4 × 0.25 = 1 s，v = 4/1 = 4 m/s", "expr": "[4 * 0.25, 4 / (4 * 0.25)]", "expect": [1, 4]}
```

## 高中·5. 光的折射与全反射（P16）

- **识别特征**：光从一种介质射入另一种介质；光纤、棱镜、水下光源。
- **关键判断**：先看光从哪种介质射向哪种介质；从光密介质射向光疏介质时，先比较入射角与临界角，再决定画折射光线还是全反射。
- **数学表达**：n = sinθ₁/sinθ₂（θ₁ 为真空或空气中的角）；n = c/v；sin C = 1/n。
- **算例**：光纤纤芯的折射率取 1.5，临界角 C = arcsin(1/1.5) ≈ 41.8°，光在纤芯中的速度 v = c/n = 2×10⁸ m/s。

```verify
{"claim": "光纤算例：C ≈ 41.8°，v = 3×10⁸/1.5 = 2×10⁸ m/s", "expr": "[Math.round(Math.asin(1 / 1.5) * 180 / Math.PI * 10) / 10, 3e8 / 1.5]", "expect": [41.8, 2e8]}
```

## 高中·6. 带电粒子在匀强磁场中的圆周运动（P15、T11）

- **识别特征**：带电粒子垂直磁场方向射入；质谱仪、回旋加速器。
- **关键判断**：洛伦兹力提供向心力；先定圆心（两处速度方向的垂线交点，或弦的中垂线与一处速度垂线的交点），再由几何关系求半径和圆心角；周期与速度无关。
- **数学表达**：qvB = mv²/r，r = mv/(qB)，T = 2πm/(qB)；经电压 U 加速后进入磁场，r = √(2mU/q)/B。
- **算例**（质谱仪）：电荷量相同、质量之比为 1 ∶ 4 的两种离子，经同一电压加速后进入同一磁场，半径之比 r₁ ∶ r₂ = √1 ∶ √4 = 1 ∶ 2——所以能按质量把它们分开。

```verify
{"claim": "质谱仪算例：r ∝ √m，质量比 1∶4 时半径比 1∶2", "expr": "Math.sqrt(1) / Math.sqrt(4)", "expect": 0.5}
```

## 高中·7. 导体棒切割（单棒）（R14、R15）

- **识别特征**：导轨上滑动的导体棒，处在匀强磁场中。
- **关键判断**：按"速度 → 电动势 → 电流 → 安培力 → 加速度"分析动态过程；安培力阻碍相对运动，最终往往达到匀速（受力平衡）；能量上，克服安培力做的功等于产生的电能。
- **数学表达**：E = BLv，I = E/R总，F安 = BIL = B²L²v/R总。
- **算例**：竖直放置的光滑导轨间距 0.5 m，磁感应强度 1 T 的匀强磁场垂直导轨平面，导轨下端接 0.5 Ω 的电阻（其余电阻不计）。质量 0.1 kg 的导体棒由静止释放，最终匀速时 mg = B²L²v/R，v = mgR/(B²L²) = 2 m/s；此时电流 2 A，重力的功率与电阻的发热功率都是 2 W。

```verify
{"claim": "导体棒算例：最终速度 2 m/s，电流 2 A，重力功率 = 发热功率 = 2 W", "expr": "[0.1 * 10 * 0.5 / (1 * 1 * 0.5 * 0.5), 1 * 0.5 * 2 / 0.5, 0.1 * 10 * 2, 2 * 2 * 0.5]", "expect": [2, 2, 2, 2]}
```

## 高中·8. 理想变压器与远距离输电（F16）

- **识别特征**：升压、降压；输电线上的电压损失和功率损失。
- **关键判断**：变压器只对交流起作用；理想变压器的输入功率由输出功率决定；输送功率一定时，提高输电电压、减小电流，线路损耗按电流的平方减小。
- **数学表达**：U₁/U₂ = n₁/n₂；只有一个副线圈时 I₁/I₂ = n₂/n₁；P损 = I²R线。
- **算例**：输送功率 100 kW，输电线电阻 1 Ω。用 1000 V 输电，电流 100 A，损失 10 kW（10%）；改用 10 kV 输电，电流 10 A，损失 100 W（0.1%）。

```verify
{"claim": "输电算例：1000 V 时损失 10000 W，10 kV 时损失 100 W", "expr": "[Math.pow(100000 / 1000, 2) * 1, Math.pow(100000 / 10000, 2) * 1]", "expect": [10000, 100]}
```

## 高中·9. 气体实验定律（F17）

- **识别特征**：气缸、活塞、液柱封闭的一定质量的气体。
- **关键判断**：先选定研究对象（一定质量的气体），列出初、末状态的 p、V、T；判断是等温、等容还是等压过程；温度用热力学温度；实际气体在压强不太大、温度不太低时可看成理想气体。
- **数学表达**：等温 p₁V₁ = p₂V₂（玻意耳定律）；等容 p₁/T₁ = p₂/T₂；等压 V₁/T₁ = V₂/T₂。
- **算例**：温度不变时，把 2 L、1.0×10⁵ Pa 的气体压缩到 0.5 L，压强变为 4.0×10⁵ Pa。

```verify
{"claim": "等温算例：p₂ = 1.0×10⁵ × 2/0.5 = 4.0×10⁵ Pa", "expr": "1e5 * 2 / 0.5", "expect": 4e5}
```

## 高中·10. 光电效应与能级跃迁（F18、C21）

- **识别特征**：光照射金属；原子发光或吸收光子。
- **关键判断**：光电子的最大初动能由光的频率决定；原子只吸收或放出能量等于两能级之差的光子（电离除外）；一群处在第 n 能级的氢原子向低能级跃迁，最多放出 n(n − 1)/2 种频率的光子（画能级图逐一数也可以）。课标对能级结构是"了解"、对光电效应方程是"知道"：按教材例题的深度计算（数谱线种类、由能级差求光子能量），等级考可与其他规律综合。
- **数学表达**：E_k = hν − W₀；hν = E_m − E_n。
- **算例**：一群处在 n = 4 能级的氢原子，最多放出 6 种频率的光子；其中能量最大的是从 n = 4 跃迁到 n = 1，E₄ − E₁ = −0.85 eV − (−13.6 eV) = 12.75 eV。

```verify
{"claim": "能级算例：4 × 3/2 = 6 种；E₄ − E₁ = −0.85 + 13.6 = 12.75 eV", "expr": "[4 * 3 / 2, Math.round((-0.85 - -13.6) * 100) / 100]", "expect": [6, 12.75]}
```
