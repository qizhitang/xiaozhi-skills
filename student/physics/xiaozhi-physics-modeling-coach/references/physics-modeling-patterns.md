# 物理建模模式详解

> 适用学段：初中（7-9 年级）。
> 本文档是物理建模教练的完整参考手册，涵盖建模通用框架、初中五大核心模型详解、模型识别决策树、跨模型综合题策略，以及文末的"初高衔接（⚠高中）"。
> 正文只写初中课标范围内的内容；超纲内容一律放进文末一节，且不作为讲解与出题依据。

---

## 一、建模通用三步框架

物理建模的核心思路是将文字描述的物理情境，转化为可计算的数学结构。这个过程分为三个步骤，每一步都有明确的任务和检测标准。

### Step 1：识别现象

**任务：把题目中的自然语言翻译成物理语言——"这道题描述了什么物理过程？"**

识别现象的关键是找到"变化"——物理题的本质就是描述某种变化，而变化就意味着有物理过程发生。

**识别现象三问：**

| 序号 | 追问内容 | 目的 |
|------|---------|------|
| ① | 题目中有哪些物体？ | 确定研究对象 |
| ② | 这些物体在做什么？（运动/静止/形变/发热/发光……） | 确定物理行为 |
| ③ | 有什么变化发生？（速度变化/温度变化/电路状态变化……） | 确定物理过程 |

**补充追问模板：**

- "用你自己的话说说，这道题描述了什么物理过程？"
- "你看到了什么现象？有什么在变化？"
- "题目中提到了哪些物理量？它们之间有什么关系？"
- "如果让你画一幅图来描述这个过程，你会画什么？"

**识别困难时的退回策略：**

- 看不出物理过程 → 退回读题画图，要求学生画草图标注关键信息
- 说不清什么在变化 → 提示"找变化量"：什么量在变？什么量不变？什么量是恒定的？
- 多个过程混在一起 → 提示"数一数，这道题描述了几个阶段？"

**识别成功的判定标准：** 学生能够用自己的话完整描述物理过程，而不是复述题目原文。

---

### Step 2：选择模型

**任务：从五大核心模型中选择——"这个现象属于哪类物理模型？"**

模型选择的本质是分类——将具体的物理情境归入已知的模型类别。每个模型都有明确的适用条件，选择模型就是判断题目条件是否满足某个模型的适用条件。

**模型识别决策树（简化版）：**

```text
这道题涉及的核心物理过程是什么？
│
├── 涉及运动快慢
│   └── 求速度、路程、时间、平均速度 → 匀速直线运动与平均速度模型
│
├── 涉及力
│   ├── 物体静止或匀速直线运动 → 力学平衡模型
│   ├── 杠杆/滑轮/机械效率 → 力学平衡模型（简单机械分支）
│   └── 压力与面积、液体深度、浮沉 → 压强与浮力模型
│
├── 涉及电路
│   ├── 分析电流/电压/电阻/功率关系 → 电路分析模型
│   └── 关注电能转化为其他形式能 → 能量守恒模型
│
└── 涉及能量转化
    └── 一种能量变为另一种能量 → 能量守恒模型
```

**模型选择追问模板：**

- "你观察到的现象，属于力的问题、电的问题、还是能量的问题？"
- "物体是静止的还是在运动？运动状态有没有改变？"
- "有没有能量从一种形式变成另一种形式？"
- "这道题的核心物理过程和哪个模型的条件最吻合？"

**选错模型时的纠正策略：**

- 不要直接说"你选错了"，而是引导检查适用条件
- "力学平衡模型要求物体静止或匀速直线运动，这个物体是吗？"
- "浮力用 F浮 = G物 有个前提——物体要漂浮或悬浮。这道题满足吗？"

---

### Step 3：数学表达

**任务：用数学语言描述模型——"模型告诉你哪些量之间有关系？把关系写成方程。"**

数学表达是建模的最终输出。从物理模型到数学方程，中间的桥梁是"核心关系式"——每个模型都有一个核心关系，把它写成数学形式就是方程。

**从模型到方程三步：**

| 步骤 | 操作 | 检查点 |
|------|------|--------|
| ① | 写出模型的核心关系式（先用符号，不代数字） | 公式形式是否正确？ |
| ② | 代入已知量（注意单位统一） | 单位是否统一？方向正负号是否正确？ |
| ③ | 求解未知量 | 结果是否合理？量纲是否正确？ |

**方程列不出时的追问模板：**

- "你选了[模型名称]，这个模型的核心关系是什么？"
- "模型告诉你[物理量A]和[物理量B]有什么关系？"
- "把这个关系写成数学表达式——左边是什么？右边是什么？"
- "你列的方程里，有几个未知数？需要几个方程才能解？"

**数学表达常见障碍：**

| 障碍 | 表现 | 处理方式 |
|------|------|---------|
| 不会写核心关系式 | "我知道是平衡但列不出式子" | 引导回忆模型的核心关系，从文字描述开始 |
| 方向正负号混乱 | "a到底取正还是取负？" | 强调先选正方向，再确定各量的正负 |
| 单位不统一 | "厘米和米能不能直接加？" | 列式前先统一单位到国际单位制 |
| 未知数太多 | "列了一个方程但有三个未知数" | 引导找补充条件或补充方程 |

## 二、匀速直线运动与平均速度模型

### 适用条件判断

- [ ] 物体沿直线运动
- [ ] 全程速度不变（匀速直线运动），或题目只要求某段/全程的平均速度
- [ ] 速度在变时，初中只作定性描述（越来越快 / 越来越慢），不作定量计算

**判断要点：** 只要题目给的是"路程和时间"，就用本模型；只要出现"平均速度"四个字，就必须回到定义式 v̄ = s总 / t总，不能把各段速度直接求平均。

### 标准建模流程

```text
第1步：画运动过程图
  - 一条直线代表运动路径，标出起点、终点和中间的转折点
  - 每一段标上它的路程 s 和时间 t

第2步：判断问的是哪一段
  - 某一段的速度 → 用这一段的 s 和 t
  - 全程平均速度 → 用总路程和总时间

第3步：统一单位
  - 长度统一为 m（或全程都用 km），时间统一为 s（或全程都用 h）
  - km/h → m/s 除以 3.6；m/s → km/h 乘以 3.6

第4步：列式求解
  - v = s / t

第5步：检验
  - 全程平均速度必须介于最慢一段和最快一段的速度之间
  - 数量级：人步行约 1.1 m/s，自行车约 5 m/s，汽车市区约 10-15 m/s
```

### 列式模板

```text
匀速直线运动：
  v = s / t，  s = v t，  t = s / v

平均速度（定义式，唯一正确写法）：
  v̄ = s总 / t总 = (s₁ + s₂ + …) / (t₁ + t₂ + …)

过桥/过隧道：
  车完全通过时走的路程 s = 桥长 + 车长

相遇（相向而行）：
  s₁ + s₂ = 两者初始距离

追及（同向而行）：
  s快 − s慢 = 初始距离
```

### 常见变形

**变形1：测平均速度实验**

- 情境：小车从斜面顶端下滑，分别测上半程、下半程、全程
- 结论：下半程速度 > 全程平均速度 > 上半程速度（小车越滑越快）
- 易错点：全程平均速度**不等于**上、下半程速度的算术平均值
- 操作要点：测上半程时不能让小车从中点起步，必须从顶端起步、在中点停表

**变形2：过桥问题**

- 情境：列车通过大桥、通过隧道
- 关键：路程要加上车身长度
- 易错点：只用桥长算，忘了车长

**变形3：相遇与追及**

- 相向：两段路程之和等于初始距离
- 同向：两段路程之差等于初始距离
- 关键：先在图上标出两个物体各自的起点和相遇点

**变形4：声与光的时间差**

- 情境：看到闪电后过了几秒听到雷声，估算距离
- 关键：光传播的时间可以忽略，用 s = v声 t，v声取 340 m/s
- 易错点：把光速也代进去算，或忘了声速的数值

### 常见错误类型

| 错误类型 | 表现 | 纠正方法 |
|---------|------|---------|
| 平均速度求算术平均 | (v₁+v₂)/2 | 回到定义：v̄ = s总/t总，先分别算出总路程和总时间 |
| 单位不统一 | km 与 m/s 混用 | 列式前先把所有量换成同一套单位 |
| 换算方向搞反 | m/s → km/h 也除以 3.6 | km/h → m/s 除以 3.6；反过来乘以 3.6 |
| 过桥漏车长 | 只用桥长 | 画图，把车头到车尾都画出来 |

### 追问序列

1. "这道题问的是哪一段的速度？某一段，还是全程？"
2. "全程的总路程是多少？总时间是多少？"
3. "如果直接把两段速度加起来除以 2，会得到什么？和用定义式算的一样吗？为什么不一样？"
4. "单位统一了吗？题目给的是 km/h 还是 m/s？"
5. "算出来的平均速度，比最慢那段快、比最快那段慢吗？"

## 三、力学平衡模型（初中版：同一直线上的二力平衡）

### 适用条件判断

- [ ] 物体处于静止状态，或做匀速直线运动
- [ ] 参与配对的两个力：大小相等、方向相反、作用在同一直线上、作用在同一个物体上（"同物、同线、等大、反向"）
- [ ] 涉及绕支点转动的硬棒时，改用杠杆平衡条件 F₁L₁ = F₂L₂

**判断要点：** "静止"和"匀速直线运动"在初中里是同一类状态——都叫平衡状态。初中只处理**同一直线上**的两个力，不把力分解到两个方向上去。题目里若出现斜面上的物体求沿斜面的分力，属于超纲，见文末"初高衔接（⚠高中）"。

### 标准建模流程

```text
第1步：确定研究对象
  - 明确分析哪个物体，一次只分析一个
  - 两个物体叠放时，先整体后隔离，或分别画两张图

第2步：画受力分析图
  - 按顺序找力：重力 → 接触产生的力（支持力/拉力/浮力）→ 摩擦力
  - 每个力从物体上画出，标明方向和符号
  - 每个力都要说得出施力物体；说不出来的就是多画的
  - 不要多画力（"下滑力""惯性力"都不是力）
  - 不要漏画力（最常漏：摩擦力、浮力）

第3步：判断运动状态
  - 静止或匀速直线 → 可以列平衡式
  - 在变速 → 初中只作定性判断（合力方向与运动方向的关系），不列式

第4步：把同一直线上的两个力配对
  - 竖直方向：拉力 / 支持力 / 浮力 ←→ 重力
  - 水平方向：拉力 / 推力 ←→ 摩擦力

第5步：列平衡式
  - F₁ = F₂

第6步：求解检验
  - 检查力的方向是否合理（支持力应指向物体，绳只能拉不能推）
  - 检查数量级（中学生体重约 400-600 N）
```

### 列式模板

**同一直线上的二力平衡：**

```text
竖直方向：F拉 = G  或  F支 = G  或  F浮 = G物（漂浮/悬浮）
水平方向：F拉 = f 滑动摩擦力（水平匀速拉动木块，这正是测摩擦力的原理）

注意：一对平衡力作用在**同一个**物体上；
      而"物体压桌面的力"与"桌面支持物体的力"作用在**两个**物体上，
      是相互作用力，不是平衡力。
```

**杠杆平衡：**

```text
F₁ × L₁ = F₂ × L₂

其中 L 为力臂——支点到力的作用线的垂直距离（不是支点到作用点的距离！）
```

**滑轮与滑轮组：**

```text
定滑轮：等臂杠杆，F = G，不省力但能改变力的方向
动滑轮：F = (G物 + G动) / 2，省一半力但费一倍距离
滑轮组：F = (G物 + G动) / n，绳子自由端移动距离 s = n h
机械效率：η = W有 / W总 = G物 h / (F s)
```

**浮力平衡：**

```text
阿基米德原理（普遍成立）：F浮 = G排 = ρ液 g V排
称重法（测浮力的实验方法）：F浮 = G物 − F示

平衡条件：F浮 = G物  （漂浮 / 悬浮时才成立）
下沉时：  F浮 < G物，容器底还要给一个支持力：F支 = G物 − F浮
```

### 常见变形

**变形1：悬挂问题**

- 情境：物体被一根竖直绳悬挂，处于静止
- 分析方法：以物体为研究对象，画重力和绳的拉力
- 平衡式：T = G = mg
- 关键：绳子只能拉不能推，拉力方向沿绳子方向
- 两根不在同一直线上的绳子同时拉一个物体，属 ⚠高中 内容，初中不作要求

**变形2：水平面上匀速拉动**

- 情境：用弹簧测力计水平匀速拉动木块
- 平衡式：F拉 = f 滑动摩擦力（这就是"测滑动摩擦力"实验的原理）
- 易错点：必须**匀速**拉动，读数才等于摩擦力；拉不匀速时读数不等于摩擦力
- 变化分析：增大压力或换粗糙的接触面 → 摩擦力变大；只增大速度 → 滑动摩擦力基本不变

**变形3：杠杆问题**

- 情境：硬棒绕支点转动，处于平衡
- 核心关系：F₁L₁ = F₂L₂
- 力臂的确定：从支点向力的作用线作垂线，垂线段就是力臂
- 易错点：力臂不是支点到作用点的距离！只有力的方向垂直于支点-作用点连线时两者才相等
- 变化分析：动力方向从垂直变为倾斜 → 动力臂变短 → 动力变大

**变形4：浮力问题**

- 情境：物体在液体中漂浮 / 悬浮 / 沉底
- 漂浮：F浮 = G物，V排 < V物
- 悬浮：F浮 = G物，V排 = V物
- 沉底：F浮 < G物，F支 = G物 − F浮
- 关键：漂浮和悬浮都是平衡态，区别在于排开液体的体积
- 易错点：浮力只与 ρ液 和 V排 有关，与物体密度、与浸没后的深度无关

### 常见错误类型

| 错误类型 | 表现 | 纠正方法 |
|---------|------|---------|
| 漏画力 | 忘了画摩擦力、浮力或支持力 | 按顺序找力：重力→接触力→摩擦力，逐一检查接触面 |
| 多画力 | 画了"下滑力""惯性力"作为独立的力 | 每个力都要说得出施力物体，说不出就删掉 |
| 平衡力与相互作用力混淆 | 把"压力"和"支持力"当成一对平衡力 | 平衡力作用在同一物体上，相互作用力作用在两个物体上 |
| 力臂概念错误 | 把支点到作用点的距离当力臂 | 力臂是支点到力的作用线的垂直距离，要画垂线 |
| 浮力条件误用 | 对沉底的物体用 F浮 = G物 | 只有漂浮/悬浮才有 F浮 = G物；一般情况用阿基米德原理或称重法 |

### 追问序列

1. "你确定研究对象了吗？是哪个物体？"
2. "按顺序数一数，这个物体受到了几个力？重力、接触力、摩擦力——都有吗？每个力是谁施加的？"
3. "这个物体是静止、匀速，还是在变速？"
4. "你配对的这两个力，是作用在同一个物体上吗？在同一条直线上吗？"
5. "你画的力臂对不对？力臂是从支点到哪里的距离？"
6. "如果把物体再往水里按下去一点（仍浸没），浮力会变吗？为什么？"

## 四、压强与浮力模型

### 适用条件判断

- [ ] 题目出现"压力""受力面积""压强""帕（Pa）"→ 固体压强
- [ ] 题目出现液体的"深度""液面下多少米"→ 液体压强
- [ ] 题目出现"浸入""浸没""漂浮""下沉""排开的液体"→ 浮力
- [ ] 题目出现"大气压""吸盘""覆杯"→ 大气压强

**判断要点：** 压强题先分清"压在固体表面"还是"在液体内部"。前者看 F 和 S，后者只看 ρ液 和 h，与容器形状、液体总量都无关。浮力题优先用阿基米德原理，只有确认漂浮/悬浮时才用 F浮 = G物。

### 标准建模流程

```text
第1步：判断类型
  - 固体压强 / 液体压强 / 浮力 / 大气压强

第2步：固体压强——先找 F 再找 S
  - 水平面上：F = G = mg（这一步最容易漏，桌上放物体时压力才等于重力）
  - S 是**实际接触**的面积；多个支点（如四条桌腿）要把面积相加
  - S 的单位必须换成 m²：1 cm² = 10⁻⁴ m²（÷10000，不是 ÷100）

第3步：液体压强——只看深度
  - h 从液面竖直向下量到该点，不是容器高度、不是物体高度
  - p = ρ液 g h，与容器粗细、形状、液体多少都无关

第4步：浮力——三条路选一条
  - 阿基米德原理：F浮 = ρ液 g V排（万能，最常用）
  - 称重法（实验）：F浮 = G物 − F示
  - 平衡法：F浮 = G物（**只在漂浮或悬浮时**成立）

第5步：检验
  - 浸没后再往深处放，F浮 不变（V排 不变）
  - 同一物体在盐水中比在清水中受的浮力大
  - 数量级：一个鸡蛋的浮力零点几牛，一个人的浮力几百牛
```

### 列式模板

```text
固体压强：
  p = F / S      （水平面上 F = G = mg）
  F = p S，  S = F / p

液体压强：
  p = ρ液 g h
  液体对容器底的压力：F = p S

阿基米德原理：
  F浮 = G排 = ρ液 g V排
  浸没时 V排 = V物；漂浮时 V排 < V物

浮沉条件（同一物体在同一液体中）：
  F浮 > G  →  上浮，最终漂浮
  F浮 = G  →  悬浮（浸没）或漂浮（部分露出）
  F浮 < G  →  下沉

漂浮时还有：ρ物 / ρ液 = V排 / V物
```

### 常见变形

**变形1：切去一半 / 叠放**

- 长方体沿水平方向切去上半部分：p = ρgh，h 减半 → 压强减半
- 长方体沿竖直方向切去一半：G 和 S 同时减半 → 压强不变
- 关键：先判断 F 和 S 各自怎么变，再看比值

**变形2：容器放在桌面上**

- 求液体对容器底的压强 → 用 p = ρ液 g h
- 求容器对桌面的压强 → 用 p = F/S，F 是容器和液体的**总重**
- 易错点：两个问题的 F 不是同一个，规则容器时液体对底的压力才等于液重

**变形3：浸入过程中的浮力变化**

- 物体从接触水面到刚好浸没：V排 变大 → F浮 变大 → 弹簧测力计读数变小
- 完全浸没后继续下降：V排 不变 → F浮 不变 → 读数不变
- 关键：画出"读数-深度"图像时，先斜线后水平

**变形4：冰化成水**

- 漂浮的冰块化成水后，液面高度不变
- 依据：漂浮时 F浮 = G冰 = G化成的水，排开水的体积等于化成水的体积

**变形5：大气压**

- 覆杯实验、吸盘、活塞式抽水机、高山上水的沸点低
- 一个标准大气压约 1.0×10⁵ Pa，托里拆利实验中约支持 760 mm 高的水银柱
- 易错点：说"水被吸上来"——实际是大气压把水**压**上来的

### 常见错误类型

| 错误类型 | 表现 | 纠正方法 |
|---------|------|---------|
| 单位不换算 | S 用 cm² 直接代入 | 1 cm² = 10⁻⁴ m²，先换算再代入 |
| 压力与重力混淆 | 斜面上或有额外压力时仍写 F = G | 只有物体自由放在水平面上时 F 才等于 G |
| h 取错 | 用容器高度或物体高度当深度 | h 是从液面到该点的竖直距离 |
| V排 取错 | 未浸没时用物体总体积 | V排 只算浸入液体的那部分 |
| 浮沉条件误用 | 对下沉物体写 F浮 = G物 | 只有漂浮/悬浮成立；一般用阿基米德原理 |
| 认为浮力随深度增大 | "越深浮力越大" | 浸没后 V排 不变，浮力就不变 |

### 追问序列

1. "这道题是压在固体表面上，还是在液体里面？"
2. "压力 F 是多少？它等于重力吗？为什么？"
3. "受力面积 S 是哪一块？单位换成 m² 了吗？"
4. "液体压强公式里的 h，你是从哪量到哪的？"
5. "这个物体是漂着、悬着，还是沉底？你怎么判断的？"
6. "把它再往下按 5 cm（仍然浸没），浮力会变吗？为什么？"

## 五、电路分析模型

### 适用条件判断

- [ ] 题目涉及电路，需要分析电流、电压、电阻、功率等量
- [ ] 电路中有明确的串并联结构（或可通过开关状态确定结构）
- [ ] 需要求解某个电学物理量

**判断要点：** 如果题目涉及"电能转化为其他形式能"而不仅仅是电路中的电压电流关系，应考虑使用能量守恒模型而非电路分析模型。两个模型可以组合使用。

### 标准建模流程

```text
第1步：画等效电路图
  - 根据开关状态画出简化电路
  - 每个开关状态画一张等效图（开关通断可能改变电路结构）
  - 滑动变阻器需要标注当前位置

第2步：识别串并联结构
  - 串联特征：电流只有一条路径，电流处处相等
  - 并联特征：电流有多条路径，各支路两端电压相等
  - 混联电路：先识别局部串并联，再逐步简化

第3步：标注已知量和未知量
  - 在电路图上标注每个元件的 R、U、I、P
  - 已知量标数值，未知量标符号
  - 特别标注额定值（额定电压、额定功率）和实际值

第4步：选择规律列方程
  - 欧姆定律：I = U/R（适用于纯电阻电路）
  - 串联分压：U₁/U₂ = R₁/R₂
  - 并联分流：I₁/I₂ = R₂/R₁
  - 电功率：P = UI = I²R = U²/R

第5步：求解检验
  - 检查功率是否超过额定值
  - 检查电流方向和大小是否合理
  - 检查串并联关系是否正确
```

### 列式模板

**欧姆定律：**

```text
I = U / R
变形：U = IR，R = U/I
适用条件：纯电阻电路（金属导体、电阻器等）
```

**串联电路：**

```text
电流：I = I₁ = I₂ = I₃ = ...
电压：U = U₁ + U₂ + U₃ + ...
电阻：R = R₁ + R₂ + R₃ + ...
分压：U₁/U₂ = R₁/R₂
功率：P₁/P₂ = R₁/R₂（串联时功率与电阻成正比）
```

**并联电路：**

```text
电压：U = U₁ = U₂ = U₃ = ...
电流：I = I₁ + I₂ + I₃ + ...
电阻：1/R = 1/R₁ + 1/R₂ + 1/R₃ + ...
分流：I₁/I₂ = R₂/R₁
功率：P₁/P₂ = R₂/R₁（并联时功率与电阻成反比）
```

**电功率：**

```text
P = UI = I²R = U²/R
W = Pt = UIt（电功）
Q = I²Rt（焦耳定律，电热）

注意区分：
  额定功率：P额 = U额 × I额（铭牌上的值）
  实际功率：P实 = U实 × I实（实际工作中的值）
  只有 U实 = U额 时，P实 才等于 P额
```

### 常见变形

**变形1：开关通断问题**

- 情境：电路中有开关，不同通断状态对应不同电路结构
- 解题方法：每个开关状态画一张等效电路图，分别分析
- 关键点：开关断开 = 该支路无电流；开关闭合可能短路某个元件
- 步骤：列出所有开关状态组合 → 逐一画等效图 → 分别列方程
- 易错点：开关闭合后可能将某个电阻短路，该电阻不再起作用

**变形2：滑动变阻器问题**

- 情境：电路中有滑动变阻器，滑片移动改变阻值
- 分析方法：找到滑片移动时接入电路的阻值如何变化
- 串联时：R滑增大 → 总电阻增大 → 总电流减小 → 各元件电压重新分配
- 并联时：R滑增大 → 该支路电流减小 → 干路电流减小；各支路两端电压不变（电源电压恒定）
- 极值分析：滑片在最左端和最右端分别对应什么阻值？
- 易错点：滑动变阻器接入电路的阻值取决于接线柱的选择，不是滑片位置

**变形3：多用电器组合问题**

- 情境：多个用电器串联或并联，分析功率分配
- 串联：P₁/P₂ = R₁/R₂（电阻大的用电器实际功率大）
- 并联：P₁/P₂ = R₂/R₁（电阻小的用电器实际功率大）
- 关键判断：用电器正常工作的条件是实际电压等于额定电压
- 功率比较技巧：先判断串并联，再根据功率与电阻的关系比较
- 易错点：额定功率和实际功率不能混淆——"220V 60W"的灯泡在110V下不是30W

### 常见错误类型

| 错误类型 | 表现 | 纠正方法 |
|---------|------|---------|
| 开关状态变化后未重新分析 | 用断开状态的电路算闭合状态的量 | 每个开关状态画一张等效图 |
| 混淆额定功率和实际功率 | 认为灯泡在任何电压下功率都是额定值 | P实 = (U实/U额)² × P额 |
| 串并联判断错误 | 把并联看成了串联（或反过来） | 从电源正极沿电流走一遍，确认路径 |
| 短路识别遗漏 | 闭合开关后某元件被短路但没发现 | 电流走最短路径——有零电阻旁路则元件被短路 |

### 追问序列

1. "你画等效电路图了吗？开关在这个状态下，电流从正极出发怎么走？"
2. "这些用电器是串联还是并联？你怎么判断的？"
3. "滑动变阻器滑片向右移，接入电路的阻值变大了还是变小了？"
4. "串联电路中功率和电阻是什么关系？并联呢？"
5. "这个灯泡的额定功率是60W，但实际电压只有110V，实际功率还是60W吗？"
6. "开关闭合后，有没有哪个元件被短路了？被短路的元件还有电流通过吗？"

## 六、能量守恒模型

### 适用条件判断

- [ ] 题目涉及不同形式能量之间的转化（动能↔势能、电能↔热能、机械能↔内能等）
- [ ] 需要分析能量的来源和去向
- [ ] 系统总能量守恒（输入能量 = 输出能量 + 损失能量）

**判断要点：** 当题目关注的是"能量从哪里来、到哪里去"而非具体的力或电路细节时，优先使用能量守恒模型。能量守恒模型是最高层次的模型，可以与其他模型组合使用——先用力学模型或电路模型分析具体过程，再用能量守恒模型验证结果。

### 标准建模流程

```text
第1步：列出所有能量形式
  - 初态有哪些能量？（E动能、E势能、E电能……）
  - 末态有哪些能量？
  - 有没有能量损失？（摩擦生热、电阻发热等）

第2步：画出能量转化路径图
  - 用箭头表示能量转化方向
  - 标注每种能量的数值（已知量）或符号（未知量）
  - 例：重力势能 → 动能 → 内能（摩擦损失）

第3步：列能量守恒方程
  - E初 = E末 + E损失
  - 或：E输入 = E输出 + E损失
  - 或：ΔE₁ + ΔE₂ + ... = 0（所有能量变化之和为零）

第4步：代入求解检验
  - 检查等式两边量纲是否一致
  - 检查能量损失项是否遗漏
  - 检查效率是否合理（0 < η ≤ 1）
```

### 列式模板

**机械能守恒（无摩擦）：**

```text
E初 = E末
½mv₀² + mgh₀ = ½mv² + mgh
（动能 + 重力势能 = 常数）
```

**机械能不守恒（有摩擦）：**

```text
E初 = E末 + E损失
½mv₀² + mgh₀ = ½mv² + mgh + f·s
（初态机械能 = 末态机械能 + 摩擦力做的功）
```

**电能转化：**

```text
W电 = W有用 + W损失
W电 = UI t（总电能）
W有用 = P有用 · t（有用能量）
W损失 = I²R t（焦耳热损失）
η = W有用 / W电 × 100%（效率）
```

**热力学（初中简化）：**

```text
Q吸 = cmΔt（吸热公式）
Q放 = mq 或 Q放 = Vq（燃料放热）
Q吸 = Q放（热平衡条件）
```

### 常见变形

**变形1：自由落体（重力势能→动能）**

- 情境：物体从高处自由下落（忽略空气阻力）
- 能量转化：重力势能 → 动能
- 守恒方程：mgh = ½mv²（下落高度 h，末速度 v）
- 速度公式：v = √(2gh)
- 易错点：h 是下落的竖直高度，不是路程

**变形2：摩擦做功（机械能→内能）**

- 情境：物体在粗糙水平面上滑动减速
- 能量转化：动能 → 内能（摩擦生热）
- 守恒方程：½mv² = f·s（初动能全部转化为内能）
- 摩擦力做功：W摩擦 = f·s = μmg·s
- 易错点：摩擦力做功的 s 是物体实际滑行的路程（不是位移），如果路程和位移相同则不影响

**变形3：电热器（电能→内能）**

- 情境：电热水器、电炉等纯电阻用电器
- 能量转化：电能 → 内能
- 守恒方程：W电 = Q热（纯电阻电路中电能全部转化为内能）
- W电 = UIt = I²Rt = U²t/R = Pt
- 效率问题：η = Q有用/W电（如加热水的效率，不是所有热量都被水吸收）
- 易错点：纯电阻电路 W电 = Q热；非纯电阻电路 W电 > Q热

**变形4：电动机（电能→机械能+内能）**

- 情境：电动机等非纯电阻用电器
- 能量转化：电能 → 机械能 + 内能
- 守恒方程：W电 = W机械 + Q热
- W电 = UIt，Q热 = I²Rt，W机械 = W电 - Q热
- 效率：η = W机械/W电 × 100%
- 关键区分：电动机的总功率 P = UI，发热功率 P热 = I²R，机械功率 P机械 = P - P热
- 易错点：电动机不能用欧姆定律 U = IR 计算（非纯电阻电路），UI ≠ I²R

### 常见错误类型

| 错误类型 | 表现 | 纠正方法 |
|---------|------|---------|
| 遗漏能量损失 | 自由落体算了动能变化但忘了摩擦 | 列出所有能量转化路径，逐一检查 |
| 电能等于电热 | 电动机问题中 W电 = Q热 | 只有纯电阻电路 W电 = Q热；非纯电阻 W电 > Q热 |
| 高度取错 | 用斜面长度代替竖直高度 | 重力势能 mgh 中的 h 是竖直高度 |
| 效率公式用错 | η = Q热/W电（电热器）套用到电动机 | 电热器效率是 Q有用/Q总；电动机效率是 W机械/W电 |

### 追问序列

1. "这道题涉及几种形式的能量？初态有哪些？末态有哪些？"
2. "能量从哪种形式转化为了哪种形式？你能画出转化路径图吗？"
3. "有没有能量损失？比如摩擦生热、电阻发热？"
4. "你列的能量守恒方程中，左边的能量和右边的能量一一对应了吗？有没有遗漏？"
5. "这是纯电阻电路还是非纯电阻电路？欧姆定律在这里能用吗？"
6. "你算出来的效率合理吗？效率应该在什么范围？"

## 七、模型识别决策树

当学生面对一道物理题不知从何入手时，以下决策树可以帮助快速定位应该使用的模型。决策树以题目中的关键词和核心物理过程为线索进行匹配。

### 完整决策树

```text
第一步：判断题目所属领域
│
├── 题目涉及运动快慢
│   │
│   └── 关键词出现"速度""平均速度""路程""用时""过桥""相遇""追上"
│       └──→ 匀速直线运动与平均速度模型
│           追加确认：问的是某一段的速度，还是全程平均速度？
│
├── 题目涉及力
│   │
│   ├── 关键词出现"匀速""静止""平衡""保持不动""匀速拉动"
│   │   └──→ 力学平衡模型
│   │       追加确认：配对的两个力是否作用在同一物体、同一直线上？
│   │
│   ├── 关键词出现"杠杆""支点""力臂""滑轮""滑轮组""机械效率"
│   │   └──→ 力学平衡模型（简单机械分支）
│   │       追加确认：力臂量对了吗？绳子几段承担物重？
│   │
│   └── 关键词出现"压力""受力面积""压强""深度""浮力""漂浮""浸没""排开"
│       └──→ 压强与浮力模型
│           追加确认：是压在固体表面，还是在液体内部？
│
├── 题目涉及电路
│   │
│   ├── 关键词出现"电路""电流""电压""电阻""欧姆""串并联""开关""变阻器"
│   │   └──→ 电路分析模型
│   │       追加确认：是否需要求电压电流功率？
│   │
│   └── 关键词出现"电热器""电动机""电能转化""效率""发热"
│       └──→ 能量守恒模型（电能转化路径）
│           追加确认：关注点在能量转化还是电路参数？
│
├── 题目涉及能量转化
│   │
│   ├── 关键词出现"能量""转化""守恒""动能""势能""内能""效率"
│   │   └──→ 能量守恒模型
│   │       追加确认：能量从哪里来、到哪里去？
│   │
│   └── 关键词出现"摩擦""做功""热"
│       └──→ 能量守恒模型（机械能→内能路径）
│
└── 无法直接归类
    │
    ├── 题目描述了多个过程
    │   └──→ 跨模型综合题策略（见第八节）
    │
    └── 确实无法归类
        └──→ 退回识别现象步骤，引导学生重新读题画图
```

### 关键词速查表

| 关键词 | 对应模型 | 判断理由 |
|-------|---------|---------|
| 匀速、静止、平衡、保持不动 | 力学平衡模型 | 同一直线上二力平衡 |
| 匀速拉动、弹簧测力计读数 | 力学平衡模型 | 拉力等于滑动摩擦力 |
| 杠杆、支点、力臂、滑轮组、机械效率 | 力学平衡模型（简单机械） | F₁L₁=F₂L₂ 与绳段数 |
| 速度、平均速度、路程、用时 | 匀速直线运动与平均速度模型 | v=s/t 与 v̄=s总/t总 |
| 过桥、过隧道、相遇、追上 | 匀速直线运动与平均速度模型 | 路程的加减关系 |
| 压力、受力面积、压强、帕 | 压强与浮力模型 | p=F/S |
| 深度、液面下、液体对底的压强 | 压强与浮力模型 | p=ρgh，只看深度 |
| 浮力、漂浮、悬浮、下沉、排开 | 压强与浮力模型 | 阿基米德原理与浮沉条件 |
| 大气压、吸盘、覆杯、抽水机 | 压强与浮力模型（大气压分支） | 大气压把液体压上来 |
| 电路、电流、电压、电阻 | 电路分析模型 | 欧姆定律与串并联 |
| 开关、通断、闭合、断开 | 电路分析模型 | 电路结构变化 |
| 滑动变阻器、滑片、阻值变化 | 电路分析模型 | 动态电路分析 |
| 串联、并联、分压、分流 | 电路分析模型 | 电路连接方式 |
| 能量、转化、守恒、效率 | 能量守恒模型 | 能量形式变化 |
| 动能、势能、机械能 | 能量守恒模型 | 机械能守恒或转化 |
| 摩擦、做功、发热、内能 | 能量守恒模型 | 机械能→内能 |
| 电热器、电动机、电热 | 能量守恒模型 | 电能→其他形式能 |

### 模型识别的追问模板

当学生无法判断使用哪个模型时，按以下顺序追问：

1. **领域判断：** "这道题主要是在讲力的问题、电的问题、还是能量的问题？"
2. **状态判断：** "物体是静止的、匀速的，还是速度在变？"
3. **过程判断：** "有没有什么物理过程在发生？比如浸入液体、开关通断、能量转化？"
4. **条件匹配：** "你说的这个现象，和哪个模型的适用条件最吻合？"
5. **验证确认：** "你选了这个模型，它的条件都满足吗？检查一下。"

## 八、跨模型综合题建模策略

综合题是物理考试中的压轴题，其本质是将多个物理过程组合在一起，每个过程对应一个物理模型。解决综合题的关键不是找一个万能模型，而是把复杂问题拆解为多个简单问题。

### 核心策略：分过程建模

```text
第1步：识别过程数量
  - 仔细读题，数一数题目描述了几个物理过程
  - 每个过程有独立的物理规律
  - 关键词："然后""之后""接着""此时"——这些词通常标记过程切换

第2步：逐过程建模
  - 对每个过程独立建模
  - 每个过程选择合适的模型
  - 每个过程独立列方程

第3步：找衔接点
  - 前一个过程的末状态 = 后一个过程的初状态
  - 最常见的衔接量：拉力或浮力（力学过程之间）、电源电压与定值电阻（电路各状态之间）、温度（热学过程之间）
  - 衔接点是连接各过程的桥梁

第4步：联立求解
  - 用衔接条件将各过程的方程连接
  - 整体求解或逐步代入
```

### 常见综合题类型

**类型1：力学综合——浮力 + 做功**

```text
题目特征：把浸没在水中的物体匀速提出水面，再匀速举高

过程1：物体完全浸没时匀速上提
  → 模型：压强与浮力模型 + 力学平衡模型
  → 式子：F拉 = G物 − F浮，F浮 = ρ水 g V物
  → 末状态：物体上表面刚到水面时的拉力

过程2：物体完全离开水面后匀速上升
  → 模型：力学平衡模型
  → 式子：F拉 = G物（衔接点：这一刻拉力从"扣掉浮力"变成"全部重力"）

过程3：求这一段拉力做的功
  → 模型：功、功率与能量转化模型
  → 式子：W = F拉 · h

衔接点：物体刚露出水面的瞬间，两个模型算出的拉力应当能对上
```

**类型2：力电综合——电路+力学**

```text
题目特征：电动机提升重物（电流做功转化为机械能）

过程1：电路分析
  → 模型：电路分析模型
  → 方程：求电动机的电流和电压

过程2：能量转化
  → 模型：能量守恒模型
  → 方程：W电 = W机械 + Q热

衔接点：电功率 P = UI
  电路分析得到的 P = 电动机总功率输入
  能量守恒中的 W电 = P × t
```

**类型3：力学+能量综合**

```text
题目特征：物体受力运动，同时涉及能量转化

建模策略：
  方案A：先用力学模型求力和加速度，再用运动学求速度，最后用能量验证
  方案B：直接用能量守恒模型求速度（更简洁）

选择建议：
  - 如果只需要求速度/高度 → 能量守恒模型更简洁
  - 如果需要求力/加速度 → 必须用力学模型
  - 如果需要验证 → 两种方法互相验证
```

**类型4：多状态电路综合——动态电路 + 电功率**

```text
题目特征：滑动变阻器滑片从一端移到另一端，问各表示数与功率如何变化

状态1：滑片在最左端（接入阻值最小 / 为零）
  → 模型：电路分析模型
  → 式子：R总 = R₁ + R滑，I = U / R总，U₁ = I R₁
  → 记下：电流表、电压表各自的读数

状态2：滑片在最右端（接入阻值最大）
  → 模型：电路分析模型（重画一张等效电路）
  → 式子同上，代入新的 R滑

变化趋势（初中常考的推导链）：
  R滑↑ → R总↑ → I↓ → U(R₁)↓ → U(R滑)↑ → P(R₁)↓

衔接点：两个状态共用同一个电源电压 U 和同一个定值电阻 R₁，
       这两个"不变量"就是列方程的桥梁
```

### 综合题建模追问序列

1. "这道题描述了几个物理过程？你能用序号标出来吗？"
2. "每个过程用什么模型？分别列一下。"
3. "前一个过程结束时的状态，和后一个过程开始时的状态，有什么联系？"
4. "衔接点上的物理量是什么？是速度？温度？还是别的？"
5. "你能把所有过程的方程列在一起，用衔接条件连接起来吗？"
6. "如果只看第一个过程，你能解出来吗？试试看，先解第一个过程。"

### 综合题常见错误

| 错误 | 表现 | 纠正方法 |
|------|------|---------|
| 不分过程 | 多段运动用同一个方程 | 标出过程切换点，每段独立建模 |
| 衔接条件错误 | 过程1末速度≠过程2初速度 | 明确写出衔接量的等式关系 |
| 模型混用 | 同一过程用了两个矛盾的模型 | 每个过程只选一个主要模型 |
| 漏掉中间过程 | 物体刚露出水面那一步没单独算 | 列出所有过程，检查有无遗漏 |

## 九、初高衔接（⚠高中）

以下模型**不在 2022 版初中物理课标范围内**。学生若从课外资料上看到并主动问起，一句话说明"这是高中的内容，初中不用这样做"，随后回到初中的替代做法；**不展开讲解、不出题、不写入错因档案**。

| ⚠高中 模型 | 一句话说明 | 初中的替代做法 |
|---|---|---|
| ⚠高中 匀变速直线运动 | 加速度恒定时，v=v₀+at、s=v₀t+½at²、v²−v₀²=2as | 初中只判断"越来越快/越来越慢"，定量只算平均速度 v̄=s总/t总 |
| ⚠高中 牛顿第二定律 F=ma | 合力与加速度成正比 | 初中只有牛顿第一定律（惯性）和二力平衡 |
| ⚠高中 力的正交分解 | 把重力分解为沿斜面的 mg sinθ 与垂直斜面的 mg cosθ，再列 ΣFx=0、ΣFy=0 | 初中斜面题只比较拉力与重力的大小、算机械效率 η=W有/W总 |
| ⚠高中 力的合成（不共线） | 两根不共线的绳同时拉一个物体，用平行四边形定则求合力 | 初中只作同一直线上二力的合成：同向相加、反向相减 |
| ⚠高中 动量与动量守恒 | m₁v₁+m₂v₂ = m₁v₁′+m₂v₂′ | **初中的碰撞题只作定性描述**：谁撞了谁、各自的运动状态怎么改变、力的作用是相互的、能量转化到哪里去了。不列任何守恒方程、不算碰后速度 |
| ⚠高中 机械能守恒的定量方程 | 无摩擦时 E动+E势 = 常数 | 初中只讲"动能与重力势能可以相互转化"，配合"能量守恒"作定性分析 |
