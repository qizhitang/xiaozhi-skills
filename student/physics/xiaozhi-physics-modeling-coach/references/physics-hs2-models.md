## 高中·1. 平抛运动（P10）

- **识别特征**：物体以水平初速度抛出，只受重力（空气阻力可忽略）。
- **关键判断**：分解为水平方向的匀速直线运动和竖直方向的自由落体运动，两个方向互不影响；落地时间只由高度决定。
- **数学表达**：x = v₀t；y = ½gt²；v_y = gt；v = √(v₀² + v_y²)。
- **算例**：从 45 m 高处以 40 m/s 的速度水平抛出。t = 3 s，x = 120 m，v_y = 30 m/s，落地速度 v = 50 m/s。

```verify
{"claim": "平抛算例：t = 3 s，x = 120 m，v_y = 30 m/s，v = 50 m/s", "expr": "[Math.sqrt(2 * 45 / 10), 40 * 3, 10 * 3, Math.hypot(40, 30)]", "expect": [3, 120, 30, 50]}
```

## 高中·2. 水平面内的匀速圆周运动（P11）

- **识别特征**：转盘上的物块、圆锥摆、火车或汽车转弯。
- **关键判断**：先找圆心和半径（圆心在轨道平面内），再找哪些力的合力指向圆心；向心力是效果力，不另画。
- **数学表达**：F合 = mv²/r = mω²r。
- **算例**：物块放在水平转盘上，离转轴 0.2 m，最大静摩擦力为重力的 0.5 倍。静摩擦力提供向心力，角速度最大时 0.5mg = mω²r，ω = √(0.5g/r) = 5 rad/s，超过就滑出去——与物块的质量无关。

```verify
{"claim": "转盘算例：ω最大 = √(0.5 × 10 / 0.2) = 5 rad/s", "expr": "Math.sqrt(0.5 * 10 / 0.2)", "expect": 5}
```

## 高中·3. 竖直面内的圆周运动（R10）

- **识别特征**：拱形桥、凹形路面、过山车、绳或杆拴着的小球在竖直面内转动。
- **关键判断**：在最高点和最低点，沿半径方向的合力提供向心力；轻绳（或轨道内侧）模型过最高点要满足 v ≥ √(gR)，轻杆（或管道）模型 v ≥ 0。
- **数学表达**：拱形桥顶 mg − N = mv²/r；绳模型最高点 mg + T = mv²/R。
- **算例**：质量 1000 kg 的汽车以 10 m/s 的速度通过半径 50 m 的拱形桥顶，桥面对它的支持力 N = mg − mv²/r = 8000 N，小于重力；速度达到 √(gr) ≈ 22.4 m/s 时，对桥面的压力为零。

```verify
{"claim": "拱形桥算例：N = 10000 − 1000 × 100/50 = 8000 N；压力为零时 v = √(gr) ≈ 22.4 m/s", "expr": "[1000 * 10 - 1000 * 100 / 50, Math.round(Math.sqrt(10 * 50) * 10) / 10]", "expect": [8000, 22.4]}
```

## 高中·4. 天体运动与卫星（C15、T10）

- **识别特征**：卫星、行星绕中心天体做匀速圆周运动。
- **关键判断**：万有引力提供向心力；在中心天体表面附近，用 GM = gR² 替换不知道的 GM（黄金代换，忽略天体自转）。
- **数学表达**：GMm/r² = mv²/r = mω²r = m(2π/T)²r；v = √(GM/r)，T = 2π√(r³/GM)。
- **算例**：地球半径取 6.4×10⁶ m，近地卫星的周期 T = 2π√(R/g) = 2π × 800 s ≈ 5027 s ≈ 84 min。轨道更高的卫星周期更长（同步卫星为 24 h）。

```verify
{"claim": "近地卫星算例：√(R/g) = 800 s，T = 2π × 800 ≈ 5027 s ≈ 84 min", "expr": "[Math.sqrt(6.4e6 / 10), Math.round(2 * Math.PI * 800), Math.round(2 * Math.PI * 800 / 60)]", "expect": [800, 5027, 84]}
```

## 高中·5. 动能定理（F11）

- **识别特征**：求变力做的功、曲线运动或多过程运动的速度，不关心中间的加速度和时间。
- **关键判断**：选定研究对象和过程，算所有力做功的代数和（总功），等于动能的变化；不需要考虑轨迹形状。
- **数学表达**：W总 = ½mv² − ½mv₀²。
- **算例**：质量 0.2 kg 的石块从 5 m 高处以 10 m/s 的速度抛出，落地速度为 14 m/s。重力做功 10 J，由动能定理 10 J − W克 = ½ × 0.2 × (14² − 10²) = 9.6 J，克服空气阻力做功 W克 = 0.4 J。检验：没有空气阻力时落地速度为 √200 ≈ 14.1 m/s，比 14 m/s 略大，说得通。

```verify
{"claim": "动能定理算例：重力做功 10 J，动能增加 9.6 J，克服阻力做功 0.4 J；无阻力时落地速度约 14.1 m/s", "expr": "[0.2 * 10 * 5, Math.round(0.5 * 0.2 * (196 - 100) * 1000) / 1000, Math.round((0.2 * 10 * 5 - 0.5 * 0.2 * (196 - 100)) * 1000) / 1000, Math.round(Math.sqrt(100 + 2 * 10 * 5) * 10) / 10]", "expect": [10, 9.6, 0.4, 14.1]}
```

## 高中·6. 机械能守恒（含系统）（F10）

- **识别特征**：光滑轨道、只受重力的抛体、弹簧连接的系统、绳连接的物体组。
- **关键判断**：先判条件——只有重力和系统内弹力做功；绳连接时对整个系统列守恒，单个物体的机械能不守恒。
- **数学表达**：E_k1 + E_p1 = E_k2 + E_p2，或 ΔE_k = −ΔE_p。
- **算例**：小球从光滑斜轨上由静止滑下，进入半径 R = 0.4 m 的竖直光滑圆轨道，要恰好通过圆轨道的最高点，释放高度至少多高？最高点 mg = mv²/R；由机械能守恒 mgh = mg · 2R + ½mv²，得 h = 2.5R = 1.0 m。

```verify
{"claim": "圆轨道算例：最高点 v² = gR = 4，h = 2R + v²/(2g) = 0.8 + 0.2 = 1.0 m = 2.5R", "expr": "[10 * 0.4, 2 * 0.4 + 10 * 0.4 / (2 * 10), 2.5 * 0.4]", "expect": [4, 1, 1]}
```

## 高中·7. 机车启动（F12）

- **识别特征**：汽车、火车以额定功率启动，或以恒定加速度启动。
- **关键判断**：P = Fv 里的 F 是牵引力；以恒定加速度启动时，牵引力不变、功率增大，功率达到额定功率时匀加速结束；此后功率不变、牵引力减小，速度最大时牵引力等于阻力。
- **数学表达**：F − f = ma；P = Fv；v_max = P额/f。
- **算例**：质量 2000 kg、额定功率 60 kW 的汽车，阻力 2000 N，以 1 m/s² 的加速度匀加速启动。牵引力 F = f + ma = 4000 N，匀加速结束时的速度 v₁ = P额/F = 15 m/s，用时 15 s；最大速度 v_max = 30 m/s。

```verify
{"claim": "机车算例：牵引力 4000 N，匀加速末速度 15 m/s、用时 15 s，最大速度 30 m/s", "expr": "[2000 + 2000 * 1, 60000 / 4000, 60000 / 4000 / 1, 60000 / 2000]", "expect": [4000, 15, 15, 30]}
```

## 高中·8. 带电粒子在电场中的加速与偏转（P10、R12）

- **识别特征**：带电粒子从静止经电场加速；或垂直电场方向射入匀强电场。
- **关键判断**：先判断要不要计重力（电子、质子等一般不计；带电小球、液滴一般要计）；加速用动能定理，偏转按类平抛分解；加速得到的速度就是偏转的初速度。
- **数学表达**：加速 qU = ½mv²；偏转 a = qE/m，x = v₀t，y = ½at²。
- **算例**：比荷为 1×10⁸ C/kg 的带正电粒子从静止经 50 V 电压加速，获得的速度 v = √(2qU/m) = 1×10⁵ m/s。

```verify
{"claim": "加速算例：v = √(2 × 10⁸ × 50) = 10⁵ m/s", "expr": "Math.sqrt(2 * 1e8 * 50)", "expect": 1e5}
```

## 高中·9. 闭合电路与电源的输出功率（C14、R11）

- **识别特征**：电源（有内阻）与外电路组成闭合回路；问电表示数变化、功率。
- **关键判断**：E = U + Ir；路端电压随外电阻增大而增大；动态分析按"局部 → 整体 → 局部"；外电阻等于内阻时电源的输出功率最大。
- **数学表达**：I = E/(R + r)；P出 = I²R。
- **算例**：E = 6 V、r = 2 Ω 的电源，外电阻 R = 2 Ω 时输出功率最大，为 E²/(4r) = 4.5 W；R = 1 Ω 和 R = 4 Ω 时输出功率都是 4 W——同一个输出功率可以对应两个外电阻。

```verify
{"claim": "输出功率算例：R = r 时 P = 4.5 W；R = 1 Ω 与 R = 4 Ω 时都是 4 W", "expr": "[Math.pow(6 / 4, 2) * 2, Math.pow(6 / 3, 2) * 1, Math.pow(6 / 6, 2) * 4]", "expect": [4.5, 4, 4]}
```
