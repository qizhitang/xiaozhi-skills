## 1. 匀变速直线运动

- **识别特征**：题目说"加速度不变""速度均匀增加 / 减小"。
- **关键判断**：先规定正方向（一般取初速度方向），与正方向相反的矢量带负号；五个量 v₀、v、a、t、x，知三求二。
- **数学表达**：v = v₀ + at；x = v₀t + ½at²；v² − v₀² = 2ax；x = (v₀ + v)t / 2。
- **算例**：初速度 2 m/s、加速度 3 m/s²，求 4 s 末速度与 4 s 内位移。v = 14 m/s，x = 32 m；用 v² − v₀² = 2ax 核对：196 − 4 = 192 = 2 × 3 × 32。

```verify
{"claim": "匀变速算例：v=14 m/s，x=32 m，且满足 v^2-v0^2=2ax", "expr": "[2 + 3 * 4, 2 * 4 + 0.5 * 3 * 16, 14 * 14 - 2 * 2 === 2 * 3 * 32]", "expect": [14, 32, true]}
```

## 2. 自由落体

- **识别特征**：由静止释放，空气阻力可忽略。
- **关键判断**：加速度为 g，与物体质量无关。
- **数学表达**：v = gt；h = ½gt²；v² = 2gh。
- **算例**：物体从 45 m 高处由静止下落，求落地时间与落地速度。t = 3 s，v = 30 m/s。

```verify
{"claim": "自由落体算例：45 m 高处下落用时 3 s，落地速度 30 m/s", "expr": "[Math.sqrt(2 * 45 / 10), 10 * Math.sqrt(2 * 45 / 10)]", "expect": [3, 30]}
```

## 3. 追及相遇

- **识别特征**：同一直线上两个物体，出发时刻、初速度或加速度不同。
- **关键判断**：两物体**速度相等**的时刻，是距离最大或最小的临界点；能否追上，看这一时刻后面的物体是否已追到前面的物体。
- **算例**：甲车以 10 m/s 匀速行驶，前方 x₀ 处的乙车同时由静止以 2 m/s² 同向匀加速。速度相等时 t = 5 s，这 5 s 内甲比乙多走 50 − 25 = 25 m。所以 x₀ < 25 m 时甲能追上乙；x₀ = 25 m 时恰好追上；x₀ > 25 m 时追不上，二者最小距离为 x₀ − 25 m。

```verify
{"claim": "追及算例：5 s 时速度相等，甲比乙多走 25 m", "expr": "[10 / 2, 10 * 5 - 0.5 * 2 * 25]", "expect": [5, 25]}
```

## 4. 共点力平衡

- **识别特征**：物体静止或做匀速直线运动，几个力作用于一点。
- **关键判断**：合力为零；两力平衡直接看，三力及以上用力的合成或正交分解，分别列两个方向的平衡方程。
- **算例**：重 20 N 的物体用两根绳悬挂，两绳与竖直方向的夹角都是 60°，求每根绳的拉力。竖直方向：2T cos60° = 20 N，T = 20 N。
  追问：夹角变大时绳的拉力怎样变？（变大——两绳越"张开"越费力）

```verify
{"claim": "共点力平衡算例：两绳各与竖直方向成 60° 时每根绳拉力 20 N", "expr": "Math.round(20 / (2 * Math.cos(Math.PI / 3)) * 1000) / 1000", "expect": 20}
```

## 5. 牛顿第二定律（单个物体）

- **识别特征**：已知力求加速度，或已知运动情况求力。
- **关键判断**：先受力分析、求合力，再用 F合 = ma；加速度方向与合力方向相同。
- **算例**：物块沿倾角 30° 的光滑斜面由静止下滑，求加速度。沿斜面方向只有重力的分力 mg sin30°，a = g sin30° = 5 m/s²（与质量无关）。

```verify
{"claim": "光滑斜面算例：a = g sin30° = 5 m/s²", "expr": "Math.round(10 * Math.sin(Math.PI / 6) * 1000) / 1000", "expect": 5}
```

## 6. 连接体

- **识别特征**：两个以上物体用绳、杆连接或相互挤压，一起运动。
- **关键判断**：求共同加速度用**整体法**；求物体之间的相互作用力用**隔离法**，隔离受力较少的那个物体更简单。
- **算例**：光滑水平面上，质量 3 kg 的物块 A 与 1 kg 的物块 B 用轻绳相连，用 8 N 的水平力拉 A，求绳的拉力。整体：a = 8 / 4 = 2 m/s²；隔离 B：T = m_B a = 2 N。

```verify
{"claim": "连接体算例：共同加速度 2 m/s²，绳的拉力 2 N", "expr": "[8 / (3 + 1), 1 * 8 / (3 + 1)]", "expect": [2, 2]}
```

## 7. 板块

- **识别特征**：木块放在木板上，外力作用在其中一个上，二者可能相对滑动。
- **关键判断**：先**假设**二者一起运动，求出共同加速度，再检验木块所需的静摩擦力是否超过最大静摩擦力（常取等于滑动摩擦力）；超过则相对滑动，分别列方程。
- **算例**：光滑地面上放着质量 2 kg 的木板，板上放 1 kg 的木块，木块与木板间的动摩擦因数为 0.2，水平拉力 F 作用在木板上。
  - 木块能获得的最大加速度 a_max = μg = 2 m/s²，对应的临界拉力 F = (2 + 1) × 2 = 6 N；
  - F = 3 N 时：假设一起运动，a = 1 m/s²，木块需要的静摩擦力 1 N ≤ 最大静摩擦力 2 N，确实一起运动；
  - F = 9 N 时：9 N > 6 N，相对滑动。木块 a₁ = μg = 2 m/s²；木板 a₂ = (9 − 2) / 2 = 3.5 m/s²。

```verify
{"claim": "板块算例：临界拉力 6 N；F=3 N 时一起运动 a=1；F=9 N 时木块 2 m/s²、木板 3.5 m/s²", "expr": "[(2 + 1) * 0.2 * 10, 3 / 3, 1 * (3 / 3) <= 0.2 * 1 * 10, 0.2 * 10, (9 - 0.2 * 1 * 10) / 2]", "expect": [6, 1, true, 2, 3.5]}
```

## 8. 传送带

- **识别特征**：物体放上运动的传送带。
- **关键判断**：比较物体与传送带的速度——物体比传送带慢，摩擦力沿传送带运动方向；速度相等后，水平传送带上的物体与传送带一起匀速运动（不再受摩擦力）。
- **算例**：水平传送带以 2 m/s 的速度匀速运动，长 4 m；把物块无初速地放在左端，物块与传送带间的动摩擦因数为 0.2。物块加速度 a = μg = 2 m/s²，1 s 后与传送带共速，这段位移 1 m；剩下 3 m 以 2 m/s 匀速走完，用时 1.5 s；共用时 2.5 s。加速的 1 s 内传送带走了 2 m，二者相对滑动 1 m。

```verify
{"claim": "传送带算例：1 s 共速、位移 1 m，匀速段 1.5 s，共 2.5 s，相对滑动 1 m", "expr": "[2 / (0.2 * 10), 0.5 * 2 * 1, (4 - 1) / 2, 2 / (0.2 * 10) + (4 - 1) / 2, 2 * 1 - 1]", "expect": [1, 1, 1.5, 2.5, 1]}
```
