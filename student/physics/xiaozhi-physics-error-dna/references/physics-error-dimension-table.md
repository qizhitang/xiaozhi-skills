# 物理错因维度表

> 适用学段：初中（7-9 年级）；第十至十二节为高中（第十节必修第一册，第十一节必修第二、三册，第十二节选择性必修）。
> 本文档为 `xiaozhi-physics-error-dna` 的核心参考资源，定义物理学科包的五维错因维度体系、子类型分类、跨维度关联规则与交接契约。
> 词表与阈值以 `shared/vocab.md` 为唯一来源；本表只定义物理子类型 ID 的含义（`shared/vocab.md §2`）。
>
> ⚠️ **编码命名空间**：本表子类型编码（P/C/F/R/T…）是**物理学科私有**——物理 `C`=概念混淆、`R`=过程分析。数学错因表的 `C`=计算失误、`R`=读题失误，含义不同。跨科交接或人工阅读时，编码须带学科前缀区分（物理记作 `物-C01`、数学记作 `数-C01`），不可仅凭字母跨科比对。

## 一、维度总览

```
物理错因维度体系（五维×多子类型）

维度①  图景建立错误 (P类) ── 物理独有的认知层错误
  "看不见"物理世界——不会画图、不会建立物理图景

维度②  概念混淆 (C类) ── 理解层错误
  物理概念理解偏差或相似概念混用

维度③  公式误用 (F类) ── 应用层错误
  知道公式但用错了——条件/单位/方向

维度④  过程分析错误 (R类) ── 分析层错误
  物理过程分析不完整或阶段划分错误

维度⑤  数学工具错误 (T类) ── 工具层错误
  物理思路对但数学执行出错

每道错题必须归入且只归入一个维度（主维度）。
如存在跨维度因素，记录为"主维度+次要维度"。

优先处理顺序：P类(图景) > C类(概念) > R类(过程) > F类(公式) > T类(数学)
→ 图景是一切物理分析的起点，图景错误会导致后续全错
```

## 二、维度①：图景建立错误

**定义：** 不会将文字描述转化为物理图景（受力分析图、运动过程图、电路图、光路图），导致后续分析缺乏可视化基础。

**判断标准：** 学生拿到题后直接列公式，不画图，或画的图有明显遗漏/错误。指出图景问题后能正确分析 → P类为主。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发学段 | 关联参考 |
|---------|------|---------|---------|---------|
| P01 | 不画受力分析图 | 凭感觉列方程，遗漏某个力 | 八年级力学 | → C01力概念混淆 |
| P02 | 运动过程分析不清 | 不会画v-t图/s-t图；过程转折点遗漏 | 八年级力学 | → R01过程阶段遗漏 |
| P03 | 电路图识别错误 | 串并联判断错误；等效电路画错 | 九年级电学 | → R03电路状态分析错误 |
| P04 | 光路图画错 | 反射角/折射角方向搞反；透镜成像位置错 | 八年级光学 | → C05光学概念混淆 |
| P05 | 参考系选取错误 | 以运动物体为参考系导致方向混乱 | 八年级力学 | → C02运动学概念混淆 |
| P06 | 隐含条件未图景化 | "光滑""轻质""缓慢"等条件没体现在图中 | 八-九年级 | → F01公式适用条件忽略 |
| P07 | 多对象关系图缺失 | 两个物体/两个电路状态不会分别画图再找关系 | 九年级 | → R02多过程关联遗漏 |

**严重程度分级：**

```
轻度（偶发）：P05 参考系选取错误
  → 处理：提醒即可，不启动专项训练

中度（模式化）：P01、P03、P04、P06
  → 处理：专项图景训练 + "先画图再列式"强制流程
  → 目标：建立"读题→画图→分析"的条件反射

重度（顽固）：P02、P07
  → 处理：图景重建训练 + 过程分析训练（联动建模教练和实验思维教练）
  → 运动过程图和多对象图景是最难建立的物理直觉
```

**根治方法映射：**

```
P01 不画受力图 → 受力分析四步法训练（选对象→画重力→画接触力→检验平衡）
  → 辅助工具：physics-diagram-guide.md 受力分析追问序列

P02 运动过程不清 → 运动过程图三步法（标状态→画过程→标转折）
  → 辅助工具：physics-diagram-guide.md 运动过程图追问序列

P03 电路图识别错误 → 电路分析三步法（识别串并联→画等效电路→标电流方向）
  → 辅助工具：physics-diagram-guide.md 电路图追问序列

P04 光路图画错 → 光路作图法（确定介质→确定入射面→画反射/折射路径）
  → 辅助工具：physics-diagram-guide.md 光路图追问序列

P06 隐含条件未图景化 → 关键词→图景标记训练
  → 建立"看到光滑→图中标注无摩擦""看到缓慢→图中标注近似平衡"的条件反射
```

## 三、维度②：概念混淆

**定义：** 对物理概念的理解有偏差，或把两个相似但本质不同的物理概念混用。

**判断标准：** 学生说"我知道这个概念但分不清它和那个的区别"，或对概念含义描述含糊。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发学段 | 关联参考 |
|---------|------|---------|---------|---------|
| C01 | 力的概念混淆 | 平衡力vs作用力反作用力；质量vs重力 | 八年级 | → concept-confusion-map §力学 |
| C02 | 运动学概念混淆 | 速度vs速率；路程（初中）——⚠加速度、位移属高中，初中不作要求 | 八年级/高中 | → concept-confusion-map §力学 |
| C03 | 压强概念混淆 | 压强vs压力；固体压强vs液体压强计算方法混用 | 八年级 | → concept-confusion-map §力学 |
| C04 | 浮力概念混淆 | 浮力方向判断错；浮力与排开液体重量的关系理解偏差 | 八年级 | → concept-confusion-map §力学 |
| C05 | 光学概念混淆 | 反射vs折射混用；实像vs虚像判断错 | 八年级 | → concept-confusion-map §光学 |
| C06 | 电学概念混淆 | 电流vs电压；电功vs电功率；短路vs断路 | 九年级 | → concept-confusion-map §电学 |
| C07 | 能量概念混淆 | 功vs能；动能vs势能；机械效率vs功率 | 八-九年级 | → concept-confusion-map §力学/电学 |
| C08 | 热学概念混淆 | 温度vs热量；蒸发vs沸腾；比热容vs热值 | 八年级 | → concept-confusion-map §热学 |

**严重程度分级：**

```
轻度：单一概念理解偏差 → 可通过生活类比一次解决
  → 处理：联动物理概念直觉器，一次类比追问重建理解

中度：两个概念混淆 → C01/C03/C06类型（最容易混淆的概念对）
  → 处理：概念对照表 + 追问 + 3道对比题
  → 工具：concept-confusion-map.md 对照追问

重度：根基概念缺失 → 影响多个后续概念
  → 如：力的概念不清 → 受力分析、力的合成、压强、浮力全部受影响
  → 处理：溯源补充前置概念，重建概念链
```

**根治方法映射：**

```
C类错误通用根治路径：
  ① 追问定位：用三层次追问第一层（现象层）确认混淆方向
  ② 类比重建：用物理概念直觉器SKILL提供生活类比
  ③ 对照区分：用concept-confusion-map做相似概念对比
  ④ 应用验证：出3道纯概念应用题确认理解
  ⑤ 迁移确认：出1道变形题确认不是只会原题

关键区分原则：
  → 如果学生说"我懂了"但同类题还是错 → C类（概念混淆）
    而不是T类（数学工具错误）
  → 区分标准：给一个简化版图景，概念判断做对了吗？
    做对了 → T类（计算执行错误）
    做错了 → C类（概念本身理解偏差）
```

## 四、维度③：公式误用

**定义：** 知道公式但用错了——适用条件不满足、单位不统一、方向不考虑等。

**判断标准：** 学生能说出公式，但代入的条件、单位或方向有误。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发学段 | 关联参考 |
|---------|------|---------|---------|---------|
| F01 | 公式适用条件忽略 | 密度公式用于混合物；欧姆定律用于非纯电阻 | 八-九年级 | → P06隐含条件未图景化 |
| F02 | 物理量单位不统一 | km/h与m/s混用；kW与W混用 | 八-九年级 | → T01单位换算错误 |
| F03 | 矢量方向未考虑 | 力的合成用代数加法；速度方向忽略 | 八年级 | → C01力的概念混淆 |
| F04 | 公式变形错误 | 从ρ=m/V推导m=ρV时搞反；I=U/R变形出错 | 八-九年级 | → T03代数运算错误 |
| F05 | 常数代入错误 | g=9.8取10时忘记说明；水的密度值记错 | 八-九年级 | — |
| F06 | 多公式联立错误 | 串联电路多步骤推理时公式选择混乱 | 九年级 | → R03电路状态分析错误 |
| F07 | 图像信息读取公式对应错误 | v-t图面积含义搞错；I-U图斜率含义搞错 | 八-九年级 | → P02运动过程分析不清 |

**严重程度分级：**

```
轻度：F05 常数记错 → 提醒即可
  → 处理：提供常数速查表

中度：F01、F02、F03、F04 → 系统性公式应用偏差
  → 处理：公式适用条件卡片 + 单位统一自检清单
  → 工具：physics-math-tools-checklist.md 自检步骤

重度：F06、F07 → 多公式联立或图像-公式对应失败
  → 处理：建模训练（联动物理建模教练）
  → 目标：建立"物理图景→选择公式→代入数据→检验单位"的完整流程
```

**根治方法映射：**

```
F01 公式适用条件忽略 → 公式卡片法
  → 每个公式写明：名称 / 表达式 / 适用条件 / 典型误用场景
  → 建立"用公式前先检查条件"的习惯

F02 单位不统一 → 单位统一自检法
  → 解题第一步：统一为国际单位制
  → 工具：physics-math-tools-checklist.md 单位换算表

F03 矢量方向 → 图景标注法
  → 在图景中用箭头标注所有矢量方向
  → 合成时用平行四边形法则，不是代数相加

F06 多公式联立 → 建模三步法
  → 联动物理建模教练：识别现象→选择模型→数学表达
```

## 五、维度④：过程分析错误

**定义：** 物理过程分析不完整，遗漏了关键阶段，或多个过程之间的关联关系理解错误。

**判断标准：** 学生能画出基本图景，但过程阶段有遗漏，或前后过程的衔接点搞错。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发学段 | 关联参考 |
|---------|------|---------|---------|---------|
| R01 | 过程阶段遗漏 | 多阶段运动只分析了一段；物态变化遗漏 | 八-九年级 | → P02运动过程分析不清 |
| R02 | 多过程关联遗漏 | 前一阶段的末状态不是下一阶段的初状态 | 九年级 | → P07多对象关系图缺失 |
| R03 | 电路状态分析错误 | 开关闭合/断开前后电路结构变化没分析 | 九年级 | → P03电路图识别错误 |
| R04 | 能量转化路径遗漏 | 摩擦生热没算；电能→热能+光能拆分错误 | 八-九年级 | → C07能量概念混淆 |
| R05 | 极值/临界条件遗漏 | "刚好离开""最大距离"等临界条件没分析 | 八-九年级 | → F01公式适用条件忽略 |
| R06 | 实验过程设计缺陷 | 控制变量遗漏；测量顺序错误 | 八-九年级 | → 实验思维教练联动 |

**严重程度分级：**

```
轻度：R01 单一过程遗漏 → 补充即可
  → 处理：提示"还有其他过程吗？"

中度：R02、R03、R04 → 多过程/多状态关联遗漏
  → 处理：过程图训练 + "每个转折点单独画图"习惯
  → 特别：R03电路状态分析是九年级物理最大失分点之一

重度：R05、R06 → 临界条件分析缺失或实验设计缺陷
  → 处理：临界条件专项训练（联动物理建模教练）
  → 实验设计训练（联动物理实验思维教练）
```

**根治方法映射：**

```
R类错误通用根治路径：
  ① 过程拆分：把完整物理过程拆成若干阶段
  ② 逐段画图：每个阶段画一张独立的图景
  ③ 找衔接点：前一段的末状态 = 下一段的初状态
  ④ 分别列式：每段独立列方程
  ⑤ 联立求解：用衔接点关系联立方程

R03 电路状态分析专项：
  → 每个开关状态画一张等效电路图
  → 标注：开关闭合/断开 → 串并联结构变化 → 总电阻变化 → 总电流变化
  → 工具：physics-diagram-guide.md 电路图三步法
```

## 六、维度⑤：数学工具错误

**定义：** 物理分析思路正确，但在数学执行层面出错——单位换算、比例运算、代数计算、几何关系等。

**判断标准：** 学生物理概念清楚、图景正确、公式选择对，但最终计算结果不对。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发学段 | 关联参考 |
|---------|------|---------|---------|---------|
| T01 | 单位换算错误 | cm²→m²除以100而非10000；kW·h→J换算错误 | 八-九年级 | → F02物理量单位不统一 |
| T02 | 比例运算错误 | 串联分压/并联分流比例计算出错 | 九年级 | → F06多公式联立错误 |
| T03 | 代数运算错误 | 解方程出错；代入数值计算出错 | 八-九年级 | → F04公式变形错误 |
| T04 | 几何关系错误 | 杠杆力臂找错；光路几何角度算错 | 八年级 | → P04光路图画错 |
| T05 | 图像读取错误 | 坐标轴含义搞错；比例尺忽略 | 八-九年级 | → F07图像信息读取错误 |
| T06 | 科学计数法错误 | 10⁻³写成10³；指数运算出错 | 八-九年级 | — |
| T07 | 近似与精度处理错误 | 中间步骤取整导致最终结果偏差大 | 八-九年级 | — |

**严重程度分级：**

```
轻度：T05、T06、T07 → 偶发性数学操作错误
  → 处理：提醒注意，不启动专项训练

中度：T01、T02、T03 → 系统性数学工具薄弱
  → 处理：数学工具自检清单 + 专项练习
  → 工具：physics-math-tools-checklist.md
  → 关键：区分是"物理问题"还是"数学问题"

重度：T04 几何关系错误 → 可能是图景问题而非数学问题
  → 处理：先确认图景是否正确，再处理几何计算
  → 如力臂找错 → 可能是P01（不会画受力图）而非T04
```

**根治方法映射：**

```
T类错误核心原则：
  → 先确认物理分析没错（图景对、概念对、公式对）
  → 再针对数学薄弱点做专项训练
  → 不在物理SKILL中做纯数学教学，而是建立"物理情境→数学执行"的桥梁

T01 单位换算 → 国际单位制速查表 + 每次计算前统一单位
T02 比例运算 → 串联分压/并联分流公式推导训练（理解而非记忆）
T03 代数运算 → 分步计算法（每步只做一次运算，减少出错机会）
T04 几何关系 → 图景标注法（在图中直接标注力臂、角度、距离）
```

## 七、跨维度关联规则

```
维度间常见交叉：

P01(不画受力图) + C01(力概念混淆)
  → 判断：画了受力图后能列对式子吗？
    能 → P类为主（图景缺失导致概念无法正确应用）
    不能 → C类为主（概念本身有偏差）

P06(隐含条件未图景化) + F01(公式适用条件忽略)
  → 判断：指出隐含条件后，能用对公式吗？
    能 → P类为主（图景意识不足导致条件遗漏）
    不能 → F类为主（即使条件明确了也不会用公式）

F02(单位不统一) + T01(单位换算错误)
  → 判断：知道需要统一单位但换算出错？
    是 → T类为主（数学工具问题）
    否(不知道要统一) → F类为主（物理公式意识问题）

R01(过程阶段遗漏) + P02(运动过程分析不清)
  → 判断：画了过程图后能完整分析吗？
    能 → P类为主（图景不清导致过程遗漏）
    不能 → R类为主（分析能力本身不足）

R03(电路状态分析错误) + P03(电路图识别错误)
  → 判断：画出等效电路后能正确分析吗？
    能 → P类为主（图景缺失导致分析错误）
    不能 → R类为主（过程分析能力不足）

C06(电学概念混淆) + F06(多公式联立错误)
  → 判断：明确概念后能选对公式吗？
    能 → C类为主（概念混淆导致公式选错）
    不能 → F类为主（公式应用本身有问题）

跨维度记录格式：
  主维度：[维度ID+子类型ID]
  次要维度：[维度ID+子类型ID]（如有）
  交叉判断依据：[图景辅助后结果/条件明确后结果]

优先处理顺序：
  P类(图景) > C类(概念) > R类(过程) > F类(公式) > T类(数学)
  → 图景是物理分析的起点，图景错了一切都错
  → 概念是图景的语言化，概念错了图景无法正确建立
  → 过程分析依赖正确的图景和概念
  → 公式应用建立在正确的分析之上
  → 数学工具是最后一层，解决前面的层次问题后自然改善
```

## 十一、高中：必修第二、三册的子类型

本节子类型用于高一下学期到高二学习必修第二、三册的学生；编号接在第十节之后，五个维度的定义不变。
内容范围对应课标必修 2 的"机械能及其守恒定律""曲线运动与万有引力定律"与必修 3 的"静电场""电路及其应用"。必修 2 的"牛顿力学的局限性与相对论初步"、必修 3 的"电磁场与电磁波初步"和"能源与可持续发展"以了解、知道为主，不单设子类型，遇到时只做通用四维分类。学业水平合格性考试考必修三册（第十、十一节），没有选考物理的学生按合格考的深度分析。

| 子类型ID | 维度 | 名称 | 典型表现 | 关联参考 |
|---|---|---|---|---|
| P10 | 图景建立 | 抛体与类平抛不做分解 | 平抛运动（或带电粒子垂直射入匀强电场的类平抛运动）沿着轨迹直接列式，不分成两个方向；求末速度时不画速度合成图，把两个分速度直接相加；把位移的方向当成速度的方向 | → P02 运动过程分析不清 |
| P11 | 图景建立 | 找不到向心力的来源 | 在受力图里另画一个"向心力"；不先确定圆心、半径和轨道平面，如把圆锥摆的半径取成绳长 | → P01 不画受力分析图 |
| P12 | 图景建立 | 电场线与等势面的图景不清 | 由电场线的疏密判断场强大小、由电场线的方向判断电势高低时弄反；把电场线当成带电粒子的运动轨迹 | → C13 |
| C12 | 概念混淆 | 功的正负与功率的概念混淆 | "力与位移方向相反时不做功"；"负功就是做的功少"——负功表示这个力阻碍物体运动（物体克服它做功），不表示做的功少；"功率大，做的功就多"（还要看时间） | → C07 能量概念混淆 |
| C13 | 概念混淆 | 电场强度、电势、电势能混淆 | "场强为零的地方电势一定为零"；"电势高的地方，电荷的电势能一定大"（负电荷在电势高处电势能反而小） | → C06 电学概念混淆 |
| C14 | 概念混淆 | 电动势与路端电压混淆 | 电路接通时，把接在电源两端的电压表读数当成电动势；"外电阻变大，路端电压不变"（外电阻变大时电流变小、内电压变小，路端电压变大） | → C06 |
| C15 | 概念混淆 | 卫星的速度与轨道高度关系颠倒 | "轨道越高，卫星跑得越快"；把第一宇宙速度的两个含义（最大的环绕速度、最小的发射速度）说反 | → T10 |
| F10 | 公式误用 | 机械能守恒的条件没判断 | 有摩擦力或其他外力做功时仍列机械能守恒；两个物体组成的系统只对其中一个物体列守恒 | → F01 公式适用条件忽略 |
| F11 | 公式误用 | 动能定理中的功不是总功 | 只算拉力做的功，漏掉摩擦力或重力做的功；负功按正值代入 | → F08 牛顿第二定律中的 F 不是合力 |
| F12 | 公式误用 | 功率问题中牵引力与合力混用 | 机车问题中把 P = Fv 的牵引力与合力混为一谈：用 P/v 求出的牵引力直接当合力求加速度，或用合力乘速度求功率；平均功率 P = W/t 与瞬时功率 P = Fv 混用。机车、功率情境记 F12，其余情境中合力取错记 F08 | → F08 |
| F13 | 公式误用 | 非纯电阻电路套用欧姆定律 | 电动机转动时仍用 I = U/R 求电流；把电功 W = UIt 与电热 Q = I²Rt 当成同一个量 | → F01 |
| R10 | 过程分析 | 竖直面圆周运动的临界条件用错 | 轻绳拉着的小球过最高点的最小速度是 √(gR)，轻杆连着的小球最小速度可以为 0，两者混用 | → R05 极值/临界条件遗漏 |
| R11 | 过程分析 | 动态电路的分析顺序错误 | 滑动变阻器的阻值变化后，不按"局部电阻 → 总电阻 → 总电流 → 路端电压 → 各支路"的顺序推，凭感觉判断电表示数的变化 | → R03 电路状态分析错误 |
| R12 | 过程分析 | 带电粒子在电场中的多过程没衔接 | 先加速、再偏转、出电场后的几段运动没接上：加速得到的速度没有作为偏转的初速度；出场后的匀速直线运动（不计重力时）没接上，如求打到屏上的位置时，没有从出场点沿出场速度的方向外推；不判断该不该计重力（电子、质子等一般不计，带电小球、液滴一般要计） | → R02 多过程关联遗漏 |
| T10 | 数学工具 | 天体运动的比例关系推错 | 由万有引力提供向心力推 v、ω、T、a 与轨道半径 r 的关系时指数写错，如把 T ∝ r^(3/2) 写成 T ∝ r² | → T02 比例运算错误 |

**跨维度判断**（判断顺序仍按第七节：P > C > R > F > T）

```text
P11(找不到向心力的来源) + R10(竖直面圆周运动的临界条件用错)
  → 判断：请学生先说出小球在最高点"谁提供向心力"
    说不出 → P11
    说得出，最小速度仍用错（绳、杆不分） → R10

P12(电场线与等势面的图景不清) + C13(场强、电势、电势能混淆)
  → 判断：给一张等量异种点电荷的电场线图，请学生在图上标出两点场强的大小关系和电势的高低
    图上就标错 → P12
    图上标对，文字判断仍错（如"场强为零处电势为零"） → C13

C14(电动势与路端电压混淆) + R11(动态电路的分析顺序错误)
  → 判断：请学生说出 U = E − Ir 里每个量的含义
    说不出，或认为路端电压不随电流变化 → C14
    说得出，推电表示数变化时顺序乱 → R11

C15(卫星的速度与轨道高度关系颠倒) + T10(天体运动的比例关系推错)
  → 判断：先给出推好的 v = √(GM/r)，请学生读出 v 随 r 怎样变化
    读反了（仍说"越高越快"） → C15
    读对了，再请学生自己从"万有引力提供向心力"推一遍：列式对、指数算错 → T10

F10(机械能守恒的条件没判断) + F11(动能定理中的功不是总功)
  → 判断：这个过程中，除重力和系统内弹力以外，还有没有别的力做功？
    有，却列了机械能守恒 → F10
    用的是动能定理，但漏算了某个力的功或把负功当正功 → F11

P10(抛体与类平抛不做分解) + R12(带电粒子在电场中的多过程没衔接)
  → 判断：请学生先画出分解图（两个方向的分位移、分速度）
    画不出，或分不清位移的方向与速度的方向 → P10
    分得清，但加速、偏转、出场几段运动没衔接，或该计重力没计 → R12
```

## 十二、高中：选择性必修的子类型

本节子类型用于选考物理的学生（学业水平等级性考试考必修与选择性必修）；编号接在第十一节之后，五个维度的定义不变。
内容范围对应选择性必修 1（动量与动量守恒定律、机械振动与机械波、光及其应用）、选择性必修 2（磁场、电磁感应及其应用、电磁振荡与电磁波、传感器）、选择性必修 3（固体液体和气体、热力学定律、原子与原子核、波粒二象性）。没有选考物理的学生遇到这些内容，说明它属于选择性必修，只做通用四维分类。

```text
    方向错：用楞次定律判断时错 → C17；导体切割时把左手定则当成右手定则 → C18
```
