## 一、高中·实验 5：验证机械能守恒定律（safetyLevel：中，涉及打点计时器接线）

- **器材与安全**：铁架台、打点计时器、纸带、重物。电磁打点计时器接学生电源的低压交流挡，接线由老师检查；电火花计时器接 220 V 交流电源，插头的插拔一律由老师完成，学生只操作计时器上的开关，不碰插头、插座与电源线；工作时放电针处有火花放电：穿纸带、调整墨粉纸盘前先关开关，工作时不碰放电针和纸盘（以说明书为准）。重物下方的地面垫软物，释放时手和脚离开下落路径。
- **操作顺序**：纸带竖直穿过限位孔，重物靠近计时器；先接通电源、打点稳定后再释放纸带。
- **为什么不必测质量**：要验证的是 mgh = ½mv²，两边都有 m，可以约去。
- **数据处理**：取纸带上的某点 B，测出它到起点 O 的距离 h；B 点的瞬时速度用前后相邻两段的平均速度求。比较 gh 与 ½v²。
- **误差**：重物和纸带受空气阻力、限位孔的摩擦，动能的增加量总是略小于重力势能的减少量——这是系统误差，不是"做错了"。

**算例**：打点间隔 0.02 s，OB = 19.60 cm，B 点前后相邻两段分别为 3.70 cm、4.08 cm。v_B = (3.70 + 4.08) cm / 0.04 s ≈ 1.945 m/s；每千克重物减少的重力势能 gh ≈ 1.92 J，增加的动能 ½v_B² ≈ 1.89 J，略小，符合预期。

```verify
{"claim": "实验5：v_B ≈ 1.945 m/s，gh ≈ 1.92 J/kg，½v² ≈ 1.89 J/kg，动能增加量略小于势能减少量", "expr": "[Math.round((3.70 + 4.08) / 0.04 / 100 * 1000) / 1000, Math.round(9.8 * 0.196 * 100) / 100, Math.round(0.5 * Math.pow((3.70 + 4.08) / 0.04 / 100, 2) * 100) / 100, 0.5 * Math.pow((3.70 + 4.08) / 0.04 / 100, 2) < 9.8 * 0.196]", "expect": [1.945, 1.92, 1.89, true]}
```

**常见错误**：用 v = gt 或 v² = 2gh 求速度（这等于先承认了机械能守恒，没有验证）；先释放纸带后接通电源。

## 二、高中·实验 6：探究平抛运动的特点（safetyLevel：低）

- **方法**：先比较——用两个小球演示，一个平抛、一个同时自由下落，听落地声判断同时落地，说明竖直方向是自由落体；再描迹——斜槽末端调水平，小球每次从同一位置由静止释放，在白纸或方格纸上记下一系列位置，连成平滑曲线。
- **为什么**：斜槽末端水平，小球才做平抛；每次从同一位置释放，初速度才相同；斜槽有摩擦不影响，因为只要求每次初速度相同。
- **数据处理**：以抛出点为原点，量出轨迹上某点的 x、y，t = √(2y/g)，v₀ = x/t；或用频闪照片：竖直方向相邻相等时间间隔内的位移差恒为 gT²。

**算例**：轨迹上一点 x = 30.0 cm、y = 19.6 cm，t = √(2 × 0.196 / 9.8) = 0.20 s，v₀ = 0.300 m / 0.20 s = 1.5 m/s。

```verify
{"claim": "实验6：t = 0.20 s，v₀ = 1.5 m/s", "expr": "[Math.round(Math.sqrt(2 * 0.196 / 9.8) * 1000) / 1000, Math.round(0.300 / Math.sqrt(2 * 0.196 / 9.8) * 1000) / 1000]", "expect": [0.2, 1.5]}
```

**常见错误**：斜槽末端没调水平；把斜槽末端当成抛出点（应以小球球心在末端时的位置为原点）；每次释放位置不同。

## 三、高中·实验 7：探究向心力大小与半径、角速度、质量的关系（safetyLevel：低）

- **器材与安全**：向心力演示器（手摇）。摇动要匀速、不要过快；转动部分附近不伸手，长发扎起。换成电动向心力实验器等需要接电的型号时按"中"：电源由老师接好、检查，学生只操作器材上的开关。
- **方法**：控制变量——保持其中两个量不变，研究向心力与第三个量的关系；标尺上露出的格子数之比，就是两个小球所受向心力之比。
- **结论**：F 与 m 成正比、与 r 成正比、与 ω² 成正比，F = mω²r。

**算例**：两球质量相同、转动半径相同，塔轮使两球的角速度之比为 1 ∶ 2，标尺格子数之比约为 1 ∶ 4，说明 F ∝ ω²。

```verify
{"claim": "实验7：角速度之比 1∶2 时，向心力之比 1∶4", "expr": "Math.pow(1 / 2, 2)", "expect": 0.25}
```

**常见错误**：研究 F 与 ω 的关系时，两球的质量或半径没有保持相同；把"格子数之比"当成向心力的具体数值。

## 四、高中·实验 8：观察电容器的充、放电现象（safetyLevel：中，涉及学生电源接线）

- **器材与安全**：学生电源（直流挡）、电容器、电流表或电流传感器、电阻、单刀双掷开关。用电解电容器时**正负极不能接反、所加电压不能超过它标称的耐压值**——接反或过压会使电容器发热、鼓包甚至爆裂，接线由老师检查后再通电。充了电的电容器两极不要用手同时去碰，放完电再拆线。
- **现象**：充电时电流从大到小，最后为零，电容器两端电压升到与电源电压相等；放电时电流反向，也由大到小。
- **数据处理**：I-t 图像与时间轴围成的面积表示电容器放出的电荷量 Q（数格子：多于半格算一格，不足半格舍去），C = Q/U。

**算例**：I-t 图上每一小格代表 0.2 mA × 0.4 s，数得约 40 格，充电电压 8 V。Q ≈ 40 × 8×10⁻⁵ C = 3.2×10⁻³ C，C = Q/U ≈ 4×10⁻⁴ F = 400 μF。

```verify
{"claim": "实验8：每格 8×10⁻⁵ C，Q ≈ 3.2×10⁻³ C，C ≈ 400 μF", "expr": "[0.2e-3 * 0.4, Math.round(40 * 0.2e-3 * 0.4 * 1e5) / 1e5, Math.round(40 * 0.2e-3 * 0.4 / 8 * 1e6)]", "expect": [8e-5, 3.2e-3, 400]}
```

**常见错误**：电解电容器的正负极接反；以为放电电流与充电电流方向相同。

## 五、高中·实验 9：长度的测量及其测量工具的选用（safetyLevel：低）

- **工具的选用**：按被测长度和需要的精度选——米尺（分度值 1 mm）、游标卡尺（10、20、50 分度，精度 0.1 mm、0.05 mm、0.02 mm，不估读）、螺旋测微器（精度 0.01 mm，要估读到 0.001 mm）。
- **读数方法**：游标卡尺读数 = 主尺上游标零刻度线左边的整毫米数 + 游标上与主尺对齐的格数 × 精度；螺旋测微器读数 = 固定刻度（注意半毫米刻线是否露出）+ 可动刻度格数（估读一位）× 0.01 mm。

**算例**：10 分度游标卡尺，主尺读 23 mm，游标第 7 条刻度线对齐，读数 23.7 mm。螺旋测微器固定刻度读 6.5 mm（半毫米线已露出），可动刻度对准 20.0 格，读数 6.700 mm。

```verify
{"claim": "实验9：游标卡尺 23 + 7 × 0.1 = 23.7 mm；螺旋测微器 6.5 + 20.0 × 0.01 = 6.700 mm", "expr": "[Math.round((23 + 7 * 0.1) * 10) / 10, Math.round((6.5 + 20.0 * 0.01) * 1000) / 1000]", "expect": [23.7, 6.7]}
```

**常见错误**：游标卡尺估读了一位；螺旋测微器漏看半毫米刻线；读数末尾的 0 被省掉（6.700 mm 写成 6.7 mm，丢了精度信息）。

## 六、高中·实验 10：测量金属丝的电阻率（safetyLevel：中，涉及接线）

- **器材与安全**：学生电源或干电池、电流表、电压表、滑动变阻器、螺旋测微器、米尺。闭合开关前滑动变阻器接入最大阻值（限流接法）或使待测部分电压为零（分压接法）；电流不宜过大、通电时间不宜过长，以免金属丝发热、电阻率随温度变化；接线由老师检查。
- **原理**：R = ρL/S，S = πd²/4，所以 ρ = πd²R/(4L)。
- **电表接法**：金属丝电阻小，远小于电压表内阻，用电流表外接法；外接法测得的电阻偏小。
- **测量**：直径用螺旋测微器在不同位置测几次取平均；长度量接入电路的那一段。

**算例**：d = 0.500 mm，接入长度 L = 0.500 m，测得 R = 2.8 Ω。S = π × (0.500×10⁻³ m)² / 4 ≈ 1.96×10⁻⁷ m²，ρ = RS/L ≈ 1.1×10⁻⁶ Ω·m。

```verify
{"claim": "实验10：S ≈ 1.96×10⁻⁷ m²，ρ = RS/L ≈ 1.1×10⁻⁶ Ω·m", "expr": "[Math.round(Math.PI * Math.pow(0.5e-3, 2) / 4 * 1e9) / 100, Math.round(2.8 * Math.PI * Math.pow(0.5e-3, 2) / 4 / 0.5 * 1e7) / 10]", "expect": [1.96, 1.1]}
```

**常见错误**：用直径代替半径算面积；长度量的是整根金属丝而不是接入电路的部分；电流过大、通电时间过长。

## 七、高中·实验 11：用多用电表测量电学中的物理量（safetyLevel：中，涉及接线）

- **安全**：多用电表只测实验电路里的低压直流电压、电流和电阻，**不用它去测家庭电路（220 V）的电压**；测量前先选对挡位和量程，不确定时从大量程开始。
- **欧姆挡**：测电阻前把被测电阻从电路中断开；选好倍率后先把红、黑表笔短接进行欧姆调零，每次换倍率都要重新调零；指针在表盘中央附近时误差较小，偏角太小换大倍率，偏角太大换小倍率。
- **电流方向**：电流从红表笔流入、黑表笔流出（测电阻时，表内电池的正极接黑表笔）。
- **用完**：把选择开关拨到"OFF"或交流电压最高挡。

**算例**：选 "×10" 倍率，调零后测电阻，指针指在 15 处，电阻为 15 × 10 Ω = 150 Ω。

```verify
{"claim": "实验11：15 × 10 = 150 Ω", "expr": "15 * 10", "expect": 150}
```

**常见错误**：换倍率后没有重新欧姆调零；测电阻时没把电阻从电路中断开；用手同时捏住两个表笔的金属部分（把人体电阻并联进去）。

## 八、高中·实验 12：测量电源的电动势和内阻（safetyLevel：低，用干电池）

- **器材与安全**：1 节干电池、电流表、电压表、滑动变阻器、开关。滑动变阻器接入的电阻不能调到零，通电时间要短——电流过大时电池内阻会明显变化，电池也会发热。
- **原理**：闭合电路欧姆定律 U = E − Ir。改变外电阻，测几组 U、I。
- **数据处理**：作 U-I 图像，纵轴截距是电动势 E，斜率的绝对值是内阻 r；纵轴不从零开始时，图线与横轴的交点不是短路电流。

**算例**：I₁ = 0.10 A 时 U₁ = 1.40 V，I₂ = 0.40 A 时 U₂ = 1.10 V。r = (1.40 − 1.10)/(0.40 − 0.10) = 1.0 Ω，E = U₁ + I₁r = 1.50 V。

```verify
{"claim": "实验12：r = 0.30/0.30 = 1.0 Ω，E = 1.40 + 0.10 × 1.0 = 1.50 V", "expr": "[Math.round((1.40 - 1.10) / (0.40 - 0.10) * 1000) / 1000, Math.round((1.40 + 0.10 * (1.40 - 1.10) / (0.40 - 0.10)) * 1000) / 1000]", "expect": [1, 1.5]}
```

**常见错误**：把 U-I 图线与横轴的交点当成短路电流（纵轴起点不为零时不是）；用新电池做实验（内阻太小，电压变化不明显）。
