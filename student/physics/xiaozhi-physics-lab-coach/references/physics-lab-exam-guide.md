# 中考物理实验操作考试备考指南

> 适用学段：初中（八—九年级）。
> 多地把物理实验操作考试计入中考总分，但**考查清单、评分细则、分值与考法各地不同，以本地当年的考试说明为准**。本文件只给通用的评分维度、常见考查实验的操作要点与扣分点，供学生考前自查。
> 实验操作要靠真实动手练，本 SKILL 只能帮学生弄懂每一步的道理，不能替代进实验室。

---

## 一、五个评分维度（通用）

各地评分细则的写法不同，但大多落在这五个维度上：

| 维度 | 看什么 | 常见扣分 |
|---|---|---|
| ① 器材检查 | 器材是否齐全完好；天平、电流表、电压表、弹簧测力计先调零 | 拿到就用，没检查；忘记调零 |
| ② 规范操作 | 按步骤、按安全规范操作 | 顺序颠倒；违反安全规范（带电连线、明火靠近易燃物） |
| ③ 观察读数 | 视线正对刻度；需要估读的测量工具（如刻度尺）估读到分度值的下一位；带单位 | 俯视或仰视；漏写单位 |
| ④ 记录结论 | 数据表填写完整；结论按规范表述（见 SKILL.md 的结论模板） | 数据空缺；结论漏写"在……相同时"的前提 |
| ⑤ 整理器材 | 断开开关、拆除导线、器材复位、熄灭火源 | 离开时电路仍接通；酒精灯或蜡烛未熄灭 |

## 二、常见考查实验

下面九个是各地清单里常见的实验，**不代表任何一地的考查范围**。

### 1. 用天平和量筒测量物质的密度

**操作要点**
1. 天平放在水平台上，把游码移到标尺左端零刻度线处，再调节平衡螺母使横梁平衡。
2. 左盘放物体、右盘放砝码；用镊子夹取砝码，按从大到小的顺序试加，最后移动游码。
3. 物体质量 = 砝码总质量 + 游码左侧边缘所对的刻度值。
4. 量筒读数时，视线与凹液面的底部相平。
5. 测固体：先测质量、再测体积。先测体积会让物体沾水，测得的质量偏大，算出的密度偏大。
6. 测液体：先测烧杯和液体的总质量，把一部分液体倒入量筒测体积，再测烧杯和剩余液体的质量，用两次质量之差计算——这样避免烧杯壁残留液体带来的误差。

**常见扣分点**：游码没归零就调平衡；称量过程中去调平衡螺母；用手直接拿砝码；物体和砝码放反；量筒俯视或仰视读数。

### 2. 探究凸透镜成像的规律

**操作要点**
1. 把蜡烛、凸透镜、光屏依次放在光具座上，调整烛焰、凸透镜、光屏三者的中心大致在同一高度，使像成在光屏中央。
2. 先知道凸透镜的焦距（题目给出或先测出）。
3. 物距从大于二倍焦距开始逐步减小，每次移动光屏直到像最清晰，再记录物距、像距和像的性质。
4. 物距小于焦距时，光屏上承接不到像，要从光屏一侧透过凸透镜观察，看到的是正立、放大的虚像。

**常见扣分点**：三者中心不在同一高度；像没调到最清晰就记录；物距小于焦距时还在光屏上找像。

**安全**：点燃的蜡烛远离纸张等易燃物，实验结束后熄灭。

### 3. 探究串联、并联电路中电流（电压）的规律

**操作要点**
1. 连接电路时开关断开。
2. 电流表串联在被测电路中，电压表与被测部分并联；电流从电表的正接线柱流入、负接线柱流出。
3. 不能估计电流或电压大小时，先用大量程试触，再换用合适的量程。
4. 换用不同规格的小灯泡多做几次，得出普遍规律。

**常见扣分点**：开关闭合着连线；正负接线柱接反；量程选择不当；只测一组就下结论；用两只相同规格的灯泡——容易得出"各支路电流一定相等"这类只在特殊情况下成立的结论。

### 4. 伏安法测电阻

**操作要点**
1. 连接电路时开关断开；闭合开关前把滑动变阻器的滑片移到阻值最大处，保护电路。
2. 电压表并联在待测电阻两端，电流表串联在电路中。
3. 调节滑片改变电压，测出几组对应的电压和电流。
4. 测**定值电阻**：多次测量求平均值，减小误差。
5. 测**小灯泡的电阻**：灯丝电阻随温度（亮度）变化，**不能求平均值**；多测几组是为了观察电阻怎样随电压变化。

**常见扣分点**：闭合开关前滑片不在阻值最大处；对小灯泡的电阻求平均值；电表接反或量程不当。

### 5. 测量小灯泡的电功率

**操作要点**
1. 电路连接规范同上：开关断开，闭合前滑片置于阻值最大处。
2. 移动滑片，使电压表示数等于小灯泡的额定电压，读出此时的电流，额定功率 P = UI。
3. 再测电压略低于、略高于额定电压时的实际功率，观察亮度的变化。
4. 不同电压下的功率对应不同的工作状态，**不能求平均值**。

**常见扣分点**：没把电压调到额定电压就读数；把几次测得的功率取平均；电压调得过高。

**安全**：电压略高于额定电压即可，不要调得过高，以免烧坏灯泡。

### 6. 探究杠杆的平衡条件

**操作要点**
1. 实验前调节杠杆两端的平衡螺母，使杠杆在水平位置平衡——便于直接从杠杆上读出力臂，并消除杠杆自重对实验的影响。
2. 实验中不再调节平衡螺母，通过改变钩码的数量和位置，使杠杆重新在水平位置平衡。
3. 改变条件多做几次，得出普遍规律。

**常见扣分点**：挂上钩码后又去调平衡螺母；只做一次就下结论。

### 7. 探究影响滑动摩擦力大小的因素

**操作要点**
1. 弹簧测力计在水平方向上调零。
2. 用弹簧测力计沿水平方向拉动木块做匀速直线运动，此时拉力与滑动摩擦力是一对平衡力，大小相等。
3. 控制变量：研究压力的影响时保持接触面的粗糙程度不变，研究接触面粗糙程度的影响时保持压力不变。

**常见扣分点**：没有匀速拉动就读数；测力计没有沿水平方向拉；同时改变了两个因素。

### 8. 探究平面镜成像的特点

**操作要点**
1. 用透明玻璃板代替平面镜，便于确定像的位置。
2. 玻璃板与桌面垂直。
3. 用两支完全相同的蜡烛：一支点燃放在玻璃板前，另一支不点燃，在玻璃板后移动，直到与像完全重合——用来比较像与物的大小。
4. 在像的位置放一块光屏，**直接**观察光屏上有没有像，判断所成的是虚像。

**常见扣分点**：玻璃板没有竖直，后面的蜡烛无法与像重合；两支蜡烛不相同；透过玻璃板去看光屏，误以为光屏上有像。

**安全**：点燃的蜡烛远离易燃物，实验结束后熄灭。

### 9. 探究水在沸腾前后温度变化的特点

**操作要点**
1. 组装器材自下而上：先根据酒精灯外焰的高度固定铁圈；拆除时自上而下。
2. 温度计的玻璃泡全部浸入水中，不碰到容器底和容器壁。
3. 读数时温度计不离开水，视线与温度计内液柱的液面相平。
4. 水沸腾后继续加热几分钟并记录温度，观察沸腾时温度是否变化。

**常见扣分点**：温度计的玻璃泡碰到杯底或杯壁；把温度计从水中取出读数；组装顺序颠倒。

**安全**：用火柴点燃酒精灯，不用燃着的酒精灯去引燃另一盏；用灯帽盖灭，不用嘴吹；小心沸水和受热器材烫伤。

## 三、口述—对照—找坑：用本 SKILL 自查

1. **口述**：学生按顺序说一遍完整步骤，从检查器材说到整理器材。
2. **对照**：对照第一节的五个维度逐项追问原因，例如"闭合开关前为什么要把滑片放到阻值最大处"（保护电路）。
3. **找坑**：用"如果不这样做会怎样"追问扣分点，例如"先测体积再测质量，测出的密度偏大还是偏小"。

学生能说清原因的步骤，考场上不容易漏；只会背的步骤，换一套器材就容易乱。

## 四、边界

- 操作考试要靠真实动手练；本 SKILL 只帮梳理步骤、评分点和原理，不能替代进实验室。
- 不教怎样省步骤应付评分——按规范完整操作本身就是考点，也是安全要求。
- 正在进行的实验操作考试中不提供帮助（`shared/hint-ladder.md` §〇）。
- 在家做实验：只讨论不用明火、不接家庭电路、不用化学品的小实验；涉及 220 V 家庭电路或明火加热的，一律不提供在家操作的步骤。
