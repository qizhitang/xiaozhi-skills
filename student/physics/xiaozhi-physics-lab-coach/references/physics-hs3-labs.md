## 一、高中·选必实验 1：验证动量守恒定律（safetyLevel：中；斜槽方案为低）

- **两种方案**：① 气垫导轨 + 光电门，直接测碰撞前后的速度——气垫导轨的气源和数字计时器接 220 V 电源，插头的插拔由老师完成，学生只操作开关和计时器的按键，因此按"中"组织；② 斜槽 + 两个小球碰撞，用平抛的水平射程代替速度，不用电，为"低"。
- **斜槽方案的关键**：入射小球的质量要大于被碰小球（防止入射球反弹），两球半径相同（保证正碰）；每次从同一位置由静止释放；斜槽末端水平。
- **为什么能用射程代替速度**：两球离开斜槽后都做平抛，下落高度相同，飞行时间相同，水平射程与速度成正比。
- **验证式**：m₁·OP = m₁·OM + m₂·ON（P 为入射球单独落下的平均落点，M、N 为碰后两球的平均落点）。

**算例**：m₁ = 20 g，m₂ = 10 g；OP = 40.0 cm，OM = 13.5 cm，ON = 52.4 cm。碰前 m₁·OP = 800 g·cm，碰后 m₁·OM + m₂·ON = 794 g·cm，相差不到 1%，在误差范围内动量守恒。

```verify
{"claim": "选必实验1：碰前 800 g·cm，碰后 794 g·cm，相对差不到 1%", "expr": "[20 * 40.0, Math.round(20 * 13.5 + 10 * 52.4), Math.abs(800 - (20 * 13.5 + 10 * 52.4)) / 800 < 0.01]", "expect": [800, 794, true]}
```

**常见错误**：入射球比被碰球轻；每次释放位置不同；落点不取多次的平均位置（用最小的圆把各落点圈起来，圆心即平均落点）。

## 二、高中·选必实验 2：用单摆测量重力加速度的大小（safetyLevel：低）

- **操作要点**：摆线选细而不易伸长的；摆球选密度大、体积小的；摆角很小（一般不超过 5°）；从摆球经过**平衡位置**时开始计时，测 30～50 次全振动的总时间求周期。
- **摆长**：悬点到球心的距离 = 摆线长 + 摆球半径，摆线长在摆球自然下垂时测量。
- **数据处理**：g = 4π²L/T²；或作 T²-L 图像，斜率 k = 4π²/g，g = 4π²/k。
- **一个好性质**：若摆长误用了摆线长（漏加半径），T²-L 图线整体平移、不过原点，但**斜率不变**，用斜率求出的 g 不受影响。

**算例**：L = 0.500 m 时 T² = 2.015 s²，L = 1.000 m 时 T² = 4.030 s²。k = 4.030 s²/m，g = 4π²/k ≈ 9.80 m/s²。

```verify
{"claim": "选必实验2：k = (4.030 − 2.015)/(1.000 − 0.500) = 4.030 s²/m，g = 4π²/k ≈ 9.80 m/s²", "expr": "[Math.round((4.030 - 2.015) / (1.000 - 0.500) * 1000) / 1000, Math.round(4 * Math.PI * Math.PI / 4.030 * 100) / 100]", "expect": [4.03, 9.8]}
```

**常见错误**：从摆球到达最大位移处开始计时（那里速度最小，计时误差大）；把 n 次全振动数成 n + 1 次；摆角过大；摆球在水平面内做圆锥摆运动。

## 三、高中·选必实验 3：测量玻璃的折射率（safetyLevel：中，涉及玻璃砖和大头针）

- **器材与安全**：长方形玻璃砖、大头针、白纸、量角器或刻度尺。玻璃砖的棱边可能割手，轻拿轻放，不用玻璃砖当尺子画线（也会磨损光学面）；大头针针尖朝下插、不对着人，用完放回盒里。
- **操作**：在白纸上画出界面，插 P₁、P₂ 确定入射光线；透过玻璃砖观察，插 P₃ 挡住 P₁、P₂ 的像，插 P₄ 挡住 P₃ 和 P₁、P₂ 的像；连接得到出射光线，再画出玻璃中的折射光线。
- **数据处理**：n = sin i / sin r（i 是空气中的入射角，r 是玻璃中的折射角）；也可以用"单位圆法"：以入射点为圆心画圆，量出两条光线与圆的交点到法线的距离之比。
- **注意**：入射角不宜过小（角度测量的相对误差大），也不宜过大（出射光线太弱）；大头针之间的距离适当大一些，确定的光线方向更准。

**算例**：入射角 i = 60°，测得折射角 r = 35°，n = sin60°/sin35° ≈ 0.866/0.574 ≈ 1.51。

```verify
{"claim": "选必实验3：n = sin60°/sin35° ≈ 1.51", "expr": "Math.round(Math.sin(Math.PI / 3) / Math.sin(35 * Math.PI / 180) * 100) / 100", "expect": 1.51}
```

**常见错误**：用玻璃砖当尺子画界面；画界面时玻璃砖移动了位置；把折射角量成了折射光线与界面的夹角。

## 四、高中·选必实验 4：用双缝干涉实验测量光的波长（safetyLevel：中，涉及光源接电与强光）

- **器材与安全**：光源、滤光片、单缝、双缝、遮光筒、测量头。光源若接 220 V，插头的插拔由老师完成，学生只操作开关；若接学生电源，接线由老师检查。灯泡工作时很烫，不用手碰。若改用激光光源：只用课堂用的低功率激光笔，不直视、不对着人和反光面，由老师操作或全程在旁。
- **调节**：光源、单缝、双缝在同一条直线上，单缝与双缝平行，才能看到清晰的条纹。
- **测量**：用测量头测出第 1 条和第 n 条亮条纹中心的位置，相邻亮条纹间距 Δx = (x_n − x₁)/(n − 1)；λ = Δx·d/L（d 为双缝间距，L 为双缝到屏的距离）。
- **为什么测 n 条**：单个间距太小，测多个间距再平均，减小误差。

**算例**：第 1 条亮纹读数 2.320 mm，第 7 条读数 16.720 mm，Δx = 14.400 mm / 6 = 2.40 mm；d = 0.25 mm，L = 1.00 m，λ = 2.40×10⁻³ × 0.25×10⁻³ / 1.00 = 6.0×10⁻⁷ m = 600 nm。

```verify
{"claim": "选必实验4：Δx = 2.40 mm，λ = 600 nm", "expr": "[Math.round((16.720 - 2.320) / (7 - 1) * 1000) / 1000, Math.round(2.40e-3 * 0.25e-3 / 1.00 * 1e9)]", "expect": [2.4, 600]}
```

**常见错误**：Δx 用 (x_n − x₁)/n 计算（n 条亮纹之间只有 n − 1 个间距）；单缝与双缝不平行，条纹模糊。

## 五、高中·选必实验 5：探究影响感应电流方向的因素（safetyLevel：低）

- **器材与安全**：条形磁铁、线圈、灵敏电流计、干电池、保护电阻、开关。先用干电池判断"电流从哪个接线柱流入时指针向哪边偏"——干电池必须串联一个大阻值的保护电阻，而且只能**瞬间试触**，否则电流过大会损坏灵敏电流计。若改用学生电源的双线圈方案（用开关接通、断开原线圈来改变磁通量），按"中"：学生电源只用低压挡，接线由老师检查；断开原线圈电路的瞬间会产生较高的自感电动势，手不要接触原线圈的接线柱和裸露导线。
- **操作**：分别让 N 极、S 极插入和拔出线圈，记录指针偏转方向，换算成感应电流的方向，再用安培定则判断感应电流的磁场方向。
- **归纳**：列表比较"原磁场方向、磁通量怎样变化、感应电流的磁场方向"，得出：磁通量增加时两者方向相反，减少时相同——感应电流的磁场总要阻碍引起感应电流的磁通量的变化（楞次定律）。

| 操作 | 线圈内原磁场 | 磁通量 | 感应电流的磁场 |
|---|---|---|---|
| N 极向下插入 | 向下 | 增加 | 向上（相反） |
| N 极向上拔出 | 向下 | 减少 | 向下（相同） |
| S 极向下插入 | 向上 | 增加 | 向下（相反） |
| S 极向上拔出 | 向上 | 减少 | 向上（相同） |

**常见错误**：没有先弄清电流计的偏转方向与电流方向的关系；只做 N 极插入一种情况就下结论。

## 六、高中·选必实验 6：探究变压器原、副线圈电压与匝数的关系（safetyLevel：中，涉及学生电源接线）

- **器材与安全**：可拆变压器、学生电源、多用电表（交流电压挡）。**原线圈只接学生电源的低压交流输出，电压不超过 12 V，不接 220 V**；升压的组合由老师确认：输入不超过 12 V 时，副线圈与原线圈的匝数比不超过 3，使输出不超过 36 V，做不到就只做降压、升压由老师演示；手不接触裸露的接线柱和导线；改接线圈、改变匝数前先断电；测量时先选好交流电压挡的量程。
- **方法**：控制变量——保持原线圈的匝数和电压不变，改变副线圈的匝数；再保持副线圈的匝数不变，改变原线圈的匝数。
- **结论**：在误差范围内 U₁/U₂ = n₁/n₂；实测的副线圈电压略小于理想值，因为有漏磁、线圈电阻和铁芯的损耗。

**算例**：n₁ = 400 匝，n₂ = 200 匝，U₁ = 8.0 V。理想值 U₂ = 4.0 V，实测 3.8 V，略小，符合预期。

```verify
{"claim": "选必实验6：理想值 U₂ = 8.0 × 200/400 = 4.0 V，实测 3.8 V 略小", "expr": "[8.0 * 200 / 400, 3.8 < 8.0 * 200 / 400]", "expect": [4, true]}
```

**常见错误**：用直流电源做变压器实验（副线圈没有感应电压）；带电改接线圈。

## 七、高中·选必实验 7：利用传感器制作简单的自动控制装置（safetyLevel：中，涉及接线）

- **器材与安全**：热敏电阻或光敏电阻、定值电阻、电磁继电器、干电池或学生电源、小灯泡或蜂鸣器。**控制电路和工作电路都只用低压电源，不接家庭电路**；接线由老师检查后再通电。
- **思路**：传感器把温度、光照的变化变成电阻的变化，再通过分压电路变成电压的变化，去控制继电器的吸合或断开。
- **设计时要想清楚**：传感器的电阻随温度（或光照）怎样变化；它放在分压电路的哪一边；继电器在什么电压下吸合。

**算例**（光控，示意数据）：电源 6 V，光敏电阻与 10 kΩ 的定值电阻串联。光照强时光敏电阻约 2 kΩ，它两端电压为 1 V；天黑时约 40 kΩ，它两端电压升到 4.8 V——用这个电压的升高去触发"天黑开灯"。

```verify
{"claim": "选必实验7：光照强时 6 × 2/(2 + 10) = 1 V，天黑时 6 × 40/(40 + 10) = 4.8 V", "expr": "[6 * 2 / (2 + 10), 6 * 40 / (40 + 10)]", "expect": [1, 4.8]}
```

**常见错误**：不知道所用光敏电阻（或热敏电阻）的电阻随光照（或温度）怎样变化就开始接线；把传感器与定值电阻的位置接反，导致"亮时开灯"。

## 八、高中·选必实验 8：用油膜法估测油酸分子的大小（safetyLevel：中，涉及易燃的酒精溶液）

- **器材与安全**：油酸酒精溶液（由老师配制，远离明火）、浅盘、水、爽身粉（痱子粉）、注射器或滴管、玻璃板、坐标纸。爽身粉轻轻撒薄薄一层，不要扬起吸入；玻璃板边缘小心割手。
- **原理**：把油膜看成由油酸分子紧密排列成的单分子层，分子直径 d = V/S，V 是一滴溶液中**纯油酸**的体积。
- **步骤要点**：用注射器测出 1 mL 溶液的滴数，算出一滴溶液的体积，再乘溶液的浓度得到纯油酸的体积；油膜形状稳定后描在玻璃板上，用坐标纸数格子求面积（多于半格算一格，不足半格舍去）。

**算例**：每 10⁴ mL 溶液中含纯油酸 6 mL，1 mL 溶液为 75 滴，油膜约占 110 个 1 cm² 的格子。一滴中纯油酸的体积 V = (1/75) mL × 6/10⁴ = 8×10⁻⁶ mL = 8×10⁻¹² m³，S = 1.10×10⁻² m²，d = V/S ≈ 7.3×10⁻¹⁰ m。

```verify
{"claim": "选必实验8：V = 8×10⁻¹² m³，d ≈ 7.3×10⁻¹⁰ m", "expr": "[Math.round(1 / 75 * 6 / 1e4 * 1e-6 * 1e14) / 100, Math.round(1 / 75 * 6 / 1e4 * 1e-6 / 110e-4 * 1e11) / 10]", "expect": [8, 7.3]}
```

**常见错误**：用一滴溶液的体积代替纯油酸的体积；爽身粉撒得太厚，油膜摊不开；油膜还没稳定就描轮廓。

## 九、高中·选必实验 9：探究等温情况下一定质量气体压强与体积的关系（safetyLevel：低）

- **器材**：注射器（密封一定质量的空气）、压力表或压强传感器、铁架台。用玻璃注射器时按"中"：轻拿轻放，破损立即停用，碎玻璃交给老师处理。
- **保持温度不变**：推拉活塞要缓慢；手不要握住注射器筒（手的温度会使气体升温）。
- **保持质量不变**：活塞上涂润滑油，检查不漏气。
- **数据处理**：计算每组的 pV，看是否近似相等；作 p-1/V 图像，是一条过原点的直线——"化曲为直"比 p-V 图像的双曲线更容易判断反比关系。

**算例**：V = 20 mL 时 p = 1.00×10⁵ Pa，V = 16 mL 时 p = 1.25×10⁵ Pa，V = 10 mL 时 p = 2.00×10⁵ Pa，三组的 pV 都是 2.0×10⁶ Pa·mL。

```verify
{"claim": "选必实验9：三组 pV 都等于 2.0×10⁶ Pa·mL", "expr": "[20 * 1.00e5, 16 * 1.25e5, 10 * 2.00e5]", "expect": [2e6, 2e6, 2e6]}
```

**常见错误**：用手握住注射器筒；推活塞太快；作 p-V 图像后直接说"成反比"（曲线看不出是不是双曲线）。
