## 一、运动的描述

### 1.1 位移与路程

| 栏目 | 内容 |
|---|---|
| 类比 | 从家到学校，地图上一根从起点指向终点的箭头是位移；你实际走过的弯弯曲曲的路是路程 |
| 失效边界 | 只有做单向直线运动时，位移的大小才等于路程 |
| 迷思订正 | "位移就是路程"——位移是矢量，有方向；路程是标量 |
| 检验问题 | 在 400 m 跑道上跑一整圈回到起点，位移和路程各是多少？ |

### 1.2 瞬时速度

| 栏目 | 内容 |
|---|---|
| 类比 | 测速相机测的，是汽车在很短一段时间里的平均速度——时间取得越短，越接近"那一刻"的速度 |
| 失效边界 | 时间间隔不能无限短地测量，实验中用足够短的时间来近似 |
| 迷思订正 | "瞬时速度没法测"——用打点计时器或光电门，取很短时间内的平均速度近似 |
| 检验问题 | 用纸带求某个计数点的瞬时速度，应该取哪一段的平均速度？ |

### 1.3 速度与加速度（C09）

| 栏目 | 内容 |
|---|---|
| 类比 | 速度是"跑得多快"，加速度是"快慢变化得多快"——像油门踩得多深，而不是车速表的读数 |
| 失效边界 | 加速度的方向可以与速度方向相反（刹车时），这时速度在减小 |
| 迷思订正 | "速度大，加速度就大"；"加速度减小，速度就减小"——只要加速度与速度同向，加速度减小时速度仍在增大，只是增大得变慢 |
| 检验问题 | 一架飞机以很大的速度匀速飞行，它的加速度是多少？ |

## 二、相互作用

### 2.1 摩擦力的方向

| 栏目 | 内容 |
|---|---|
| 类比 | 走路时脚向后蹬地，地面给脚一个向前的摩擦力——摩擦力可以帮人前进 |
| 失效边界 | 摩擦力的方向看的是"相对"运动（或相对运动趋势），不是物体相对地面的运动方向 |
| 迷思订正 | "摩擦力总是阻碍物体运动""摩擦力方向与运动方向相反" |
| 检验问题 | 传送带把箱子匀速向上运送，箱子受到的摩擦力沿什么方向？ |

### 2.2 力的合成

| 栏目 | 内容 |
|---|---|
| 类比 | 两个人从不同方向拉同一辆车，车沿"两根绳中间"的某个方向走 |
| 失效边界 | 合力不一定比分力大：两个分力的夹角越大，合力越小 |
| 迷思订正 | "合力一定大于每一个分力" |
| 检验问题 | 两个大小都是 10 N 的力，夹角为 120° 时合力多大？ |

### 2.3 作用力与反作用力，不是一对平衡力

| 栏目 | 内容 |
|---|---|
| 类比 | 你推墙，墙也推你——两个力分别作用在墙上和你身上 |
| 失效边界 | 类比只说明"成对出现、作用在两个物体上"；它们同时产生、同时消失，性质相同 |
| 迷思订正 | "作用力与反作用力大小相等、方向相反，所以是一对平衡力"——平衡力作用在同一个物体上，作用力与反作用力作用在两个物体上，不能相互抵消 |
| 检验问题 | 马拉车，车也拉马，两个力大小相等，为什么车还能被拉动？ |

## 三、运动与相互作用

### 3.1 力与运动的关系（C10）

| 栏目 | 内容 |
|---|---|
| 类比 | 在冰面上推一下冰壶，它能滑很远——滑行时并没有"推力"一直跟着它 |
| 失效边界 | 地面上的物体最终停下，是因为受到了摩擦力，而不是"力用完了" |
| 迷思订正 | "力是维持物体运动的原因"——力是改变物体运动状态的原因 |
| 检验问题 | 踢出去的足球在空中飞行时，还受到脚的踢力吗？ |

### 3.2 惯性（C10）

| 栏目 | 内容 |
|---|---|
| 类比 | 满载的货车比空车难启动，也更难刹住 |
| 失效边界 | 惯性不是力，不能说"受到惯性的作用"；惯性大小只由质量决定 |
| 迷思订正 | "速度越大，惯性越大"——高速时刹车距离长，是因为速度大，不是惯性变大 |
| 检验问题 | 同一辆汽车，高速行驶和低速行驶时，惯性一样大吗？ |

### 3.3 牛顿第二定律中的"合力"（F08）

| 栏目 | 内容 |
|---|---|
| 类比 | 用同样大的力推空购物车和装满货物的购物车，空车加速快得多 |
| 失效边界 | 公式里的 F 是物体受到的合力，不是某一个力 |
| 迷思订正 | 只把拉力代入，忘了减去摩擦力 |
| 检验问题 | 用水平力拉地面上的物块，物块做匀速直线运动，此时它的加速度和合力各是多少？ |

### 3.4 超重与失重（C11）

| 栏目 | 内容 |
|---|---|
| 类比 | 电梯刚开始向上加速时，站在体重秤上会发现读数变大了 |
| 失效边界 | 体重秤的读数是人对秤的压力，不是重力；重力 mg 没有变 |
| 迷思订正 | "超重时重力变大""失重时没有重力" |
| 检验问题 | 在向下加速的电梯里，人受到的重力变小了吗？体重秤的读数呢？ |

### 3.5 自由落体与质量无关（C10）

| 栏目 | 内容 |
|---|---|
| 类比 | 在抽成真空的玻璃管里，羽毛和铁片同时落到底部 |
| 失效边界 | 在空气中，羽毛、纸片等受空气阻力影响明显，下落得慢；空气阻力可以忽略时才是自由落体 |
| 迷思订正 | "越重的物体下落越快" |
| 检验问题 | 大小相同的铁球和木球从同一高度同时由静止释放（空气阻力可忽略），哪个先落地？ |
