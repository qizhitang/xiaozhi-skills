## 一、高中·机械能及其守恒定律

### 1.1 功的正负（C12）

| 栏目 | 内容 |
|---|---|
| 类比 | 推着购物车往前走，你的推力在"帮忙"；车往前滑、你往后拉住它，你的拉力在"拖后腿"——力和位移的夹角决定这个力是帮忙还是拖后腿 |
| 失效边界 | 功是标量，正负不表示方向：正功表示这个力对物体的运动起推动作用，负功表示起阻碍作用（也说物体克服这个力做功）；只有这一个力做功时，正功使动能增加，负功使动能减少 |
| 迷思订正 | "力与位移方向相反时不做功"——这时做负功；"负功就是做的功少"——−10 J 的功和 +10 J 的功一样多，只是一个是阻力做的功、一个是动力做的功 |
| 检验问题 | 用 20 N 的拉力斜向上、与水平方向成 60° 拉箱子，箱子沿水平地面移动 5 m，拉力做了多少功？箱子受到的滑动摩擦力做正功还是负功？ |

```verify
{"claim": "1.1：W = Fx cos60° = 20 × 5 × 0.5 = 50 J", "expr": "Math.round(20 * 5 * Math.cos(Math.PI / 3) * 1000) / 1000", "expect": 50}
```

### 1.2 功率与机车的最大速度（C12、F12）

| 栏目 | 内容 |
|---|---|
| 类比 | 同一个人爬同一层楼，跑上去比走上去功率大；骑自行车上坡要换低速挡——功率一定时，速度小才能换来大的牵引力 |
| 失效边界 | P = Fv 里的 F 是牵引力，不是合力；匀速行驶时牵引力才等于阻力 |
| 迷思订正 | "功率大，做的功就一定多"——做功还要看时间；把 P = Fv 里的 F 当成合力 |
| 检验问题 | 汽车的额定功率为 60 kW，在水平路面上行驶时受到的阻力恒为 2000 N，它能达到的最大速度是多少？ |

```verify
{"claim": "1.2：最大速度时牵引力等于阻力，v = P/f = 60000/2000 = 30 m/s", "expr": "60000 / 2000", "expect": 30}
```

### 1.3 动能定理（F11）

| 栏目 | 内容 |
|---|---|
| 类比 | 动能像账户余额，每个力做的功像一笔存款（正功）或取款（负功）；余额的变化 = 所有收支的代数和 |
| 失效边界 | 等式左边是合外力做的总功（各力做功的代数和），不是某一个力做的功 |
| 迷思订正 | 只算拉力做的功，漏掉摩擦力做的负功 |
| 检验问题 | 质量 4 kg 的物体静止在水平面上，受 10 N 的水平拉力，滑动摩擦力为 2 N，物体移动 4 m 时速度多大？ |

```verify
{"claim": "1.3：总功 (10 − 2) × 4 = 32 J = ½ × 4 × v²，v = 4 m/s；只算拉力做功会得到 √20 ≈ 4.47 m/s", "expr": "[(10 - 2) * 4, Math.sqrt(2 * 32 / 4), Math.round(Math.sqrt(2 * 40 / 4) * 100) / 100]", "expect": [32, 4, 4.47]}
```

### 1.4 机械能守恒（F10）

| 栏目 | 内容 |
|---|---|
| 类比 | 没有摩擦的过山车：爬得越高跑得越慢，冲下来又变快——高度和速度在"换钱"，总数不变 |
| 失效边界 | 只有重力（或系统内的弹力）做功时才守恒；有摩擦力做功时，一部分机械能变成了内能 |
| 迷思订正 | "物体做匀速直线运动，机械能一定守恒"——匀速上升的电梯，动能不变、重力势能增加，机械能在增加（拉力做了正功） |
| 检验问题 | 小孩从高 5 m 的光滑滑梯顶端由静止滑下，到达底端时速度多大？真实的滑梯有摩擦，底端的速度会更大还是更小？ |

```verify
{"claim": "1.4：v = √(2gh) = √(2 × 10 × 5) = 10 m/s", "expr": "Math.sqrt(2 * 10 * 5)", "expect": 10}
```

## 二、高中·曲线运动与万有引力定律

### 2.1 物体做曲线运动的条件

| 栏目 | 内容 |
|---|---|
| 类比 | 掷链球时，运动员一松手，球就沿着那一刻的速度方向飞出去——之后受重力，轨迹才弯下去 |
| 失效边界 | 曲线运动的条件是合力方向与速度方向不在同一直线上；合力可以是恒力 |
| 迷思订正 | "做曲线运动的物体一定受变力"——平抛运动只受重力，是恒力，加速度始终为 g |
| 检验问题 | 平抛运动的加速度变不变？速度的方向变不变？ |

### 2.2 平抛运动的分解（P10）

| 栏目 | 内容 |
|---|---|
| 类比 | 同一高度同时释放两个小球：一个水平抛出，一个自由下落——它们同时落地；平抛的竖直方向就是一次自由落体 |
| 失效边界 | 不计空气阻力时，水平方向匀速、竖直方向自由落体，两个方向互不影响；速度要按矢量合成，不能把 v₀ 和 gt 直接相加 |
| 迷思订正 | "水平速度越大，在空中飞的时间越长"——落地时间只由下落高度决定 |
| 检验问题 | 从 5 m 高处以 10 m/s 的速度水平抛出一个小球，多久落地？水平飞出多远？落地速度多大？ |

```verify
{"claim": "2.2：t = √(2h/g) = 1 s，水平距离 10 m，落地速度 √(10² + 10²) ≈ 14.1 m/s（不是 10 + 10 = 20 m/s）", "expr": "[Math.sqrt(2 * 5 / 10), 10 * Math.sqrt(2 * 5 / 10), Math.round(Math.hypot(10, 10 * 1) * 10) / 10]", "expect": [1, 10, 14.1]}
```

### 2.3 向心力不是一种新的力（P11）

| 栏目 | 内容 |
|---|---|
| 类比 | 用绳子甩着水桶转圈，是绳的拉力（和重力一起）把水桶"拽"在圆周上——松手，水桶就沿切线飞出去 |
| 失效边界 | 向心力是按作用效果命名的：由其他力的合力（或某个力的分力）提供，受力分析时不另画一个"向心力" |
| 迷思订正 | 受力图里多画一个向心力；"物体做离心运动，是因为受到了离心力"——是提供的向心力不够了 |
| 检验问题 | 汽车通过拱形桥的最高点时，是什么力提供向心力？此时汽车对桥面的压力比重力大还是小？ |

### 2.4 竖直面内的圆周运动：绳与杆（R10）

| 栏目 | 内容 |
|---|---|
| 类比 | 杂技"水流星"：转得太慢，到最高点时水就会洒下来 |
| 失效边界 | 轻绳只能拉、不能推：最高点至少要重力单独提供向心力，最小速度为 √(gR)；轻杆既能拉又能支撑，最高点的速度可以为 0 |
| 迷思订正 | 绳模型与杆模型的最小速度混用 |
| 检验问题 | 用长 0.4 m 的轻绳拴着小球在竖直面内做圆周运动，小球恰好能通过最高点时速度多大？换成长 0.4 m 的轻杆呢？ |

```verify
{"claim": "2.4：轻绳 v最小 = √(gR) = √(10 × 0.4) = 2 m/s；轻杆最高点速度可以为 0", "expr": "Math.sqrt(10 * 0.4)", "expect": 2}
```

### 2.5 卫星：越高越慢（C15）

| 栏目 | 内容 |
|---|---|
| 类比 | 太阳系里，离太阳近的水星公转得最快，离得远的海王星公转得很慢 |
| 失效边界 | 只对绕同一个中心天体做圆周运动的卫星成立：由万有引力提供向心力，轨道半径越大，线速度、角速度、向心加速度越小，周期越长 |

## 三、高中·牛顿力学的局限性与相对论初步

### 3.1 相对论初步（课标：初步了解）

| 栏目 | 内容 |
|---|---|
| 类比 | 牛顿力学像一张城市地图：在城里用非常准；要去跨越半个地球的地方，就得换一张考虑地球曲率的地图 |
| 失效边界 | 速度接近光速或引力极强时牛顿力学不再适用；质量很大的天体会使周围的时空弯曲（如星光经过太阳附近发生微小的偏折，1919 年日食观测证实）；日常的低速、宏观情形下相对论效应极小，只有原子钟等精密仪器才测得出，一般的工程计算可以忽略（北斗等卫星导航系统的原子钟例外，必须做相对论修正） |
| 迷思订正 | "相对论推翻了牛顿力学"——牛顿力学是相对论在低速情形下的近似，至今仍是工程上的主要工具；"运动的尺子变短、运动的钟变慢只是看起来如此"——长度收缩、时间延缓是真实的效应：高速运动的 μ 子寿命变长就是实测证据，精密原子钟在飞机、卫星上也测到了；日常低速时效应极小，感觉不到 |
| 检验问题 | 为什么设计汽车、发射卫星时仍然用牛顿力学计算？ |

## 四、高中·静电场

### 4.1 电场强度

| 栏目 | 内容 |
|---|---|
| 类比 | 描述重力场用 g = G/m——"每千克受多大的重力"；描述电场用 E = F/q——"每库仑受多大的电场力" |
| 失效边界 | E 由电场本身决定，与放不放试探电荷、放多大的试探电荷无关；这是"用物理量之比定义新物理量"的方法 |
| 迷思订正 | "E = F/q，所以 E 与 F 成正比、与 q 成反比" |
| 检验问题 | 在电场中某点放一个电荷量为 q 的试探电荷，它受力为 F；换成电荷量为 2q 的试探电荷，受力和该点的场强各怎么变？ |

### 4.2 电场线（P12）

| 栏目 | 内容 |
|---|---|
| 类比 | 电场线像"下山的方向"，等势面像地形图上的等高线：电场线的疏密表示场强的大小，沿着电场线的方向电势逐渐降低 |
| 失效边界 | 电场线是为了描述电场画出的假想线，不是带电粒子的运动轨迹；只有在电场线是直线、粒子只受电场力、且初速度为零或沿电场线方向时，二者才重合 |
| 迷思订正 | "带电粒子一定沿电场线运动"；把"电场线密"说成"电势高" |
| 检验问题 | 电场线越密的地方，电势一定越高吗？ |

### 4.3 电势与电势能（C13）

| 栏目 | 内容 |
|---|---|
| 类比 | 电势像高度，电势能像重力势能：同一高度，物体的质量不同，重力势能就不同 |
| 失效边界 | 类比在"电荷有正负"这里失效：负电荷在电势高的地方电势能反而小（Ep = qφ，q 为负）；场强为零的地方电势不一定为零 |
| 迷思订正 | "电势高的地方，电荷的电势能一定大"；"场强为零处电势一定为零" |
| 检验问题 | 把一个电子从电势较低的 A 点移到电势较高的 B 点，电场力做正功还是负功？电子的电势能怎么变？ |

### 4.4 电容器的电容

| 栏目 | 内容 |
|---|---|
| 类比 | 电容器像一个水桶，电容像桶的横截面积：水位（电压）升高同样多，横截面积越大的桶装进的水（电荷）越多 |
| 失效边界 | C = Q/U 是定义式，电容由电容器本身的结构决定，与带不带电无关 |
| 迷思订正 | "电容器带的电荷越多，电容越大" |
| 检验问题 | 某电容器两端电压为 10 V 时带电荷量 2×10⁻⁴ C，它的电容多大？电压升到 20 V 时，电容变不变？ |

## 五、高中·电路及其应用

### 5.1 电阻与电阻率

| 栏目 | 内容 |
|---|---|

```verify

```

### 5.2 电动势与路端电压（C14）

| 栏目 | 内容 |
|---|---|
| 类比 | 电源像一台有内部阻力的水泵：抽的水越多，泵内部损耗的压力越多，出水口剩下的压力就越小 |
| 失效边界 | 电动势由电源本身决定；路端电压 U = E − Ir 随电流变化，外电阻越大，电流越小，路端电压越大，断路时才等于电动势 |
| 迷思订正 | 把接在电源两端的电压表读数当成电动势；"外电阻变大，路端电压不变" |
| 检验问题 | 电动势 3 V、内阻 1 Ω 的电源外接 2 Ω 的电阻，路端电压多大？把外电阻断开呢？ |


## 六、高中·电磁场与电磁波初步

### 6.1 磁场与磁感线

| 栏目 | 内容 |
|---|---|
| 类比 | 磁感线像电场线：疏密表示磁场的强弱，切线方向表示磁场的方向；通电直导线周围的磁感线是一圈圈同心圆 |
| 失效边界 | 磁感线是闭合曲线（磁体外部从 N 极到 S 极，内部从 S 极到 N 极），静电场的电场线不闭合 |
| 迷思订正 | "磁感线从 N 极出发，到 S 极就终止了" |
| 检验问题 | 用安培定则判断：竖直向上的电流，从上往下看，它周围的磁感线是顺时针还是逆时针？ |

### 6.2 磁通量与产生感应电流的条件

| 栏目 | 内容 |
|---|---|
| 类比 | 磁通量像穿过窗户的风量：风越大、窗户越大、窗户越正对着风，穿过的风越多 |
| 失效边界 | Φ = BS 只在磁场与平面垂直时成立，否则取垂直分量；磁通量与线圈的匝数无关 |
| 迷思订正 | "线圈放在磁场里就有感应电流"——闭合回路的磁通量发生变化时才有 |
| 检验问题 | 闭合线圈静止在不变的匀强磁场中，线圈里有感应电流吗？让它绕线圈平面内、垂直于磁场方向的轴转动呢？绕平行于磁场方向的轴转动呢？ |

### 6.3 电磁波与能量子

| 栏目 | 内容 |
|---|---|
| 类比 | 光是一种电磁波；光的能量像台阶一级一级的，不像斜坡那样可以连续取任意值 |
| 失效边界 | 电磁波的传播不需要介质，在真空中的速度都是光速；课标要求"知道""初步了解"，c = λf、ε = hν 按所用教材例题的深度做简单计算（如由频率求波长、求光子能量） |
| 迷思订正 | "电磁波和声波一样，要靠介质传播" |
| 检验问题 | 手机信号和可见光都是电磁波，它们在真空中的传播速度一样吗？ |

### 7.1 能量守恒与能量转化的方向性

| 栏目 | 内容 |
