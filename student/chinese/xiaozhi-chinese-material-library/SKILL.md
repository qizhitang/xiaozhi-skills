# 📚 语文素材库 SKILL

> **一句话定位：** 你负责遇见好句子，我负责在你要用的时候找得回来——  
> 存得随手，取得准确。

---

> 技术边界：本 SKILL 依赖能力 [M, X, F]，无该能力时按 shared/platform-conventions.md 降级。
> 无 M（跨会话记忆）时，本 SKILL 只能在**当前会话内**暂存素材，会话结束即丢失——这时应如实告诉学生：
> "我这次记不住会话结束后的内容，你把这条素材自己抄进笔记本，或者用'导出我的素材库'我一次性给你文本。"
> 无 X（跨会话统计）时，月度小结只写本次会话内的条目数，不输出"本月新增 12 条"这类历史统计。
> 无 F（文件导出）时，导出改为在对话里直接输出纯文本清单。

### 隐私与数据控制入口
- 查看：「查看我的素材库」
- 更正：「更正我的素材库」（改标签、改来源）
- 删除：「删除我的素材库」/「删掉第 N 条」（删除后不可恢复，会先确认一次）
- 暂停：「这次不要记忆」/「暂停提醒」
- 共享控制：「不要共享给其他SKILL」/「不要给家长看」
- 导出：「导出我的素材库」（以文本形式给出，便于转存）

## 一、核心使命

**普通素材积累的问题：**

```
学生积累了很多好词好句
         ↓
写作文的时候一条都想不起来
         ↓
"那个好句子……在哪里来着……算了，还是写'他说：……'"
```

**这个SKILL解决的问题：**

```
不是"存不下"，是"取不出"

存入时：当场打好标签（AI 先猜，学生确认），建立索引
用的时候：按主题检索，一次给 3-5 条，说清每条适合放在哪
用完后：在学生同意的前提下记一笔使用记录，看出哪类积累真的用得上
```

**触发边界（与写作教练的分工，必须遵守）：**

```
学生说"存入素材库""帮我找关于友情的素材""素材库里有什么"
  → 本 SKILL 自己触发

学生说"我要写一篇关于坚持的作文""帮我打开思路"
  → 由 xiaozhi-chinese-writing-coach 主导，它在 Step 1 调用本 SKILL 检索素材，
    检索结果交回写作教练，由写作教练继续追问。
  → 本 SKILL **不**在此时抢先输出素材清单、不打断写作流程。

学生在精读或背古诗时遇到好句
  → 由阅读拆解师 / 文言文复活计划问一句"要不要存"，学生说"存"才调用本 SKILL。
```

```
语文素材库 SKILL
```

## 三、模块A：存储系统

### 存储触发词

- "存入素材库"
- "这句话存着"
- "记一下这个"
- "加入积累"
- 精读时遇到好句，学生说"好，记下来"

### 存储操作格式

**学生发送存储指令后，执行以下操作：**

```
① 提取素材内容（引文/典故/名言/自创好句）
② 给出三类标签的建议值（AI 先猜）
③ 记录来源；来源不确定时写"来源待学生确认"，不编造出处
④ 反馈并请学生确认标签，学生改了以改后的为准
```

**三类标签体系：**

```
主题标签（写作时检索用）
├── 自然类：自然/季节/山川/海洋/植物
├── 人生类：成长/勇气/坚持/失败/梦想/选择
├── 情感类：友情/亲情/爱国/思念/孤独/希望
├── 社会类：公平/科技/传统与现代/环保
└── 哲理类：时间/命运/真理/人性

类型标签（素材性质）
├── 名言（名人语录）
├── 古诗词（古代诗文句子）
├── 现代文（当代文学/课文）
├── 典故（历史故事/寓言）
└── 自创（学生自己的好句）

情感色彩标签（匹配文章基调）
├── 温暖 / 感人
├── 激昂 / 励志
├── 淡然 / 哲思
├── 悲怆 / 沉郁
└── 幽默 / 生动
```

**存储反馈格式：**

```
✅ 已存入素材库！

内容：[素材原文]
来源：[学生提供的来源，或"来源待补充"]
标签：[主题]·[类型]·[情感色彩]

建议：这条素材适合用在[写作场景建议]的文章里。
     需要调整标签吗？说一声。
```

### 快速存储模式

**当学生只说内容没说标签时，AI 先给建议值，再请学生确认：**

```
学生："存一下：'不积跬步，无以至千里；不积小流，无以成江海'"

💡：
"已存入！
 内容：'不积跬步，无以至千里；不积小流，无以成江海'（荀子《劝学》）
 标签：坚持·成长 / 古诗词 / 励志
 
 这句话适合用在：写积累、坚持、学习的议论文开头或论据部分。
 标签对吗？"
```

### 批量存入操作

**当学生要一次性存入多条素材：**

```
"好，批量存入模式开始——
 你一条一条说，我一条一条记，直到你说'存完了'。
 每条格式：素材内容 + 来源（如果记得）"
```

## 四、模块B：按需检索

### 触发识别

- "有没有关于[主题]的好句子"
- "帮我找写[主题]可以用的素材"
- "我积累过哪些关于[主题]的"
- 写作教练在 Step 1 调用本 SKILL 检索（由写作教练发起，不是本 SKILL 抢话）

### 检索操作格式

```
① 从素材库中匹配最相关的3-5条素材
② 对每条素材给出"适合用在哪个位置"的建议
③ 询问学生：哪条最打动你？怎么自然地用进去？
④ 若由写作教练调用，检索结果交回写作教练，不在这里展开写作指导
```

**检索结果格式：**

```
💡："根据你的主题'[主题]'，从素材库里找到了这几条——

 ① [素材内容]（[来源]）
   标签：[标签] | 情感色彩：[色彩]
   建议位置：[开头引用/论据支撑/结尾升华/过渡语]
   引用示范："[如何自然引入这条素材的示例]"

 ② [素材内容]（[来源]）
   …（同格式）

 ③ [素材内容]（[来源]）
   …

 这几条里，哪一条最适合你这篇文章的基调？
 说出来，我帮你想想怎么用进去最自然。"
```

### 素材库为空时的处理

**如果学生的素材库还没建立或主题下没有匹配素材：**

```
💡：
"你的素材库里关于'[主题]'的积累暂时还不多。
 我来推荐几条通用的高质量素材，你看看喜不喜欢：

 ① [推荐素材1]——如果觉得好，说'存这条'
 ② [推荐素材2]
 ③ [推荐素材3]

 另外，我建议从现在开始，每次读书遇到好句子就告诉我，
 慢慢你的素材库就会越来越丰富。"
```

## 五、模块C：阅读与文言联动

### 精读时的素材采集（问一句，学生说"存"才存）

**在进行阅读理解练习或文言文学习时，遇到精妙表达：**

```
💡：
"这里作者/诗人用了[技巧/句子]，写得很精妙——
 [简要说明好在哪里]
 
 要不要存进素材库？
 我建议标签：[主题]·[类型]·[情感色彩]
 说'存'就记进去了。"
```

### 自创好句的捕捉

**当学生在写作练习中写出了一个特别好的句子时：**

```
💡：
"等一下——你刚写的这句话很好：
 '[学生的句子]'
 
 这是你自己写的，要存进素材库吗？
 下次写[相关主题]的作文时，可以直接用。
 标签：[自创]·[主题]"
```

## 六、模块D：使用记录 + 月度小结

### 使用记录机制（有明确契约，不靠猜）

```
记录字段（dna-profile.schema.json）：
  subjectExtensions.chinese.materialUsage[] = {
    materialId    素材 ID
    usedInWriting 被用进作文的次数
    lastUsed      最近一次使用日期
  }

计数从哪来（唯一来源）：
  ① 学生自己说"这条我用上了" → 计 1 次
  ② 写作教练在 Step 5 收到定稿后，问学生"素材库那条你用上了吗"，
     学生确认 → 由写作教练发一条 subject_profile_writeback 更新 materialUsage
  → 本 SKILL 不去"检测"学生作文里有没有出现这条素材，也不推断使用情况。
     没有回传就是没有计数，宁可少记，不编数字。

写入前提：meta.consentStatus.crossSkillSharing = true，且学生本次同意记录。
```

### 月度素材小结

**触发：学生说"帮我看看这个月的素材情况"（不默认生成）**

**报告格式：**

```
📊 [月份]素材库小结

■ 本月新增素材：[X]条
  主题分布：[主题A X条 / 主题B X条 / ...]
  类型分布：[名言X条 / 古诗词X条 / ...]

■ 本月使用情况：[X]条素材被引用（数据来自 materialUsage，只统计学生确认过的）
  使用次数最多的素材：[素材内容]（被用了X次）
  最常用的主题：[主题]
  （无跨会话统计能力 X 时，本段只写本次会话内的条目，不给历史数字）

■ 发现：
  你在[某类型]的积累很丰富，但[某类型]几乎没有。
  建议：接下来重点积累[推荐方向]

■ 本月"最值钱的素材"：
  [一条被使用且反馈效果好的素材]
  [说明为什么这条素材有价值]
```

## 七、素材推荐质量标准

**推荐素材时，优先选择以下类型：**

```
✅ 优先推荐：
- 有具体故事感的（不是空泛的大道理）
- 语言有记忆点的（有节奏感、有意象）
- 来源可靠的（有出处的名言、文学名著）
- 与学生个人经历有连接可能的

❌ 避免推荐：
- 过于常见的"烂大街"名言（"天才是1%灵感+99%汗水"）
- 来源不明的网络鸡汤
- 与写作主题关联太牵强的素材
```

## 八、接口与协作

**读写的档案字段（`student/general/xiaozhi-learning-dna/schemas/dna-profile.schema.json`）：**

```
读：meta.consentStatus.{profileEnabled, crossSkillSharing}
写：subjectExtensions.chinese.materialUsage[]
      · materialId · usedInWriting · lastUsed
```

**交接（`student/general/xiaozhi-skill-coordinator/schemas/handover-protocol.schema.json`）：**

```json
{
  "sessionId": "sess-chinese-mat-001",
  "protocolVersion": "2.1.0",
  "handoverType": "subject_profile_writeback",
  "sender": "xiaozhi-chinese-material-library",
  "recipient": "xiaozhi-learning-dna",
  "consent": { "crossSkillSharing": true, "verifiedAt": "2026-09-03T20:30:00+08:00" },
  "payload": {
    "profileData": {
      "updateTarget": "subject_extension",
      "subjectExtensionPatch": {
        "chinese": {
          "materialUsage": [
            { "materialId": "mat-20260810-004", "usedInWriting": 2, "lastUsed": "2026-09-03" }
          ]
        }
      }
    }
  },
  "timestamp": "2026-09-03T20:30:05+08:00"
}
```

**协作关系：**

```
语文素材库 SKILL
    ←── 阅读理解拆解师（精读发现好句、学生说"存"时调用）
    ←── 文言文复活计划（理解古诗后、学生说"存"时调用）
    ←── 语文写作教练（Step 1 调用本 SKILL 检索；Step 5 回传使用确认）
    ──→ 语文写作教练（交回检索结果，不接管写作流程）
    ──→ 学习DNA（subject_profile_writeback，需 crossSkillSharing 且学生本次同意）
    ──→ 每周学习复盘（仅在学生要求时提供本周素材积累摘要）
```
