# 地理读图：地图三要素、经纬网、等高线与气候资料图

> 示例题验算：2026-09-23
> 适用学段：初中地理；第六节为高中。
> 本文是 `xiaozhi-geography-map-reader` 的参考资源：读图的先后顺序、经纬网、等高线地形图、气温曲线与降水量柱状图、专题地图的读法。示范中的换算写成 `verify` 断言，由 CI 验算；标"示意数据"的数字只用于演示方法，不是真实测量值。
> 课程依据：《义务教育地理课程标准（2022 年版）》"地理工具与地理实践"（地球仪、地图）与主题三"地球的表层"；《普通高中地理课程标准（2017 年版 2025 年修订）》地理 1、选择性必修 1 与学业水平考试命题建议。

## 一、读图先看图名和地图三要素

地图的三要素是方向、比例尺、图例和注记。读图时在三要素之前先看图名：

```text
① 看图名：这是什么图？（地形图、气候类型分布图、人口分布图……）
② 看图例和注记：每个符号、每种颜色代表什么？
③ 看比例尺和方向：图上 1 厘米代表实地多远？哪边是北？
```

学生跳过这三步就开始答题时，先拉回来："先告诉我，这张图的图名和图例是什么。"（子类型 DM02）

**定方向的三种情况**（子类型 DM01）

| 地图上有什么 | 怎么定方向 |
|---|---|
| 没有指向标，也没有经纬网 | 一般按"上北下南，左西右东" |
| 有指向标 | 指向标的箭头一般指向北方 |
| 有经纬网 | 经线指示南北方向，纬线指示东西方向 |

**比例尺**：比例尺 = 图上距离 ÷ 实地距离，有数字式（如 1∶100 000）、线段式和文字式（如"图上 1 厘米代表实地距离 1 千米"）三种写法。图幅相同时，比例尺越大，表示的范围越小，内容越详细。换算时先统一单位：1 千米 = 100 000 厘米（子类型 DQ01）。

```verify
{"claim": "数字式 1∶100 000 即图上 1 厘米代表实地 1 千米", "expr": "1 * 100000 / 100000", "expect": 1}
```

```verify
{"claim": "比例尺 1∶5 000 000 的地图上两地相距 4 厘米，实地距离为 200 千米", "expr": "4 * 5000000 / 100000", "expect": 200}
```

## 二、经纬网

| | 经线 | 纬线 |
|---|---|---|
| 形状 | 连接南北两极的半圆 | 与赤道平行的圆圈 |
| 指示方向 | 南北方向 | 东西方向 |
| 长度 | 所有经线长度相等 | 赤道最长，向两极逐渐缩短 |
| 度数 | 以本初子午线为 0°，向东、向西各 180°，分为东经（E）和西经（W） | 以赤道为 0°，向北、向南各 90°，分为北纬（N）和南纬（S） |

**判读诀窍**（子类型 DM03）：度数向东增大的是东经，向西增大的是西经；度数向北增大的是北纬，向南增大的是南纬。

**半球的划分**：南北半球以赤道为界；东西半球以 20°W 和 160°E 组成的经线圈为界。**纬度分带**：0°—30° 为低纬度，30°—60° 为中纬度，60°—90° 为高纬度。

```verify
{"claim": "20°W 与 160°E 相对，两者组成一个经线圈（20 + 160 = 180）", "expr": "20 + 160", "expect": 180}
```

## 三、等高线地形图

**海拔与相对高度**：海拔是某地高出海平面的垂直距离；相对高度是两地海拔之差（子类型 DQ02）。

**示范（自拟的一座小山）**：山顶 A 的海拔 1350 米，山下村庄 B 的海拔 450 米，A 比 B 高多少米？

```verify
{"claim": "山顶 A 海拔 1350 米、村庄 B 海拔 450 米，相对高度为 900 米", "expr": "1350 - 450", "expect": 900}
```

**五种地形部位**（子类型 DM04）

| 部位 | 等高线的样子 |
|---|---|
| 山顶 | 闭合曲线，中间数值高 |
| 鞍部 | 两个山顶之间相对低洼的部位 |
| 山脊 | 等高线向海拔低处凸出 |
| 山谷 | 等高线向海拔高处凸出 |
| 陡崖 | 几条等高线重合在一起 |

**坡度**：等高线越密集，坡度越陡；越稀疏，坡度越缓。

**分层设色地形图**：按图例读每种颜色对应的海拔范围；教材地图一般用绿色表示低平的平原，黄色、棕色表示较高的高原和山地，蓝色表示海洋——具体以图例为准。

**五种基本地形**：平原海拔较低、地面平坦；高原海拔较高、面积较大、边缘比较陡峭；山地海拔较高、峰峦起伏、坡度较陡；丘陵海拔较低、起伏不大、坡度较缓；盆地四周高、中间低。

## 四、气温曲线与降水量柱状图

```text
① 看两侧纵轴：哪一侧是气温（℃），哪一侧是降水量（毫米）？——各图不一定相同，先看轴标
② 看横轴：1—12 月
③ 读气温：最热月、最冷月各是几月、多少度？算气温年较差 = 最热月气温 − 最冷月气温
④ 读降水：哪几个月多、哪几个月少？全年分配均匀吗？
⑤ 判断半球：最热月在 7 月前后的是北半球，在 1 月前后的是南半球
```

**示范（示意数据）**：某地最热月气温 26 ℃，最冷月 −4 ℃，气温年较差是多少？（子类型 DQ03）

```verify
{"claim": "示意数据：最热月 26 ℃、最冷月 −4 ℃，气温年较差为 30 ℃", "expr": "26 - (-4)", "expect": 30}
```

**示范（示意数据）**：北半球某地年降水量 800 毫米，6、7、8 月的降水量分别为 150、200、180 毫米，这三个月合计 530 毫米，约占全年的三分之二——降水集中在夏季。（南半球的 6—8 月是冬季，先判断半球再说季节。）

```verify
{"claim": "示意数据：150、200、180 毫米合计 530 毫米", "expr": "150 + 200 + 180", "expect": 530}
```

```verify
{"claim": "示意数据：530 毫米占全年 800 毫米的比例约为三分之二（0.6625）", "expr": "530 / 800", "expect": 0.6625}
```

读完图以后，用纬度位置、海陆位置、地形解释"为什么是这样的气候"，转地理成因链教练。

## 五、专题地图

人口分布图、气候类型分布图、农业或工业分布图等专题地图，按三步读：

```text
① 看图名与图例：表示的是什么要素？
② 找分布规律：哪里多、哪里少？集中在哪里？
③ 联系其他要素解释：分布为什么是这样？——转地理成因链教练
```

问"分布特点"时答"哪里多、哪里少、集中在哪里"，不是只列地名（子类型 DE04）。

**数字地图**：课标要求学生养成在生活中使用数字地图的习惯。练习路线规划时，用教材地名或知名的公共地标（如火车站、博物馆），不必用自己就读的学校，不输入自己家的住址。

## 六、高中：读图的升级

以下内容对应《普通高中地理课程标准》；没有选考地理的学生只学必修（地理 1、地理 2）部分。

**等值线图**（地理 1 内容要求 1.6 的等压面；选择性必修 1 内容要求 1.4 的天气图）：等值线向数值高的一侧凸出，凸出处的数值比两侧低；向数值低的一侧凸出，凸出处的数值比两侧高。等高线的山脊、山谷就是这条规律的特例（子类型 DM06）。

**时区与区时**（选择性必修 1 内容要求 1.1）：全球按经度划分为 24 个时区，每个时区跨经度 15°；北京时间是东八区的区时，即 120°E 的地方时。东边的时刻早，西边的时刻晚（子类型 DQ05）。

```verify
{"claim": "全球 360° 按每 15° 一个时区，共 24 个时区", "expr": "360 / 15", "expect": 24}
```

```verify
{"claim": "北京时间（东八区）10:00 时，西五区的区时为前一天 21:00", "expr": "(10 - (8 - (-5)) + 24) % 24", "expect": 21}
```

**正午太阳高度**（选择性必修 1 内容要求 1.1）：正午太阳高度 = 90° − 当地纬度与太阳直射点纬度之差（两地在同一半球时纬度相减，不在同一半球时相加）（子类型 DQ06）。

```verify
{"claim": "秋分日太阳直射赤道时，南纬 40° 的正午太阳高度为 50°", "expr": "90 - Math.abs(-40 - 0)", "expect": 50}
```

**考试口径**：课标的学业水平考试命题建议规定，合格性考试的范围是必修课程，以单项选择题为主并有一定比例的主观题，一般采用纸笔测试与地理实践活动相结合的形式；等级性考试覆盖必修与选择性必修，主观题分值占比高于客观题。纸笔考试的主观题一般有简答题、填图作图题、论述题等。具体的考查方式以本地当年的考试说明为准。
