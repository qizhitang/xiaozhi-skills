## 一、高中地理 2 第 2.2 条：城镇和乡村内部的空间结构

**范围**：必修（合格考、等级考都考）。
**课标**：「结合实例，解释城镇和乡村内部的空间结构，说明合理利用城乡空间、城乡融合发展的意义。」两个动词：空间结构要"解释"，合理利用城乡空间与城乡融合发展要"说明意义"；都要结合实例。
**先问**："'城镇内部的空间结构'和'城镇在一个区域里的分布'，是一回事吗？""教材这个实例里，商店最集中的地方在哪一带？住宅、工厂又在哪里？"

| 四步 | 讲城镇和乡村内部的空间结构时问什么 |
|---|---|
| ① 定位 | 这个城镇或乡村在哪里？地形、河流、对外交通线从哪里经过？位置会影响内部的形态，如河谷里的城镇沿河延伸（教材说法） |
| ② 归纳特征 | 内部有哪几类用地（教材说法：城镇有住宅区、商业区、工业区等功能区，乡村有居住用地、耕地、林地、水域等），各在哪里、怎样组合？归纳成一句"结构特点"，不逐个罗列 |
| ③ 比较 | 城镇与乡村比；同一城镇不同时期比。用四列表，同一个项目两边都写（`references/region-cognition-guide.md` 第四节） |
| ④ 联系 | 城与乡之间流动的是什么（人口、农产品与工业品、资金、技术、信息），对双方各有什么意义——"城乡融合发展的意义"就落在这里 |

- **说明意义的要点**（教材常见说法，以所用教材为准）：合理利用城乡空间——节约集约用地，保护耕地和生态空间，各类用地布局得当、减少相互干扰（如工业与居住）；城乡融合发展——人口、资金、技术、信息等在城乡之间双向流动，基础设施和公共服务向乡村延伸，城乡分工协作、缩小差距。每一点都落到实例里看得见的变化上，不写成放在哪个城镇都成立的套话（DE03）。
- **成因与读图**：商业区为什么多在交通便利的中心、工业区为什么多靠近对外交通线（教材说法），是成因问题，转地理成因链教练（xiaozhi-geography-causal-chain）；城市功能区与土地利用图读不懂，转地理读图教练（xiaozhi-geography-map-reader）。

**常见说法与订正**（对应子类型 DR06）
- ①"城镇内部空间结构就是城镇分布在哪里"——课标说的是"内部"：城镇和乡村里面不同用地怎样分布、怎样组合；城镇在区域里怎样分布是另一个尺度的问题。
- ②"这个城市有商业区、住宅区、工业区"——只列了有哪几类，没说各在哪里、怎样组合、为什么这样组合。
- ③"城乡融合就是把乡村都变成城市"——城乡融合说的是城乡之间要素流动、功能互补、差距缩小（教材说法），乡村仍有自己的生产、生态和生活功能。

**自己走一遍**："用教材里的一个城镇或乡村实例，按四步说一遍它的内部空间结构，最后用一句话说明'城乡融合'在这个实例里体现在哪里。"（要点：定位说出地形或交通线；特征归纳成一句结构特点；联系说出至少两种城乡之间的流动和对双方的意义。开放题，要点不唯一）

## 二、高中地理 2 第 2.3 条：地域文化在城乡景观中的体现

**范围**：必修（合格考、等级考都考）。
**课标**：「结合实例，说明地域文化在城乡景观中的体现。」"城乡景观"既有城镇的，也有乡村的聚落与农田。
**先问**："一张传统村落的照片里，你看到了什么？其中哪些和'文化'有关，哪些和'自然'有关？"

讲法：从看得见的景观，读到看不见的文化，再找原因。

| 环节 | 问什么 | 落在四步的哪一步 |
|---|---|---|
| 看景观 | 建筑的形式、材料与色彩，聚落的选址与布局，街巷与公共空间，农田的形态，标志物 | ② 归纳特征（人文） |
| 读文化 | 体现了怎样的生产方式、生活习俗、审美与信仰、历史传统 | ② 归纳特征 |
| 找原因 | 和当地的地形、气候、水源、可用的材料有什么关系 | ① 定位；成因转地理成因链教练（xiaozhi-geography-causal-chain） |
| 比一比 | 换一个地方，同一类景观有什么不同，为什么不同 | ③ 比较 |
| 看变化 | 交流与经济发展让景观发生了什么变化，怎样保护与发展 | ④ 联系（接地理 2 第 2.10 条） |

**示范**（教材常见案例，细节以所用教材为准）：黄土高原的窑洞——看景观：依黄土崖壁开挖的窑洞民居；读文化：就地取材、顺应环境的居住方式；找原因：黄土层深厚、直立性好，便于开挖，窑洞冬暖夏凉（教材说法）。

**课标例 1：浙江青田县稻田养鱼**。课标的问题式教学例 1 写明：「必修地理 2 的内容要求“结合实例，说明地域文化在城乡景观中的体现”“说明协调人地关系和可持续发展的主要途径”中，包含了两个核心内容：地域文化景观、可持续发展。」选材依据是：「我国浙江青田县的稻田养鱼，在 2005 年 6 月被联合国粮农组织评为“全球重要农业文化遗产保护试点”，成为中国第一个世界农业文化遗产。」例 1 的问题链可以直接套进上面的环节：

| 例 1 问题链（原文） | 对应的环节 |
|---|---|
| 「怎样认识青田县的气候特征？」 | 找原因：景观的自然背景 |
| 「青田县丰富的溪水资源从何而来？」 | 找原因（成因转地理成因链教练） |
| 「稻田养鱼对水稻生产有什么好处？」 | 找原因：人与自然的相互关系 |
| 「青田县人们长期以来的生产和生活方式是怎样的？」 | 看景观：生产生活方式 |
| 「这里积淀了怎样的地域文化？」 | 读文化：本条的核心 |
| 「为什么今天的青田县稻田养鱼处于濒危状态？」 | 看变化。情境原文：「当地掌握这一技术而又专业养鱼的人正在迅速减少，因为要靠种田养鱼发家致富很难」 |
| 「青田县的农业生产怎样才能持续发展？」 | 看变化：保护与发展，接地理 2 第 2.10 条 |

## 三、高中地理 2 第 2.7 条：用专题地图组合说明国家战略的地理背景

**范围**：必修（合格考、等级考都考）。
**课标**：「运用不同类型的专题地图，说明国家某项重大发展战略的地理背景。」课标只写"国家某项重大发展战略"，不点名哪一项。讲哪一项以所用教材为准；本技能不替教材选，也不对战略本身作评论，只教"怎样用一组专题地图把它的地理背景说清"。这一条和地理 2 学业要求的这一句对得上：「收集或分析真实情境中有关人口、城乡、产业活动等人文地理数据、图表和地图，并据此描述人文地理事物的空间现象及其变化」。
**先问**："教材讲的是哪一项战略？它涉及的范围在哪里？教材给了哪几张专题地图？"

**方法：专题地图组合 → 区域条件 → 战略背景**

```text
① 定范围：从教材的范围图读出战略涉及的区域在哪里（经纬度位置、海陆位置、相邻位置）
② 配地图：选几种不同类型的专题地图，每张图只回答一个问题（见下表）
③ 读条件：每张图读出一条事实，归纳成一句"区域条件"（优势或问题），注明出自哪张图
④ 连背景：把与这项战略直接相关的条件归成三类——可以依托的优势、需要解决的问题、需要加强的区域联系
⑤ 查证据：每一条背景都能指回一张图；没有图支撑的话不写进"地理背景"
```

| 专题地图的类型（以教材所给为准） | 回答什么 | 归纳成区域条件的写法（示意） |
|---|---|---|
| 地形图 | 地势、地形类型、平地多少 | "以平原为主，地势低平" |
| 气温、降水分布图 | 热量、降水与水热配合 | "热量充足、降水丰富" |
| 河流水系图 | 水源、航运、上下游关系 | "河网密布，水运便利" |
| 资源分布图（矿产、能源、土地等） | 有哪些资源、怎样组合 | "能源与矿产资源丰富" |
| 人口与城镇分布图 | 劳动力与市场、城镇的分布 | "人口稠密、城镇密集" |
| 交通线路图 | 对内、对外联系的通道 | "多条交通干线在这里交会" |
| 产业分布图 | 已有的产业基础 | "已形成一定的产业基础" |
| 生态环境类专题图 | 生态的约束与保护需要 | "生态环境脆弱" |

- 区域条件写成一句"特点"，不抄图上的地名（`references/region-cognition-guide.md` 第三节"归纳，不是罗列"）；背景里的每一条都要落到这个区域，不写成"区位优越、资源丰富"这类放在哪个区域都成立的话。
- 战略的目标、内容和措施按教材讲；学生追问对战略的评价或时事，本技能回到"用地图说明地理背景"这件事上。
- **与读图的分工**：图本身读错（图例、数值、范围看错）记 DM11，转地理读图教练（xiaozhi-geography-map-reader）；图读对了，却只把图上的地名一一抄下来，记 DR05；写成放在哪个区域都成立的套话，记 DE03。

**自己走一遍**："找到教材讲某项国家战略的那一组专题地图，填这张表：地图 | 读出的事实 | 区域条件 | 支撑哪一类背景（优势、问题或联系）。"（要点：至少用到三种不同类型的地图；每条背景都能指回一张图。开放题，要点不唯一）

## 四、高中地理 2 第 2.8 条：海洋权益与海洋发展战略

**范围**：必修（合格考、等级考都考）。
**课标**：「结合实例，说明维护国家海洋权益和重视海洋发展战略的重要意义。」动词是"说明……重要意义"，要结合实例。
**先问**："教材用了哪个实例？它涉及的是海洋资源、海上运输，还是别的方面？"

| 四步 | 讲海洋时问什么 |
|---|---|
| ① 定位 | 实例在哪片海域？和陆地、岛屿、港口是什么关系？位置一律看教材地图和标准地图 |
| ② 归纳特征 | 这片海域有什么：海洋资源（教材常讲生物、矿产、能源等）、海洋空间（航道、港口、海岛等）、海洋生态环境 |
| ③ 比较 | 需要时和另一片海域比，或同一海域开发前后比 |
| ④ 联系 | 海上通道连接了哪些区域？沿海港口和内陆怎样联系？这片海域的开发与保护关系到国家哪些方面的利益？ |

**说明"重要意义"的结构**（以所用教材为准）：

```text
实例 → 涉及哪一类海洋权益或海洋开发活动 → 维护它、开发它对国家的意义（分点说，如安全、发展、生态）
```

- 海洋权益怎样分类，领海、专属经济区、大陆架等概念怎样解释，按所用教材讲（教材说法）。课标把解释这些概念的要求写在选修 2 海洋地理第 2.10 条：「根据《联合国海洋法公约》，解释内水、领海、毗连区、专属经济区、大陆架、公海和国际海底区域等概念。」选修是校本课程，不进考试范围。
- 海洋发展战略的名称和内容以所用教材为准；海域面积等数字以教材为准，本技能不另给数字。
- 等级考的延伸：选必 3 第 3.4 条「结合实例，说明海洋空间资源开发对国家安全的影响。」只在等级考范围，讲法见 `references/resources-environment-security-hs.md` 第四节。

**常见说法与订正**
- ① 意义只写"海洋很重要"一句——要结合实例分点说，每一点落到实例上（DE03）。
- ② 把海洋权益只理解为"捕鱼"或只理解为"领海"——教材讲的海洋权益涉及资源、通道、安全、生态等多个方面（DE02）。
- ③ 自造概念、改写课标与教材的表述，或把选修里的概念要求说成必修要求（DE05）。

**自己走一遍**："用教材里的一个实例，按'实例 → 涉及哪类海洋权益或开发活动 → 对国家的意义（至少两点）'说一遍。"（要点：两点意义都落到实例上；概念用教材的说法。开放题，要点不唯一）

## 五、高中地理 2 第 2.9 条：南海诸岛与钓鱼岛及其附属岛屿

**范围**：必修（合格考、等级考都考）。
**课标原文（照录，一字不改）**：「运用资料，说明南海诸岛是中国领土的组成部分，钓鱼岛及其附属岛屿是中国固有领土，中国对其拥有无可争辩的主权。」

**怎样讲"运用资料，说明"**
- 资料只用教材里给的地图、文字资料和图片，出处以教材的标注为准。本技能不自拟史料，不编造文献名称、年代和引文，也不引用教材以外、来源不明的材料。
- 位置看教材地图和标准地图，用定位的方法说清（`references/region-cognition-guide.md` 第二节）；本技能不为这两处画示意图。
- 原句里某个词的含义（如"固有领土"），按教材的解释讲；教材没有解释的，不自行下定义，请学生问老师。
- 组织说明时，每份资料走一遍：

```text
教材里的哪一份资料 → 资料里的哪一处（哪句话、图上的哪个位置）→ 说明了什么（一句话）
结论用课标原句，不改写、不扩展
```

**结论句照原文写全：四个检查点**（对应子类型 DE05）
1. "南海诸岛"后面接"是中国领土的组成部分"；
2. "钓鱼岛及其附属岛屿"写全，"及其附属岛屿"不省略，后面接"是中国固有领土"；
3. 末句"中国对其拥有无可争辩的主权"写全，"无可争辩的"不省略；
4. 两个分句的说法不对调、不合并，不换成别的词。
