> 示例题验算：2026-10-03

> 课程依据：《普通高中地理课程标准日常修订版（2017 年版 2025 年修订）》选择性必修 3 的模块说明、内容要求、教学提示与学业要求，附录 2 人地协调观的水平描述。

## 〇、高中选必 3：主线、课标原词与深度

**主线**：「本模块主要包括三方面内容：自然资源开发利用，环境保护，资源、环境对国家安全的重要意义。」「本模块旨在帮助学生了解资源、环境与国家安全的关系，增强保护资源与环境的意识，树立总体国家安全观。」各条的落脚点：第 3.3 条粮食安全，第 3.4 条国家安全，第 3.6 条生态安全，第 3.7 条环境安全，第 3.8 条国家安全。"增强……意识""树立……观"是态度要求，可以请学生谈认识，不出成知识判断题。

**四步用在资源与环境上**

| 四步 | 问什么 |
|---|---|
| ① 定位 | 资源分布在哪里？污染源、受影响区、保护地在哪里？ |
| ② 归纳特征 | 资源的数量、质量、空间分布（第 3.1 条的三个方面）；环境问题的类型与程度 |
| ③ 比较 | 资源分布与人口、产业分布对不对得上；不同区域的条件与问题有什么不同 |
| ④ 联系 | 资源怎样调配、贸易；污染物怎样跨区域、跨境转移；一地的保护让哪些区域受益——这些联系最后落到"安全" |

**课标原词与教材说法**（讲解时可以用教材说法，不说成"课标要求掌握"）

| 条目 | 课标原词（照用） | 教材常用、课标没用的说法 |
|---|---|---|
| 选必 3 第 3.1 条 | 自然资源的数量、质量、空间分布 | 资源安全、人均占有量 |
| 选必 3 第 3.2 条 | 战略性矿产资源；分布特点；开发利用现状 | 能源安全、对外依存度 |
| 选必 3 第 3.3 条 | 耕地资源；耕地保护；粮食安全 | 永久基本农田、高标准农田、耕地占补平衡 |
| 选必 3 第 3.4 条 | 海洋空间资源；国家安全 | 港口与航道、跨海桥梁与海底隧道、海底管道与电缆、人工岛 |
| 选必 3 第 3.5 条 | 碳循环和温室效应原理；碳排放；碳减排国际合作；碳达峰碳中和（教学提示） | 《联合国气候变化框架公约》《巴黎协定》；"共同但有区别的责任" |
| 选必 3 第 3.6 条 | 自然保护地；生态安全；国家公园（教学提示） | 自然保护区、自然公园、生态保护红线 |

| 选必 3 第 3.8 条 | 环境保护政策、措施；国家安全；政策和法规（学业要求） | 各项政策的名称（以所用教材为准） |

## 一、高中选必 3 第 3.1 条：自然资源的数量、质量、空间分布与人类活动

**范围**：选择性必修（只在等级考范围）。
**课标**：「结合实例，说明自然资源的数量、质量、空间分布与人类活动的关系。」
**先问**："说一种资源'多'，是总量多，还是人均多？质量好不好，对开发有什么影响？"

| 方面 | 怎样影响人类活动 | 人类活动怎样反过来影响它 |
|---|---|---|
| 数量（总量与人均） | 决定能开发多大规模，要不要从外面调入或进口 | 过度开采使可用数量减少；技术进步使原来用不上的资源变得可用（教材说法） |
| 质量（如矿石品位、土壤肥力、水质） | 决定开发的成本和利用方式 | 污染、退化使质量下降；改良、治理使质量提高 |
| 空间分布（集中或分散，与需求地是否一致） | 影响产业布局、运输与跨区域调配 | 调配工程与贸易改变资源的空间配置（接选必 2 第 2.7 条） |

**示范（示意数据，区域是虚构的）**：甲地某种资源的总量是乙地的 2 倍，人口是乙地的 4 倍。甲地这种资源的人均占有量是乙地的多少？
答：2 ÷ 4 = 0.5，只有乙地的一半——总量多，人均不一定多。常见错答"是乙地的 2 倍"，只看了总量。

```verify
{"claim": "示意数据：总量为乙地的 2 倍、人口为乙地的 4 倍，人均占有量为乙地的 0.5 倍；与只看总量的错答 2 倍不同", "expr": "[2 / 4, 2 / 4 === 2]", "expect": [0.5, false]}
```

- 教材常见案例：水资源、土地资源、矿产资源的分布与利用（具体以所用教材为准）。

**常见说法与订正**（对应子类型 DI15）
- ① 只看总量，不看人均和质量。
- ② 只说资源影响人类活动，不说人类活动反过来改变资源的数量和质量（初中阶段同类的"只说一面"记 DI03）。
- ③ 只说资源在哪里，不说它和人口、产业的分布对不对得上。

**自己走一遍**："用教材的一个实例，按数量、质量、空间分布各写一句'它怎样影响人类活动'，再写一句人类活动怎样反过来影响它。"（要点：三个方面都写到；有一句反向的影响）

## 二、高中选必 3 第 3.2 条：战略性矿产资源

**范围**：选择性必修（只在等级考范围）。
**课标**：「以某种战略性矿产资源为例，分析其分布特点及开发利用现状。」课标不点名矿种，选哪一种以所用教材为准；我国的战略性矿产以国家公布的目录和所用教材为准。教材常见案例有石油、稀土等。
**先问**："教材选的是哪一种？它为什么算'战略性'的？"

| 环节 | 这一条要说清什么 |
|---|---|
| 为什么是"战略性" | 对国家经济、国防或新兴产业有多重要（按教材的说法） |
| 分布特点 | 世界上集中在哪些地方；我国的分布：集中还是分散，储量与品位，和需求地是否一致（用教材的分布图与数据） |
| 开发利用现状 | 产量与消费量、自给还是需要进口（教材说法：对外依存度）、开采与加工的技术、开发中的环境问题 |
| 和国家安全的联系 | 供应是否稳定、运输通道是否安全、能否高效利用（教材说法：资源安全、能源安全） |
| 应对（以教材为准） | 加强勘探、节约与高效利用、供应来源多元、建立储备、发展替代资源（教材说法） |

**常见说法与订正**（对应子类型 DI15）
- ① 分布特点只列产地名——要归纳成"集中在……，与需求地……"这样的一句话。
- ② 现状只写"储量丰富"——还要说开发利用的程度、供需关系和存在的问题。
- ③ 自己补充教材里没有的储量、产量数字——数字一律用教材资料。

**自己走一遍**："用教材选的那种矿产，按'为什么是战略性 → 分布特点 → 开发利用现状 → 和国家安全的联系'各写一句。"（要点：分布特点是归纳句；现状里有供需关系）

## 三、高中选必 3 第 3.3 条：中国耕地资源与粮食安全

**范围**：选择性必修（只在等级考范围）。
**课标**：「运用图表，描述中国耕地资源的分布，说明其开发利用现状，以及耕地保护与粮食安全的关系。」这是课标全文唯一写到"耕地""粮食安全"的条目。三个动作：描述分布、说明现状、说明关系。
**先问**："看教材的耕地分布图：耕地集中在哪些地形区？北方和南方的耕地类型一样吗？"

- **描述分布**（按教材图表；以下是教材常见说法）：耕地主要分布在东部季风区的平原、盆地和低缓丘陵，如东北平原、华北平原、长江中下游平原、四川盆地；北方以旱地为主，南方以水田为主（初中的南北对比见 `references/region-cognition-guide.md` 第四节）；西北干旱地区的耕地多在有灌溉条件的绿洲和沿河平原。分布特点写成一句话，不罗列地名。
- **说明现状**（教材常见说法，数字以教材为准）：人均耕地少，后备耕地资源不足；优质耕地比重不高；有建设占用、耕地质量下降等问题；部分教材还讲到粮食生产重心北移、"北粮南运"。
- **说明关系**：

```text
耕地的数量与质量 → 粮食生产能力 → 粮食供应是否稳定 → 粮食安全
耕地减少或退化 → 生产能力下降 → 依赖外部供应的风险增加
```

- 耕地保护的措施按教材讲（教材说法：耕地保护制度、永久基本农田、高标准农田建设、耕地占补平衡等）；讲每项措施时说清它保护的是耕地的数量、质量还是生态。
- 粮食安全还和水资源、种子、科技、储备、贸易等有关，本条讲的是耕地这一侧。耕地分布图、统计图读不懂，转地理读图教练（xiaozhi-geography-map-reader）。

**示范（示意数据）**：某地粮食播种面积比原来减少 5%，单位面积产量提高 5%，粮食总产量怎样变化？
答：0.95 × 1.05 = 0.9975，总产量减少 0.25%——单产提高没有完全抵消面积的减少。常见错答"不变"（把 −5% 和 +5% 直接相加）。

```verify
{"claim": "示意数据：播种面积 ×0.95、单产 ×1.05，总产量为原来的 0.9975 倍，即减少 0.25%（不是不变）", "expr": "[0.95 * 1.05, Math.round((0.95 * 1.05 - 1) * 10000) / 100]", "expect": [0.9975, -0.25]}
```

**常见说法与订正**（对应子类型 DI16）
- ① 只说耕地的数量，不说质量。
- ② 把"耕地分布"写成一串省名或地名。
- ③ 认为单产提高了，耕地少一点没关系——面积减少要靠单产来补，上面的示意数据里就没有补平。

**自己走一遍**："用教材的耕地分布图写一句分布特点，再用'耕地 → 粮食生产能力 → 粮食安全'的链条，说明一项耕地保护措施的作用。"（要点：分布特点是归纳句；措施对准数量、质量或生态中的一项）

## 四、高中选必 3 第 3.4 条：海洋空间资源开发与国家安全

**范围**：选择性必修（只在等级考范围）。
**课标**：「结合实例，说明海洋空间资源开发对国家安全的影响。」
**先问**："海洋的'空间'能拿来做什么？教材的实例属于哪一种？"

| 环节 | 这一条要说清什么 |
|---|---|
| 实例属于哪一类开发（教材说法） | 海上交通运输（港口、航道）、海底空间（隧道、管道、电缆）、海上空间（人工岛、海上风电等）、海岸带开发等 |
| 区域条件 | 在哪片海域、离陆地多远，自然条件（水深、风浪、海冰、地质）怎样 |
| 有利影响 | 拓展发展空间；保障海上运输与能源、物资的进口；保障通信（教材说法） |
| 可能的不利影响与风险 | 不合理开发破坏海岸带与海洋生态；设施受海洋灾害、事故的威胁（教材说法） |
| 结论 | 按教材的分类，说清影响到国家安全的哪些方面 |

- 必修里的相关条目是地理 2 第 2.8 条（维护国家海洋权益和重视海洋发展战略的重要意义），讲法见 `references/region-hs-required.md` 第四节。海域面积、开发规模等数字以教材为准。

**常见说法与订正**（对应子类型 DI16）
- ① 只说有利，不说风险。
- ② 把"海洋空间资源"说成海里的鱼、油气——那是海洋生物资源、矿产资源；空间资源说的是利用海洋的空间（教材说法）。
- ③ "影响国家安全"只写一句，不说是哪一方面。

**自己走一遍**："用教材的一个海洋空间开发实例，按'属于哪类开发 → 区域条件 → 有利影响 → 风险'各写一句。"（要点：有利与风险都写；影响落到国家安全的具体方面）

## 五、高中选必 3 第 3.5 条：碳排放与碳减排国际合作（区域侧）

**范围**：选择性必修（只在等级考范围）。
**课标**：「结合实例，运用碳循环和温室效应原理，分析碳排放对环境的影响，说明碳减排国际合作的重要性。」
**分工**：碳循环和温室效应的原理、碳排放怎样影响环境，归地理成因链教练（xiaozhi-geography-causal-chain），原理说错记 DP21；本文讲区域侧：排放的区域差异，以及为什么要国际合作、怎样合作。
**先问**："比较两个国家的碳排放，只看排放总量够不够？"

- **区域差异**：比较不同国家或地区的碳排放，总量、人均、历史累计一起看（教材说法）；各地的发展阶段、能源结构、产业结构不同，排放与减排的条件也不同。
- **为什么要国际合作**：温室气体在全球大气中混合，影响是全球性的；一个国家或地区单独减排难以解决问题；各国条件不同，需要分工合作、相互支持（教材说法："共同但有区别的责任"）。
- **怎样合作**（教材说法，以所用教材为准）：国际公约与协定（如《联合国气候变化框架公约》《巴黎协定》）、技术合作、资金支持等。
- **我国的行动**：课标教学提示建议「研讨我国积极稳妥推进碳达峰碳中和战略对人类社会可持续发展的贡献」，这是教学活动，不是内容要求；碳达峰、碳中和的含义与时间目标以所用教材为准。

模板（把"重要性"写具体，对应子类型 DE07）：

```text
要解决的问题（全球性的影响）→ 各方的条件与责任（区域差异）→ 合作做什么 → 对各方与全球的意义
```

**常见说法与订正**
- ① 比较排放只看总量就下结论，漏了人均与历史累计（要点不全，DE02）。
- ② 重要性只写"保护地球，人人有责"一句——要写出全球性的影响、各方的条件与合作的具体内容（DE07）。
- ③ 把温室效应说成臭氧层破坏——原理错误，转地理成因链教练（DP21）。

**自己走一遍**："用教材的一个实例，按模板的四个环节各写一句，说明碳减排国际合作的重要性。"（要点：有区域差异；合作内容具体）

## 六、高中选必 3 第 3.6 条：自然保护地与生态安全

**范围**：选择性必修（只在等级考范围）。
**课标**：「结合实例，说明设立自然保护地对生态安全的意义。」课标用"自然保护地"；教学提示有一项活动：「探究我国建设国家公园的意义」。
**先问**："为什么偏偏在这里设立保护地？保护好这里，受益的只有这里吗？"

- 自然保护地的类型按教材讲（教材说法：我国的自然保护地包括国家公园、自然保护区和各类自然公园等）。
- 生态安全（教材说法）：生态系统保持完整、稳定，能持续提供水源涵养、水土保持、防风固沙、生物多样性维护等生态服务，支撑人的生存与发展。

| 环节 | 这一条要说清什么 |
|---|---|
| 选址的区域条件 | 这里有什么值得保护：典型的生态系统、珍稀动植物、重要的水源地或生态屏障 |
| 面临的威胁 | 不合理开发、人类活动干扰、生境破碎（教材说法）等 |
| 设立后起什么作用 | 保护生态系统和物种，维持生态服务 |
| 对生态安全的意义 | 从本地到区域再到国家：如上游保护好水源，中下游的用水与生态也受益（④ 联系） |
| 与当地发展的协调 | 当地居民的生产生活怎样安排（如生态旅游、生态补偿，教材说法） |

- 教材常见案例：三江源国家公园等（以所用教材为准）。生态系统稳定性的生物学原理是生物学选择性必修的内容，本文讲区域与生态安全一侧。

**常见说法与订正**（对应子类型 DI17）
- ① 意义只写"保护动植物"——还要说它维持了哪些生态服务、对哪些区域的生态安全有意义。
- ② 只说保护，不说和当地发展怎样协调。
- ③ 把"自然保护地"和"自然保护区"当成同一个概念——自然保护区是自然保护地的一种（教材说法）。

**自己走一遍**："用教材的一个保护地案例，按表里五个环节各写一句。"（要点：意义写到区域尺度，不只写本地）

## 七、高中选必 3 第 3.7 条：污染物跨境转移与环境安全

**范围**：选择性必修（只在等级考范围）。
**课标**：「结合实例，说明污染物跨境转移对环境安全的影响。」
**先问**："污染物从哪里来，经过什么到了哪里？"

区域联系的四点（`references/region-cognition-guide.md` 第五节）正好用来说跨境转移：

```text
从哪里（污染源所在区域）→ 到哪里（受影响的区域）→ 流动的是什么、经过什么途径 → 对双方各有什么影响
```

| 途径（教材说法） | 怎样转移（以所用教材的案例为准） |
|---|---|
| 大气 | 大气污染物随风扩散到下风向的国家和地区 |
| 河流 | 跨国河流上游的污染随水流到下游国家 |
| 海洋 | 海洋污染物随洋流扩散 |
| 人为转移 | 固体废物的跨境转移；污染较重的产业向其他国家和地区转移 |

- 对环境安全的影响：受影响区的大气、水、土壤和生物受到损害，危及生态和人体健康；源区负有治理的责任。
- 应对（教材说法）：源头控制、监管与法规、国际合作。
- 案例按教材的表述讲，不作超出教材的评论。

**常见说法与订正**（对应子类型 DI17）
- ① 只说"污染很严重"，说不出从哪里到哪里、经过什么途径。
- ② 只想到大气、河流等自然途径，漏了固体废物、污染产业转移等人为途径。
- ③ 只说受影响区，不说源区的责任和应对。

**自己走一遍**："用教材的一个跨境转移案例，按'从哪里 → 到哪里 → 流动的是什么、经什么途径 → 对双方的影响'说一遍。"（要点：途径说得出；双方都写）

## 八、高中选必 3 第 3.8 条：环境保护政策、措施与国家安全

**范围**：选择性必修（只在等级考范围）。
**课标**：「举例说明环境保护政策、措施与国家安全的关系。」学业要求对应的一句：「能够用事实说明我国自然资源利用现状及政策和法规对维护国家安全的意义。」
**先问**："教材举了哪一项政策或措施？它针对的是什么问题？"

模板：

```text
政策或措施（以教材所举为准）→ 针对的资源或环境问题 → 怎样起作用 → 维护了哪一方面的安全（如生态安全、粮食安全、资源安全）
```

- 教材常见案例：生态保护红线、耕地保护制度（接第三节）、退耕还林还草、固体废物进口管理等（名称与内容以所用教材和国家公开发布为准）。
- 讲政策只讲课标与教材的内容，用事实说明，不作超出教材的评论。
- 教学提示里的「树立“绿水青山就是金山银山”的理念」和模块目标里的总体国家安全观，是观念目标，可以请学生谈认识，不出成知识判断题。

**常见说法与订正**（对应子类型 DI17）
- ① 只写政策名，不说它针对什么问题、怎样起作用。
- ② "与国家安全的关系"只写"很重要"——要说清维护的是哪一方面的安全。

**自己走一遍**："用教材举的一项政策或措施，按模板的四个环节各写一句。"（要点：最后一环说出具体是哪一方面的安全）

## 九、高中选必 3：调查家乡的安全与错因速查

教学提示：「组织学生开展社会调查和专题探究，例如：调查家乡的自然资源、生态环境状况」；学业要求：「能够结合家乡出现的自然资源、生态环境问题，分析成因，有理有据地提出可行性对策。」
- 离校的社会调查、实地调查由学校组织、成人带领、结伴进行，按学校外出活动安全制度执行；访谈在公共场所进行，不入户；不独自去水边、山地、工地。需要采集水样、土样的，由学校组织、老师带领；本技能不给在家或自行外出采样的步骤。
- 问卷与访谈只做汇总，不收集姓名、电话、住址；不需要学生提供自己家的住址或实时位置；家乡只说到县（区）一级。本技能只给口径，不给外出的路线与时间安排；课标点名的活动与组织方式见 `shared/geography-hs-practice-activities.md`。
- 家乡问题的成因转地理成因链教练（xiaozhi-geography-causal-chain）；对策对准成因，有理有据。

| DI16 | 耕地、海洋空间资源与国家安全的联系说不清 | 第三、四节 |
| DP21 | 碳排放对环境的影响与碳循环、温室效应原理说错 | 第五节（原理转地理成因链教练） |

| DI17 | 设立自然保护地对生态安全的意义、污染物跨境转移对环境安全的影响说不清 | 第六、七、八节 |
