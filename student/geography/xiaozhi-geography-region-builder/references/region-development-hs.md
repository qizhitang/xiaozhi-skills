## 一、高中选必 2 第 2.1 条：区域的含义及类型

**范围**：选择性必修（只在等级考范围）。
**课标**：「结合实例，说明区域的含义及类型。」课标在"区域认知"素养的内涵里写到：「将其划分成不同空间尺度、不同类型的区域加以认识，是人们认识地理环境复杂性的基本方法」；区域认知有助于学生「认识不同的区域既各有特色，又相互联系」。
**先问**："区域一定有清清楚楚的边界吗？""'一片平原'和'以一座城市为中心的通勤范围'，是按同一种思路划出来的吗？"

| 要点（教材说法，以所用教材为准） | 怎么讲 | 落在四步的哪一步 |
|---|---|---|
| 区域是按一定的指标划分出来的 | 指标不同，划出的区域不同：按地形、气候、农业类型、行政管理……都可以 | 先说清指标，再定位 |
| 有一定的位置和范围 | 行政区有明确的界线；自然区之间常是逐渐过渡的地带 | ① 定位 |
| 内部某些特征相对一致，与别的区域有差异 | 所以区域特征能归纳成一句话，区域之间能比较 | ② 归纳特征、③ 比较 |
| 区域之间相互联系 | 物质、人员、信息在区域之间流动 | ④ 联系 |
| 有尺度，可以层层划分 | 大区域里还可以划出小区域；比较之前先说清是哪个尺度 | 全程 |

**类型**（教材说法，具体分类与名称以所用教材为准）：按内部特征是否相对一致划分的，叫均质区，如按气候、地形或农业类型划出的区域；按与某个中心的联系划分的，叫功能区，如以一座城市为中心的通勤范围、商品流通范围；按行政管理划分的是行政区。这里的"功能区"是区域的一种类型，和城市内部的功能区（地理 2 第 2.2 条的教材说法）不是一回事。

**常见说法与订正**（对应子类型 DR07）
- ①"区域都有明确的边界"——行政区有，很多自然区之间是过渡带。
- ②"以城市为中心的经济区，内部各地都差不多"——功能区看的是与中心的联系，内部差异可以很大（教材说法）。
- ③ 把不同尺度的区域放在一起比，又不说明尺度。
- ④ 把区域类型里的"功能区"和城市内部的功能区混为一谈。

**自己走一遍**："教材里举了哪几个区域？各是按什么指标划分的？属于哪一种类型？边界清楚还是过渡？"（要点：每个区域都说出指标、类型和边界情况）

## 二、高中选必 2 第 2.2 条：比较区域发展的异同，说明因地制宜

**范围**：选择性必修（只在等级考范围）。
**课标**：「结合实例，从地理环境整体性和区域关联的角度，比较不同区域发展的异同，说明因地制宜对于区域发展的重要意义。」
**先问**："两个区域的发展条件，你打算比哪几项？两边都写了吗？""它们发展的路子一样吗？为什么？"

两个角度：**地理环境整体性**——区域内的地形、气候、水、土壤、生物和人口、产业相互影响，组成一个整体，发展条件放在一起看，不只看一项；**区域关联**——一个区域的发展离不开外部：市场在哪里、原料从哪里来、交通通到哪里、和哪些区域分工。

比较表（四列表的升级，原表见 `references/region-cognition-guide.md` 第四节）：同一个项目两边都写，多一列"对发展的影响"。

| 比较项目 | 区域甲 | 区域乙 | 差异的原因 | 对发展的影响 |
|---|---|---|---|---|
| 区位（位置、交通） | | | | |
| 自然条件（地形、气候、水源、土壤） | | | | |
| 资源 | | | | |
| 人口与劳动力、市场 | | | | |
| 产业基础 | | | | |
| 生态环境的约束 | | | | |
| 与外部的联系 | | | | |

然后写"异同"：相同点、不同点各写；再写"因地制宜"——发展方向依据本区域的条件，发挥优势，避开或改善限制；同一种做法搬到条件不同的区域，效果可能完全不同。选必 1 的学业要求也讲到「人们因地制宜的生产生活智慧」。

**示范**（两个虚构的区域，只演示比法）

| 比较项目 | 甲：沿海平原 | 乙：内陆山区 |
|---|---|---|
| 地形 | 平原广阔 | 山地多、平地少 |
| 交通与对外联系 | 有港口，多条干线交会，对外联系方便 | 交通线少，对外联系不便 |
| 资源 | 土地条件较好，矿产少 | 森林、水能较丰富 |
| 人口与市场 | 人口稠密，市场大 | 人口稀少，市场小 |
| 生态环境的约束 | 用地紧张 | 坡地多，容易水土流失 |

发展路径（示意，不是唯一答案）：甲可以依托港口和市场发展外向型的制造业和服务业；乙可以发展林特产品加工、水能利用和生态旅游，开发坡地时注意水土保持。相同点是都要依托自身的条件、加强和外部的联系；不同点是依托的条件不同，甲的路子不能照搬到乙。

**常见说法与订正**（对应子类型 DR08）
- ① 两边写的不是同一个项目（甲写地形，乙写气候；初中阶段同类问题记 DR03）。
- ② 只比条件，不比发展——课标要"比较不同区域发展的异同"。
- ③ 给条件很不一样的两个区域开同一张"药方"（如都写"发展高新技术产业"）——没有因地制宜。
- ④ 只说优势，不说限制。

**自己走一遍**："拿教材里的两个区域填上面的比较表，再各写一条'因地制宜'的发展路径，说明它依托了哪一项条件。"（要点：每一项两边都写；路径与条件一一对应。开放题，要点不唯一）

## 三、高中选必 2：六条"以某……为例"的通用案例模板

**范围**：选择性必修（只在等级考范围）。
选必 2 第 2.3—2.8 条都写"以某……为例"，课标不点名具体区域，案例以所用教材为准；教学提示建议「结合典型的或身边的案例，也可结合我国区域协调发展战略」。案例换了，思路不换：

```text
区域条件 → 问题或变化 → 原因 → 路径 → 评价
```

| 环节 | 问什么 | 对应四步与学业质量 |
|---|---|---|
| 区域条件 | 在哪里，有哪些自然条件与社会经济条件，优势和限制都写 | ① 定位、② 归纳特征 |
| 问题或变化 | 发生了什么变化，或面临什么问题；用教材的图表与数据说话 | ② 归纳特征（时空变化） |
| 原因 | 内部原因（条件变了）与外部原因（市场、技术、政策、和其他区域的联系） | 外部原因属 ④ 联系；成因链转地理成因链教练（xiaozhi-geography-causal-chain） |
| 路径 | 怎样发展、怎样治理、怎样协作；每条路径对准一条原因或问题 | 因地制宜 |
| 评价 | 效果与代价都说：经济、社会、生态三方面；对本区域，也对相关区域 | ③ 比较、④ 联系；附录 2 区域认知水平 3：「较全面地评析某一区域发展决策的得失，并提出较为可行的改进建议」 |

- 案例写"教材常见案例"，具体以所用教材为准；案例的数据与过程按教材资料讲，本技能不另补数据。
- 评价不是表态：要有观点、有论据，论据来自案例的区域条件和资料。

## 四、高中选必 2 第 2.3 条：大都市的辐射功能

**范围**：选择性必修（只在等级考范围）。
**课标**：「以某大都市为例，从区域空间组织的视角出发，说明大都市辐射功能。」"区域空间组织的视角"可以对照学业质量水平 3 的说法：「运用相关证据说明区域间物质流动、人员流动和信息流动的方式、强度，以及空间组织形式」。
**先问**："大都市向周边'辐射'出去的是什么？周边又给大都市带来什么？"

| 环节 | 这一条要说清什么 |
|---|---|
| 区域条件 | 大都市的位置与交通（是不是交通枢纽，教材说法）、经济与科技实力、服务功能（如金融、贸易、科技、教育） |
| 变化 | 辐射出去的内容（产业、资金、技术、人才、信息、服务）和辐射范围怎样变化 |
| 原因 | 交通与通信网络的发展、产业分工与转移、市场联系 |
| 路径 | 大都市怎样提升自身的功能；周边区域怎样承接、分工，与大都市错位发展 |
| 评价 | 对周边：有带动（扩散）的一面，也有人口、资金向大都市集中（集聚）的一面；对大都市：疏解部分功能，也面临自身的压力（教材说法） |

- 用四点说联系（`references/region-cognition-guide.md` 第五节）：从大都市 → 到周边哪些区域 → 流动的是什么 → 对双方各有什么意义。
- 说空间组织时可以分三部分整理（本文的整理方法，不是课标原词）：中心（大都市）、通道（交通线、通信网络）、腹地（受辐射的周边区域，教材说法）。
- 教材常见案例：上海等（以所用教材为准）。

**常见说法与订正**（对应子类型 DR09）
- ① 只说大都市"经济发达"，不说辐射出去的是什么、到了哪里。
- ② 只说单向的带动，不说周边对大都市的支撑，也不说集聚的一面。
- ③ 辐射范围只写"全国"一句，不按空间组织说清方向和通道。

**自己走一遍**："用教材的大都市案例，按'从哪里 → 到哪里 → 流动的是什么 → 对双方各有什么意义'说清它的两种辐射内容。"（要点：两种内容都说出方向与通道；对双方的意义各写一条）

## 五、高中选必 2 第 2.4 条：地区产业结构的变化

**范围**：选择性必修（只在等级考范围）。
**课标**：「以某地区为例，分析地区产业结构变化过程及原因。」动词是"分析"，过程与原因都要有。
**先问**："这个地区原来以什么产业为主？现在呢？中间分了几个阶段？"

| 环节 | 这一条要说清什么 |
|---|---|
| 区域条件 | 起步时的资源、劳动力、交通、市场、政策 |
| 变化过程 | 三次产业（教材说法）的比重和主导产业怎样变，分几个阶段 |
| 原因 | 内部：资源、劳动力成本、技术、产业基础的变化；外部：市场需求、产业转移、政策、和其他区域的分工 |
| 路径 | 产业升级的方向（教材说法），如发展技术含量高的产业和服务业 |
| 评价 | 经济、社会（就业）、生态三方面的效果与代价 |

**示范（示意数据，地区是虚构的）**：某地区三次产业产值比重，2000 年第一产业 25%、第二产业 45%、第三产业 30%；2020 年依次为 8%、40%、52%。问：比重下降最多的是哪个产业？产业结构怎样变化？
答：第一产业下降最多，降了 17 个百分点（第二产业降 5 个百分点，第三产业升 22 个百分点）；比重最高的产业由第二产业变为第三产业。比重的变化用"百分点"说：25% 降到 8% 是下降 17 个百分点，按原来的比重算是相对下降 68%，不是"下降 17%"。比重算错属地理计算（DQ），转地理读图教练（xiaozhi-geography-map-reader）。


## 六、高中选必 2 第 2.5 条：资源枯竭型城市的转型发展

**范围**：选择性必修（只在等级考范围）。
**课标**：「以某资源枯竭型城市为例，分析该类城市转型发展的方向。」
**先问**："这座城市原来靠什么资源发展起来？资源快采完了，城市会遇到哪些问题？"

**课标例 3：德国鲁尔区**。课标表现性评价的例 3 是「例 3“德国鲁尔区的探索”的表现性评价」，评价内容是：「能否在真实的世界中确定符合该主题要求的地区；能否选择不同的资料作为证据，说明该地区某资源枯竭状况；能否根据该地区的特点和发生的问题，提出合理可行的发展方案。」例 3 的三个任务（图 2，按原文大意）正好对上案例模板：任务一，分析德国鲁尔区、我国山西省煤炭基地的区位条件（区域条件）；任务二，探究德国鲁尔区"兴衰"的过程与原因（变化与原因）；任务三，借鉴德国鲁尔区的发展经验，为我国山西省煤炭基地的能源开发设计"发展路径"（路径）。
- 例 3 研究的是"地区"：鲁尔区是一个工业区，区内有多座城市；用它学第 2.5 条，学的是这一类资源型地区和城市的转型思路。
- 例 3 里的山西省煤炭基地是借鉴经验、设计发展路径的对象；课标没有把它称为资源枯竭型城市，本技能也不这样称呼它。例 3 是教学与评价建议里的示例，不是必做。

| 环节 | 这一条要说清什么 |
|---|---|
| 区域条件 | 依托什么资源兴起，当时还有哪些有利条件（如交通、水源、市场） |
| 问题或变化 | 资源枯竭或开采条件变差以后：产业结构单一、经济衰退、失业增加、环境问题等（教材说法） |
| 原因 | 资源本身：储量减少、开采成本上升；外部：能源消费结构变化、市场需求变化、技术进步 |
| 路径（转型方向） | 延长产业链、发展接续替代产业、发展服务业（如工业遗产旅游）、生态修复与环境治理、改善交通、发展教育与科技、提高劳动者技能（教材说法，按案例取舍） |
| 评价 | 每个方向对准哪个问题；经济、社会、生态三方面的效果；转型需要的时间与代价 |

- 教材常见案例：德国鲁尔区（课标例 3），以及教材选用的我国资源型城市（以所用教材为准）。

**常见说法与订正**（对应子类型 DI12）
- ① 转型方向只写"发展第三产业"——要说明依托什么条件、解决哪个问题。
- ② 原因只写"资源枯竭"一条——外部的市场、能源结构、技术变化也要说。
- ③ 把例 3 里的山西省煤炭基地说成资源枯竭型城市——课标没有这样写。

**自己走一遍**："按例 3 的三个任务，用教材的资源型城市案例各写一两句：区位条件、兴衰的过程与原因、转型的发展路径。"（要点：路径与问题一一对应。开放题，要点不唯一）

## 七、高中选必 2 第 2.6 条：生态脆弱区的问题与综合治理

**范围**：选择性必修（只在等级考范围）。
**课标**：「以某生态脆弱区为例，说明该类地区存在的环境与发展问题，以及综合治理措施。」两类问题（环境的、发展的）都要说，治理是"综合"的。
**先问**："这个地区为什么'脆弱'？脆弱在自然条件的哪几项？"

| 环节 | 这一条要说清什么 |
|---|---|
| 区域条件 | 自然方面的脆弱：气候（干旱，或降水集中、多暴雨）、地形（坡陡）、土壤（疏松或土层薄）、植被（稀少）；人文方面：人口压力、生产方式（教材说法） |
| 问题 | 环境问题，如水土流失、土地荒漠化、石漠化（教材说法）；发展问题，如经济落后、产业单一 |
| 原因 | 自然条件是基础，不合理的人类活动加剧问题；两方面都写 |
| 路径（综合治理） | 工程措施、生物措施、农业技术措施，加上调整产业结构、减轻人口压力、政策与制度（教材说法）；每条措施对准一条原因 |
| 评价 | 生态、经济、社会效益兼顾；治理见效需要时间 |

**问题、原因、措施要对得上**（教材常见说法，细节以所用教材为准）

| 问题 | 原因 | 对症的措施 |
|---|---|---|
| 水土流失 | 土质疏松、坡陡、植被少，夏季多暴雨；加上陡坡开垦、植被破坏 | 坡面修梯田、退耕还林还草，沟道打淤地坝 |
| 土地荒漠化 | 气候干旱、多大风；加上过度放牧、过度开垦、过度樵采、水资源利用不当 | 合理利用水资源、营造防护林、调整农林牧用地、退耕还林还草 |

- 教材常见案例：黄土高原（水土流失）、西北干旱半干旱地区（荒漠化）、西南喀斯特地区（石漠化）等（以所用教材为准）。
- 环节之间的成因链（如"植被破坏 → 水土流失加剧 → 土壤变贫瘠 → 植被更难恢复"）转地理成因链教练（xiaozhi-geography-causal-chain）。

**常见说法与订正**（对应子类型 DI13）
- ① 措施和问题对不上，如给荒漠化写"打淤地坝"。
- ② 只说环境问题，不说发展问题；或者治理只写"种树"一项——课标要"综合治理"。
- ③ 原因只说人为、不说自然条件，或反过来。

**自己走一遍**："用教材的生态脆弱区案例，填'问题 → 原因 → 对症的措施'三列表，每一行都对得上。"（要点：每条措施都能指回一条原因）

## 八、高中选必 2 第 2.7 条：产业转移与资源跨区域调配

**范围**：选择性必修（只在等级考范围）。
**课标**：「以某区域为例，说明产业转移和资源跨区域调配对区域发展的影响。」一条里有两件事；影响要对两头都写。
**先问**："产业从哪里转到哪里？资源从哪里调到哪里？对两头各有什么影响？"

区域联系的四点（`references/region-cognition-guide.md` 第五节）到高中再加一层：案例模板的每个环节两头都写，影响的有利、不利都写；资源调配还要看沿线地区。表中的条件与影响是教材常见说法，以所用教材为准。

| 环节 | 转出地或调出区 | 转入地或调入区 |
|---|---|---|
| 区域条件 | 产业转移：土地、劳动力成本上升，有产业升级的需要和环境压力；资源调配：资源丰富 | 产业转移：劳动力和土地成本较低，有资源、市场或政策条件；资源调配：资源短缺 |
| 问题或变化 | 产业或资源流出 | 产业或资源流入 |
| 原因 | 两头条件的差异；交通改善、政策引导等外部条件 | 同左 |
| 路径 | 腾出空间发展新的产业；资源调出区把资源优势转化为经济优势 | 承接产业，配套基础设施和服务；建好输送与配套设施，用好调入的资源 |
| 评价（有利、不利都写） | 有利：产业升级，资源调出区带动基础设施建设；不利：部分就业岗位减少，资源调出区可能承受生态环境压力 | 有利：增加就业，促进经济增长和产业升级；资源调入区缓解短缺，调入清洁能源的还能改善能源结构与环境。不利：承接污染较重的产业时，可能带来环境压力 |

- 资源调配工程的建设与运行对沿线生态环境的影响，按教材案例讲。
- 教材常见案例：产业转移——我国东部沿海地区向中西部地区的转移、东亚的国际产业转移等；资源跨区域调配——南水北调、西气东输、西电东送等（以所用教材为准）。初中学过南水北调"从哪里调到哪里"（`references/region-cognition-guide.md` 第五节），高中再说清对两头、对沿线的影响。

**常见说法与订正**（对应子类型 DI14）
- ① 只说转入地得到好处，不说转出地；或只说有利，不说不利。
- ② 把产业转移和资源跨区域调配混成一件事——一个流动的是产业，一个流动的是资源。
- ③ 说不清流动的方向与原因（初中阶段同类问题记 DR04）。

**自己走一遍**："用教材的一个案例画两栏表：转出地（或调出区）| 转入地（或调入区），每栏写有利、不利各一条。"（要点：四格都填；不利影响有依据）

## 九、高中选必 2 第 2.8 条：流域内部的协作

**范围**：选择性必修（只在等级考范围）。
**课标**：「以某流域为例，说明流域内部协作开发水资源、协调发展、保护环境的意义。」意义要说三方面：协作开发水资源、协调发展、保护环境。
**先问**："上游修水库、用水多了，下游会怎样？上游的污染会流到哪里？"

| 环节 | 这一条要说清什么 |
|---|---|
| 区域条件 | 流域是以河流为纽带的整体：上中下游、干支流、左右岸相互影响；各河段的地形、水量、水能、人口与产业不同 |
| 问题 | 上下游用水矛盾、上游开发影响下游、污染随水流向下游、开发与保护的矛盾 |
| 原因 | 流域内各区域的条件不同、利益不同，一地的做法会影响别处 |
| 路径（协作） | 统一规划和管理、分河段开发（教材说法：梯级开发）、上下游协同治理污染、上下游之间的补偿（教材说法：生态补偿）、产业分工 |
| 评价 | 三方面意义各写一点：协作开发水资源、协调发展、保护环境 |

- 教材常见案例：美国田纳西河流域，我国长江流域、黄河流域等（以所用教材为准）。

**常见说法与订正**（对应子类型 DR10）
- ① 只从一个河段说，看不到上下游的联系。
- ② 把流域协作只写成"修水库发电"——还有用水分配、污染治理、生态保护和产业分工。
- ③ 三方面意义漏了"保护环境"。

**自己走一遍**："用教材的流域案例，上游、中游、下游各写一条'对别的河段的影响'，再写一件需要协作才能办成的事。"（要点：影响有方向；协作的事能对上一个问题）

## 十、高中选必 2 第 2.9 条："一带一路"建设与国际合作
