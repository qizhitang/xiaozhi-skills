## 一、怎么用

**链条更长，起点常是能量和物质运动。** 选必 1 的学业要求是「从自然环境要素的物质运动和能量交换的角度，分析现实世界一些自然现象的成因、过程及其对人类活动的影响」：起点常是能量（太阳辐射、地球内部的热能）或物质运动（大气、水、岩石），终点常落到人类活动。等级考的上限水平 3 要求「综合分析地理分布、特征等的形成过程或原因、条件，并解释地理过程前后承袭、时间变化等的特点和规律」，也就是多要素、多环节，还要讲清先后和变化。

**怎么练、怎么记。** 同必修文件第一节：每块末尾的"检验"由学生自己答，AI 不代答；提示按 `shared/hint-ladder.md` 逐级给，即兴出的题按 `shared/ai-item-check.md` 自检；连错时记"常见断环"行里的子类型。光照图、地质剖面图、简易天气图、气候资料图、洋流图的读法和计算转地理读图教练。

**实践与安全。** 选必 1 的教学提示提倡「采取野外考察、地理实验等方法」，选必 3 的学业要求写「在地理野外考察、社会调查等实践活动中」。离校的野外考察、社会调查由学校组织、成人带领、结伴进行，按学校外出活动安全制度执行；访谈在公共场所进行、不入户；问卷不收集姓名、电话、住址，也不需要学生提供自己家的住址或实时位置；不独自去水边、山地、工地。课堂演示按 `shared/lab-safety.md` 定档，本技能不给在家做的、有风险的操作步骤。课标点名的实践活动见 `shared/geography-hs-practice-activities.md`。

## 二、选必 1：自然地理基础（第 1.1—1.9 条）

### （一）地球运动的地理意义（选必 1 第 1.1 条）

范围：选择性必修（只在等级考范围）。课标：「结合实例，说明地球运动的地理意义。」课标只有这一句，自转、公转和下面各项意义都是教材说法。初中的两条（昼夜交替与时间差异、四季与五带）见 `references/causal-chain-guide.md` 第三节第 1、2 条；光照图、昼长与日出日落时刻、地方时与区时、正午太阳高度的读图和计算转地理读图教练（DM12、DQ08、DQ05、DQ06）。

**直观含义**：地球自己转一圈是一天，带来昼夜交替和各地的时间差；绕太阳转一圈是一年，带来昼夜长短、太阳高低和四季的变化。
```text
自转
   昼夜交替的周期不长 → 白天增温不至于过高、夜晚降温不至于过低 → 有利于生物生存
   自西向东自转 → 东边先见到日出 → 经度不同，地方时不同（东早西晚）→ 生活中统一使用时区和区时
   沿地表水平运动的物体方向发生偏转：北半球向右偏、南半球向左偏、赤道上不偏（地转偏向力）
      → 影响风向和洋流的方向；北半球的河流顺着水流方向看，右岸往往冲刷较重（教材常见案例）
公转
   黄赤交角约 23°26′，地轴的空间指向保持不变 → 太阳直射点在南、北回归线之间往返移动
   → 昼夜长短随纬度和季节变化：直射点在哪个半球，哪个半球昼长夜短，且纬度越高昼越长；春分、秋分全球昼夜等长；赤道终年昼夜等长
   → 正午太阳高度随纬度和季节变化：由直射点所在的纬度向南北两侧递减
   → 昼长和正午太阳高度共同决定各地获得的太阳辐射 → 四季更替；以回归线、极圈为界 → 五带
```

```verify
{"claim": "黄赤交角约 23°26′（教材说法）：回归线的纬度等于黄赤交角，极圈的纬度 = 90° − 23°26′ = 66°34′；按角分计算 5400′ − 1406′ = 3994′ = 66°34′", "expr": "[90 * 60 - (23 * 60 + 26), 66 * 60 + 34]", "expect": [3994, 3994]}
```

- 演示：地球仪配干电池光源的演示（如昼夜交替）按 `shared/lab-safety.md` 属低档；接 220 V 的灯具或光源，插头由老师插拔，属中档。
- 常见断环：把冬冷夏热说成"冬季离太阳远"（1 月初地球在近日点附近，教材说法；冷暖来自直射点移动引起的昼长和正午太阳高度的变化）；地转偏向在南北半球说反，或说赤道上偏转最大。对应子类型 DP08。
- 检验（学生自己答）："北半球冬季比夏季冷，是因为冬季地球离太阳远吗？"（要点：不是；1 月初地球在近日点附近。北半球冬季太阳直射南半球，北半球昼短夜长、正午太阳高度小，获得的太阳辐射少）

### （二）岩石圈物质循环（选必 1 第 1.2 条）

范围：选择性必修（只在等级考范围）。课标：「运用示意图，说明岩石圈物质循环过程。」三大类岩石和各种作用的名称是教材说法；"软流层一般被认为是岩浆的发源地"见 `references/causal-chains-hs-required.md` 第二节（二）。

**直观含义**：岩石会"变身"——岩浆冷却成岩石，岩石被风化、冲刷后又压成新的岩石，在地下高温高压下还会变质，或重新熔成岩浆。
```text
① 结果：岩石圈的物质在岩浆与三大类岩石之间循环转化
② 起点：地球内部的热能推动岩浆活动和变质作用；太阳辐射能和重力能推动风化、流水等外力作用（教材说法）
③ 岩浆 → 侵入地壳或喷出地表，冷却凝固 → 岩浆岩（侵入岩、喷出岩）
   出露地表的各类岩石 → 风化、侵蚀、搬运、堆积 → 沉积物 → 固结成岩 → 沉积岩（常有层理，可能含化石）
   各类岩石在高温、高压下 → 变质作用 → 变质岩
   各类岩石在地下深处熔化 → 重熔再生 → 新的岩浆
④ 一句话：岩浆冷凝成岩浆岩，岩石经外力作用成沉积岩、经变质作用成变质岩，又都能熔回岩浆，周而复始
```

- 读图的抓手（教材常见做法）：只有一个箭头指向、而且这个箭头来自岩浆的，是岩浆岩；由岩石指向岩浆的箭头代表重熔再生；指向沉积岩的箭头代表外力作用；指向变质岩的箭头代表变质作用。
- 意义：物质在岩石圈与大气圈、水圈、生物圈之间交换 → 形成矿产、改变地表形态（教材说法）。
- 常见断环：让沉积岩或变质岩不经过岩浆直接变成岩浆岩；把指向沉积岩的箭头说成变质作用。对应子类型 DP14。地质剖面图的读法转地理读图教练（DM13）。
- 检验（学生自己答）："在岩石圈物质循环示意图里，有一类岩石只有一个箭头指向它，箭头来自岩浆。它是哪一类岩石？这个箭头代表什么作用？"（要点：岩浆岩；冷却凝固）

### （三）内力和外力对地表形态的影响（选必 1 第 1.3 条）

范围：选择性必修（只在等级考范围）。课标：「结合实例，解释内力和外力对地表形态变化的影响，并说明人类活动与地表形态的关系。」褶皱、断层、背斜、向斜和各类地貌的名称都是教材说法，实例以所用教材为准；板块碰撞与张裂一链见 `references/causal-chain-guide.md` 第三节第 5 条。

**直观含义**：地球内部的力量把地面抬高、压弯、错开；风、流水、冰川等把高处削低、把低处填平。
```text
总方向：内力作用 → 地表高低起伏加大；外力作用 → 削高填低，地表趋于平坦（教材说法）
内力
   岩层受水平挤压 → 弯曲变形 → 褶皱：向上拱起的是背斜，向下弯曲的是向斜
   背斜顶部受张力、裂隙多 → 易被侵蚀 → 可能成谷；向斜槽部受挤压、岩性坚实 → 不易被侵蚀 → 可能成山（教材说法：背斜成谷、向斜成山）
   岩层受力超过一定限度 → 断裂，并沿断裂面明显错动 → 断层 → 上升的岩块常成山，下降的岩块常成谷地或盆地；断层带岩石破碎 → 常发育成沟谷
外力（教材常见案例）
   河流上游落差大、流速快 → 向下侵蚀强 → V 形谷
   河流出山口，地势变缓、河道变宽 → 流速减慢 → 泥沙堆积 → 冲积扇
   河流入海，流速减慢，又受海水顶托 → 泥沙堆积 → 三角洲
   干旱区风力强 → 风蚀地貌与沙丘；石灰岩地区流水溶蚀 → 溶洞、峰林等（喀斯特地貌）
```

- 应用（教材常见案例）：背斜顶部常储存石油、天然气，向斜槽部常储存地下水；隧道多选在背斜处（岩层呈拱形、比较稳定，地下水沿两翼流走）；断层带不宜修建大型工程。
- 人类活动与地表形态：冲积扇、三角洲地势平坦、土壤肥沃、水源充足 → 农业和聚落集中；山区的交通线常沿河谷延伸。反过来，修梯田、开挖道路、采矿 → 改变坡面；过度开垦 → 侵蚀加剧；上游修水库拦住泥沙 → 下游入海的泥沙减少 → 三角洲增长变慢，甚至被海浪侵蚀后退。
- 常见断环：把"背斜"当成"山"的同义词（背斜、向斜说的是岩层怎样弯曲，地表是山是谷还要看外力）；说冲积扇是"流速加快"造成的；只说内力或只说外力；人类活动只说一个方向。对应子类型 DP15。
- 检验（学生自己答）："背斜一定形成山岭吗？举出一种相反的情况并说明成因。"（要点：不一定；背斜顶部受张力、岩石破碎，易被侵蚀，可能被侵蚀成谷地）

### （四）锋、低压（气旋）、高压（反气旋）（选必 1 第 1.4 条）

范围：选择性必修（只在等级考范围）。课标：「运用示意图，分析锋、低压（气旋）、高压（反气旋）等天气系统，并运用简易天气图，解释常见天气现象的成因。」课标的原词是"锋"；锋面、冷锋、暖锋、准静止锋、气团、等压线是教材说法。简易天气图的读法转地理读图教练（DM14）；课标建议「可以利用互联网提供的实时天气云图和风场图，帮助学生感知和理解真实的大气状况」。

**直观含义**：冷、暖空气相遇的地方（锋）和气压低的地方，空气被抬升，容易下雨；气压高的地方空气下沉，多晴天。

**总规律**：空气上升 → 冷却 → 水汽凝结 → 云雨；空气下沉 → 增温 → 水汽不易凝结 → 晴朗。下面每个天气系统都落到这一环。
```text
冷锋：冷气团主动推向暖气团 → 冷气团密度大，楔入暖气团下方 → 暖气团被迫抬升 → 冷却凝结 → 锋后多云雨，常伴大风、降温
   → 过境后由冷气团控制 → 气温下降、气压升高、天气转晴（教材常见案例：寒潮，北方夏季的暴雨）
暖锋：暖气团主动推向冷气团 → 暖气团沿锋面缓慢爬升 → 冷却凝结 → 锋前多连续性降水
   → 过境后由暖气团控制 → 气温升高、气压降低、天气转晴
   两种锋的降水都主要在冷气团一侧
准静止锋：冷、暖气团势均力敌 → 锋面来回摆动 → 长时间阴雨（教材常见案例：江淮地区的梅雨）
低压（气旋）：中心气压低 → 近地面空气向中心辐合（北半球逆时针、南半球顺时针）→ 中心空气上升 → 多阴雨；台风是强烈发展的热带气旋
高压（反气旋）：中心气压高 → 中心空气下沉 → 近地面空气向四周辐散（北半球顺时针、南半球逆时针）→ 多晴朗（教材常见案例：长江中下游盛夏的伏旱）
简易天气图上：等压线密集 → 水平气压差大 → 风力大；锋多出现在低压槽附近（教材说法）
```

- 常见断环：把冷锋的降水说在锋前，或说暖锋过境后降温；说气旋中心盛行下沉气流；南北半球气旋、反气旋的旋转方向说反。对应子类型 DP16。
- 检验（学生自己答）："冷锋过境后，气温、气压和天气分别怎样变化？"（要点：气温下降、气压升高、天气转晴）

### （五）气压带、风带与气候、景观（选必 1 第 1.5 条）

范围：选择性必修（只在等级考范围）。课标：「运用示意图，说明气压带、风带的分布，并分析气压带、风带对气候形成的作用，以及气候对自然地理景观形成的影响。」三圈环流、地转偏向力、信风、西风、季风和气候类型的名称都是教材说法。气候资料图的读法转地理读图教练（DM05）。

**直观含义**：赤道一带热空气上升、多雨，副热带一带空气下沉、少雨；一个地方全年或某个季节受哪种气压带、风带控制，决定了它是干还是湿，也决定了长出什么样的植被。
```text
分布（教材说法：三圈环流）
   赤道终年受热多 → 空气膨胀上升 → 近地面形成赤道低气压带（热力原因）
   高空气流流向高纬，受地转偏向影响逐渐偏转 → 在南北纬 30° 附近堆积下沉 → 副热带高气压带（动力原因）
   两极寒冷 → 空气冷却收缩下沉 → 极地高气压带（热力原因）
   南北纬 60° 附近，从副热带流来的较暖空气与从极地流来的冷空气相遇 → 较暖的空气被抬升 → 副极地低气压带（动力原因）

季节移动：太阳直射点北移、南移 → 气压带、风带随之北移、南移
```

### （六）陆地水体之间的相互关系（选必 1 第 1.6 条）

范围：选择性必修（只在等级考范围）。课标：「绘制示意图，解释各类陆地水体之间的相互关系。」这是五个模块里唯一要求"绘制示意图"的条目；河流补给类型的名称是教材说法。河流流量过程线的读法转地理读图教练。

**直观含义**：河流、湖泊、地下水、冰川是连通的；谁的水位高，水就从谁那里流向谁。
```text
补给类型（教材说法）
   雨水补给：降水 → 河流 → 汛期与雨季一致（我国东部季风区的河流多以这一类为主）
   季节性积雪融水补给：春季气温回升 → 积雪融化 → 春汛（教材常见案例：东北的河流）
   冰川融水补给：夏季气温高 → 冰川融化多 → 夏季流量大，随气温变化（教材常见案例：西北内陆的河流）
   湖泊水、地下水补给：比较稳定
相互补给：水位高的一方补给水位低的一方
   河流与湖泊：汛期河流水位高 → 河水补给湖泊；枯水期湖泊水位高 → 湖水补给河流 → 湖泊削减洪峰、补充枯水（教材常见案例：长江与洞庭湖、鄱阳湖）
   河流与地下水：河流水位高于地下水位 → 河水补给地下水（教材常见案例：河床高于两岸地面的黄河下游"地上河"）；地下水位高于河流水位 → 地下水补给河流（枯水期常靠它维持流量）
   冰川融水 → 河流：单向补给
```

- 绘制示意图：画出各类水体 → 标出水位高低（随季节变化的，汛期、枯水期各画一张）→ 箭头从水位高的一方指向水位低的一方 → 单向补给只画一个箭头，互补的标明季节。
- 人类活动：地下水超采 → 地下水位下降 → 枯水期河流水量减少，还可能引起地面沉降；围湖造田 → 湖泊调蓄能力减弱 → 洪峰加大（教材常见案例）。
- 常见断环：互补关系不分季节，箭头画成固定方向；把冰川融水补给的汛期说成由降水决定（它主要取决于气温）。对应子类型 DP18。
- 检验（学生自己答）："黄河下游的'地上河'河段，河水和两岸的地下水之间，是谁补给谁？为什么？"（要点：河水补给地下水；河床高于两岸地面，河水水位高于两岸的地下水位）

### （七）洋流的分布规律与影响（选必 1 第 1.7 条）

范围：选择性必修（只在等级考范围）。课标：「运用世界洋流分布图，说明世界洋流的分布规律，并举例说明洋流对地理环境和人类活动的影响。」"洋流"在课标里只出现在这一条，必修地理 1 第 1.8 条没有点名；寒流、暖流、渔场等是教材说法。世界洋流分布图的读法转地理读图教练。

**直观含义**：海洋里有大规模、比较稳定的"海水河流"，主要由盛行风推动；比流经海区暖的叫暖流，让沿岸更暖、更湿，比流经海区冷的叫寒流，让沿岸更冷、更干。
```text
成因（教材说法）：盛行风吹拂海面 → 表层海水随风流动（风海流，最主要）；海水密度不同 → 密度流；一处海水流走 → 邻近海水流来补充（补偿流）
分布规律（教材说法）
   中低纬海区：以副热带海区为中心的大洋环流 → 北半球顺时针、南半球逆时针
   北半球中高纬海区：以副极地海区为中心的大洋环流 → 逆时针
   南半球西风带海域少有陆地阻挡 → 环绕全球的西风漂流
   北印度洋：季风洋流，冬季逆时针、夏季顺时针
   → 中低纬大陆东岸多暖流、西岸多寒流；北半球中高纬大陆东岸多寒流、西岸多暖流
寒暖流判断：洋流的水温比流经的海区高 → 暖流；低 → 寒流（看相对高低，不看绝对数值）
```

### （八）海—气相互作用与厄尔尼诺、拉尼娜（选必 1 第 1.8 条）

范围：选择性必修（只在等级考范围）。课标：「运用图表，分析海—气相互作用对全球水热平衡的影响，解释厄尔尼诺、拉尼娜现象对全球气候和人类活动的影响。」沃克环流、冷水上泛是教材说法；海温距平图的读法转地理读图教练。

**直观含义**：海洋给大气"供水、供热"，大气用风推着海水走；赤道太平洋的风一变弱或变强，太平洋东西两岸的旱涝就会跟着反过来。
```text
海—气相互作用与水热平衡（教材说法）
   水：海洋蒸发 → 向大气输送水汽 → 降水（一部分落到陆地）→ 径流回到海洋 → 维持全球水的平衡
   热：海洋吸收、储存太阳辐射 → 以蒸发（释放潜热）和长波辐射把热量传给大气 → 驱动大气运动

正常年份（教材说法：沃克环流）
   赤道附近的信风把表层暖水吹向太平洋西部 → 西部水温高、空气上升、多雨；东部（南美西岸）冷水上泛、水温低、空气下沉、少雨
厄尔尼诺：赤道中东太平洋表层海水温度异常升高
   信风减弱 → 向西输送的暖水减少、东部冷水上泛减弱 → 中东太平洋水温异常升高 → 上升气流区东移
   → 南美西岸降水增多，易发洪涝；冷水上泛减弱 → 营养盐类减少 → 浮游生物、鱼类减少 → 秘鲁渔场减产
   → 太平洋西部（印度尼西亚、澳大利亚东部等）降水减少 → 干旱、森林火灾增多
拉尼娜：赤道中东太平洋表层海水温度异常降低
   信风增强 → 更多暖水堆积到西部、东部冷水上泛增强 → 西部降水更多、易洪涝，东部更干旱
→ 一处海水温度的异常，经大气环流影响远处的冷暖和旱涝 → 影响农业、渔业和防灾（每次的影响不同，以资料为准）
```

- 检验（学生自己答）："厄尔尼诺发生时，秘鲁渔场的鱼为什么减少？"（要点：信风减弱 → 东太平洋冷海水上泛减弱 → 带到表层的营养盐类减少 → 浮游生物减少 → 鱼类的饵料减少）

### （九）自然环境的整体性和差异性（选必 1 第 1.9 条）

范围：选择性必修（只在等级考范围）。课标：「运用图表并结合实例，分析自然环境的整体性和差异性。」自然带、地带性、非地带性、垂直地带性、地域分异都是教材说法；自然带分布图、垂直带谱图的读法转地理读图教练。整体性的示例链（植被破坏 → 水土流失加剧 → 土壤变得贫瘠 → 植被更难恢复）见 `references/causal-chain-guide.md` 第五节。

**直观含义**：一个地方的气候、水、土壤、植被、地形连成一个整体，动一个、其他跟着变；从赤道到两极、从沿海到内陆、从山脚到山顶，景观会依次变化。
```text
整体性：要素之间相互影响 → 一个要素变化引起其他要素连锁变化，还会影响别的区域
   黄土高原植被破坏 → 水土流失加剧 → 黄河含沙量增大 → 下游泥沙淤积、河床抬高 → 下游防洪压力加大（教材常见案例）
差异性（教材说法：地域分异规律）
   从赤道到两极：太阳辐射由低纬向高纬减少 → 热量不同 → 自然带大致沿纬线方向延伸、随纬度更替
   从沿海到内陆：距海远近不同 → 水分不同 → 自然带随距海远近更替（教材常见案例：我国温带地区自东向西森林 → 草原 → 荒漠）
   山地的垂直分异：海拔升高 → 气温降低，降水在一定高度内增加 → 水热组合改变 → 自然带随海拔更替
      → 山麓的自然带一般与当地所在的水平自然带一致；纬度越低、山体越高，垂直自然带往往越多
   地方性分异（教材说法：非地带性）：海陆分布、地形、洋流等 → 局部打破上述规律
      （教材常见案例：马达加斯加岛东部迎着东南信风、沿岸有暖流 → 热带雨林；南美西岸寒流沿岸 → 荒漠延伸到低纬的海边）
```

- 常见断环：只用纬度解释自然带的变化，忘了水分和地形；把山地的垂直变化说成"山顶离太阳近"；整体性只说一个要素变了，没有连锁。对应子类型 DI11。
- 检验（学生自己答）："一座位于温带落叶阔叶林带里的高山，山麓的自然带一般是什么？往山顶方向自然带为什么会变化？"（要点：温带落叶阔叶林带，与当地的水平自然带一致；海拔升高，气温降低、水热组合改变，自然带随之更替）

### （一）碳循环、温室效应与碳排放（选必 3 第 3.5 条）

范围：选择性必修（只在等级考范围）。课标：「结合实例，运用碳循环和温室效应原理，分析碳排放对环境的影响，说明碳减排国际合作的重要性。」"碳循环""温室效应""碳排放""碳减排国际合作"是原词；温室气体、全球变暖、碳汇是教材说法。"碳达峰碳中和"在选必 3 只出现在教学提示里（另一处在选修 4 第 4.6 条，不在考试范围）：「研讨我国积极稳妥推进碳达峰碳中和战略对人类社会可持续发展的贡献」，是研讨活动，不是内容要求。生态系统里碳怎样在生产者、消费者、分解者之间流动，细讲转生物概念网络构建器（xiaozhi-biology-concept-network）。

**直观含义**：烧煤、石油，把地下埋藏了很久的碳变成二氧化碳放进空气；空气的"保温"作用变强，全球就变暖。
```text
碳循环（教材说法的环节）
   大气中的二氧化碳 → 植物光合作用固定为有机碳 → 生物的呼吸作用、分解者的分解作用 → 回到大气
   大气 ⇄ 海洋：海水溶解、释放二氧化碳；一部分碳沉积成碳酸盐岩，长期储存在岩石圈
   地质时期的生物遗体埋藏 → 煤、石油、天然气 → 人类大量燃烧 → 短时间内把大量的碳释放回大气
   毁林 → 光合作用吸收的减少，燃烧、分解又释放碳 → 大气中的二氧化碳进一步增多
温室效应（接必修的大气受热过程，见 `references/causal-chain-guide.md` 第五节）
   太阳辐射大部分穿过大气 → 地面增温、放出地面辐射 → 二氧化碳、甲烷、水汽等温室气体强烈吸收地面辐射 → 大气逆辐射把热量还给地面 → 地表温度比没有这些气体时高，适合生命（自然的温室效应）
碳排放对环境的影响
   碳排放增加 → 大气中二氧化碳浓度升高 → 吸收的地面辐射更多、大气逆辐射增强 → 温室效应增强 → 全球变暖
   → 冰川和冰盖融化、海水受热膨胀 → 海平面上升 → 沿海低地受淹、海水入侵
   → 气候带、自然带向高纬和高海拔移动 → 生物的分布改变，一些物种的生存受到威胁
   → 高温、暴雨、干旱等极端天气增多 → 农业生产有利有弊，总体风险加大
   → 海洋吸收更多二氧化碳 → 海水酸化（教材说法，各版本详略不同）→ 珊瑚等海洋生物受影响
碳减排国际合作的重要性
   二氧化碳在大气中混合、扩散到全球 → 任何国家的排放都影响全球气候 → 一国单独减排解决不了 → 需要各国合作
   各国的发展阶段、历史排放和能力不同 → 通过国际公约、协定协调责任与行动（教材常见案例：《联合国气候变化框架公约》《巴黎协定》）
   技术和资金合作 → 帮助更多国家发展清洁能源、提高能效 → 全球减排更快
   减排的途径：节能、提高能效、发展可再生能源（减少排放）；植树造林、保护湿地和海洋生态（增加碳汇，教材说法）
```

- 常见断环：把温室效应和臭氧层破坏混为一谈；说"温室效应都是人类造成的、都有害"；海平面上升只说冰川融化，漏了海水受热膨胀；把碳循环说成植物只吸收、不释放二氧化碳。对应子类型 DP21。"国际合作的重要性"写成放在哪里都成立的空话，对应子类型 DE07（处理技能是区域认知构建器（xiaozhi-geography-region-builder））。
- 检验（学生自己答）："'温室效应都是有害的，是人类活动造成的。'这句话错在哪里？"（要点：温室效应是大气本来就有的保温作用，使地表温度适合生命存在；问题在于碳排放增加使温室效应增强，导致全球变暖）

### （二）设立自然保护地与生态安全（选必 3 第 3.6 条）

范围：选择性必修（只在等级考范围）。课标：「结合实例，说明设立自然保护地对生态安全的意义。」原词是"自然保护地"（不是"自然保护区"）；国家公园、自然保护区、自然公园等类型的划分是教材说法，课标只在教学提示里写「探究我国建设国家公园的意义」。模块目标「树立总体国家安全观」是态度类目标，不出成知识判断题。区域案例和政策转区域认知构建器（xiaozhi-geography-region-builder），本技能只帮连成因链。

**直观含义**：把最重要的山、水、林、草、湖和野生动植物划出来、保护好，它们提供的水源、土壤、气候调节和物种才不会丢，生态的家底才安全。
```text
① 结果：设立自然保护地，有利于维护生态安全
② 起点：把重要的自然生态系统、自然遗迹、自然景观和生物多样性划定范围、长期保护（教材说法）
③ 限制破坏性开发 → 栖息地保持完整 → 野生动植物的种群得以维持、恢复 → 生物多样性和遗传资源得到保存
   → 森林、草地、湿地、冰川等保存完好 → 涵养水源、保持水土、防风固沙、调节气候的功能得以维持
   → 为周边和下游提供生态屏障（教材说法）→ 减轻洪涝、沙尘等灾害的风险，保障水资源
   → 生态系统稳定、健康 → 生态安全有保障，生态安全是国家安全的组成部分
④ 一句话：划出来、保护好，生态系统的功能就保得住，周边和下游的生态安全也就有了屏障
人地两面：保护地限制了部分开发 → 当地居民的生计受到影响 → 需要生态补偿、发展生态旅游等（教材说法）→ 兼顾保护与发展
```

- 实例（教材常见案例）：在大江大河的源头设立国家公园 → 保护高寒草地、湿地和冰川 → 中下游的水量更稳定、泥沙减少 → 保障中下游的水资源与生态安全。
- 常见断环：只说"保护动物"，连不到水源涵养、生态屏障和生态安全；只说保护，不说对当地居民生计的影响和补偿。对应子类型 DI17（处理技能是区域认知构建器）。
- 检验（学生自己答）："用一条链说明：在一条大江的源头设立自然保护地，怎样维护中下游的生态安全？"（要点示例：保护源头的草地、湿地和冰川 → 涵养水源、保持水土 → 中下游水量更稳定、泥沙减少 → 水资源与生态安全有保障）
