# 地理成因链：从起点连到结果

> 适用学段：初中地理；第五节为高中。
> 本文是 `xiaozhi-geography-causal-chain` 的参考资源：成因链的四步连法、四类常见链条、初中最常考的几条成因链、链条出错时对应的子类型。所有链条的表述以教材为准，示范只讲教材里的现象。
> 课程依据：《义务教育地理课程标准（2022 年版）》核心素养"综合思维"，主题二"地球的运动"、主题三"地球的表层"、主题五"认识中国"；《普通高中地理课程标准（2017 年版 2025 年修订）》地理 1、地理 2、选择性必修 1。
> 内容边界：只解释教材里的自然与人文现象；涉及具体区域的版图与领土表述以课程标准和教材为准。

## 一、成因链的四步连法

```text
① 找结果：要解释的现象是什么？（如"这里降水多"）
② 找起点：根本原因是哪个要素？纬度位置、海陆位置、地形，还是人类活动？
③ 补中间环节：起点怎样一步一步影响到结果？每一步只走一格
④ 读成一句话：从起点读到结果，再倒过来检查方向有没有说反
```

学生说"因为 A，所以 C"时，追问一句："A 是怎么变成 C 的？中间还发生了什么？"（子类型 DI02）

---

## 二、四类常见链条

| 类型 | 方向 | 例子 |
|---|---|---|
| 自然 → 自然 | 一个自然要素影响另一个 | 地势西高东低 → 许多大河自西向东流 |
| 自然 → 人类活动 | 自然条件影响生产生活 | 热量充足、降水丰富 → 适宜种植水稻 |
| 人类活动 → 自然 | 人类活动反过来影响环境 | 过度放牧 → 植被破坏 → 土地荒漠化 |
| 多要素综合 | 几个要素共同作用 | 纬度、海陆位置、地形共同决定一地的气候 |

分析人地关系时两个方向都要想到：自然环境怎样影响人类活动，人类活动又怎样影响自然环境；有利和不利两方面都要说（子类型 DI03）。

## 三、初中最常考的成因链

**1. 昼夜交替与时间差异（地球自转）**

```text
地球是一个不发光、不透明的球体 → 同一时间太阳只能照亮地球的一半（昼半球与夜半球）
→ 地球自西向东不停地自转 → 各地轮流经历白天和黑夜 → 昼夜交替
自西向东自转 → 东边的地方先看到日出 → 东边的时刻比西边早（时间差异）
```

**2. 四季变化与五带（地球公转）**

```text
地球斜着身子绕太阳公转，地轴的空间指向保持不变
→ 太阳直射点在南、北回归线之间往返移动 → 各地获得的太阳光热随季节变化 → 四季变化
各地获得的太阳光热多少不同 → 按回归线与极圈划分出热带、南北温带、南北寒带
```

把昼夜交替说成公转产生，或把四季变化说成自转产生，归子类型 DP01。

**3. 气候的三个影响因素**

| 起点 | 中间环节 | 结果 |
|---|---|---|
| 纬度位置 | 纬度越低，获得的太阳光热越多 | 从低纬度到高纬度，气温逐渐降低 |
| 海陆位置 | 沿海地区受海洋的影响大，水汽充足 | 沿海地区降水较多，内陆地区降水较少 |
| 地形 | 湿润气流遇到山地被迫抬升，气温下降，水汽凝结 | 迎风坡降水多，背风坡降水少 |
| 地形 | 海拔每升高 100 米，气温约下降 0.6 ℃ | 同一地区，山地比平原凉爽 |

解释气候差异时只会说"纬度"，或迎风坡、背风坡说反，归子类型 DP03。

**4. 中国地势西高东低、呈阶梯状分布**

```text
地势西高东低 → 许多大河自西向东流入海洋 → 沟通东西交通
地势西高东低 → 有利于来自东部海洋的湿润气流深入内地 → 带来降水
阶梯交界处地势落差大 → 河流落差大 → 水能资源丰富
```

**5. 板块运动**

```text
由岩石组成的地球表层由六大板块拼合而成 → 板块处于不断运动之中
→ 板块交界地带地壳比较活跃 → 多火山、地震
板块相互碰撞挤压 → 形成高大的山脉（如喜马拉雅山）
板块张裂 → 形成裂谷或海洋（如东非大裂谷、红海）
```

**6. 人类活动与环境**

```text
过度放牧、过度开垦 → 植被被破坏 → 地表裸露，风力侵蚀加剧 → 土地荒漠化
```

## 四、链条出错时对应的子类型

| 学生的说法 | 问题 | 子类型 |
|---|---|---|
| "这里地势西高东低，所以交通方便" | 跳过了"大河自西向东流"这一环 | DI02 |
| "这里农业发达，因为气候好" | 只说一个要素，漏了地形、水源、市场 | DI01 |
| "这里人口稠密，所以地形平坦" | 因果方向说反 | DI04 |
| "人类在这里修水库，对环境只有好处" | 人地关系只说一面 | DI03 |
| "四季变化是地球自转造成的" | 原理本身说错 | DP01 |

原因类设问写成答案时，从起点写到结果，每一环一句；自然原因与人为原因分开写，分点作答（子类型 DE02）。

## 五、高中：成因链的升级

以下成因链对应《普通高中地理课程标准》；没有选考地理的学生只学必修（地理 1、地理 2）部分。

**大气受热过程**（地理 1 内容要求 1.6，子类型 DP05）

```text
太阳辐射大部分穿过大气到达地面 → 地面吸收后增温，向外放出地面辐射
→ 大气中的水汽、二氧化碳等强烈吸收地面辐射而增温 → 大气逆辐射把热量还给地面
→ 对地面起保温作用
```

**热力环流**（地理 1 内容要求 1.6，子类型 DP06）

```text
地面冷热不均 → 受热处空气膨胀上升，近地面形成低压、高空形成高压
冷却处空气收缩下沉，近地面形成高压、高空形成低压
→ 同一水平面上，空气由高压流向低压 → 形成热力环流
```

**水循环**（地理 1 内容要求 1.7，子类型 DP07）

```text
海陆间循环：海水蒸发 → 水汽输送到陆地上空 → 降水 → 地表径流与下渗形成的地下径流 → 汇入海洋
人类活动目前影响最大的是地表径流环节（如修建水库、跨流域调水）
```

**区位因素**（地理 2 内容要求 2.5，子类型 DI05）：说明工业、农业或服务业的区位因素时，自然条件（地形、气候、水源、土壤等）与社会经济条件（市场、交通、劳动力、政策等）都要考虑。

**自然环境的整体性**（选择性必修 1 内容要求 1.9）：一个要素变化会引起其他要素的连锁变化，例如植被被破坏 → 水土流失加剧 → 土壤变得贫瘠 → 植被更难恢复。
