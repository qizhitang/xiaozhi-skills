## 一、怎么用

**四步不变，深度跟着课标动词走。** 找结果 → 找起点 → 补中间环节（每步只走一格）→ 读成一句话，再倒过来查方向。课标没有给"描述、说明、解释、列举、归纳"分级或释义，本技能照原词讲到位：描述，说出特点；说明、解释，一环一环讲清原因或过程；列举，举出几项并各说一句为什么对得上；归纳，先分类再举实例。

**同一条链，合格考和等级考差在情境。** 学业质量水平 1 是「在结构良好的地理情境中」「解释地理要素相互影响的方式和结果」，水平 2、3 是「在结构不良的地理情境中」。没有选考地理的学生，材料直接给出起点，把链讲全；选考地理的学生，同一条链放进没有直接给起点的材料里，自己从材料里找起点，并说清随时间、地点的变化。

**怎么练。** 每块末尾的"检验"由学生自己答，AI 不代答；提示按 `shared/hint-ladder.md` 逐级给（本技能默认最高 L5：换一个区域或现象示范），即兴出的题按 `shared/ai-item-check.md` 自检。连错时记"常见断环"行里的子类型；学生同意后再交接，做法见 SKILL 的"接口与协作"一节。

**实践与安全。** 地理 1 第 1.4、1.9、1.10 条的野外观察都可以用视频、图像或土壤标本代替。离校的野外考察、社会调查由学校组织、成人带领、结伴进行，按学校外出活动安全制度执行；访谈在公共场所进行、不入户；问卷不收集姓名、电话、住址，也不需要学生提供自己家的住址或实时位置；不独自去水边、山地、工地。课堂演示按 `shared/lab-safety.md` 定档，本技能不给在家做的、有风险的操作步骤。课标点名的实践活动见 `shared/geography-hs-practice-activities.md`。

## 二、地理 1（第 1.1—1.11 条）

### （一）太阳对地球的影响（地理 1 第 1.1 条）

范围：必修（合格考、等级考都考）。课标：「运用资料，描述地球所处的宇宙环境，说明太阳对地球的影响。」宇宙环境以"描述"为主，天体系统层次图的读法转地理读图教练；太阳的影响要连成链。
```text
① 结果：太阳辐射（教材说法）是地表的水、大气运动和生物活动的主要能量来源
② 起点：太阳内部的核聚变反应（教材说法）
③ 核聚变释放巨大能量 → 以电磁波的形式向四周放射 → 一部分到达地球
   → 为地表提供光和热、维持地表温度 → 推动水循环、大气运动和植物的光合作用
   → 地质时期生物固定的太阳能随遗体埋藏 → 形成煤、石油等 → 今天人类使用的化石能源
④ 一句话：太阳辐射给地表送来光和热，水、大气、生物都靠它运动，煤和石油也是储存下来的太阳能
到达地面的多少：纬度低 → 太阳高度大（教材说法）→ 单位面积得到的太阳辐射多
   海拔高、空气稀薄、晴天多 → 大气削弱少 → 太阳辐射强（教材常见案例：青藏高原）
   阴雨云雾多 → 大气削弱多 → 太阳辐射弱（教材常见案例：四川盆地）
太阳活动（教材说法：黑子、耀斑等）增强时
   耀斑爆发 → 发射的电磁波扰动地球高空的电离层 → 无线电短波通信受干扰，甚至短暂中断
   抛出的高能带电粒子流 → 扰动地球磁场 → 产生"磁暴"，磁针不能正确指示方向
   高能带电粒子流冲进两极高空大气 → 与大气相互作用 → 产生极光
```

- 教材描述宇宙环境时，常把"地球为什么有生命"也连成链（教材说法）：日地距离适中 → 地表温度适宜 → 水能以液态存在；地球的体积、质量适中 → 引力能吸住大气 → 形成适合生物呼吸的大气；太阳稳定、各行星各行其道 → 光照稳定、宇宙环境安全。
- 常见断环：把太阳活动的影响说成太阳辐射的（"极光是阳光太强"）；把短波通信中断说成磁暴造成的；太阳辐射的多少只讲纬度，漏了天气和海拔。对应子类型 DP09（"地球为什么有生命"一链说错也记 DP09）。
- 检验（学生自己答）："'极光和无线电短波通信中断，都是太阳辐射太强造成的。'错在哪里？"（要点：两者都是太阳活动的影响；短波通信中断来自耀斑的电磁波扰动电离层，极光来自高能带电粒子流冲进两极高空大气）

### （二）地球的圈层结构（地理 1 第 1.2 条）

范围：必修（合格考、等级考都考）。课标：「运用示意图，说明地球的圈层结构。」"说明"要讲清"凭什么这样分"，不只背三层的名字。
```text
① 结果：地球内部分为地壳、地幔、地核（教材说法）
② 起点：地震波（教材说法）的传播速度随所经物质的性质而变化；纵波能通过固体、液体和气体，横波只能通过固体
③ 向下到某一深度，纵波、横波的速度都明显增加 → 上下物质的性质明显不同 → 莫霍界面，以上是地壳
   → 再往下到某一深度，纵波速度突然下降、横波完全消失 → 古登堡界面，以下是地核
   → 横波穿不过外核 → 推断外核呈液态或熔融状态（教材说法）
④ 一句话：地震波的速度在两个深度上突然变化，据此划出两个界面，把地球内部分成地壳、地幔、地核
```

- 岩石圈（"岩石圈"在课标里只见于选必 1 第 1.2 条）：地壳和上地幔顶部（软流层以上）由坚硬的岩石组成，合称岩石圈；软流层一般被认为是岩浆的发源地（教材说法），这是选必 1 岩石圈物质循环一链的起点。外部圈层：大气圈、水圈、生物圈相互联系、相互渗透，生物圈占有大气圈的底部、水圈的全部和岩石圈的上部（教材说法）。
- 常见断环：把岩石圈等同于地壳；把横波消失的界面说成莫霍界面；说不出划分圈层的依据。对应子类型 DP10。
- 检验（学生自己答）："地震波向下传到某一界面时，横波完全消失、纵波速度突然下降。这个界面叫什么？界面以下是哪一层？据此能推断什么？"（要点：古登堡界面；地核；外核可能呈液态或熔融状态）

### （三）地球的演化与地貌景观（地理 1 第 1.3、1.4 条）

范围：必修（合格考、等级考都考）。课标：「运用地质年代表等资料，简要描述地球的演化过程。」「通过野外观察或运用视频、图像，识别 3—4 类地貌，描述其景观的主要特点。」两条的动词是"简要描述""识别""描述"，不要求讲成因。读地质年代表、地层与化石的错误记 DM07，识别地貌的错误记 DM08，都转地理读图教练；识别哪 3—4 类地貌以所用教材为准。学生追问"为什么"时，只连两条短链：岩层没有经过强烈变动时，地层（教材说法）一般下老上新 → 同一时代的地层含有相同或相似的化石 → 由化石推断地层的年代和当时的环境；早期的蓝细菌等（教材说法）进行光合作用 → 释放氧气 → 大气含氧量逐渐增加 → 为后来更多生物的出现创造条件。
地貌景观的成因（内力和外力）是选必 1 第 1.3 条，见 `references/causal-chains-hs-elective.md` 第二节（三）；没有选考地理的学生描述到景观特点即可。

### （四）大气的组成和垂直分层（地理 1 第 1.5 条）

范围：必修（合格考、等级考都考）。课标：「运用图表等资料，说明大气的组成和垂直分层，及其与生产和生活的联系。」读垂直分层图的错误记 DM09，转地理读图教练；这里只连"组成、分层 → 与生产生活的联系"。
```text
组成 → 作用（教材说法）：氧 → 维持生物呼吸；氮 → 生物体的基本成分；臭氧 → 吸收太阳紫外线 → 保护地面生物
   二氧化碳 → 光合作用的原料，又吸收地面辐射 → 对地面保温（接第（五）块）；水汽和杂质 → 成云致雨的必要条件
对流层（教材说法；低纬度地面受热多、对流旺盛 → 对流层较厚，高纬度较薄）
   地面是对流层大气主要的直接热源 → 离地面越远气温越低 → 上冷下热 → 对流运动显著
   → 又集中了几乎全部的水汽和杂质 → 云、雨、雪等天气现象复杂多变 → 与人类关系最密切
平流层（教材说法）
   臭氧吸收太阳紫外线而增温 → 气温总体随高度增加而上升 → 上热下冷 → 大气稳定，以水平运动为主
   → 水汽、杂质少，天气晴朗 → 有利于高空飞行
高层大气：电离层能反射无线电短波 → 对无线电通信有重要作用（接第（一）块的耀斑）
```

- 人类活动反过来改变大气组成：燃烧煤、石油等 → 二氧化碳增多（对环境的影响是选必 3 第 3.5 条）；使用氟氯烃等物质 → 平流层臭氧减少 → 到达地面的紫外线增多 → 危害人体健康和生物（教材说法）。
- 常见断环：说"对流层越往上越冷，是因为离太阳越远"（热量主要直接来自地面，离地面越远越冷；这点高度差对日地距离来说可以忽略）；把臭氧减少和气候变暖混为一谈。读图错记 DM09；分层成因说错的（如上面"离太阳越远"的说法）记 DP05——对流层大气的热量主要直接来自地面，属于大气受热过程的问题。
- 检验（学生自己答）："平流层为什么有利于飞机高空飞行？连成一条链。"（要点：臭氧吸收紫外线，气温随高度增加而上升 → 上热下冷，大气稳定、以水平运动为主 → 水汽、杂质少，天气晴朗）

### （五）大气受热过程与热力环流：解释相关现象（地理 1 第 1.6 条）

范围：必修（合格考、等级考都考）。课标：「运用示意图等，说明大气受热过程与热力环流原理，并解释相关现象。」原理链见 `references/causal-chain-guide.md` 第五节（DP05、DP06），这里补两个作用，再把原理迁移到现象。"温室效应"在课标里只在选必 3 第 3.5 条。
两个作用（教材说法）：大气对太阳辐射有削弱作用（吸收、反射、散射），白天起作用；大气以大气逆辐射把热量还给地面，对地面有保温作用，夜里尤其明显。下面四个现象，都是问"哪个作用变强或变弱了""哪里受热、哪里冷却"。

**1. 昼夜温差：晴天大，阴天小**
```text
① 结果：同一地方，晴天的昼夜温差比阴天大
② 起点：云量（天气状况）
③ 白天：云少 → 削弱作用弱 → 到达地面的太阳辐射多 → 最高气温高
   夜晚：云少 → 大气逆辐射弱 → 保温作用弱 → 地面散热多 → 最低气温低
④ 一句话：晴天白天削弱少、夜里保温差，最高气温更高、最低气温更低，所以昼夜温差大
示例数据（示意）：同一地方晴天最高 26 ℃、最低 12 ℃，昼夜温差 14 ℃；阴天最高 20 ℃、最低 15 ℃，昼夜温差 5 ℃
```

迁移（教材常见案例）：青藏高原空气稀薄、晴天多 → 昼夜温差大；深秋晴朗的夜晚，大气逆辐射弱 → 地面降温快 → 容易出现霜冻。

**2. 海陆风**
```text
① 结果：沿海地区近地面白天吹海风、夜晚吹陆风
② 起点：海陆热力性质差异——陆地增温快、降温也快，海洋增温慢、降温也慢（教材说法）
③ 白天：陆地增温快 → 陆地气温高于海洋 → 陆地上空气受热膨胀上升 → 近地面陆地形成低压、海洋上形成高压 → 风由海洋吹向陆地（海风）
   夜晚：陆地降温快 → 陆地气温低于海洋 → 陆地上空气冷却收缩下沉 → 近地面陆地形成高压、海洋上形成低压 → 风由陆地吹向海洋（陆风）
④ 一句话：白天陆地热、近地面气压低，风从海洋吹向陆地；夜晚反过来
```

**3. 山谷风**
```text
白天：山坡增温快 → 山坡上的空气比同一高度上谷地上空的空气热 → 沿山坡上升 → 谷底的空气沿山坡上来补充 → 谷风（由谷地吹向山坡）
夜晚：山坡降温快 → 山坡上的空气比同一高度上谷地上空的空气冷 → 沿山坡下沉 → 流入谷底 → 山风（由山坡吹向谷地）
迁移：夜里冷空气沉到谷底聚集 → 谷底大气较稳定 → 污染物不易扩散 → 谷底不宜布局有大气污染的工厂（教材常见案例）
```

**4. 城市热岛与城市风**
```text
① 结果：市区气温比郊区高；近地面风从郊区吹向市区
② 起点：城市人口和产业集中，地面多被建筑和硬化路面覆盖
③ 生产、生活、交通排放大量废热；硬化地面多、绿地和水面少 → 蒸发吸热少 → 市区气温高于郊区（城市热岛，教材说法）
   → 市区空气受热上升，近地面形成低压；郊区空气相对下沉，近地面形成高压
   → 近地面风由郊区吹向市区，高空由市区流向郊区（城市风，教材说法）
④ 一句话：市区热、空气上升，近地面的风就从郊区吹向市区
```

- 迁移（教材常见案例）：近地面风从郊区吹向市区 → 有大气污染的工厂布局在城郊热力环流的范围以外；城郊之间建绿化带，可以净化流入市区的空气。
- 课堂上用热水（可能超过 60 ℃）或点燃的线香（明火）演示热力环流，按 `shared/lab-safety.md` 属中档，由老师操作或老师全程在场；只用冰块和常温水属低档；本技能不给在家做的步骤。
- 常见断环：会背热力环流，换成海陆、山谷、城郊就不会用，对应子类型 DI06；阴天温差小只说白天、漏了夜晚的保温，对应子类型 DI06；把受热地区的近地面说成高压、风向说反，对应子类型 DP06；分不清削弱作用和保温作用，对应子类型 DP05。
- 检验（学生自己答）："沿海某地夜晚，近地面的风从哪里吹向哪里？用一条链说明。"（要点：从陆地吹向海洋（陆风）；夜晚陆地降温快 → 陆地气温低于海洋 → 陆地上空气下沉、近地面形成高压 → 风由陆地吹向海洋）

### （六）水循环的过程及其地理意义（地理 1 第 1.7 条）

范围：必修（合格考、等级考都考）。课标：「运用示意图，说明水循环的过程及其地理意义。」海陆间循环的环节与"人类活动目前影响最大的是地表径流"见 `references/causal-chain-guide.md` 第五节（DP07）；这里补另两类循环和地理意义。
```text
海上内循环：海水蒸发 → 水汽在海洋上空凝结 → 降水落回海洋
陆地内循环：陆地上的水蒸发、植物蒸腾 → 水汽在陆地上空凝结 → 降水落回陆地
海陆间循环：只有这一类把海洋的水不断送上陆地 → 陆地上的淡水不断得到补充、更新 → 淡水资源可以再生
地理意义（教材说法，每句连一环）
   水在大气、海洋、陆地和生物之间运动 → 联系各圈层，在它们之间进行物质迁移和能量交换
   水和水汽在海陆之间、高低纬之间转移，蒸发吸热、凝结放热 → 调节不同地区的热量和水分
   海陆间循环不断补给陆地 → 维持全球水的动态平衡
   地表径流冲刷、搬运泥沙，在下游堆积 → 塑造地表形态
人类活动（主要作用在地表径流和下渗两环，教材常见案例）
   修建水库 → 汛期蓄水、枯水期放水 → 径流的季节变化减小
   跨流域调水 → 改变地表径流的空间分布
   城市地面硬化 → 下渗减少 → 地表径流增加、汇流加快 → 暴雨时容易积水内涝
   植树种草、建绿地和透水路面 → 截留降水、增加下渗 → 地表径流减少、地下水得到补充
```

- 课标例 2 的模拟实验「不同地面状况对径流及下渗的影响」正好检验最后两环（课标没写它对应哪一条）：草地、沙地、砾石地面、硬化地面在同样的降水下比较径流和下渗。课堂上做由老师组织，用塑料器材时按 `shared/lab-safety.md` 属低档，用玻璃量筒、烧杯等玻璃器皿时属中档。
- 常见断环：下渗和地表径流的增减说反；说陆地内循环能把海洋的水送上陆地；地理意义只会说"水在循环"，说不出能量交换和塑造地表。对应子类型 DP07。
- 检验（学生自己答）："城市里大面积硬化地面以后，水循环中哪个环节减少、哪个环节增加？暴雨时会带来什么问题？"（要点：下渗减少，地表径流增加、汇流加快；容易积水内涝）

### （七）海水性质和运动对人类活动的影响（地理 1 第 1.8 条）

范围：必修（合格考、等级考都考）。课标：「运用图表等资料，说明海水性质和运动对人类活动的影响。」课标没有点名温度、盐度、密度、海浪、潮汐、洋流，按教材讲（教材说法）。洋流在课标里只出现在选必 1 第 1.7 条，分布规律与影响见 `references/causal-chains-hs-elective.md` 第二节（七）；所用教材在必修里讲到洋流的，按教材和本地考试说明讲到"对人类活动的影响"为止；洋流的分布规律属选必 1 第 1.7 条，只在等级考范围。
```text
温度：表层海水主要靠太阳辐射加热 → 由低纬度向高纬度递减；随深度增加而降低
   → 影响海洋生物的分布和沿海的气温；高纬海域冬季海面结冰 → 影响航运
盐度：蒸发量大于降水量 → 盐度高；大量河水注入 → 盐度低
   → 副热带海区降水少、蒸发旺盛 → 表层盐度最高，由此向赤道和两极降低（教材说法）
   → 盐度较高、晴天多、蒸发旺盛、海滩平坦的地方 → 适合晒盐（教材常见案例）
密度：水温越低、盐度越高 → 密度越大；表层海水密度大致由赤道向两极增大（教材说法）
   → 潜艇进入密度突然变小的海水 → 受到的浮力突然变小 → 急剧下沉（教材常见案例："掉深"）
海浪：风吹海面 → 风浪等海浪 → 侵蚀海岸、塑造海岸；可以用来发电、开展冲浪等活动
   风暴潮、海啸（教材说法；"风暴潮"课标只在选修 3 用）：台风、温带气旋、寒潮等带来的强风和气压骤变 → 近岸海面异常升降（风暴潮）；海底地震、火山爆发或水下滑坡、坍塌 → 海啸，到近岸形成巨浪
   → 能量巨大，给沿岸地区带来严重灾害 → 需要预报预警（接第（十）块）
潮汐：月球和太阳的引力（教材说法：引潮力）→ 海水周期性涨落
   → 滩涂养殖、赶海；潮汐发电；大船乘涨潮进出港（教材常见案例）
```

- 去海边看潮：由成人带领、结伴，在岸上的安全处观看，不下水，不下到滩涂、礁石；按当地部门公布的潮汐时间和安全提示安排；遇到海浪、风暴潮预警，听从当地的安排（口径同 `shared/geography-hs-practice-activities.md` 第五节 1）。
- 常见断环：盐度高只说"温度高"，漏了"蒸发量大于降水量"这一环；说海水密度变小时潜艇会"上浮"（方向说反）；把潮汐说成风引起的。对应子类型 DP11。
- 检验（学生自己答）："潜艇在水下航行时，突然进入海水密度明显变小的海域，会上浮还是下沉？为什么？"（要点：下沉；海水密度变小 → 潜艇受到的浮力变小）

### （八）土壤的主要形成因素（地理 1 第 1.9 条）

范围：必修（合格考、等级考都考）。课标：「通过野外观察或运用土壤标本，说明土壤的主要形成因素。」教材一般讲成土母质、生物、气候、地形、时间五个因素，再加人类活动。看土壤标本或剖面照片时，先说颜色、质地、分层，再追问每一处是哪个因素造成的。
```text
成土母质（教材说法）→ 提供矿物质 → 决定土壤最初的矿物成分、养分和质地
生物 → 植物残体经微生物分解 → 土壤有机质 → 生物是有机质的来源，也是土壤形成中最活跃的因素（教材说法）
气候 → 温度、降水影响岩石风化（教材说法）的快慢、有机质的积累与分解、矿物质的淋溶
地形 → 坡陡处物质易被冲走 → 土层薄；坡麓、谷地物质堆积 → 土层厚；海拔改变水热 → 土壤随高度变化
时间 → 成土时间越长 → 土层越厚、分层越明显
人类活动 → 施有机肥、合理耕作 → 培育肥沃的土壤；不合理利用 → 水土流失、土壤盐碱化等
两个对照（教材常见案例）
东北的黑土：冬季寒冷漫长 → 微生物分解慢；夏季草类茂盛 → 有机质来源多 → 有机质积累多 → 土壤黑而肥沃
南方的红壤：高温多雨 → 风化和淋溶强、有机质分解快 → 有机质少、养分易流失，铁铝氧化物相对积累 → 土壤偏红、偏酸、较贫瘠
```

- 常见断环：只说"气候"一个因素；说不出生物是有机质的来源；把"有机质分解快"说成"有机质多"。对应子类型 DI07。
- 检验（学生自己答）："东北的黑土和南方的红壤，哪一种有机质含量高？从气候和生物两个因素各说一环。"（要点：黑土；气候冷 → 微生物分解有机质慢；草类茂盛 → 有机质来源多）

### （九）植被与自然环境的关系（地理 1 第 1.10 条）

范围：必修（合格考、等级考都考）。课标：「通过野外观察或运用视频、图像，识别主要植被，说明其与自然环境的关系。」"识别"看景观图片，转地理读图教练；这里连"环境 → 植被"和"植被 → 环境"两个方向，植被类型的名称按教材。
```text
环境 → 植被（教材说法）
   全年高温多雨 → 热带雨林：植物种类多、乔木高大、层次多，有板状根、藤本和附生植物
   夏季高温多雨、冬季温和 → 常绿阔叶林：四季常绿，叶片多革质、有光泽
   冬季寒冷、夏季温暖 → 落叶阔叶林：冬季落叶，减少水分散失
   寒冷 → 针叶林：叶片呈针状，减少蒸腾
   降水较少 → 草原：以草本植物为主
   降水稀少 → 荒漠：植被稀疏；根系发达，叶片退化，或有肉质茎贮水
植被 → 环境
   森林、草地 → 涵养水源、保持水土、防风固沙、调节局地气候
   植被破坏 → 地表裸露 → 水土流失或风沙加剧（荒漠化一链见 `references/causal-chain-guide.md` 第三节第 6 条）
```

- 常见断环：只说降水、不说热量（或反过来）；只说环境影响植被，不说植被反过来影响环境。对应子类型 DI07。
- 检验（学生自己答）："荒漠里的植物为什么根系特别发达？"（要点：降水稀少、地表缺水 → 根扎得深、伸得广，才能吸收深层和更大范围的水分）

### （十）自然灾害的成因与防灾减灾（地理 1 第 1.11 条）

范围：必修（合格考、等级考都考）。课标：「运用资料，说明常见自然灾害的成因，列举防灾减灾的措施。」课标不点名灾种，讲哪几种以所用教材为准；下面给方法，表里的灾种和例子都是教材常见案例。

**成因的连法**：触发的自然变异（强降水、强冷空气、地球内部能量突然释放等）＋所在的自然环境（地形、地质、植被、河道）＋人类活动与暴露在危险中的人口和财产 → 成灾。只说触发、不说环境和人，链就断了。**列举措施**时，每一项都要说得出它作用在成因链的哪一环。

| 灾害（教材常见案例） | 成因链 | 对得上的措施 |
|---|---|---|
| 洪涝 | 短时强降水或连续降水 → 河湖水位暴涨；地势低平、排水不畅 → 积水；围湖造田、上游植被破坏 → 调蓄能力减弱、河床淤积 → 灾情加重 | 修建水库和堤防、疏浚河道、退田还湖、植树造林、预报预警 |
| 干旱 | 降水长期偏少 → 土壤缺水、河湖水量减少 → 作物缺水减产；用水多、水利设施不足 → 加重 | 修建水利工程、节水灌溉、跨流域调水 |
| 台风 | 热带洋面上形成的强烈热带气旋 → 狂风、暴雨、风暴潮 → 建筑损毁、洪涝、海水倒灌 | 监测预报、加固设施、人员及时转移 |
| 寒潮 | 冬半年强冷空气迅速南下 → 剧烈降温、大风、雨雪冰冻 → 农作物冻害、交通受阻 | 预报预警、覆盖保温、提前防冻 |
| 地震 | 地球内部能量突然释放 → 岩层断裂错动 → 地面震动 → 建筑物倒塌是伤亡的主要原因；还可能引发滑坡、火灾、海啸等次生灾害 | 建筑抗震设防、选址避开活动断裂带、监测、防震演练 |
| 滑坡、泥石流 | 山高坡陡、岩土松散，遇暴雨或地震触发 → 斜坡岩土整体下滑（滑坡）、含大量泥沙石块的洪流（泥石流）；开挖坡脚、植被破坏 → 加剧 | 监测预警、修挡土墙和拦挡坝、植树造林、不在沟口和陡坡下建房 |

**个人避险常识**（教材与应急管理部门公开的常识；遇到真实灾情，听从当地政府和应急管理部门的预警与指挥）：
- 地震：在室内就近躲到坚固的桌下或内墙角，"伏地、遮挡、手抓牢"，不乘电梯、不跳楼；震后有序撤到空旷地带，远离建筑物、广告牌和电线杆。
- 洪水：迅速向高处转移；不涉水过河、不靠近河道；远离电线杆和变压器。
- 泥石流：向与泥石流流动方向垂直的两侧山坡高处跑，不要顺着沟谷跑。
- 台风：待在坚固的建筑物里，关好门窗；不在临时搭建物、广告牌和大树下停留。

- 常见断环：措施和成因对不上（如把"植树造林"列为防地震的措施，把"修堤防"列为防寒潮的措施）；成因只说"下大雨"，漏了地形和人类活动。对应子类型 DP12。地理信息技术在防灾减灾中的应用（地理 1 第 1.12 条）转地理读图教练。
- 检验（学生自己答）："'在山区植树造林'对减轻哪一种灾害更直接——泥石流还是地震？为什么？"（要点：泥石流；植被固土、拦截降水，减少松散物质和地表径流；地震由地球内部能量释放引起，植树减少不了地震的发生）

## 三、地理 2（第 2.1、2.2、2.4、2.5、2.6、2.10 条）

地理 2 的教学提示写「注重运用社会调查等方法」；做人口、城镇化、交通方面的调查时，安全与隐私按第一节的口径。

### （一）人口分布、迁移与区域资源环境承载力（地理 2 第 2.1 条）

范围：必修（合格考、等级考都考）。课标：「运用资料，描述人口分布、迁移的特点，说明其影响因素，并结合实例，解释区域资源环境承载力、人口合理容量。」课标写"人口分布、迁移"，不连写"人口迁移"（教材的节名常用，教材说法）。
```text
分布：中低纬度、气候温和湿润 + 地形平坦 + 水源充足 → 便于农业生产和交通 → 经济较发达 → 人口稠密
   高寒、干旱、地势高峻的地区 → 农业和交通条件差 → 人口稀疏（教材常见案例：我国东部与西部的对比）
迁移：迁出地就业机会少、收入低（推力）+ 迁入地就业机会多、收入与公共服务较好（拉力）→ 人口迁移
   经济因素往往起主导作用，政策、社会文化、生态环境、家庭与个人等也有影响（教材说法）
承载力：一个区域的资源（水、土地、能源等）和环境（容纳污染物的能力）有限 → 能支撑的人口和经济活动规模有限
   资源越丰富、科技水平越高、对外开放程度越高 → 承载力越大
   人均消费水平越高 → 每人消耗的资源越多 → 能供养的人口越少
合理容量：按合理的生活方式、保证健康的生活水平、不妨碍后代的生活质量 → 一个区域最适宜的人口数量（教材说法，定义以所用教材为准）
   → 比资源环境能持续供养的最大人口数量小（教材说法）
超载：人口超过承载力 → 过度开垦、放牧 → 资源短缺、环境恶化 → 承载力进一步下降（教材常见案例：草场退化）
```

- 常见断环：把消费水平、科技水平对承载力的影响方向说反；迁移原因只说"想去大城市"，说不出推力和拉力；把承载力当成固定不变的数。对应子类型 DI08。
- 检验（学生自己答）："其他条件不变，一个区域的人均消费水平提高了，它能持续供养的人口会增多还是减少？"（要点：减少；每人消耗的资源更多）

### （二）城镇和乡村内部的空间结构（地理 2 第 2.2 条）

范围：必修（合格考、等级考都考）。课标：「结合实例，解释城镇和乡村内部的空间结构，说明合理利用城乡空间、城乡融合发展的意义。」功能区、中心商务区、地租是教材说法；城乡景观与地域文化（地理 2 第 2.3 条）转区域认知构建器（xiaozhi-geography-region-builder）。
```text
城镇：离市中心越近、交通越便利 → 通达度越高 → 顾客多、地价高（教材常用"地租"讲）
   → 商业单位面积收益高、付得起高地价 → 占据市中心和交通干线交会处 → 商业区（教材说法：中心商务区）
   → 住宅区占据外围较大的范围
   → 工业占地大、对地价敏感，有的还有污染 → 布局在城市外围、交通干线沿线
   收入、文化等社会因素 → 住宅区分化；早期的布局和城市规划 → 影响今天的格局
乡村：地形、水源、耕地和交通 → 决定聚落、耕地和公共服务用地怎样布局（平原多集中成片，山区多沿河谷分散，教材常见案例）
意义：合理利用城乡空间 → 布局合理 → 减少交通拥堵和污染、节约土地 → 提高运行效率和生活质量
   城乡融合发展 → 人口、资金、技术等在城乡之间双向流动，公共服务向乡村延伸 → 缩小城乡差距
```

- 常见断环：只会背"商业区在市中心"，说不出"通达度 → 地价 → 付得起地价"这几环。对应子类型 DR06（处理技能是区域认知构建器，本技能只帮连成因链）。
- 检验（学生自己答）："城市中心交通最便利的地段，为什么多被商业用地而不是工业用地占据？"（要点：通达度高 → 顾客多、地价高 → 商业单位面积收益高，付得起；工业占地大、对地价敏感，多在外围）

### （三）城镇化的过程、特点与利弊（地理 2 第 2.4 条）

范围：必修（合格考、等级考都考）。课标：「运用资料，说明不同地区城镇化的过程和特点，以及城镇化的利弊。」课标统一用"城镇化"；城市化、郊区城市化、逆城市化、城市病是教材说法。城镇化水平的计算错误记 DQ07，转地理读图教练。
```text
动力：农业生产率提高 → 乡村富余劳动力增多（推力）；二、三产业在城镇集聚 → 就业机会多、收入与公共服务较好（拉力）
   → 乡村人口迁入城镇 → 城镇人口比重上升、城镇用地扩大 → 城镇化
过程（教材说法：S 形曲线）：初期水平低、发展慢 → 中期工业化加快，人口迅速向城镇集聚，发展最快 → 后期水平高、发展趋缓
   → 一些发达国家出现人口从中心城区迁往郊区、乡村的现象（教材说法：郊区城市化、逆城市化，名称以所用教材为准）
特点：发达国家起步早、水平高、现在发展慢；发展中国家起步晚、水平较低、发展快
   有的地区城镇人口增长快于工业化和就业岗位的增长 → 城市问题突出（教材说法）
利：人口和产业集聚 → 规模效益、提高效率 → 推动经济发展；公共服务集中 → 生活水平提高
弊：人口、产业增长快于住房、交通、环保设施的建设 → 交通拥堵、住房紧张、环境污染（教材说法：城市病）
   城镇用地扩张 → 占用耕地；地面硬化 → 内涝、热岛加重（接第二节（五）（六）块）
```

- 检验（学生自己答）："甲、乙、丙三地总人口都是 1000 万，城镇人口分别是 250 万、650 万、800 万。按教材的城镇化过程曲线（分界常取 30% 与 70%，以所用教材为准），哪个地区城镇化推进最可能最快？"（要点：乙地；城镇化水平 65%，处在中期阶段）

### （四）工业、农业和服务业的区位因素及其变化（地理 2 第 2.5 条）

范围：必修（合格考、等级考都考）。课标：「结合实例，说明工业、农业和服务业的区位因素。」学业要求是「能够用实例解释不同地方的人们如何对产业活动进行区位选择」。"自然条件与社会经济条件都要考虑"见 `references/causal-chain-guide.md` 第五节（DI05）；这里分产业讲，再加"区位因素会变"。因素的分类以所用教材为准。

| 产业 | 主要区位因素（教材说法） | 一条链（教材常见案例） |
|---|---|---|
| 农业 | 气候、地形、土壤、水源；市场、交通运输、劳动力、技术、政策 | 城市郊区 → 离市场近、运输时间短 → 适合生产蔬菜、鲜奶、花卉等不耐储运的产品 |
| 工业 | 原料、动力（能源）、劳动力、市场、交通运输、技术、政策、环境 | 原料运输中损耗大或不易保存（如制糖）→ 靠近原料产地；耗电量大（如炼铝）→ 靠近电力充足、电价较低的地方；技术要求高（如集成电路）→ 靠近高校和科研机构集中的地方 |
| 服务业 | 市场（人口、消费水平）、交通（通达度）、集聚、地价、劳动力 | 商业网点 → 顾客要多、要方便到达 → 布局在人口密集、交通便利的地方；物流中心 → 靠近交通枢纽和市场 |

```text
区位因素的变化（教材常见案例）
交通运输和冷藏保鲜技术进步 → 运输更快、损耗更少 → 农产品可以远销 → 农业可以离消费市场更远（如鲜花空运外销）
技术进步、原料和能源利用率提高 → 对原料地、能源地的依赖减弱
   → 钢铁工业：早期多靠近煤炭产地 → 后来更多靠近铁矿、市场，或建在海运便利的沿海（可以利用进口原料）
市场、技术、劳动力素质和环境要求的作用增强 → 污染重的企业布局受到更多限制
网络购物和快递物流发展 → 一部分商业不必靠近顾客 → 商业网点的区位发生变化
```

- 常见断环：用过去的条件解释今天的布局，说不出区位因素的变化，对应子类型 DI09；分析一个产业只说自然条件或只说一个因素，对应子类型 DI05。
- 检验（学生自己答）："过去许多钢铁厂建在煤矿附近，后来不少新建的钢铁厂建在沿海港口附近。说出两个区位因素的变化。"（要点：技术进步、炼钢耗煤减少 → 对煤炭产地的依赖减弱；海运便利 → 可以利用进口的铁矿石和煤炭，并接近市场）

### （五）运输方式和交通布局与区域发展（地理 2 第 2.6 条）

范围：必修（合格考、等级考都考）。课标：「结合实例，说明运输方式和交通布局与区域发展的关系。」"交通运输"在课标里只见于选修 6，教材的章节名常用（教材说法）。这一条的关系是双向的：
```text
区域发展 → 交通布局：经济发展 → 客货运量增大、对速度和质量的要求提高 → 修建高速铁路、高速公路、机场，运输方式升级
   地形、气候、地质等自然条件 → 影响线路走向和工程难度（教材常见案例：在高原冻土上修铁路）
交通布局 → 区域发展：新线路、新枢纽 → 区域通达度提高 → 运输成本下降、市场和原料来源扩大 → 吸引产业和人口 → 沿线城镇和产业发展
   原有交通线的地位下降 → 依赖它的城镇可能衰落（教材常见案例：运河沿线城镇在铁路兴起后的变化）
   修路也会影响环境 → 需要留出野生动物通道、保护植被（教材常见案例）
运输方式的选择：货物的性质、运量、运距、时间和运费 → 鲜活易腐或贵重的多选航空或冷链运输，大宗笨重的多选水运或铁路，液体、气体多选管道（教材说法）
```

- 常见断环：只说交通促进发展，不说区域发展反过来推动交通；以为"修了路就一定繁荣"，漏了产业、市场等条件；运输方式和货物性质对不上。对应子类型 DI10。
- 检验（学生自己答）："某山区县通了高速公路。分别说出一条'交通 → 区域发展'的链和一条'区域发展 → 交通'的链。"（要点示例：通达度提高 → 农产品运得出去、游客进得来 → 产业发展；产业发展、客货运量增大 → 需要扩建道路、增开班次）

### （六）环境问题与可持续发展的途径（地理 2 第 2.10 条）

范围：必修（合格考、等级考都考）。课标：「运用资料，归纳人类面临的主要环境问题，说明协调人地关系和可持续发展的主要途径。」"归纳"是先分类、再举例；"说明"途径要连到具体问题上。课标例 1 用浙江青田县稻田养鱼做情境，问题链里有一问「稻田养鱼对水稻生产有什么好处？」。
```text
归纳：环境问题大致分三类（教材说法）——环境污染（大气、水、土壤……）、生态破坏（植被破坏、水土流失、荒漠化、生物多样性减少……）、资源短缺（淡水、耕地、能源……）
根源：人口增长、经济活动规模扩大 → 索取资源的速度超过资源再生的速度 → 资源短缺、生态破坏
   → 排放的废弃物超过环境的自净能力 → 环境污染
途径（每一条都说清作用在哪一环）
   发展循环经济、清洁生产（教材说法）→ 一个环节的废弃物成为另一个环节的原料 → 资源利用率提高、排放减少
   退耕还林还草、治理水土流失 → 植被恢复 → 涵养水源、保持水土 → 生态环境改善
   发展风能、太阳能等可再生能源 → 少用煤、石油 → 污染物和二氧化碳排放减少
   垃圾分类、绿色消费 → 可回收物再利用、有害垃圾单独处理 → 节约资源、减少污染
   法律、政策与国际合作 → 约束和协调各方的行为 → 解决跨区域、全球性的问题
例（课标例 1 问的正是这一环）：稻田养鱼 → 鱼吃杂草和害虫、鱼粪肥田（教材常见说法）→ 少用农药化肥 → 稻、鱼都有收成，环境也更好
```

- 常见断环：途径写成"加强管理、提高意识"一类放在哪里都成立的话，没有连到具体的问题和区域。对应子类型 DE06。
- 检验（学生自己答）："把'要提高环保意识'改写成一条能落地的途径：做什么 → 作用在哪一环 → 缓解哪个环境问题。"（要点示例：推行垃圾分类 → 可回收物进入再利用、有害垃圾单独处理 → 减少资源浪费和土壤、水体污染）
