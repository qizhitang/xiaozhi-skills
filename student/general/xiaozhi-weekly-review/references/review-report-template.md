# 每周复盘报告文案参考模板

> 适用学段：小学中段、小学高段（用 §六 三问版）、初中、高中（用完整六模块）。
> 此文档为 `xiaozhi-weekly-review` 提供各情境下的文案参考，
> 帮助小智生成有温度、有数据、不套话的复盘报告。

---

## 一、一句话总结参考（根据本周情况选择）

### 突破型（攻克了某个难点）
```
"这周你把[具体薄弱点]给干掉了——这个曾经让你连续出错的东西，
 现在已经不是问题了。这是本周最有价值的进步。"

"[知识点]之前在你的错题本里躺了[X]次了，这周你把它彻底解决了。
 这叫做消灭错误基因，值得记录。"
```

### 积累型（没有大突破但稳定前进）
```
"这周没有戏剧性的大突破，但你做了一件更重要的事——坚持。
 每一次认真的对话，都在让你的学习DNA变得更准确。"

"这是一周稳扎稳打的学习。没有什么轰轰烈烈的，
 但你接触了[X]个新知识点，完成了[X]次复习，
 这是复利积累最重要的那种进步。"
```

### 需要改善型（本周有明显问题需要指出）
```
"这周我注意到一件事：[具体问题]。
 我直接说，是因为你需要知道这个。
 但同时，你也在[进步点]上做得很好——两件事都是真的。"

"这周的数据告诉我，[问题描述]。
 不是批评，是信号——下周我们一起重点解决这个。"
```

### 考前冲刺型
```
"距离[考试名称]还有[X]天。这周你完成了[具体准备内容]，
 薄弱点[XX]还需要加强，但[优势点]已经没问题了。
 按照我下面的建议走，你有准备好的底气。"
```

## 二、进步描述参考（必须具体，不能用套话）

### ❌ 不允许的套话写法
```
"你这周非常努力"
"学习态度认真"
"有明显进步"
"继续加油"
```

### ✅ 正确的具体写法
```
进步① 【数学·行程问题】
"两周前你在行程问题上连续错了3次，这周你做了[X]道同类题，
 全部答对了，而且你的解题过程比以前清晰了很多——
 从'凑答案'变成了'真的理解速度×时间=路程'的关系。"

进步② 【英语·现在完成时】
"这是你第一次在费曼测试里完整解释了现在完成时的用法，
 而且举的例子是你自己想的，不是课文里的。
 这说明它不再是你背来的知识，而是你理解了的能力。"

进步③ 【学习习惯】
"这周你有[X]次在问完问题之后，主动说'让我再想想'，
 而不是等我直接给答案。这个习惯的改变，
 比学会任何一个知识点都更有价值。"
```

## 三、下周建议参考（聚焦且可执行）

### 原则：只选一个最重要的，给出具体行动

```
下周最值得重点攻克的一件事：
[问题]：英语完形填空的语境判断能力

为什么选这个：
你这周在3道完形填空题上都出现了类似的问题——
不是单词不认识，是没有把前后句放在一起理解。
这是一个需要专门练习的能力，不是靠刷题能自动解决的。

具体建议：
• 每天做1-2道完形填空时，做完后给我说说你的判断过程
  （不是答案，是你怎么想的）
• 遇到犹豫的选项，不要猜，先说"我觉得是XX，因为……"
• 周三左右，我们做一次费曼测试，验证你的语境判断思路
```

## 四、小智结语参考（个性化，有温度）

### 鼓励突破的
```
"你攻克了[XX]，这很难，值得你记住这一天。
 下周继续。"
```

### 激励坚持的
```
"我知道这周有几天你很累——我看到了。
 但你还是来了，还是在认真想，还是完成了复习。
 这就是飞轮一直在转的证明。"
```

### 温柔指出问题的
```
"有一件事我需要告诉你，因为我觉得你准备好了听：
 [问题]。这不是说你不好，是说这里还有空间——
 而且你完全有能力填上它。"
```

### 考试前的
```
"[X]天后考试。你准备得怎么样，你比任何人都清楚。
 我从数据上看，[优势点]没问题。[薄弱点]还需要[具体建议]。
 你不是在裸考，你是带着这[X]周的积累去考的。"
```

## 五、月度复盘素材（本 SKILL 只提供素材，月报由学习系统协调器生成）

> 本 SKILL 不生成月报。学生请求月报时，把以下摘要交给 `xiaozhi-skill-coordinator`。

```
🏆 本月攻克清单（都要有证据）

✅ 弱项攻克：[知识点]（按 shared/vocab.md §5 完成两次独立验证，间隔 [N] 天）
✅ 费曼达到"真正掌握"：[知识点]（能讲清、能举自己的例子、能迁移）
✅ 习惯改变：[具体行为，如"这个月有 3 次主动说'让我先想想'"]
（不写"复习坚持成就""对话次数里程碑"——使用量不是学习成果）
```

```
📈 这个月，你的弱项状态发生了什么变化

上个月                     本月状态（shared/vocab.md §4 五档）
──────────────────────────────────────────────
数学-行程问题              ✅ 已攻克
英语-现在完成时            🔄 突破中
语文-议论文结构            ⏳ 本月未重点练习，仍是 初步弱项

新出现的弱项：[如有，注明是第几次、什么维度]
```

## 六、小学中高段：三问版模板

```
📊 [昵称] 的本周小复盘
[日期范围]

1️⃣ 这周你做成了哪一件事？
   你说的是：__________
   （小智复述一遍，确认没理解错）

2️⃣ 这周哪里卡住了？
   你说的是：__________

3️⃣ 下周你想先解决哪一个？
   你选的是：__________

小智的一句话：
"[针对第 1 条的具体肯定，不说'你真棒'，说他具体做对了什么]"
```

三问版纪律：不出图表、不算完成率、不做成长曲线、全流程 ≤ 4 轮；不生成家庭版，除非学生自己要求且 `parentSharingConsent = true`。

## 七、家庭分享版文案（生成条件见 SKILL.md §9.0）

前提：`parentSharingConsent = true`；含情绪内容的段落另需 `emotionSharingWithParent = true`；学生随时可否决。

```
👪 [昵称] 的本周家庭成长报告
[日期范围]

一、这周的具体进展
   - [一件学生自己认可、也同意让家长看到的具体进展]

二、这周遇到的挑战（只写学习事实）
   - 客观情况：[科目][知识点]在 28 天内同一维度累计 [N] 次，当前状态 [五档之一]
   - ➡️ 家长可以做的一件事：不对次数做评价，本周找一个时间让孩子当一次小老师，
        家长只负责听和提问。

三、（本段仅在 emotionSharingWithParent = true 时输出）
   - 客观情况：本周在 [科目] 学习中有些紧张，出现过回避迹象
   - ➡️ 家长可以做的一件事："无声陪伴"——一杯水、一次散步，不谈成绩

四、下周孩子自己定的一件事
   - [孩子自己说的，不是小智替他定的]
```

家庭版的三条纪律：只写学生同意公开的内容；不写心理标签；不写"和别的孩子比"。
