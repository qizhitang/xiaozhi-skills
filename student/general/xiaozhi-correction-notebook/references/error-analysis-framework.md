# 各科错因判定线索与子类型对照

> 适用学段：小学中段、小学高段、初中、高中（示例以初中为主）。
> 此文档供 `xiaozhi-correction-notebook` 做通用四维定位时参考，并说明各科如何交接给对应的学科错误 DNA。
> 词表唯一来源：`shared/vocab.md §1`（通用四维）与 `§2`（学科子类型编码）。本文件**不定义新词表**。

---

## 零、判定顺序（所有学科通用）

```text
① 让学生复述题目条件 → 复述后立刻会做 = 读题失误(R)
② 给"纯净版"最简题   → 纯净版也做不对 = 概念模糊(C)
③ 换一个同型题        → 换题型就不会   = 概念模糊(C)；会做但选错路径 = 方法用错(M)
④ 以上都排除          → 计算失误(K)
```

**一道题只记一个主维度。**"粗心"不是原因，是结果——把它拆成 K（算错抄错）或 R（看错条件）。

## 一、数学

| 通用维度 | 典型表现 | 判定线索 |
|---|---|---|
| 概念模糊 | 混淆相似概念（函数的增减性与图象位置）；公式适用条件不清（二次根式被开方数 ≥ 0）；定义域/取值范围理解偏差；正负数运算规则混用 | 纯净版最简题也做不对 |
| 读题失误 | 漏读"整数解""最小值""不超过"等限定词；没注意"相向""返回"等方向词；忽略图形中的隐含条件；未读完题就动笔 | 复述条件后立刻会做 |
| 计算失误 | 符号错误；移项漏变号；分数运算出错；开方乘方算错；抄错数字 | 列式正确，结果错 |
| 方法用错 | 该列方程却硬算；不画辅助图/不列表；步骤顺序混乱 | 概念清楚、条件读全，但路径选错 |

> "移项不变号"归**概念模糊**（规则记错的本质是概念），不归计算失误。

交接：完成上表定位后，把结果写入 `wrongAnswerData.basicDimension`（值为四维之一），推送给 `xiaozhi-math-error-dna`。学科端回写 `subtypeId`（如 B03）与深度 `rootCause`。子类型定义见 `xiaozhi-math-error-dna` 的数学错因维度表。

## 二、物理

物理有五维子类型（P 图景建立 / C 概念混淆 / F 公式误用 / R 过程分析 / T 数学工具），与通用四维**非 1:1 映射**，交接时必须在 `judgmentClue` 里写清判断依据。

| 通用维度 | 典型表现 | 交接建议（physicsBasicDimension） |
|---|---|---|
| 概念模糊 | 不画受力图/电路图就列公式 → P；速度与加速度方向混淆 → C；压强与压力混用 → C；参照物选错 → P | `图景建立(P)` 或 `概念混淆(C)` |
| 读题失误 | 漏读"匀速""光滑"等条件词 → P；没意识到"静止"隐含合力为零 → C；忽略图中隐含条件 → P | `图景建立(P)` 或 `概念混淆(C)` |
| 计算失误 | 单位换算出错（km/h→m/s）；比例运算出错；图象读数错（坐标含义、斜率截距） | `数学工具错误(T)` |
| 方法用错 | 公式适用条件不满足仍套用 → F；多阶段运动只分析一段 → R；矢量方向没考虑 → F；步骤顺序混乱 → R | `公式误用(F)` 或 `过程分析错误(R)` |

> 判断规则：**缺"画图景"的意识和习惯**归 P；**画了图但概念理解有偏差**归 C；**公式选错**归 F；**过程拆分不完整**归 R。

交接给 `xiaozhi-physics-error-dna`；`new_error` 类型时 `judgmentClue` 必填。子类型定义见 `xiaozhi-physics-error-dna` 的物理错因维度表。

## 三、化学

化学有六维子类型（HS 符号表征 / HM 微观表征 / HC 宏观概念 / HR 读题与条件 / HE 实验与探究 / HQ 定量计算），按"宏观—微观—符号"三重表征组织，与通用四维**非 1:1 映射**，交接时在 `judgmentClue` 里写清判断依据。

| 通用维度 | 典型表现 | 交接建议（chemistryDimension） |
|---|---|---|
| 概念模糊 | 化合价记错、化学式写错、改化学式右下角的数字来配平 → HS；说不出化学变化的微观过程、"受热膨胀是分子变大" → HM；把碳酸钠当成碱、"降低着火点灭火" → HC | `符号表征(HS)` / `微观表征(HM)` / `宏观概念(HC)` |
| 读题失误 | 漏读"足量""恰好完全反应""滴加顺序"；推断题的特征颜色、特征现象没看见 | `读题与条件(HR)` |
| 计算失误 | 相对分子质量漏乘括号外的角标；溶液质量没减逸出的气体或生成的沉淀 | `定量计算(HQ)` |
| 方法用错 | 气体装置选错、操作顺序错、现象写成结论、除杂引入新杂质 → HE；配平策略混乱 → HS | `实验与探究(HE)` 或 `符号表征(HS)` |

> 判断规则：单独写这个化学式或方程式仍错 → HS；请学生用"粒子"讲一遍讲不出 → HM；纯净版概念判断题仍错 → HC；复述题目条件后立刻会做 → HR。

七、八年级学生发来的"化学题"，先问一句学校教没教过化学（五四制八年级开课，浙江等地在《科学》课里学，见 shared/grade-bands.md §四）；没教过的多半是物理或生物题，按学科判别重新确认。交接给 `xiaozhi-chemistry-error-dna`；`new_error` 类型时 `judgmentClue` 必填。子类型定义见 `xiaozhi-chemistry-error-dna` 的化学错因维度表。

## 四、历史

历史有五维子类型（LS 史料信息提取 / LT 时空定位 / LK 史实与概念混淆 / LA 论证结构 / LE 表述规范），与通用四维**非 1:1 映射**，交接时在 `judgmentClue` 里写清判断依据。

| 通用维度 | 典型表现 | 交接建议（historyDimension） |
|---|---|---|
| 读题失误 | 漏看材料的出处与时间；把材料里的观点当成史实；设问问“变化”只答了现状 | `史料信息提取(LS)` |
| 概念模糊 | 公元前纪年、世纪、年代换算错，中外同期对应错 → LT；相近的制度、事件、人物混淆，因果倒置 → LK | `时空定位(LT)` / `史实与概念混淆(LK)` |
| 方法用错 | 只有观点没有史实，或史实与观点脱节 → LA；不分点、不用历史术语、答非所问 → LE | `论证结构(LA)` / `表述规范(LE)` |

> 判断规则：请学生复述材料说了什么（出处、时间、主要信息），复述有误 → LS；把事件放到时间轴或地图上仍放错 → LT；换个问法考同一史实仍错 → LK；史实都对但观点立不住、连不起来 → LA；意思对但写法不合规范 → LE。纪年换算算错归 LT，不归计算失误。

交接给 `xiaozhi-history-source-analyzer`（历史错因维度表的持有者）；`new_error` 类型时 `judgmentClue` 必填。子类型定义见该技能的历史错因维度表。

## 五、英语

| 通用维度 | 典型表现 | 学科维度前缀 |
|---|---|---|
| 概念模糊 | 时态混用（一般过去 vs 现在完成）；主谓一致；冠词 a/an/the；从句结构搭错 | `G` 语法 / `V` 词汇 |
| 读题失误 | 阅读定位段落错；没找到关键词对应位置；完形没考虑上下文语境；听力抓不住信息词 | `L` 听力 |
| 计算失误 | 拼写错误、词形变化写错（复数、过去式） | `P`（拼写部分） |
| 方法用错 | 中式英语（直接照译中文逻辑）；句子结构单一、缺连接词；答题不按题干要求作答 | `T` 表达 |

交接给 `xiaozhi-english-grammar-coach`。子类型定义见 `xiaozhi-english-grammar-coach` 的英语错因维度表。

## 六、语文

| 通用维度 | 典型表现 | 学科维度前缀 |
|---|---|---|
| 概念模糊 | 混淆修辞手法（比喻/拟人/借代）；文体特征不清（记叙要素 vs 议论结构）；文言实词虚词义项记错 | `CL` 文言 |
| 读题失误 | 没注意"结合全文"还是"结合第X段"；漏读"情感"与"主旨"的区别；作文审题偏题 | `RC` 阅读 |
| 计算失误 | 默写错字、引用原文抄错 | —（少见） |
| 方法用错 | 答题格式不规范、缺术语；分析停留表面没答"为什么"；语病改了一处漏一处 | `AR` 答题规范 / `WT` 写作 / `LG` 语病 |

交接给 `xiaozhi-chinese-reading-decoder`（阅读类）或 `xiaozhi-chinese-grammar-tracker`（语病类）。子类型定义见 `xiaozhi-chinese-reading-decoder` 的语文错因维度表。

## 七、错误严重程度分级

| 等级 | 描述 | 处理方式 |
|-----|-----|---------|
| ⭐ 偶发失误 | 单次出现，理解无问题 | 记录，低优先级；状态 `待处理` |
| ⭐⭐ 理解偏差 | 28 天内同口径第 2 次 | 重新讲解，中优先级；状态 `初步弱项` |
| ⭐⭐⭐ 固定模式 | 28 天内同口径第 3 次（`shared/vocab.md §5`） | 专项突破，高优先级；状态 `顽固弱项` |
| ⭐⭐⭐⭐ 根基缺失 | 前置知识点有缺口，纯净版也做不对 | 溯源到前置知识点补讲；状态 `顽固弱项` + 记入概念图谱 `requires` 边 |

> ⭐⭐⭐ 与 ⭐⭐⭐⭐ 的**突破流程**由对应学科错误 DNA 执行；通用错题本只负责计数、推送与汇总，不独立启动专项突破。

## 八、交接字段速查

| 字段 | 取值 | 说明 |
|---|---|---|
| `basicDimension` | 概念模糊 / 计算失误 / 读题失误 / 方法用错 | **所有学科必填**，通用四维 |
| `subtypeId` | `^(RC\|AR\|WT\|CL\|LG\|H[SMCREQ]\|L[STKAE]\|[A-Z])[0-9]{2}$` | 可选；由学科端回写，通用层只存不解释（化学、历史为两字母前缀，如 `HS04`、`LS02`） |
| `physicsBasicDimension` | 图景建立(P) / 概念混淆(C) / 公式误用(F) / 过程分析错误(R) / 数学工具错误(T) | 仅 `subject=physics` |
| `chemistryDimension` | 符号表征(HS) / 微观表征(HM) / 宏观概念(HC) / 读题与条件(HR) / 实验与探究(HE) / 定量计算(HQ) | 仅 `subject=chemistry` |
| `historyDimension` | 史料信息提取(LS) / 时空定位(LT) / 史实与概念混淆(LK) / 论证结构(LA) / 表述规范(LE) | 仅 `subject=history` |
| `chineseDimension` | 阅读理解(RC) / 答题规范(AR) / 写作(WT) / 文言文(CL) / 语病(LG) | 仅 `subject=chinese` |
| `englishDimension` | 语法(G) / 词汇(V) / 表达/中式英语(T) / 发音(P) / 听力(L) | 仅 `subject=english` |
| `occurrenceCountInWindow` | 整数 ≥ 1 | 错题本按 `shared/vocab.md §5` 统计的 28 天累计次数 |
| `judgmentClue` | 自由文本 | 物理、化学、历史 `new_error` 必填，说明为何归到该学科维度 |

字段的完整约束见 `shared/handover-protocol.schema.json`。
