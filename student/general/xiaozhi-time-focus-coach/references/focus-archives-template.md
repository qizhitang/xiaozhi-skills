# 专注力履历档案模板

> 适用学段：小学中段（简化版，只填 A、B 两栏）、小学高段、初中、高中。
> 本文档为 `xiaozhi-time-focus-coach` 模块E 的填写模板。
> 长期存储落在学习DNA的 `extensions.focus`（见 `../../xiaozhi-learning-dna/schemas/dna-profile.schema.json`），
> 通过 `subject_profile_writeback`（`updateTarget: "extension"`）写入，写前确认 `crossSkillSharing`。

---

## 一、每日记录（学生每天一行，30 秒内可填完）

```
日期：2026-05-12
今天最长的一段不被打断的学习：[45] 分钟，做的是 [数学错题回看]
中断次数：[2] 次；原因：[手机消息] [家人叫吃饭]
今天最"进得去"的时段：[19:00-20:00]
今天最"进不去"的时段：[21:00 以后]
一句话：[今天开头拖了 20 分钟才动笔]
```

小学中段简化到两问："今天哪段时间最专心？""什么打断了你？"

## 二、两周汇总（生成黄金时段分析时用）

```
统计区间：2026-04-29 ~ 2026-05-12（有效记录 [11] 天）
置信度：🟢 数据充分 / 🟡 初步趋势 / 🔴 样本不足   ← 见 shared/vocab.md §7

A. 黄金时段（写入 extensions.focus.goldenSlots[]）
   最容易进入状态的时段：晚饭后 1 小时
   次优时段：周末上午
   最难进入状态的时段：睡前半小时
   依据：这 11 天里，晚饭后那段的"任务做完"次数最多（8/11），
         睡前那段最多只完成一半（2/9）

B. 常见分心来源（写入 extensions.focus.commonDistractions[]）
   1. 手机消息（11 天中出现 9 次）
   2. 思维漂移（7 次）
   3. 家人打断（3 次）

C. 平均专注时长（写入 extensions.focus.avgFocusMinutes，整数 5-90）
   本期平均：[22] 分钟
   最长一次：[45] 分钟
   最短一次：[8] 分钟

D. 有效方法记录（只留在本 SKILL 内，不写入DNA）
   已试过：M2 手机隔离法（用了 8 天）
   我自己的前后对比：用之前平均 15 分钟被打断一次，用之后 22 分钟
   结论：对我有效，继续用两周再看
   无明显效果：M1 白噪音（3 天，没感觉出差别）

E. 进步记录（只做自身纵向对比，不与他人比较）
   开始学习前的拖延时间：第 1 周平均 18 分钟 → 第 2 周平均 11 分钟
   单次专注中断次数：第 1 周平均 2.4 次 → 第 2 周平均 1.5 次
```

## 三、写回字段对照表

| 模板栏位 | DNA 字段 | 约束 |
|---|---|---|
| A. 黄金时段 | `extensions.focus.goldenSlots[]` | 粗粒度字符串，每条 ≤ 30 字（如"晚饭后 1 小时"），**不记精确作息** |
| B. 常见分心来源 | `extensions.focus.commonDistractions[]` | 每条 ≤ 30 字 |
| C. 平均专注时长 | `extensions.focus.avgFocusMinutes` | 整数，5-90 |
| 置信度 | `extensions.focus.confidenceLevel` | `data_sufficient` / `preliminary_trend` / `insufficient_sample` |
| 汇总日期 | `extensions.focus.lastUpdated` | `YYYY-MM-DD` |
| D、E 两栏 | 不写入 | 只在本 SKILL 会话内使用 |

---

## 四、填写纪律

1. **只记学习相关的分心原因**，不记家庭矛盾、人际冲突、健康状况等细节；学生说到这类内容时改写为低敏概括（如"被家里的事打断"），或直接不记。
2. **不写算不出来的比例**："分心率 37%""完成率提升 22%"这类数字在没有完整计时数据时一律不写；只写两次记录的绝对值对比与数据天数。
3. **不足 5 天的数据只做观察**，标 🔴 样本不足，不生成正式报告、不写入长期档案。
4. **考试周、生病、放假的数据单独标注**，不混进常规统计。
5. **不做使用时长里程碑**：不记"连续 N 天使用番茄钟"，那是使用量不是学习成果。
6. 学生随时可以说「查看我的专注力档案」「删除我的专注力档案」，删除后不可恢复，删除前确认一次。
