# 兴趣探索记录模板

> 适用学段：小学中段 / 小学高段（只用 §四 的 8 周试探版表格）、初中、高中（用 §一至 §三 的完整版）。
> 本文档为 `xiaozhi-interest-explorer` 的配套记录模板。
> 长期存储落在学习DNA的 `interestDNA`（见 `../../xiaozhi-learning-dna/schemas/dna-profile.schema.json`），
> 需 `interestTrackingConsent = true`，通过 `profile_writeback` 写入。

---

## 一、单次探索记录（每周一次，学生 5 分钟填完）

```
【第 [N] 次探索】日期：____-__-__
领域：__________（如：动物行为 / 前端开发 / 版画 / 天文观测）

1) 我这次具体做了什么？（一句话，要具体到动作）
   □ 读了 __________
   □ 看了 __________
   □ 动手做了 __________
   □ 问了 __________（人 / 论坛 / 视频作者）

2) 有没有某个瞬间让我"停不下来"？
   有 / 没有；如果有，是在做什么的时候：__________

3) 这次的困难是什么？（每次必须有一个"有点难"的时刻）
   困难：__________
   我的第一反应：□ 想放弃  □ 想找资料继续  □ 有点烦但还想搞懂

4) 花掉的时间感觉：□ 过得很快  □ 差不多  □ 有点熬

5) 一周后回看，这个困难还让我在意吗？（下周填）
   □ 还在意，想解决   □ 已经忘了   □ 想起来还是不想碰
```

## 二、领域档案（每个正在探索的领域一份）

```
【兴趣记录 · [领域名称]】
探索开始日期：____-__-__
已探索次数：[N] 次

■ 内容层（我被什么吸引）
  最吸引我的具体方向：__________
  停不下来的内容类型：__________
  出现过"原来如此"的地方：__________

■ 困难反应记录（按时间，这一栏最重要）
  第 1 次：[困难] → [想放弃 / 想继续 / 挫败但想继续]
  第 2 次：[同格式]
  第 3 次：[同格式]
  ……

  综合信号：□ 浅层喜好  □ 可能是真正兴趣  □ 确认是真正兴趣
  置信度：□ 🔴样本不足(<3次)  □ 🟡初步趋势(3-8次)  □ 🟢数据充分(>8次)
          （shared/vocab.md §7）

■ 时间感记录
  有过"时间过得飞快"的次数：[N]
  主动放下别的事来做这个的次数：[N]

■ 外部反馈（每月更新）
  别人给过的具体反馈：__________
  和自己上个月比，哪里更顺了：__________
  ⚠️ 不填"和同学比快还是慢"——这一栏不做同龄人比较

■ 阶段判断（8 次以后，小智给出）
  当前判断：__________
  依据：__________
  下一步：□ 继续深入  □ 横向试试别的  □ 先放一放
```

## 三、写回字段对照表

| 模板栏位 | DNA 字段 | 说明 |
|---|---|---|
| 领域名称 + 开始日期 + 次数 | `interestDNA.currentExploringFields[]`（`fieldName` / `startedDate` / `explorationWeeks`） | |
| 综合信号 | `interestDNA.challengeReactionSignals[].reactionSignal` | 取值：`放弃信号` / `继续信号` / `确认兴趣` |
| 置信度 | `interestDNA.challengeReactionSignals[].confidenceLevel` | `insufficient_sample` / `preliminary_trend` / `data_sufficient` |
| 判定为浅层喜好的领域 | `interestDNA.confirmedShallowLikes[]` | 只存领域名 |
| 判定为可能真兴趣的领域 | `interestDNA.possibleTrueInterests[]` | 只存领域名 |
| 更新日期 | `interestDNA.lastUpdated` | `YYYY-MM-DD` |
| 单次探索的具体内容、困难描述 | **不写入DNA** | 只在会话与学生自己的记录里保留 |

## 五、填写纪律

1. **困难反应比喜好自评可信**：学生说"我超喜欢"但每次遇到难就换领域，记录以困难反应为准。
2. **不足 3 次不下判断**，标 🔴 样本不足，不写入长期档案。
3. **区分 The Dip 与真的无感**：连续三次"想放弃"可能只是学习曲线初期的正常低谷，结论一律标 🟡，并问一句"要不要再给它两周"。
4. **不用物质奖励推动探索**——外在奖励会污染"内在驱动力"这项测量本身。
5. **不做同龄人比较**，也不推断专业、职业、升学方向。
6. **家长可见的简报不默认生成**：需学生本人同意且 `parentSharingConsent = true`；含情绪内容另需 `emotionSharingWithParent`。
7. 学生随时可以说「查看我的兴趣记录」「删除我的兴趣记录」，删除后不可恢复，删除前确认一次。
