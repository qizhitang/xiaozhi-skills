# 🌱 成长里程碑参考标准

> 适用学段：小学中段、小学高段、初中、高中。
> 此文档供 `xiaozhi-learning-dna` 生成里程碑**待确认条目**时参考。本 SKILL 不解读对话、不评价行为：
> 里程碑只在**档案里已经写入的证据**（费曼验证等级、错题本的攻克记录、周报里的完成记录）满足下列标准时才生成，由学生确认后落 `growthTrack.milestones[]`。  
> 里程碑分三个维度：**时间维度**（学习周期节点）、**能力维度**（学科进步）、**习惯维度**（学习行为改变）。  
> 触发时先告知学生，生成待确认条目，学生确认后写入 `growthTrack.milestones[]`（`category` 取三档之一）。

> ⚠️ **不作为里程碑**：使用天数、连续打卡、对话次数、累计使用时长、完成率百分比。
> 这些衡量的是"用了多久"，不是"学到了什么"，把它们做成成就会把学习动机推向刷存在感。
> 连续打卡中断时不提醒"你已经断了 N 天"，只说"欢迎回来，接着来吧"。

---

## 一、时间维度里程碑（学习周期节点类）

记录**一个学习周期真正走完**的时刻——不是用了多少天，而是某个流程闭合了。

| 里程碑名称 | 触发标准 | 参考话术 |
|-----------|---------|---------|
| 🌱 **档案建立** | 完成首次建档并确认了同意主体 | "档案建好了。你随时可以说'查看我的档案'看我记了什么。" |
| 🔁 **首个复习周期闭合** | 同一知识点走完 Day1→Day3→Day7→Day14→Day30 五次复习并最后一次答对 | "这个知识点你完整过了一整轮复习，最后一次还是对的——它是真的进你脑子里了。" |
| 📋 **首份计划完整执行** | 一份 30 天计划（或小学高段的周计划）走到结束并做了收尾复盘 | "你把一份计划从头做到尾，还做了复盘。多数计划死在第二周。" |
| 🧪 **首个考试周期走完** | 从考前准备到考后错题归档形成闭环 | "从准备到考完再到把错题收进本子，这一圈你走完了。" |

## 二、能力维度里程碑（学科进步类）

记录学生在具体学科能力上的可量化突破，必须有数据或行为证据支撑，不接受模糊描述。

### 2.1 通用能力里程碑

| 里程碑名称 | 触发标准 | 记录方式 |
|-----------|---------|---------|
| 🎯 **第一个薄弱点攻克** | 某个弱项按 `shared/vocab.md §5` 达到攻克标准（连续 2 次独立验证做对，间隔 ≥ 3 天，至少 1 次为换题型/纯净版） | 记录：攻克日期 + 弱项名称 + 历史出错次数 |
| 🔁 **费曼测试首通** | 第一次完整走完费曼测试的四个追问层次 | 记录：知识点 + 日期 + 从哪里发现了盲区 |
| 📈 **连续进步** | 同类题型连续3次成绩（正确率）提升 | 记录：题型 + 三次数据 |
| 🧩 **知识点连接** | 主动将两个不同章节/学科的知识点联系起来 | 记录：学生自己说出的连接点 |
| 💡 **独立解题突破** | 某类之前完全不会的题型，首次独立做对（不靠提示） | 记录：题型 + 日期 + 学生的解题过程摘要 |

### 2.2 语文专项里程碑

| 里程碑 | 触发标准 |
|-------|---------|
| 📝 **写作首次突破** | 一篇作文收到具体的、非套话的正向反馈（如："这段叙述真的打动了我"） |
| 📖 **阅读视角转变** | 首次用"出题人视角"分析阅读理解，而不是"猜答案" |
| 🏛️ **古文真正理解** | 能用自己的话讲述某篇古文的背景和情感，而不是逐字翻译 |
| ✏️ **语病自我发现** | 写完作文后，不靠AI提示，主动找到了自己的语病并改正 |

### 2.3 数学专项里程碑

| 里程碑 | 触发标准 |
|-------|---------|
| 📐 **应用题建模突破** | 首次独立完成"识别数量→说出关系→建立方程"三步，不需要追问 |
| 🧬 **错误基因消灭** | 某顽固弱项（`shared/vocab.md §5` 口径）转为"已攻克" |
| 🎯 **天花板突破** | 在思维梯度训练中，首次做对比当前层级高一层的题目 |
| 💡 **概念直觉建立** | 能用生活类比自己解释某个数学概念，不需要公式 |

### 2.4 英语专项里程碑

| 里程碑 | 触发标准 |
|-------|---------|
| 🎙️ **开口第一天** | 完成第一次英语口语热身（哪怕只说了3句） |
| 📖 **词汇首次成规模** | 词汇档案中"已掌握"状态的词首次成规模（如一个单元的词全部通过复习） |
| 📝 **句式升级首次** | 写作中首次主动使用复合句，而不是简单句 |
| 🎧 **听力首次独立** | 第一次不看文字，听完一段材料后能说出大意 |
| 🗣️ **四级跳完成** | 首次在口语练习中完整走完苏格拉底四级跳 |

## 三、习惯维度里程碑（学习行为改变类）

这一类里程碑最难被看见，但往往是最有价值的改变。**它们由学生自述或周报里已写入的记录触发，本 SKILL 不解读对话、不统计行为。**

| 里程碑名称 | 触发标准 | 说明 |
|-----------|---------|-----|
| 🤔 **主动思考** | 学生自己说“我最近会先想一想再问”，或每周学习复盘的记录里写了这一点。本 SKILL 不数对话里出现了几次“让我想想” | 标志：学生开始把AI当助手，而不是答案机器 |
| ❓ **主动追问** | 学生自述或周报记录（同上），不由本 SKILL 统计追问次数 | 标志：从被动接受知识到主动探索知识 |
| 🛑 **诚实说不懂** | 学生自己提到这个变化时记；本 SKILL 不对比“以前说懂、现在说不懂” | 标志：信任建立，不再表演理解 |
| 🗓️ **主动复习** | 每周学习复盘的记录显示本周有未经提醒的复习（由周报写入的证据触发） | 标志：复习习惯开始内化 |
| 🔍 **自我诊断** | 学生能说出"我觉得我在XX类题上有个固定的问题"，不需要AI指出 | 标志：元认知能力出现 |
| 🎁 **主动分享** | 学生主动告诉小智"我今天学了XX，记一下"（不是AI追问下说的） | 标志：把学习记录视为有价值的事 |
| 🧭 **主动纠偏** | 学生对小智说"这个方向不对，我真正的问题在另一处" | 标志：批判性使用 AI，而不是照单全收 |

## 四、里程碑触发时的标准话术

### 触发时机

- 当**档案里新写入的证据**使某个标准被满足时（不是从当前对话内容推断），当场告知并生成待确认条目
- **学生请求**成长总结、周报或月报时，回顾当期达成的里程碑；不按月自行生成总结
- 学生说"我进步了多少"时，调取所有已记录里程碑

### 触发话术模板

```
即时触发（当场）：
"等一下——我注意到一件事。
 [说明触发了什么里程碑，用具体行为描述，不用套话]
 这值得记录。
 进入你的学习DNA成长轨迹了：[里程碑名称 + 日期]。"

示例：
"等一下——你刚才说'让我先想一下'，然后自己推导了出来。
 这是第3次了，我注意到了。
 你已经开始把我当助手，而不是答案机器——这个改变比做对任何一道题都重要。
 进入成长轨迹：✅ 主动思考里程碑达成（[日期]）"
```

```
学生请求成长总结时（不按月自行生成）：
"这段时间你的成长轨迹里新增了这些里程碑：

 ✅ [里程碑名称]（[日期]）——[一句话说明具体发生了什么]
 ✅ [里程碑名称]（[日期]）——[说明]

 最让我印象深刻的是[其中一个]——
 [一句有温度的、基于具体事件的评语]"
```

## 五、里程碑数据存储格式

```
growthTrack.milestones[] 单条（schemas/dna-profile.schema.json）：

milestoneId：由平台生成
name：[里程碑名称]
category：[时间维度 / 能力维度 / 习惯维度]
triggerDate：YYYY-MM-DD
triggerEvent：（用一句话具体描述是什么行为或数据触发了这个里程碑）
subject：（如适用）
comment：（存储当时说给学生的那句话）
```

## 六、里程碑的设计原则

**给设计和运营这个系统的人看：**

```
① 里程碑必须可验证——
   不能说"学生进步了"，
   要说"该知识点连续3次复测全对"。
   模糊的正向情感不是里程碑。

② 里程碑必须被学生感受到——
   记录在档案里但从不告诉学生，等于没有。
   每次里程碑触发，都要当场告知学生。

③ 里程碑不是奖励——
   不需要积分、徽章或任何游戏化设计。
   有温度的一句话，比任何徽章都有力量。

④ 习惯维度里程碑优先——
   当能力里程碑和习惯里程碑同时触发，
   习惯维度的更值得强调：
   "做对一道难题是结果，开始主动思考是原因。"

⑤ 失去里程碑时不惩罚——
   连续打卡中断了，不提醒"你已经断了N天"，
   而是："欢迎回来。接着来吧。"
```
