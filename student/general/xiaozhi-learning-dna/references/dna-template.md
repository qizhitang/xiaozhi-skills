# 🧬 学习DNA模板（首次建档引导用）

> 适用学段：小学中段、小学高段、初中、高中（小学各段必须先有监护人同意）。
> 此文档用于引导学生完成第一次建档对话。  
> 不要直接发给学生——用自然对话的方式逐步引出这些信息。

---

## 建档前置：确认说话人与同意主体

```
第一句（必问）：
"先确认一下——现在是同学本人在吗？"

小学各段（ageBand = 小学低段/中段/高段）：
"要建立长期学习档案，需要爸爸妈妈或其他监护人也同意一下。
 在他们同意之前，我只用这次聊天的信息帮你。"
→ consentGivenBy 必须包含"监护人"

初中及以上：
"要不要开一个长期学习档案？开了以后，'给家长看'和'记录情绪'
 是两个单独的开关，默认都关着，你随时可以改。"
→ consentGivenBy = 学生本人 或 学生与监护人
```

无法确认说话人时：**不要默认按学生本人处理**（那等于用未经核实的身份读写未成年人档案）。
确认之前进入**受限模式**：不读长期档案、不写任何记录、不执行删除、不变更授权位、不输出家长版内容，只用当前会话信息作答；反复追问仍无法确认就停在这里，不建档、不更新。（`shared/vocab.md` §8 规则 3）

```

■ 学科强弱（1=非常薄弱 → 5=比较自信）
  语文：__ / 具体薄弱点：
  数学：__ / 具体薄弱点：
  英语：__ / 具体薄弱点：

■ 学习风格
  偏好解释方式：□ 类比举例  □ 分步骤拆解  □ 先看结论再看过程  □ 图示辅助

  有没有近期要备考的内容：

■ 第一个目标
  我希望用小智帮我完成的第一件事：
```

## 首次建档对话示范脚本

**开场（不要用"您好"开头，太正式）：**
```
"嘿，终于见到你了！在我们开始之前，我想多了解你一点——
 放心，不是考试，就是聊聊天。你几年级？"
```

**引出薄弱点（不要问"哪里不好"，太宽泛）：**
```
"如果明天有一门课的考试，你最不希望是哪门？
 然后在那门课里，哪个部分是你一看就头大的那个？"
```

**了解学习风格（用选择题降低门槛）：**
```
"我帮你解释一个概念的时候，你更喜欢哪种方式——
 A：先举个生活里的例子，然后再讲定义？
 B：直接一步一步拆开讲？
 C：让你先自己试一试，遇到卡的地方再帮你？"
```

**确认目标（要具体，不要"我想提高成绩"）：**
```
"说一个你最近最想实现的学习目标——
 不用太大，就是'下次月考数学过80分'这种具体的就好。"
```

## DNA更新触发词表

当学生说以下内容时，**只生成待确认条目（先复述、学生确认后才写入）**。这些话在普通辅导里很常见，所以下面每一行都只是“问一句”的触发，不是写入的触发；学生没有明确说“记”，一个字都不写。

| 学生说 | 生成的待确认条目 | 落点字段 |
|-------|------------|------|
| "我懂了" / "明白了" | **不改掌握度**——只问一句“要不要做个费曼验证？”；掌握度只由费曼学习法的验证等级经交接写入 | （无） |
| "还是不太明白" / "有点迷" | **不加薄弱标记**——薄弱与否由错题本按 shared/vocab.md §5 计数后写入；这里最多问“要不要把这道题发给错题本？” | （无） |
| "我考试考了 XX 分" | 不写分数；问“要不要把这次考试记进档案（只记科目与日期，不记分数）？” | `growthTrack`（确认后） |
| "我升XX年级了" | 更新年级与 `ageBand`，重新确认授权主体 | `basicInfo.gradeLevel`、`meta.consentStatus.ageBand` |
| "我发现我最近XX进步了" | 生成里程碑待确认条目（需具体行为证据） | `growthTrack.milestones[]` |
| "我这周要考XX" | 记录考试节点；提醒需另行征得 `reminderConsent`，由 IM 提醒入队 | `basicInfo.upcomingExams[]` |
| "这道题我做了三次都错" | 转给错题本按 `shared/vocab.md §5` 计数，本 SKILL 不自行计数 | — |

> ⚠️ **注意事项：**  
> DNA的价值 = 信息的真实程度 × 积累的深度  
> 帮助学生理解：诚实地反馈"懂了/没懂"，是让DNA准确的前提。  
> 骗了AI，受损失的是自己的学习DNA。
