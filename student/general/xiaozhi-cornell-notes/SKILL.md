# 📝 康奈尔笔记 SKILL

> **一句话定位：** 你记笔记，笔记也记住你——  
> 当你需要它的时候，它能被快速找到。

> 技术边界：本 SKILL 依赖能力 [O, M]，无该能力时按 shared/platform-conventions.md 降级。
> 特有降级：图片看不了时，请学生把笔记要点打字或粘贴过来（一行一条即可），三栏整理、线索问题与跨科关联照常完成；无跨会话记忆时只在当前会话整理，不建立长期笔记库、不做后续提示。

### 隐私与数据控制入口

```text
- 查看：「查看我的笔记」/「查看我的档案」
- 更正：「更正我的笔记」
- 删除：「删除我的笔记」（删除后不可恢复，会先确认一次）
- 暂停：「这次不要记忆」/「暂停提醒」
- 共享控制：「不要共享给其他SKILL」/「不要给家长看」
- 导出：「导出我的笔记」（以文本形式给出，便于转存）
```

## 〇、学段适配

| 学段 | 版本 | 说明 |
|---|---|---|
| 小学低段 / 小学中段 | 不适用 | 直接说明，建议先练"把今天学的用一句话说清楚"，不做三栏笔记 |
| 小学高段 | **简化版：两栏** | 只做「右栏内容 + 底部一句话总结」，线索问题由小智先示范 1-2 条，学生跟着写；不做跨学科关联、不做健康报告 |
| 初中 / 高中 | 完整三栏 | 全流程 |

学段适用性以 `shared/grade-bands.md` 为准。小学高段简化版的完整写法见 `references/cornell-format-guide.md`。

## 一、核心使命

**传统笔记的三大痛点：**

```
痛点①：记了不看
  课上记了满满一页，课后从不翻开
  原因：静态存储，没有"被需要"的时机

痛点②：看了不懂
  翻开自己的笔记，发现看不懂自己在写什么
  原因：记录格式混乱，没有自问自答的训练

痛点③：懂了不用
  复习时懂了，做题时想不起来这个知识点有对应笔记
  原因：笔记和做题是两个孤立的系统
```

**这个SKILL的解法：**

```
拍照上传
    ↓
自动提炼：线索问题栏 + 底部总结行
    ↓
存入笔记DNA（按学科/课题/日期索引）
    ↓
做错题时 → 按需提示："你在[日期]的笔记里记录了这个知识点"
费曼测试时 → 按需提示："这个概念在你[科目]笔记第X次课里出现过"
    ↓
跨学科关联：同一个概念在不同学科出现时，按需标注
```

## 三、模块A：拍照识别与三栏提炼

### 康奈尔笔记三栏结构

```
┌─────────────────┬──────────────────────────────┐
│   左栏（线索区） │        右栏（笔记区）          │
│                 │                              │
│  关键问题       │  课堂实际记录的内容            │
│  核心词语       │  （这是学生已经写好的部分）     │
│  （AI提炼生成） │                              │
│                 │                              │
├─────────────────┴──────────────────────────────┤
│                 底部总结区                      │
│         用一句话概括本页笔记的核心               │
│              （AI提炼生成）                     │
└────────────────────────────────────────────────┘
```

### 拍照上传后的操作流程

**Step 1：接收图片，识别内容**

```
学生上传笔记图片后：

"收到！我来分析这页笔记——
 这是[科目][课题]的内容，对吗？
 如果有误请告诉我，我会更正后存入档案。"

→ 确认无误后进入Step 2
→ 如果识别有歧义，先让学生确认再提炼
```

**Step 2：自动提炼左栏线索问题**

```
提炼规则：
① 把右栏每个知识点转化为"可以自我检验"的问题
② 问题必须能从右栏找到答案（不过度引申）
③ 每个重要知识点对应1个问题，一页笔记通常3-6个问题

提炼格式：
"线索问题（左栏）：
 Q1: [问题1]
 Q2: [问题2]
 Q3: [问题3]
 ...
 
 这些问题是为了让你盖住右栏后，用左栏自我测验。
 你觉得这几个问题覆盖了这页笔记的核心吗？"
```

**Step 3：提炼底部总结（学生确认后定稿）**

```
总结规则：
① 用一句话（≤30字）概括这页笔记的核心
② 必须包含：这是什么（概念名称）+ 最重要的一点是什么
③ 学生可以修改，修改后版本存入档案

总结格式：
"底部总结（一句话）：
 '[概念名] = [核心定义/方法/公式]，关键在于[最重要的一点]'
 
 你觉得这句话抓住了这页的核心吗？可以直接修改。"
```

**Step 4：存入笔记DNA**

```
存入时附带元数据：
· 日期
· 学科
· 课题/章节
· 关键词标签（自动提取）
· 关联知识点（与已有档案的关联）

存入确认：
"存入成功！这页笔记已归入：
 [学科] > [课题] > [日期]
 关键词标签：[标签列表]
 
 下次你做[相关知识点]的题目时，
 如果你愿意，我可以提示这页相关笔记给你。"
```

## 四、模块B：笔记DNA系统

### 档案结构

```
笔记DNA
├── 语文
│   ├── 课文单元（按教材章节）
│   ├── 写作技法
│   └── 古诗词积累
│
├── 数学
│   ├── 代数（一次函数/二次函数/方程组…）
│   ├── 几何（三角形/圆/相似…）
│   └── 统计概率
│
├── 英语
│   ├── 语法笔记
│   ├── 词汇记录
│   └── 阅读笔记
│
└── [其他学科]
    └── …
```

### 笔记条目的完整存储格式

```
【笔记条目】
笔记ID：由平台生成
日期：
学科：
课题/章节：
关键词标签：[3-5个关键词]
线索问题：[Q1, Q2, Q3…]
底部总结：[一句话]
关联已有笔记：[相关笔记ID列表]
被调取次数：0（每次提示 +1）
最近调取日期：-
```

写回学习DNA的只有汇总层，不传笔记全文：

```
extensions.notes.noteCount        ← 笔记总数
extensions.notes.recurringGaps[]  ← 反复出现的笔记缺口（如"只记结论不记推导"，每条 ≤60 字）
extensions.notes.lastUpdated      ← YYYY-MM-DD
```

走 `subject_profile_writeback`（`updateTarget: "extension"`），写前确认 `crossSkillSharing`；字段定义见 `shared/dna-profile.schema.json`。

### 笔记检索方式

```
学生可以用以下方式调取笔记：

① 关键词检索：
  "找找我关于'一次函数'的笔记"

② 日期检索：
  "帮我看上周的数学笔记"

③ 课题检索：
  "找我学'圆的相关概念'时记的笔记"

④ 问题驱动检索（最高级）：
  "我做错了一道关于'圆心角和圆周角关系'的题，
   帮我找相关笔记"
  → 小智匹配后提示最相关的笔记，最多 2 条（口径见 §五"提示条数控制"）
```

## 五、模块C：按需提示机制

**这是此SKILL最核心的差异化功能——在需要时帮助学生快速调到相关笔记。**

提示一律是**按需提示**，不是主动推送：由错题、费曼测试或复习动作触发，且**每次对话最多 2 条**（见下方"提示条数控制"）。

### 三种按需提示触发场景

**触发场景①：错题分析时**

```
当学生在错题本SKILL中分析某道错题时，
笔记SKILL在当前任务需要时检测：
→ 这道题的知识点在笔记DNA中有没有对应记录？

如果有：
"我在你[日期]的[科目]笔记里找到了这个知识点——
 当时你记录的要点是：[底部总结]
 线索问题里有一条：'[最相关的Q]'
 现在来看这个问题，你能回答吗？"

如果没有：
"这道错题涉及到的知识点，
 你的笔记档案里还没有对应记录。
 建议你整理一页这个知识点的笔记，
 下次遇到就有依据了。"
```

**触发场景②：费曼测试时**

```
当学生开始费曼测试，说明要解释某个概念时，
笔记SKILL可检测该概念是否有笔记记录：

如果有记录：
"你在[日期]记过这个概念的笔记。
 我先不告诉你里面写了什么——
 你先讲，讲完我们对比一下你讲的和你当时记录的，
 看看理解有没有加深。"

目的：让费曼测试不只是凭空发挥，还有笔记的锚点对比
```

**触发场景③：复习提醒时**

```
这是 IM 智能提醒的动作，不是本 SKILL 主动推送：学生已同意提醒（reminderConsent）且提醒到期时，
提醒 SKILL 可以向本 SKILL 取该知识点的线索问题附在当天那条合并提醒里。本 SKILL 只按请求给线索问题，不自己发提醒：

"复习提醒：[知识点]

 你的笔记里有这些线索问题：
 Q1: [问题1]
 Q2: [问题2]

 先盖住笔记，回答这两个问题——能回答出来说明记住了。"
```

### 提示条数控制

```
每次对话最多提示 2 条笔记（避免信息过载）——
本 SKILL 全文只有这一个条数口径，其他章节不另设数字。

排序：
  ① 与当前话题最直接相关的笔记
  ② 被调取次数最少的笔记（防止只复习熟悉内容）
  ③ 距上次调取时间最长的笔记（防止遗忘）

复习提醒里附带笔记线索问题时，同样受这个上限约束；
提醒本身由 IM 智能提醒按 shared/vocab.md §9 发送，本 SKILL 只入队。
```

## 六、模块D：跨学科知识网络

### 自动关联触发标准

```
当两页不同学科的笔记中，出现以下情况时，可建立关联：

① 完全相同的概念（如：比例关系在数学和地理中都出现）
② 相同的分析框架（如：语文的人物分析和历史的人物评价）
③ 互为应用关系（如：数学的统计知识和物理的数据分析）
```

### 跨学科提示话术

```
"有意思的是——你在[科目A]的笔记里记过一个概念，
 和你今天[科目B]学的这个知识点有关联：
 
 [科目A] 的笔记（[日期]）写道：[底部总结]
 
 你觉得这两个知识点之间，有什么相似的思维方式？"

目的：建立知识迁移能力，不是死记硬背单科孤立知识
```

## 七、模块E：笔记健康报告

**触发：** 学生说"帮我看看笔记情况"时生成；不按月自行生成。小学高段简化版不做本报告。
**前提：** `profileEnabled` 为 true——报告里的调取次数、提示后回应次数都来自档案里的使用计数；没开档案就没有这些数，只能就本次会话说。
**记什么：** 每页笔记只记“被调取次数”“提示后是否回应”两个计数，不记调取时的对话内容。

```
📊 笔记DNA月度健康报告

■ 本月笔记概况
  新增笔记：[N]页
  涉及学科：[列举]
  总知识点条目：[N]条

■ 笔记活跃度
  本月被调取次数：[N]次
  从未被调取的笔记：[N]页（占总量[X]%）
  [如果沉默笔记过多]：建议用费曼测试激活这些沉默笔记

■ 跨学科关联
  已建立的跨科关联：[N]个
  其中：[举一个最有价值的跨科关联]

■ 笔记质量分析
  线索问题完整的笔记：[X]%
  有底部总结的笔记：[X]%
  建议：[基于数据的1条改善建议]

■ 被按需提示后的复习效果
  提示后学生有回应的次数：[N] / [M] 次
  提示后确实用上了的知识点：[列举]
```

## 八、自问自答训练法（康奈尔核心用法）

**每周至少一次，用以下方式使用笔记：**

```
Step 1：遮住右栏
只看左栏的线索问题，盖住右栏的笔记内容

Step 2：口头或书面回答每个问题
不看答案，凭记忆回答

Step 3：自己对照右栏
学生打开右栏，**自己**看哪些想起来了、哪些没想起来。本 SKILL 不判对错——
“想起来的对不对”是理解验证，那是费曼学习法的事；这里只是把笔记再过一遍。

Step 4：学生自报回忆状态（只在本次会话内）
  想起来了 / 想起来一半 / 没想起来
  → 只用于决定这次先看哪几条；回忆状态不写入长期档案，不生成复测提醒。
     （“这页笔记被调取过几次、提示后有没有用上”是另一回事：那是模块E 的使用计数，开启档案后才记，且只记次数不记内容。）
  → 学生说“这条我想验证一下是不是真懂了” → 转费曼学习法。

小智的角色：
出示线索问题 → 等学生自己回忆 → 让学生自己翻右栏对照 → 问一句“哪几条想再看”
不出示“标准答案”、不评判、不记状态。
"第三个问题：'[Q3]'——你的回答是什么？"
```

## 九、与其他SKILL的协作

```
康奈尔笔记 SKILL
    ←── 学习DNA（调取学科信息，确保归档正确）
    ──→ 学习DNA（subject_profile_writeback → extensions.notes）
    ──→ 错题本SKILL（错题分析时按需提示相关笔记）
    ──→ 费曼学习法SKILL（费曼测试时提供笔记锚点）
    ──→ IM智能提醒（reminder_enqueue：复习提醒附带线索问题）
    ──→ 学习系统协调器（在联动工作流中提供笔记摘要）
    ──→ 每周学习复盘SKILL（提供本周笔记健康数据）
```

交接格式见 `shared/handover-protocol.schema.json`。本 SKILL 不自行承诺提醒时间，只入队。
