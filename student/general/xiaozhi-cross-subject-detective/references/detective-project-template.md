# 跨学科侦探周项目记录模板

> 适用学段：小学高段（用 §五 的简化版）、初中、高中（用 §一至 §四 完整版）。
> 本文档为 `xiaozhi-cross-subject-detective` 的配套记录模板。
> 长期存储：项目本身落在 `extensions.projects[]`，联结落在 `growthMap.conceptGraph`
> （见 `../../xiaozhi-learning-dna/schemas/dna-profile.schema.json`）。

---

## 一、开题记录（Step 1-2，第一天填）

```
【侦探周开题】
主题：__________（如：丝绸之路 / 城市化 / 一条河的上下游）
研究周期：____-__-__ 至 ____-__-__
选这个主题的原因（一句话，必须是学生自己的好奇心）：__________

打算从这几科切入（初中及以上 3-5 科，小学高段 2-3 科）：
  □ 历史：这一科最想弄清的问题 __________
  □ 地理：__________
  □ 语文：__________
  □ 数学：__________
  □ 物理 / 生物 / 其他：__________

小智留了一个空白视角让我先猜：
  猜的是：__________
  （几天后回来对照，看猜得准不准）
```

选题自检：这个主题够复杂吗（能撑起 3 科以上）？够具体吗（不是"世界历史"这种范围）？我真的好奇吗？

## 二、逐日深潜记录（Step 3-4，每天一段）

```
【第 [N] 天】日期：____-__-__   今天的视角：[学科]

今天的核心问题：__________

我提的延伸问题（至少 3 个）：
  1. __________
  2. __________
  3. __________

深潜到哪一级？
  □ 初级：问了基本概念（"这条路经过哪些地方"）
  □ 中级：问了因果（"为什么走这条线不走另一条"）
  □ 高级：问了反事实（"如果没有这条路，会怎样"）
  目标：至少到中级

今天最意外的一个发现：__________

和前几天的联结（每天结束前必答）：
  今天的 [内容A]（[学科]）和第 [N] 天的 [内容B]（[学科]）有关系：
  关系是：__________
  联结分级：□ 表层（同时代/同地点） □ 中层（一件事影响另一件事） □ 深层（受同一底层规律驱动）
```

## 四、写回字段对照表

| 模板栏位 | DNA 字段 | 说明 |
|---|---|---|
| 主题 / 周期 / 涉及学科 / 阶段 | `extensions.projects[]`（`projectId` / `theme` / `subjects[]` / `stage` / `startDate`） | `stage` 取 选题 / 调查 / 联结 / 展示 / 完成 |
| 模块四的节点 | `growthMap.conceptGraph.nodes[]` | `masteryLevel` 用三档（`shared/vocab.md §6`） |
| 模块四的边 | `growthMap.conceptGraph.edges[]` | `relationType` 只有四种；`discoverySource` 填"跨学科侦探周" |
| 模块一、二、三的正文 | 不写入DNA | 建议存进康奈尔笔记（带跨科标签） |

写入方式：项目走 `subject_profile_writeback`（`updateTarget: "extension"`），图谱走 `profile_writeback`（`updateTarget: "concept_graph"`）；两者都生成待确认条目，学生确认后落库。

## 五、小学高段简化版（一页纸）

```
【我的小侦探周】主题：__________

我从这两三科看了同一件事：
  ① [学科]：我知道了 __________
  ② [学科]：我知道了 __________
  ③ [学科]：我知道了 __________

我发现的一个联系：
  ____ 和 ____ 有关系，因为 __________

我还想弄清楚的一个问题：__________
```

小学高段不填模块三、四，联结由小智整理成一句话记进概念图谱即可；不要求分级。

---

## 六、填写纪律

1. **联结必须是学生自己说出来的**，小智可以给线索、指出"哪个条件还没用到"（提示阶梯 L3），但不替学生下结论。
2. **深层联结不强求**：一周能出一个中层联结就是成功的一周。
3. **不把跨科联结当成学科知识点的替代**：某一科没学会就是没学会，交给该科的 SKILL。
4. **临时出题要自检**：本模板本身不含任何题目；深潜过程中临时生成的题，发给学生前按 `shared/ai-item-check.md` 走一遍自检。
5. 学生随时可以说「查看我的项目记录」「删除我的项目记录」，删除后不可恢复，删除前确认一次。
