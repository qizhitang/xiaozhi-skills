## 0. 总体结论（审计当时）

> **状态：已整改。** 下表“现状”列为 v2.1.1 的实际情况。

这套 SKILL 的**教育理念层是好的**：不代做、不贴标签、苏格拉底式追问、支架渐退、危机例外优先、家长沟通低焦虑——这些设计在同类产品里少见。但它当时处于“**理念完备、内容与契约未经校验**”的状态，离一线可落地还差三层：

| 层 | 审计当时（v2.0） | 一句话判断 | **现状（v2.1.1）** |
|---|---|---|---|
| 合规与定位 | 全库 0 处提及“双减/校外培训”；独立教师包默认周末排课、60+ 课时包、试听转化 | 义务教育学科类场景下**不能直接上线** | ⏸ **未处理**。项目方决定本轮暂缓，判断依然成立；面向义务教育阶段学科类场景前必须先关闭本项 |
| 学科内容 | 六个域共发现 20+ 处“教错”（无解题、错误规则、错误类比、错误示范数据）；老师端物理三个 SKILL 整体是高中内容 | 未经学科教研审校，**会把错误教给学生和老师** | ✅ 26 处逐条修正；高中术语未标注即 CI 失败（G1）；含示例题的 references 须带验算日期声明（A1）。**学科教研员正式审校仍未做**（§5 阶段 3） |
| 数据契约 | 错因词表 4 套并存、schema 无学科落点、老师端接口字段虚构、`overdue` 不在枚举、6 组循环依赖 | 跨 SKILL 协作大部分是**纸面协议**，运行时无法成立 | ✅ 词表收敛为 `shared/vocab.md` 单一来源；schema 补齐学科落点与授权位；接口路径必须命中 schema 字段（I1）；循环依赖 0 组（F2） |
| 学段适配 | 声称 7-16 岁；30/58 SKILL 无学段词；仅 3 个有小学/中学分支 | 实际只对**初中生**基本适用，小学低段几乎不可用 | ✅ `grade_bands` 成为 frontmatter 必填并校验（F1）；`shared/grade-bands.md` 统一学段划分与参数表 |
| 一线可用性 | IM 场景单题流程 30 分钟+、要求学生手打结构化提示词、老师逐题标注 45×25 格 | 流程为“理想学生”设计，**未按 IM 与班额现实压缩** | ✅ CLAW 模板内部化、流程合并、每步轮次预算与退出策略、错题本快速记录模式 |

上一轮评估报告列出的修复项，当时复核结果：**真落地约 1/3，形式落地（改了 SKILL.md 没改 references、改了一处漏了同类）约 1/3，未落地约 1/3**。根因是修复只针对报告点名的行，没有建立“单一事实源 + CI 校验”，同类问题在其他文件原样存在或回归。

> **这条根因是本轮整改的重点。** v2.1.0 的做法是：先建 `shared/` 单一事实源，再把“同类问题”写成 CI 检查项而不是逐行修补——
> 现在 `npm run check` 跑 18 项校验（引用完整性 + 14 项内容级 + schema + 共享副本漂移），
> 任何一项不通过即失败。这样“改了一处漏了同类”不再可能悄悄发生。
