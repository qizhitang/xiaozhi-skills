## 0. 总体结论

这套 SKILL 的**教育理念层是好的**：不代做、不贴标签、苏格拉底式追问、支架渐退、危机例外优先、家长沟通低焦虑——这些设计在同类产品里少见。但它现在处于"**理念完备、内容与契约未经校验**"的状态，离一线可落地还差三层：

| 层 | 现状 | 一句话判断 |
|---|---|---|
| 合规与定位 | 全库 0 处提及"双减/校外培训"；独立教师包默认周末排课、60+ 课时包、试听转化 | 义务教育学科类场景下**不能直接上线** |
| 学科内容 | 六个域共发现 20+ 处"教错"（无解题、错误规则、错误类比、错误示范数据）；老师端物理三个 SKILL 整体是高中内容 | 未经学科教研审校，**会把错误教给学生和老师** |
| 数据契约 | 错因词表 4 套并存、schema 无学科落点、老师端接口字段虚构、`overdue` 不在枚举、6 组循环依赖 | 跨 SKILL 协作大部分是**纸面协议**，运行时无法成立 |
| 学段适配 | 声称 7-16 岁；30/58 SKILL 无学段词；仅 3 个有小学/中学分支 | 实际只对**初中生**基本适用，小学低段几乎不可用 |
| 一线可用性 | IM 场景单题流程 30 分钟+、要求学生手打结构化提示词、老师逐题标注 45×25 格 | 流程为"理想学生"设计，**未按 IM 与班额现实压缩** |

上一轮评估报告列出的修复项，本轮复核结果：**真落地约 1/3，形式落地（改了 SKILL.md 没改 references、改了一处漏了同类）约 1/3，未落地约 1/3**。根因是修复只针对报告点名的行，没有建立"单一事实源 + CI 校验"，同类问题在其他文件原样存在或回归。

### A. 定位与合规（P0）

1. **无"双减"定位声明**。全库 0 处提及双减/校外培训/学科类；`docs/installation-guide.md:126` 宣称适用 7-16 岁，`:213` 面向一对一/家教。独立教师包默认周末集中排课与寒暑假加课（`T/independent/schedule-manager/SKILL.md:282-288`、`weekly-schedule-template.md:31,59,73-80`）、"学期包 60+ 课时"（`renewal-report/SKILL.md:260`）、推荐新学员优惠（`:270-273`），均落在义务教育阶段学科类校外培训禁区。
   → 修法：README/architecture 增"合规适用范围矩阵"（学段 × 学科/非学科 × 机构/个人）；排课模板去掉周末/寒暑假默认值；课时包上限 ≤60 课时/3 个月；删推荐返利。

   - "基础班/提升班"、"哪些学生该进提升班"、"建议拆班"：`T/general/lesson-planner/SKILL.md:48,67`、`assignment-designer/SKILL.md:68`、`student-analyzer/SKILL.md:74,145`。
