本文档描述小智伴学 SKILL 库的完整清单、协作架构、数据契约、方法论依据与目录结构。当前版本 v2.1.0。

### 1.1 错因四维（vocab §1）

| 代码 | 维度 | 判定 |
|---|---|---|
| C | 概念模糊 | 换成"纯净版"最简题也做不对 |
| K | 计算失误 | 思路对、列式对，算错/抄错/漏单位 |
| R | 读题失误 | 把条件读对后立刻会做 |
| M | 方法用错 | 概念清楚、读题无误，但选错工具/路径 |

判定顺序 R → C → M → K；一道错题只记一个主维度，学科层再记一个子类型 ID。
学科子类型前缀：数学 B/C/R/M，物理 P/C/F/R/T，英语 G/V/T/P/L，语文 RC/AR/WT/CL/LG。

### 1.2 弱项状态五档与"3 次顽固"口径（vocab §4-§5）

`待处理 → 初步弱项 → 顽固弱项 → 突破中 → 已攻克`

- 粒度：同一知识点 + 同一通用四维；时间窗：滚动 28 天；**累计**（非连续），同日多次只计 1 次
- 计数权威：学生端唯一由**智能错题本**计数，学科错误 DNA 只接收"顽固"事件；老师端唯一由**作业跟进管家**计数
- 攻克标准：连续 2 次独立验证做对，间隔 ≥ 3 天，至少 1 次为换题型或纯净版验证

### 3.2 学科与通用扩展档案的写入方

```
subjectExtensions.math      ← 数学 5 个 SKILL
subjectExtensions.physics   ← 物理 5 个 SKILL
subjectExtensions.chinese   ← 语文 5 个 SKILL
subjectExtensions.english   ← 英语 5 个 SKILL（发音写 growthMap.oralGrowthTrack）
extensions.understanding    ← 费曼学习法
extensions.notes            ← 康奈尔笔记
extensions.focus            ← 时间与专注力教练
extensions.plans            ← 30天学习计划制定师
extensions.projects         ← 跨学科侦探周（并写 growthMap.conceptGraph）
interestDNA                 ← 兴趣成长探索计划
growthTrack                 ← 每周学习复盘
subjectMap / errorPatterns / growthMap.errorMap  ← 智能错题本
safetyRecord                ← 任何触发危机例外的 SKILL（只记处置事实）
```

协同白名单共 **30 个 SKILL**（通用 10 + 学科 20），未列入者默认不得读写档案。老师端经 `teacher_writeback` 写入，需 `teacherWritebackConsent`。

  ❌ 智能错题本            🎓 费曼 / 📝 笔记         🗓️ 计划 / ⏱️ 专注

```

学习系统协调器负责路由，包含**学科判别**：单位优先（N/Pa/Ω → 物理），图片优先（电路图/受力图 → 物理），判不准就问。

### 4.2 师生协同

老师端与学生端**不共享档案**，只通过 `teacher_writeback` 单向写入弱项与掌握度，且必须 `teacherWritebackConsent=true`。老师端内部数据落在两份工作空间 schema，学生一律化名或座号。

### 4.3 独立教师包

```
试听与学员建档 ─┐
                ├→ 排课与课时管理 ─┐
课后记录助手 ───┴──────────────────┼→ 独立教师工作台（只读聚合）

课后记录助手与试听建档**零依赖**，整包可脱离老师通用包独立安装。

## 五、方法论依据

| 设计 | 依据 | 落地位置 |

## 六、安全与授权模型

```
consentStatus
├── profileEnabled            是否建立长期档案
├── consentGivenBy            学生本人 / 监护人 / 学生与监护人
├── ageBand                   学段，推导 guardianConsentRequired
├── guardianConsentRequired   小学各段为真，必须监护人同意
├── crossSkillSharing         跨 SKILL 共享最小字段
├── parentSharingConsent      学习摘要可给家长
├── emotionSharingWithParent  情绪内容可给家长（须学生本人同意）
├── teacherWritebackConsent   老师端可写回
└── reminderConsent / emotionTrackingConsent / interestTrackingConsent
```

- 学生与家长共用会话时先确认说话人；无法确认按"学生本人"处理，不输出家长版内容。
- **危机例外优先于以上全部授权位**：出现自伤、轻生、霸凌、持续绝望、家庭安全信号时，立即停止本 SKILL 流程，不做低敏美化，如实提示可信成年人并给出求助渠道；档案只记"已转介"的处置事实。
- 控制入口六项：查看 / 更正 / 删除 / 暂停 / 共享控制 / 导出。
- 最小化记录：不记真实姓名、联系方式、住址、证件、医疗与家庭信息。
