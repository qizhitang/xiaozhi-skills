### 0.2 v1 → v2 决策变更

| 决策 | v1（09-13） | v2（09-22） | 依据 |
|---|---|---|---|
| 学段基线 | 学科技能只做初中 | **学科技能扩到初中 + 高中** | 中考降权、高考加权（§1.5） |
| 第一优先 | 化学（初中） | **物理高中化 + 化学（九年级→高中）** | 物理类考生六成以上；理工农医基本要求物理 + 化学（§1.4） |
| 物理 | 已有，不动 | **全路线图单位投入回报最高的一步**：就地延伸到高中 | 唯一"中考加权、高考首选"两头都硬的学科 |
| 初高衔接 | 化学包内 1 个技能 | **通用技能「初高衔接规划师」**，各学科技能带衔接章节 | 中考后暑假是多学科断档，不只化学 |
| 历史 | 初中开卷形态 | **高中首选科目为主**，初中开卷为辅 | 历史类考生近四成，按原始分计入 |
| 开卷 | 历史包内的技能 | **抽成通用技能**，服务道法、历史、生地开卷 | 多地"小四门"全开卷，道法与历史合卷开卷 |
| 生物 / 地理 | 初中"生地会考包" 4 + 2 | **高中生物、高中地理分开做**；初中会考降为轻量层 | 初中多数退出计分；高中选考不捆绑 |
| 遗传推理 | 撤销（不计分撑不起） | **恢复**，放进高中生物 | 高中遗传是选考与合格考核心，撤销理由在高中不成立 |
| 实验操作 | 未涉及 | **第零批先补物理，化学、生物随包** | 多地实验操作计入中考总分 |
| 道法 / 政治 | 不做 | **仍不做** | 内容风险未变；开卷技能只教方法、不产出观点 |

### 0.3 四条贯穿判断

1. **中考降权 + 高考加权 = 价值迁到高中。** 化学、生物、地理、历史在中考里被压分值、转等级、改开卷，在高考里却是选考科目且人人要过合格考。继续只做初中，等于在需求流出的地方投资。
2. **只有物理两头都硬。** 中考全部计分且在加权，高考是首选科目、按原始分计入。本库已有一套成熟的初中物理——延伸它比新建任何学科都便宜。
3. **形状由学科认知结构决定，不照抄物理的 5 个。** 历史 3 个、地理 3 个、生物 5 个，各有理由（§2.6、§2.7）。
4. **每加一个学科都要全库 bump 版本号**（schemaVersion 是单值 enum，58 份 SKILL.md 的 frontmatter 都带 version）。同批次多学科一起发更便宜。

**课标依据**：高中用 2025 日常修订版的文字版原文（生物学、地理均为 2017 年版 2025 年修订）；初中用 2022 年版原文（扫描件，按页读取），技能里注明"如有调整以修订版为准"。

## 1.4 高考：选考结构 ⭐

- **新高考覆盖**：2026 年 29 个省份进入新高考——"3+1+2" 23 省、"3+3" 6 省市（浙江、上海、北京、天津、山东、海南）。**新疆 2024 级起实行"3+1+2"，2027 年首考**；西藏已启动改革。
- **"3+1+2"**：语数外统考；**物理 / 历史二选一（首选科目，按原始分计入）**；思想政治 / 地理 / 化学 / 生物学四选二（再选科目，等级赋分）。
- **物理类约占六成**：

  | 省份 | 年份 | 物理类 | 历史类 | 物理类占比 |
  |---|---|---|---|---|
  | 河南 | 2025 | 55.5 万 | 约 35.2 万 | 约 61% |
  | 湖南 | 2025 | 18.5 万 | 10.7 万 | 约 63.4% |
  | 广东 | 2024 | 45.1 万 | 26.9 万 | 约 62.6% |

  河南口径为"100 分以上考生"共 90.7 万；原文历史类一处写 35 万、另一处写 36.2 万，与总数不自洽，此处取 90.7 − 55.5。

  录取端更倾斜：江苏 2021 年物理类报名占 55%，本科招生却占 74%；2022 年历史类报名占 43%，本科招生只占 21%。
- **选考科目要求：物理 + 化学绑定。** 理学、工学、农学、医学四大类本科专业基本要求物理 + 化学。按专业类统计，约七成要求物理、约六成要求化学（二手整理，原始口径待核）。
  2027 版要求小幅松动（中医学类、部分护理专业不再强制物理 + 化学），**物化绑定仍是主流**。
- **组合**：物化生是各省最常见的组合，史政地是历史类中最常见的组合；物化 + X 的专业覆盖率在 95% 以上。
- **学业水平合格性考试**：11 科（语数外、物化生、史地政、通用技术、信息技术）。**没选考的科目也要过合格线**——每个高中生都要学化学、生物、地理、历史、政治的必修内容。

### 1.8.1 「考试试题」口径：指启用前的统考密卷，不含日常作业题

原文在《指南》**"四、保障措施 →（三）教师"**节，与"不得作为替代性教学主体""未经授权不得复制传播他人作品"并列，是**教师职务行为条款**：

> 严禁将个人信息、考试试题等敏感数据输入 AI 工具，防止数据泄露与隐私侵害

四条证据：
1. **理由是保密，不是教学法。** 正文写"防止数据泄露与隐私侵害"，答记者问写"从源头上杜绝隐私泄露风险"。已公开的作业题无"泄露"可言。
2. **「考试试题」是法定术语。** 《教育工作中国家秘密及其密级具体范围的规定》（教育部、国家保密局）：国家级统考**启用前**试题（含副题）、参考答案、评分标准为**绝密级**；省级为**机密级**；地市级为**秘密级**。启用后密级下降或解除。**日常作业题、练习题不在该规定范围内。**
3. **学生一节的 6 条里没有这一条。** 学生被要求避免的是：作业中简单复制 AI 内容；用 AI 参加考试测验、作弊；创造性任务中滥用；未查权威资料前贸然用 AI 获取信息；输入个人信息；未授权复制传播作品。**没有一条禁止学生把题目输入 AI。**
4. **答记者问把主语放宽到"师生"**，但宾语仍是"考试试题"、理由仍是隐私泄露——放宽的是谁受约束，不是约束什么。

| # | 对本库的影响 | 涉及 |
|---|---|---|
| 1 | **学生拍题上传不受影响**，不用改 | 全库学科技能 |
| 2 | ⚠️ **老师端命题类技能直接踩线**：设计校级以上统考试卷，启用前即属国家秘密。现无相关边界 | `xiaozhi-teach-exam-designer`、`xiaozhi-teach-math-exam-designer`、`xiaozhi-teach-english-assessment`；`xiaozhi-teach-assignment-designer` 相邻 |
| 3 | 学生端补**"正在进行中的考试"识别**：既是作弊，也可能碰保密 | 全库学科解题类技能 |
| 4 | 指南是"不**输入**个人信息"，`SECURITY_BASELINE.md` 写的是"不**记录**"——应在读到疑似个人信息时主动提醒并不落库 | `SECURITY_BASELINE.md` |

> 💡 学生节第 4 条"避免在未查阅高质量教材或权威资料前贸然使用 AI"与 `shared/hint-ladder.md` 的 L0 天然契合，可补进 `docs/architecture.md` §五。

## 2.3 物理高中化（第一批）

**决定：就地延伸现有 5 个学生端技能，不另起高中技能。**

三个理由：
1. **档案连续性是本库的独特价值。** 学习DNA 是长期档案，同一个学生从九年级到高一的物理档案应当连续——断档恰恰发生在这里。拆成两套技能等于在断档处把档案也切断。
2. **不增技能数**：不抢触发、不占发布配额。
3. **方法论对高中同样成立**：四步法（读题画图 → 建模 → 列式 → 检验）、错因五维 P / C / F / R / T、图景优先。

**分两步：**
- **第一步（第一批）只做高一衔接段**：运动的描述、匀变速直线运动、相互作用、牛顿运动定律。这是初中到高中的主要跃迁段——标量走向矢量，公式走向图像，受力分析从单体走向连接体。
- **第二步（后续）**：其余必修与选择性必修。

| 技能 | 第一步要加的 |
|---|---|
| 🧲 物理解题教练 | 高一样板题；图像法（v-t、x-t）；描述改为"初中与高中" |
| 🧬 物理错误DNA | 高中子类型续编号（§2.2 #6） |
| 💡 物理概念直觉器 | 高一迷思：速度与加速度、力与运动、惯性 |
| 📐 物理建模教练 | 初中五类模型之后接高一模型：匀变速直线、追及相遇、共点力平衡、连接体、板块、传送带 |
| 🔬 物理实验思维教练 | ①**中考实验操作考试模块**（第零批，评分点、操作顺序、安全规范、易错点）；②高一必做实验（纸带与打点计时器、探究加速度与力和质量的关系、验证力的平行四边形定则） |

老师端 3 个物理技能暂不动，列入第三批之后。

## 2.4 化学：九年级→高中贯通（第一批）

> **定位（v2 改写）**：九年级化学在中考普遍低权重（典型 50–70，安徽 40、云南 30），北京、西安已退出录取计分——

## 2.5 两个通用技能（第一批、第二批各一）

### 🪜 初高衔接规划师 `xiaozhi-bridge-planner`（第一批，`student/general/`）

- **时间窗**：中考结束到高一上期中。
- **做什么**：诊断数学、物理、化学、英语的衔接缺口 → 排暑假与高一上的衔接计划 → 按学科路由到学科技能执行。

### 📖 开卷答题教练 `xiaozhi-openbook-coach`（第二批，`student/general/`）

- **服务**：道法与历史合卷开卷（河北、南京、重庆、安徽）、湖南"小四门"全开卷、吉林生地开卷。
- **做什么**：教材索引怎么建、考场上怎么定位、材料怎么组织成得分点——**开卷考的是检索与组织，不是记忆**。
- **边界**：只教方法。**不产出任何道法观点性内容**，观点性表述一律指回教材原文——这与"不做道法"一致。
- **为什么是通用技能**：开卷是考试形态，横跨四科。放在历史包里会漏掉道法和生地。
- `grade_bands`：初中。

> 不引入争议性解读。论述题要"自拟观点"，技能只帮学生从**史料**里找依据、检查论证结构，不替学生给出观点。

## 2.7 高中生物、高中地理：分开做（第三批）

> **定位（v2 改写）**：初中生地多数退出中考计分，会考合格即可；高中生物是物化生第三科、地理是史政地与物化地的常见科目，

## 2.8 两处框架改动（v1 保留，v2 扩充）

### 改动一：子类型编码改两字母

现有 pattern `^(RC|AR|WT|CL|LG|[A-Z])[0-9]{2}$`。单字母码在 4 个学科时已要靠 `subject` 字段消歧（物理错因表里 `物-C01` vs `数-C01` 的警告就是证据）；
到 8 个学科，`C` 同时是数学的计算、物理的概念、化学的宏观概念，人工阅读没法看。

新学科一律「学科前缀 + 维度」两字母：化学 `H*`、生物 `S*`、地理 `D*`、历史 `L*`。pattern 显式扩成：

```
^(RC|AR|WT|CL|LG|H[SMCREQ]|S[CFGVEQ]|D[MRPIEQ]|L[STKAE]|[A-Z])[0-9]{2}$
```

纯放宽，存量编码全部继续通过。历史用 `LK` 而不用 `LC`，是为了不和语文文言 `CL` 在人工阅读时相混；`L[STKAE]` 不含 `G`，与语文语病 `LG` 不冲突。
数学 / 物理的单字母存量不动——既有债，不值得为此做一次全库迁移。

### 改动二：新增第 7 份共享约定 `shared/lab-safety.md`

`safetyLevel` 三档定义现在藏在 `teacher/physics/xiaozhi-teach-physics-experiment-coach/references/experiment-types.md` 里——一个学科的 reference 承担了全库安全口径。
理化生都要用，必须提到共享层。内容：

- **跨学科硬红线**：**绝不向学生输出可在家自行操作的危险实验步骤**（"洁厕灵 + 84"是真实家庭事故场景）
- 化学：浓硫酸稀释顺序、可燃性气体点燃前验纯、CO 尾气处理、剩余药品不放回原瓶
- 生物：解剖刀片、微生物培养（不培养来源不明菌落、不开盖闻）、不接触野生动物
- 物理（已有）：220 V、激光笔
- **v2 新增：实验操作考试口径**——只讲操作步骤、评分点与安全规范，不替代真实动手练习；学生问"考试时能不能跳过某步"一律按规范作答

`scripts/sync-shared.mjs` 自动扫 `shared/*.md`，脚本不用动；README / architecture 里"6 份共享约定"要改成 7。

## 2.9 协调器学科判别：新冲突与两道门

| 冲突 | 判据 |
|---|---|
| **化学 vs 物理** | 看"**变化前后有没有新物质生成**"。溶液密度、气体压强这类交叉题，出现化学式 / 元素符号即判化学 |
| **生物 vs 化学** | 问生物体的结构 / 功能 / 过程 → 生物；问物质的组成 / 转化 / 计算 → 化学 |
| **历史 vs 语文** | 问史实、时序、历史评价 → 历史；问修辞、赏析、语言运用 → 语文 |
| **地理 vs 生物** | 问区域与空间分布 → 地理；问生物体与种群 → 生物 |
| **开卷 vs 学科** | 问"开卷怎么翻书、怎么组织答案" → 开卷答题教练；问某道题本身 → 学科技能 |

**两道门（v2 新增第二道）**：
- **年级门**：七八年级学生的化学提问 → 先问一句学校教没教过（五四制八年级开课，浙江等地在《科学》课里学）；没教过再说明未开课。
- **选科门**：高中学生先看 `basicInfo` 选科字段（§2.2 #5），没有就问一句"你是物理类还是历史类"。未选考的科目按**合格考深度**讲，不推选考难度；判不准就问，不凭猜测路由。
