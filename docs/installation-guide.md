# 🗺️ 安装指南

本文档给出在 WorkBuddy 中的安装方式、学生端与老师端的分阶段安装路径、按学段的适用性提示，以及打包上架的元数据建议。当前版本 **v2.1.0**。

> ⚠️ **两条原则**
> 1. SKILL 不是装得越多越好。先把 3-5 个用熟，再考虑加装。
> 2. 安装顺序必须符合依赖关系：被依赖的 SKILL 先装。各 SKILL 的 `depends_on` 已在 frontmatter 中声明，且全库无循环依赖（由 `npm run check` 校验）。

---

## 🤝 在 WorkBuddy 中安装

本库已上架 WorkBuddy 官方技能市场 **SkillHub**（[skillhub.cn](https://skillhub.cn)）。全部 SKILL 的 `compatibility` 已声明 `WorkBuddy / SkillHub / OpenClaw / ClawHub`。

WorkBuddy 的技能是可插拔模块：装好后不需要额外配置，模型依据每个 SKILL 的 `description` 自动判断是否调用，用完即走。

### 方式一 · 对话内一句话安装（最省事）

直接在 WorkBuddy 对话框里说要装什么，由内置的市场安装技能完成检索、下载与登记：

```text
安装 小智伴学 智能错题本
```

也可以只描述需求，让它替你找：

```text
帮我装一个能分析我错题原因、还能追踪反复出错知识点的技能
```

已安装过的会提示当前版本；市场上有新版时会先问你是否更新。

### 方式二 · 市场页安装

打开 [skillhub.cn](https://skillhub.cn) 搜索"小智伴学"，按学生端/老师端的分包选择安装。分包划分见本文《打包上架建议》一节。

### 共享约定：每个技能包已自带

本库不是 57 个互不相干的技能，而是一套共享同一份词表与数据契约的体系。SKILL 正文里有 **707 处**引用 `shared/` 的六份共享约定（错因四维、危机例外、提示阶梯、出题自检、平台降级、学段参数）。

为了让**单技能安装也能工作**，每个 SKILL 目录下都放了一份 `shared/` 副本：

```
xiaozhi-correction-notebook/
├── SKILL.md
├── references/
└── shared/            ← 六份共享约定，随包分发
    ├── vocab.md
    ├── platform-conventions.md
    ├── crisis-exception.md
    ├── hint-ladder.md
    ├── ai-item-check.md
    └── grade-bands.md
```

这样 `shared/vocab.md` 这类路径在两种场景下都能解析：整库使用时相对仓库根，单技能安装后相对技能目录。

除这六份外，被多个技能引用的**跨技能契约**也按需分发到引用方的 `shared/` 下（共 38 份副本）：

| 契约 | 源文件归属 | 分发给 |
|---|---|---|
| `handover-protocol.schema.json` | 学习系统协调器 | 引用交接协议的 24 个 SKILL |
| `dna-profile.schema.json` | 学习DNA | 读写档案字段的 11 个 SKILL |
| `english-error-dimension-table.md` | 英语语法突破教练 | 其余 4 个英语学生端 SKILL |

源文件仍留在归属技能里，归属技能用自己的原件、不重复复制；只有正文真正引用的技能才会拿到副本，包不会无谓变大。

副本由 `npm run sync:shared` 从源生成，Markdown 副本头部有"请勿直接编辑"横幅（JSON 为逐字节复制）；`npm run check` 会校验副本与源一致，并清理已不再引用的残留。**要改共享约定或契约，请改源文件再重新同步。**

### 方式三 · 整库安装（团队协作或需要改内容时推荐）

```bash
git clone https://github.com/qizhitang/xiaozhi-skills.git ~/.workbuddy/skills/xiaozhi-skills
```

需要随项目走、团队共享时装到项目级：

```bash
git clone https://github.com/qizhitang/xiaozhi-skills.git <你的项目>/.workbuddy/skills/xiaozhi-skills
```

装好后在 WorkBuddy 里执行 `/reload-skills` 重新扫描技能目录。

> ⚠️ **单技能安装的已知限制**：经上述分发后，仍有 **16 处跨技能引用**在单独安装时无法解析——3 处交接协议的示例 JSON、3 处语文错因维度表、2 处受力图指南、2 处跨学科联结、2 处遗忘曲线表，以及危机转介协议全文、初中实验清单、独立教师工作空间 schema 各 1 处。这些都是"想深入时可以去看"的补充材料，缺失不影响 SKILL 的主流程。需要完整体验请用整库安装，或把相关联的技能一并装上。

### 安装位置怎么选

| 位置 | 路径 | 适合 |
|---|---|---|
| 用户级 | `~/.workbuddy/skills/` | 个人使用，所有项目都能调用 |
| 项目级 | `<项目>/.workbuddy/skills/` | 教研组或团队共享，随仓库分发、可版本化 |

### 触发与指定

- **自动触发**：装好后直接说需求即可。本库每个 `description` 都写明了"处理什么"和"不处理什么、转给谁"，用于减少多个技能互相抢占。
- **手动指定**：需要点名时用 `@技能名`，例如 `@xiaozhi-correction-notebook`。
- **学科判别**：说"这道题我不会"而没讲学科时，由学习系统协调器按关键词、单位与图片特征判断转给数学还是物理；判不准会先问你一句。

### 安装顺序

WorkBuddy 不会自动解析本库 frontmatter 里的 `depends_on`，请按后文的阶段顺序自行安装。最低要求：**先装学习DNA**，它是其他 SKILL 的档案层。

### 更新与卸载

| 操作 | 市场安装 | 整库安装 |
|---|---|---|
| 更新 | 对话里说"更新 XXX 技能"，或按新版提示确认 | `git pull` 后执行 `/reload-skills` |
| 卸载 | 对话里说"卸载 XXX 技能" | 删除对应目录后执行 `/reload-skills` |
| 改内容 | 不建议就地改，改动会在更新时被覆盖 | 改仓库再 `git pull`，并跑 `npm run check` |

### 安全审查

建议安装前用 WorkBuddy 自带的技能审查工具跑一遍。本库自身的边界见 [`SECURITY_BASELINE.md`](../SECURITY_BASELINE.md)，其中授权主体、家长可见内容双门控与危机例外三条尤其需要在启用前读一遍。

本库**不设 `agent_created: true`**：这些 SKILL 由 git 维护并有 CI 校验，不希望被就地改写。需要修改请改仓库、跑校验、再拉取。

### 平台能力与降级

本库的 SKILL 在正文顶部用能力代号声明了依赖（如 `[M, T]` 表示需要跨会话记忆与定时任务），能力缺失时按 [`shared/platform-conventions.md`](../shared/platform-conventions.md) 降级并如实告知，而不是默默失效。若你的 WorkBuddy 环境没有定时能力，提醒类 SKILL 会改为"进入会话时补发到期项"。

### 装完先验证一次

```text
1. 说「查看我的档案」            → 应看到已记录内容与授权状态
2. 发一道做错的题                → 错题本应先问来源与状态，而不是直接给答案
3. 说「这次不要记忆」            → 本轮不应写入长期档案
4. 说「删除我的档案」            → 应先向你确认一次再执行
```

第 2 条若直接给出了答案，说明触发到的不是本库的错题本，用 `@xiaozhi-correction-notebook` 再试一次。

## 📐 先看学段

各 SKILL 的 `grade_bands` 字段声明了适用学段，完整参数（作息、专注时长、课时、适用性矩阵）见 [`shared/grade-bands.md`](../shared/grade-bands.md)。

| 学段 | 建议 |
|---|---|
| 小学低段（1-2 年级） | 本库暂不适用。建议由监护人或老师直接陪伴学习。 |
| 小学中段（3-4 年级） | 只装学习DNA（监护人开启）、错题本（快速记录模式）、费曼（前两跳）、每周复盘（三问版）。学科 SKILL 暂不适用。 |
| 小学高段（5-6 年级） | 上述 + 语文/英语学科 SKILL 的降级版；数学、物理学科 SKILL 仍以初中为基线，谨慎使用。 |
| 初中（7-9 年级） | 全库基线学段，所有 SKILL 均适用。 |
| 高中（10-12 年级） | 通用 SKILL 全部适用；学科 SKILL 中标 `⚠高中` 的内容为衔接材料，主体仍是初中口径。 |

## 🎒 学生端安装路径

### 第一阶段 · 核心四件套（第 1-2 周）

```
1. 🧬 学习DNA          → 完成授权与首次建档（其他 SKILL 的档案层）
2. ❌ 智能错题本        → 发一道近期错题，体验"找根因"而非"找答案"
3. ⏰ IM智能提醒        → 在你同意后，把这道题加入复习队列
4. 🎓 费曼学习法        → 挑一个刚学的知识点，讲给小智听
```

**验证**：能完成一次"错题 → 费曼验证 → 进入提醒队列"的闭环。

### 第二阶段 · 复盘与协同（第 3-5 周）

```
5. 📊 每周学习复盘      → 周末生成第一份基于证据的周报
6. 🔗 学习系统协调器    → 让多个 SKILL 之间的交接走统一协议
7. 📝 康奈尔笔记        → 把一页课堂笔记结构化入档（小学高段用两栏简化版）
```

### 第三阶段 · 自我管理（第 6-9 周）

```
8.  🗓️ 30天学习计划制定师  → 基于真实档案生成第一份计划
9.  ⏱️ 时间与专注力教练    → 记录第一周的时间流向
10. 🔭 跨学科侦探周        → 选第一个跨学科主题
11. ☕ 兴趣成长探索计划    → 启动 8 周试探（小学中/高段）或长周期探索
```

### 第四阶段 · 学科专项（按需，不必全装）

按当前最需要的学科选一个包，装完用两周再考虑下一个。

```
语文：📚 语文素材库 → 🔍 语病追踪档案 → 🖊️ 语文写作教练 → 📖 阅读理解拆解师 → 🏛️ 文言文复活计划
数学：🧬 数学错误DNA → 📐 数学解题教练 → 💡 数学概念解释器 → 📝 应用题数学建模教练 → 🎯 思维梯度训练师
英语：📖 智能词汇DNA系统 → 🎙️ 英语口语陪练 → 📝 英语语法突破教练 → 🎧 个性化英语听力训练师 → ✍️ 英语写作进化教练
物理：🧬 物理错误DNA → 🧲 物理解题教练 → 💡 物理概念直觉器 → 📐 物理建模教练 → 🔬 物理实验思维教练
```

> **依赖提示**：各学科的"错误DNA"由通用错题本推送错题，因此错题本要先装。反过来，**学科包对错题本是可选的**：没装学科包时，错题本只做通用四维分类与顽固计数，功能完整。英语听力训练师依赖词汇DNA；英语写作教练依赖语法教练。

## 👩‍🏫 老师端安装路径

### 校内班级老师

```
1. 教案设计器      2. 学情分析师      3. 测评设计师
4. 作业设计师      5. 课堂互动教练    6. 复习规划师
7. 对应学科教学 SKILL（语文 3 / 数学 3 / 英语 3 / 物理 3）
```

学情分析师需要**逐题得分**才能给出知识点热力图；只有总分时它只做分数分布。逐题数据与题号→知识点映射的格式见该 SKILL 的说明。

### 独立教师（一对一 / 小班）

```
1. 独立教师工作台    2. 试听与学员建档    3. 排课与课时管理
4. 课后记录助手      5. 家长沟通助手      6. 作业跟进管家
7. 阶段报告与续课助手  8. 教学资源复用库
9. 老师通用教学 SKILL（按需）  10. 对应学科教学 SKILL
```

独立教师包的全部数据落在 `teacher/independent/schemas/solo-teacher-workspace.schema.json`；课时扣减、作业状态等写入一律先生成**待确认条目**，由老师确认后入账。

## 🧰 开发者工具

`tools/xiaozhi-skill-creator/`（🛠️ SKILL 编写工具）面向想自建 SKILL 的开发者与高中生；它不读学生档案、不发交接、不在收发方枚举内，不属于学生日常学习任务，也不在学生包内分发。

## 🏷️ 打包上架建议

建议以"包"为单位分发：学生端 6 个包 + 老师端 3 个包 + 开发者工具。

| 包 | 内容 | 前置依赖 | 适用学段 |
|---|---|---|---|
| 核心通用包 | 学习DNA、错题本、IM提醒、费曼、每周复盘、学习系统协调器 | 无 | 小学中段起 |
| 自我管理包 | 康奈尔笔记、30天学习计划、时间与专注力、跨学科侦探周、兴趣探索 | 核心通用包 | 小学高段起（兴趣探索小学中段即可用）|
| 语文专项包 | 学生端语文 5 个 | 核心通用包 | 小学高段 / 初中 |
| 数学专项包 | 学生端数学 5 个 | 核心通用包 | 初中 |
| 英语专项包 | 学生端英语 5 个 | 核心通用包 | 小学高段 / 初中 |
| 物理专项包 | 学生端物理 5 个 | 核心通用包 | 初中 |
| 老师通用教学包 | 老师通用 6 个 | 无 | 小学中段–初中 |
| 独立教师日常包 | 独立教师 8 个 | 无（可独立安装，课后记录与试听建档零依赖）| 小学中段–高中 |
| 老师学科专项包 | 老师学科 12 个 | 老师通用教学包 | 按学科 |

**通用元数据**

| 字段 | 值 |
|---|---|
| 作者 | 小智伴学 |
| 版本 | v2.1.0 |
| 许可证 | MIT |
| 平台 | WorkBuddy / SkillHub · OpenClaw / ClawHub |
| 分类 | 教育 > K12 学习工具 / 教师工具 |

**推荐组合**

```
轻度学生：核心通用包 + 一个最需要的学科包
进阶学生：核心通用包 + 自我管理包 + 一到两个学科包
校内老师：老师通用教学包 + 对应学科专项
独立教师：老师通用教学包 + 独立教师日常包 + 对应学科专项
```

2. 说"这次不要记忆"，确认本轮不写入长期档案。
