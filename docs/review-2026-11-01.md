## 2. 留给教研员定的条目

复核时提出、但不属于明确的数值或事实错误，没有改。按文件列出，行号以本次提交后的文件为准（大致位置）。

**物理解题教学指导**
- 五步法模板 · 滑轮组追问“换成 4 段绳，效率不变”：一个动滑轮最多 3 段绳承重，4 段要再加动滑轮，G动 变大、效率下降；原答案隐含“动滑轮总重不变”，建议写明前提。
- 五步法模板 · “把它按得更深”：金属块吊在测力计下，用手按会多一个力，原意应是“放得更深”。
- 五步法模板 · ⚠高中 表里“a = f/m，v = v₀ + at”：减速时 a 取正值应写 v = v₀ − at。
- 变式题组 · 把 P = UI 称为“定义式”：教材的定义式是 P = W/t，P = UI 是普遍适用的计算式。
- 变式题组 · “四道题的电路图一模一样”：变式 4 把 R₂ 换成了滑动变阻器。

**物理实验教学指导**
- 数据处理评分 · 评分维度“区分系统/随机误差”：人教版初中教材不讲这种分类，要不要标 ⚠高中。
- 实验报告样例 · ρ 写作 2.7：27.0 g 与 10.0 cm³ 都是三位有效数字，严格应写 2.70 g/cm³；初中不要求有效数字运算。

**数学**
- 类比素材库 · 出租车起步价讲截距 b：真实计价分段，整条线不是 y = kx + b（SKILL.md 里的 y = 2x + 8 也是同样的简化），建议补边界说明。
- 类比素材库 · 水果类比把 x 当成“苹果”本身：是“字母代表物体”这一已知误区，也解释不了本条自己的追问“3x² 和 3x 是不是同类项”；建议补“x 是苹果的个数，是一个数”。
- 类比素材库 · 文件头写“每条类比后面都标了讲得到哪儿、讲不到哪儿”，实际约 11 条没有边界注：收窄这句话，还是补边界注。
- 类比素材库 · “(-3)×5 与 (+3)×5，两个因数里只有一个是负的”措辞；“5 天后你的钱比原来多了多少”的“原来”有歧义。
- 测评设计流程 · “选择 2-3 分”可能偏窄（有的地区每题 4 分）；“留 10-15% 检查时间”与题源占比建议未标“经验值”。
- 概念建构模板 · 代数式分类树没有根式（七年级范围内可接受）；“四步合计 ≤ 100%”而四段上限合计 105%。

**语文 · 语病题库**
- 类型③第5题改正①“相差悬殊”：题库当它无病，SKILL.md 却把“相差悬殊”列为赘余，两处口径要统一。
- 类型②第4题按题意含两处搭配错误，与“每题只含一个主病点”不符（已在声明注明为例外，是否换题）。
- 类型②第3题“各地真题一律判为动宾搭配不当”无法核实；表层是主语“条件”与宾语“改进”不搭。
- 类型⑥“A 对于 B 是陌生的”（主客颠倒）与速查表同条：教材经典例句，但“这里对我很陌生”是规范用法，“书本身不会陌生”的理由站不住；改正后的句子内容也别扭。
- 类型③第3题“在这本书里，描写了……”：按中考惯例判缺主语，有语法书认可为无主句。
- 类型④第4题甲：删一个词就能救，按口诀也可归赘余，各家归类不一。
- 术语与口诀：“‘我’是受事”（应为与事）、“的字结构”（应为定中短语）、状语顺序“情态/程度 → 对象”对程度副词不成立、“查四样”漏了主客颠倒、识别标志会误判“避免不必要的损失”。

**老师通用与独立教师**
- 作业评分与任务卡模板：§三 A 层“4 道基础题”与 §二 任务卡一“3 基础 + 1 中等”不一致，B 层题数也不一致；“抄错原题数字”归在计算失误，`shared/vocab.md` §3 归读题失误（SKILL.md 自己也有两处同样的矛盾）；“考前 3-7 天”的模板排到了考前 1 天。
- 三层教案示例与教案设计器 SKILL.md §7.2 不一致：弹性时间（A 层 20% 对 30%，B 层 0 对 10%）、B 层变式数（1 道对 2 道）、C 层在 25 分钟里加量；出租车题没有明确的问题，参考答案应是分段式。
- 资源入库示例：R-Q002、R-Q003 没有 `subject` 字段，而“题目”的入库要求列了它。

## 4. 行为回归

**未跑**：本次云端会话没有 Anthropic API 凭据（只有会话自己的代理地址，不能拿来跑项目的回归）。运行器已在上一轮修好（官方 SDK、自动重试、截断与拒答单独计数、提示缓存、记录用量）。

```bash

```

**成本粗估**：全量 1073 条用例，被测调用约 3,900 万字符输入（大部分走缓存读取）、判卷调用输入很小；按默认的 `claude-sonnet-5-5` 计价，粗估几十美元（约 30–80 美元，取决于中文的 token 数与思考长度），以试跑一个技能的实测用量为准。被测模型最好与用户实际所在平台的模型一致，可用 `EVAL_MODEL` 换。
